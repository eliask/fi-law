### 1 § Ministeriön organisaatio

<a id="section-1-subsection-1"></a>
#### \(1\)

Ympäristöministeriössä on:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yleinen osasto;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** ympäristönsuojeluosasto;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kaavoitus\- ja rakennusosasto; sekä

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** asunto\-osasto\.

<a id="section-2"></a>
### 2 § Ministeriön alaiset keskusvirastot

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön alaisina keskusvirastoina ovat asuntohallitus sekä vesi\- ja ympäristöhallitus\.

<a id="section-3"></a>
### 3 § Yleinen osasto

<a id="section-3-subsection-1"></a>
#### \(1\)

Yleisessä osastossa on:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** taloustoimisto; sekä

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** kansainvälisten asiain toimisto\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Yleinen osasto käsittelee asiat, jotka koskevat:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** virka\- ja työsuhteita sekä muuta ministeriön henkilöstöhallintoa;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** ministeriön sisäistä hallintoa ja järjestystä;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** ministeriön hallinnonalan virastojen henkilöstöhallintoa sekä hallinnon yleistä kehittämistä;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** rationalisointia ja tehokkuusvalvontaa;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** henkilöstökoulutusta sekä ministeriön hallinnonalan koulutustoiminnan yhteensovittamista;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** tiedotustoiminnan yhteensovittamista;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** asiakirjojen kirjaamista, lähettämistä ja arkistointia;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** edustusta tuomioistuimissa ja muissa viranomaisissa sekä laitoksissa ja yhteisöissä, jollei asia kuulu muun osaston käsiteltäviin;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** viranomaisille annettavia esityksiä ja lausuntoja, jos ne kuuluvat useiden osastojen toimialaan;

<a id="section-4-subsection-1-paragraph-10"></a>
- **10.** taloussuunnittelua, laskentatointa ja ministeriölle tilivirastona kuuluvia tehtäviä;

<a id="section-4-subsection-1-paragraph-11"></a>
- **11.** tulo\- ja menoarvioehdotusta sekä erityismenoarviota;

<a id="section-4-subsection-1-paragraph-12"></a>
- **12.** toimitiloja ja hankintoja;

<a id="section-4-subsection-1-paragraph-13"></a>
- **13.** tietohallinnon sekä tietotekniikan käyttöönoton yhteensovittamista;

<a id="section-4-subsection-1-paragraph-14"></a>
- **14.** kansainvälisten asioiden hoidon yhteensovittamista; sekä

<a id="section-4-subsection-1-paragraph-15"></a>
- **15.** sen mukaan kuin erikseen määrätään lainsäädäntö\- ja muita valmistelutehtäviä\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Yleinen osasto käsittelee myös ne muut ministeriön asiat, jotka eivät kuulu toisille osastoille\.

<a id="section-5"></a>
### 5 § Ympäristönsuojeluosasto

<a id="section-5-subsection-1"></a>
#### \(1\)

Ympäristönsuojeluosastossa on:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** suunnittelu\- ja kehittämistoimisto;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** luonnonsuojelutoimisto;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** jätehuoltotoimisto;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** vesiasiaintoimisto; sekä

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** ilmansuojelu\- ja meluntorjuntatoimisto\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Ministeriön yhteydessä toimivat ympäristönsuojeluneuvosto, jätehuollon neuvottelukunta, meriympäristöneuvottelukunta, vesiasiain neuvottelukunta, ilmansuojelun neuvottelukunta ja meluntorjunnan neuvottelukunta, joista on säädetty erikseen\.

<a id="section-6"></a>
### 6 §

<a id="section-6-subsection-1"></a>
#### \(1\)

Ympäristönsuojeluosasto käsittelee asiat, jotka koskevat:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** ympäristönsuojelun yleissuunnittelua, valvontaa, kehittämistä ja yhteensovittamista sekä tähän liittyvää suunnitelmien ja muiden toimien ympäristövaikutusten arviointia;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** ympäristönsuojelun tutkimusta;

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** ympäristön tilan seurantaa;

<a id="section-6-subsection-1-paragraph-4"></a>
- **4.** ympäristötietojärjestelmän kehittämistä;

<a id="section-6-subsection-1-paragraph-5"></a>
- **5.** ympäristötaloutta;

<a id="section-6-subsection-1-paragraph-6"></a>
- **6.** luonnonsuojelua ja maisemanhoitoa;

<a id="section-6-subsection-1-paragraph-7"></a>
- **7.** muuta kuin kaavoitukseen liittyvää maa\-ainesten ottamista;

<a id="section-6-subsection-1-paragraph-8"></a>
- **8.** ulkoilua ja muuta luonnon virkistyskäyttöä;

<a id="section-6-subsection-1-paragraph-9"></a>
- **9.** moottorikäyttöisten ajoneuvojen maastokäyttöä;

<a id="section-6-subsection-1-paragraph-10"></a>
- **10.** jätehuoltoa ja jätteiden hyödyntämistä;

<a id="section-6-subsection-1-paragraph-11"></a>
- **11.** ilmansuojelua;

<a id="section-6-subsection-1-paragraph-12"></a>
- **12.** vesiensuojelua sekä vesien käytön, hoidon ja suojelun kokonaissuunnittelua;

<a id="section-6-subsection-1-paragraph-13"></a>
- **13.** meriympäristön suojelua;

<a id="section-6-subsection-1-paragraph-14"></a>
- **14.** öljyvahinkojen torjuntaa;

<a id="section-6-subsection-1-paragraph-15"></a>
- **15.** kemikaalien ympäristöhaittojen ehkäisemistä;

<a id="section-6-subsection-1-paragraph-16"></a>
- **16.** meluntorjuntaa;

<a id="section-6-subsection-1-paragraph-17"></a>
- **17.** alan kansainvälistä yhteistoimintaa;

<a id="section-6-subsection-1-paragraph-18"></a>
- **18.** ympäristönsuojelun hallintoa, mikäli asia ei kuulu yleisen osaston käsiteltäviin; sekä

<a id="section-6-subsection-1-paragraph-19"></a>
- **19.** muuta ympäristönsuojelua\.

<a id="section-7"></a>
### 7 § Kaavoitus\- ja rakennusosasto

<a id="section-7-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosastossa on:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** tutkimus\- ja kehittämistoimisto;

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** kaavoitustoimisto; sekä

<a id="section-7-subsection-1-paragraph-4"></a>
- **4.** rakennusasiaintoimisto\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Ministeriön yhteydessä toimivat kaavoitus\- ja rakennusneuvosto, kaavoitus\- ja rakennustutkimuksen neuvottelukunta, maa\-ainesasiain neuvottelukunta, rakennusteknillinen neuvottelukunta sekä rakennussuojeluneuvottelukunta, joista on säädetty erikseen\.

<a id="section-8"></a>
### 8 §

<a id="section-8-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosasto käsittelee asiat, jotka koskevat:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** kaavoitusta ja muuta alueiden käytön suunnittelua;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** rakentamista ja rakennusvalvontaa;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** yhdyskuntasuunnittelua, rakentamista ja rakennettua ympäristöä koskevaa tutkimus\- ja kehittämistoimintaa sekä sen yhteensovittamista;

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** kaavoitusta ja rakentamista koskevia määräyksiä ja ohjeita sekä niiden yhteensovittamista;

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** rakennussuojelua, rakennusten korjaamista ja rakennetun ympäristön hoitoa;

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** kaavoitukseen liittyvää maa\-ainesten ottamista ja ympäristövaikutusten arviointia;

<a id="section-8-subsection-1-paragraph-7"></a>
- **7.** kaavoitus\- ja rakennustoimeen liittyvää yhdyskuntatekniikkaa;

<a id="section-8-subsection-1-paragraph-8"></a>
- **8.** lunastamista rakennuslain \(370/58\) nojalla ja kuntien etuosto\-oikeutta;

<a id="section-8-subsection-1-paragraph-9"></a>
- **9.** kaavoitusmittauksen ja kaavojen pohjakartoituksen ylintä valvontaa;

<a id="section-8-subsection-1-paragraph-10"></a>
- **10.** kiinteistötietojärjestelmän kehittämistä;

<a id="section-8-subsection-1-paragraph-11"></a>
- **11.** rakennusalan tyyppihyväksyntää;

<a id="section-8-subsection-1-paragraph-12"></a>
- **12.** rakennuslaissa ja kaavoitusalueiden jakolaissa \(101/60\) tarkoitettuja lupa\- ja muita asioita;

<a id="section-8-subsection-1-paragraph-13"></a>
- **13.** alan kansainvälistä yhteistoimintaa;

<a id="section-8-subsection-1-paragraph-14"></a>
- **14.** kaavoitus\- ja rakennustoimen hallintoa, mikäli asia ei kuulu yleisen osaston käsiteltäviin; sekä

<a id="section-8-subsection-1-paragraph-15"></a>
- **15.** muuta kaavoitus\- ja rakennustointa\.

<a id="section-9"></a>

<a id="section-10"></a>
### 10 § Ministeriön virkamiehet

<a id="section-10-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-10-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikkö;

<a id="section-10-subsection-1-paragraph-2"></a>
- **2.** yleisen osaston, ympäristönsuojeluosaston, kaavoitus\- ja rakennusosaston sekä asunto\-osaston osastopäälliköt;

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** apulaisosastopäälliköitä, joista on kaksi ympäristönsuojeluosastossa, kaksi kaavoitus\- ja rakennusosastossa ja yksi asunto\-osastossa;

<a id="section-10-subsection-1-paragraph-4"></a>
- **4.** hallitusneuvoksia, toimistopäälliköinä, jotka ovat yleisen osaston yleisen toimiston, ympäristönsuojeluosaston yleisen toimiston sekä kaavoitus\- ja rakennusosaston yleisen toimiston päälliköinä;

<a id="section-10-subsection-1-paragraph-5"></a>
- **5.** luonnonsuojelunvalvoja, toimistopäällikkönä, joka on ympäristönsuojeluosaston luonnonsuojelutoimiston päällikkönä;

<a id="section-10-subsection-1-paragraph-6"></a>
- **6.** toimistopäälliköitä muiden toimistojen päällikköinä;

<a id="section-10-subsection-1-paragraph-7"></a>
- **7.** hallitusneuvos, lainsäädäntöneuvos ja neuvotteleva virkamies;

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** vanhempia ja nuorempia hallitussihteereitä;

<a id="section-10-subsection-1-paragraph-9"></a>
- **9.** yliarkkitehtejä ja yli\-insinöörejä;

<a id="section-10-subsection-1-paragraph-10"></a>
- **10.** ylitarkastajia;

<a id="section-10-subsection-1-paragraph-11"></a>
- **11.** toimistoinsinöörejä;

<a id="section-10-subsection-1-paragraph-12"></a>
- **12.** erikoistutkijoita;

<a id="section-10-subsection-1-paragraph-13"></a>
- **13.** erikoissuunnittelijoita ja suunnittelijoita;

<a id="section-10-subsection-1-paragraph-15"></a>
- **15.** tiedotuspäällikkö ja tiedottaja;

<a id="section-10-subsection-1-paragraph-16"></a>
- **16.** koulutuspäällikkö;

<a id="section-10-subsection-1-paragraph-17"></a>
- **17.** kansainvälisten asiain sihteereitä;

<a id="section-10-subsection-1-paragraph-18"></a>
- **18.** kirjastonhoitaja;

<a id="section-10-subsection-1-paragraph-19"></a>
- **19.** kielenkääntäjä;

<a id="section-10-subsection-1-paragraph-20"></a>
- **20.** kamreeri ja pääkirjanpitäjä;

<a id="section-10-subsection-1-paragraph-21"></a>
- **21.** tarkastajia;

<a id="section-10-subsection-1-paragraph-22"></a>
- **22.** kirjaaja ja arkistonhoitaja;

<a id="section-10-subsection-1-paragraph-23"></a>
- **23.** ministerin sihteeri;

<a id="section-10-subsection-1-paragraph-24"></a>
- **24.** osastosihteereitä, julkaisusihteereitä, tiedotussihteereitä, koulutussihteeri ja avustaja;

<a id="section-10-subsection-1-paragraph-25"></a>
- **25.** toimistosihteereitä, toimistovirkailijoita, piirtäjiä, tekstinkäsittelijöitä, puhelinvaihteen hoitaja ja puhelunvälittäjä; sekä

<a id="section-10-subsection-1-paragraph-26"></a>
- **26.** ylivirastomestari ja virastomestareita\.

<a id="section-10-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä voi olla tulo\- ja menoarvion rajoissa tilapäisiä virkamiehiä ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-11"></a>
### 11 §

<a id="section-11-subsection-1"></a>
#### \(1\)

Osastopäälliköillä on ylijohtajan arvo\.

<a id="section-11-subsection-2"></a>
#### \(2\)

Ympäristönsuojeluosastossa on apulaisosastopäälliköillä ympäristönsuojeluneuvoksen arvo\.

<a id="section-11-subsection-3"></a>
#### \(3\)

Kaavoitus\- ja rakennusosastossa on apulaisosastopäälliköllä, joka on suorittanut arkkitehdin tai diplomi\-insinöörin tutkinnon, rakennusneuvoksen arvo ja apulaisosastopäälliköllä, joka on suorittanut oikeustieteen kandidaatin tutkinnon, hallitusneuvoksen arvo\. Kaavoitus\- ja rakennusosaston toimistopäälliköllä, joka on suorittanut arkkitehdin tai diplomi\-insinöörin tutkinnon, on yliarkkitehdin tai yli\-insinöörin arvo\.

<a id="section-11-subsection-4"></a>
#### \(4\)

Asunto\-osastossa on apulaisosastopäälliköllä, joka on suorittanut oikeustieteen kandidaatin tutkinnon, hallitusneuvoksen arvo\.

<a id="section-12"></a>
### 12 § Virkojen kelpoisuusvaatimukset

<a id="section-12-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena on:

<a id="section-12-subsection-1-paragraph-1"></a>
- **1.** kansliapäälliköllä virkaan soveltuva ylempi korkeakoulututkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-12-subsection-1-paragraph-2"></a>
- **2.** yleisen osaston osastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-12-subsection-1-paragraph-3"></a>
- **3.** ympäristönsuojeluosaston, kaavoitus\- ja rakennusosaston sekä asunto\-osaston osastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys hallintotehtäviin ja osaston toimialaan;

<a id="section-12-subsection-1-paragraph-4"></a>
- **4.** ympäristönsuojeluosaston ja asunto\-osaston apulaisosastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys hallintotehtäviin ja osaston toimialaan;

<a id="section-12-subsection-1-paragraph-5"></a>
- **5.** kaavoitus\- ja rakennusosaston apulaisosastopäälliköistä toisella virkaan soveltuva arkkitehdin tai diplomi\-insinöörin tutkinto sekä perehtyneisyys hallintotehtäviin ja osaston toimialaan ja toisella oikeustieteen kandidaatin tutkinto sekä perehtyneisyys hallintotehtäviin ja osaston toimialaan;

<a id="section-12-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksella, toimistopäällikkönä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-12-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköllä ja luonnonsuojelunvalvojalla, toimistopäällikkönä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys hallintotehtäviin ja toimiston toimialaan;

<a id="section-12-subsection-1-paragraph-8"></a>
- **8.** lainsäädäntöneuvoksella oikeustieteen kandidaatin tutkinto sekä lainvalmistelutyössä tarvittavaa tutkimus\- ja suunnittelutaitoa;

<a id="section-12-subsection-1-paragraph-9"></a>
- **9.** hallitusneuvoksella ja hallitussihteerillä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-12-subsection-1-paragraph-10"></a>
- **10.** yliarkkitehdillä arkkitehdin tutkinto;

<a id="section-12-subsection-1-paragraph-11"></a>
- **11.** yli\-insinöörillä virkaan soveltuva diplomi\-insinöörin tutkinto ja toimistoinsinöörillä virkaan soveltuva insinöörin tutkinto;

<a id="section-12-subsection-1-paragraph-12"></a>
- **12.** neuvottelevalla virkamiehellä, ylitarkastajalla, erikoistutkijalla, erikoissuunnittelijalla, suunnittelijalla, koulutuspäälliköllä, tiedotuspäälliköllä, kansainvälisten asiain sihteerillä, kirjastonhoitajalla ja tiedottajalla virkaan soveltuva ylempi korkeakoulututkinto;

<a id="section-12-subsection-1-paragraph-13"></a>
- **13.** kielenkääntäjällä virkaan soveltuva korkeakoulututkinto ja viran hoitamiseen tarvittava kielitaito;

<a id="section-12-subsection-1-paragraph-14"></a>
- **14.** avustajalla, kamreerilla, kirjaajalla, pääkirjanpitäjällä, arkistonhoitajalla, tiedotussihteerillä ja koulutussihteerillä virkaan soveltuva korkeakoulututkinto tai opistotason tutkinto;

<a id="section-12-subsection-1-paragraph-16"></a>

<a id="section-12-subsection-1-paragraph-17"></a>
- **17.** muilla virkamiehillä sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="section-13"></a>
### 13 § Virkojen täyttäminen

<a id="section-13-subsection-1"></a>
#### \(1\)

Kansliapäällikön, osastopäällikön, apulaisosastopäällikön, hallitusneuvoksen toimistopäällikkönä, luonnonsuojelunvalvojan toimistopäällikkönä, toimistopäällikön, hallitusneuvoksen ja hallitussihteerin nimittää tasavallan presidentti valtioneuvoston esityksestä\. Kansliapäällikön, osastopäällikön ja apulaisosastopäällikön virat täytetään haettavaksi julistamatta\.

<a id="section-13-subsection-2"></a>
#### \(2\)

Lainsäädäntöneuvoksen ja neuvottelevan virkamiehen nimittää valtioneuvosto\. Lainsäädäntöneuvos nimitetään määräajaksi, enintään viideksi vuodeksi kerrallaan\.

<a id="section-13-subsection-3"></a>
#### \(3\)

Muun henkilökunnan nimittää tai ottaa ministeriö\.

<a id="section-14"></a>
### 14 § Virkamiesten tehtävät

<a id="section-14-subsection-1"></a>
#### \(1\)

Kansliapäällikön tehtävänä on seurata ministeriön hallinnonalalla tapahtuvaa kehitystä sekä tehdä tarpeellisia aloitteita lainsäädännöllisiksi ja muiksi uudistuksiksi\. Kansliapäällikön tulee ministerin lähimpänä apuna sovittaa yhteen ministeriön eri osastojen toimintoja sekä osallistua laajakantoisten tai muutoin tärkeiden asioiden valmisteluun ja toteuttamiseen\. Kansliapäällikkö käsittelee myös asiat, jotka ministeri niiden tärkeyden tai laadun vuoksi antaa hänen käsiteltäväkseen\. Lisäksi kansliapäällikön tehtävistä on voimassa, mitä valtioneuvoston ohjesäännössä \(995/43\) on säädetty\.

<a id="section-15"></a>
### 15 §

<a id="section-15-subsection-1"></a>
#### \(1\)

Osastopäällikön tulee:

<a id="section-15-subsection-1-paragraph-1"></a>
- **1.** olla osaston toimialaan kuuluvissa asioissa ministerin apuna;

<a id="section-15-subsection-1-paragraph-2"></a>
- **2.** johtaa, sovittaa yhteen ja kehittää osaston toimintaa, huolehtia sen työskentelyedellytyksistä sekä valvoa, että osaston asiat hoidetaan tehokkaasti;

<a id="section-15-subsection-1-paragraph-3"></a>
- **3.** seurata hallintoa ja olojen kehitystä osaston toimialalla sekä tehdä tarpeellisia aloitteita lainsäädäntö\- ja muiksi uudistuksiksi;

<a id="section-15-subsection-1-paragraph-4"></a>
- **4.** huolehtia osaston toimialan tarkoituksenmukaisesta ja taloudellisesta suunnittelusta; sekä

<a id="section-15-subsection-1-paragraph-5"></a>
- **5.** käsitellä tärkeimmät osaston asiat\.

<a id="section-16"></a>
### 16 §

<a id="section-16-subsection-1"></a>
#### \(1\)

Apulaisosastopäällikön tehtävänä on:

<a id="section-16-subsection-1-paragraph-1"></a>
- **1.** johtaa, kehittää ja valvoa osastopäällikön apuna osaston toimintaa; sekä

<a id="section-16-subsection-1-paragraph-2"></a>
- **2.** käsitellä ne osastolle kuuluvat asiat, jotka työjärjestyksen mukaan kuuluvat apulaisosastopäällikölle tai jotka ministeri, kansliapäällikkö tai osastopäällikkö määrää hänen käsiteltäväkseen\.

<a id="section-17"></a>
### 17 §

<a id="section-17-subsection-1"></a>
#### \(1\)

Toimistopäällikön tehtävistä on soveltuvin osin voimassa, mitä 15§:ssä on osastopäällikön tehtävistä säädetty\.

<a id="section-18"></a>
### 18 §

<a id="section-18-subsection-1"></a>
#### \(1\)

Osastojen ja toimistojen sekä virkamiesten tehtävistä ja työnjaosta määrätään tarkemmin työjärjestyksessä, jonka ministeriö vahvistaa\. Työjärjestyksessä määrätään myös virkamiehet, jotka toimivat osastoilla toimistoihin kuulumattomina osastopäällikön välittömässä alaisuudessa\.

<a id="section-18-subsection-2"></a>
#### \(2\)

Vahvistetusta työnjaosta riippumatta virkamies on velvollinen tarvittaessa suorittamaan tehtävät, jotka ministeri, kansliapäällikkö, asianomainen osasto\- tai apulaisosastopäällikkö taikka toimistopäällikkö hänelle määrää\.

<a id="section-19"></a>
### 19 §

<a id="section-19-subsection-1"></a>
#### \(1\)

Kansliapäällikön ollessa estynyt toimii hänen sijaisenaan yleisen osaston osastopäällikkö tai tämänkin ollessa estynyt se tai ne osastopäälliköt, jotka ministeri määrää\.

<a id="section-19-subsection-2"></a>
#### \(2\)

Osastopäällikön ollessa estynyt toimii hänen sijaisenaan ministerin määräämä apulaisosastopäällikkö, toimistopäällikkö tai muu virkamies\.

<a id="section-19-subsection-3"></a>
#### \(3\)

Muiden virkamiesten sijaisuuksista määrää asianomainen osastopäällikkö\.

<a id="section-20"></a>
### 20 §

<a id="section-20-subsection-1"></a>
#### \(1\)

Jos syntyy epätietoisuutta siitä, minkä osaston käsiteltäväksi jokin asia kuuluu, ratkaisee tämän kansliapäällikkö, mikäli ministeri ei siitä määrää\.

<a id="section-20-subsection-2"></a>
#### \(2\)

Vastaavasti ratkaisee kansliapäällikkö osastojen yhteisten virkamiesten kohdalta ja osastopäällikkö osastonsa kohdalta, minkä virkamiehen tai toimiston käsiteltävä asia on\.

<a id="section-21"></a>
### 21 § Asiain ratkaiseminen

<a id="section-21-subsection-1"></a>
#### \(1\)

Kansliapäällikkö ratkaisee, mikäli valtioneuvoston ohjesäännön 32§:stä ei muuta johdu tai ministeri ole pidättänyt asiaa ratkaistavakseen, ne ministeriössä päätettävät asiat, jotka koskevat:

<a id="section-21-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista muulle viranomaiselle lain tai asetuksen säätämistä, muuttamista tai kumoamista koskevista ehdotuksista, jollei asia ole merkitykseltään vähäinen;

<a id="section-21-subsection-1-paragraph-2"></a>
- **2.** edellä 10§:n 1 momentin 19\-22 ja 24 kohdissa mainittujen virkamiesten nimittämistä sekä väliaikaisen hoitajan ja viransijaisen ottamista näihin virkoihin;

<a id="section-21-subsection-1-paragraph-3"></a>
- **3.** sellaisen tilapäisen ja työsopimussuhteisen henkilökunnan ottamista, jonka palkkaus vastaa enintään palkkausluokan A 20 mukaista palkkaa, jollei jäljempänä toisin säädetä;

<a id="section-21-subsection-1-paragraph-4"></a>
- **4.** muun kuin sellaisen virkavapauden myöntämistä, johon virkamiehellä on oikeus lain tai virkaehtosopimuksen nojalla, jollei valtioneuvoston ohjesäännön 12§:n 1 momentin 3 kohdasta tai 42§:stä muuta johdu eikä jäljempänä tässä asetuksessa toisin säädetä;

<a id="section-21-subsection-1-paragraph-4a"></a>
- **4a.** valtion virkamieslain \(755/86\) 30§:n 1 momentissa tarkoitetun sopimuksen tekemistä;

<a id="section-21-subsection-1-paragraph-5"></a>
- **5.** osastopäälliköiden ja heidän sijaistensa vuosilomajärjestystä ja vuosilomia;

<a id="section-21-subsection-1-paragraph-6"></a>
- **6.** ulkomaille tehtäviä virkamatkoja koskevan suunnitelman \(virkamatkasuunnitelma\) vahvistamista sekä, jollei muuta ole säädetty tai määrätty, virkamatkoja koskevien määräysten antamista; sekä

<a id="section-21-subsection-1-paragraph-7"></a>
- **7.** ministeriön sisäistä järjestystä\.

Ympäristönsuojeluosaston ilmansuojelu\- ja meluntorjuntatoimiston toimistopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-36-subsection-1-paragraph-1"></a>
- **1.** ilmansuojelulain \(67/82\) 13§:n 1 momentissa tarkoitetun luvan myöntämistä ilmoituksen tekemiseen säädettyä ajankohtaa myöhemmin;

<a id="section-36-subsection-1-paragraph-2"></a>
- **2.** ilmansuojelua koskevan lainan hyväksymistä korkotukilainaksi, kun lainan määrä on enintään 1 000 000 markkaa;

<a id="section-36-subsection-1-paragraph-3"></a>
- **3.** määrärahojen myöntämistä lääninhallituksille ilmansuojelulain 29§:n mukaisten valtionosuuksien maksamiseen; sekä

<a id="section-36-subsection-1-paragraph-4"></a>
- **4.** toimiston käytettäväksi käyttösuunnitelmassa tai muutoin asetettujen määrärahojen käyttämistä enintään 200 000 markan menoeriin asti\.

<a id="section-37"></a>
### 37 §

<a id="section-37-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-37-subsection-1-paragraph-1"></a>
- **1.** yleiskaavan taikka sen muutoksen tai kumoamisen vahvistamista;

<a id="section-37-subsection-1-paragraph-2"></a>
- **2.** asema\- ja rakennuskaavan taikka sen muutoksen tai kumoamisen vahvistamista, milloin asiassa on tehty valitus tai ratkaisulla on olennaista merkitystä maankäytön järjestämisen kannalta;

<a id="section-37-subsection-1-paragraph-3"></a>
- **3.** rakennuslain mukaisia poikkeuslupia, milloin ratkaisulla on olennaista merkitystä maankäytön järjestämisen kannalta, sekä rakennustai muita kieltoja ja rakentamisrajoituksia;

<a id="section-37-subsection-1-paragraph-4"></a>
- **4.** poikkeusten myöntämistä Suomen rakentamismääräyskokoelman määräyksistä, milloin ratkaisulla on periaatteellista merkitystä;

<a id="section-37-subsection-1-paragraph-5"></a>
- **5.** kaavoitus\- ja rakennustoimen tutkimuksen vuosiohjelman hyväksymistä;

<a id="section-37-subsection-1-paragraph-6"></a>
- **6.** valtionosuuksien ja \-avustusten myöntämistä, jollei jäljempänä toisin säädetä; sekä

<a id="section-37-subsection-1-paragraph-7"></a>
- **7.** ympäristöministeriölle valitusviranomaisena tehtyjä valituksia kaavoitus\- ja rakennustoimen osalta\.

<a id="section-38"></a>
### 38 §

<a id="section-38-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston apulaisosastopäälliköt ratkaisevat työjärjestyksessä määrättävän työnjaon mukaisesti asiat, jotka koskevat:

<a id="section-38-subsection-1-paragraph-1"></a>
- **1.** asema\- ja rakennuskaavan taikka sen muutoksen tai kumoamisen vahvistamista 37§:n 2 kohdassa ja 41§:ssä mainittuja tapauksia lukuun ottamatta;

<a id="section-38-subsection-1-paragraph-2"></a>
- **2.** rakennuslain mukaisia poikkeuslupia, ei kuitenkaan 37§:n 3 kohdassa ja 41§:ssä mainituissa tapauksissa;

<a id="section-38-subsection-1-paragraph-3"></a>
- **3.** rakennusalan tyyppihyväksyntäpäätösten antamista; sekä

<a id="section-38-subsection-1-paragraph-4"></a>
- **4.** osaston määrärahojen käyttämistä hyväksytyn käyttösuunnitelman rajoissa\.

<a id="section-39"></a>
### 39 §

<a id="section-39-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston yleisen toimiston toimistopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-39-subsection-1-paragraph-1"></a>
- **1.** määrärahojen myöntämistä valtionosuuksiksi rakennustarkastajien palkkaukseen; sekä

<a id="section-39-subsection-1-paragraph-2"></a>
- **2.** valtionavustuksen myöntämistä aluearkkitehtien palkkaukseen\.

<a id="section-40"></a>
### 40 §

<a id="section-40-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston tutkimus\- ja kehittämistoimiston toimistopäällikkö ratkaisee toimiston käytettäväksi käyttösuunnitelmassa tai muutoin asetettujen määrärahojen käyttämistä koskevat asiat enintään 200 000 markan menoeriin asti\.

<a id="section-41"></a>
### 41 §

<a id="section-41-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston kaavoitustoimiston toimistopäällikkö, yliarkkitehti ja yli\-insinööri ratkaisevat työjärjestyksessä määrättävän työnjaon mukaisesti 37§:n 2 ja 3 kohdassa mainitut asiat, milloin niitä on pidettävä vähäisinä\.

<a id="section-42"></a>
### 42 §

<a id="section-42-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston rakennusasiaintoimiston toimistopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-42-subsection-1-paragraph-1"></a>
- **1.** rakentamisesta annettujen teknillisten määräysten ja ohjeiden soveltamista, ei kuitenkaan 43§:ssä mainituissa tapauksissa;

<a id="section-42-subsection-1-paragraph-2"></a>
- **2.** poikkeusten myöntämistä Suomen rakentamismääräyskokoelman määräyksistä muissa kuin 37§:n 4 kohdassa ja 43§:n 2 kohdassa tarkoitetuissa tapauksissa;

<a id="section-42-subsection-1-paragraph-3"></a>
- **3.** I\-luokan betonirakenteiden suunnittelijan ja työnjohtajan pätevyyttä; sekä

<a id="section-42-subsection-1-paragraph-4"></a>
- **4.** toimiston käytettäväksi käyttösuunnitelmassa tai muutoin asetettujen määrärahojen käyttämistä enintään 200 000 markan menoeriin asti\.

<a id="section-43"></a>
### 43 §

<a id="section-43-subsection-1"></a>
#### \(1\)

Kaavoitus\- ja rakennusosaston rakennusasiaintoimiston yli\-insinööri ratkaisee asiat, jotka koskevat:

<a id="section-43-subsection-1-paragraph-1"></a>
- **1.** rakentamisesta annettujen teknillisten määräysten ja ohjeiden soveltamista rakennusten paloturvallisuuden sekä lämpö\-, vesijohto\-ja ilmanvaihtolaitteiden osalta; sekä

<a id="section-43-subsection-1-paragraph-2"></a>
- **2.** poikkeusten myöntämistä Suomen rakentamismääräyskokoelman määräyksistä 1 kohdassa mainittujen asioiden osalta muissa kuin 37§:n 4 kohdassa tarkoitetuissa tapauksissa\.

<a id="section-45"></a>
### 45 §

<a id="section-45-subsection-1"></a>
#### \(1\)

Mikäli toisin ei ole säädetty, ministeriöstä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\.

<a id="section-46"></a>
### 46 § Voimaantulo

<a id="section-46-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1988\.

<a id="section-46-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan ympäristöministeriöstä 17 päivänä kesäkuuta 1983 annettu asetus \(571/83\) siihen myöhemmin tehtyine muutoksineen\. Kumottavan asetuksen nojalla annettu työjärjestys ja virastodemokratiaohjesääntö ovat kuitenkin edelleen voimassa, kunnes ympäristöministeriö toisin määrää\.

<a id="section-46-subsection-3"></a>
#### \(3\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä tarvittaviin toimenpiteisiin sen täytäntöönpanemiseksi\.

<a id="section-47"></a>
### 47 §

<a id="section-47-subsection-1"></a>
#### \(1\)

Täytettäessä virkaa, jonka hakuaika on päättynyt ennen 1 päivää maaliskuuta 1988, sovelletaan hakuajan päättyessä voimassa olleita kelpoisuusvaatimuksia\.
