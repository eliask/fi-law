### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Järjestelyosastossa on kansliatoimisto ja järjestelytoimisto\.

<a id="section-9"></a>
### 9 §

<a id="section-9-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikkö,

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** hallitusneuvoksia, joista yksi toimii keskusosaston ja yksi kiinteistöosaston osastopäällikkönä,

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** sotilasasiainosaston osastopäällikkö,

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** järjestelyosaston ja talousosaston osastopäälliköt, joilla on puolustusasiainneuvoksen arvonimi,

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** rakennusosaston osastopäällikkönä toimiva rakennusneuvos,

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksia, toimistopäällikköinä,

<a id="section-9-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköitä,

<a id="section-9-subsection-1-paragraph-8"></a>
- **8.** vanhempia ja nuorempia hallitussihteereitä,

<a id="section-9-subsection-1-paragraph-9"></a>
- **9.** vanhempia ja nuorempia toimistoesiupseereita sekä vanhempia toimistoupseereita,

<a id="section-9-subsection-1-paragraph-10"></a>
- **10.** arkkitehti, maanmittausinsinööri ja insinöörejä,

<a id="section-9-subsection-1-paragraph-11"></a>
- **11.** metsänhoitaja ja aluemetsänhoitajia,

<a id="section-9-subsection-1-paragraph-12"></a>
- **12.** pääsihteeri ja yleissihteeri,

<a id="section-9-subsection-1-paragraph-13"></a>
- **13.** ylitarkastajia, taloustarkastajia ja tarkastajia,

<a id="section-9-subsection-1-paragraph-14"></a>
- **14.** erikoistutkija,

<a id="section-9-subsection-1-paragraph-15"></a>
- **15.** esittelijöitä,

<a id="section-9-subsection-1-paragraph-16"></a>
- **16.** kamreereita, apulaiskamreereita ja vanhempi reviisori,

<a id="section-9-subsection-1-paragraph-17"></a>
- **17.** tiedotuspäällikkö,

<a id="section-9-subsection-1-paragraph-18"></a>
- **18.** suunnittelusihteeri, henkilöstösihteeri ja osastosihteereitä,

<a id="section-9-subsection-1-paragraph-19"></a>
- **19.** suunnittelija,

<a id="section-9-subsection-1-paragraph-20"></a>
- **20.** metsätalousinsinööri,

<a id="section-9-subsection-1-paragraph-21"></a>
- **21.** maanmittausteknikko,

<a id="section-9-subsection-1-paragraph-22"></a>
- **22.** sotilaspalotoimen tarkastaja,

<a id="section-9-subsection-1-paragraph-23"></a>
- **23.** ministerin sihteeri ja sihteereitä,

<a id="section-9-subsection-1-paragraph-24"></a>
- **24.** notaari ja kirjaajia, sekä

<a id="section-9-subsection-1-paragraph-25"></a>
- **25.** kartoittaja, pääkirjanpitäjä, ylivirastomestari, virastomestari, arkistonhoitaja, toimistosihteereitä, konekirjoittajia ja toimistovirkailijoita\.

<a id="section-9-subsection-2"></a>
#### \(2\)

Lisäksi puolustusministeriössä voi olla tilapäisiä virkamiehiä ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-10"></a>
### 10 §

<a id="section-10-subsection-1"></a>
#### \(1\)

Lisäksi vaaditaan erityisenä kelpoisuusvaatimuksena:

<a id="section-10-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköltä, pääsihteeriltä, yleissihteeriltä, ylitarkastajalta ja taloustarkastajalta virkaan soveltuva ylempi korkeakoulututkinto sekä kiinteistöosaston toimistopäälliköltä lisäksi hyvä perehtyneisyys hallintotoimiin ja talousosaston taloustarkastajalta perehtyneisyyttä tiliviraston tehtäviin;

<a id="section-20"></a>
### 20 §

<a id="section-20-subsection-1"></a>
#### \(1\)

Toimistopäällikkönä toimivat hallitusneuvos, toimistopäällikkönä ja toimistopäällikkö sekä ministeriön erikseen määräämänä muukin 9§:ssä tarkoitettu sellaisen viran haltija, johon kelpoisuusvaatimuksena vaaditaan ylempi korkeakoulututkinto\.

<a id="section-23"></a>
### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Muista kuin 22§:ssä tarkoitetuista ministeriössä päätettävistä asioista ratkaisee:

<a id="section-23-subsection-1-paragraph-5"></a>
- **5.** talousosaston osastopäällikkö asiat, jotka koskevat:

<a id="section-23-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** menoarvioon otettujen puolustusvoimien määrärahojen jakamista, sitten kun valtioneuvosto tai ministeriö on vahvistanut ne perusteet ja ehdot, joiden mukaan määrärahat on jaettava, sekä varainhoitovuotta aikaisempaan vuoteen kohdistuvan menon maksamista kulumassa olevan varainhoitovuoden vastaavaan tarkoitukseen käytettävissä olevasta määrärahasta;

<a id="section-23-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** myöhästyneinä esitettyjen matkalaskujen maksamista;

<a id="section-23-subsection-1-paragraph-5-subparagraph-c"></a>
  - **c.** hankintaennakoiden vakuuksien hyväksymistä; sekä

<a id="section-23-subsection-1-paragraph-5-subparagraph-d"></a>
  - **d.** kaluston ja muun siihen verrattavan omaisuuden hylkäämistä ja poistamista sekä tileistä poistoja\.
