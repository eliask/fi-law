<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Avoimen yhtiön perusilmoituksessa on mainittava:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** yhtiön toiminimi;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** päivä, jona yhtiösopimus on allekirjoitettu;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** kaikkien yhtiömiesten täydelliset nimet sekä heidän kansalaisuutensa ja kotipaikkansa;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** yhtiön toiminnan laatu;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** kunta, josta yhtiön toimintaa johdetaan;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** yhtiön postiosoite;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** kuka tai ketkä yhtiömiehistä kirjoittavat yhtiön toiminimen; sekä

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** jos yhtiöllä on toimitusjohtaja, tämän täydellinen nimi ja kotipaikka\.

<a id="section-6"></a>
### 6 §

<a id="section-6-subsection-1"></a>
#### \(1\)

Kommandiittiyhtiön perusilmoituksessa on mainittava:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** yhtiön toiminimi;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** päivä, jona yhtiösopimus on allekirjoitettu;

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** kaikkien yhtiömiesten täydelliset nimet sekä heidän kansalaisuutensa ja kotipaikkansa;

<a id="section-6-subsection-1-paragraph-4"></a>
- **4.** yhtiön toiminnan laatu;

<a id="section-6-subsection-1-paragraph-5"></a>
- **5.** kunta, josta yhtiön toimintaa johdetaan;

<a id="section-6-subsection-1-paragraph-6"></a>
- **6.** yhtiön postiosoite;

<a id="section-6-subsection-1-paragraph-7"></a>
- **7.** äänettömien yhtiömiesten omaisuuspanosten arvo rahassa ilmaistuna;

<a id="section-6-subsection-1-paragraph-8"></a>
- **8.** kuka tai ketkä vastuunalaisista yhtiömiehistä kirjoittavat yhtiön toiminimen; sekä

<a id="section-6-subsection-1-paragraph-9"></a>
- **9.** jos yhtiöllä on toimitusjohtaja, tämän täydellinen nimi ja kotipaikka\.

<a id="section-14"></a>
### 14 §

<a id="section-14-subsection-1"></a>
#### \(1\)

Muutosilmoitus on myös tehtävä, milloin avoimen yhtiön tai kommandiittiyhtiön yhtiösopimukseen, osakeyhtiön yhtiöjärjestykseen taikka osuuskunnan, säästöpankin tai hypoteekkiyhdistyksen sääntöihin taikka vakuutusyhdistyksen yhdistysjärjestykseen tehdään muutos\.

<a id="section-18"></a>
### 18 §

<a id="section-18-subsection-1"></a>
#### \(1\)

Avoimen yhtiön, kommandiittiyhtiön, osakeyhtiön, osuuskunnan, säästöpankin ja vakuutusyhdistyksen selvitys\- ja suoritustilan samoin kuin avoimen yhtiön, kommandiittiyhtiön, osakeyhtiön ja osuuskunnan sulautumisen johdosta rekisteriviranomaiselle toimitettavista tiedonannoista ja ilmoituksista on säädetty erikseen\.
