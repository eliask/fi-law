# Asetus eräistä opetusministeriön hallinnonalan virkajärjestelyistä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion ammatillisissa oppilaitoksissa lakkautetaan ja oppilaitoksiin perustetaan seuraavat peruspalkkaiset virat:

<a id="section-1-subsection-2"></a>
#### \(2\)

Lakkautetaan:

<a id="section-1-subsection-3"></a>
#### \(3\)

Kainuun ammattioppilaitos

<a id="section-1-subsection-3-paragraph-1"></a>
- **1.** yksi C 36 palkkausluokkaan kuuluva lehtorin \(ammatilliset aineet\) virka \(Vaala\); ja

<a id="section-1-subsection-3-paragraph-2"></a>
- **2.** yksi C 47 palkkausluokkaan kuuluva lehtorin \(ammatilliset aineet\) virka \(Kajaani\);

<a id="section-1-subsection-4"></a>
#### \(4\)

Perttulan erityisammattikoulu

<a id="section-1-subsection-4-paragraph-1"></a>
- **1.** yksi A 10 palkkausluokkaan kuuluva ohjaajan virka;

<a id="section-1-subsection-4-paragraph-2"></a>
- **2.** yksi A 7 palkkausluokkaan kuuluva hoitajan virka; ja

<a id="section-1-subsection-4-paragraph-3"></a>
- **3.** yksi A 7 palkkausluokkaan kuuluva toimistovirkailijan virka\.

<a id="section-1-subsection-5"></a>
#### \(5\)

Perustetaan:

<a id="section-1-subsection-6"></a>
#### \(6\)

Ammattioppilaitokset

<a id="section-1-subsection-6-paragraph-1"></a>
- **1.** kaksi C 38 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet\) virkaa;

<a id="section-1-subsection-7"></a>
#### \(7\)

Vammaisten ammattikoulut

<a id="section-1-subsection-7-paragraph-1"></a>
- **1.** yksi A 10 palkkausluokkaan kuuluva toimistosihteerin virka; ja

<a id="section-1-subsection-7-paragraph-2"></a>
- **2.** yksi C 40 palkkausluokkaan kuuluva ammattiopettajan virka\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 15 päivänä lokakuuta 1988\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella perustettu virka voidaan täyttää ensimmäisellä kerralla sitä haettavaksi julistamatta\.
