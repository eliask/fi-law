### 1 § Ministeriön organisaatio

<a id="section-1-subsection-1"></a>
#### \(1\)

Sisäasiainministeriössä on:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yleinen osasto;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** lääni\- ja kuntaosasto;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** aluepoliittinen osasto;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** poliisiosasto;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** pelastusosasto; sekä

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** rajavartio\-osasto\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Ministeriössä on lisäksi ulkomaalaiskeskus\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Poliisiosasto toimii poliisin ylijohtona\. Rajavartio\-osastona on rajavartiolaitoksen esikunta\.

<a id="section-2"></a>
### 2 § Ministeriön alaiset virastot ja laitokset

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön alaisia ovat:

- **1.** lääninhallitukset;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** väestörekisterikeskus;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** keskusrikospoliisi;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** suojelupoliisi;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** liikkuva poliisi;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** poliisiopisto;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** poliisikoulu;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** poliisikoiralaitos;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** poliisivarikot;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** pelastushallinnon koulutuskeskus; sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** rajavartiolaitos\.

<a id="section-3"></a>
### 3 § Yleinen osasto

<a id="section-3-subsection-1"></a>
#### \(1\)

Yleisessä osastossa on:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto; ja

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** taloustoimisto\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ministeriön apuna on hengenpelastusmitalilautakunta, josta on säädetty erikseen\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Yleinen osasto käsittelee asiat, jotka koskevat:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** ministeriön sisäistä hallintoa ja järjestystä;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** ministeriön virka\- ja työsuhteita;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** ministeriön henkilöstökoulutusta, nimikirjanpitoa, työnantajan ja henkilöstön yhteistoimintaa sekä muuta henkilöstöhallintoa;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** työjärjestystä ja tiliohjesääntöä;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** ministeriön asiakirjojen kirjaamista, lähettämistä ja arkistointia;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** tiedotusta, mikäli asia ei kuulu muun osaston käsiteltäviin;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** rationalisointia ja tehokkuusvalvontaa;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** ministeriön edustusta tuomioistuimissa ja muissa viranomaisissa sekä laitoksissa ja yhteisöissä, mikäli asia ei kuulu muun osaston käsiteltäviin;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** viranomaisille annettavia esityksiä ja lausuntoja, mikäli ne kuuluvat useamman kuin yhden osaston käsiteltäviin;

<a id="section-4-subsection-1-paragraph-10"></a>
- **10.** ministeriön toimitiloja sekä kalustoa ja tarvikkeita;

<a id="section-4-subsection-1-paragraph-11"></a>
- **11.** toiminnan ja talouden suunnittelua;

<a id="section-4-subsection-1-paragraph-12"></a>
- **12.** tulo\- ja menoarvioehdotusta sekä erityismenoarviota;

<a id="section-4-subsection-1-paragraph-13"></a>
- **13.** ministeriölle tilivirastona kuuluvia tehtäviä;

<a id="section-4-subsection-1-paragraph-14"></a>
- **14.** kansainvälisiä asioita, mikäli asia ei kuulu muun osaston käsiteltäviin; sekä

<a id="section-4-subsection-1-paragraph-15"></a>
- **15.** tietotekniikan käytön yhteensovittamista ministeriössä\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Osasto käsittelee myös ne muut ministeriön asiat, jotka eivät kuulu toisille osastoille\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Lääni\- ja kuntaosasto voi jakaantua toimintayksiköihin siten kuin työjärjestyksellä määrätään\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Ministeriön apuna ovat kantokykyluokitustoimikunta ja väestökirja\-asiain neuvottelukunta, joista on säädetty erikseen\. Ministeriön yhteydessä toimivat kunnallistalouden ja \-hallinnon neuvottelukunta sekä julkisen hallinnon tietohallinnon neuvottelukunta, joista myös on säädetty erikseen\.

<a id="section-6"></a>
### 6 §

<a id="section-6-subsection-1"></a>
#### \(1\)

Lääni\- ja kuntaosasto käsittelee asiat, jotka koskevat:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** yleistä hallinnollista jaotusta;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** lääninhallintoa;

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** valtion yleistä paikallishallintoa;

<a id="section-6-subsection-1-paragraph-4"></a>
- **4.** väestökirjanpitoa;

<a id="section-6-subsection-1-paragraph-5"></a>
- **5.** ulkomaalaisten ja ulkomaalaisten yhteisöjen oikeutta omistaa ja hallita kiinteätä omaisuutta;

<a id="section-6-subsection-1-paragraph-6"></a>
- **6.** kuntajakoa ja kaupunkien perustamista;

<a id="section-6-subsection-1-paragraph-7"></a>
- **7.** kunnallishallintoa;

<a id="section-6-subsection-1-paragraph-8"></a>
- **8.** kunnallistaloutta;

<a id="section-6-subsection-1-paragraph-9"></a>
- **9.** kuntien kantokykyluokitusta;

<a id="section-6-subsection-1-paragraph-10"></a>
- **10.** kunnallista työmarkkinalaitosta; sekä

<a id="section-6-subsection-1-paragraph-11"></a>
- **11.** kunnallista eläkelaitosta\.

<a id="section-7"></a>
### 7 § Aluepoliittinen osasto

<a id="section-7-subsection-1"></a>
#### \(1\)

Aluepoliittisessa osastossa on:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** hallintotoimisto;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** suunnittelu\- ja tutkimustoimisto;

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** seuranta\- ja kehittämistoimisto; sekä

<a id="section-7-subsection-1-paragraph-4"></a>
- **4.** maaseutu\- ja saaristoasiain toimisto\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Ministeriön yhteydessä toimivat aluepoliittinen neuvottelukunta, saaristoasiain neuvottelukunta, saamelaisasiain neuvottelukunta ja saamelaisvaltuuskunta, joista on säädetty tai määrätty erikseen\.

<a id="section-8"></a>
### 8 §

<a id="section-8-subsection-1"></a>
#### \(1\)

Aluepoliittinen osasto käsittelee asiat, jotka koskevat:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** aluepolitiikkaa ja siihen liittyvää yhteiskuntapoliittista suunnittelua ja sen yhteensovittamista;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** aluepoliittisia kehittämistoimia ja niihin liittyviä muita toimia koskevien ehdotusten laatimista sekä tätä palvelevaa selvitystä ja tutkimusta;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** saamelaisia koskevien asioiden yhteensovittamista; sekä

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** saaristoa koskevien asioiden yhteensovittamista\.

<a id="section-9"></a>
### 9 § Poliisiosasto

<a id="section-9-subsection-1"></a>
#### \(1\)

Poliisiosastossa on:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** hallintotoimisto;

<a id="section-9-subsection-1-paragraph-2"></a>

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** teknillinen toimisto;

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** tietojärjestelmätoimisto\.

<a id="section-9-subsection-2"></a>
#### \(2\)

Ministeriön apuna on poliisiasiain neuvottelukunta, josta on säädetty erikseen\. Ministeriön yhteydessä toimivat rahankeräys\- ja tavara\-arpajaislautakunta sekä vartioimisliikelautakunta, joista myös on säädetty erikseen\.

- **2.** poliisihallintoa;

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** passintarkastusta;

<a id="section-10-subsection-1-paragraph-4"></a>
- **4.** Suomen kansalaisen oikeutta matkustaa maasta;

<a id="section-10-subsection-1-paragraph-5"></a>
- **5.** rajanylitystä;

<a id="section-10-subsection-1-paragraph-6"></a>
- **6.** rikoksentekijöiden luovuttamista;

<a id="section-10-subsection-1-paragraph-7"></a>
- **7.** luvanvaraisten yhdistysten perustamista ja yhdistysten toiminnan valvontaa;

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** eräiden erikseen säänneltyjen elinkeinojen harjoittamisen valvontaa;

<a id="section-10-subsection-1-paragraph-9"></a>
- **9.** arpajaislaissa \(491/65\) säädettyjä toimintoja ja rahankeräyksiä;

<a id="section-10-subsection-1-paragraph-11"></a>

<a id="section-14-subsection-1-paragraph-2"></a>

<a id="section-14-subsection-1-paragraph-3"></a>

- **4.** yleisen osaston, lääni\- ja kuntaosaston, aluepoliittisen osaston ja pelastusosaston osastopäälliköt;

- **27.** toimistosihteereitä, lomakesuunnittelija, toimistovirkailijoita, tekstinkäsittelijöitä ja konekirjoittajia; sekä

<a id="section-14-subsection-2"></a>

Lisäksi ministeriössä voi olla tulo\- ja menoarvion rajoissa tilapäisiä virkamiehiä ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-14-subsection-3"></a>
#### \(3\)

Rajavartio\-osaston viroista on säädetty erikseen\.

<a id="section-15"></a>
### 15 §

<a id="section-15-subsection-1"></a>
#### \(1\)

Yleisessä osastossa on hallitusneuvos, toimistopäällikkönä, yleisen toimiston ja toimistopäällikkö taloustoimiston päällikkönä\.

<a id="section-15-subsection-3"></a>
#### \(3\)

Poliisiosastossa toimii toinen poliisiylitarkastaja osaston apulaispäällikkönä ja toinen poliisitoimiston päällikkönä sekä hallitusneuvos, toimistopäällikkönä, hallintotoimiston päällikkönä ja toimistopäälliköt muiden toimistojen päällikköinä\.

<a id="section-15-subsection-4"></a>
#### \(4\)

Pelastusosastossa on hallitusneuvos, toimistopäällikkönä, hallintotoimiston päällikkönä ja toimistopäälliköt muiden toimistojen päällikköinä\.

<a id="section-15-subsection-5"></a>
#### \(5\)

Ulkomaalaiskeskuksen päällikkönä on johtaja ja apulaispäällikkönä apulaisjohtaja\.

<a id="section-16"></a>
### 16 §

<a id="section-16-subsection-1"></a>
#### \(1\)

Ministeriö määrää 14, 15 ja 19§:stä ilmenevin rajoituksin, missä osastossa ja toimistossa tai muussa toimintayksikössä virkamiehen on toimittava\.

<a id="section-17"></a>
### 17 §

<a id="section-17-subsection-1"></a>
#### \(1\)

Lääni\- ja kuntaosaston, aluepoliittisen osaston ja pelastusosaston osastopäälliköillä on ylijohtajan arvonimi\.

<a id="section-17-subsection-2"></a>
#### \(2\)

Yleisen osaston osastopäälliköllä ja lääni\- ja kuntaosaston apulaisosastopäälliköllä on, mikäli he ovat suorittaneet oikeustieteen kandidaatin tutkinnon, hallitusneuvoksen arvonimi\.

<a id="section-17-subsection-3"></a>
#### \(3\)

Aluepoliittisen osaston apulaisosastopäälliköllä on aluepolitiikkaneuvoksen arvonimi\.

<a id="section-17-subsection-4"></a>
#### \(4\)

Poliisiosaston ja pelastusosaston teknillisen toimiston toimistopäälliköillä on yli\-insinöörin arvonimi\.

<a id="section-18"></a>
### 18 §

<a id="section-18-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena on:

<a id="section-18-subsection-1-paragraph-1"></a>
- **1.** kansliapäälliköllä virkaan soveltuva ylempi korkeakoulututkinto ja hyvä perehtyneisyys julkishallintoon;

<a id="section-18-subsection-1-paragraph-2"></a>
- **2.** poliisiylijohtajalla oikeustieteen kandidaatin tutkinto sekä hyvä perehtyneisyys poliisitoimeen ja hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-3"></a>
- **3.** osastoihin kuulumattomalla neuvottelevalla virkamiehellä virkaan soveltuva ylempi korkeakoulututkinto sekä hyvä perehtyneisyys kunnallishallintoon ja perehtyneisyys hallintotehtäviin sekä muulla neuvottelevalla virkamiehellä virkaan soveltuva ylempi korkeakoulututkinto ja perehtyneisyys asianomaisen osaston toimialaan kuuluviin tehtäviin;

<a id="section-18-subsection-1-paragraph-4"></a>
- **4.** osastopäälliköllä ja apulaisosastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä hyvä perehtyneisyys osaston toimialaan kuuluviin tehtäviin ja perehtyneisyys hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-5"></a>
- **5.** poliisiylitarkastajalla oikeustieteen kandidaatin tutkinto sekä hyvä perehtyneisyys poliisitoimeen ja perehtyneisyys hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-5a"></a>
- **5a.** ulkomaalaiskeskuksen johtajalla ja apulaisjohtajalla virkaan soveltuva ylempi korkeakoulututkinto sekä hyvä perehtyneisyys ulkomaalaiskeskuksen toimialaan kuuluviin tehtäviin ja perehtyneisyys hallintotehtäviin sekä viran hoitamiseen tarvittava kielitaito;

<a id="section-18-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksella toimistopäällikkönä ja hallitusneuvoksella oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-8"></a>
- **8.** aluepoliittisen osaston hallintotoimiston toimistopäälliköllä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-9"></a>
- **9.** poliisiosaston teknillisen toimiston ja pelastusosaston teknillisen toimiston toimistopäälliköllä virkaan soveltuva diplomi\-insinöörin tutkinto sekä perehtyneisyys toimiston toimialaan kuuluviin tehtäviin ja hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-10"></a>
- **10.** muulla toimistopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys toimiston toimialaan kuuluviin tehtäviin ja hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-10a"></a>
- **10a.** tietohallintopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto ja hyvä perehtyneisyys tietohallintoon;

<a id="section-18-subsection-1-paragraph-11"></a>
- **11.** hallitussihteerillä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-12"></a>
- **12.** yli\-insinöörillä virkaan soveltuva diplomi\-insinöörin tutkinto;

<a id="section-18-subsection-1-paragraph-13"></a>
- **13.** ylitarkastajalla, lukuunottamatta poliisiosaston poliisitoimiston ja tietojärjestelmätoimiston sekä ulkomaalaiskeskuksen ylitarkastajaa, tehtävien laadun mukaan joko virkaan soveltuva ylempi korkeakoulututkinto tai oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin taikka yhdellä pelastusosaston ylitarkastajalla upseerin tutkinto;

<a id="section-18-subsection-1-paragraph-14"></a>
- **14.** poliisiosaston poliisitoimiston ylitarkastajalla oikeustieteen kandidaatin tutkinto sekä perehtyneisyys poliisitoimeen ja hallintotehtäviin;

<a id="section-18-subsection-1-paragraph-15"></a>
- **15.** poliisiosaston tietojärjestelmätoimiston ylitarkastajalla joko virkaan soveltuva korkeakoulututkinto tai poliisipäällystön virkatutkinto ja perehtyneisyys tietojenkäsittelyyn;

<a id="section-18-subsection-1-paragraph-15a"></a>
- **15a.** ulkomaalaiskeskuksen ylitarkastajalla oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin sekä viran hoitamiseen tarvittava kielitaito;

<a id="section-18-subsection-1-paragraph-16"></a>
- **16.** poliisiosaston tietojärjestelmätoimiston erikoissuunnittelijalla joko virkaan soveltuva korkeakoulututkinto tai poliisialipäällystön virkatutkinto ja perehtyneisyyttä tietojenkäsittelyyn;

<a id="section-18-subsection-1-paragraph-18"></a>
- **18.** muulla erikoissuunnittelijalla, koulutuspäälliköllä, tiedotuspäälliköllä, suunnittelijalla, erikoistutkijalla, tutkijalla, koulutussuunnittelijalla ja tiedotussihteerillä virkaan soveltuva ylempi korkeakoulututkinto tai poliisiosaston koulutussuunnittelijalla poliisipäällystön virkatutkinto taikka poliisiosaston tiedotussihteerillä poliisipäällystön virkatutkinto ja perehtyneisyys tiedotustoimintaan;

<a id="section-18-subsection-1-paragraph-19"></a>
- **19.** toimistoinsinöörillä tehtävien laadun mukaan joko virkaan soveltuva diplomi\-insinöörin tutkinto tai insinöörin tutkinto;

<a id="section-18-subsection-1-paragraph-20"></a>
- **20.** poliisiosaston hallintotoimiston ja ulkomaalaistoimiston tarkastajalla oikeustieteen kandidaatin tutkinto, poliisitoimiston tarkastajalla varanotaarin tutkinto ja perehtyneisyys poliisitoimeen tai poliisipäällystön virkatutkinto sekä teknillisen toimiston tarkastajalla virkaan soveltuva opistotasoinen tutkinto, kuitenkin niin, että poliisin työsuojeluasioita hoitavalta tarkastajalta vaaditaan joko virkaan soveltuva korkeakoulututkinto tai poliisipäällystön virkatutkinto;

<a id="section-18-subsection-1-paragraph-20a"></a>
- **20a.** ulkomaalaiskeskuksen tarkastajalla tehtävien laadun mukaan joko oikeustieteen kandidaatin tutkinto tai muu virkaan soveltuva korkeakoulututkinto ja perehtyneisyys ulkomaalaiskeskuksen toimialaan kuuluviin tehtäviin taikka poliisipäällystön virkatutkinto ja perehtyneisyys ulkomaalaiskeskuksen toimialaan kuuluviin tehtäviin sekä viran hoitamiseen tarvittava kielitaito;

<a id="section-18-subsection-1-paragraph-21"></a>
- **21.** muulla tarkastajalla virkaan soveltuva teknillisen koulun tutkinto tai muu virkaan soveltuva tutkinto;

<a id="section-18-subsection-1-paragraph-22"></a>
- **22.** esittelijällä tehtävien laadun mukaan joko oikeustieteen kandidaatin tutkinto tai muu virkaan soveltuva ylempi korkeakoulututkinto;

<a id="section-18-subsection-1-paragraph-23"></a>
- **23.** kielenkääntäjällä virkaan soveltuva korkeakoulututkinto tai diplomikielenkääntäjän tutkinto sekä viran hoitamisen edellyttämä kielitaito;

<a id="section-18-subsection-1-paragraph-24"></a>
- **24.** kirjaajalla virkaan soveltuva korkeakoulututkinto tai virkaan soveltuva opistotason tutkinto;

<a id="section-18-subsection-1-paragraph-25"></a>
- **25.** kamreerilla, reviisorilla, tutkimussihteerillä, pääkirjanpitäjällä, osastosihteerillä, ministerin sihteerillä, apulaistarkastajalla ja apulaistutkijalla virkaan soveltuva tutkinto; sekä

<a id="section-18-subsection-1-paragraph-26"></a>
- **26.** muilla virkamiehillä sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="section-19"></a>
### 19 §

<a id="section-19-subsection-1"></a>
#### \(1\)

Kansliapäällikön, poliisiylijohtajan, osastopäällikön, osastoihin kuulumattoman neuvottelevan virkamiehen, apulaisosastopäällikön, poliisiylitarkastajan, ulkomaalaiskeskuksen johtajan ja apulaisjohtajan, hallitusneuvoksen toimistopäällikkönä, hallitusneuvoksen, toimistopäällikön ja hallitussihteerin nimittää tasavallan presidentti valtioneuvoston esityksestä\. Kansliapäällikön, poliisiylijohtajan, osastopäällikön, osastoihin kuulumattoman neuvottelevan virkamiehen, apulaisosastopäällikön, poliisiosaston apulaispäällikkönä toimivan poliisiylitarkastajan ja ulkomaalaiskeskuksen johtajan virka täytetään sitä haettavaksi julistamatta\.

<a id="section-19-subsection-2"></a>
#### \(2\)

Muun neuvottelevan virkamiehen ja tietohallintopäällikön nimittää valtioneuvosto\.

<a id="section-19-subsection-3"></a>
#### \(3\)

Muut virkamiehet samoin kuin työsopimussuhteisen henkilöstön nimittää tai ottaa ministeriö\.

<a id="section-19-subsection-4"></a>
#### \(4\)

Rajavartio\-osaston virkojen täyttämisestä on säädetty erikseen\.

<a id="section-20"></a>
### 20 § Virkamiesten tehtävät

<a id="section-20-subsection-1"></a>
#### \(1\)

Kansliapäällikön tehtävänä on seurata ministeriön hallinnonalalla tapahtuvaa kehitystä sekä tehdä tarpeellisia aloitteita lainsäädännöksi ja muiksi uudistuksiksi\. Kansliapäällikön tulee ministerin lähimpänä apuna sovittaa yhteen ministeriön eri osastojen toimintoja sekä osallistua laajakantoisten tai muutoin tärkeiden asioiden valmisteluun ja toteuttamiseen\. Kansliapäällikkö käsittelee myös asiat, jotka ministeri niiden tärkeyden tai laadun vuoksi on antanut hänen käsiteltäväkseen\. Lisäksi kansliapäällikön tehtävistä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\.

<a id="section-21"></a>
### 21 §

<a id="section-21-subsection-1"></a>
#### \(1\)

Osastopäällikön tulee:

<a id="section-21-subsection-1-paragraph-1"></a>
- **1.** olla osaston toimialaan kuuluvissa asioissa ministerin apuna;

<a id="section-21-subsection-1-paragraph-2"></a>
- **2.** johtaa osaston toimintaa ja huolehtia sen työskentelyedellytysten kehittämisestä sekä valvoa, että osaston asiat hoidetaan tehokkaasti;

<a id="section-21-subsection-1-paragraph-3"></a>
- **3.** seurata hallintoa ja olojen kehitystä osaston toimialalla sekä tehdä tarpeellisia aloitteita lainsäädännöksi ja muiksi uudistuksiksi;

<a id="section-21-subsection-1-paragraph-4"></a>
- **4.** huolehtia osastonsa toimialan tarkoituksenmukaisesta ja taloudellisesta suunnittelusta; sekä

<a id="section-21-subsection-1-paragraph-5"></a>
- **5.** käsitellä tärkeimmät osaston asiat\.

<a id="section-22"></a>
### 22 §

<a id="section-22-subsection-1"></a>
#### \(1\)

Poliisiylijohtajan tulee sen lisäksi, mitä 21§:ssä on säädetty, ministerin antamien yleisten ohjeiden mukaisesti:

<a id="section-22-subsection-1-paragraph-1"></a>
- **1.** johtaa ja valvoa poliisin toimintaa maassa;

<a id="section-22-subsection-1-paragraph-2"></a>
- **2.** ilmoittaa ministerille tärkeimmistä yleistä järjestystä ja turvallisuutta sekä poliisin toimintaa koskevista tapahtumista ja havainnoistaan;

<a id="section-22-subsection-1-paragraph-3"></a>
- **3.** pitää yhteyttä asianomaisiin muiden hallinnonalojen viranomaisiin;

<a id="section-22-subsection-1-paragraph-4"></a>
- **4.** tarkastaa ja tarkastuttaa poliisiviranomaisten toimintaa; sekä

<a id="section-22-subsection-1-paragraph-5"></a>
- **5.** huolehtia yhteydenpidosta ulkomaisiin poliisiviranomaisiin\.

<a id="section-23"></a>
### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Osastoihin kuulumattoman neuvottelevan virkamiehen tehtävänä on osallistua kunnallishallinnon kehittämiseen, seurata sen kansainvälistä kehitystä ja valmistella alan erityiskysymyksiä\. Muiden neuvottelevien virkamiesten tehtävistä määrätään osaston työjärjestyksessä\.

<a id="section-23-subsection-2"></a>
#### \(2\)

Osastoihin kuulumattoman neuvottelevan virkamiehen tulee tarvittaessa hoitaa myös muita ministeriön määräämiä erityistehtäviä\.

<a id="section-24"></a>
### 24 §

<a id="section-24-subsection-1"></a>
#### \(1\)

Apulaisosastopäällikön tehtävänä on:

<a id="section-24-subsection-1-paragraph-1"></a>
- **1.** johtaa, kehittää ja valvoa osastopäällikön apuna osaston toimintaa; ja

<a id="section-24-subsection-1-paragraph-2"></a>
- **2.** käsitellä ne osastolle kuuluvat asiat, jotka osaston työjärjestyksen mukaan kuuluvat apulaisosastopäällikölle\.

<a id="section-25"></a>
### 25 §

<a id="section-25-subsection-1"></a>
#### \(1\)

Poliisiosaston apulaispäällikkönä toimivan poliisiylitarkastajan tulee poliisiylijohtajan apuna seurata ja valvoa poliisin toimintaa maassa ja toimittaa sitä koskevia tarkastuksia\.

<a id="section-25a"></a>
### 25 a §

<a id="section-25a-subsection-1"></a>
#### \(1\)

Ulkomaalaiskeskuksen johtajan tehtävistä on soveltuvin osin vastaavasti voimassa, mitä 21§:ssä on osastopäällikön tehtävistä säädetty\.

<a id="section-26"></a>
### 26 §

<a id="section-26-subsection-1"></a>
#### \(1\)

Toimistopäällikön ja pääsihteerin tehtävistä on soveltuvin osin vastaavasti voimassa, mitä 21§:ssä on osastopäällikön tehtävistä säädetty\.

<a id="section-26a"></a>
### 26 a §

<a id="section-26a-subsection-1"></a>
#### \(1\)

Ulkomaalaiskeskuksen apulaisjohtajan tehtävistä on soveltuvin osin vastaavasti voimassa, mitä 24§:ssä on apulaisosastopäällikön tehtävistä säädetty\.

<a id="section-27"></a>
### 27 §

<a id="section-27-subsection-1"></a>
#### \(1\)

Osastojen, ulkomaalaiskeskuksen ja toimistojen tehtävistä sekä asioiden käsittelystä ministeriössä määrätään tarkemmin ministeriön työjärjestyksessä \(työjärjestys\), jonka ministeri vahvistaa\.

<a id="section-27-subsection-2"></a>
#### \(2\)

Osaston ja ulkomaalaiskeskuksen virkamiesten tehtävistä sekä asioiden käsittelystä osastolla tai keskuksessa määrätään työjärjestyksessä \(osaston työjärjestys\), jonka osastopäällikkö tai ulkomaalaiskeskuksen johtaja vahvistaa\.

<a id="section-27-subsection-3"></a>
#### \(3\)

Rajavartio\-osaston ja sen virkamiesten tehtävistä on säädetty tai määrätty erikseen\.

<a id="section-27-subsection-4"></a>
#### \(4\)

Vahvistetusta työnjaosta riippumatta virkamies on velvollinen tarvittaessa suorittamaan tehtävät, jotka ministeri, kansliapäällikkö tai asianomaisen toimintayksikön päällikkö hänelle määrää\.

<a id="section-28"></a>
### 28 §

<a id="section-28-subsection-1"></a>
#### \(1\)

Kansliapäällikön ollessa estynyt hänen sijaisenaan toimii yleisen osaston osastopäällikkö tai tämänkin ollessa estynyt se tai ne osastopäälliköt, jotka ministeri määrää\.

<a id="section-28-subsection-2"></a>
#### \(2\)

Osastopäällikön ollessa estynyt hänen sijaisenaan toimii apulaisosastopäällikkö tai ministerin määräämä toimistopäällikkö\.

<a id="section-28-subsection-3"></a>
#### \(3\)

Osastoihin kuulumattoman neuvottelevan virkamiehen ollessa estynyt hänen sijaisenaan toimii tarvittaessa ministerin määräämä virkamies\.

<a id="section-28-subsection-4"></a>
#### \(4\)

Ulkomaalaiskeskuksen johtajan sijaisena toimii apulaisjohtaja tai ministerin määräämä ylitarkastaja\.

<a id="section-28-subsection-5"></a>
#### \(5\)

Muiden virkamiesten sijaisista määrää asianomainen osastopäällikkö tai ulkomaalaiskeskuksen johtaja\.

<a id="section-30"></a>
### 30 §

<a id="section-30-subsection-1"></a>
#### \(1\)

Jos on epäselvää, kenen käsiteltäväksi jokin asia kuuluu, määrää siitä asianomainen osastopäällikkö, apulaisosastopäällikkö, ulkomaalaiskeskuksen johtaja tai toimistopäällikkö sekä osastojen ja ulkomaalaiskeskuksen kesken kansliapäällikkö, jollei ministeri siitä määrää\.

<a id="section-31"></a>
### 31 § Asiain ratkaiseminen

<a id="section-31-subsection-1"></a>
#### \(1\)

Kansliapäällikkö, osastopäällikkö, apulaisosastopäällikkö, ulkomaalaiskeskuksen johtaja, toimistopäällikkö sekä muut virkamiehet ratkaisevat ministeriössä päätettävät 32\-55 b§:ssä mainitut asiat, jollei asiaa ole valtioneuvoston ohjesäännön 32§:n perusteella alistettava ministerin ratkaistavaksi taikka jollei ministeri, kansliapäällikkö, osastopäällikkö tai ulkomaalaiskeskuksen johtaja ole pidättänyt asiaa ratkaistavakseen\.

<a id="section-31-subsection-2"></a>
#### \(2\)

Jäljempänä 32\-55 b§:ssä säädetystä ratkaisuvallan käyttämisestä annetaan tarpeellisilta osin tarkemmat määräykset työjärjestyksessä\.

<a id="section-31-subsection-3"></a>
#### \(3\)

Rajavartio\-osastossa käsiteltävien asioiden ratkaisemisesta on säädetty erikseen\.

<a id="section-32"></a>
### 32 §

<a id="section-32-subsection-1"></a>
#### \(1\)

Kansliapäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-32-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista asioissa, jotka kuuluvat useamman kuin yhden osaston toimialaan;

<a id="section-32-subsection-1-paragraph-2"></a>
- **2.** ministeriön käyttövaroja;

<a id="section-32-subsection-1-paragraph-3"></a>
- **3.** neuvottelevan virkamiehen, osastopäälliköiden ja heidän sijaistensa vuosilomajärjestystä ja vuosilomia;

<a id="section-32-subsection-1-paragraph-4"></a>
- **4.** ulkomaille tehtäviä virkamatkoja koskevien määräysten antamista neuvottelevalle virkamiehelle ja osastopäälliköille;

<a id="section-32-subsection-1-paragraph-5"></a>
- **5.** lakkautuspalkalle asettamista;

<a id="section-32-subsection-1-paragraph-6"></a>
- **6.** ministeriön sisäistä järjestystä;

<a id="section-32-subsection-1-paragraph-7"></a>
- **7.** edellä 14§:n 1 momentin 24\-26 kohdassa mainittujen virkamiesten nimittämistä ja harkinnanvaraista virkavapautta sekä väliaikaisen hoitajan ja viransijaisen ottamista näihin virkoihin;

<a id="section-32-subsection-1-paragraph-8"></a>
- **8.** ministeriön tilapäisten virkamiesten ja työsopimussuhteisen henkilöstön ottamista;

<a id="section-32-subsection-1-paragraph-9"></a>
- **9.** harkinnanvaraista virkavapautta enintään vuodeksi 14§:n 1 momentin 12\-23 kohdassa mainituille virkamiehille sekä viran väliaikaisen hoitajan ja viransijaisen ottamista enintään vuodeksi näihin virkoihin; sekä

<a id="section-32-subsection-1-paragraph-10"></a>
- **10.** ulkomaalaisen maasta karkottamista\.

<a id="section-32-subsection-2"></a>
#### \(2\)

Työjärjestyksellä voidaan määrätä 1 momentissa mainitut asiat kansliapäällikön sijaisena toimivan osastopäällikön ratkaistavaksi\.

<a id="section-33"></a>
### 33 §

<a id="section-33-subsection-1"></a>
#### \(1\)

Osastopäällikkö ja ulkomaalaiskeskuksen johtaja ratkaisevat asiat, jotka koskevat:

<a id="section-33-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista yksikön toimialaan kuuluvissa asioissa, jollei asia jäljempänä säädetyn perusteella kuulu muun virkamiehen ratkaistavaksi;

<a id="section-33-subsection-1-paragraph-2"></a>
- **2.** yksikön virkamiesten ja muun henkilöstön vuosilomajärjestystä ja vuosilomia, lukuun ottamatta osastopäällikön, ulkomaalaiskeskuksen johtajan ja heidän sijaistensa lomia;

<a id="section-33-subsection-1-paragraph-3"></a>
- **3.** virkamatkoja koskevien määräysten antamista yksikön virkamiehille;

<a id="section-33-subsection-1-paragraph-4"></a>
- **4.** yksikön toimialaan kuuluvien komiteoiden sihteereiden palkkioiden vahvistamista sekä komiteanmietintöjen painos\- tai monistemäärää ja mietintöjen jakelua; sekä

<a id="section-33-subsection-1-paragraph-5"></a>
- **5.** yksikön käytettäväksi tai sen toimialalle osoitettujen määrärahojen käyttämistä\.

<a id="section-33-subsection-2"></a>
#### \(2\)

Osaston työjärjestyksellä voidaan määrätä 1 momentin 2\-5 kohdassa mainitut asiat osaston tai ulkomaalaiskeskuksen muun virkamiehen ratkaistavaksi\.

<a id="section-34"></a>
### 34 §

<a id="section-34-subsection-1"></a>
#### \(1\)

Toimistopäällikkö ratkaisee asiat, jotka koskevat lausunnon antamista toimiston toimialaan kuuluvissa asioissa, joiden merkitys ei ole huomattava\.

<a id="section-35"></a>
### 35 §

<a id="section-35-subsection-1"></a>
#### \(1\)

Yleisen osaston osastopäällikkö ratkaisee 33§:n 1 momentin 1\-4 kohdassa mainittujen asioiden lisäksi asiat, jotka koskevat:

<a id="section-35-subsection-1-paragraph-1"></a>
- **1.** ministeriön käytettäväksi yleisiin kulutusmenoihin ja kalustohankintoihin osoitettujen määrärahojen käyttämistä,

<a id="section-35-subsection-1-paragraph-2"></a>
- **2.** edellä 14§:n 1 momentin 27 ja 28 kohdassa mainittujen virkamiesten nimittämistä ja harkinnanvaraista virkavapautta sekä viran väliaikaisen hoitajan ja viransijaisen ottamista näihin virkoihin;

<a id="section-35-subsection-1-paragraph-3"></a>
- **3.** virkavapautta, johon virkamiehellä on oikeus lain tai virkaehtosopimuksen nojalla;

<a id="section-35-subsection-1-paragraph-4"></a>
- **4.** valtion virkamieslain \(755/86\) 30§:n 1 momentissa tarkoitetun sopimuksen tekemistä;

<a id="section-35-subsection-1-paragraph-5"></a>

<a id="section-57"></a>
### 57 § Voimaantulo

<a id="section-57-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä toukokuuta 1988 ja sillä kumotaan sisäasiainministeriöstä 16 päivänä syyskuuta 1983 annettu asetus \(753/83\) siihen myöhemmin tehtyine muutoksineen\.

<a id="section-57-subsection-2"></a>
#### \(2\)

Aikaisemman asetuksen nojalla annettu työjärjestys ja virastodemokratiaohjesääntö ovat kuitenkin edelleen noudatettavina, kunnes sisäasiainministeriö toisin määrää\.

<a id="section-57-subsection-3"></a>
#### \(3\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin\.
