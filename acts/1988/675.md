# Asetus opetusministeriön hallinnonalan eräiden virkojen lakkauttamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Pohjois\-Karjalan ammattioppilaitoksessa \(Outokumpu\) lakkautetaan 1 päivästä elokuuta 1988 lukien jäljempänä mainitut peruspalkkaiset virat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yksi A 11 palkkausluokkaan kuuluva toimistosihteerin virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** yksi C 60 palkkausluokkaan kuuluva apulaisrehtorin virka;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kolme C 47 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet\) virkaa;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** yksi C 41 palkkausluokkaan kuuluva lehtorin \(äidinkieli, toinen kotimainen kieli, vieraat kielet, kansalaistieto, matematiikka, fysiikka, kemia ja tietotekniikka\) virka;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** yksi C 38 palkkausluokkaan kuuluva lehtorin \(ammatilliset aineet\) virka; ja

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** kolme C 36 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet\) virkaa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä elokuuta 1988\.
