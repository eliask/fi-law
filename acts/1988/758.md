# Asetus valtiovarainministeriön hallinnonalaan kuuluvien eräiden virkojen lakkauttamisesta ja perustamisesta

<a id="section-1"></a>
### 1 § Valtiokonttori

<a id="section-1-subsection-1"></a>
#### \(1\)

Lakkautetaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yksi A 5 palkkausluokkaan kuuluva konekirjoittajan virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** neljä A 5 palkkausluokkaan kuuluvaa toimistovirkailijan virkaa; ja

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** yksi A 3 palkkausluokkaan kuuluva toimistovirkailijan virka,

<a id="section-1-subsection-2"></a>
#### \(2\)

Perustetaan:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** yksi A 25 palkkausluokkaan kuuluva toimistopäällikön virka;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** yksi A 16 palkkausluokkaan kuuluva osastosihteerin virka;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** yksi A 14 palkkausluokkaan kuuluva toimistosihteerin virka; ja

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** yksi A 12 palkkausluokkaan kuuluva laskentasihteerin virka\.

<a id="section-2"></a>
### 2 § Verohallinto

<a id="section-2-subsection-1"></a>
#### \(1\)

Lakkautetaan:
kolme A 4 palkkausluokkaan kuuluvaa toimistoapulaisen virkaa\.

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Läänin vero virastot

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Verotoimistot

<a id="section-2-subsection-2"></a>
#### \(2\)

Perustetaan:
kaksi A 18 palkkausluokkaan kuuluvaa verosihteerin virkaa\.

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Lääninverovirastot

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Verotoimistot
