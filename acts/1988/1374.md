# Valtioneuvoston päätös eräiden kuntien ja kunnan osien määräämisestä erityisalueiksi

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erityisalueeksi vuosiksi 1989\-90 määrätään seuraavat kunnat tai kunnan osat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Lapin läänistä Enontekiö, Kittilä, Kolari, Pelkosenniemi, Pello, Posio, Salla ja Savukoski;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Oulun läänistä Haukiputaan Martinniemi, Hyrynsalmi, Kestilä, Kuhmo, Pudasjärvi, Puolanka, Pyhäjärvi, Ristijärvi, Suomussalmi, Taivalkoski ja Vihanti;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Keski\-Suomen läänistä Keuruun Haapamäki, Pihtipudas ja Saarijärvi;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Kuopion läänistä Pielavesi ja Rautavaara;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Pohjois\-Karjalan läänistä Eno, Juuka ja Outokumpu;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Hämeen läänistä Vilppula; sekä

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Turun ja Porin läänistä Karvia ja Parkano\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Erityisalueeksi vuodeksi 1989 määrätään seuraavat kunnat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Lapin läänistä Simo;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Oulun läänistä Raahe;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Vaasan läänistä Kokkola ja Oravainen;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen läänistä Viitasaari;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Kuopion läänistä Kaavi;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan läänistä Kiihtelysvaara;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Mikkelin läänistä Mikkeli ja Savonlinna;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Kymen läänistä Kotka ja Pyhtää;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Hämeen läänistä Kylmäkoski ja Viiala;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Turun ja Porin läänistä Hämeenkyrö, Kihniö ja Pori; sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Uudenmaan läänistä Tenhola\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1989\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Valtionavustus, jota koskeva hakemus on toimitettu asianomaiselle viranomaiselle ennen tämän päätöksen voimaantuloa, voidaan kuitenkin myöntää sen suuruisena kuin se olisi ollut myönnettävissä ennen tämän päätöksen voimaantuloa voimassa olleiden päätösten nojalla\.
