# Asetus pelastushallinnon koulutuskeskuksen eräistä virkajärjestelyistä

- Statute: [`521/1988`](<https://www.finlex.fi/fi/laki/ajantasa/1988/521>)
- Version: `1989-01-01`
- LawVM tree hash: `4b18accc87ca21c8e7cae7d94190df13acdfb1f4557af192f77abb4f962b660c`

## Contents

- [1 §](#section-1)

- [2 §](#section-2)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Perustetaan: kaksi C 52 palkkausluokkaan kuuluvaa vanhemman opettajan virkaa sekä viisi C 41 palkkausluokkaan kuuluvaa vanhemman harjoitusmestarin virkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Lakkautetaan: kaksi C 47 palkkausluokkaan kuuluvaa opettajan virkaa sekä kuusi C 38 palkkausluokkaan kuuluvaa harjoitusmestarin virkaa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 1989\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Toimenpiteisiin tällä asetuksella perustettujen virkojen täyttämiseksi saa ryhtyä jo ennen ajankohtaa, josta lukien virat on perustettu\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Tällä asetuksella perustetut virat voidaan täyttää ensimmäisen kerran niitä haettavaksi julistamatta\.
