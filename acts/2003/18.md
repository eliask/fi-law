## 5 a luku Telekuuntelu, televalvonta ja tekninen tarkkailu

<a id="chapter-5a-section-2"></a>
### 2 § Telekuuntelun edellytykset

<a id="chapter-5a-section-2-subsection-1"></a>
#### \(1\)

Kun on syytä epäillä jotakuta
rikoksen esitutkintaa toimittavalle viranomaiselle voidaan antaa lupa kuunnella ja tallentaa televiestejä, joita epäilty lähettää hallussaan olevalla tai oletettavasti muuten käyttämällään teleliittymällä, tai tällaiseen teleliittymään tulevia hänelle tarkoitettuja viestejä, jos kuuntelulla saatavilla tiedoilla voidaan olettaa olevan erittäin tärkeä merkitys rikoksen selvittämiselle\.

<a id="chapter-5a-section-2-subsection-1-paragraph-1"></a>
- **1.** Suomen itsemääräämisoikeuden vaarantamisesta, sotaan yllyttämisestä, maanpetoksesta, törkeästä maanpetoksesta, vakoilusta, törkeästä vakoilusta, turvallisuussalaisuuden paljastamisesta, luvattomasta tiedustelutoiminnasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-2"></a>
- **2.** valtiopetoksesta, törkeästä valtiopetoksesta, valtiopetoksen valmistelusta,

<a id="chapter-5a-section-2-subsection-1-paragraph-3"></a>
- **3.** taposta, murhasta, surmasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-4"></a>
- **4.** törkeästä vapaudenriistosta, ihmisryöstöstä, panttivangin ottamisesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-5"></a>
- **5.** törkeästä ryöstöstä, törkeästä kiristyksestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-6"></a>
- **6.** törkeästä kätkemisrikoksesta, ammattimaisesta kätkemisrikoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-7"></a>
- **7.** tuhotyöstä, liikennetuhotyöstä, törkeästä tuhotyöstä, törkeästä terveyden vaarantamisesta, ydinräjähderikoksesta, kaappauksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-8"></a>
- **8.** törkeästä kiskonnasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-9"></a>
- **9.** törkeästä rahanväärennyksestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-10"></a>
- **10.** törkeästä ympäristön turmelemisesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-11"></a>
- **11.** törkeästä huumausainerikoksesta taikka

<a id="chapter-5a-section-2-subsection-1-paragraph-12"></a>
- **12.** edellä mainittujen rikosten rangaistavasta yrityksestä,

<a id="chapter-5a-section-2-subsection-2"></a>
#### \(2\)

Lupa 1 momentin mukaiseen telekuunteluun voidaan siinä säädetyin edellytyksin antaa myös, kun on syytä epäillä jotakuta

<a id="chapter-5a-section-2-subsection-2-paragraph-1"></a>
- **1.** joukkotuhonnasta, joukkotuhonnan valmistelusta, kemiallisen aseen kiellon rikkomisesta, biologisen aseen kiellon rikkomisesta,

<a id="chapter-5a-section-2-subsection-2-paragraph-2"></a>
- **2.** rikoslain 34 a luvun 1 §:n 1 momentin 2―7 kohdassa tai 2 momentissa tarkoitetusta terroristisessa tarkoituksessa tehdystä rikoksesta, terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta, terroristiryhmän johtamisesta, terroristiryhmän toiminnan edistämisestä, terrorismin rahoittamisesta taikka

<a id="chapter-5a-section-2-subsection-2-paragraph-3"></a>
- **3.** edellä mainittujen rikosten rangaistavasta yrityksestä\.

<a id="chapter-5a-section-3"></a>
### 3 § Televalvonnan edellytykset

<a id="chapter-5a-section-3-subsection-1"></a>
#### \(1\)

Kun on syytä epäillä jotakuta

<a id="chapter-5a-section-3-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta ei ole säädetty lievempää rangaistusta kuin neljä kuukautta vankeutta,

<a id="chapter-5a-section-3-subsection-1-paragraph-2"></a>
- **2.** automaattiseen tietojenkäsittelyjärjestelmään kohdistuneesta rikoksesta, joka on tehty telepäätelaitetta käyttäen, laittomasta uhkauksesta, oikeudenkäytössä kuultavan uhkaamisesta tai huumausainerikoksesta,

<a id="chapter-5a-section-3-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen rikosten rangaistavasta yrityksestä, tai

<a id="chapter-5a-section-3-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta,

<a id="chapter-5a-section-4"></a>
### 4 § Teknisen tarkkailun edellytykset

<a id="chapter-5a-section-4-subsection-1"></a>
#### \(1\)

Kun on syytä epäillä jotakuta
esitutkintaviranomainen saa kohdistaa epäiltyyn teknistä kuuntelua, jos siten saatavilla tiedoilla voidaan olettaa olevan erittäin tärkeä merkitys rikoksen selvittämiselle\.

<a id="chapter-5a-section-4-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta,

<a id="chapter-5a-section-4-subsection-1-paragraph-2"></a>
- **2.** huumausainerikoksesta,

<a id="chapter-5a-section-4-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen rikosten rangaistavasta yrityksestä, tai

<a id="chapter-5a-section-4-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta,

<a id="chapter-5a-section-4-subsection-2"></a>
#### \(2\)

Kun on syytä epäillä jotakuta rikoksesta, josta säädetty ankarin rangaistus on enemmän kuin kuusi kuukautta vankeutta, epäiltyyn tai tiettyyn paikkaan, jossa hänen voidaan olettaa oleskelevan, saadaan kohdistaa teknistä katselua, jos katselulla saatavilla tiedoilla voidaan olettaa olevan erittäin tärkeä merkitys rikoksen selvittämiselle\. Jos tekninen katselu kohdistuu 4 momentissa tarkoitettuun vankeinhoitolaitoksen huostassa olevaan henkilöön, edellytetään kuitenkin, että epäily koskee rikosta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta, taikka huumausainerikosta tai näiden rikosten rangaistavaa yritystä taikka terroristisessa tarkoituksessa tehtävän rikoksen valmistelua ja että katselulla saatavilla tiedoilla voidaan olettaa olevan erittäin tärkeä merkitys rikoksen selvittämiselle\.

### 5 § DNA\-tunnisteiden määrittäminen ja tallettaminen

<a id="chapter-6-section-5-subsection-1"></a>
#### \(1\)

Henkilölle, jonka on lainvoimaisella tuomiolla todettu syyllistyneen

<a id="chapter-6-section-5-subsection-1-paragraph-1"></a>
- **1.** raiskaukseen, törkeään raiskaukseen, sukupuoliyhteyteen pakottamiseen, pakottamiseen seksuaaliseen tekoon, seksuaaliseen hyväksikäyttöön, lapsen seksuaaliseen hyväksikäyttöön, törkeään lapsen seksuaaliseen hyväksikäyttöön,

<a id="chapter-6-section-5-subsection-1-paragraph-2"></a>
- **2.** tappoon, murhaan, surmaan, törkeään pahoinpitelyyn,

<a id="chapter-6-section-5-subsection-1-paragraph-3"></a>
- **3.** törkeään ryöstöön tai törkeään kiristykseen,

<a id="chapter-6-section-5-subsection-1-paragraph-4"></a>
- **4.** rikoslain 34 luvussa mainittuun rikokseen,

<a id="chapter-6-section-5-subsection-1-paragraph-5"></a>
- **5.** rikoslain 34 a luvussa mainittuun rikokseen,

<a id="chapter-6-section-5-subsection-1-paragraph-6"></a>
- **6.** törkeään kiskontaan,

<a id="chapter-6-section-5-subsection-1-paragraph-7"></a>
- **7.** törkeään huumausainerikokseen tai

<a id="chapter-6-section-5-subsection-1-paragraph-8"></a>
- **8.** näiden rikosten rangaistavaksi säädettyyn yritykseen taikka avunantoon tai yllytykseen,
