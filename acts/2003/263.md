# Valtioneuvoston asetus valtion virkamiesasetuksen 7 ja 28 §:n muuttamisesta

<a id="section-7"></a>
### 7 §

<a id="section-7-subsection-1"></a>
#### \(1\)

Pääministerin toimikaudeksi nimitettävän valtiosihteerin virka täytetään sitä haettavaksi julistamatta tai sen avoinna olemisesta ilmoittamatta\. Samaa menettelyä noudattaen nimitetään ministerin erityisavustajan määräaikaiseen virkasuhteeseen\.

<a id="section-28"></a>
### 28 §

<a id="section-28-subsection-1"></a>
#### \(1\)

Valtion virkamieslain 26 §:n 3 kohdassa tarkoitettuja osastopäällikköä virka\-asemaltaan vastaavia ministeriön virkamiehiä ovat:

<a id="section-28-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriön osastopäällikön tehtävään määrätty ulkoasiainneuvos;

<a id="section-28-subsection-1-paragraph-2"></a>
- **2.** ministeriön osaston päällikkönä toimiva ylijohtaja;

<a id="section-28-subsection-1-paragraph-3"></a>
- **3.** sisäasiainministeriön poliisiosaston poliisiylijohtaja ja pelastusosaston pelastusylijohtaja;

<a id="section-28-subsection-1-paragraph-4"></a>
- **4.** valtakunnansovittelija;

<a id="section-28-subsection-1-paragraph-5"></a>
- **5.** ohjelmajohtaja\.
