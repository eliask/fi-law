<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Yleisvaarallisia tartuntatauteja ovat

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** EHEC\-infektio,

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** hemorragiset kuumeet, ei kuitenkaan myyräkuume,

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** hepatiitti A,

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** keltakuume,

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kolera,

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** kuppa,

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** kurkkumätä,

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** lavantauti, pikkulavantauti ja muut salmonellojen aiheuttamat taudit,

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** meningokokin aiheuttamat septiset taudit ja aivokalvontulehdukset,

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** pernarutto,

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** polio,

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** rutto,

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** SARS,

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** shigellapunatauti ja

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** tuberkuloosi\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Ilmoitettavia tartuntatauteja ovat

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** ekinokokkoosi,

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** hepatiitti B,

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** hepatiitti C,

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** HIV\-infektio,

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** klamydiainfektiot, sukupuoliteitse leviävät, legionelloosi,

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** listerioosi,

<a id="section-2-subsection-2-paragraph-7"></a>
- **7.** malaria,

<a id="section-2-subsection-2-paragraph-8"></a>
- **8.** mykobakteeritaudit, muut kuin tuberkuloosi,

<a id="section-2-subsection-2-paragraph-9"></a>
- **9.** rabies,

<a id="section-2-subsection-2-paragraph-10"></a>
- **10.** sankkerit,

<a id="section-2-subsection-2-paragraph-11"></a>
- **11.** septiset hemofilustaudit,

<a id="section-2-subsection-2-paragraph-12"></a>
- **12.** sikotauti,

<a id="section-2-subsection-2-paragraph-13"></a>
- **13.** tippuri,

<a id="section-2-subsection-2-paragraph-14"></a>
- **14.** toisintokuume,

<a id="section-2-subsection-2-paragraph-15"></a>
- **15.** tuhkarokko ja

<a id="section-2-subsection-2-paragraph-16"></a>
- **16.** vihurirokko\.
