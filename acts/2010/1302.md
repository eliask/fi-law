### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään Turvallisuus\- ja kemikaaliviraston maksullisista suoritteista, niiden maksuperusteista sekä julkisoikeudellisista suoritteista perittävistä maksuista\.

<a id="section-2"></a>
### 2 § Maksulliset julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain \(150/1992\) 6 §:ssä tarkoitettuja maksullisia julkisoikeudellisia suoritteita ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** kemikaalien ja räjähteiden käsittelyn turvallisuudesta annetussa laissa \(390/2005\) ja sen nojalla annetuissa säännöksissä mainitut luvat, ilmoitukset, tarkastukset, pelastussuunnitelmat, tutkinnot ja pätevyyskokeet, pätevyys\- ja muut todistukset, siirtotodistukset, turvallisuusselvitykset, vahvistamiset, hyväksymiset sekä muutokset silloin, kun ne koskevat:

<a id="section-2-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** vaarallisten kemikaalien käsittelyä ja varastointia;

<a id="section-2-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** vaarallisiin kemikaaleihin liittyviä tuotteita;

<a id="section-2-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** vaarallisiin kemikaaleihin liittyvien laitteistojen asennus\- ja huolto\- ja tarkastusliikkeitä;

<a id="section-2-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** räjähteiden valmistusta, varastointia, maahantuontia ja siirtoa;

<a id="section-2-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** pyroteknisiä välineitä;

<a id="section-2-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** ilotulitteiden valmistusta ja maahantuontia ja ilotulitteisiin liittyvää toimintaa;

<a id="section-2-subsection-1-paragraph-1-subparagraph-g"></a>
  - **g.** ilotulitusnäytöksen järjestämistä;

<a id="section-2-subsection-1-paragraph-1-subparagraph-h"></a>
  - **h.** tarkastuslaitoksia;

<a id="section-2-subsection-1-paragraph-2"></a>

<a id="section-2-subsection-1-paragraph-2-subparagraph-a"></a>

<a id="section-2-subsection-1-paragraph-2-subparagraph-b"></a>

<a id="section-2-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** kemikaalilain 30 h §:ssä tarkoitetun biosidivalmisteen hyväksymistä;

<a id="section-2-subsection-1-paragraph-2-subparagraph-d"></a>

<a id="section-2-subsection-1-paragraph-2-subparagraph-e"></a>

<a id="section-2-subsection-1-paragraph-2-subparagraph-i"></a>

<a id="section-2-subsection-1-paragraph-3"></a>

<a id="section-3"></a>
### 3 § Eräitä julkisoikeudellisista suoritteista perittäviä maksuja koskevia säännöksiä

<a id="section-3-subsection-1"></a>
#### \(1\)

Turvallisuus\- ja kemikaalivirasto perii edellä 2 §:ssä mainituista suoritteista tämän asetuksen liitteenä olevan maksutaulukon mukaiset omakustannusarvoon perustuvat maksut\. Maksutaulukon mukainen lisämaksu peritään kultakin alkavalta tunnilta\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Myönteisestä ja kielteisestä päätöksestä peritään samansuuruinen maksu\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Suoritteista voidaan periä ennakkomaksua sen mukaan kuin tämän asetuksen liitteenä olevassa maksutaulukossa säädetään\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Peruutetun tai muuten rauenneen ilmoituksen tai hakemuksen käsittelystä peritään tehtyä työmäärää vastaava osuus sen mukaan kuin tämän asetuksen liitteenä olevassa maksutaulukossa säädetään\. Peruutetusta tai aineiston puutteellisuuden vuoksi hylätystä hakemuksesta maksettua ennakkomaksua ei palauteta\.

<a id="section-3-subsection-5"></a>
#### \(5\)

Maksu 2 §:n 2 kohdassa mainituista suoritteista voidaan jättää perimättä kokonaan tai osittain, jos kemikaalin käyttö on vähäistä tai on jokin muu erityinen syy, jonka vuoksi maksua voidaan kemikaalilain 60 §:n 3 momentin nojalla pitää kohtuuttomana\.

<a id="section-3-subsection-6"></a>
#### \(6\)

Edellä 2 §:n 3 kohdan b alakohdassa mainituista suoritteista perittävässä maksussa otetaan lisäksi huomioon kasvinsuojeluaineista annetun lain 53 §:n 2 momentissa tarkoitetut alennukset\.

<a id="section-4"></a>
### 4 § Maksulliset liiketaloudellisin perustein hinnoiteltavat suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja suoritteita, jotka Turvallisuus\- ja kemikaalivirasto hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** tilaukseen tai toimeksiantoon perustuvat selvitykset, tutkimukset ja lausunnot;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** henkilöstön käyttö viraston ulkopuolisissa koulutus\-, suunnittelu\- ja muissa asiantuntijatehtävissä lukuun ottamatta tapauksia, joissa tehtävien hoito tukee viraston maksutonta toimintaa;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** kirjasto\- ja tietopalvelut;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** julkaisut;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** ilmoitustilan myynti viraston julkaisuissa;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** sähköiset tietotuotteet;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** viraston hallinnassa olevien tilojen ja laitteiden käyttö sekä virasto\- ja toimistopalvelut ulkopuolisille;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** valokopiot, tulosteet ja muut jäljennökset lukuun ottamatta 2 momentissa tarkoitettuja kopioita ja tulosteita;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** toimeksiantoon perustuva asiakirjojen ja muun aineiston lähettäminen ja postitus, jos nämä eivät sisälly aineistosta perittävään hintaan; sekä

<a id="section-4-subsection-1-paragraph-10"></a>
- **10.** muut erikseen tilatut tai sovitut palvelut\.

<a id="section-5"></a>
### 5 § Voimaantulo ja siirtymäsäännökset

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2011 ja on voimassa 31 päivään joulukuuta 2013\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan kauppa\- ja teollisuusministeriön päätös turvatekniikan keskuksen suoritteiden maksullisuudesta ja maksuperusteista \(1032/1996\)\.

<a id="section-5-subsection-3"></a>
#### \(3\)

Suoritteesta, jota koskeva asia on vireillä turvatekniikan keskuksessa, Elintarviketurvallisuusvirastossa, Sosiaali\- ja terveysalan lupa\- ja valvontavirastossa tai Suomen ympäristökeskuksessa tämän asetuksen tullessa voimaan, peritään asian vireille tullessa voimassa olleiden maksujen suuruinen maksu\.
