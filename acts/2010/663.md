## 17 luku Rikoksista yleistä järjestystä vastaan

<a id="chapter-17-section-16a"></a>
### 16 a § Rahapelirikos

<a id="chapter-17-section-16a-subsection-1"></a>
#### \(1\)

Joka
on tuomittava, jollei teosta muualla laissa säädetä ankarampaa rangaistusta, rahapelirikoksesta sakkoon tai vankeuteen enintään kahdeksi vuodeksi\.

<a id="chapter-17-section-16a-subsection-1-paragraph-1"></a>
- **1.** toimeenpanee rahapelin ilman arpajaislain \(1047/2001\) 11 §:ssä tarkoitettua rahapelilupaa,

<a id="chapter-17-section-16a-subsection-1-paragraph-2"></a>
- **2.** myy tai välittää arpoja ilman arpajaislaissa tarkoitettua rahapelilupaa toimeenpantuun rahapeliin tai markkinoi sellaista rahapeliä vastoin arpajaislain 62 §:n 2 momentin 1 kohdassa säädettyä kieltoa,

<a id="chapter-17-section-16a-subsection-1-paragraph-3"></a>
- **3.** myy tai välittää arpoja rahapeliin ulkomaille tai markkinoi rahapeliä ulkomaille vastoin arpajaislain 62 §:n 2 momentin 2 kohdassa säädettyä kieltoa,

<a id="chapter-17-section-16a-subsection-1-paragraph-4"></a>
- **4.** ilman rahapelin toimeenpanijan lupaa myy tai välittää arpajaislaissa tarkoitetun rahapeliluvan nojalla toimeenpantuun rahapeliin liittyviä arpoja taikka vastaanottaa sellaiseen rahapeliin liittyviä pelipanoksia tai välittää sellaiseen rahapeliin liittyviä voittoja vastoin arpajaislain 62 §:n 2 momentin 3 kohdassa säädettyä kieltoa taikka

<a id="chapter-17-section-16a-subsection-1-paragraph-5"></a>
- **5.** luovuttaa tilan ilman arpajaislaissa tarkoitettua rahapelilupaa tapahtuvaan raha\-automaatin tai kasinopelin käytettävänä pitämiseen vastoin arpajaislain 62 §:n 3 momentissa säädettyä kieltoa,

<a id="chapter-17-section-16b"></a>
### 16 b § Arpajaisrikos

<a id="chapter-17-section-16b-subsection-1"></a>
#### \(1\)

Joka
on tuomittava, jollei teosta muualla laissa säädetä ankarampaa rangaistusta, arpajaisrikoksesta sakkoon tai vankeuteen enintään kuudeksi kuukaudeksi\.

<a id="chapter-17-section-16b-subsection-1-paragraph-1"></a>
- **1.** toimeenpanee muut kuin 16 a §:n 1 kohdassa tarkoitetut arpajaiset ilman arpajaislaissa tarkoitettua lupaa,

<a id="chapter-17-section-16b-subsection-1-paragraph-2"></a>
- **2.** muulla kuin 16 a §:ssä tarkoitetulla tavalla rikkoo arpajaislain 62 §:n 1―4 momentissa säädettyä kieltoa,

<a id="chapter-17-section-16b-subsection-1-paragraph-3"></a>
- **3.** käyttää arpajaisten tuotot olennaisesti vastoin laissa, arpajaisten toimeenpanoon annetussa luvassa tai tuottojen käyttötarkoituksen muuttamista koskevassa luvassa annettua määräystä,

<a id="chapter-17-section-16b-subsection-1-paragraph-4"></a>
- **4.** laiminlyö arpajaisten toimeenpanoon kuuluvan tilitysvelvollisuuden,

<a id="chapter-17-section-16b-subsection-1-paragraph-5"></a>
- **5.** toimeenpanee arpajaislain 27 §:n 1 momentissa tarkoitetut pienarpajaiset, vaikkei täytä arpajaislain 5 §:ssä säädettyjä arpajaisten toimeenpanijaa koskevia edellytyksiä,

<a id="chapter-17-section-16b-subsection-1-paragraph-6"></a>
- **6.** rikkoo olennaisesti tai toistuvasti arpajaisten toimeenpanoon annettuun lupaan liitettyjä ehtoja tai määräyksiä taikka

<a id="chapter-17-section-16b-subsection-1-paragraph-7"></a>
- **7.** rikkoo rahapelien markkinointia koskevia arpajaislain 14 b §:n säännöksiä,

<a id="chapter-17-section-16c"></a>
### 16 c § Rahankeräysrikos

<a id="chapter-17-section-16c-subsection-1"></a>
#### \(1\)

Joka tahallaan
on tuomittava, jollei teosta muualla laissa säädetä ankarampaa rangaistusta, rahankeräysrikoksesta sakkoon tai vankeuteen enintään kahdeksi vuodeksi\.

<a id="chapter-17-section-16c-subsection-1-paragraph-1"></a>
- **1.** toimeenpanee rahankeräyksen ilman rahankeräyslaissa \(255/2006\) tarkoitettua lupaa taikka lain 5 §:n 2 tai 3 momentin vastaisesti,

<a id="chapter-17-section-16c-subsection-1-paragraph-2"></a>
- **2.** toimeenpanee rahankeräyksen vastoin rahankeräyslain 9 §:ssä säädettyä kieltoa,

<a id="chapter-17-section-16c-subsection-1-paragraph-3"></a>
- **3.** toimeenpannessaan rahankeräyksen antaa keräyksen kohderyhmälle merkityksellisiä totuudenvastaisia tai harhaanjohtavia tietoja,

<a id="chapter-17-section-16c-subsection-1-paragraph-4"></a>
- **4.** antaa rahankeräyslaissa tarkoitetulle lupaviranomaiselle väärän tiedon seikasta, joka on omiaan vaikuttamaan rahankeräysluvan saantiin tai ehtoihin, tai salaa sellaisen seikan taikka luvan saatuaan jättää ilmoittamatta lupaviranomaiselle olosuhteiden muutoksesta, josta luvan myöntämisen yhteydessä tai muuten on erityisesti velvoitettu ilmoittamaan,

<a id="chapter-17-section-16c-subsection-1-paragraph-5"></a>
- **5.** käyttää rahankeräyksellä saatuja varoja olennaisesti vastoin rahankeräysluvassa tai varojen käyttötarkoituksen muuttamista koskevassa luvassa asetettuja ehtoja tai annettuja määräyksiä,

<a id="chapter-17-section-16c-subsection-1-paragraph-6"></a>
- **6.** laiminlyö rahankeräyslain 21 §:ssä säädetyn tilitys\- tai ilmoitusvelvollisuuden tai

<a id="chapter-17-section-16c-subsection-1-paragraph-7"></a>
- **7.** toimii rahankeräyksen käytännön toimeenpanijana ilman rahankeräyslain 15 §:n 1 momentissa tarkoitettua määräystä,

<a id="chapter-17-section-16d"></a>
### 16 d § Lievä rahankeräysrikos

<a id="chapter-17-section-16d-subsection-1"></a>
#### \(1\)

Jos rahankeräysrikos on kokonaisuutena arvostellen vähäinen, rikoksentekijä on tuomittava lievästä rahankeräysrikoksesta sakkoon\.

<a id="chapter-17-section-24"></a>
### 24 § Oikeushenkilön rangaistusvastuu

<a id="chapter-17-section-24-subsection-1"></a>
#### \(1\)

Järjestäytyneen rikollisryhmän toimintaan osallistumiseen, laittoman maahantulon järjestämiseen, törkeään laittoman maahantulon järjestämiseen, eläinsuojelurikokseen, uhkapelin järjestämiseen, rahapelirikokseen, arpajaisrikokseen, rahankeräysrikokseen, väkivaltakuvauksen levittämiseen, sukupuolisiveellisyyttä loukkaavan kuvan levittämiseen, törkeään sukupuolisiveellisyyttä loukkaavan lasta esittävän kuvan levittämiseen, sukupuolisiveellisyyttä loukkaavan lasta esittävän kuvan hallussapitoon ja sukupuolisiveellisyyttä loukkaavaan markkinointiin sovelletaan, mitä oikeushenkilön rangaistusvastuusta säädetään\.
