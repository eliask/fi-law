# Valtioneuvoston päätös eräitä ftalaatteja koskevista rajoituksista alle kolmivuotiaille lapsille tarkoitetuissa suuhunpantavissa lastenhoitotarvikkeissa ja leluissa

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tämä valtioneuvoston päätös koskee alle kolmivuotiaille lapsille tarkoitettuja suuhunpantavia lastenhoitotarvikkeita ja leluja

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Edellä 1 §:ssä tarkoitetuissa lastenhoitotarvikkeissa ja leluissa, jotka on valmistettu pehmitetystä PVC:stä, ei saa olla yli 0\.05 painoprosenttia yhtä tai useampaa seuraavista ftalaateista:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** di\-isonyyliftalaatti \(DINP\),

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** di\(2\-etyyliheksyyli\)ftalaatti \(DEHP\),

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** dibutyyliftalaatti \(DBP\),

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** di\-isodekyyliftalaatti \(DIDP\),

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** di\-n\-oktyyliftalaatti \(DNOP\) tai

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** butyylibentsyyliftalaatti \(BBP\)\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä marraskuuta 1999\.
