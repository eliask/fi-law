# Asetus vuonna 1999 kertyvien työnantajan sosiaaliturvamaksujen jakautumasta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Vuodelta 1999 ilman erillistä maksuunpanoa suoritetuista työnantajan sosiaaliturvamaksuista on katsottava olevan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** kun palkan maksajana on valtio, muu valtion laitos kuin sellainen liikelaitos, johon sovelletaan valtion liikelaitoksista annettua lakia \(627/1987\), tai Ahvenanmaan maakunta

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kun palkan maksajana on kunta, kuntayhtymä tai kunnallinen liikelaitos, evankelis\-luterilainen kirkko, sen seurakunta tai seurakuntayhtymä taikka ortodoksinen kirkkokunta tai sen seurakunta

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kun palkan maksajana on muu kuin 1―2 kohdassa tarkoitettu työnantaja

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Vuodelta 1999 maksuunpanon perusteella suoritetuista työnantajan sosiaaliturvamaksuista on katsottava olevan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** kansaneläkemaksua 65,3 %

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** sairausvakuutusmaksua 34,7 %

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Vuonna 1999 kertyvistä, vuoteen 1998 ja sitä aikaisempiin vuosiin kohdistuvista työnantajan sosiaaliturvamaksuista on katsottava olevan:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** kansaneläkemaksua 65,1 %

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** sairausvakuutusmaksua 34,9 %

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä helmikuuta 1999\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Tätä asetusta sovelletaan myös ennen sen voimaantuloa maksuunpantuihin, 1 päivänä tammikuuta 1999 tai sen jälkeen kertyneisiin työnantajan sosiaaliturvamaksuihin\.
