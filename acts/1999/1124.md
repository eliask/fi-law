# Opetusministeriön päätös Suomen elokuva\-arkiston suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Suomen elokuva\-arkiston maksuttomia suoritteita ovat vain vähäisiä kustannuksia aiheuttavat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** lakisääteisten ja vapaaehtoisten talletusten luovutus tallettajan omaan käyttöön; sekä

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kansainväliseen kulttuurivaihtoon liittyvä palvelutoiminta\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion [maksuperustelain \(150/1992\)](<https://www.finlex.fi/fi/lainsaadanto/1992/150>) 7 §:n 1 momentissa tarkoitettuja muita suoritteita, jotka Suomen elokuva\-arkisto hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tieto\-, kuva\- ja lainauspalvelut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** huolinta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** elokuvien käyttö\- ja esitysoikeuksien myynti;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** esitystoiminta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** tilojen ja laitteiden käyttö;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** elokuvateattereiden käyttö;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** koulutus ja konsultointi;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** filmi\- ja videokatselu;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** arkistopelasteen käyttö; sekä

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** muut tilauksesta tuotetut suoritteet\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Suomen elokuva\-arkiston kirjasto\- ja tietopalveluiden maksullisuuteen ja maksuperusteisiin sovelletaan kirjasto\- ja tietopalveluista perittävistä maksuista annettua opetusministeriön päätöstä \(82/1993\)\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 2000 ja on voimassa 31 päivään joulukuuta 2002\.
