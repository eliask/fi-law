# Opetusministeriön päätös opetushallituksen suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maksullisia julkisoikeudellisia suoritteita, joista opetushallitus perii kiinteän maksun, ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** lupa sellaisen perusopetusta, lukiota ja ammatillista koulutusta koskevan kokeilun järjestämiseen, jossa poiketaan opetushallituksen antamista määräyksistä 3 000 markkaa;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kelpoisuustodistuksen antaminen muussa Pohjoismaassa suoritetun opettajankoulutuksen perusteella perusopetuksen ja lukion aineenopettajan kelpoisuutta varten 800 markkaa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kelpoisuustodistuksen antaminen muussa Pohjoismaassa suoritetun opettajankoulutuksen perusteella erityisopetusta antavan opettajan kelpoisuutta varten 800 markkaa;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kelpoisuustodistuksen antaminen muussa Pohjoismaassa suoritetun opettajankoulutuksen perusteella ammatillisen koulutuksen yhteisten opintojen opettajan kelpoisuutta varten 800 markkaa;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** opetushallituksen päätös opettajan riittävistä opinnoista vieraskielistä opetusta, ulkomailla järjestettävää opetusta ja steiner\-pedagogiikkaan perustuvaa opetusta varten 800 markkaa;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** lupa yleisten kielitutkintojen järjestämiseen 1 000 markkaa;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** opetushallituksen yleisiä kielitutkintosuorituksia arvostelemaan oikeutetuista henkilöistä pitämään luetteloon merkitseminen 200 markkaa;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** päätös ulkomailla suoritettujen korkeakouluopintojen rinnastamisesta Suomessa suoritettaviin korkeakouluopintoihin 1 000 markkaa;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Euroopan yhteisön yleisen tutkintojen tunnustamisjärjestelmän voimaanpanosta annetussa laissa tarkoitettu päätös kelpoisuudesta virkaan tai tehtävään 1 000 markkaa;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** ulkomaisessa oppilaitoksessa suoritetun merenkulkua koskevan koulutuksen vastaavuudesta päättäminen 1 000 markkaa;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** opetushallinnon tutkintoon osallistuminen, tutkintomaksu jokaiselta tutkintokerralta 300 markkaa; sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** 11 kohdassa mainitun tutkinnon tai sen osan suorittamisesta annettava todistus 100 markkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Maksullisia julkisoikeudellisia suoritteita ovat myös 1 momentissa tarkoitetuissa asioissa annetut kielteiset päätökset\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Suoritteita, jotka opetushallitus hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** koulutus\- ja konsultointipalvelut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** oppimateriaalin tuottaminen ja siihen liittyvä kustannustoiminta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** opetushallituksen rekistereihin ja tietokantoihin perustuva tietopalvelu ja tietokantojen suorakäyttö;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** tilauksesta tehdyt selvitykset ja tutkimukset sekä tiedonkeruu\- ja jakelupalvelut;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** julkaisut ja kustannuspalvelut;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** ilmoitukset opetushallituksen julkaisuissa;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** sähköiset tietotuotteet ja AV\-tuotteet;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** opetushallituksen toimitilojen ja laitteiden käyttö;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** valokopio\- ja muut jäljennökset;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** asiakirjojen ja muun aineiston lähettäminen ja postitus; sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** muut tilatut palvelusuoritteet\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Edellä 1 momentin kohdissa 3, 5 ja 7 tarkoitetut suoritteet ovat kuitenkin maksuttomia silloin, kun ne liittyvät koulutusta koskevan tiedotuksen ja neuvonnan järjestämiseen ja tukemiseen\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Maksullista on myös 1 momentissa mainit\- tujen suoritteiden käyttöoikeuksien ja muiden oikeuksien väliaikainen luovuttaminen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1999 ja on voimassa 31 päivään joulukuuta 2001 saakka\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan 14 päivänä heinäkuuta 1997 annettu samanniminen päätös [\(688/1997\)](<https://www.finlex.fi/fi/lainsaadanto/1997/688>)\.
