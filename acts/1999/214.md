# Maa\- ja metsätalousministeriön päätös eräistä kalastusrajoituksista Saimaalla

<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä päätöksellä kielletään eräiden pyydysten ja kalastustapojen käyttö saimaanhylkeen elinolosuhteiden ja lisääntymisen turvaamiseksi sen keskeisillä elinalueilla toukokuun 1999 alusta huhtikuun 2004 loppuun\.

<a id="section-2"></a>
### 2 § Saimaanhylkeen keskeiset elinalueet

<a id="section-2-subsection-1"></a>
#### \(1\)

Tässä päätöksessä tarkoitettuja saimaanhylkeen keskeisiä elinalueita Saimaalla ovat liitteenä oleviin karttapiirroksiin merkityt seuraavat vesialueet tai vesialueen osat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Pyhäselän saaristot, liite 1;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Oriveden saaristot, liite 2;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Joutenvesi―Pyyvesi, liite 3;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kolovesi, liite 4;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Linnansaari, liite 5;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Hevonniemi, liite 6;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Pihlajavesi, liite 7;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Katosselkä―Tolvanselkä ympäristöineen, liite 8;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Luonteri, liite 9;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Lietvesi ympäristöineen, liite 10;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Ilkonselkä, liite 11\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Saimaanhylkeen keskeisiksi elinalueiksi ei kuitenkaan katsota 1 momentissa tarkoitetulla alueella sijaitsevissa saarissa olevia sisäjärviä ja lampia\.

<a id="section-3"></a>
### 3 § Kielletyt pyydykset

<a id="section-3-subsection-1"></a>
#### \(1\)

Seuraavien pyydysten ja pyyntitapojen käyttö on kielletty 2 §:ssä tarkoitetuilla alueilla:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** pitkäsiima ja muu koukkupyydys, jossa käytetään syöttinä kalaa tai kalanpalaa;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** verkko ja riimuverkko, jonka liina tai riimu on tehty monisäikeisestä langasta \(multimonofiililanka\) tai joka on tehty paksummasta kuin 0,20 millimetrin vahvuisesta yksisäikeisestä langasta \(monofiililanka\);

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** päältä avoin isorysä ja muu isorysää vastaava seisova pyydys, jonka silmäkoko on yli 110 millimetriä tai jonka solmuväli on yli 55 millimetriä, sekä sellainen isorysä, joka ei ole päältä avoin\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Pyydyksiä ja pyyntitapoja koskevat 1 momentissa säädetyt rajoitukset eivät koske onkimista, pilkkimistä ja uistelua, vaikka niitä harjoitettaisiin kalasyöttiä käyttäen, eivätkä pyyntiä katiskalla, merralla tai sellaisella rysällä, joka aitaverkkoineen on enintään kuuden metrin pituinen\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä toukokuuta 1999\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa käyttöön otettuja verkkoja, riimuverkkoja, isorysiä ja muita isorysää vastaavia pyydyksiä saadaan käyttää 2 §:ssä tarkoitetulla alueella kalastettaessa enintään huhtikuun 2002 loppuun\.
