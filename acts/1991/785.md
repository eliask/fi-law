# Valtioneuvoston päätös eräiden tilojen ja alueiden siirtämisestä Suonenjoen kaupungista ja Tuusniemen, Heinäveden sekä Jäppilän kunnista Leppävirran kuntaan

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Suonenjoen kaupungista siirretään Leppävirran kuntaan Sydänmaan kylästä talojen N:ot 1\-9 yhteinen Humalajoen palsta sekä palstan alueella olevat muut yhteiset ja yleiset alueet\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Tuusniemen kunnasta siirretään Leppävirran kuntaan Kosulan kylästä kokonaan tilat Jakosensuo 3:8 ja Hultinsuo 5:1 sekä talon N:o 2 yhteinen Alasuon palsta ja edellä mainittujen tilojen ja palstan alueella olevat muut yhteiset ja yleiset alueet\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Heinäveden kunnasta siirretään Leppävirran kuntaan Kypäräjärven kylästä kokonaan tilat Konnanlahti 8:2, Kortekannaksen kanava\-alue 8:60, Kortesaari 8:112, Suviniemi 8:113, Siniranta 8:114 ja Kortekanta 8:115 sekä tilojen alueella olevat yhteiset ja yleiset alueet\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Jäppilän kunnasta siirretään Leppävirran kuntaan Kukkolan kylästä kokonaan tila Puttaa 7:26 sekä tilan alueella olevat yhteiset alueet\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-6"></a>
### 6§

<a id="section-6-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1992\.
