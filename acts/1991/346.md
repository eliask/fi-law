### 1§ Määritelmät

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa tarkoitetaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** liikenneyrittäjäkurssilla liikenneministeriön ohjauksessa ja valvonnassa tapahtuvaa tavaraliikenteen alalletulokoulutusta;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** valvontapaikalla liikenneluvan haltijan kotikuntaa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** liikenteestä vastaavalla henkilöllä oikeushenkilön tähän tehtävään esittämää ja lupaviranomaisen hyväksymää henkilöä, joka vastaa siitä, että liikennettä hoidetaan säännösten, määräysten ja lupaehtojen mukaisesti; sekä

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** ajoneuvolla moottoriajoneuvoa ja liikennetraktoria\.

<a id="section-2"></a>
### 2 § Liikenneluvan myöntämisen edellytykset

<a id="section-2-subsection-1"></a>
#### \(1\)

Kotimaan liikennelupa myönnetään hakijalle, joka

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** on hyvämaineinen ja muutoinkin henkilönä sopiva harjoittamaan liikennettä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** on suorittanut hyväksytysti asianomaista ajoneuvoluokkaa vastaavan kotimaan liikenneyrittäjäkurssin tai osoittanut hallitsevansa kurssia vastaavat tiedot liikenneministeriön määräämällä tavalla järjestetyssä näyttökokeessa;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** täyttää liikenneministeriön asettamat vaatimukset käytännön kokemuksesta liikennealalla;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** hallitsee itseään ja omaisuuttaan; sekä

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** on vakavarainen\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Liikennelupa myönnetään 1 momentin 5 kohdan vaatimuksen täyttävälle oikeushenkilölle, jonka liikenteestä vastaava henkilö täyttää 1\-4 kohdan vaatimukset ja kykenee asianmukaisesti vastaamaan velvoitteistaan\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Ulkomaan liikenneluvan myöntämisen edellytyksenä on 1 ja 2 momentin vaatimusten lisäksi, että hakija tai liikenteestä vastaava henkilö on suorittanut hyväksytysti ulkomaan liikenneyrittäjäkurssin\.

<a id="section-2-subsection-4"></a>
#### \(4\)

Hakija on katsottava vakavaraiseksi, jos hän kykenee asianmukaisesti vastaamaan velvoitteistaan ja osoittaa liikenneministeriön määräämällä tavalla, että hänellä on riittävät taloudelliset voimavarat liikenteen asianmukaiseen hoitamiseen\.

<a id="section-2-subsection-5"></a>
#### \(5\)

Hakijan tai liikenteestä vastaavan henkilön ei ole katsottava täyttävän 1 momentin 1 kohdassa säädettyä hyvämaineisuuden vaatimusta, jos

<a id="section-2-subsection-5-paragraph-1"></a>
- **1.** hänet on viimeksi kuluneiden viiden vuoden aikana tuomittu vankeusrangaistukseen rikoksesta tai

<a id="section-2-subsection-5-paragraph-2"></a>
- **2.** hänet on vähintään kolmesti viimeksi kuluneen vuoden aikana tuomittu sakkorangaistukseen työ\- tai palkkasuhdetta, liikenteen harjoittamista, ajo\- ja lepoaikojen noudattamista taikka liikenne\- tai ajoneuvoturvallisuutta koskevien säännösten ja määräysten rikkomisesta ja jos rikokset osoittavat hänen olevan ilmeisen sopimaton harjoittamaan luvanvaraista tavara liikennettä\.

<a id="section-3"></a>
### 3 § Liikenneluvan hakeminen

<a id="section-3-subsection-1"></a>
#### \(1\)

Lupahakemus on tehtävä kirjallisesti\. Siihen on liitettävä:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** yksi jäljennös hakemuksesta;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** oikeaksi todistetut jäljennökset ammattitaitovaatimusten täyttämisen osoittavista todistuksista;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** selvitys siitä, että hakija tai liikenteestä vastaava henkilö hallitsee itseään ja omaisuuttaan;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** asianmukainen takaussitoumus alkuperäisenä; sekä

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** lupaviranomaisen mahdollisesti edellyttämä muu selvitys\.

<a id="section-4"></a>
### 4§ Liikenneluvan sisältö

<a id="section-4-subsection-1"></a>
#### \(1\)

Jokaiselle ajoneuvolle annetaan erillinen liikennelupa\. Siihen on merkittävä ainakin:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** luvan haltija ja tämän kotikunta;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** liikenteen laajuus;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** ajoneuvoluokka;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** voimassaoloaika;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** oikeushenkilön liikenteestä vastaava henkilö; sekä

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** ehdot, joita liikennettä harjoitettaessa on noudatettava\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Liikenneluvan voimassaoloaika on viisi vuotta\. Kun hakijalle myönnetään liikennelupa ensi kertaa, sen voimassaoloaika on kolme vuotta\. Erityisistä syistä liikennelupa voidaan myöntää edellä tarkoitettuja määräaikoja lyhyemmäksi ajaksi\.

<a id="section-5"></a>
### 5§ Kotimaan liikenneluvalla sallitut ulkomaankuljetukset

<a id="section-5-subsection-1"></a>
#### \(1\)

Kotimaan liikennelupa oikeuttaa:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** kuljettamaan tavaraa Ruotsin ja Norjan Suomen rajaan rajoittuviin kuntiin sekä Venäjän Alakurttiin ja näiltä paikkakunnilta Suomeen;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** kuljettamaan ulkomaille sellaisen koneen, laitteen tai varaosan, jota sen vastaanottaja kiireellisesti tarvitsee rikkoontuneen tilalle liikkeen, laitoksen tai yrityksen toiminnan ylläpitämiseksi, ja tuomaan paluukuormana rikkoontuneen koneen, laitteen tai varaosan;

<a id="section-5-subsection-1-paragraph-2a"></a>
- **2a.** kuljettamaan ulkomaille tai ulkomailta vahingoittuneita tai rikkoontuneita moottoriajoneuvoja;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** kuljettamaan ulkomaille tai ulkomailta maa\- ja kiviaineksia sekä jalostamatonta puutavaraa; sekä

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** suorittamaan ulkomaille tai ulkomailta muutto\- ja näyttelykuljetuksia\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Edellä 1 momentin 3 ja 4 kohdassa tarkoitetuissa tapauksissa saa paluukuljetuksena kuljettaa muutakin tavaraa\.

<a id="section-7"></a>
### 7 § Kuljetuksen keskeyttäminen

<a id="section-7-subsection-1"></a>
#### \(1\)

Milloin kuljetus luvanvaraisesta tavaraliikenteestä tiellä annetun lain 15 §:n nojalla keskeytetään, on poliisi\-, tulli\- ja rajavartiomiehellä oikeus tarvittaessa ottaa ajoneuvon rekisteriote ja \-kilvet haltuunsa\. Ne on annettava takaisin, kun perustetta kuljetuksen keskeyttämiselle ei enää ole\.

<a id="section-8"></a>
### 8§ Liikenneluvan muuttaminen ja uusiminen

<a id="section-8-subsection-1"></a>
#### \(1\)

Liikenneluvan muuttamista tai uusimista haetaan siinä järjestyksessä kuin luvan hakemisesta 3§:ssä säädetään\.

<a id="section-8-subsection-2"></a>
#### \(2\)

Hakemusta ratkaistaessa on 2§:n säännösten lisäksi otettava huomioon, onko liikennettä harjoitettu lupien mukaisesti ja muutoin asianmukaisesti\.

<a id="section-8-subsection-3"></a>
#### \(3\)

Jos uusiminen on pantu vireille viimeistään kaksi kuukautta ennen liikenneluvan viimeistä voimassaolopäivää, uusittavalla luvalla saa jatkaa liikennettä siihen saakka kun asia on ratkaistu\.

<a id="section-9"></a>
### 9§ Kuolinpesän oikeus jatkaa liikennettä

<a id="section-9-subsection-1"></a>
#### \(1\)

Kuolleen luvanhaltijan liikenteen hoitamista koskevista velvollisuuksista vastaavan henkilön tulee täyttää 2§:n 1 momentin 1 ja 4 kohdassa säädetyt vaatimukset\.

<a id="section-10"></a>
### 10 § Liikenteestä vastaava henkilö

<a id="section-10-subsection-1"></a>
#### \(1\)

Oikeushenkilöllä tulee aina olla lupaviranomaisen hyväksymä liikenteestä vastaava henkilö, joka tosiasiallisesti ja jatkuvasti toimii tässä tehtävässä\. Liikenteestä vastaavaa henkilöä vaihdettaessa noudatetaan soveltuvin osin mitä liikenneluvan hakemisesta säädetään\.

<a id="section-10-subsection-2"></a>
#### \(2\)

Jos liikenteestä vastaavaa henkilöä on vaihdettava kuoleman, äkillisen vakavan sairauden, tapaturman tai muun näihin verrattavan ennalta arvaamattoman tapahtuman vuoksi, on hakemus toimitettava viipymättä lupaviranomaiselle\. Mikäli tehtävään ei voida heti esittää 2 §:n 1 momentin 2 ja 3 kohdassa säädetyt vaatimukset täyttävää henkilöä, on vaatimusten täyttämisen osoittavat selvitykset toimitettava mahdollisimman pian ja kuitenkin viimeistään vuoden kuluttua vaihtamistarpeen aiheuttaneesta tapahtumasta\.

<a id="section-10-subsection-3"></a>
#### \(3\)

Jos oikeushenkilöt muodostavat konsernin tai siihen verrattavan yhtymän, sama henkilö voidaan tällaisissa tapauksissa hyväksyä kahden tai useamman oikeushenkilön liikenteestä vastaavaksi henkilöksi\. Luonnollinen henkilö, jolla on liikennelupa, voidaan hyväksyä oikeushenkilön liikenteestä vastaavaksi henkilöksi vain, jos hänellä on osakkuuteen tai osakkeiden omistukseen perustuva määräämisvalta tässä yhteisössä\.

<a id="section-11"></a>
### 11 § Liikenteen valvonta

<a id="section-11-subsection-1"></a>
#### \(1\)

Valvontapaikan poliisin tulee ilmoittaa lupaviranomaiselle tiedossaan olevista seikoista, joiden voidaan olettaa johtavan luvanvaraisesta tavaraliikenteestä tiellä annetun lain 10 §:ssä tarkoitettuun liikenneluvan peruuttamiseen tai varoitukseen\.

<a id="section-11a"></a>
### 11 a § Kuljetuslupien jakaminen

<a id="section-11a-subsection-1"></a>
#### \(1\)

Liikenneministeriö ja tullilaitos jakavat kansainvälisissä sopimuksissa edellytetyt kuljetusluvat sopimallaan tavalla\.

<a id="section-11b"></a>
### 11 b § Kansainvälisestä tavaraliikenteestä ja kabotaasiliikenteestä annetuissa neuvoston asetuksissa tarkoitetut toimivaltaiset viranomaiset

<a id="section-11b-subsection-1"></a>
#### \(1\)

Yhteisössä jäsenvaltion alueelle tai sen alueelta taikka yhden tai useamman jäsenvaltion alueen kautta tapahtuvan maanteiden tavaraliikenteen markkinoille pääsystä annetussa Euroopan yhteisöjen neuvoston asetuksessa \(ETY\) N:o 881/92 tarkoitettu toimivaltainen viranomainen on Suomessa lääninhallitus\.

<a id="section-11b-subsection-2"></a>
#### \(2\)

Edellytyksistä, joilla muut kuin jäsenvaltiosta olevat liikenteenharjoittajat voivat harjoittaa kansallista maanteiden tavaraliikennettä jäsenvaltiossa, annetussa neuvoston asetuksessa \(ETY\) N:o 3118/93 tarkoitettu toimivaltainen viranomainen on Suomessa liikenneministeriö\.

<a id="section-11c"></a>
### 11 c § Valtuutussäännös

<a id="section-11c-subsection-1"></a>
#### \(1\)

Liikenneministeriö voi antaa tarkempia määräyksiä luvanvaraisesta tavaraliikenteestä tiellä annetun lain 17 §:n 2 momentissa tarkoitettujen Euroopan yhteisöjen neuvoston säädösten täytäntöönpanosta ja soveltamisesta\.

<a id="section-12"></a>
### 12§ Voimaantulo

<a id="section-12-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1991\. Asetuksen 4§:n 1 momentti ja 5§ tulevat kuitenkin voimaan 1 päivänä tammikuuta 1993\.

<a id="section-13"></a>
### 13§ Siirtymäsäännökset

<a id="section-13-subsection-1"></a>
#### \(1\)

Vuosien 1991 ja 1992 aikana myönnettäviin liikennelupiin merkitään:

<a id="section-13-subsection-1-paragraph-1"></a>
- **1.** luvan haltija;

<a id="section-13-subsection-1-paragraph-2"></a>
- **2.** liikenteen laatu;

<a id="section-13-subsection-1-paragraph-3"></a>
- **3.** linjaliikenteen reitti tai tilausliikenteen liikennealue;

<a id="section-13-subsection-1-paragraph-4"></a>
- **4.** tilausliikenteessä käytettävien ajoneuvojen laji ja lukumäärä;

<a id="section-13-subsection-1-paragraph-5"></a>
- **5.** valvontapaikka;

<a id="section-13-subsection-1-paragraph-6"></a>
- **6.** voimassaoloaika;

<a id="section-13-subsection-1-paragraph-7"></a>
- **7.** oikeushenkilön liikenteestä vastaava henkilö; sekä

<a id="section-13-subsection-1-paragraph-8"></a>
- **8.** ehdot, joita liikennettä harjoitettaessa on noudatettava\.

<a id="section-13-subsection-2"></a>
#### \(2\)

Vuoden 1992 loppuun saakka linjaliikenteeseen ei sovelleta ajoneuvon liikenneluvalle ilmoittamista ja vaihtamista koskevia 6 ja 7§:n säännöksiä\.

<a id="section-13-subsection-3"></a>
#### \(3\)

Mitä tässä asetuksessa säädetään valvontapaikasta, koskee soveltuvin osin myös asemapaikkaa\.
