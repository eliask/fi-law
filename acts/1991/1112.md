<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Jyväskylän yliopiston humanistisessa tiedekunnassa johtavat filosofian kandidaatin tutkintoon seuraavat koulutusohjelmat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** suomen kielen ja sen sukukielten koulutusohjelma;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** vieraiden kielten koulutusohjelma;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** klassillisten kielten koulutusohjelma;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** historian koulutusohjelma;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** taiteiden tutkimuksen koulutusohjelma;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** kulttuurien tutkimuksen koulutusohjelma;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** musiikkikasvatuksen ja musiikkiterapian koulutusohjelma;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** soveltavan kielitieteen ja puheentutkimuksen koulutusohjelma;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** journalistiikan koulutusohjelma; sekä

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** puheviestinnän koulutusohjelma\.
