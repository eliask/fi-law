# Valtioneuvoston päätös rakennushallinnon rakennuspiireistä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion rakennushallinnon paikallisia tehtäviä varten maa jaetaan kymmeneen rakennuspiiriin\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Rakennuspiirien alueet ja niiden hallintopaikat ovat seuraavat:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** Helsingin rakennuspiiri käsittää Helsingin kaupungin hallintopaikkanaan Helsingin kaupunki\.

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** Uudenmaan rakennuspiiri käsittää Uudenmaan läänin lukuunottamatta Helsingin kaupunkia hallintopaikkanaan Espoon kaupunki\.

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** Turun rakennuspiiri käsittää Turun ja Porin läänin sekä Ahvenanmaan läänin hallintopaikkanaan Turun kaupunki\.

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** Hämeen rakennuspiiri käsittää Hämeen läänin hallintopaikkanaan Hämeenlinnan kaupunki\.

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** Kymen ja Mikkelin rakennuspiiri käsittää Kymen läänin ja Mikkelin läänin hallintopaikkanaan Kouvolan kaupunki\.

<a id="section-1-subsection-2-paragraph-6"></a>
- **6.** Kuopion ja Pohjois\-Karjalan rakennuspiiri käsittää Kuopion läänin ja Pohjois\-Karjalan läänin hallintopaikkaan Kuopion kaupunki\.

<a id="section-1-subsection-2-paragraph-7"></a>
- **7.** Keski\-Suomen rakennuspiiri käsittää Keski\-Suomen läänin hallintopaikkanaan Jyväskylän kaupunki\.

<a id="section-1-subsection-2-paragraph-8"></a>
- **8.** Vaasan rakennuspiiri käsittää Vaasan läänin hallintopaikkanaan Vaasan kaupunki\.

<a id="section-1-subsection-2-paragraph-9"></a>
- **9.** Oulun rakennuspiiri käsittää Oulun läänin hallintopaikkanaan Oulun kaupunki\.

<a id="section-1-subsection-2-paragraph-10"></a>
- **10.** Lapin rakennuspiiri käsittää Lapin läänin hallintopaikkanaan Rovaniemen kaupunki\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Helsingin rakennuspiiri on kaksikielinen\. Asukkaiden enemmistö on suomenkielinen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1992 ja sillä kumotaan rakennushallinnon rakennuspiireistä 11 päivänä kesäkuuta 1986 annettu valtioneuvoston päätös [\(466/86\)](<https://www.finlex.fi/fi/lainsaadanto/1986/466>)\.
