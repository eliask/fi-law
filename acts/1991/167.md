<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan ja lakkautetaan jäljempänä mainitut peruspalkkaiset virat\.

<a id="section-2"></a>
### 2§ Ammatilliset opettajakorkeakoulut

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan 1 päivästä maaliskuuta 1991 lukien:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yksi A 11 palkkausluokkaan kuuluva toimistosihteerin virka;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yksi A 10 palkkausluokkaan kuuluva kirjastovirkailijan virka;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kaksi A 9 palkkausluokkaan kuuluvaa toimistosihteerin virkaa;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** yksi A 8 palkkausluokkaan kuuluva toimistovirkailijan virka;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** yksi A 7 palkkausluokkaan kuuluva puhelunvälittäjän virka; ja

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** yksi A 5 palkkausluokkaan kuuluva toimistovirkailijan virka\.

<a id="section-2-subsection-2"></a>
#### \(2\)

1 päivästä elokuuta 1991 lukien:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** yksi C 57 palkkausluokkaan kuuluva yliopettajan virka\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Lakkautetaan 1 päivästä elokuuta 1991 lukien:

<a id="section-2-subsection-3-paragraph-1"></a>
- **1.** Ammattikoulujen Hämeenlinnan opettajaopiston ammattikoulu

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1991\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Tällä asetuksella perustetut virat voidaan ensimmäisellä kerralla täyttää niitä haettavaksi julistamatta\.

<a id="section-4-subsection-3"></a>
#### \(3\)

Toimenpiteisiin tällä asetuksella perustettujen virkojen täyttämiseksi saadaan ryhtyä jo ennen sitä ajankohtaaa, josta lukien virka on perustettu\.
