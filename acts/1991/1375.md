<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Korkotukilainoja voidaan antaa:

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** yritysten ja yhdyskuntien energiansäästöinvestointien suorittamiseen;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** kotimaista energialähdettä käyttävien laitosten rakentamiseen ja kotimaisten polttoaineiden tuotannon investointien suorittamiseen;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** uuteen energiateknologiaan perustuvien investointien suorittamiseen;
