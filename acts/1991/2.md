## 1 luku Autorekisterikeskuksen tehtävät, organisaatio ja johto

<a id="chapter-1-section-1"></a>
### 1§ Autorekisterikeskuksen tehtävät

<a id="chapter-1-section-1-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen tehtävänä on:

<a id="chapter-1-section-1-subsection-1-paragraph-1"></a>
- **1.** johtaa ja valvoa ajoneuvojen katsastustointa ja siihen liittyviä tehtäviä;

<a id="chapter-1-section-1-subsection-1-paragraph-2"></a>
- **2.** johtaa ja valvoa kuljettajaopetus\- ja kuljettajantutkintotoimintaa;

<a id="chapter-1-section-1-subsection-1-paragraph-3"></a>
- **3.** toimittaa ajoneuvojen tyyppikatsastukset;

<a id="chapter-1-section-1-subsection-1-paragraph-4"></a>
- **4.** pitää rekisteriä ajoneuvoista;

<a id="chapter-1-section-1-subsection-1-paragraph-5"></a>
- **5.** pitää autorekisterikeskuksesta annetun lain 1§:n mukaista ajokorttirekisteriä;

<a id="chapter-1-section-1-subsection-1-paragraph-6"></a>
- **6.** toimittaa moottoriajoneuvoveron maksuunpano, kanto ja tilitystehtävät;

<a id="chapter-1-section-1-subsection-1-paragraph-7"></a>
- **7.** käsitellä autokiinnitysasiat;

<a id="chapter-1-section-1-subsection-1-paragraph-8"></a>
- **8.** kehittää toimialaansa ja tehdä sitä koskevia parannusesityksiä; sekä

<a id="chapter-1-section-1-subsection-1-paragraph-9"></a>
- **9.** suorittaa sille säädetyt ja määrätyt muut tehtävät\.

<a id="chapter-1-section-2"></a>
### 2§ Autorekisterikeskuksen osastot ja toimistot

<a id="chapter-1-section-2-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksessa on yleinen osasto, katsastusosasto ja tietohallinto\-osasto\. Osastoissa on toimistoja ja toimistoissa jaostoja sen mukaan kuin työjärjestyksessä määrätään\.

<a id="chapter-1-section-3"></a>
### 3§ Autorekisterikeskuksen johtokunta

<a id="chapter-1-section-3-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen toimintaa ohjaa ja valvoo valtioneuvoston enintään neljäksi vuodeksi kerrallaan nimeämä johtokunta\.

<a id="chapter-1-section-3-subsection-2"></a>
#### \(2\)

Johtokuntaan kuuluu puheenjohtaja, varapuheenjohtaja ja neljä muuta jäsentä\. Yksi jäsen on määrättävä autorekisterikeskuksen edustavimpien henkilöstöjärjestöjen ehdottamista, autorekisterikeskuksen palveluksessa olevista henkilöistä\.

<a id="chapter-1-section-3-subsection-3"></a>
#### \(3\)

Liikenneministeriö vahvistaa johtokunnan jäsenten palkkiot\.

<a id="chapter-1-section-4"></a>
### 4§ Johtokunnan tehtävät

<a id="chapter-1-section-4-subsection-1"></a>
#### \(1\)

Johtokunnan tehtävänä on:

<a id="chapter-1-section-4-subsection-1-paragraph-1"></a>
- **1.** päättää autorekisterikeskuksen yleisistä toimintalinjoista ja käytännön tavoitteista ottaen huomioon liikenneministeriön virastolle asettamat tavoitteet;

<a id="chapter-1-section-4-subsection-1-paragraph-2"></a>
- **2.** päättää autorekisterikeskuksen tulo\- ja menoarvioehdotuksesta sekä toiminta\- ja taloussuunnitelmasta;

<a id="chapter-1-section-4-subsection-1-paragraph-3"></a>
- **3.** ohjata ja valvoa autorekisterikeskukselle asetettujen tavoitteiden toteuttamista;

<a id="chapter-1-section-4-subsection-1-paragraph-4"></a>
- **4.** päättää merkittävistä tutkimus\- ja kehittämistehtävistä;

<a id="chapter-1-section-4-subsection-1-paragraph-5"></a>
- **5.** antaa lausunto ylijohtajan, osastopäällikön ja lääninkatsastusmiehen nimitysasiassa; sekä

<a id="chapter-1-section-4-subsection-1-paragraph-6"></a>
- **6.** käsitellä muita viraston kannalta merkittäviä asioita, joiden esittelystä johtokunnalle päättää ylijohtaja\.

<a id="chapter-1-section-5"></a>
### 5§ Asiain käsittely johtokunnassa

<a id="chapter-1-section-5-subsection-1"></a>
#### \(1\)

Johtokunta on päätösvaltainen, kun kokouksen puheenjohtaja sekä vähintään kolme muuta jäsentä on läsnä\.

<a id="chapter-1-section-5-subsection-2"></a>
#### \(2\)

Johtokunnan kokouksessa päätetään asiat erimielisyyden sattuessa yksinkertaisella äänten enemmistöllä\. Äänten mennessä tasan tulee päätökseksi se mielipide, jota kokouksen puheenjohtaja on kannattanut\.

<a id="chapter-1-section-5-subsection-3"></a>
#### \(3\)

Johtokunta vahvistaa tarkemmat määräykset asiain käsittelystä johtokunnassa\.

<a id="chapter-1-section-6"></a>
### 6§ Autorekisterikeskuksen virkamiesjohto

<a id="chapter-1-section-6-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen päällikkönä on ylijohtaja\.

<a id="chapter-1-section-6-subsection-2"></a>
#### \(2\)

Yleisen osaston, katsastusosaston ja tietohallinto\-osaston päällikkönä on osastopäällikkö\. Yleisen osaston osastopäälliköllä on johtajan ja katsastusosaston osastopäälliköllä yli\-insinöörin arvonimi\.

<a id="chapter-1-section-7"></a>
### 7§ Ylijohtajan tehtävät

<a id="chapter-1-section-7-subsection-1"></a>
#### \(1\)

Ylijohtaja johtaa autorekisterikeskuksen toimintaa ja valvoo, että sille kuuluvat tehtävät hoidetaan tehokkaasti, taloudellisesti ja tarkoituksenmukaisesti\. Ylijohtaja huolehtii johtokunnan päätösten toimeenpanosta\. Hänen tulee seurata yleistä kehitystä alalla sekä tehdä aloitteita ja valmistaa suunnitelmia tarpeellisiksi uudistuksiksi ja parannuksiksi\.

<a id="chapter-1-section-7-subsection-2"></a>
#### \(2\)

Ylijohtaja ratkaisee ne autorekisterikeskukselle kuuluvat asiat, joita ei ole tässä asetuksessa säädetty johtokunnan tai autorekisterikeskuksen työjärjestyksessä osastopäällikön, toimistopäällikön tai muun virkamiehen ratkaistaviksi\.

<a id="chapter-1-section-7-subsection-3"></a>
#### \(3\)

Ylijohtaja ratkaisee asianomaisen virkamiehen esittelystä asiat, joissa autorekisterikeskus on valitusviranomainen, jollei työjärjestyksessä ole toisin määrätty\.

<a id="chapter-1-section-7-subsection-4"></a>
#### \(4\)

Ylijohtaja voi ottaa ratkaistavakseen asian, joka työjärjestyksessä on määrätty muun virkamiehen ratkaistavaksi\.

<a id="chapter-1-section-8"></a>
### 8§ Ylijohtajan sijainen

<a id="chapter-1-section-8-subsection-1"></a>
#### \(1\)

Ylijohtajan ollessa estynyt toimii hänen sijaisenaan yleisen osaston osastopäällikkö\.

<a id="chapter-2"></a>
## 2 luku Aluehallinto

<a id="chapter-2-section-9"></a>
### 9§ Katsastustoimipaikkojen sijoituspaikat ja toimialueet

<a id="chapter-2-section-9-subsection-1"></a>
#### \(1\)

Liikenneministeriö määrää katsastustoimipaikkojen eli katsastuskonttorien ja katsastustoimistojen sijoituspaikat ja toimialueet\.

<a id="chapter-2-section-10"></a>
### 10§ Katsastustoimipaikkojen tehtävät

<a id="chapter-2-section-10-subsection-1"></a>
#### \(1\)

Katsastuskonttori johtaa ja valvoo katsastustoimistojen toimintaa ja suorittaa muut sille jäljempänä säädetyt tehtävät\.

<a id="chapter-2-section-10-subsection-2"></a>
#### \(2\)

Katsastustoimipaikan tehtävänä on:

<a id="chapter-2-section-10-subsection-2-paragraph-1"></a>
- **1.** suorittaa erikseen säädetyt ajoneuvojen ja laitteiden katsastukset;

<a id="chapter-2-section-10-subsection-2-paragraph-2"></a>
- **2.** toimittaa kuljettajantutkinnot;

<a id="chapter-2-section-10-subsection-2-paragraph-3"></a>
- **3.** valvoa toimialueensa autokoulujen toimintaa;

<a id="chapter-2-section-10-subsection-2-paragraph-4"></a>
- **4.** valvoa ajoneuvojen käyttöä liikenteessä siten kuin siitä on erikseen säädetty tai määrätty;

<a id="chapter-2-section-10-subsection-2-paragraph-5"></a>
- **5.** suorittaa erikseen säädetyt rekisteröintitehtävät; sekä

<a id="chapter-2-section-10-subsection-2-paragraph-6"></a>
- **6.** suorittaa sille säädetyt ja määrätyt muut tehtävät\.

<a id="chapter-2-section-11"></a>
### 11§ Katsastustoimipaikkojen päälliköt ja toimihenkilöt

<a id="chapter-2-section-11-subsection-1"></a>
#### \(1\)

Katsastuskonttorin päällikkönä on liikenneministeriön määräämä lääninkatsastusmies\.

<a id="chapter-2-section-11-subsection-2"></a>
#### \(2\)

Katsastustoimiston päällikkönä on autorekisterikeskuksen määräämä katsastusmies, apulaiskatsastusmies tai katsastusteknikko\.

<a id="chapter-2-section-11-subsection-3"></a>
#### \(3\)

Katsastusalueiden toimihenkilöiden sijoittamisesta katsastustoimipaikkoihin määrää autorekisterikeskus, jollei työjärjestyksessä toisin määrätä\.

<a id="chapter-3"></a>
## 3 luku Henkilöstö

<a id="chapter-3-section-12"></a>
### 12§ Esimiesten tehtävät

<a id="chapter-3-section-12-subsection-1"></a>
#### \(1\)

Osastopäällikön, toimistopäällikön, katsastuskonttorin päällikön ja muun esimiehen tehtävänä on:

<a id="chapter-3-section-12-subsection-1-paragraph-1"></a>
- **1.** johtaa ja kehittää alansa toimintaa;

<a id="chapter-3-section-12-subsection-1-paragraph-2"></a>
- **2.** huolehtia siitä, että hänen alaansa kuuluvat tehtävät hoidetaan tehokkaasti, taloudellisesti ja tarkoituksenmukaisesti;

<a id="chapter-3-section-12-subsection-1-paragraph-3"></a>
- **3.** huolehtia sellaisesta toimipaikkansa sisäisestä ja ulkoisesta yhteydenpidosta, jota hänen tehtävänsä edellyttävät;

<a id="chapter-3-section-12-subsection-1-paragraph-4"></a>
- **4.** huolehtia alaisensa henkilöstön kehittämisestä ja kouluttamisesta sekä työskentelyolosuhteista;

<a id="chapter-3-section-12-subsection-1-paragraph-5"></a>
- **5.** edistää alaistensa välistä yhteistyötä; sekä

<a id="chapter-3-section-12-subsection-1-paragraph-6"></a>
- **6.** huolehtia alaisensa henkilöstön ja muiden voimavarojen tarkoituksenmukaisesta sijoittelusta ja käytöstä\.

<a id="chapter-3-section-13"></a>
### 13§ Virkojen kelpoisuusvaatimukset

<a id="chapter-3-section-13-subsection-1"></a>
#### \(1\)

Yleisenä kelpoisuusvaatimuksena autorekisterikeskuksen virkoihin on sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="chapter-3-section-13-subsection-2"></a>
#### \(2\)

Lisäksi vaaditaan:

<a id="chapter-3-section-13-subsection-2-paragraph-1"></a>
- **1.** ylijohtajalta virkaan soveltuva ylempi korkeakoulututkinto ja hyvää perehtyneisyyttä hallinnollisiin tehtäviin;

<a id="chapter-3-section-13-subsection-2-paragraph-2"></a>
- **2.** yleisen osaston osastopäälliköltä oikeustieteen kandidaatin tutkinto ja hyvää perehtyneisyyttä hallinnollisiin tehtäviin;

<a id="chapter-3-section-13-subsection-2-paragraph-3"></a>
- **3.** katsastusosaston osastopäälliköltä diplomi\-insinöörin tutkinto ja hyvää perehtyneisyyttä autoalaan;

<a id="chapter-3-section-13-subsection-2-paragraph-4"></a>
- **4.** tietohallinto\-osaston osastopäälliköltä ylempi korkeakoulututkinto sekä hyvää perehtyneisyyttä tietohallintoon; sekä

<a id="chapter-3-section-13-subsection-2-paragraph-5"></a>
- **5.** lääninkatsastusmieheltä diplomi\-insinöörin tutkinto ja perehtyneisyyttä autoalaan\.

<a id="chapter-3-section-13-subsection-3"></a>
#### \(3\)

Katsastus\- ja kuljettajantutkintotehtävissä työskentelevällä tulee olla vähintään BC\-luokan ajokortti\.

<a id="chapter-3-section-14"></a>
### 14§ Nimitystoimivalta

<a id="chapter-3-section-14-subsection-1"></a>
#### \(1\)

Ylijohtajan nimittää tasavallan presidentti\.

<a id="chapter-3-section-14-subsection-2"></a>
#### \(2\)

Osastopäällikön nimittää valtioneuvosto\.

<a id="chapter-3-section-14-subsection-3"></a>
#### \(3\)

Lääninkatsastusmiehen nimittää liikenneministeriö\.

<a id="chapter-3-section-14-subsection-4"></a>
#### \(4\)

Muut virkamiehet nimittää autorekisterikeskus, jollei työjärjestyksessä ole toisin määrätty\.

<a id="chapter-3-section-14-subsection-5"></a>
#### \(5\)

Työsopimussuhteessa olevan henkilökunnan ottaa autorekisterikeskus, jollei työjärjestyksessä ole toisin määrätty\.

<a id="chapter-3-section-15"></a>
### 15§ Virkavapauden myöntäminen

<a id="chapter-3-section-15-subsection-1"></a>
#### \(1\)

Ylijohtajalle myöntää virkavapautta liikenneministeriö\. Yli vuoden kestävän virkavapauden myöntää kuitenkin valtioneuvosto, jollei virkavapaus perustu lakiin tai virkaehtosopimukseen\.

<a id="chapter-3-section-15-subsection-2"></a>
#### \(2\)

Osastopäällikölle myöntää virkavapautta ylijohtaja\. Yli vuoden kestävän virkavapauden myöntää kuitenkin liikenneministeriö, jollei virkavapaus perustu lakiin tai virkaehtosopimukseen\.

<a id="chapter-3-section-15-subsection-3"></a>
#### \(3\)

Virkavapauden muille kuin 1 ja 2 momentissa tarkoitetuille virkamiehille myöntää ylijohtaja, jollei työjärjestyksessä ole toisin määrätty\.

<a id="chapter-3-section-15-subsection-4"></a>
#### \(4\)

Viran hoidosta virkavapauden aikana päättää se, joka on virkavapauden myöntänyt\.

<a id="chapter-3-section-16"></a>
### 16§ Avoinna olevan viran hoitaminen

<a id="chapter-3-section-16-subsection-1"></a>
#### \(1\)

Avoinna olevan viran väliaikaisen hoitajan määrää se, joka siitä myöntää virkavapautta\. Virkavapautta myöntänyt voi kuitenkin määrätä viran väliaikaisen hoitajan enintään vuodeksi, jos virkavapautta myöntänyt ei ole samalla nimittävä viranomainen\.

<a id="chapter-4"></a>
## 4 luku Erinäiset säännökset

<a id="chapter-4-section-17"></a>
### 17§ Toimihenkilöiden tehtäviin soveltu\- mattoman toiminnan kielto

<a id="chapter-4-section-17-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen ja katsastusalueen toimihenkilö ei saa ansio\- tai hyötymistarkoituksessa osallistua tässä asetuksessa tarkoitettujen ajoneuvojen, laitteiden tai niiden osien taikka tarvikkeiden valmistukseen, kauppaan, korjaukseen tai vakuutukseen, poltto\- tai voiteluaineiden kauppaan, ammattimaisen moottoriajoneuvoliikenteen harjoittamiseen, autokoulutoimintaan taikka ajo\-opetus\- tai kuljettajantutkintoaineiston julkaisemiseen eikä muuhunkaan toimintaan, joka on katsottava soveltumattomaksi toimihenkilön asemaan ja tehtäviin\.

<a id="chapter-4-section-17-subsection-2"></a>
#### \(2\)

Autorekisterikeskus voi erityisestä syystä myöntää poikkeuksia 1 momentin säännöksistä\.

<a id="chapter-4-section-18"></a>
### 18§ Valtion edun valvonta

<a id="chapter-4-section-18-subsection-1"></a>
#### \(1\)

Autorekisterikeskus kantaa ja vastaa valtion puolesta sekä valvoo tuomioistuimissa ja virastoissa valtion etua ja oikeutta kaikissa autorekisterikeskuksen hallinnonalaan kuuluvissa asioissa\.

<a id="chapter-4-section-19"></a>
### 19§ Virka\-apu

<a id="chapter-4-section-19-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksella ja katsastustoimipaikalla on niiden toimialoihin liittyvissä asioissa oikeus saada virka\-apua poliisilta\.

<a id="chapter-4-section-20"></a>
### 20§ Virkamerkki

<a id="chapter-4-section-20-subsection-1"></a>
#### \(1\)

Katsastus\- ja kuljettajantutkintotehtävissä työskentelevällä tulee virantoimituksessa olla autorekisterikeskuksen määräämä virkamerkki, joka on tarvittaessa esitettävä\.

<a id="chapter-4-section-21"></a>
### 21§ Työjärjestys

<a id="chapter-4-section-21-subsection-1"></a>
#### \(1\)

Ylijohtaja vahvistaa autorekisterikeskukselle sekä katsastuskonttoreille ja \-toimistoille työjärjestyksen\.

<a id="section-22"></a>
### 22§ Voimaantulo

<a id="section-22-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 15 päivänä tammikuuta 1991\.

<a id="section-22-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan autorekisterikeskuksesta 24 päivänä kesäkuuta 1982 annettu asetus \(478/82\) siihen myöhemmin tehtyine muutoksineen\.
