<a id="section-14"></a>
### 14§

<a id="section-14-subsection-1"></a>
#### \(1\)

Ministeriössä on seuraavat sopimuspalkkaiset virat:

<a id="section-14-subsection-1-paragraph-6"></a>
- **6.** apulaisosastopäälliköitä, joista kaksi toimii metsäosastossa ja yksi kalastus\- ja metsästysosastossa;

<a id="section-14-subsection-2"></a>
#### \(2\)

Ministeriössä on seuraavat peruspalkkaiset virat:

<a id="section-14-subsection-2-paragraph-6a"></a>
- **6a.** ylimetsänhoitaja;

### 15§

<a id="section-15-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena on:

<a id="section-15-subsection-1-paragraph-12a"></a>
- **12a.** ylimetsänhoitajalla virkaan soveltuva ylempi korkeakoulututkinto;
