# Asetus rajavartiolaitoksen eräiden virkojen perustamisesta ja lakkauttamisesta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan ja lakkautetaan jäljempänä mainitut peruspalkkaiset rajavartiolaitoksen virat\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan 1 päivästä maaliskuuta 1991 lukien

<a id="section-2-subsection-2"></a>
#### \(2\)

Lakkautetaan 1 päivästä maaliskuuta 1991 lukien

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1991\.
