# Valtioneuvoston päätös eräiden kuntien ja kunnan osan määräämisestä erityisalueiksi

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erityisalueiksi vuodeksi 1992 määrätään seuraavat kunnat ja kunnan osa:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Lapin läänistä Kemijärvi, Muonio, Pelkosenniemi, Tervola ja Ylitornio;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Oulun läänistä Haapajärvi, Kuivaniemi, Reisjärvi, Utajärvi ja Vaala;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Vaasan läänistä Evijärvi, Kauhajoki, Kortesjärvi, Kurikka, Lappajärvi, Lehtimäki, Lestijärvi ja Soini;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen läänistä Jyväskylän maalaiskunnan Tikkakoski \(Tikkamannilan kylä\), Kannonkoski, Keuruu, Kinnula, Kivijärvi, Multia ja Viitasaari;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Kuopion läänistä Iisalmi, Leppävirta, Suonenjoki, Varkaus ja Varpaisjärvi;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan läänistä Nurmes, Tohmajärvi, Valtimo ja Värtsilä;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Mikkelin läänistä Kangasniemi, Mäntyharju, Pieksämäki ja Pieksämäen maalaiskunta;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kymen läänistä Hamina;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Hämeen läänistä Mänttä, Toijala, Urjala, Valkeakoski, Viiala ja Virrat;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Turun ja Porin läänistä Kihniö, Kullaa, Luvia, Noormarkku, Pori ja Ulvila; sekä

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Uudenmaan läänistä Loviisa ja Ruotsinpyhtää\.
