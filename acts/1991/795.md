### 1§ Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tämä päätös koskee elintarvikkeiden pakkausmerkinnöistä annetun asetuksen \(794/91\) soveltamista ja asetuksen säännöksistä määrättyjä yleisiä poikkeuksia\.

<a id="section-2"></a>
### 2§ Ainesosien ilmoittamatta jättäminen

<a id="section-2-subsection-1"></a>
#### \(1\)

Seuraavaa ainetta tai valmistetta ei pidetä ainesosana:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** ainesosan osaa, joka on väliaikaisesti valmistusprosessin aikana erotettu, mutta joka myöhemmin on palautettu alkuperäiseen määräänsä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** lisäainetta:

<a id="section-2-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** joka on joutunut elintarvikkeeseen ainesosan mukana eikä sillä ole lisäaineellista vaikutusta lopullisessa elintarvikkeessa;

<a id="section-2-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** jota on käytetty valmistuksen apuaineena; eikä

<a id="section-2-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** ainetta tai valmistetta, jota on käytetty aromiaineen tai muun lisäaineen liuottimena tai kantaja\-aineena siinä pitoisuudessa, joka on toiminnon kannalta teknisesti välttämätön\.

<a id="section-3"></a>
### 3§ Elintarvikkeet, joiden ainesosia ei tarvitse ilmoittaa

<a id="section-3-subsection-1"></a>
#### \(1\)

Seuraavien elintarvikkeiden ainesosia ei tarvitse ilmoittaa:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** käymisen avulla valmistetut etikat, jotka on saatu yksinomaan yhdestä valmistusaineesta, edellyttäen, että etikkaan ei ole lisätty muita ainesosia ja että valmistusaine näkyy nimestä;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** hapatettu maito ja kerma, edellyttäen, että valmisteeseen ei ole lisätty muita kuin maitohappovalmisteita, entsyymejä tai mikrobiviljelmiä, jotka ovat valmistuksen kannalta välttämättömiä; ja

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** elintarvikkeet, jotka koostuvat yhdestä ainesosasta\.

<a id="section-3a"></a>
### 3 a § Ruokasuolan määrän ilmoittaminen

<a id="section-3a-subsection-1"></a>
#### \(1\)

Seuraavien elintarvikkeiden pakkauksessa on ilmoitettava ruokasuolan \(natriumkloridi\) määrä painoprosentteina:

<a id="section-3a-subsection-1-paragraph-1"></a>
- **1.** voi;

<a id="section-3a-subsection-1-paragraph-2"></a>
- **2.** makkarat ja muut lihavalmisteet;

<a id="section-3a-subsection-1-paragraph-3"></a>
- **3.** kalavalmisteet;

<a id="section-3a-subsection-1-paragraph-4"></a>
- **4.** ruokaleipä, näkkileipä ja hapankorppu;

<a id="section-3a-subsection-1-paragraph-5"></a>
- **5.** liemet, keitot ja kastikkeet, myös jauheena tai tiivisteenä;

<a id="section-3a-subsection-1-paragraph-6"></a>
- **6.** laatikkoruoat, jauheliha\-, maksa\- ja kalamurekeruoat; sekä

<a id="section-3a-subsection-1-paragraph-7"></a>
- **7.** ruokasuolaa sisältävät mausteseokset\.

<a id="section-4"></a>
### 4 § Eräiden elintarvikkeiden ilmoittaminen voimakassuolaiseksi

<a id="section-4-subsection-1"></a>
#### \(1\)

Sen lisäksi mitä edellä 3 a §:ssä määrätään, on seuraavien elintarvikkeiden pakkaukseen tehtävä merkintä voimakassuolainen tai lisätty paljon suolaa, jos elintarvikkeen suolapitoisuus \(natriumkloridi\) on:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** voissa enemmän kuin 2,0 painoprosenttia;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** juustossa enemmän kuin 1,4 painoprosenttia;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** leikkele\-, ruoka\- ja raakamakkarassa enemmän kuin 1,8 painoprosenttia;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** ruokaleivässä enemmän kuin 1,3 painoprosenttia;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** näkkileivässä ja hapankorpussa enemmän kuin 1,7 painoprosenttia; ja

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** aamiaismuroissa ja \-hiutaleissa enemmän kuin 1,7 painoprosenttia\.

<a id="section-5"></a>
### 5 § Eräiden elintarvikkeiden ilmoittaminen vähäsuolaiseksi

<a id="section-5-subsection-1"></a>
#### \(1\)

Seuraavien elintarvikkeiden pakkaukseen saa tehdä merkinnän vähäsuolainen tai kevyesti suolattu tai muun vastaavan merkinnän, jos elintarvikkeen suolapitoisuus \(natriumkloridi\) on:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** voissa enintään 1,0 painoprosenttia;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** juustossa enintään 0,7 painoprosenttia;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** makkarassa ja muussa lihavalmisteessa enintään 1,2 painoprosenttia;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** kalavalmisteessa enintään 1,0 painoprosenttia;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** ruokaleivässä enintään 0,7 painoprosenttia;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** näkkileivässä ja hapankorpussa enintään 1,2 painoprosenttia;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** aamiaismuroissa ja \-hiutaleissa enintään 1,0 painoprosenttia;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** liemessä, keitossa ja kastikkeessa nautintavalmiina enintään 0,5 painoprosenttia; ja

<a id="section-5-subsection-1-paragraph-9"></a>
- **9.** laatikkoruoissa, jauheliha\-, maksa\- ja kalamurekeruoissa enintään 0,5 painoprosenttia\.

<a id="section-5a"></a>
### 5 a § Ruokasuolan korostaminen

<a id="section-5a-subsection-1"></a>
#### \(1\)

Jos elintarvikkeen pakkauksessa on 4 tai 5 §:ssä tarkoitettu merkintä tai muu ruokasuolan korostamista koskeva ilmoitus, on pakkauksessa ilmoitettava ruokasuolan määrä painoprosentteina\.

<a id="section-6"></a>
### 6§ Tiivistetyn tai kuivatun ainesosan ilmoittaminen

<a id="section-6-subsection-1"></a>
#### \(1\)

Ainesosat, jotka on lisätty tiivisteinä tai kuivattuina ja jotka palautuvat ennalleen valmistuksen aikana, voidaan ilmoittaa sen painon mukaisesti, joka niillä oli ennen tiivistämistä tai kuivaamista\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Tiivistetyissä tai kuivatuissa elintarvikkeissa, jotka on tarkoitettu nautittavaksi vedellä alkuperäiseen olomuotoonsa tai väkevyyteensä palautettuna, voidaan ainesosat ilmoittaa siinä järjestyksessä kuin ne ovat nautintavalmiissa valmisteessa\. Pakkauksessa on tällöin ilmoitettava, että kysymyksessä ovat nautintavalmiin tai alkuperäiseen väkevyyteensä palautetun valmisteen ainesosat\.

<a id="section-7"></a>
### 7§ Ainesosina olevien seosten ilmoittaminen

<a id="section-7-subsection-1"></a>
#### \(1\)

Jos kysymyksessä on hedelmä\-, kasvis\-, mauste\- tai yrttisekoitus, jossa mikään ainesosa painoltaan ei ole olennaisesti määräävässä asemassa, nämä ainesosat voidaan ilmoittaa muussakin kuin painon mukaan alenevassa järjestyksessä edellyttäen, että ainesosien ilmoittamisen yhteydessä käytetään sanontaa ''vaihtelevassa suhteessa'' tai muuta vastaavaa ilmaisua\.

<a id="section-8"></a>
### 8 § Ainesosan ilmoittaminen ryhmänimellä

<a id="section-8-subsection-1"></a>
#### \(1\)

Ainesosat, jotka kuuluvat johonkin jäljempänä mainituista ryhmistä, voidaan ilmoittaa käyttäen vain tämän ryhmän nimeä:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** ''kasviöljy'' tai ''eläinöljy'', kaikkien kasviöljyjen, ei kuitenkaan oliiviöljyn, ja eläinöljyjen yleisnimi; jos öljy on kovetettu tulee kovettamisesta mainita ainesosaluettelossa sanalla ''kovetettu'' öljyn nimen tai ryhmänimen yhteydessä;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** ''kasvirasva'' tai ''eläinrasva'', kaikkien kasvirasvojen ja eläinrasvojen yleisnimi; jos rasva on kovetettu tulee kovettamisesta mainita ainesosaluettelossa sanalla ''kovetettu'' rasvan nimen tai ryhmänimen yhteydessä;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** ''jauhot'', kahdesta tai useammasta viljalajista tehtyjen jauhoseosten yleisnimi, jota on täydennettävä luettelemalla seokseen käytetyt viljat painon mukaan alenevassa järjestyksessä;

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** ''tärkkelys'', kaikkien tärkkelysten ja fysikaalisesti tai entsymaattisesti muunnettujen tärkkelysten yleisnimi;

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** ''kala'', kaikkien kalalajien yleisnimi, ellei pakkauksessa korosteta valmistuksessa käytetyn kalan tai käytettyjen kalojen lajia;

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** ''juusto'', kaikkien juustojen ja niiden seosten yleisnimi, ellei pakkauksessa korosteta valmistuksessa käytetyn juuston tai käytettyjen juustojen lajia;

<a id="section-8-subsection-1-paragraph-7"></a>
- **7.** ''mausteet'', kaikkien mausteiden ja niiden seosten yleisnimi, jollei niiden määrä ylitä 2 prosenttia elintarvikkeessa;

<a id="section-8-subsection-1-paragraph-8"></a>
- **8.** ''mausteyrtit'', kaikkien mausteyrttien ja niiden seosten yleisnimi, jollei niiden määrä ylitä 2 prosenttia elintarvikkeessa;

<a id="section-8-subsection-1-paragraph-9"></a>
- **9.** ''purukumin perusmassa'', purukumien perustana käytettyjen kumiainesmassojen yleisnimi;

<a id="section-8-subsection-1-paragraph-10"></a>
- **10.** ''korppujauhot'' kaikkien paistettujen, kuivattujen ja murennettujen viljavalmisteiden yleisnimi;

<a id="section-8-subsection-1-paragraph-11"></a>
- **11.** ''sokeri'', sokerijuurikkaasta ja sokeriruo'osta valmistettujen sakkaroosituotteiden, myös inverttisokerin yleisnimi;

<a id="section-8-subsection-1-paragraph-12"></a>
- **12.** ''glukoosi'', vedettömän glukoosin ja glukoosimonohydraatin yleisnimi;

<a id="section-8-subsection-1-paragraph-13"></a>
- **13.** ''tärkkelyssiirappi'', kaikkien nestemäisten ja kuivien tärkkelyssiirappien yleisnimi;

<a id="section-8-subsection-1-paragraph-14"></a>
- **14.** ''maitoproteiinit'', kaikkien maitoproteiinien \(kaseiinien, kaseinaattien ja heraproteiinien\) ja niiden seosten yleisnimi;

<a id="section-8-subsection-1-paragraph-15"></a>
- **15.** ''kaakaovoi'', puristetun, expellermenetelmällä puristetun ja puhdistetun kaakaovoin yleisnimi;

<a id="section-8-subsection-1-paragraph-16"></a>
- **16.** ''sokerikuorrutetut hedelmät'', kaikkien sokerilla kuorrutettujen tai kyllästettyjen hedelmien yleisnimi, jollei niiden määrä ylitä 10 prosenttia elintarvikkeessa;

<a id="section-8-subsection-1-paragraph-17"></a>
- **17.** ''kasvikset'', kaikkien kasvisten yleisnimi, jollei niiden määrä ylitä 10 prosenttia elintarvikkeessa; kasvikset, jotka voivat aiheuttaa elintarvikkeen käyttäjälle yliherkkyysoireita on kuitenkin ilmoitettava omalla nimellään; ja

<a id="section-8-subsection-1-paragraph-18"></a>
- **18.** ''viini'', kaikkien neuvoston asetuksessa ETY N:o 822/87 määriteltyjen viinityyppien yleisnimi\.

<a id="section-8b"></a>
### 8 b § Pakkauskaasusta ilmoittaminen

<a id="section-8b-subsection-1"></a>
#### \(1\)

Jos elintarvikkeen säilyvyyttä on lisätty elintarvikelisäaineista annetun asetuksen \(521/92\) mukaisesti sallitulla pakkauskaasulla tulee elintarvikkeen pakkaukseen tehdä merkintä "pakattu suojakaasuun"\.

<a id="section-9"></a>
### 9§ Koostetun ainesosan ilmoittaminen

<a id="section-9-subsection-1"></a>
#### \(1\)

Elintarvikkeiden pakkausmerkinnöistä annetun asetuksen 10§:n 2 momentissa tarkoitetun koostetun ainesosan valmistukseen käytetyistä ainesosista ilmoitetaan ainakin seuraavat ainesosat:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** herne, kala, kananmuna, maito, soijapapu ja äyriäinen sekä näistä tehdyt valmisteet;

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** maapähkinät, mantelit ja pähkinät; sekä

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** kaura, ohra, ruis ja vehnä\.

<a id="section-10"></a>
### 10§ Oleelliset ainesosat

<a id="section-10-subsection-1"></a>
#### \(1\)

Ainesosa on elintarvikkeiden pakkausmerkinnöistä annetun asetuksen 12§:ssä tarkoitetulla tavalla oleellinen, jos se on mainitussa pykälässä tarkoitettujen ominaisuuksien suhteen määräävässä asemassa elintarvikkeessa\.

<a id="section-11"></a>
### 11§ Kasvisten, marjojen ja hedelmien sisällön määrän ilmoittaminen

<a id="section-11-subsection-1"></a>
#### \(1\)

Myytäessä tuoreita kasviksia, marjoja tai hedelmiä pakattuna saa verkon, kalvon tai muun vähäisen päällyksen sisällyttää elintarvikkeen sisällön määrään\. Sisällön määrän voi tällöin jättää merkitsemättä pakkaukseen, jos tarvike punnitaan ostohetkellä\.

<a id="section-12"></a>
### 12§ Poikkeukset vähimmäissäilyvyysaikaa koskevista säännöksistä

<a id="section-12-subsection-1"></a>
#### \(1\)

Seuraaviin elintarvikkeisiin ei vaadita ''parasta ennen'' \-merkintää:

<a id="section-12-subsection-1-paragraph-1"></a>
- **1.** sellaiset tuoreet marjat, hedelmät ja kasvikset, joita ei ole kuorittu, pilkottu tai käsitelty muulla vastaavalla tavalla; tämä määräys ei kuitenkaan koske siemeniä, ituja tai muita vastaavia luonnontuotteita;

<a id="section-12-subsection-1-paragraph-2"></a>
- **2.** sellaiset mehut, nektarit ja virvoitusjuomat, jotka on tarkoitettu suurtalouksille ja jotka on pakattu suurempiin kuin viiden litran pakkauksiin;

<a id="section-12-subsection-1-paragraph-3"></a>
- **3.** sellaiset leipomotuotteet ja leipä, jotka ovat ominaisuuksiltaan sellaisia, että ne tavallisesti nautitaan yhden vuorokauden kuluessa;

<a id="section-12-subsection-1-paragraph-4"></a>
- **4.** etikka;

<a id="section-12-subsection-1-paragraph-5"></a>
- **5.** suola ja suolavalmisteet;

<a id="section-12-subsection-1-paragraph-6"></a>
- **6.** sokeri;

<a id="section-12-subsection-1-paragraph-7"></a>
- **7.** sokerimakeiset; ja

<a id="section-12-subsection-1-paragraph-8"></a>
- **8.** purukumit ja muut vastaavat pureskeltavat elintarvikkeet\.

<a id="section-13"></a>
### 13§ Mikrobiologisesti helposti pilaantuvat elintarvikkeet

<a id="section-13-subsection-1"></a>
#### \(1\)

Elintarvikkeiden pakkausmerkinnöistä annetun asetuksen 3§:ssä tarkoitetuiksi mikrobiologisesti helposti pilaantuviksi elintarvikkeiksi katsotaan esimerkiksi seuraavat elintarvikkeet:

<a id="section-13-subsection-1-paragraph-1"></a>
- **1.** maito ja kerma;

<a id="section-13-subsection-1-paragraph-2"></a>
- **2.** kypsyttämätön juusto;

<a id="section-13-subsection-1-paragraph-3"></a>
- **3.** munavalmisteet;

<a id="section-13-subsection-1-paragraph-4"></a>
- **4.** tuore liha, elimet, veri ja tuore plasma;

<a id="section-13-subsection-1-paragraph-5"></a>
- **5.** jauheliha ja muut kypsentämättömät lihavalmisteet;

<a id="section-13-subsection-1-paragraph-6"></a>
- **6.** tuore kala, mäti ja äyriäinen;

<a id="section-13-subsection-1-paragraph-7"></a>
- **7.** tuoresuolattu kala sekä savustettu ja hiillostettu kala; ja

<a id="section-13-subsection-1-paragraph-8"></a>
- **8.** sellaiset ruokaeinekset, jälkiruoat sekä konditoriavalmisteet, joita ei ole lämpökäsitelty\.

<a id="section-14"></a>
### 14§ Pakkausmerkintöjä koskevat helpotukset

<a id="section-14-subsection-1"></a>
#### \(1\)

Pakkausmerkintöjen tekemisestä ovat voimassa seuraavat helpotukset:

<a id="section-14-subsection-1-paragraph-1"></a>
- **1.** pakkauksessa, jonka suurimman pinnan pinta\-ala on vähemmän kuin 10 cm 2 tarvitsee ilmoittaa vain elintarvikkeen nimi ja sisällön määrä sekä vähimmäissäilyvyysaika tai viimeinen käyttöajankohta, jollei 12§:stä muuta johdu;

<a id="section-14-subsection-1-paragraph-2"></a>
- **2.** pakkauksen sisällön määrää ei tarvitse ilmoittaa, jos se on vähemmän kuin 5 g tai 5 ml; tämä määräys ei kuitenkaan koske luonnonmausteita eikä yrttejä;

<a id="section-14-subsection-1-paragraph-3"></a>
- **3.** myyntipaikassa pakatussa elintarvikkeessa tarvitsee ilmoittaa vain elintarvikkeen nimi ja sisällön määrä; jos elintarvikkeen säilyvyys on alle 3 kuukautta tulee siinä lisäksi olla elintarvikkeiden pakkausmerkinnöistä annetun asetuksen 15 tai 16§:n mukainen päiväysmerkintä, jollei 12§:stä muuta johdu;

<a id="section-14-subsection-1-paragraph-4"></a>
- **4.** tuoreita marjoja, hedelmiä tai kasviksia sisältävässä pakkauksessa, jos pakkaus on kokonaan tai osaksi läpinäkyvä, tarvitsee ilmoittaa vain sisällön määrä ottaen huomioon mitä 11§:ssä on määrätty, sekä alkuperämaa tai \-alue, jos alkuperän ilmoittamatta jättäminen voi johtaa ostajaa harhaan;

<a id="section-14-subsection-1-paragraph-5"></a>
- **5.** ammattikoulussa tai muussa vastaavasa oppilaitoksessa oppilastyönä valmistettujen ja siellä myytävien elintarvikkeiden pakkauksiin voidaan jättää tekemättä muut merkinnät kuin elintarvikkeen nimi ja sisällön määrä;

<a id="section-14-subsection-1-paragraph-6"></a>
- **6.** koti\- tai maatilataloudessa valmistettujen ja myyjäisissä tai vastaavissa tilaisuuksissa tilapäisesti myytävien elintarvikkeiden pakkauksiin voidaan jättää tekemättä muut merkinnät kuin elintarvikkeen nimi;

<a id="section-14-subsection-1-paragraph-7"></a>
- **7.** kypsentämättömän kinkun pakkaukseen voidaan jättää tekemättä sisällön määrää koskeva merkintä, edellyttäen, että kinkku punnitaan myyntipaikassa ja sisällön määrä ilmoitetaan kuluttajalle; ja

<a id="section-14-subsection-1-paragraph-8"></a>
- **8.** pakkaukseen ei tarvitse tehdä merkintöjä siltä osin kuin merkinnät ovat selvästi nähtävissä pakkausta avaamatta\.

<a id="section-14-subsection-1-paragraph-9"></a>
- **9.** jos elintarvikkeen ainesosana on käytetty ruokasuolavalmistetta, voidaan elintarvikkeen pakkaukseen jättää merkitsemättä ruokasuolavalmisteessa olevien ruokasuolaa korvaavien lisäaineiden ryhmänimet; ja

<a id="section-14-subsection-1-paragraph-10"></a>
- **10.** suklaamuniin ja muihin vastaaviin suklaasta valmistettuihin koristemakeisiin sekä yksittäin myytäviin suklaakonvehteihin ja suklaapaloihin voidaan jättää tekemättä vähimmäissäilyvyysaikaa ja elintarvike\-erää osoittava merkintä, jos mainittu merkintä on tehty valmisteen ryhmäpakkaukseen\.
