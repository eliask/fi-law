<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Lisäksi ministeriössä on erillinen tiedotusyksikkö\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Puolustusministeriön hallinnon alaisia ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** puolustusvoimat;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** maanpuolustustiedotuksen suunnittelukunta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** maanpuolustuksen tieteellinen neuvottelukunta;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** kutsunta\-asiain keskuslautakunta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kutsuntalautakunnat;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** suomalaiset YK\-rauhanturvaamisorganisaatiot; sekä

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Valtion pukutehdas\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Puolustusministeriön valvontaan kuuluvat valtionenemmistöiset osakeyhtiöt Patruunatehdas Lapua Oy ja Vammas Oy\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Lisäksi ministeriön hallinnonalaan kuuluu puolustusneuvosto\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Keskusosasto käsittelee asiat, jotka koskevat:

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** ministeriön alaisen valtion teollisuuslaitoksen ja ministeriön valvontaan kuuluvien valtionenemmistöisten osakeyhtiöiden hallintoa\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Keskusosaston jakamisesta toimistoihin tai muihin pysyviin toimintayksiköihin määrätään työjärjestyksessä\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Järjestelyosasto käsittelee asiat, jotka koskevat:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** puolustushallinnon toimintojen taloudellisuuden ja tarkoituksenmukaisuuden kehittämistä;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** hallinnon ja toimintojen rationalisointia ja standardointia;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** hallinnonalan organisaatiota;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** tietohallintoa;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** hallinnonalan teknillistä tarkastustoimintaa;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** virkoihin ja tehtäviin liittyvää tulo\- ja menoarvion valmistelua sekä hallinnonalan henkilöstön kehittämistä ja henkilöstökoulutusta;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** hallinnonalan henkilöstön palvelussuhteita ja niiden ehtoja sekä muita hallinnonalan yleisiä henkilöstöhallinnollisia kysymyksiä;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** hallinnonalan työehtosopimuksia;

<a id="section-5-subsection-1-paragraph-9"></a>
- **9.** hallinnonalan työsuojelua ja sosiaalitoimintaa sekä terveydenhuoltoa; sekä

<a id="section-5-subsection-1-paragraph-10"></a>
- **10.** ministeriön sisäisten hallinto\- ja talousasioiden hoitoa\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Järjestelyosaston jakamisesta toimistoihin tai muihin pysyviin toimintayksiköihin määrätään työjärjestyksessä\.

<a id="section-9"></a>
### 9 §

#### \(1\)

Ministeriössä on:

- **1.** kansliapäällikkö,

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** sotilasasiainosaston osastopäällikkö,

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** järjestelyosaston ja talousosaston osastopäälliköt, joilla on puolustusasiainneuvoksen arvonimi,

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** rakennusosaston osastopäällikkönä toimiva rakennusneuvos,

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksia, toimistopäällikköinä,

<a id="section-9-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköitä,

<a id="section-9-subsection-1-paragraph-8"></a>
- **8.** vanhempia ja nuorempia hallitussihteereitä,

<a id="section-9-subsection-1-paragraph-9"></a>
- **9.** vanhempia ja nuorempia toimistoesiupseereita sekä vanhempia toimistoupseereita,

<a id="section-9-subsection-1-paragraph-10"></a>
- **10.** arkkitehti, maanmittausinsinööri ja insinöörejä,

<a id="section-9-subsection-1-paragraph-11"></a>
- **11.** metsänhoitaja, aluemetsänhoitajia ja metsätalousinsinööri,

<a id="section-9-subsection-1-paragraph-12"></a>
- **12.** neuvotteleva virkamies, pääsihteeri ja yleissihteeri,

- **13.** koulutuspäällikkö ja tiedotuspäällikkö,

<a id="section-9-subsection-1-paragraph-14"></a>
- **14.** ylitarkastajia, taloustarkastajia ja tarkastajia,

<a id="section-9-subsection-1-paragraph-15"></a>
- **15.** erikoistutkija ja esittelijöitä,

<a id="section-9-subsection-1-paragraph-16"></a>
- **16.** kamreereita ja apulaiskamreereita,

<a id="section-9-subsection-1-paragraph-17"></a>
- **17.** suunnittelusihteeri, henkilöstösihteeri, laskentasihteeri ja osastosihteereitä,

<a id="section-9-subsection-1-paragraph-18"></a>
- **18.** maanmittausteknikko ja agrologi,

<a id="section-9-subsection-1-paragraph-19"></a>
- **19.** sotilaspalotoimen tarkastaja,

<a id="section-9-subsection-1-paragraph-20"></a>
- **20.** ministerin sihteeri, hankintasihteeri ja sihteereitä,

<a id="section-9-subsection-1-paragraph-21"></a>
- **21.** notaari ja kirjaajia,

<a id="section-9-subsection-1-paragraph-22"></a>
- **22.** arkistonhoitaja, pääkirjanpitäjä, kartoittaja, tekstinkäsittelijöitä, piirtäjiä, toimistosihteereitä, konekirjoittaja ja toimistovirkailijoita, sekä

<a id="section-9-subsection-1-paragraph-23"></a>
- **23.** ylivirastomestari ja virastomestari\.

<a id="section-10"></a>
### 10 §

<a id="section-10-subsection-1"></a>
#### \(1\)

Lisäksi vaaditaan erityisenä kelpoisuusvaatimuksena:

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** talousosaston toimistopäälliköltä, taloustarkastajalta, tarkastajalta ja laskentasihteeriltä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyyttä tiliviraston tehtäviin;

<a id="section-10-subsection-1-paragraph-15"></a>
- **15.** erikoistutkijalta ja koulutuspäälliköltä virkaan soveltuva ylempi korkeakoulututkinto;

<a id="section-10-subsection-1-paragraph-17"></a>
- **17.** tiedotuspäälliköltä, suunnittelusihteeriltä, henkilöstösihteeriltä, osastosihteeriltä ja kamreerilta virkaan soveltuva korkeakoulututkinto sekä kamreerilta lisäksi valtion maksuliikkeen ja kirjanpidon tuntemus;

<a id="section-17"></a>
### 17 §

<a id="section-17-subsection-1"></a>
#### \(1\)

Yhteistoiminnassa ministeriön ja henkilöstön välillä noudatetaan, mitä yhteistoiminnasta valtion virastoissa ja laitoksissa annetussa laissa \(651/88\) säädetään ja sen nojalla tehdyissä sopimuksissa määrätään\.

### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Muista kuin 22§:ssä tarkoitetuista ministeriössä päätettävistä asioista ratkaisee:

<a id="section-23-subsection-1-paragraph-2"></a>
- **2.** sotilasasiainosaston osastopäällikkö asiat, jotka koskevat:

<a id="section-23-subsection-1-paragraph-2a"></a>
- **2a.** järjestelyosaston osastopäällikkö asiat, jotka koskevat:

<a id="section-28"></a>
### 28 §

<a id="section-28-subsection-1"></a>
#### \(1\)

Virkavapautta, johon virkamiehellä on oikeus lain tai asetuksen taikka valtion virkaehtosopimuslain mukaisen virkaehtosopimuksen nojalla, sekä tätä virkavapautta vastaavan vapautuksen työsopimussuhteiselle henkilöstölle myöntää järjestelyosaston päällikkö\.

<a id="section-28-subsection-2"></a>
#### \(2\)

Muuta kuin 1 momentissa tarkoitettua virkavapautta tai vastaavaa vapautusta myöntää:

<a id="section-28-subsection-2-paragraph-1"></a>
- **1.** tasavallan presidentin nimittämälle virkamiehelle enintään yhdeksi vuodeksi ministeri ja yli yhdeksi vuodeksi valtioneuvosto;

<a id="section-28-subsection-2-paragraph-2"></a>
- **2.** valtioneuvoston nimittämälle virkamiehelle ministeri; sekä

<a id="section-28-subsection-2-paragraph-3"></a>
- **3.** muulle henkilöstölle kansliapäällikkö\.

<a id="section-28-subsection-3"></a>
#### \(3\)

Viran väliaikaisen hoitajan ottamisesta avoinna olevaan virkaan ja viran hoitamisesta virkavapauden aikana päättää se viranomainen tai virkamies, joka 2 momentin mukaan myöntää siitä virkavapauden, 11§:n 1 momentissa tarkoitettujen virkamiesten osalta kuitenkin järjestelyosaston päällikkö\.
