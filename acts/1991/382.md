<a id="section-1"></a>
### 1§ Tehtävät

<a id="section-1-subsection-1"></a>
#### \(1\)

Sen lisäksi, mitä valtioneuvoston kanslian tehtävistä valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta annetussa laissa \(78/22\) ja valtioneuvoston ohjesäännössä \(995/43\) taikka muualla säädetään, valtioneuvoston kanslia käsittelee asiat, jotka koskevat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** valtioneuvoston ja pääministerin tehtäviä tukevien toiminta\- ja informaatiojärjestelmien ylläpitoa ja kehittämistä;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** valtioneuvoston tiedotustoimintaa ja eri ministeriöissä tapahtuvan ulkoisen tiedotustoiminnan avustamista, kehittämistä ja yhteensovittamista;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** valtionhallinnon ulkoisen tiedotustoiminnan yleistä kehittämistä ja koordinointia;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** hallinnon nimikkeitä ja sanastoja;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** valtioneuvoston edustus\- ja virkahuoneistoja;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** valtioneuvoston kuljetuspalveluja\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Valtioneuvoston kanslian yhteydessä on valtioneuvoston arkisto\.

<a id="section-2"></a>
### 2§ Organisaatio

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtioneuvoston kanslian organisaatiosta määrätään valtioneuvoston kanslian työjärjestyksessä, jonka pääministeri vahvistaa\.

<a id="section-3"></a>
### 3§ Virkamiehet

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvoston kansliassa on valtiosihteeri, joka nimitetään enintään pääministerin toimikaudeksi, sekä alivaltiosihteeri ja muita vakinaisia virkamiehiä\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Valtioneuvoston kansliassa on lisäksi pääministerin toimikaudekseen ottamia avustavia tilapäisiä virkamiehiä\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Valtioneuvoston kansliassa on myös valtioneuvoston turvallisuuspäällikkö, jonka puolustusvoimat on pääministerin pyynnöstä komentanut tehtävään\. Turvallisuuspäällikkö toimii kansliassa esittelijänä toimialaansa kuuluvissa asioissa\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Valtioneuvoston kansliaan voidaan ottaa myös muita tilapäisiä virkamiehiä ja työsopimussuhteista henkilöstöä\.

<a id="section-4"></a>
### 4§ Virkamiesten kelpoisuusvaatimukset

<a id="section-4-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena on:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** valtiosihteerillä hyvä perehtyneisyys julkishallintoon ja yhteiskunnan edunvalvontaorganisaatioiden tuntemus;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** alivaltiosihteerillä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** hallitusneuvoksella ja hallitussihteerillä, mitä valtioneuvoston ohjesäännössä säädetään;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** kehittämispäälliköllä ylempi korkeakoulututkinto sekä hyvä perehtyneisyys viran tehtäväalueeseen;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** tiedotuspäälliköllä ja apulaistiedotuspäälliköllä ylempi korkeakoulututkinto sekä laaja kokemus tiedotustoiminnasta taikka pitkäaikainen ja laaja kokemus tiedotustoiminnasta sekä perehtyneisyys viran tehtäväalueeseen;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** käännöstoimintaa johtavalla toimistopäälliköllä oikeustieteen kandidaatin tutkinto, apulaistoimistopäälliköllä ja ylikielenkääntäjällä ylempi korkeakoulututkinto, kuitenkin vähintään yhdellä apulaistoimistopäälliköllä oikeustieteen kandidaatin tutkinto, sekä näillä jokaisella molempien kotimaisten kielten täydellinen hallitseminen;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** arkistopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto, valtionarkiston ylempi arkistotutkinto tai sitä vastaava koulutus sekä perehtyneisyys julkiseen hallintoon ja arkistotoimeen;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** kielenkääntäjällä korkeakoulututkinto tai kieli\-instituutissa suoritettu tutkinto sekä molempien kotimaisten kielten täydellinen hallitseminen;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** muilla virkamiehillä virkaan soveltuva koulutus sekä sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="section-5"></a>
### 5§ Virkojen täyttäminen

<a id="section-5-subsection-1"></a>
#### \(1\)

Valtiosihteerin, alivaltiosihteerin, hallitusneuvoksen, toimistopäällikön ja hallitussihteerin nimittämisestä on voimassa, mitä valtioneuvoston ohjesäännössä säädetään\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Pääministeri ottaa pääministeriä avustavat virkamiehet toimikaudekseen tehtäviä haettavaksi julistamatta\.

<a id="section-5-subsection-3"></a>
#### \(3\)

Ministerin erityisavustajan ottaa pääministeri asianomaisen valtioneuvoston jäsenen esityksestä tämän toimikauden ajaksi tehtävää haettavaksi julistamatta\.

<a id="section-5-subsection-4"></a>
#### \(4\)

Muun henkilökunnan nimittää tai ottaa valtioneuvoston kanslia\.

<a id="section-6"></a>
### 6§

<a id="section-6-subsection-1"></a>
#### \(1\)

Pääministeri nimittää tai ottaa 5§:n 4 momentissa tarkoitetun virkamiehen, jonka palkkaus on vähintään A 22 palkkausluokan mukainen\. Alivaltiosihteeri nimittää tai ottaa palkkausluokkiin A 21\-A 15 sijoitetut virkamiehet\. Muut virkamiehet nimittää tai ottaa alivaltiosihteeri tai, sen mukaan kuin työjärjestyksessä määrätään, hallitusneuvos taikka hallinnollisia tehtäviä hoitamaan määrätty vanhempi hallitussihteeri\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Virkamiehelle annettavan todistuksen virkamiehen irtisanoutumisesta ja virkasuhteen päättymisestä antaa alivaltiosihteeri\.

<a id="section-7"></a>
### 7§ Virkavapaus

<a id="section-7-subsection-1"></a>
#### \(1\)

Virkavapauden, johon virkamiehellä on oikeus lain tai virkaehtosopimuksen nojalla, myöntää alivaltiosihteeri tai, sen mukaan kuin työjärjestyksessä määrätään, hallitusneuvos taikka hallinnollisia tehtäviä hoitamaan määrätty vanhempi hallitussihteeri\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Muun kuin 1 momentissa tarkoitetun virkavapauden myöntää:

<a id="section-7-subsection-2-paragraph-1"></a>
- **1.** valtiosihteerille ja alivaltiosihteerille enintään vuodeksi pääministeri ja yli vuodeksi valtioneuvosto;

<a id="section-7-subsection-2-paragraph-2"></a>
- **2.** muulle kuin 1 kohdassa mainitulle tasavallan presidentin nimittämälle virkamiehelle enintään vuodeksi alivaltiosihteeri ja yli vuodeksi valtioneuvosto;

<a id="section-7-subsection-2-paragraph-3"></a>
- **3.** pääministerin nimittämälle virkamiehelle enintään vuodeksi alivaltiosihteeri ja yli vuodeksi pääministeri;

<a id="section-7-subsection-2-paragraph-4"></a>
- **4.** muulle virkamiehelle se, joka on virkamiehen nimittänyt\.

<a id="section-8"></a>
### 8§

<a id="section-8-subsection-1"></a>
#### \(1\)

Virkaan, johon tasavallan presidentti nimittää, ottaa viransijaisen ja viran väliaikaisen hoitajan enintään vuodeksi pääministeri\.

<a id="section-8-subsection-2"></a>
#### \(2\)

Muun viransijaisen tai viran väliaikaisen hoitajan ottamisesta on voimassa, jollei valtioneuvoston ohjesäännöstä muuta johdu, mitä 6§:ssä vakinaisen virkamiehen nimittämisestä säädetään\.

<a id="section-9"></a>
### 9§

<a id="section-9-subsection-1"></a>
#### \(1\)

Mitä 6\-8 §:ssä säädetään virasta tai virkamiehestä, noudatetaan soveltuvin osin myös työsopimussuhteessa olevaan henkilöön\.

<a id="section-10"></a>
### 10§ Virkamiesten tehtävät

<a id="section-10-subsection-1"></a>
#### \(1\)

Valtioneuvoston kanslian kansliapäällikkönä on valtiosihteeri\.

<a id="section-10-subsection-2"></a>
#### \(2\)

Valtiosihteerin tehtävänä on sen lisäksi, mitä valtioneuvoston ohjesäännössä säädetään:

<a id="section-10-subsection-2-paragraph-1"></a>
- **1.** pääministerin avustajana käsitellä ne asiat, jotka pääministeri niiden laadun ja tärkeyden takia hänelle antaa;

<a id="section-10-subsection-2-paragraph-2"></a>
- **2.** edistää ja seurata hallitusohjelman toteuttamista;

<a id="section-10-subsection-2-paragraph-3"></a>
- **3.** ylläpitää yhteyksiä eduskuntaan, ministeriöihin ja etujärjestöihin;

<a id="section-10-subsection-2-paragraph-4"></a>
- **4.** osallistua kauaskantoisten tai muutoin tärkeiden ratkaisujen suunnittelemiseen ja toteuttamiseen;

<a id="section-10-subsection-2-paragraph-5"></a>
- **5.** johtaa pääministerin apuna 3§:n 2 momentissa tarkoitettujen virkamiesten toimintaa;

<a id="section-10-subsection-2-paragraph-6"></a>
- **6.** edistää ministeriöiden välistä yhteistyötä\.

<a id="section-11"></a>
### 11§

<a id="section-11-subsection-1"></a>
#### \(1\)

Alivaltiosihteerin tehtävänä on:

<a id="section-11-subsection-1-paragraph-1"></a>
- **1.** johtaa valtioneuvoston kanslian toimintaa ja huolehtia, että sen tehtävät hoidetaan tuloksekkaasti;

<a id="section-11-subsection-1-paragraph-2"></a>
- **2.** vastata valtioneuvoston toimintajärjestelmien ja tietohallinnon yhdenmukaisuudesta, ylläpidosta ja kehittämisestä:

<a id="section-11-subsection-1-paragraph-3"></a>
- **3.** johtaa ja kehittää valtioneuvoston kanslian henkilöstöhallintoa ja muuta sisäistä hallintoa;

<a id="section-11-subsection-1-paragraph-4"></a>
- **4.** käsitellä valtioneuvoston kanslian tulo\- ja menoarvioehdotusta, toiminta\- ja taloussuunnitelmaa sekä työjärjestystä\.

<a id="section-12"></a>
### 12§

<a id="section-12-subsection-1"></a>
#### \(1\)

Valtiosihteerin ja alivaltiosihteerin tulee seurata kanslian toimialalla kotimaassa ja ulkomailla tapahtuvaa kehitystä sekä tehdä tarpeellisia aloitteita lainsäädännöllisiksi ja muiksi uudistuksiksi\.

<a id="section-13"></a>
### 13§ Asiain ratkaiseminen

<a id="section-13-subsection-1"></a>
#### \(1\)

Valtiosihteerin oikeudesta ratkaista valtioneuvoston kansliassa päätettäviä asioita on voimassa, mitä valtioneuvoston ohjesäännössä säädetään, mikäli tästä asetuksesta ei muuta johdu\.

<a id="section-14"></a>
### 14§

<a id="section-14-subsection-1"></a>
#### \(1\)

Alivaltiosihteeri ratkaisee, jollei valtioneuvoston ohjesäännön 32§:stä muuta johdu, asiat, jotka koskevat:

<a id="section-14-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista valtioneuvoston kanslian toimialaan kuuluvissa asioissa;

<a id="section-14-subsection-1-paragraph-2"></a>
- **2.** valtioneuvoston kanslian sisäistä järjestystä;

<a id="section-14-subsection-1-paragraph-3"></a>
- **3.** valtioneuvoston kanslian hallinnonalalle osoitettujen määrärahojen yleistä käyttösuunnitelmaa;

<a id="section-14-subsection-1-paragraph-4"></a>
- **4.** merkittäviä hankintoja ja sopimuksia;

<a id="section-14-subsection-1-paragraph-5"></a>
- **5.** vuosilomajärjestystä;

<a id="section-14-subsection-1-paragraph-6"></a>
- **6.** kertaluonteisten palkkioiden sekä hyväksyttyjen perusteiden mukaisten palkkausten vahvistamista\.

<a id="section-15"></a>
### 15§

<a id="section-15-subsection-1"></a>
#### \(1\)

Alivaltiosihteeri tai, sen mukaan kuin työjärjestyksessä määrätään, hallitusneuvos taikka hallinnollisia tehtäviä hoitamaan määrätty vanhempi hallitussihteeri ratkaisee asiat, jotka koskevat:

<a id="section-15-subsection-1-paragraph-1"></a>
- **1.** valtioneuvoston jäsenten, valtioneuvoston kanslian virkamiesten ja ministerien erityisavustajien virkamatkoista suoritettavien matkakustannusten korvausten maksattamista sekä lupaa oman auton käyttämiseen virkamatkoilla;

<a id="section-15-subsection-1-paragraph-2"></a>
- **2.** tasavallan presidentin esittelyjen ja valtioneuvoston yleisistuntojen pöytäkirjojen pitämistä;

<a id="section-15-subsection-1-paragraph-3"></a>
- **3.** kirjaamista ja arkistointia;

<a id="section-15-subsection-1-paragraph-4"></a>
- **4.** yleisten asiakirjain julkisuudesta annetun lain \(83/51\) 20§:n 2 momentissa tarkoitetun luvan antamista;

<a id="section-15-subsection-1-paragraph-5"></a>
- **5.** valtioneuvoston kanslian sisäistä toimintaa varten osoitettujen varojen käyttämistä ja niitä koskevien laskujen hyväksymistä;

<a id="section-15-subsection-1-paragraph-6"></a>
- **6.** ikälisiä;

<a id="section-15-subsection-1-paragraph-7"></a>
- **7.** määräajan jälkeen esitettyjen matkalaskujen maksamista;

<a id="section-15-subsection-1-paragraph-8"></a>
- **8.** huonetilojen hankkimista, vuokraamista ja hoitamista;

<a id="section-15-subsection-1-paragraph-9"></a>
- **9.** omaisuuden poistamista ja tileistä poistoa;

<a id="section-15-subsection-1-paragraph-10"></a>
- **10.** komiteanmietintöjen ja muiden valtioneuvoston kanslian julkaisujen painattamista, monistamista ja jakelua;

<a id="section-15-subsection-1-paragraph-11"></a>
- **11.** lomakkeiden ja asiakirjojen kaavojen samoin kuin sinettien ja leimojen vahvistamista\.

<a id="section-16"></a>
### 16§

<a id="section-16-subsection-1"></a>
#### \(1\)

Valtioneuvoston kanslian sisäistä toimintaa varten käytettävissä olevien määrärahojen jakoa toimintayksiköiden käyttöön koskevat asiat ratkaisee alivaltiosihteeri\.

<a id="section-16-subsection-2"></a>
#### \(2\)

Toimintayksiköiden käytettäväksi osoitettujen määrärahojen käyttöä koskevat asiat ratkaisee asianomaisen toimintayksikön esimies\.

<a id="section-16-subsection-3"></a>
#### \(3\)

Menojen maksamisesta ja materiaalitoiminnoista määrätään tarkemmin valtioneuvoston kanslian tiliohjesäännössä ja sen nojalla annetuissa määräyksissä\.

<a id="section-17"></a>
### 17§ Erinäisiä säännöksiä

<a id="section-17-subsection-1"></a>
#### \(1\)

Tasavallan presidentin koko valtioneuvostoa koskevan päätöksen varmentaa valtiosihteeri tai hänen estyneenä ollessaan alivaltiosihteeri\.

<a id="section-18"></a>
### 18§

<a id="section-18-subsection-1"></a>
#### \(1\)

Yhteistoiminnassa valtioneuvoston kanslian ja henkilöstön välillä noudatetaan, mitä yhteistoiminnasta valtion virastoissa ja laitoksissa annetussa laissa \(651/88\) säädetään ja sen nojalla tehdyissä sopimuksissa määrätään\.

<a id="section-19"></a>
### 19§

<a id="section-19-subsection-1"></a>
#### \(1\)

Valtiosihteerin ollessa estyneenä virkaansa hoitamasta tai vuosilomalla toimii hänen sijaisenaan alivaltiosihteeri tai hänenkin ollessa estyneenä pääministerin määräämä muu virkamies\. Alivaltiosihteerin ollessa estyneenä virkaansa hoitamasta tai vuosilomalla toimii hänen sijaisenaan pääministerin määräämä virkamies\. Muissa tapauksissa alivaltiosihteeri määrää tehtävien hoidosta virkamiehen ollessa estyneenä virkaansa hoitamasta tai vuosilomalla\.

<a id="section-20"></a>
### 20§

<a id="section-20-subsection-1"></a>
#### \(1\)

Jollei tässä asetuksessa toisin säädetä, sovelletaan valtioneuvoston ohjesääntöä\.

<a id="section-21"></a>
### 21§

<a id="section-21-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1991\.

<a id="section-21-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan valtioneuvoston kansliasta 26 päivänä tammikuuta 1990 annettu asetus \(88/90\)\.
