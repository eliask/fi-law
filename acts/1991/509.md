<a id="section-1"></a>
### 1 § Lain soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä lakia sovelletaan ammattikasvatushallituksen alaisiin ammatillisiin oppilaitoksiin, joita ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ammattioppilaitokset;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** hotelli\- ja ravintolaoppilaitokset;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kauppaoppilaitokset;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** koti\- ja laitostalousoppilaitokset;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** käsi\- ja taideteollisuusoppilaitokset;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** maatalousalan oppilaitokset;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** merenkulkuoppilaitokset;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** metsä\- ja puutalousoppilaitokset;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** sosiaalialan oppilaitokset;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** taide\- ja viestintäkulttuurioppilaitokset;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** teknilliset oppilaitokset;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** terveydenhuolto\-oppilaitokset;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** ammatilliset erikoisoppilaitokset; sekä

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** ammatilliset erityisoppilaitokset\.
