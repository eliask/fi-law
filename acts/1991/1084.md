## 46 luku Säännöstelyrikoksista ja salakuljetuksesta

<a id="chapter-46-section-1"></a>
### 1 § Säännöstelyrikos

<a id="chapter-46-section-1-subsection-1"></a>
#### \(1\)

Joka rikkoo tai yrittää rikkoa

<a id="chapter-46-section-1-subsection-1-paragraph-1"></a>
- **1.** eräiden Suomelle Yhdistyneiden Kansakuntien jäsenenä kuuluvien velvoitusten täyttämisestä annetussa laissa \(659/67\),

<a id="chapter-46-section-1-subsection-1-paragraph-2"></a>
- **2.** maan ulkomaankaupan ja taloudellisen kasvun turvaamisesta annetussa laissa \(157/74\),

<a id="chapter-46-section-1-subsection-1-paragraph-3"></a>
- **3.** valuuttalaissa \(954/85\),

<a id="chapter-46-section-1-subsection-1-paragraph-4"></a>
- **4.** eräistä Etelä\-Afrikkaan kohdistuvista toimenpiteistä annetussa laissa \(1104/85\),

<a id="chapter-46-section-1-subsection-1-paragraph-5"></a>
- **5.** hintasulusta annetussa laissa \(717/88\) tai

<a id="chapter-46-section-1-subsection-1-paragraph-6"></a>
- **6.** valmiuslaissa \(1080/91\)

<a id="chapter-46-section-1-subsection-2"></a>
#### \(2\)

säädettyä tai viranomaisen näiden lakien nojalla antamaa säännöstelymääräystä, on tuomittava säännöstelyrikoksesta sakkoon tai vankeuteen enintään kahdeksi vuodeksi\.
