# Korkeimman oikeuden päätös hovioikeuksien työjärjestyksestä annetun korkeimman oikeuden päätöksen muuttamisesta

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Hallintojaostossa käsitellään ne oikeushallintoja talousasiat, jotka eivät tämän työjärjestyksen mukaan kuulu täysistunnon tai hovioikeuden virkamiehen käsiteltäviksi\.

<a id="section-26"></a>
### 26 §

<a id="section-26-subsection-1"></a>
#### \(1\)

Sihteerin tulee sen lisäksi, mitä hänelle edellä sanotun mukaan kuuluu:

<a id="section-26-subsection-1-paragraph-1"></a>
- **1.** huolehtia täysistunnossa ja hallintojaostossa esittelemissään oikeushallintoja talousasioissa laadittavien toimituskirjojen, kuulutusten ja kirjeiden lähettämisestä sekä muista asian vaatimista toimenpiteistä,

<a id="section-26-subsection-1-paragraph-2"></a>
- **2.** esitellä presidentille ne asiat, jotka on hänen ratkaistavikseen määrätty, sekä varmentaa niistä mahdollisesti annettavat toimituskirjat,

<a id="section-26-subsection-1-paragraph-3"></a>
- **3.** huolehtia jäsenten esittelemissä asioissa laadittavien toimituskirjojen antamisesta ja kirjeiden lähettämisestä sekä asiasta aiheutuvista muista tehtävistä,

<a id="section-26-subsection-1-paragraph-4"></a>
- **4.** hovioikeuden kanslian päällikkönä valvoa kanslian ja kirjaamon henkilökunnan sekä hovioikeuden muiden toimihenkilöiden työskentelyä,

<a id="section-26-subsection-1-paragraph-5"></a>
- **5.** valmistaa ehdotus hovioikeuden taloussuunnitelmaksi sekä tulo\- ja menoarvioksi,

<a id="section-26-subsection-1-paragraph-6"></a>
- **6.** valvoa palkkalaskentaa ja henkilöstöilmoitusten laatimista, huolehtia maksuliikkeestä ja laskentatoimesta sekä hyväksyä menot, ei kuitenkaan käyttövaroista suoritettavien maksujen osalta,

<a id="section-26-subsection-1-paragraph-7"></a>
- **7.** valvoa kirjaston, arkiston ja kaluston hoitamista sekä oikeustapauskortiston pitämistä,

<a id="section-26-subsection-1-paragraph-8"></a>
- **8.** ratkaista alkuperäisen asiakirjan takaisin antamista hovioikeudesta koskevat anomukset,

<a id="section-26-subsection-1-paragraph-9"></a>
- **9.** ratkaista ikälisät sekä muistutusten mukaiset palkkausluokkien tarkistukset,

<a id="section-26-subsection-1-paragraph-10"></a>
- **10.** valvoa, että tilastot ja luettelot sekä hovioikeudesta annettavat muutkin tiedot asianmukaisesti ja määräajassa lähetetään, sekä

<a id="section-26-subsection-1-paragraph-11"></a>
- **11.** suorittaa ne muut tehtävät, jotka presidentti määrää\.

<a id="section-28"></a>
### 28 §

<a id="section-28-subsection-1"></a>
#### \(1\)

Viskaalin tulee hänelle jaetuissa asioissa sen lisäksi, mitä hänelle edellä sanotun mukaan kuuluu:

<a id="section-28-subsection-1-paragraph-1"></a>
- **1.** allekirjoittaa hovioikeuden puolesta annettavat haasteet, kehotukset, pyynnöt, kutsut ja ilmoitukset,

<a id="section-28-subsection-1-paragraph-2"></a>
- **2.** huolehtia toimituskirjojen annettavaksi tai lähetettäväksi toimittamisesta,

<a id="section-28-subsection-1-paragraph-3"></a>
- **3.** todistaa oikeiksi hovioikeuden ratkaisusta sen antamisen yhteydessä lähetettävät jäljennökset,

<a id="section-28-subsection-1-paragraph-4"></a>
- **4.** allekirjoittaa toimituskirjan tai sen jäljennöksen lähettämisestä viran puolesta aiheutuvat kirjeet ja huolehtia niiden lähettämisestä,

<a id="section-28-subsection-1-paragraph-5"></a>
- **5.** valvoa, että sakkoja muihin luetteloihin ja oikeustapauskortistoon tehdään tarpeelliset merkinnät,

<a id="section-28-subsection-1-paragraph-6"></a>
- **6.** allekirjoittaa säädetyt päätös\- ja muut ilmoitukset sekä huolehtia niiden lähetettäväksi toimittamisesta,

<a id="section-28-subsection-1-paragraph-7"></a>
- **7.** huolehtia tarvittavien tilastotietojen antamisesta, sekä

<a id="section-28-subsection-1-paragraph-8"></a>
- **8.** suorittaa ne muut tehtävät, jotka presidentti tai jaoston puheenjohtaja määrää\.

<a id="section-32"></a>
### 32 §

<a id="section-32-subsection-1"></a>
#### \(1\)

Notaarin tulee:

<a id="section-32-subsection-1-paragraph-1"></a>
- **1.** avustaa viskaaleita asioiden valmisteluun liittyvissä tehtävissä,

<a id="section-32-subsection-1-paragraph-2"></a>
- **2.** avustaa tuomioiden ja päätösten antamisesta aiheutuvissa töissä, kuten merkintöjen tekemisessä sekä ilmoitusten ja tilastotietojen laatimisessa ja lähettämisessä,

<a id="section-32-subsection-1-paragraph-3"></a>
- **3.** pitää hallintoasioiden diaaria ja nimikirjaa sekä antaa otteita nimikirjasta, sekä

<a id="section-32-subsection-1-paragraph-4"></a>
- **4.** suorittaa ne muut tehtävät, jotka sihteeri määrää\.

<a id="section-35"></a>
### 35 §

<a id="section-35-subsection-1"></a>
#### \(1\)

Presidentti saa tarvittaessa antaa tästä työjärjestyksestä poikkeavia määräyksiä kanslistin, osastosihteerin ja notaarin tehtävien jaosta sekä hovioikeuden ratkaisun antamiseen liittyvien viskaalin ja notaarin, tai jäsenten esittelemissä asioissa sihteerin ja notaarin tehtävien jaosta\. Presidentti voi työjärjestyksestä poiketen määrätä asian valmisteluun tai ratkaisun antamiseen liittyviä tehtäviä myös muun virkamiehen suoritettavaksi\. Sen lisäksi, mitä muuten on säädetty, hovioikeus saa määrätä millä tavoin hovioikeuden varojen hoitoa on tarkastettava\.
