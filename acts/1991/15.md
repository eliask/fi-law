<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Opintokeskuksen tarkoituksena on opintokerho\-, luento\- ja kurssitoimintaa harjoittamalla tarjota tilaisuuksia suunnitelmalliseen aikuisopiskeluun\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Opintokeskus, joka täyttää säädetyt ehdot, saa valtionapua todellisista ja hyväksyttävistä 3\-7§:ssä luetelluista menoista seuraavasti:

<a id="section-2-subsection-2"></a>
#### \(2\)

2\) 80 prosenttia opintokerhojen ja kurssien ohjaajakoulutuksesta aiheutuvista 4§:ssä tarkoitetuista menoista;

<a id="section-2-subsection-3"></a>
#### \(3\)

4\) 80 prosenttia julkisesta luentotoiminnasta aiheutuvista 6§:ssä tarkoitetuista menoista; ja

<a id="section-2-subsection-4"></a>
#### \(4\)

Siltä osin kuin opintokeskus saa 3\-7§:ssä tarkoitettuihin menoihin muuta kuin tässä laissa säädettyä valtionapua, menoihin ei myönnetä valtionapua tämän lain nojalla\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Opintokeskuksen opintokerho\-, luento\- ja kurssitoiminnan ylläpitämisestä aiheutuviin valtionapuun oikeuttaviin menoihin luetaan:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** tarpeellisen henkilökunnan palkat sekä lakisääteiset palkkauksen perusteella työnantajalle määrätyt maksut, ryhmähenkivakuutusmaksut sekä henkilökunnan tarpeellisesta koulutuksesta aiheutuvat kustannukset;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** henkilökunnan matkakustannukset ja päivärahat;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** tarpeellisten huonetilojen kohtuulliset vuokrat;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** kohtuulliset lämmitys\-, valaistus\-, vesi\- ja käyttövoimakustannukset;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** käsikirjastosta, opetusvälineiden ja kaluston hankkimisesta, vuokraamisesta ja kunnossapidosta sekä irtaimistovakuutuksista aiheutuvat kohtuulliset menot;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** kohtuulliset ilmoitus\-, monentamis\-, posti\- ja puhelinkulut;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** tarpeellisten ulkopuolisten palvelujen hankkimisesta aiheutuvat kohtuulliset kustannukset; ja

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** muut kouluhallituksen hyväksymät tarpeelliset käyttömenot\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Opintokerhojen ja kurssien ohjaajakoulutuksesta aiheutuviin valtionapuun oikeuttaviin menoihin luetaan:

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Opintokerhon valtionapuun oikeuttaviin menoihin luetaan opintokerhon työskentelyn kannalta tarpeelliset ja kohtuulliset menot\.

<a id="section-7"></a>
### 7§

<a id="section-7-subsection-1"></a>
#### \(1\)

Työnantajan henkilöstölleen tilaamasta kurssista aiheutuvia kustannuksia ei pidetä opintokeskuksen valtionapuun oikeuttavina menoina\.

<a id="section-7a"></a>
### 7 a§

<a id="section-7a-subsection-1"></a>
#### \(1\)

Kouluhallituksen tehtävänä on valvoa, että valtionapua ei makseta tarpeettomiksi katsottaviin kustannuksiin\. Tätä varten kouluhallitus voi antaa ohjeita luentopalkkioista, huonetiloista, kalustosta, opetusvälineistä, palvelujen hankkimisesta, ilmoittamisesta, monentamisesta sekä opiskelijoiden majoituksesta ja matkoista\.

<a id="section-7a-subsection-2"></a>
#### \(2\)

Kouluhallitus antaa tarvittaessa tarkemmat määräykset 4, 5 ja 7§:ssä tarkoitettujen ohjaajakoulutuksen, opintokerhojen ja kurssien opiskelijoiden määristä sekä luento\- ja kurssitoiminnan vuotuisista tuntimääristä\.

<a id="section-8a"></a>
### 8 a§

<a id="section-8a-subsection-1"></a>
#### \(1\)

Opintokeskus voi saada valtakunnallisesti merkittävää kokeilua sekä kehittämistehtäviä varten erityistä valtionapua valtion tulo\- ja menoarviossa tarkoitukseen osoitetusta määrärahasta\. Valtionavun saamisen edellytyksenä on, että kouluhallitus on hyväksynyt suunnitelman kokeilua tai kehittämistä varten\.

<a id="section-8a-subsection-2"></a>
#### \(2\)

Kokeilussa voidaan poiketa tämän lain säännöksistä siten kuin asetuksella säädetään ja sen nojalla opetusministeriö tarvittaessa määrää\.

<a id="section-9"></a>
### 9§

<a id="section-9-subsection-1"></a>
#### \(1\)

Opintokeskukselle voidaan myöntää valtion tulo\- ja menoarviossa olevan määrärahan rajoissa valtionapua omien toimitilojen hankkimiseen, perusparannuksiin tai uudelleenjärjestämiseen\.

<a id="section-9-subsection-2"></a>
#### \(2\)

Valtionavun saamiseksi tarpeellisista selvityksistä säädetään asetuksella\.

<a id="section-10"></a>
### 10§

<a id="section-10-subsection-1"></a>
#### \(1\)

Valtionavun saamisen edellytyksenä on lisäksi, että:
Opintokeskuksen perustamiseen myönnetyn luvan muuttamisesta päättää opetusministeriö\.

<a id="section-10-subsection-1-paragraph-1"></a>
- **1.** opintokeskuksella on kouluhallituksen vahvistama ohjesääntö;

<a id="section-10-subsection-1-paragraph-2"></a>
- **2.** opintokeskusta ei ylläpidetä taloudellisen edun tavoittelemiseksi;

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** opintokeskuksen toiminta on järjestetty tehokkaasti ja tarkoituksenmukaisesti; ja

<a id="section-10-subsection-1-paragraph-4"></a>
- **4.** opintokeskus täyttää asetuksella säädettävät muut valtionavun ehdot\.

<a id="section-14"></a>
### 14§

<a id="section-14-subsection-1"></a>
#### \(1\)

Kouluhallitus myöntää tässä laissa tarkoitetun valtionavun\.

<a id="section-14a"></a>
### 14 a§

<a id="section-14a-subsection-1"></a>
#### \(1\)

Kouluhallituksen päätökseen, joka koskee 2\-7, 8 ja 10§:n soveltamista, ei saa hakea muutosta valittamalla\. Kouluhallituksen päätökseen tyytymätön opintokeskuksen ylläpitäjä voi kuitenkin vaatia päätökseen oikaisua\.

<a id="section-14a-subsection-2"></a>
#### \(2\)

Oikaisua on vaadittava kirjallisesti kouluhallitukselta kolmen kuukauden kuluessa päätöksen tiedoksi saamisesta\. Päätökseen, johon voidaan vaatia oikaisua, on liitettävä oikaisuvaatimusosoitus\.

<a id="section-15"></a>
### 15§

<a id="section-15-subsection-1"></a>
#### \(1\)

Jos valtionapua saava opintokeskus ei täytä säädettyjä ehtoja tai jos sen toiminnassa ilmenee epäkohtia, joita ei huomautuksesta huolimatta korjata asetetussa määräajassa, voi kouluhallitus keskeyttää valtionavun antamisen toistaiseksi joko kokonaan tai osaksi\. Jos kouluhallitus katsoo, että valtionavun antaminen on lopetettava, on sen tehtävä siitä esitys opetusministeriölle, joka päättää asiasta\.

<a id="section-15-subsection-2"></a>
#### \(2\)

Jos valtionavun antaminen on keskeytetty tai lopetettu, valtioneuvosto voi peruuttaa opintokeskuksen perustamiseen myönnetyn luvan\. Kouluhallitus voi opintokeskuksen ylläpitäjää kuultuaan saattaa luvan peruuttamista koskevan asian ilman ylläpitäjän hakemustakin valtioneuvoston päätettäväksi\.

<a id="section-15-subsection-3"></a>
#### \(3\)

Jos valtionavun antaminen on lopetettu tai jos opintokeskus on lopettanut toimintansa taikka jos opintokeskuksen valtionavulla hankittua omaisuutta lakataan käyttämästä tämän lain mukaiseen tarkoitukseen, on myönnettyä valtionapua vastaava osuus omaisuuden käyvästä arvosta palautettava valtiolle, jollei opetusministeriö erityisestä syystä toisin päätä\.
