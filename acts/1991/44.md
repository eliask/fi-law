# Asetus sisäasiainministeriön ja liikkuvan poliisin eräiden virkojen perustamisesta ja lakkauttamisesta sekä sisäasiainministeriön eräiden virkojen nimien muuttamisesta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan ja lakkautetaan jäljempänä mainitut sopimuspalkkaiset virat sekä muutetaan eduskunnan suostumuksella jäljempänä mainittujen virkojen nimet\.

<a id="section-2"></a>
### 2§ Sisäasiainministeriö

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** kaksi S 31 palkkausluokkaan kuuluvaa osastopäällikön virkaa;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yksi S 31 palkkausluokkaan kuuluva neuvottelevan virkamiehen virka;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** yksi S 30 palkkausluokkaan kuuluva poliisiylitarkastajan virka;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** kaksi S 29 palkkausluokkaan kuuluvaa poliisiylitarkastajan virkaa;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** yksi S 29 palkkausluokkaan kuuluva lainsäädäntöneuvoksen virka; sekä

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** yksi S 28 palkkausluokkaan kuuluva teknisen johtajan virka\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Lakkautetaan:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Yleinen osasto

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Lääni\- ja kuntaosasto

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** Aluepoliittinen osasto

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** Poliisiosasto

<a id="section-2-subsection-3"></a>
#### \(3\)

Muutetaan:

<a id="section-2-subsection-3-paragraph-1"></a>
- **1.** yksi S 31 palkkausluokkaan kuuluva osastopäällikön virka samaan palkkausluokkaan kuuluvaksi pelastusylijohtajan, osastopäällikkönä viraksi;

<a id="section-2-subsection-3-paragraph-2"></a>
- **2.** yksi S 29 palkkausluokkaan kuuluva apulaisosastopäällikön virka samaan palkkausluokkaan kuuluvaksi aluekehitysneuvoksen viraksi;

<a id="section-2-subsection-3-paragraph-3"></a>
- **3.** kaksi A 29 palkkausluokkaan kuuluvaa hallitusneuvoksen, toimistopäällikkönä virkaa samaan palkkausluokkaan kuuluviksi hallitusneuvoksen viroiksi;

<a id="section-2-subsection-3-paragraph-4"></a>
- **4.** neljä S 28 palkkausluokkaan kuuluvaa toimistopäällikön virkaa samaan palkkausluokkaan kuuluviksi aluekehitysneuvoksen viroiksi;

<a id="section-2-subsection-3-paragraph-5"></a>
- **5.** yksi S 28 palkkausluokkaan kuuluva toimistopäällikön virka samaan palkkausluokkaan kuuluvaksi talousjohtajan viraksi; sekä

<a id="section-2-subsection-3-paragraph-6"></a>
- **6.** yksi S 28 palkkausluokkaan kuuluva toimistopäällikön virka samaan palkkausluokkaan kuuluvaksi tietohallintopäällikön viraksi\.

<a id="section-3"></a>
### 3§ Liikkuva poliisi

<a id="section-3-subsection-1"></a>
#### \(1\)

Lakkautetaan:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** yksi S 28 palkkausluokkaan kuuluva päällikön virka\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1991\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Tällä asetuksella perustetut poliisiylitarkastajan, lainsäädäntöneuvoksen sekä teknisen johtajan virat saadaan ensimmäisellä kerralla täyttää niitä haettavaksi julistamatta\.

<a id="section-4-subsection-3"></a>
#### \(3\)

Toimenpiteisiin tällä asetuksella perustettavan viran täyttämiseksi saadaan ryhtyä jo ennen sitä ajankohtaa, josta lukien virka on perustettu\.
