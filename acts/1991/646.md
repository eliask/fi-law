# Sisäasiainministeriön päätös kuntajaon muuttamisesta eräiltä osin Maskun ja Nousiaisten kuntien välillä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maskun kunnasta siirretään Nousiaisten kuntaan seuraavat tilat, tilanosa ja alueet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Humikkalan kylästä kokonaan tilat Sarkala 6:11, Erkinpelto 6:51 ja Aulinkallio 6:52;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Kaiturin kylästä kokonaan tilat Metsämäki 1:4 ja Peräpelto 1:5;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Kajalan kylästä kokonaan tila Ketola 1:28;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Kallelan kylästä kokonaan tilat Sarkala II 3:3, Metsämäki II 3:4, Maskunmetsä 4:10, Sarkala III 4:11 ja Kalliokoski II 4:12 sekä tilan Kannisto 4:19 metsäpalsta;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Kelhoisen kylästä kokonaan tila Inkisvuori 1:3;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Kurittulan kylästä kokonaan tila Puistola 7:5;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Lellaisen kylästä kokonaan tila Korpimetsä 1:1;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Syväsalon kylästä kokonaan tilat Puistola III 1:1 ja Äijämäki 1:2; sekä

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** edellä mainittujen tilojen ja tilanosan alueella olevat yleiset alueet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.
