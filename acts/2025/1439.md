### 11 § Itsehoitolääkkeet, joita saa myydä myös muualla kuin apteekissa

<a id="section-11-subsection-1"></a>
#### \(1\)

Itsehoitolääkkeet, jotka kuuluvat seuraaviin anatomis\-terapeuttis\-kemiallisen luokituksen \(ATC\-luokitus\) mukaisiin ATC\-ryhmiin, muodostavat lääkelain 23 d §:ssä tarkoitetun rajatun itsehoitolääkevalikoiman:

<a id="section-11-subsection-1-paragraph-1"></a>
- **1.** A02AD01 tavanomaiset aluminium/kalsium/magnesiumyhdisteet;

<a id="section-11-subsection-1-paragraph-2"></a>
- **2.** A02BX02 sukralfaatti;

<a id="section-11-subsection-1-paragraph-3"></a>
- **3.** A06AC01 ispaghula \(psylliumin siemenet\);

<a id="section-11-subsection-1-paragraph-4"></a>
- **4.** A06AC51 ispaghula, yhdistelmävalmisteet;

<a id="section-11-subsection-1-paragraph-5"></a>
- **5.** A06AD11 laktuloosi;

<a id="section-11-subsection-1-paragraph-6"></a>
- **6.** A06AD15 makrogoli;

<a id="section-11-subsection-1-paragraph-7"></a>
- **7.** A06AD65 makrogoli, yhdistelmävalmisteet;

<a id="section-11-subsection-1-paragraph-8"></a>
- **8.** A11DB B1\-vitamiinin ja B6\- ja/tai B12\-vitamiinin yhdistelmävalmisteet;

<a id="section-11-subsection-1-paragraph-9"></a>
- **9.** A11HA02 pyridoksiini \(B6\-vitamiini\);

<a id="section-11-subsection-1-paragraph-10"></a>
- **10.** B03BA01 syanokobalamiini;

<a id="section-11-subsection-1-paragraph-11"></a>
- **11.** A12AX kalsiumin yhdistelmävalmisteet D\-vitamiinin ja/tai muiden lääkeaineiden kanssa;

<a id="section-11-subsection-1-paragraph-12"></a>
- **12.** A12AA04 kalsiumkarbonaatti;

<a id="section-11-subsection-1-paragraph-13"></a>
- **13.** A11CC01 ergokalsiferoli;

<a id="section-11-subsection-1-paragraph-14"></a>
- **14.** A11CC05 kolekalsiferoli;

<a id="section-11-subsection-1-paragraph-15"></a>
- **15.** B03AA01 ferroglysiinisulfaatti;

<a id="section-11-subsection-1-paragraph-16"></a>
- **16.** B03AB05 rautaoksidipolymaltoosikompleksit;

<a id="section-11-subsection-1-paragraph-17"></a>
- **17.** B03AA07 ferrosulfaatti;

<a id="section-11-subsection-1-paragraph-18"></a>
- **18.** D03AX03 dekspantenoli;

<a id="section-11-subsection-1-paragraph-19"></a>
- **19.** G04BX01 magnesiumhydroksidi;

<a id="section-11-subsection-1-paragraph-20"></a>
- **20.** A12CC04 magnesiumsitraatti;

<a id="section-11-subsection-1-paragraph-21"></a>
- **21.** A12CC30 magnesium \(eri suolojen yhdistelmävalmisteet\) ja

<a id="section-11-subsection-1-paragraph-22"></a>
- **22.** S01XA20 keinokyyneleet ja muut luokittelemattomat valmisteet\.

<a id="section-12"></a>
### 12 §

<a id="section-12-subsection-1"></a>
#### \(1\)

Itsehoitolääkkeiden vähittäismyyntiluvan haltijan tulee täyttää lääkelain 54 h §:ssä säädetyt vaatimukset ja lisäksi:

<a id="section-12-subsection-1-paragraph-1"></a>
- **1.** myydä ja varastoida itsehoitolääkkeet luvassa tarkoitetussa toimipisteessä\. Varastona voidaan käyttää myös toimipisteen välittömässä läheisyydessä sijaitsevaa, luvanhaltijan hallinnoimaa varastotilaa;

<a id="section-12-subsection-1-paragraph-2"></a>
- **2.** järjestää henkilöstölle tarvittaessa lisäperehdytystä ja dokumentoida annettu perehdytys;

<a id="section-12-subsection-1-paragraph-3"></a>
- **3.** antaa henkilöstölle toimintaohjeet itsehoitolääkkeitä koskien ja pidettävä ohjeet ajan tasalla;

<a id="section-12-subsection-1-paragraph-4"></a>
- **4.** varastoida itsehoitolääkkeet niiden valmisteyhteenvetojen mukaisessa lämpötilassa ja olosuhteissa;

<a id="section-12-subsection-1-paragraph-5"></a>
- **5.** hävittää myymättä jääneet itsehoitolääkkeet lääkejätteenä, joka pidetään erillään myyntivarastosta ja

<a id="section-12-subsection-1-paragraph-6"></a>
- **6.** estää asiattomien pääsy myynti\- ja varastotiloihin ja lääkejätteisiin\.

<a id="section-12a"></a>
### 12 a §

<a id="section-12a-subsection-1"></a>
#### \(1\)

Itsehoitolääkkeiden vähittäisluvanhaltijan nimeämän vastuuhenkilön tehtävänä on lääkelain 54 i §:ssä säädetyn lisäksi:

<a id="section-12a-subsection-1-paragraph-1"></a>
- **1.** seurata ja dokumentoida säännöllisesti luotettavien välineiden ja laitteistojen avulla, että itsehoitolääkkeitä säilytetään valmistajan edellyttämissä olosuhteissa\. Mikäli seurannassa havaitaan poikkeamia, ryhtyä välittömiin toimiin poikkeamien arvioimiseksi, dokumentoimiseksi ja korjaamiseksi\. Poikkeamatilanteissa vastuuhenkilön on tarvittaessa konsultoitava kyseisen itsehoitolääkevalmisteen myyntiluvanhaltijaa\.

<a id="section-12a-subsection-1-paragraph-2"></a>
- **2.** toimia luvanhaltijan yhteyshenkilönä viranomaisiin nähden itsehoitolääkkeiden tuotevalitus\-, tuotevirhe\- ja lääkeväärennös\- ja takaisinvetotapauksissa ja huolehtia itsehoitolääkkeisiin liittyvien toimenpiteiden toteuttamisesta;

<a id="section-12a-subsection-1-paragraph-3"></a>
- **3.** seurata itsehoitolääkkeiden myyntiä lääkkeiden väärinkäytön ja virheellisen käytön ehkäisemiseksi;

<a id="section-12a-subsection-1-paragraph-4"></a>
- **4.** laatia myytävistä itsehoitolääkkeistä luettelo, johon merkitään lääkevalmisteiden säilytysolosuhteet ja mahdolliset myyntirajoitukset, pidettävä luettelo ajan tasalla ja huolehdittava luettelon noudattamisesta varastoitaessa ja myytäessä itsehoitolääkkeitä;

<a id="section-12a-subsection-1-paragraph-5"></a>
- **5.** tarkastaa toimipiste vuosittain ja varmistua siitä, että itsehoitolääkkeiden myynnissä noudatetaan tätä lakia, sen nojalla annettuja säädöksiä ja kuluttajansuojalakia\. Tarkastuksesta on pidettävä pöytäkirjaa\. Pöytäkirja on säilytettävä viisi vuotta\.
