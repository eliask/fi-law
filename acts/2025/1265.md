# Valtioneuvoston asetus eräiden maa\- ja puutarhatalouden kansallisista tuista annettujen valtioneuvoston asetusten kumoamisesta

- Version: `2026-01-01`

- [2 §](#section-2)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä asetuksella kumotaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** vuodelta 2014 maksettavasta Etelä\-Suomen kansallisesta tuesta annettu valtioneuvoston asetus [\(13/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/13>);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** vuodelta 2014 maksettavasta pohjoisesta tuesta annettu valtioneuvoston asetus [\(14/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/14>);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** vuodelta 2014 maksettavasta sokerijuurikkaan kansallisesta tuesta annettu valtioneuvoston asetus [\(44/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/44>);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** vuodelta 2014 maksettavasta mehiläistalouden kansallisesta pesäkohtaisesta tuesta annettu valtioneuvoston asetus [\(240/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/240>);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** vuodelta 2013 maksettavasta sokerijuurikkaan kuljetustuesta annettu valtioneuvoston asetus [\(241/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/241>);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** vuodelta 2014 maksettavien kansallisten kasvintuotannon tukien ja kotieläintukien valvonnasta annettu valtioneuvoston asetus [\(297/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/297>);

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** poronhoitovuodelta 2014/2015 maksettavasta eläinkohtaisesta tuesta annettu valtioneuvoston asetus [\(469/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/469>);

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** vuodelta 2014 maksettavasta lihan ja vuodelta 2013 maksettavasta maidon kuljetusavustuksesta sekä eräiden kotieläintalouden palvelujen tuesta vuodelta 2014 annettu valtioneuvoston asetus [\(777/2014\)](<https://www.finlex.fi/fi/lainsaadanto/2014/777>);

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2026\.
