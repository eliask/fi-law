# Opetus\- ja kulttuuriministeriön asetus ammatillisen koulutuksen toiminnanohjauksen kokeilusta

<a id="section-1"></a>
### 1 § Rajattavat tutkinnot

<a id="section-1-subsection-1"></a>
#### \(1\)

Opetus\- ja kulttuuriministeriö päätöksellä ammatillisen koulutuksen kokeilusta annettavaan järjestämislupaan voidaan tehdä seuraavia tutkintoja ja osaamisaloja koskevia rajoituksia:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Energia\-alan ammattitutkinto, voimalaitostekniikan osaamisala

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Energia\-alan erikoisammattitutkinto, voimalaitostekniikan osaamisala

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Kaivosalan perustutkinto, kaivostyön osaamisala

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Kuljetusalan ammattitutkinto, palvelukuljetusten osaamisala, tavarakuljetusten osaamisala, metsäteollisuuden kuljetusten osaamisala ja henkilökuljetusten osaamisala

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Liikunnanohjauksen perustutkinto

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Liikunnan ja valmennuksen ammattitutkinto

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Liikuntapaikka\-alan ammattitutkinto

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Liikuntapaikka\-alan erikoisammattitutkinto

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Lentokoneasennuksen perustutkinto

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Lentoasemapalvelujen ammattitutkinto

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Lentokonetekniikan ammattitutkinto

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** Lentokonetekniikan erikoisammattitutkinto

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** Logistiikan perustutkinto, kuljetuspalvelujen osaamisala ja lentoasemapalvelujen osaamisala

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** Maarakennusalan ammattitutkinto, liikennealueiden ylläpidon osaamisala ja infra\-alan kuljetusten osaamisala

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** Metsäalan perustutkinto, metsäkoneenkuljetuksen osaamisala

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** Metsäalan ammattitutkinto, metsäkoneenkuljetuksen osaamisala

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** Musiikkialan perustutkinto

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** Musiikkituotannon ammattitutkinto

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** Porotalouden ammattitutkinto

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** Rakennusalan perustutkinto, maarakennuskoneenkuljetuksen osaamisala

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** Saamenkäsityöalan ammattitutkinto

<a id="section-1-subsection-1-paragraph-22"></a>
- **22.** Saamenkäsityöalan erikoisammattitutkinto

<a id="section-1-subsection-1-paragraph-23"></a>
- **23.** Talotekniikan ammattitutkinto, kylmäasennuksen osaamisala

<a id="section-1-subsection-1-paragraph-24"></a>
- **24.** Talotekniikan erikoisammattitutkinto, kylmätekniikan osaamisala

<a id="section-1-subsection-1-paragraph-25"></a>
- **25.** Tanssialan perustutkinto

<a id="section-1-subsection-1-paragraph-26"></a>
- **26.** Tieto\- ja kirjastopalvelujen ammattitutkinto, kirjastoautopalvelujen osaamisala

<a id="section-1-subsection-1-paragraph-27"></a>
- **27.** Valmennuksen erikoisammattitutkinto

<a id="section-1-subsection-1-paragraph-28"></a>
- **28.** Ympäristöalan ammattitutkinto, jätteiden ja vaarallisten aineiden kuljetuksen osaamisala
