### 2 § Opetus\- ja kulttuuriministeriön toimialan virastot, laitokset, yhtiöt ja muut toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Opetus\- ja kulttuuriministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yliopistot ja niiden harjoittelukoulut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** ammattikorkeakoulut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Opetushallitus ja sen erillisyksikköinä toimivat ylioppilastutkintolautakunnan kanslia, Kansallinen koulutuksen arviointikeskus ja Jatkuvan oppimisen ja työllisyyden palvelukeskus sekä Opetushallituksen toimialaan kuuluvat valtion oppilaitokset;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** opiskelijoiden oikeusturvalautakunta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Suomen Akatemia;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Kansallisarkisto;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Taide\- ja kulttuurivirasto, taide\- ja kulttuurineuvosto;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Museovirasto;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** kuvaohjelmalautakunta;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Suomen kansallisooppera ja \-baletti;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Suomen Kansallisteatteri;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Kansallisgalleria;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Suomen elokuvasäätiö;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** CSC – Tieteen tietotekniikan keskus Oy;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Hevosopisto Oy\.
