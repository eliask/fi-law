<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Virallisia liputuspäiviä ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** helmikuun 28\. päivä, Kalevalan päivä, suomalaisen kulttuurin päivä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** toukokuun 1\. päivä, vappu, suomalaisen työn päivä;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** toukokuun toinen sunnuntai, äitienpäivä;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** kesäkuun 4\. päivä, puolustusvoimain lippujuhlan päivä;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kesäkuun 20\. päivän ja 26\. päivän välinen lauantai, juhannus, Suomen lipun päivä;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** marraskuun toinen sunnuntai, isänpäivä;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** joulukuun 6\. päivä, itsenäisyyspäivä;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** päivä, jolloin toimitetaan valtiolliset vaalit, aluevaalit, kuntavaalit, Suomesta valittavien Euroopan parlamentin jäsenten vaalit tai neuvoa\-antava kansanäänestys koko maassa;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** päivä, jolloin tasavallan presidentti astuu toimeensa\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Asianomainen ministeriö saa erityistapauksissa määrätä valtion virastojen ja laitosten liputuksesta koko maassa tai yksittäisillä paikkakunnilla muulloin kuin virallisina liputuspäivinä\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ministeriöt saavat tarvittaessa määrätä alaistensa virastojen ja laitosten liputtamisesta muulloin kuin virallisina liputuspäivinä\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Valtion virasto tai laitos saa liputtaa erityisenä merkkipäivänä ja milloin sen sijaintipaikkakunnalla toimeenpannaan yleinen liputus\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Valtion aluksen liputtamisessa on noudatettava kansainvälistä tapaa\.
