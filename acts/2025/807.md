### 10 § Viranomaisten tiedonsaantioikeudet salassapidettävistä tiedoista

<a id="section-10-subsection-1"></a>
#### \(1\)

Seuraavilla viranomaisilla on oikeus saada tehtäviensä hoitamisen kannalta välttämättömät tiedot maksutta salassapitosäännösten estämättä rakennetun ympäristön tietojärjestelmästä:

<a id="section-10-subsection-1-paragraph-1"></a>
- **1.** Digi\- ja väestötietovirasto;

<a id="section-10-subsection-1-paragraph-2"></a>
- **2.** elinvoimakeskukset;

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** Hätäkeskuslaitos;

<a id="section-10-subsection-1-paragraph-4"></a>
- **4.** Lupa\- ja valvontavirasto;

<a id="section-10-subsection-1-paragraph-5"></a>
- **5.** Maanmittauslaitos;

<a id="section-10-subsection-1-paragraph-6"></a>
- **6.** Museovirasto;

<a id="section-10-subsection-1-paragraph-7"></a>
- **7.** museolaissa \(314/2019\) tarkoitetut alueelliset vastuumuseot niiden hoitaessa mainitun lain 7 §:n 1 momentin 2 kohdassa tarkoitettua tehtävää;

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** pelastusviranomaiset;

<a id="section-10-subsection-1-paragraph-9"></a>
- **9.** puolustusministeriö;

<a id="section-10-subsection-1-paragraph-10"></a>
- **10.** Puolustusvoimat;

<a id="section-10-subsection-1-paragraph-11"></a>
- **11.** Ruokavirasto;

<a id="section-10-subsection-1-paragraph-12"></a>
- **12.** Tilastokeskus;

<a id="section-10-subsection-1-paragraph-13"></a>
- **13.** Työllisyys\-, kehittämis\- ja hallintokeskus;

<a id="section-10-subsection-1-paragraph-14"></a>
- **14.** Verohallinto\.
