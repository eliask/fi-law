<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion oikeusaputoimistot, niiden sivutoimistot ja sivuvastaanotot sijaitsevat oikeusapupiirien alueilla seuraavasti:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Oikeusaputoimisto

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Sivutoimisto \(st\)

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Sivuvastaanotto \(sv\)

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Turun oikeusapupiiri

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Vaasan oikeusapupiiri

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Itä\-Suomen oikeusapupiiri

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Helsingin oikeusapupiiri

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kouvolan oikeusapupiiri

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Rovaniemen oikeusapupiiri

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Sivuvastaanoton järjestävä oikeusaputoimisto määrää työjärjestyksessään, miten usein ja millä tavoin sivuvastaanotto järjestetään\. Käyntikertojen tiheyttä harkittaessa on otettava huomioon vastaanottoa käyttävien alueiden asukasmäärä, aikaisempien vuosien kysyntä sekä sivuvastaanotosta aiheutuvat kustannukset\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2008\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Asetuksen täytäntöönpanon edellyttämiin toimiin voidaan ryhtyä ennen asetuksen voimaantuloa\.
