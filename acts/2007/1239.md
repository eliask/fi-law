### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään Ajoneuvohallintokeskuksen maksullisista suoritteista ja niiden maksuperusteista sekä julkisoikeudellisista suoritteista perittävistä kiinteistä maksuista\.

<a id="section-2"></a>
### 2 § Omakustannusarvon mukaiset kiinteämaksuiset julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Ajoneuvohallintokeskus perii omakustannusarvon mukaisen, tämän asetuksen liitteessä määrätyn kiinteän maksun seuraavista suoritteista:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** ajoneuvon, osan, järjestelmän ja erillisen teknisen yksikön tyyppihyväksyntä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** ajoneuvotekniset lausunnot ja luvat;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** liikennetarvikkeiden kauppaan sekä asennus\- ja korjaustoimintaan liittyvät suoritteet;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** autokiinnityssuoritteet;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** ajoneuvojen rekisteröintisuoritteet;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** ajokorttisuoritteet;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** kuljettajaopetukseen ja kuljettajantutkintoihin liittyvät suoritteet ja päätökset;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** vaarallisten aineiden ajolupakoulutukseen ja ajolupiin sekä turvallisuusneuvonantajatutkintoon liittyvät suoritteet ja päätökset;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** todistukset;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** katsastustoiminnan kouluttamiseen liittyvät suoritteet;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** katsastusluvat;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** asiakirjapalvelut;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** piirturikortit;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** kansainväliset kuljetusluvat;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** liikenneyrittäjäsuoritteet;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** kuljettajien ammattipätevyyteen liittyvät suoritteet\.

<a id="section-3"></a>
### 3 § Katsastustoiminnan maksu

<a id="section-3-subsection-1"></a>
#### \(1\)

Ajoneuvohallintokeskus perii katsastusluvan haltijoilta ajoneuvojen katsastusluvista annetun lain [\(1099/1998\) 24 a §:ssä](<https://www.finlex.fi/fi/lainsaadanto/1998/1099#sec_24a>) tarkoitettua katsastustoiminnan maksua kultakin edellisen kuukauden aikana suoritetulta katsastukselta 1,50 euroa\.

<a id="section-4"></a>
### 4 § Omakustannusarvosta poikkeavat kiinteämaksuiset julkisoikeudelliset suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Ajoneuvohallintokeskus perii omakustannusarvoa alemman kiinteän maksun seuraavista suoritteista:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** toimiluvan mukaisen katsastustoiminnan aloittamistarkastus 300 euroa;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** toimiluvan haltijan, kuljettajantutkinnon vastaanottajan tai ajolupakokeen vastaanottajan päätöksestä tehdyn oikaisuvaatimuksen ratkaisu 42 euroa;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** poikkeuksen myöntäminen ajokorttilupaa tai henkilöauton ammattiajolupaa koskevista terveysvaatimuksista 25 euroa;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** suullinen teoriakoe terveysperustein 16 euroa;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** ajoneuvoverolain [\(1281/2003\) 48 §:n](<https://www.finlex.fi/fi/lainsaadanto/2003/1281#chp_8__sec_48>) mukainen ennakkoratkaisu 90 euroa;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** polttoainemaksusta annetun lain [\(1280/2003\) 19 §:n](<https://www.finlex.fi/fi/lainsaadanto/2003/1280#sec_19>) mukainen ennakkoratkaisu 90 euroa;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** autoverolain [\(1482/1994\) 67 §:n](<https://www.finlex.fi/fi/lainsaadanto/1994/1482#chp_10__sec_67>) mukainen ennakkoratkaisu 90 euroa;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** poikkeus ajo\-oikeutta tai ammattiajolupaa koskevista ikävaatimuksista 50 euroa\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Ajoneuvohallintokeskus ei peri eräiden ennakkopäätösten maksuperusteista annetun lain [\(1209/2006\) 2 §:n](<https://www.finlex.fi/fi/lainsaadanto/2006/1209#sec_2>) 2 momentissa tarkoitettua käsittelymaksua\.

<a id="section-4-subsection-3"></a>
#### \(3\)

Ajoneuvohallintokeskus perii omakustannusarvoa korkeamman kiinteän maksun seuraavista suoritteista:

<a id="section-4-subsection-3-paragraph-1"></a>
- **1.** päätös erityistunnuksen myöntämisestä 1 000 euroa;

<a id="section-4-subsection-3-paragraph-2"></a>
- **2.** koenumerotodistus 300 euroa;

<a id="section-4-subsection-3-paragraph-3"></a>
- **3.** poikkeusluvan myöntäminen muualla kuin Euroopan talousalueeseen kuuluvassa valtiossa rekisteröidyn tai käyttöön otetun ajoneuvon suurimmista sallituista mitoista ja massoista 180 euroa\.

<a id="section-5"></a>
### 5 § Muut maksulliset suoritteet

<a id="section-5-subsection-1"></a>
#### \(1\)

Jollei suoritteen maksullisuus määräydy viranomaisten toiminnan julkisuudesta annetun lain [\(621/1999\) 34 §:n](<https://www.finlex.fi/fi/lainsaadanto/1999/621#chp_8__sec_34>) nojalla, Ajoneuvohallintokeskus perii maksut liiketaloudellisilla perusteilla seuraavista suoritteista:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** tietojen luovuttaminen ajoneuvoliikennerekisteristä;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** tiedotustoimintaan kuulumaton koulutus;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** tiedotustoimintaan kuulumattomat painotuotteet;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** toimeksiantoon perustuvat tutkimus\- ja tilauspalvelut;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** valokopiot ja muut jäljennökset;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** asiakirjojen tai muun aineiston lähettäminen, jollei aiheutuvia kustannuksia ole sisällytetty muusta suoritteesta perittävään maksuun\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Viranomaisten toiminnan julkisuudesta annetun lain 34 §:n 2 momentissa tarkoitetusta tiedon esille hakemisesta sekä saman lain 34 §:n 3 momentissa tarkoitettujen kopioiden ja tulosteiden antamisesta perittävistä maksuista päättää Ajoneuvohallintokeskus ottaen huomioon, mitä viranomaisten toiminnan julkisuudesta annetun lain 34 §:ssä säädetään\.

<a id="section-6"></a>
### 6 § Hylkäävistä päätöksistä perittävä maksu

<a id="section-6-subsection-1"></a>
#### \(1\)

Tässä asetuksessa tarkoitettu maksu peritään myös hakemukseen annetusta hylkäävästä päätöksestä\.

<a id="section-7"></a>
### 7 § Voimaantulo

<a id="section-7-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2008 ja on voimassa vuoden 2009 loppuun\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimiin\.
