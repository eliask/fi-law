<a id="section-7"></a>
### 7 § Lausunnon antaminen

<a id="section-7-subsection-1"></a>
#### \(1\)

Työneuvoston tehtävänä on antaa pyynnöstä lausuntoja työaikalain \(605/1996\), vuosilomalain \(162/2005\), työturvallisuuslain \(738/2002\), nuorista työntekijöistä annetun lain \(998/1993\) ja kotitaloustyöntekijäin työsuhteesta annetun lain \(951/1977\) soveltamisesta ja tulkinnasta sekä siitä, onko yritystä pidettävä sellaisena, että siihen sovelletaan yhteistoiminnasta yrityksissä annettua lakia \(334/2007\) tai yhteistoiminnasta suomalaisissa ja yhteisönlaajuisissa yritysryhmissä annettua lakia \(335/2007\)\.

<a id="section-8"></a>
### 8 § Lausunnon pyytäjä ja sen pyytäminen

<a id="section-8-subsection-1"></a>
#### \(1\)

Työneuvoston lausuntoa voi pyytää:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** tuomioistuin;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** työsuojelupiirin työsuojelutoimisto;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** työnantajien tai työntekijöiden keskusjärjestö;

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** valtion työmarkkinapolitiikkaa käsittelevä ministeriö;

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** kirkon sopimusvaltuuskunta;

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** kunnallinen työmarkkinalaitos;

<a id="section-8-subsection-1-paragraph-7"></a>
- **7.** Ahvenanmaan maakunnan hallitus tai Ahvenanmaan maakunnan kunnallinen sopimusvaltuuskunta; taikka

<a id="section-8-subsection-1-paragraph-8"></a>
- **8.** työministeriö siitä, sovelletaanko yhteistoiminnasta yrityksissä annettua lakia tai yhteistoiminnasta suomalaisissa ja yhteisönlaajuisissa yritysryhmissä annettua lakia yritykseen tai yritysryhmään\.
