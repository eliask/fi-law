<a id="section-24"></a>
### 24 § Ruokasuolan määrän ilmoittaminen

<a id="section-24-subsection-1"></a>
#### \(1\)

Seuraavien elintarvikkeiden pakkausmerkinnöissä on ilmoitettava ruokasuolan \(natriumkloridi\) kokonaismäärä painoprosentteina:

<a id="section-24-subsection-1-paragraph-1"></a>
- **1.** juustot;

<a id="section-24-subsection-1-paragraph-2"></a>
- **2.** lihavalmisteet, mukaan lukien makkarat;

<a id="section-24-subsection-1-paragraph-3"></a>
- **3.** kalavalmisteet;

<a id="section-24-subsection-1-paragraph-4"></a>
- **4.** ruokaleivät, näkkileivät ja hapankorput;

<a id="section-24-subsection-1-paragraph-5"></a>
- **5.** liemet, keitot ja kastikkeet, myös jauheena ja tiivisteenä;

<a id="section-24-subsection-1-paragraph-6"></a>
- **6.** muut puolivalmiit tai valmiit ruoat; sekä

<a id="section-24-subsection-1-paragraph-7"></a>
- **7.** ruokasuolaa sisältävät maustevalmisteet\.

<a id="section-25"></a>
### 25 § Elintarvikkeiden ilmoittaminen voimakassuolaiseksi

<a id="section-25-subsection-1"></a>
#### \(1\)

Sen lisäksi, mitä 24 §:ssä säädetään, on seuraavien elintarvikkeiden pakkaukseen tehtävä merkintä "voimakassuolainen" tai "lisätty paljon suolaa", jos elintarvikkeen suolapitoisuus \(natriumkloridi\) on:

<a id="section-25-subsection-1-paragraph-1"></a>
- **1.** juustoissa yli 1,3 painoprosenttia;

<a id="section-25-subsection-1-paragraph-2"></a>
- **2.** leikkele\-, ruoka\- ja raakamakkaroissa yli 1,7 painoprosenttia;

<a id="section-25-subsection-1-paragraph-3"></a>
- **3.** muissa leikkeleenä käytettävissä lihavalmisteissa yli 1,9 painoprosenttia;

<a id="section-25-subsection-1-paragraph-4"></a>
- **4.** kalavalmisteissa yli 1,9 painoprosenttia;

<a id="section-25-subsection-1-paragraph-5"></a>
- **5.** ruokaleivissä yli 1,2 painoprosenttia;

<a id="section-25-subsection-1-paragraph-6"></a>
- **6.** näkkileivissä ja hapankorpuissa yli 1,6 painoprosenttia;

<a id="section-25-subsection-1-paragraph-7"></a>
- **7.** aamiaisviljavalmisteissa yli 1,6 painoprosenttia;

<a id="section-25-subsection-1-paragraph-8"></a>
- **8.** keitoissa, liemissä ja kastikkeissa sekä niiden valmistukseen tarkoitetuissa jauheissa ja tiivisteissä nautintavalmiina yli 0,9 painoprosenttia; sekä

<a id="section-25-subsection-1-paragraph-9"></a>
- **9.** muissa puolivalmiissa ja valmiissa ruoissa, mukaan lukien maustetut kypsennettäväksi tarkoitetut raakaliha\- ja \-kalavalmisteet, yli 1,1 painoprosenttia\.
