<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä lailla perustetaan työ\- ja elinkeinoministeriöön seuraavat virat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikön virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kolme alivaltiosihteerin virkaa; ja

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** neljä osastopäällikön virkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Kukin alivaltiosihteeri vastaa yhdestä seuraavista vastuualueista:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** strategia;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** konserniohjaus; ja

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** alueiden kehittäminen\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Kukin osastopäällikkö vastaa yhdestä seuraavista osastoista:

<a id="section-1-subsection-3-paragraph-1"></a>
- **1.** työllisyys\- ja yrittäjyysosasto;

<a id="section-1-subsection-3-paragraph-2"></a>
- **2.** työelämä\- ja markkinaosasto;

<a id="section-1-subsection-3-paragraph-3"></a>
- **3.** innovaatio\-osasto; ja

<a id="section-1-subsection-3-paragraph-4"></a>
- **4.** energiaosasto\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtakunnansovittelijan virat ja valtakunnansovittelijan virkaa hoitava virkamies siirtyvät työ\- ja elinkeinoministeriöön\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Seuraavat kauppa\- ja teollisuusministeriön toimialalle kuuluvat talousarviossa eritellyt virat lakkautetaan:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikön virka;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** neljä osastopäällikön virkaa; ja

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** kolme apulaisosastopäällikön virkaa\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Seuraavat työministeriön toimialalle kuuluvat talousarviossa eritellyt virat lakkautetaan:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikön virka;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** yksi ylijohtajan virka; ja

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** seitsemän johtajan virkaa\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Sisäasiainministeriön alueiden ja hallinnon kehittämisosaston osastopäällikön virka lakkautetaan\.

<a id="section-6"></a>
### 6 §

<a id="section-6-subsection-1"></a>
#### \(1\)

Edellä 1 §:ssä tarkoitettuihin virkoihin sovelletaan niiden perustamisen jälkeen valtion virkamieslain \(750/1994\) säännöksiä\.

<a id="section-7"></a>
### 7 §

<a id="section-7-subsection-1"></a>
#### \(1\)

Tämä laki tulee voimaan 1 päivänä tammikuuta 2008\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Edellä 1 §:ssä tarkoitettujen virkojen täyttämiseen voidaan ryhtyä ennen tämän lain voimaantuloa\.
