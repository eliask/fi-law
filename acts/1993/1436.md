# Asetus erikoislääkärin tutkinnosta annetun asetuksen muuttamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erikoislääkärin tutkinto voidaan suorittaa Helsingin yliopiston, Kuopion yliopiston, Oulun yliopiston, Tampereen yliopiston ja Turun yliopiston lääketieteellisessä tiedekunnassa, joita tässä asetuksessa kutsutaan koulutusyksiköiksi\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Erikoislääkärin tutkintoa suorittamaan voidaan ottaa henkilö, joka on saanut Suomessa oikeuden harjoittaa lääkärin ammattia laillistettuna lääkärinä tai luvan toimia lääkärin tehtävissä\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Erikoislääkärin tutkintoon johtava opiskelu järjestetään koulutusohjelmina, joiden pituus on täysipäiväisenä opiskeluna kuusi tai kahdeksan vuotta\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Opetusministeriö päättää asianomaisen yliopiston esityksestä ja sosiaali\- ja terveysministeriötä kultuaan, mitä erikoislääkärin tutkintoon johtavia koulutusohjelmia kussakin koulutusyksikössä on\.

<a id="section-3a"></a>
### 3 a §

<a id="section-3a-subsection-1"></a>
#### \(1\)

Koulutusohjelmat, joiden pituus on kuusi vuotta, ovat anestesiologia, foniatria, fysiatria, geriatria, iho\- ja sukupuolitaudit, keuhkosairaudet, kirurgia, kliininen farmakologia, kliininen fysiologia, kliininen kemia, kliininen mikrobiologia, kliininen neurofysiologia, korva\-, nenä\- ja kurkkutaudit, lastenneurologia, lastenpsykiatria, lastentaudit, leukakirurgia, liikuntalääketiede, naistentaudit ja synnytykset, neurokirurgia, neurologia, oikeuslääketiede, patologia, perinnöllisyyslääketiede, psykiatria, radiologia, silmätaudit, sisätaudit, syöpätaudit ja sädehoito, terveydenhuolto, työterveyshuolto sekä yleislääketiede\.

<a id="section-3a-subsection-2"></a>
#### \(2\)

Koulutusohjelmat, joiden pituus on kahdeksan vuotta ja jotka suoritetaan 1 momentissa mainittujen koulutusohjelmien pohjalta, ovat:

<a id="section-3a-subsection-2-paragraph-1"></a>
- **1.** foniatria: audiologia;

<a id="section-3a-subsection-2-paragraph-2"></a>
- **2.** iho\- ja sukupuolitaudit: allergologia, ammatti\-ihotaudit;

<a id="section-3a-subsection-2-paragraph-3"></a>
- **3.** keuhkosairaudet: allergologia;

<a id="section-3a-subsection-2-paragraph-4"></a>
- **4.** kirurgia: gastroenterologia, käsikirurgia, lastenkirurgia, ortopedia ja traumatologia, plastiikkakirurgia, thorax\- ja verisuonikirurgia, urologia;

<a id="section-3a-subsection-2-paragraph-5"></a>
- **5.** kliininen fysiologia: isotooppitutkimukset, lasten fysiologia;

<a id="section-3a-subsection-2-paragraph-6"></a>
- **6.** kliininen kemia: endokrinologiset laboratoriotutkimukset, hematologiset laboratoriotutkimukset, isotooppilaboratoriotutkimukset, lääkeaineiden laboratoriotutkimukset, proteiinikemialliset laboratoriotutkimukset, teollisuustoksikologiset laboratoriotutkimukset;

<a id="section-3a-subsection-2-paragraph-7"></a>
- **7.** kliininen mikrobiologia: bakteriologia, immunologia, virologia;

<a id="section-3a-subsection-2-paragraph-8"></a>
- **8.** korva\-, nenä\- ja kurkkutaudit: allergologia, audiologia;

<a id="section-3a-subsection-2-paragraph-9"></a>
- **9.** lastenpsykiatria: nuorisopsykiatria;

<a id="section-3a-subsection-2-paragraph-10"></a>
- **10.** lastentaudit: lasten allergologia, lasten endokrinologia, lasten gastroenterologia, lasten hematologia, lasten infektiosairaudet, lasten kardiologia, lasten nefrologia, neonatologia;

<a id="section-3a-subsection-2-paragraph-11"></a>
- **11.** naistentaudit ja synnytykset: gynekologinen endokrinologia, gynekologinen endoskopia \(urologia\), gynekologinen sädehoito, perinatologia;

<a id="section-3a-subsection-2-paragraph-12"></a>
- **12.** neurologia: geriatria;

<a id="section-3a-subsection-2-paragraph-13"></a>
- **13.** patologia: neuropatologia, pediatrinen patologia;

<a id="section-3a-subsection-2-paragraph-14"></a>
- **14.** psykiatria: geriatria, nuorisopsykiatria, oikeuspsykiatria;

<a id="section-3a-subsection-2-paragraph-15"></a>
- **15.** radiologia: isotooppitutkimukset, lasten radiologia, neuroradiologia;

<a id="section-3a-subsection-2-paragraph-16"></a>
- **16.** silmätaudit: neuro\-oftalmologia;

<a id="section-3a-subsection-2-paragraph-17"></a>
- **17.** sisätaudit: allergologia, endokrinologia, gastroenterologia, geriatria, infektiosairaudet, kardiologia, kliininen hematologia, nefrologia, reumatologia;

<a id="section-3a-subsection-2-paragraph-18"></a>
- **18.** terveydenhuolto: ympäristöterveydenhuolto;

<a id="section-3a-subsection-2-paragraph-19"></a>
- **19.** työterveyshuolto: työlääketiede, ympäristöterveydenhuolto;

<a id="section-3a-subsection-2-paragraph-20"></a>
- **20.** yleislääketiede: ympäristöterveydenhuolto\.

<a id="section-3a-subsection-3"></a>
#### \(3\)

Erikoislääkäri voi suorittaa hallinnon pätevyyteen vaadittavan koulutusohjelman, jonka pituus on kaksi vuotta\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Erikoislääkärin tutkinnon suorittamiseksi opiskelijan tulee:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** palvella koulutusohjelmaan soveltuvassa päätoimisessa lääkärin virassa, toimessa tai tehtävässä yleiskoulutuksena vähintään kaksi vuotta;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** palvella koulutusyksikön hyväksymässä erikoistumisvirassa täysipäiväisenä opiskeluna 3 a §:n 1 momentissa mainitussa koulutusohjelmassa vähintään neljä vuotta ja 3 a §:n 2 ja 3 momentissa mainitussa koulutusohjelmassa lisäksi vähintään kaksi vuotta sekä osallistua tänä aikana koulutusyksikön hyväksymällä tavalla asianomaisen laitoksen toimintaan ja säännölliseen, ohjattuun erikoisalakohtaiseen toimipaikkakoulutukseen;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** suorittaa koulutusyksikön hyväksymä tai järjestämä kurssimuotoinen, teoreettinen koulutus, jonka laajuus on vähintään 80 tuntia 3 a §:n 1 momentissa mainituissa koulutusohjelmissa ja lisäksi vähintään 30 tuntia 3 a §:n 2 ja 3 momentissa mainituissa koulutusohjelmissa; sekä

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** osoittaa saavuttaneensa tutkinnon tavoitteet suorittamalla valtakunnallinen erikoisalakohtainen kuulustelu kuuden vuoden ja sen lisäksi kahdeksan vuoden opiskelussa\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Lääkärin perusterveydenhuollon lisäkoulutus tai koulutusohjelmaan soveltuva osa siitä hyväksytään 1 momentin 1 kohdassa tarkoitetuksi yleiskoulutukseksi\.

<a id="section-8"></a>
### 8 §

<a id="section-8-subsection-1"></a>
#### \(1\)

Koulutusyksikkö päättää opiskelijan suorittaman palvelun ja aikaisemman opiskelun hyväksymisestä koulutukseen kuuluvaksi\.
