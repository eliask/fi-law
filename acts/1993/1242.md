# Sosiaali\- ja terveysministeriön päätös Järvenpään sosiaalisairaalan maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka Järvenpään sosiaalisairaala hinnoittelee liiketaloudellisin perustein ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** hoitovuorokausi;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** asumis\- ja hoitopalvelut;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ulkopuolelle myytävät laboratoriopalvelut;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** koulutus\-, konsultointi\- ja työnohjauspalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** muut tilauksesta tehtävät tutkimukset, selvitykset ja palvelut;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** julkaisut;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** tilojen ja laitteiden käyttö ulkopuolisille;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** ravintopalvelut;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** toimistopalvelut;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** maatilatalouden tuotteet ja palvelut sekä muut työsuoritukset

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\. Päätös on voimassa 30\.6\.1994 saakka\.
