# Opetusministeriön päätös opetushallituksen maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:ssä tarkoitettuja maksullisia julkisoikeudellisia suoritteita, joista opetushallitus perii kiinteät maksut, ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ammattikasvatushallinnon tutkintoon osallistumisesta tutkintomaksuna 200 mk;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kouluhallinnon tutkintoon osallistumisesta tutkintomaksuna 200 mk;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** musiikkioppilaitoshallinnon tutkintoon osallistumisesta tutkintomaksuna 200 mk;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** 2\-osaiseen opetushallinnon tutkintoon osallistumisesta tutkintomaksuna 200 mk kummastakin tutkinnon osasta, sekä

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** 1\-4\-kohdassa mainitun tutkinnon tai sen osan suorittamisesta annettavasta todistuksesta maksuna 100 mk\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita maksullisia suoritteita, jotka opetushallitus hinnoittelee liiketaloudellisin perustein ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** koulutus\- ja konsultointipalvelut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** oppimateriaalin tuottaminen ja siihen liittyvä kustannustoiminta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** opetushallituksen rekistereihin ja tietokantoihin perustuva tietopalvelu ja tietokantojen suorakäyttö;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** tilauksesta tehdyt selvitykset ja tutkimukset sekä tiedonkeruu\- ja jakelupalvelut;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** julkaisut ja kustannuspalvelut;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** ilmoitukset opetushallituksen julkaisuissa;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** sähköiset tietotuotteet ja AV\-tuotteet;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** opetushallituksen hallinnoimien toimitilojen vuokraaminen;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** valokopio\- ja muut jäljennökset;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** asiakirjojen ja muun aineiston lähettäminen ja postitus, sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** muut tilatut palvelusuoritteet\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä helmikuuta 1993 ja on voimassa vuoden 1993 loppuun\.
