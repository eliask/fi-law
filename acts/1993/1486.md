# Sisäasiainministeriön päätös rajavartiolaitoksen suoritteiden maksullisuudesta

### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä päätöksellä määrätään rajavartiolaitoksen suoritteiden maksullisuudesta ja maksujen suuruudesta\. Tämä päätös koskee myös rajavartiolaitoksen esikunnan sisäasiainministeriön rajavartio\-osastona tuottamaa suoritetta\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Rajavartiolaitoksen suoritteen maksullisuus tai maksuttomuus ei lisää tai vähennä oikeutta saada tällaista suoritetta\.

<a id="section-2"></a>
### 2 § Maksuttomat suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 5 §:ssä mainittuja maksuttomia suoritteita ovat rajavartiolaitoksen tehtäväksi säädetyt tai määrätyt:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** valvonta\- ja turvaamistehtävät sekä muut yleisen järjestyksen ja turvallisuuden ylläpitämiseen liittyvät suoritteet;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** esitutkintalain mukaiset suoritteet;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** yhteistoimintaviranomaiselle rajavartiolaitoksen tehtävien suorittamiseksi tai kehittämiseksi tuotetut suoritteet; sekä

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** meripelastuspalveluun ihmishengen pelastamiseksi kuuluvat suoritteet\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Maksua ei peritä valtion maksuperustelain 6 §:n 3 momentin nojalla seuraavista rajavartiolaitoksen suoritteista:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** rajavyöhykkeeseen kohdistuvista luvista, päätöksistä ja lausunnoista;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** rajanylityslupahakemukseen annetusta päätöksestä, luvasta ja lausunnosta; sekä

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** kalastussopimusalueille kohdistuvista luvista, päätöksistä ja lausunnoista\.

<a id="section-3"></a>
### 3 § Liiketaloudellisin perustein hinnoiteltavat suoritteet

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka rajavartiolaitos hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** tilojen, kaluston ja laitteiden käyttö sekä palkatun henkilöstön ja asevelvollisten käyttö rajavartiolaitoksen ulkopuolisissa tehtävissä lukuun ottamatta tapauksia, joissa tehtävien hoitaminen tukee välittömästi rajavartiolaitoksen omaa toimintaa tai on tarpeellista sidosryhmäsuhteiden hoitamiselle;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** kuljetus tai muu työsuorite rajavartiolaitoksen ilma\-aluksella ulkopuolisille;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** kuljetus tai muu työsuorite rajavartiolaitoksen laivalla, veneellä ja ilmatyynyaluksella ulkopuolisille;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** kuljetus tai muu työsuorite moottorikelkalla, kiitoreellä ja robottikalustolla tai muulla kalustolla ulkopuolisille;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** tilauksesta tehtävät suunnittelu\-, asiantuntija\- ja konsultointipalvelut;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** tilastot ja selvitykset;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** muu tietopalvelu; sekä

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** suoritteet, jotka tilauksesta tai pyynnöstä tuotetaan merilain \(167/39\) 7 luvussa tarkoitetun omaisuuden pelastamiseksi; sekä

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** muu tilaukseen tai toimeksiantoon perustuva suorite ulkopuolisille\.

<a id="section-4"></a>
### 4 § Maksusta päättävä viranomainen

<a id="section-4-subsection-1"></a>
#### \(1\)

Liiketaloudellisin perustein hinnoiteltavista maksuista päättää rajavartiolaitoksen esi\- kunta\.

<a id="section-5"></a>
### 5 § Voimaantulo

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\. Täytäntöönpanon edellyttämiin toimenpiteisiin voidaan ryhtyä ennen tämän päätöksen voimaan tuloa\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Päätöksen mukaisia maksuja peritään sen voimassaoloaikana tilatuista suoritteista\.
