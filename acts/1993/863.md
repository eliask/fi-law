# Verohallituksen päätös ilmoittamisvelvollisuuden rajoittamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Veroilmoituksessa ei ilmoiteta seuraavia Suomesta saatuja tuloja:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** eläkettä ja elinkorkoa, paitsi jos kyseessä on tuloverolain 37 §:n mukainen veronalainen syytinki eikä eläkevakuutuksen vakuutusmaksujen palautuksena, takaisinostolla tai muutosarvona luonnolliselle henkilölle maksettua suoritusta,

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** sairausvakuutuslain nojalla saatua päivä\-, äitiys\-, isyys\- ja vanhempainrahaa eikä muuta mainitun lain, kansaneläkelain tai potilasvahinkolain nojalla saatua korvausta tulojen tai elatuksen vähentymisestä,

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** pakollisen tapaturma\- eikä liikennevahinkoturvan nojalla tulojen tai elatuksen vähentymisestä saatua korvausta,

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** tuloverolain 34 §:ssä tarkoitetun henkivakuutuksen nojalla luonnolliselle henkilölle maksettua vakuutussuoritusta, vakuutusmaksujen palautuksena ja takaisinostolla saatua määrää eikä muutosarvoa,

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** muun kuin 2, 3 ja 4 kohdassa tarkoitetun vakuutuksen nojalla maksettua päivärahaa, muuta vastaavaa tulojen ja elatuksen vähentymisestä maksettua korvausta eikä sairaalavakuutuksen perusteella maksettua hoitopäiväkorvausta,

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** tartuntatautilain \(583/86\) nojalla saatua päivärahaa eikä ansionmenetyksestä saatua korvausta,

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** rikosvahinkojen korvaamisesta valtion varoista annetun lain \(935/73\) nojalla tulojen tai elatuksen vähentymisestä maksettua korvausta,

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** työttömyysturvalain \(602/84\) nojalla maksettua etuutta eikä työvoimapoliittisesta aikuiskoulutuksesta annetussa laissa \(763/90\) tarkoitettua koulutus\- ja erityistukea,

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** työllisyysasetuksen \(130/93\) nojalla yrittäjäksi ryhtyvälle työttömälle tai vajaakuntoiselle työttömälle maksettua tukea eikä myöskään työttömän muuhun kuin elinkeinotoimintaan tai maatilatalouteen palkanneelle luonnolliselle henkilölle maksettua työllistämistukea taikka ammatinvalinnan ohjauksesta annetun lain nojalla \(43/60\) maksettua vastaavaa tukea,

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** työllisyysasetuksen \(130/93\) nojalla maksettua työharjoittelutukea eikä omatoimiseen työllistämiseen annettua tukea,

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** valtioneuvoston päätöksen \(321/93\) nojalla myönnettyä nuorten kesätyötukea,

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** opintotukilain 10 §:ssä \(684/90\) tarkoitettua aikuisopintorahana maksettua ansionmenetyskorvausta eikä korkeakouluopiskelijoiden opintotuesta annetun lain \(111/92\) nojalla maksettua opintorahaa ja aikuisopintorahaa,

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** lapsen kotihoidon tukea,

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** valtion virkamieslain \(755/86\) nojalla maksettua toistuvaa korvausta,

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** ulkomaan edustuksen virkamiesten puolisoille maksettavasta erityiskorvauksesta annetun lain \(657/89\) nojalla maksettua erityiskorvausta,

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** reserviläispalkkaa,

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** tuloverolain \(1535/92\) 74 §:ssä tarkoitettua merityötuloa,

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** sellaisia rakennustoiminnan aloilla maksettuja lomapalkkoja, lomakorvauksia ja lomaltapaluurahoja \(lomarahoja\), jotka työnantaja on valtakunnallisen työehtosopimuksen mukaan tilittänyt Postipankkiin työnantajajärjestön erityiselle postisiirtotilille,

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** henkilöstörahastojen jäsenilleen maksamaa rahasto\-osuutta ja ylijäämää,

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** sairausvakuutuslain mukaisen omavastuuajan korvaamisesta maatalousyrittäjille annetun lain \(118/91\) mukaista päivärahaa,

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** kuntoutusrahaa, kuntoutusavustusta ja kuntoutusajalta tapaturma\- ja liikennevakuu\- tuslain perusteella korvattavasta kuntoutuksesta annettujen lakien \(625/91 ja 626/91\) nojalla maksettua ansionmenetyskorvausta,

<a id="section-1-subsection-1-paragraph-22"></a>
- **22.** vakuutuskassalaissa \(1164/92\) tarkoitettujen kassojen suorittamia etuuksia,

<a id="section-1-subsection-1-paragraph-23"></a>
- **23.** työtaistelun johdosta asianomaisen työmarkkinajärjestön suorittamaa veronalaista avustusta eikä muuta siihen rinnastettavaa avustusta,

<a id="section-1-subsection-1-paragraph-24"></a>
- **24.** ennakkoperintälain soveltamisalaan kuuluvaa rahalaitoksen suorittamaa tai välittämää korkoa, ennakkoperintälain soveltamisalaan kuuluvaa joukkovelkakirjalainan liikkeeseen laskijan maksamaa korkoa ja lainan koroksi katsottavaa tuottoa eikä myöskään sijoitusrahaston maksamaa voitto\-osuutta, jos suorituksen saajana on luonnollinen henkilö tai kotimainen kuolinpesä eikä korko tai voitto\-osuus liity elinkeinotoiminnan tai maatilatalouden tuloksi luettavaan korkoon tai voitto\-osuuteen,

<a id="section-1-subsection-1-paragraph-25"></a>
- **25.** maatalousyrittäjien luopumiskorvauksesta annetun lain \(1330/92\) mukaista luopumiskorvausta,

<a id="section-1-subsection-1-paragraph-26"></a>
- **26.** palkkaturvaviranomaisen palkkaturvalain \(649/73\) nojalla suoraan työntekijälle maksamaa palkkaturvaa eikä

<a id="section-1-subsection-1-paragraph-27"></a>
- **27.** patentin, tekijänoikeuden ja muun niihin verrattavan oikeuden perusteella luonnolliselle henkilölle tai kotimaiselle kuolinpesälle maksettua korvausta, jos korvaus ei liity liike\- tai ammattitoiminnan tuloon\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Verovelvollisen, jolla ei ole ollut veronalaisia varoja eikä muita kuin 1 §:ssä mainittuja ilmoittamisvelvollisuudesta vapautettuja tuloja, ei tarvitse kehotuksetta antaa veroilmoitusta\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä joulukuuta 1993\. Päätöstä sovelletaan ensimmäisen kerran vuodelta l993 toimitettavaan verotukseen\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Päätöksellä kumotaan verohallituksen ilmoittamisvelvollisuuden rajoittamisesta 8 päivänä lokakuuta 1992 antama päätös \(963/92\)\.
