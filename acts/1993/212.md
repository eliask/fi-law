# Valtioneuvoston päätös työsuojelupiireistä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Työsuojelupiirit ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan työsuojelupiiri, joka käsittää Uudenmaan läänin;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Turun ja Porin työsuojelupiiri, joka käsittää Turun ja Porin läänin sekä Ahvenanmaan maakunnan;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Hämeen työsuojelupiiri, joka käsittää Hämeen läänin;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen työsuojelupiiri, joka käsittää Keski\-Suomen läänin;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Kymen työsuojelupiiri, joka käsittää Kymen läänin;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Mikkelin työsuojelupiiri, joka käsittää Mikkelin läänin;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Kuopion työsuojelupiiri, joka käsittää Kuopion läänin;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Pohjois\-Karjalan työsuojelupiiri, joka käsittää Pohjois\-Karjalan läänin;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Vaasan työsuojelupiiri, joka käsittää Vaasan läänin;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Oulun työsuojelupiiri, joka käsittää Oulun läänin; sekä

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Lapin työsuojelupiiri, joka käsittää Lapin läänin\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Työsuojelutoimisto on:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan työsuojelupiirissä Helsingin kaupungissa;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Turun ja Porin työsuojelupiirissä Turun kaupungissa;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Hämeen työsuojelupiirissä Tampereen kaupungissa;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen työsuojelupiirissä Jyväskylän kaupungissa;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Kymen työsuojelupiirissä Lappeenrannan kaupungissa;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Mikkelin työsuojelupiirissä Mikkelin kaupungissa;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Kuopion työsuojelupiirissä Kuopion kaupungissa;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Pohjois\-Karjalan työsuojelupiirissä Joensuun kaupungissa;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Vaasan työsuojelupiirissä Vaasan kaupungissa;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Oulun työsuojelupiirissä Oulun kaupungissa; sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Lapin työsuojelupiirissä Kemin kaupungissa\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1993\.
