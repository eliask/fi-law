# Asetus puolustusministeriöstä annetun asetuksen muuttamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Puolustusministeriössä on:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** keskusosasto;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** sotilasasiainosasto;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** järjestelyosasto;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** rakennusosasto; sekä

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** kiinteistöosasto\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä on erillinen tiedotusyksikkö\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Osastojen jakamisesta vastuualueisiin tai muihin pysyviin toimintayksiköihin määrätään työjärjestyksessä\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Keskusosasto käsittelee asiat, jotka koskevat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** lainsäädäntöä sekä oikeudellisia ja hallinnollisia asioita, jollei asia kuulu muun osaston käsiteltäviin tai jos se koskee useamman kuin yhden osaston toimialaa;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** sotilasoikeudenhoitoa sekä ministeriön edustamista tuomioistuimissa ja muissa viranomaisissa sekä laitoksissa ja yhteisöissä, jollei asia kuulu ministeriön muun osaston käsiteltäviin;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** hankintoja ja muita kaupallisia asioita sekä sotataloudellisia asioita ja puolustustarvikkeiden maastavientiä;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** ministeriön valvontaan kuuluvien valtionenemmistöisten osakeyhtiöiden ja Valtion pukutehtaan hallintoa;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** talousarvioesityksen valmistelua ja talousarvion toimeenpanoa sekä niihin liittyvää taloudellista ohjausta, suunnittelua ja seurantaa;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** puolustusministeriölle tilivirastona kuuluvia tehtäviä; sekä

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** hallinnonalan sisäistä talousvalvontaa ja sen ohjausta\.

<a id="section-9"></a>
### 9 §

<a id="section-9-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikkö,

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** hallitusneuvoksia, joista yksi toimii keskusosaston ja yksi kiinteistöosaston osastopäällikkönä,

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** sotilasasiainosaston osastopäällikkö,

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** järjestelyosaston osastopäällikkö, jolla on puolustusasiainneuvoksen arvonimi,

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** rakennusosaston osastopäällikkönä toimiva rakennusneuvos,

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksia, toimistopäälliköinä,

<a id="section-9-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköitä,

<a id="section-9-subsection-1-paragraph-8"></a>
- **8.** vanhempia ja nuorempia hallitussihteereitä,

<a id="section-9-subsection-1-paragraph-9"></a>
- **9.** vanhempia ja nuorempia toimistoesiupseereita,

<a id="section-9-subsection-1-paragraph-10"></a>
- **10.** arkkitehti, maanmittausinsinööri ja insinöörejä,

<a id="section-9-subsection-1-paragraph-11"></a>
- **11.** metsänhoitaja, aluemetsänhoitajia ja metsätalousinsinööri,

<a id="section-9-subsection-1-paragraph-12"></a>
- **12.** neuvottelevia virkamiehiä, pääsihteeri ja yleissihteeri,

<a id="section-9-subsection-1-paragraph-13"></a>
- **13.** koulutuspäällikkö ja tiedotuspäällikkö,

<a id="section-9-subsection-1-paragraph-14"></a>
- **14.** ylitarkastajia ja taloustarkastajia,

<a id="section-9-subsection-1-paragraph-15"></a>
- **15.** erikoistutkija ja esittelijöitä,

<a id="section-9-subsection-1-paragraph-16"></a>
- **16.** kamreeri,

<a id="section-9-subsection-1-paragraph-17"></a>
- **17.** suunnittelusihteeri, henkilöstösihteeri, laskentasihteereitä ja osastosihteereitä,

<a id="section-9-subsection-1-paragraph-18"></a>
- **18.** maanmittausteknikko ja agrologi,

<a id="section-9-subsection-1-paragraph-19"></a>
- **19.** ministerin sihteeri, hankintasihteeri ja sihteereitä,

<a id="section-9-subsection-1-paragraph-20"></a>
- **20.** notaari ja kirjaajia,

<a id="section-9-subsection-1-paragraph-21"></a>
- **21.** arkistonhoitaja, pääkirjanpitäjä, kartoittaja, tekstinkäsittelijöitä, piirtäjiä, toimistosihteereitä ja toimistovirkailija, sekä

<a id="section-9-subsection-1-paragraph-22"></a>
- **22.** ylivirastomestari ja virastomestari\.

<a id="section-10"></a>
### 10 §

<a id="section-10-subsection-1"></a>
#### \(1\)

Lisäksi vaaditaan erityisenä kelpoisuusvaatimuksena:

<a id="section-10-subsection-1-paragraph-5"></a>
- **5.** järjestelyosaston osastopäälliköltä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys puolustushallintoon;

<a id="section-10-subsection-1-paragraph-9"></a>
- **9.** vanhemmalta toimistoesiupseerilta viran laadun mukaan kelpoisuus puolustusvoimien everstin tai kommodorin taikka everstiluutnantin tai komentajan virkaan ja nuoremmalta toimistoesiupseerilta kelpoisuus puolustusvoimien majurin tai komentajakapteenin virkaan;

<a id="section-23"></a>
### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Muista kuin 22 §:ssä tarkoitetuista ministeriössä päätettävistä asioista ratkaisee:

<a id="section-23-subsection-1-paragraph-1"></a>
- **1.** keskusosaston päällikkönä toimiva hallitusneuvos asiat, jotka koskevat:

<a id="section-23-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** talousarvion toimeenpanoa;

<a id="section-23-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** hankintaennakoiden vakuuksien hyväksymistä sekä kaluston ja muun siihen verrattavan omaisuuden hylkäämistä ja poistamista sekä tileistä poistoja;

<a id="section-23-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** varainhoitovuotta aikaisempaan vuoteen kohdistuvan menon maksamista kulumassa olevan varainhoitovuoden vastaavaan tarkoitukseen käytettävissä olevasta määrärahasta sekä myöhästyneinä esitettyjen matkalaskujen maksamista;

<a id="section-23-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** rintamasotilastunnuksesta annetussa asetuksessa \(772/69\), rintamapalvelustunnuksesta annetussa asetuksessa \(554/78\) ja rintamatunnuksesta annetussa asetuksessa \(256/88\) tarkoitettuja valituksia; sekä

<a id="section-23-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** vahingonkorvauksia\.
