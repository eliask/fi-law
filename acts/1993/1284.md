# Kauppa\- ja teollisuusministeriön päätös matkailun edistämiskeskuksen maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka matkailun edistämiskeskus hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** tilauksesta tehdyt messut, näyttelyt ja kampanjat;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** asiantuntija\- ja konsulttipalvelut;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** julkaisutoiminta;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** tietopalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** koulutus\- ja seminaaritilaisuudet; ja

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** muut matkailun edistämiskeskukselta erikseen tilatut, sen toimialaan kuuluvat palvelut\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\.
