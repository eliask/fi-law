# Valtiovarainministeriön päätös valtiovarainministeriön suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtiovarainministeriön ja sen yhteydessä toimivien lautakuntien ja muiden elinten suoritteista peritään valtiolle maksuja tämän päätöksen mukaisesti, jollei niiden osalta ole muuta erikseen säädetty tai määrätty\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Maksu peritään myös silloin, kun 2 tai 3 §:ssä tarkoitettuun hakemukseen annetaan kielteinen päätös\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Julkisoikeudellisia suoritteita, joista peritään yksittäisen suoritteen omakustannusarvoa vastaava maksu, ovat:

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** lupa talletuspankin tai muun luottolaitoksen sivukonttorin tai sijoituspalveluyrityksen sivuliikkeen perustamiseen ulkomaille tai päätös sivukonttorin tai sivuliikkeen lakkauttamisesta;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** päätös talletuspankin tai muun luottolaitoksen toiminnan keskeyttämisestä, keskeyttämisen jatkamisesta, sulkemisesta, selvitystilaan asettamisesta tai selvitysmiehen määräämisestä;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** päätös liike\-, säästö\- ja osuuspankkien vakuusrahastojen sääntöjen tai niiden muutosten vahvistamisesta;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** lupa arvopaperipörssitoiminnan harjoittamiseen;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** päätös arvopaperipörssin toimiluvan peruuttamisesta tai toiminnan keskeyttämisestä;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** arvopaperipörssin sääntöjen tai niiden muutoksen vahvistaminen;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** lupa optioyhteisölle optiopörssitoiminnan tai optiokauppojen selvitystoiminnan harjoittamiseen;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** päätös optioyhteisön toiminnan rajoittamisesta tai toimiluvan peruuttamisesta;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** optioyhteisön sääntöjen tai muutoksen vahvistaminen;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** hypoteekkiyhdistyksen toimilupa;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** lupa hypoteekkiyhdistyksen jakamiseen tai yhdistysten sulautumiseen taikka yhdistämiseen;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** päätös säästökassatoimintaa harjoittavan osuuskunnan jäsensijoitustilien tiliehtojen tai niiden muutosten vahvistamisesta;

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** lupa talletuspankin tai muun luottolaitoksen toimintaan;

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** päätös talletuspankin tai muun luottolaitoksen toimiluvan mukaisen toiminnan rajoittamisesta tai peruuttamisesta;

<a id="section-3-subsection-1-paragraph-17"></a>
- **17.** lupa sijoituspalveluyrityksen toimintaan;

<a id="section-3-subsection-1-paragraph-18"></a>
- **18.** päätös sijoituspalveluyrityksen toiminnan rajoittamisesta tai toimiluvan peruuttamisesta;

<a id="section-3-subsection-1-paragraph-19"></a>
- **19.** rahastoyhtiön toimilupa, toimiluvan muuttaminen tai peruuttaminen;

<a id="section-3-subsection-1-paragraph-20"></a>
- **20.** panttilainausliikkeen toimilupa;

<a id="section-3-subsection-1-paragraph-21"></a>
- **21.** päätös osuuspankkien yhteenliittymän keskusyhteisön sääntöjen ja niiden muutosten vahvistamisesta\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Maksullisia suoritteita, jotka hinnoitellaan liiketaloudellisin perustein, ovat seuraavat tilaukseen tai muuhun toimeksiantoon perustuvat palvelut ja muut suoritteet:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** selvitykset ja tutkimukset;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** henkilöstön käyttö koulutus\-, suunnittelu\- ja muissa asiantuntijatehtävissä;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** henkilöstöhallinnon tietojärjestelmien ylläpitoon, käyttöön ja käytönohjaukseen liittyvät palvelut;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** valtion virkaehtosopimusasetuksen muuttamisesta annetun asetuksen \(290/93\) 1 §:n 2 momentissa tarkoitetut palvelut Liikelaitosten työnantajayhdistys ry:lle;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** kirjasto\- ja tietopalvelut;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** julkaisut;

<a id="section-4-subsection-1-paragraph-6a"></a>
- **6a.** mallioikeuslain mukainen käyttölupa;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** valokopiot ja muut jäljenteet;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** valtiovarainministeriön hallinnassa olevien toimitilojen ja laitteiden käyttö;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** muut virasto\- ja toimistopalvelut\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Sellaisesta 1\-3 §:ssä tarkoitetusta suoritteesta, jota koskeva asia on tullut vireille ennen tämän päätöksen voimaantuloa, peritään maksu kuitenkin enintään sen suuruisena kuin siitä perittävä maksu tai leimavero olisi ollut ennen tämän päätöksen voimaantuloa voimassa olleiden säännösten tai maksuperustepäätösten mukaan\.
