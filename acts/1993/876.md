# Valtiovarainministeriön päätös Valtion taloudellisen tutkimuskeskuksen maksullisista suoritteista

- Statute: [`876/1993`](<https://www.finlex.fi/fi/laki/ajantasa/1993/876>)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maksullisia suoritteita, jotka Valtion taloudellinen tutkimuskeskus hinnoittelee liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** tilauksesta tehdyt tutkimukset ja selvitykset

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** tutkimusaineistot

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** asiantuntija\- ja konsulttipalvelut

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** julkaisutoiminta

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** kirjasto\- ja tietopalvelut

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** koulutus\- ja seminaaritilaisuudet; ja

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** muut Valtion taloudelliselta tutkimuskeskukselta erikseen tilatut palvelut\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\.
