# Valtiovarainministeriön päätös valtiokonttorin maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:ssä tarkoitettuja julkisoikeudellisia suoritteita, joista valtiokonttori perii omakustannusarvon mukaiset maksut, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** lainanotto\- ja velanhoitopalvelut valtion asuntorahastolle;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** palkansaajien työttömyysvakuutusmaksun perintä ja tilitys;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** valtion liikelaitosten työnantajan työttömyysvakuutusmaksun perintä ja tilitys;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** petoeläinten aiheuttamien henkilövahinkojen ja liikennevahinkojen korvausten hoito; sekä

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** hirvieläinten liikenteelle aiheuttamien vahinkojen korvaustoiminnan hoito\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka valtiokonttori hinnoittelee liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** taloushallinnon tietojärjestelmiin ja laskentatoimeen liittyvät konsultointi\-, koulutus\- ja käytönohjauspalvelut sekä muut kuin valtion keskuskirjanpitoon liittyvät kirjanpitopalvelut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** valtion keskushenkilörekistereitä lukuunottamatta henkilöstöhallinnon tietojärjestelmien käyttöönotto\-, ylläpito\-, käyttö\-, koulutus\- ja konsultointipalvelut sekä palkanlaskentapalvelut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** valtion ylimmän johdon henkilöstötietojärjestelmän käyttö\- ja ylläpitopalvelut;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** henkilöstövoimavarojen uudelleen järjestämistä tukevat palvelut;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** pyynnöstä tehdyt valtion eläketurvan piiriin kuuluvien henkilöiden kirjalliset eläkearviot ja ennakkoselvitykset, lukuunottamatta eläketurvan piiriin kuuluvan henkilön pyytämiä itseään koskevia mainittuja tietoja, kun todennäköiseen eläketapahtumaan on aikaa alle vuosi tai kun laskelma on tarpeen hakijan eläkkeelle siirtymisen edellytysten harkitsemiseksi;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** työnantajan järjestämät eläkkeelle valmentautumistilaisuudet eläkearvioineen, kun ne eivät suoranaisesti tue valtiokonttorin maksutonta viranomaistoimintaa;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** sopimukseen perustuva muun kuin valtion varoista suoritettavan eläketurvan hoitopalvelu eläketurvasta vastuussa olevalle eläkelaitokselle tai yhteisölle;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** lainanotto\-, velanhoito\-, sijoitus\- ja säilytyspalvelut valtion liikelaitoksista annetun lain \(627/1987\) mukaisille liikelaitoksille, talousarvion ulkopuolisille rahastoille ja erityisistä syistä valtionhallinnon ulkopuolisille yhteisöille;

<a id="section-2-subsection-1-paragraph-9a"></a>
- **9a.** arvopaperistettujen lainojen hoito\- ja sijoituspalvelut tarkoitusta varten perustetuille erityisyhteisöille;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** pyynnöstä toimitetut lainojen saldo\- ja vakuustodistukset, jälkipanttaussitoumukset, vakuuksien uudistamiset ja vaihdot ja muut asiakirjat sekä muut lainoja koskevat pyynnöstä toimitetut tulosteet ja tiedostot lukuunottamatta viranomaistoimintaa varten tarvittavia asiakirjoja, tulosteita ja muita tallenteita;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** valtiokonttorin hallinnassa olevien toi\-mitilojen ja laitteiden käyttö sekä virasto\- ja toimistopalvelut valtiokonttorin ulkopuolisille;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** julkaisut ja jäljenteet lukuunottamatta valtiokonttorin viranomaistoimintaan liittyvää jakelua sekä tiedotus\- ja ohjeluonteisia julkaisuja; sekä

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** tilaukseen perustuva henkilöstön käyttö valtiokonttorin ulkopuolisissa koulutus\-, suunnittelu\- ja muissa asiantuntijatehtävissä sekä valtiokonttorin toimintaan liittyvät muut koulutuspalvelut\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1994\.
