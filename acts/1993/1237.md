<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Yleisvaarallisia tartuntatauteja ovat

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** hemorragiset kuumeet, ei kuitenkaan myyräkuume,

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** hepatiitti A,

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** keltakuume,

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** kolera,

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kuppa,

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** kurkkumätä,

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** lavantauti, pikkulavantauti ja muut salmonellojen aiheuttamat taudit,

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** meningokokin aiheuttamat septiset taudit ja aivokalvontulehdukset,

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** pernarutto,

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** polio,

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** rutto,

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** shigellapunatauti ja

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** tuberkuloosi\.

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** Ilmoitettavia tartuntatauteja ovat

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** ekinokokkoosi,

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** hepatiitti B,

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** HIV\-infektio,

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** klamydiainfektiot, sukupuoliteitse leviävät,

<a id="section-2-subsection-1-paragraph-19"></a>
- **19.** legionelloosi,

<a id="section-2-subsection-1-paragraph-20"></a>
- **20.** listerioosi,

<a id="section-2-subsection-1-paragraph-21"></a>
- **21.** malaria,

<a id="section-2-subsection-1-paragraph-22"></a>
- **22.** mykobakteeritaudit, muut kuin tuberkuloosi, rabies,

<a id="section-2-subsection-1-paragraph-23"></a>
- **23.** sankkerit,

<a id="section-2-subsection-1-paragraph-24"></a>
- **24.** septiset hemofilustaudit,

<a id="section-2-subsection-1-paragraph-25"></a>
- **25.** sikotauti,

<a id="section-2-subsection-1-paragraph-26"></a>
- **26.** tippuri,

<a id="section-2-subsection-1-paragraph-27"></a>
- **27.** toisintokuume,

<a id="section-2-subsection-1-paragraph-28"></a>
- **28.** tuhkarokko ja

<a id="section-2-subsection-1-paragraph-29"></a>
- **29.** vihurirokko\.

<a id="section-16a"></a>
### 16 a §

<a id="section-16a-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriö voi määrätä 2 §:ssä todettujen tartuntatautien ilmoittamisen lisäksi lääkärit ilmoittamaan toteamiaan muita tartuntatautiepidemioita ja tartuntatautilain 10 §:ssä tarkoitetut laboratoriot ilmoittamaan toteamiaan muita tartuntatautitapauksia osoittavia tutkimustuloksia\. Ilmoitukset voivat sisältää tartuntatautien vastustamistyössä tarpeellisia taustatietoja, eivät kuitenkaan henkilötietoja\.
