## 29 luku Rikoksista julkista taloutta vastaan

<a id="chapter-29-section-4"></a>
### 4 § Verorikkomus

<a id="chapter-29-section-4-subsection-1"></a>
#### \(1\)

Joka hankkiakseen itselleen tai toiselle taloudellista hyötyä jättää muun syyn kuin maksukyvyttömyyden tai tuomioistuimen päätökseen perustuvan maksukiellon takia määräajassa suorittamatta

<a id="chapter-29-section-4-subsection-1-paragraph-1"></a>
- **1.** ennakonpidätyksen tai lähdeveron,

<a id="chapter-29-section-4-subsection-1-paragraph-2"></a>
- **2.** kalenterikuukaudelta lasketun liikevaihtoveron tai vastaavan eräistä vakuutusmaksuista suoritettavan veron tai

<a id="chapter-29-section-4-subsection-1-paragraph-3"></a>
- **3.** työnantajan sosiaaliturvamaksun,

<a id="chapter-29-section-4-subsection-2"></a>
#### \(2\)

on tuomittava, jollei teko ole rangaistava veropetoksena, verorikkomuksesta sakkoon tai vankeuteen enintään kuudeksi kuukaudeksi\.

<a id="chapter-30"></a>
## 30 luku Elinkeinorikoksista

<a id="chapter-30-section-5"></a>
### 5 § Yrityssalaisuuden rikkominen

<a id="chapter-30-section-5-subsection-1"></a>
#### \(1\)

Joka hankkiakseen itselleen tai toiselle taloudellista hyötyä tai toista vahingoittaakseen oikeudettomasti ilmaisee toiselle kuuluvan yrityssalaisuuden tai oikeudettomasti käyttää tällaista yrityssalaisuutta, jonka hän on saanut tietoonsa

<a id="chapter-30-section-5-subsection-1-paragraph-1"></a>
- **1.** ollessaan toisen palveluksessa,

<a id="chapter-30-section-5-subsection-1-paragraph-2"></a>
- **2.** toimiessaan yhteisön tai säätiön hallintoneuvoston tai hallituksen jäsenenä, toimitusjohtajana, tilintarkastajana tai selvitysmiehenä taikka niihin rinnastettavassa tehtävässä,

<a id="chapter-30-section-5-subsection-1-paragraph-3"></a>
- **3.** suorittaessaan tehtävää toisen puolesta tai muuten luottamuksellisessa liikesuhteessa tai

<a id="chapter-30-section-5-subsection-1-paragraph-4"></a>
- **4.** yrityksen saneerausmenettelyn yhteydessä,

<a id="chapter-30-section-5-subsection-2"></a>
#### \(2\)

on tuomittava, jollei teosta ole muualla laissa säädetty ankarampaa rangaistusta, yrityssalaisuuden rikkomisesta sakkoon tai vankeuteen enintään kahdeksi vuodeksi\.

<a id="chapter-39"></a>
## 39 luku Velallisen rikoksista

<a id="chapter-39-section-2"></a>
### 2 § Velallisen petos

<a id="chapter-39-section-2-subsection-1"></a>
#### \(1\)

Velallinen, joka hankkiakseen itselleen tai toiselle oikeudetonta taloudellista hyötyä konkurssi\-, ulosmittaus\-, velkajärjestely\- tai saneerausmenettelyssä

<a id="chapter-39-section-2-subsection-1-paragraph-1"></a>
- **1.** salaa omaisuuttaan,

<a id="chapter-39-section-2-subsection-1-paragraph-2"></a>
- **2.** ilmoittaa kokonaan tai osittain perusteettoman taikka valeoikeustoimeen perustuvan velvoitteen,

<a id="chapter-39-section-2-subsection-1-paragraph-3"></a>
- **3.** antaa muun väärän tai harhaanjohtavan tiedon velkojien kannalta merkityksellisestä seikasta, tai

<a id="chapter-39-section-2-subsection-1-paragraph-4"></a>
- **4.** jättää ilmoittamatta velan,

<a id="chapter-39-section-2-subsection-2"></a>
#### \(2\)

on tuomittava velallisen petoksesta sakkoon tai vankeuteen enintään kahdeksi vuodeksi\.
