### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä päätöksessä määrätään merenkulkulaitoksen maksullisista suoritteista ja niiden maksuperusteista sekä julkisoikeudellisista suoritteista perittävistä kiinteistä maksuista\.

<a id="section-2"></a>
### 2 § Kiinteämaksuiset julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain [\(150/92\) 6 §:n](<https://www.finlex.fi/fi/lainsaadanto/1992/150#chp_2__sec_6>) 2 momentissa tarkoitettuja maksullisia julkisoikeudellisia suoritteita, joista merenkulkulaitos perii oheisessa liitteessä olevien maksutaulukoiden mukaiset kiinteät maksut, ovat seuraavat suoritteet:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** luotsaus \(liite 1\);

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** alusrekisterisuoritteet sekä muut yleisen osaston suoritteet \(liite 2\);

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** aikataulun mukainen yhteysalusliikenne \(liite 3\);

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** merenkulun tarkastustoiminnan suoritteet sekä muut merenkulkuosaston suoritteet \(liite 4\); sekä

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** linjaluotsin tutkinto \(liite 5\)\.

<a id="section-3"></a>
### 3 § Omakustannusarvon mukaiset julkisoikeudelliset suoritteet

<a id="section-3-subsection-1"></a>
#### \(1\)

Maksullisia julkisoikeudellisia suoritteita, joista merenkulkulaitos perii suoritteen omakustannusarvon mukaisesti määräämänsä maksun, ovat seuraavat merenkulun tarkastustoiminnan suoritteet:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** katsastukset ja tarkastukset, joista säädetään tai määrätään:

<a id="section-3-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** alusten katsastuksista annetussa asetuksessa [\(748/83\)](<https://www.finlex.fi/fi/lainsaadanto/1983/748>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** vuokraveneiden turvallisuudesta annetussa asetuksessa [\(438/83\)](<https://www.finlex.fi/fi/lainsaadanto/1983/438>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** aluksista aiheutuvan vesien pilaantumisen ehkäisemisestä annetussa asetuksessa [\(635/93\)](<https://www.finlex.fi/fi/lainsaadanto/1993/635>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** kalastusaluksista annetussa asetuksessa [\(531/61\)](<https://www.finlex.fi/fi/lainsaadanto/1961/531>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** paineastia\-asetuksessa [\(549/73\)](<https://www.finlex.fi/fi/lainsaadanto/1973/549>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** laivaväen asuintiloista aluksella annetussa asetuksessa [\(518/76\)](<https://www.finlex.fi/fi/lainsaadanto/1976/518>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-g"></a>
  - **g.** alusten varalaidasta kotimaanliikenteessä annetussa asetuksessa [\(855/88\)](<https://www.finlex.fi/fi/lainsaadanto/1988/855>);

<a id="section-3-subsection-1-paragraph-1-subparagraph-h"></a>
  - **h.** kansainvälisessä lastiviivayleissopimuksessa, 1966 \(SopS 52/68\);

<a id="section-3-subsection-1-paragraph-1-subparagraph-i"></a>
  - **i.** Suomen tasavallan ja Sosialististen neuvostotasavaltojen liiton välillä Itämeren lastiviivoista tehdyssä sopimuksessa \(SopS 26/88\); sekä

<a id="section-3-subsection-1-paragraph-1-subparagraph-j"></a>
  - **j.** yleisillä teillä olevien lauttojen varusteista ja niiden liikenteen valvomisesta annetussa liikenneministeriön päätöksessä [\(221/88\)](<https://www.finlex.fi/fi/lainsaadanto/1988/221>);

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** aluksen jäämaksuluokan määrääminen; sekä

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** tarkastus, jolla todetaan, onko aluksella öljysuojarahastosta annetun lain 2 §:n 1 momentin tarkoittama kaksoispohja\.

<a id="section-4"></a>
### 4 § Maksulliset liiketaloudelliset suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja suoritteita, jotka merenkulkulaitos hinnoittelee liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** merenkulkulaitoksen toimialaan kuuluvat suunnittelu\-, rakentamis\- ja rakennuttamistehtävät, tutkimukset, mittaukset, luotaukset, haraukset ja muut työsuoritukset;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** merenkulkulaitoksen aluksen, kulkuneuvon tai tukialusretkikunnan toimeksiannosta suorittama kuljetus, hinaus, avustustehtävä, vuokraus tai muu työsuoritus;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** merenkulun turvalaitteet;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** painotuotteet ja muu tietoaineisto;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** valokopiot, telekopiot, sähköiset tallenteet sekä muut jäljennökset tai otteet merenkulkulaitoksen hallussa olevasta asiakirjasta; sekä

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** muut toimeksiantoon perustuvat merenkulkulaitoksen suoritteet\.

<a id="section-5"></a>
### 5 § Voimaantulo

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1995\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
