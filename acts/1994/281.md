# Valtioneuvoston päätös kihlakuntien virastotyypistä ja kielellisestä jaotuksesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erilliset virastot ovat kihlakunnissa, joihin kuuluvat Helsingin kaupunki, Hämeenlinnan kaupunki, Joensuun kaupunki, Jyväskylän kaupunki, Kotkan kaupunki, Kuopion kaupunki, Lahden kaupunki, Lappeenrannan kaupunki, Oulun kaupunki, Porin kaupunki, Tampereen kaupunki, Turun kaupunki ja Vaasan kaupunki\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Muissa kihlakunnissa on kihlakunnanvirasto\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Kihlakunnat ovat suomen\- tai ruotsinkielisiä tai kaksikielisiä seuraavasti:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan lääni

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Turun ja Porin lääni

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Kymen lääni

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Vaasan lääni

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Muut läänit

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä joulukuuta 1996\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä päätöksen täytäntöönpanon edellyttämiin toimenpiteisiin\.
