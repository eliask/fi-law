# Liikenneministeriön päätös postipalveluista

<a id="section-1"></a>
### 1 § Peruspalvelut

<a id="section-1-subsection-1"></a>
#### \(1\)

Postin peruspalveluun kuuluu kirje tai muu alle kaksi kilogrammaa painava postilähetys\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Peruspalveluun kuuluvat postilähetykset on jaettava jokaisena työpäivänä postitoimintalain 7 §:ssä säädetyllä tavalla\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Kansalaisille tulee järjestää mahdollisuus jättää peruspalveluun kuuluvia postilähetyksiä postilaitoksen kuljetettavaksi kohtuullisen matkan päässä asunnostaan sijaitsevaan keräilypisteeseen\.

<a id="section-2"></a>
### 2 § Voimaantulo

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 3 päivänä helmikuuta 1994\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimiin\.
