<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä lakia sovelletaan valtion, tai rekisteröidyn yhteisön tai säätiön järjestämään koulutukseen, josta säädetään:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** perusopetuslaissa \(628/1998\);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** lukiolaissa \(629/1998\);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ammatillisesta koulutuksesta annetussa laissa \(531/2017\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** vapaasta sivistystyöstä annetussa laissa \(632/1998\);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** taiteen perusopetuksesta annetussa laissa \(633/1998\)\.
