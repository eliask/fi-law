# Valtioneuvoston asetus rakennuksissa käytettävien energiamuotojen kertoimien lukuarvoista

- Statute: [`788/2017`](<https://www.finlex.fi/fi/laki/ajantasa/2017/788>)

## Contents

- [1 §](#section-1)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maankäyttö\- ja rakennuslain [\(132/1999\) 117 g §:ssä](<https://www.finlex.fi/fi/lainsaadanto/1999/132>) tarkoitetut rakennuksissa käytettävät energiamuotojen kertoimien lukuarvot ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** sähkö 1,20;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kaukolämpö 0,50;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kaukojäähdytys 0,28;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** fossiiliset polttoaineet 1,00;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** rakennuksessa käytettävät uusiutuvat polttoaineet 0,50\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2018\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan rakennuksissa käytettävien energiamuotojen kertoimien lukuarvoista annettu valtioneuvoston asetus [\(9/2013\)](<https://www.finlex.fi/fi/lainsaadanto/2013/9>)\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Tämän asetuksen voimaan tullessa vireillä olevaan hankkeeseen sovelletaan tämän asetuksen voimaan tullessa voimassa olleita säännöksiä\.
