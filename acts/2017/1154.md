### 2 § Ministeriön toimialan virastot, laitokset, toimielimet ja yhteisöt

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Terveyden ja hyvinvoinnin laitos;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Lääkealan turvallisuus\- ja kehittämiskeskus;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Sosiaali\- ja terveysalan lupa\- ja valvontavirasto;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Säteilyturvakeskus;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** sosiaaliturva\-asioiden muutoksenhakulautakunta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** työterveyslaitos;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** työsuojeluhallinto;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Alko Oy;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** työsuojelurahasto;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Koulutusrahasto;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** työttömyysvakuutusrahasto;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** työehtosopimuksen yleissitovuuden vahvistamislautakunta;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Lääkkeiden hintalautakunta;

<a id="section-2-subsection-1-paragraph-14"></a>

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** terveydenhuollon palveluvalikoimaneuvosto;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** STUK International Oy\.

<a id="section-3"></a>
### 3 § Ministeriön organisaatio

<a id="section-3-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriössä on seuraavat osastot:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** sosiaali\- ja terveydenhuollon ohjausosasto;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** sosiaaliturva\- ja vakuutusosasto;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** hyvinvointi\- ja palveluosasto;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** työ\- ja tasa\-arvo\-osasto\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Osastojen ulkopuolella ovat erillisyksiköinä johdon tuki \-yksikkö, hallintoyksikkö, viestintäyksikkö ja kansainvälisten asioiden yksikkö\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Osastojen ja erillisyksiköiden välisestä työnjaosta säädetään ministeriön työjärjestyksessä\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Osastot voivat jakautua yksiköihin ja tulosryhmiin ja erillisyksiköt voivat jakautua tulosryhmiin\. Osaston ja erillisyksikön sisäisestä organisaatiosta määrätään tarvittaessa ministeriön sisäisessä määräyksessä, jonka osaston tai erillisyksikön päällikkö vahvistaa\.

<a id="section-3-subsection-5"></a>
#### \(5\)

Sisäinen tarkastus toimii kansliapäällikön alaisena\.
