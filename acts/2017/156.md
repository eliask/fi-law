# Valtioneuvoston asetus erityistason sairaanhoidon erityisvastuualueista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erityistason sairaanhoidon järjestämistä varten olevat erityisvastuualueet ja niihin kuuluvat sairaanhoitopiirit ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Helsingin yliopistollisen keskussairaalan erityisvastuualue, johon kuuluvat:

<a id="section-1-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** Helsingin ja Uudenmaan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** Kymenlaakson sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** Etelä\-Karjalan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** Päijät\-Hämeen sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Turun yliopistollisen sairaalan erityisvastuualue, johon kuuluvat:

<a id="section-1-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** Varsinais\-Suomen sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** Satakunnan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** Vaasan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Tampereen yliopistollisen sairaalan erityisvastuualue, johon kuuluvat:

<a id="section-1-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** Pirkanmaan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** Kanta\-Hämeen sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** Etelä\-Pohjanmaan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Kuopion yliopistollisen sairaalan erityisvastuualue, johon kuuluvat:

<a id="section-1-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** Pohjois\-Savon sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** Keski\-Suomen sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** Etelä\-Savon sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** Itä\-Savon sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-4-subparagraph-e"></a>
  - **e.** Pohjois\-Karjalan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Oulun yliopistollisen sairaalan erityisvastuualue, johon kuuluvat:

<a id="section-1-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** Pohjois\-Pohjanmaan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** Keski\-Pohjanmaan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-5-subparagraph-c"></a>
  - **c.** Kainuun sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-5-subparagraph-d"></a>
  - **d.** Länsi\-Pohjan sairaanhoitopiiri;

<a id="section-1-subsection-1-paragraph-5-subparagraph-e"></a>
  - **e.** Lapin sairaanhoitopiiri\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2018\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan erityistason sairaanhoidon erityisvastuualueista annettu valtioneuvoston asetus [\(812/2012\)](<https://www.finlex.fi/fi/lainsaadanto/2012/812>)\.
