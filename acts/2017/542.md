<a id="section-1"></a>
### 1 § Lain soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä lakia sovelletaan tutkintoihin ja perusopetuksen ja lukion oppimääriin, joista säädetään seuraavissa laeissa ja niiden nojalla annetuissa asetuksissa:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** perusopetuslaki \(628/1998\);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** lukiolaki \(629/1998\);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ammatillisesta koulutuksesta annettu laki \(531/2017\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** ammattikorkeakoululaki \(932/2014\);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** yliopistolaki \(558/2009\);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Maanpuolustuskorkeakoulusta annettu laki \(1121/2008\);

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Rikosseuraamusalan koulutuskeskuksesta annettu laki \(1316/2006\);

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Poliisiammattikorkeakoulusta annettu laki \(1164/2013\);

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Pelastusopistosta annettu laki \(607/2006\)\.
