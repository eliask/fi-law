<a id="section-4"></a>
### 4 § Määritelmät

<a id="section-4-subsection-1"></a>
#### \(1\)

Tässä laissa tarkoitetaan:

<a id="section-4-subsection-1-paragraph-10"></a>
- **10.** kalastusoikeuden haltijalla:

<a id="section-4-subsection-1-paragraph-10-subparagraph-a"></a>
  - **a.** yhteisen vesialueen osakaskuntaa;

<a id="section-4-subsection-1-paragraph-10-subparagraph-b"></a>
  - **b.** osakaskuntaan kuulumattoman vesialueen omistajaa;

<a id="section-4-subsection-1-paragraph-10-subparagraph-c"></a>
  - **c.** kiinteistön omistajaa, jos kiinteistölle kuuluu 21 kohdassa tarkoitettuja erityisperusteisia kalastusetuuksia;

<a id="section-4-subsection-1-paragraph-10-subparagraph-d"></a>
  - **d.** kalastusrasitteeseen tai muuhun oikeusperusteeseen perustuen kalastusoikeutta hallinnoivaa luonnollista tai oikeushenkilöä;

<a id="section-4-subsection-1-paragraph-10-subparagraph-e"></a>
  - **e.** kalastusoikeutta omistajaa kuulematta siirrettävissä olevaan vuokrasopimukseen perustuen hallinnoivaa luonnollista tai oikeushenkilöä; tai

<a id="section-4-subsection-1-paragraph-10-subparagraph-f"></a>
  - **f.** kalastuksesta Tenojoen vesistössä Suomen ja Norjan välillä tehdyn sopimuksen \(SopS 42/2017 \) kalastussääntöä sovellettaessa a–e alakohdassa säädetyn lisäksi yhteisen vesialueen osakaskuntaan kuuluvaa osakaskiinteistöä;

<a id="section-4-subsection-1-paragraph-22"></a>
- **22.** kalastussäännöllä:

<a id="section-4-subsection-1-paragraph-22-subparagraph-a"></a>
  - **a.** Suomen ja Ruotsin välillä tehtyä rajajokisopimusta \(SopS 91/2010\) ja siihen sisältyvää kalastussääntöä;

<a id="section-4-subsection-1-paragraph-22-subparagraph-b"></a>
  - **b.** Suomen ja Norjan välillä kalastuksesta Tenojoen vesistössä tehtyä sopimusta ja siihen liittyvää kalastussääntöä; sekä

<a id="section-4-subsection-1-paragraph-22-subparagraph-c"></a>
  - **c.** Suomen tasavallan ja Norjan kuningaskunnan välillä kalastuksesta Näätämöjoen kalastusalueella tehtyä sopimusta \(SopS 18/1978\) ja siihen liittyvää kalastussääntöä\.

<a id="section-78"></a>
### 78 § Eräiden Ylä\-Lapin vesistöjen kalakantojen suojelu

<a id="section-78-subsection-1"></a>
#### \(1\)

Valtioneuvoston asetuksella voidaan Tenojoen, Näätämöjoen, Paatsjoen, Tuulomajoen ja Uutuanjoen vesistöalueiden kalakantojen suojelemiseksi asettaa kieltoja, ehtoja, rajoituksia ja toimenpiteitä, jotka koskevat:

<a id="section-78-subsection-1-paragraph-1"></a>
- **1.** elävien kalojen, mädin sekä kalastuksessa käytettävien kulkuneuvojen, välineiden, pyydysten ja syöttikalojen siirtämistä mainituille alueille;

<a id="section-78-subsection-1-paragraph-2"></a>
- **2.** syöttikalojen käyttämistä alueilla harjoitettavassa kalastuksessa;

<a id="section-78-subsection-1-paragraph-3"></a>
- **3.** alueiden ulkopuolelta tuotujen kalojen perkausta alueiden luonnonvesissä;

<a id="section-78-subsection-1-paragraph-4"></a>
- **4.** perkausjätteiden laskemista alueiden luonnonvesiin; sekä

<a id="section-78-subsection-1-paragraph-5"></a>
- **5.** kalastusvälineiden ja kalastuksessa käytettävien kulkuneuvojen desinfiointia ja kuivausta\.

<a id="section-118"></a>
### 118 § Kalastusrikkomus

<a id="section-118-subsection-1"></a>
#### \(1\)

Joka tahallaan tai huolimattomuudesta

<a id="section-118-subsection-1-paragraph-1"></a>
- **1.** käyttää 46 tai 49 §:ssä tai niiden nojalla taikka kalastussäännössä kiellettyä kalastustapaa, pyyntimenetelmää tai kalastusvälinettä, pitää kiellettyä kalastusvälinettä kalastukseen käytettävässä kulkuneuvossa tai muutoin siten, että se on pyyntiä varten helposti käsillä,

<a id="section-118-subsection-1-paragraph-2"></a>
- **2.** kalastaa alueella, jossa kalastaminen on 7, 52–54, 59, 65–68, 70 tai 71 §:ssä tai niiden nojalla taikka kalastussäännössä kielletty tai sitä on rajoitettu,

<a id="section-118-subsection-1-paragraph-3"></a>
- **3.** kalastaa 52 tai 53 §:n nojalla kiellettynä aikana tai 55 §:n nojalla tai kalastussäännössä säädettynä rauhoitusaikana kalaa taikka sanottuna aikana pitää vedessä sen pyyntiin sopivaa pyydystä,

<a id="section-118-subsection-1-paragraph-4"></a>
- **4.** kalastaa 60 §:ssä tarkoitetun sopimuksen täytäntöönpanemiseksi asetetun rajoituksen vastaisesti,

<a id="section-118-subsection-1-paragraph-5"></a>
- **5.** pyydystää 56 §:n tai kalastussäännön vastaisesti ali\- tai ylimittaista kalaa, tai ottaa kalan saaliiksi 52 tai 53 §:n nojalla säädetyn tai määrätyn taikka kalastussäännössä säädetyn kiellon vastaisesti,

<a id="section-118-subsection-1-paragraph-6"></a>
- **6.** laiminlyö 58 §:ssä tai kalastussäännössä säädetyn vapauttamisvelvollisuuden,

<a id="section-118-subsection-1-paragraph-7"></a>
- **7.** tuo maahan muun kuin Suomessa luonnonvaraisena esiintyvän kalalajin tai sen kannan tai sukusoluja ilman 77 §:n 2 momentissa säädettyä lupaa tai lupaehdon vastaisesti,

<a id="section-118-subsection-1-paragraph-8"></a>
- **8.** istuttaa vesialueelle kalalajin tai sen kannan 73 tai 74 §:ssä tai 75 §:n nojalla säädetyn taikka kalastussäännön vastaisesti,

<a id="section-118-subsection-1-paragraph-9"></a>
- **9.** laiminlyö 48 §:ssä tai kalastussäännössä säädetyn pyydyksen merkitsemisvelvollisuuden tai pitää pyydysmerkkiä vedessä 48 §:ssä säädetyn vastaisesti,

<a id="section-118-subsection-1-paragraph-10"></a>
- **10.** rikkoo 91 §:ssä säädettyä kalan ensimyyntikieltoa tai 55 §:ssä säädettyä rauhoitetun kalan myyntikieltoa,

<a id="section-118-subsection-1-paragraph-11"></a>
- **11.** säilyttää rapuja tai käyttää rapujen pyyntiin käytettäviä välineitä 51 §:n vastaisesti,

<a id="section-118-subsection-1-paragraph-12"></a>
- **12.** laiminlyö 62 §:ssä säädetyn sivusaalista koskevan ilmoitusvelvollisuuden taikka kalastussäännössä tai kalastuksesta Tenojoen vesistössä Norjan kanssa tehdyn sopimuksen lainsäädännön alaan kuuluvien määräysten voimaansaattamisesta ja soveltamisesta annetun lain \(176/2017\) 7 §:ssä säädetyn saalistietoa koskevan ilmoitusvelvollisuuden,

<a id="section-118-subsection-1-paragraph-13"></a>
- **13.** rikkoo 78 §:n nojalla säädettyjä kieltoja, ehtoja tai rajoituksia tai

<a id="section-118-subsection-1-paragraph-14"></a>
- **14.** rikkoo kalastussäännössä säädettyä veneen\- tai moottorinkäyttökieltoa,

<a id="section-118-subsection-2"></a>
#### \(2\)

on tuomittava, jollei teosta muualla laissa säädetä ankarampaa rangaistusta, kalastusrikkomuksesta sakkoon\.
