### 1 § Maksulliset julkisoikeudelliset suoritteet

<a id="section-1-subsection-1"></a>
#### \(1\)

Patentti\- ja rekisterihallituksen julkisoikeudellisista suoritteista perittävät maksut määräytyvät suoriteryhmäkohtaisen kustannusvastaavuuden perusteella Patentti\- ja rekisterihallituksen suoritteista perittävistä maksuista annetun lain 2 ja 3 §:n mukaisesti\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Suoriteryhmän muodostavat Patentti\- ja rekisterihallituksen maksuista annetun lain 2 §:n 3 kohdan määritelmän mukaiset seuraavat julkisoikeudellisten suoritteiden kokonaisuudet:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** patenttiasiat;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** hyödyllisyysmalliasiat;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** integroidun piirin piirimalliasiat;

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** teollisoikeusasiamiesasiat;

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** kaupparekisteriasiat;

<a id="section-1-subsection-2-paragraph-6"></a>
- **6.** tavaramerkkiasiat;

<a id="section-1-subsection-2-paragraph-7"></a>
- **7.** mallioikeusasiat;

<a id="section-1-subsection-2-paragraph-8"></a>
- **8.** yrityskiinnitysasiat;

<a id="section-1-subsection-2-paragraph-9"></a>
- **9.** säätiöasiat;

<a id="section-1-subsection-2-paragraph-10"></a>
- **10.** yhdistysasiat;

<a id="section-1-subsection-2-paragraph-11"></a>
- **11.** uskonnollisia yhdyskuntia koskevat asiat; sekä

<a id="section-1-subsection-2-paragraph-12"></a>
- **12.** tilintarkastusasiat

<a id="section-2"></a>
### 2 § Alle omakustannusarvon hinnoitellut julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Patentti\- ja rekisterihallituksen suoritteista perittävistä maksuista annetun lain 3 §:n 4 momentissa tarkoitettuja suoritteita, joista Patentti\- ja rekisterihallitus perii suoritteen omakustannusarvoa alhaisemman maksun, ovat seuraavat suoritteet taikka suoriteryhmät:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yhdistysasiat

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** uskonnollisia yhdyskuntia koskevat asiat\.

<a id="section-3"></a>
### 3 § Maksuttomat suoritteet

<a id="section-3-subsection-1"></a>
#### \(1\)

Patentti\- ja rekisterihallituksen suoritteista perittävistä maksuista annetun lain 3 §:n 4 momentissa tarkoitettuja suoritteita, joista Patentti\- ja rekisterihallitus jättää maksun perimättä, ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Patentti\- ja rekisterihallituksen tai teollisoikeusasiamieslautakunnan ylläpitämiin rekistereihin merkittyjen oikeuksien lakkaamisilmoitukset;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** viranomaisen lähettämän tiedonannon merkitseminen Patentti\- ja rekisterihallituksen pitämiin rekistereihin;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** Patentti\- ja rekisterihallituksen antamat vastaanottotodistukset;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** tilinpäätöstietojen julkistaminen;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** osoitteenmuutoksen merkitseminen Patentti\- ja rekisterihallituksen tai teollisoikeusasiamieslautakunnan ylläpitämiin rekistereihin;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** elinkeinotoiminnan lopettamista tai yhteisön purkautumista koskeva ilmoitus Patentti\- ja rekisterihallituksen rekisteriin sekä niihin liittyvät lopputilitysilmoitukset;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** jäljennös yhtiöjärjestyksestä, säännöistä ja yhtiösopimuksesta sekä ote kaupparekisteristä, jotka Patentti\- ja rekisterihallitus antaa perus\- tai muutosilmoituksen rekisteröinnin yhteydessä;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** yrityskiinnityksen kuolettaminen;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** henkilön omaa eroa koskeva ilmoitus, joka perustuu todettuun rekisterimerkintärikokseen;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** perustamisluvan saaneen säätiön rekisteröinti;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** valtuuskuntaa tai muuta sellaista säätiölain \(109/30\) 10 b §:n tarkoittamaa toimielintä koskeva muutos;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** nimen, kotipaikan ja asiamiehen muutosta koskeva merkintä patenttirekisteriin, hyödyllisyysmallirekisteriin, piirimallirekisteriin, tavaramerkkirekisteriin, mallirekisteriin ja teollisoikeusasiamieslautakunnan ylläpitämiin rekistereihin;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** patenttiyhteistyösopimuksen sääntöjen 44\.3\(b\), 45bis\.7\(c\) ja 71\.2\(b\) mukaiset viitejulkaisujen kopiot ensimmäisen kopio\-sarjan osalta;

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** Patentti\- ja rekisterihallituksen vakiomuotoiset tietoluovutukset valtion virastoille ja laitoksille sekä tuomioistuimille ja muille lainkäyttöelimille, kunnallisille viranomaisille, eduskunnalle ja sen virastoille ja laitoksille, tasavallan presidentin kanslialle, Ahvenanmaan maakunnassa toimiville maakunnan, kunnan ja valtion viranomaisille, tieteelliseen tutkimukseen ja lakisääteiseen tutkintoon johtavaa koulutusta järjestäville oppilaitoksille sekä Kansaneläkelaitokselle; sekä

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** kaupparekisteriin ennen 1\.1\.1994 rekisteröidyn elinkeinonharjoittajan rekisteriin merkityissä tehtävissä olevien henkilöiden henkilötunnusten ilmoittamista koskevat asiat\.

<a id="section-4"></a>
### 4 § Liiketaloudelliset suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Patentti\- ja rekisterihallituksen suoritteista perittävistä maksuista annetun lain 4 §:ssä tarkoitettuja suoritteita, jotka Patentti\- ja rekisterihallitus hinnoittelee liiketaloudellisin perustein, ovat seuraavat tilauksesta toimitettavat tai saatavilla olevat suoritteet:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** selvitykset ja tutkimukset;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** koulutus\- ja konsultointipalvelut;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** julkaisut;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** jäljenteet;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** rekisteri\- ja tietokantapalvelut;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** Patentti\- ja rekisterihallituksen hallinnassa olevien laitteiden ja tilojen käyttö; sekä

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** muut tilaukseen tai toimeksiantoon perustuvat palvelut ja suoritteet\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Viranomaisten toiminnan julkisuudesta annetun lain \(621/1999\) 34 §:n 2 momentissa tarkoitetusta tiedon esille hakemisesta sekä saman lain 34 §:n 3 momentissa tarkoitettujen kopioiden ja tulosteiden antamisesta perittävistä maksuista päättää Patentti\- ja rekisterihallitus ottaen huomioon, mitä viranomaisten toiminnan julkisuudesta annetun lain 34 §:ssä säädetään\.

<a id="section-5"></a>
### 5 § Julkisoikeudellisten suoritteiden hinnoittelu

<a id="section-5-subsection-1"></a>
#### \(1\)

Pykälissä 1 ja 2 tarkoitetut maksut sisältyvät tämän asetuksen liitteenä olevaan taulukkoon\.

<a id="section-6"></a>
### 6 § Voimaantulo

<a id="section-6-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2018 ja se on voimassa 31 päivään joulukuuta 2019 saakka\.
