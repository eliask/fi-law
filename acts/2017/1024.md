# Valtioneuvoston asetus käräjäoikeuksien tuomiopiireistä yrityksen saneerausta koskevissa asioissa

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Yrityksen saneerauksesta annetun lain [\(47/1993\) 67 §:n](<https://www.finlex.fi/fi/lainsaadanto/1993/47#chp_10__sec_67>) 1 momentissa tarkoitettujen käräjäoikeuksien tuomiopiirit yrityksen saneerausta koskevissa asioissa ovat seuraavat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Ahvenanmaan käräjäoikeuden tuomiopiiri käsittää Ahvenanmaan käräjäoikeuden tuomiopiirin;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Helsingin käräjäoikeuden tuomiopiiri käsittää Helsingin käräjäoikeuden tuomiopiirin;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Länsi\-Uudenmaan käräjäoikeuden tuomiopiiri käsittää Itä\-Uudenmaan ja Länsi\-Uudenmaan käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Oulun käräjäoikeuden tuomiopiiri käsittää Kainuun, Lapin ja Oulun käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaan käräjäoikeuden tuomiopiiri käsittää Kanta\-Hämeen ja Pirkanmaan käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjanmaan käräjäoikeuden tuomiopiiri käsittää Etelä\-Pohjanmaan, Keski\-Suomen, Pohjanmaan ja Satakunnan käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Pohjois\-Savon käräjäoikeuden tuomiopiiri käsittää Etelä\-Savon, Pohjois\-Karjalan ja Pohjois\-Savon käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Päijät\-Hämeen käräjäoikeuden tuomiopiiri käsittää Etelä\-Karjalan, Kymenlaakson ja Päijät\-Hämeen käräjäoikeuksien tuomiopiirit;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Varsinais\-Suomen käräjäoikeuden tuomiopiiri käsittää Varsinais\-Suomen käräjäoikeuden tuomiopiirin\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2019\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan käräjäoikeuksien tuomiopiireistä yrityksen saneerausta koskevissa asioissa annettu valtioneuvoston asetus [\(339/2013\)](<https://www.finlex.fi/fi/lainsaadanto/2013/339>)\.
