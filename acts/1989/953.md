# Verohallituksen päätös ilmoittamisvelvollisuuden rajoittamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Veroilmoituksessa ei ilmoiteta seuraavia Suomesta saatuja tuloja:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** rahana maksettua eläkettä tai elinkorkoa, paitsi jos eläke tai elinkorko on tulo\- ja varallisuusverolain 119§:n 2 kohdan ja 120§:n 3 kohdan mukaan veronalaisia varoja tai jos kyseessä on tulo\- ja varallisuusverolain 63 ja 164§:n mukaan veronalainen syytinki,

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** sairausvakuutuslain nojalla saatua päivä\-, äitiys\-, isyys\- tai vanhempainrahaa taikka muuta mainitun lain, kansaneläkelain tai potilasvahinkolain nojalla saatua korvausta tulojen tai elatuksen vähentymisestä,

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** pakollisen tapaturma\- eikä liikennevahinkoturvan nojalla tulojen tai elatuksen vähentymisestä saatua korvausta,

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** tulo\- ja varallisuusverolain 58§:ssä tarkoitetun henkilövakuutuksen nojalla maksettavaa vakuutussuoritusta, vakuutusmaksujen palautuksena ja takaisin ostolla saatua määrää,

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** muun kuin 2, 3 tai 4 kohdassa tarkoitetun vakuutuksen nojalla maksettua päivärahaa tai muuta vastaavaa tulojen ja elatuksen vähentymisestä maksettua korvausta,

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** tartuntatautilain \(583/86\) nojalla saatua päivärahaa tai ansionmenetyksestä saatua korvausta,

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** rikosvahinkojen korvaamisesta valtion varoista annetun lain \(935/73\) nojalla tulojen tai elatuksen vähentymisestä maksettua korvausta,

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** työttömyysturvalain \(602/84\) nojalla maksettua etuutta eikä työllisyyskoulutuksesta annetussa laissa \(31/76\) tarkoitettua koulutustukea,

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** työllisyysasetuksen \(737/87\) nojalla yrittäjäksi ryhtyvälle työttömälle, työelämään harjaantumassa olevalle työttömälle tai vajaakuntoiselle maksettua työllistämistukea ja ammatinvalinnan ohjauksessa olevalle henkilölle ammatinvalinnan ohjauksesta annetun lain nojalla \(43/60\) maksettua vastaavaa tukea,

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** opintotukilain 10 a§:ssä \(95/87\) tarkoitettua aikuisopintorahana maksettua ansionmenetyskorvausta,

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** lapsen kotihoidon tukea,

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** valtion virkamieslain \(755/86\) nojalla maksettua toistuvaa korvausta,

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** tulo\- ja varallisuusverolain \(1240/88\) 93§:ssä ja 94§:n 1 momentissa tarkoitettua merityötuloa eikä

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** sellaisia rakennustoiminnan aloilla maksettuja lomapalkkoja, lomakorvauksia ja lomaltapaluurahoja \(lomarahoja\), jotka työnantaja on valtakunnallisen työehtosopimuksen mukaan tilittänyt Postipankkiin työnantajajärjestön erityiselle postisiirtotilille\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Verovelvollisen, jolla ei ole ollut veronalaisia varoja eikä muita kuin 1§:ssä mainittuja ilmoittamisvelvollisuudesta vapautettuja tuloja, ei tarvitse kehotuksetta antaa veroilmoitusta\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä joulukuuta 1989\. Päätöstä sovelletaan ensimmäisen kerran vuodelta 1989 toimitettavaan verotukseen\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Päätöksellä kumotaan verohallituksen ilmoittamisvelvollisuuden rajoittamisesta 22 päivänä syyskuuta 1988 antama päätös \(844/88\)\.
