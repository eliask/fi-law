<a id="section-7"></a>
### 7 §

<a id="section-7-subsection-1"></a>
#### \(1\)

Lennonvarmistusosastossa on järjestelmäsuunnittelutoimisto, lennonjohtotoimisto sekä viesti\- ja sähkötoimisto\.

<a id="section-7a"></a>
### 7 a §

<a id="section-7a-subsection-1"></a>
#### \(1\)

Järjestelmäsuunnittelutoimisto käsittelee asiat, jotka koskevat:

<a id="section-7a-subsection-1-paragraph-1"></a>
- **1.** ilmaliikenteen suunnittelua ja tutkimusta lennonvarmistuspalvelujen kannalta sekä

<a id="section-7a-subsection-1-paragraph-2"></a>
- **2.** lennonjohto\- ja lennonvarmistusjärjestelmien kehittämistä\.

<a id="section-8"></a>
### 8 §

<a id="section-8-subsection-1"></a>
#### \(1\)

Lennonjohtotoimisto käsittelee asiat, jotka koskevat:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** ilmaliikennepalvelua;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** ilmaliikenteen etsintä\- ja pelastuspalvelua;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** ilmailutiedotus\- ja ilmailukarttapalvelua;

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** ilmailun tarvitsemaa sääpalvelua;

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** lennonvarmistuksen tietoliikennettä; sekä

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** lentosääntöjä\.

<a id="section-9"></a>
### 9§

<a id="section-9-subsection-1"></a>
#### \(1\)

Viesti\- ja sähkötoimisto käsittelee asiat, jotka koskevat:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** lennonvarmistus\-, navigaatio\- ja telejärjestelmien teknistä suunnittelua, hankintaa ja toimivuutta;

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** lennonvarmistuspalvelun tietoliikennetekniikkaa;

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** ilmailuhallinnon valaistus\- ja sähköjärjestelmiä;

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** ilmailuhallinnon sähkölaitoksia ja sähköenergian hankintaa ja jakelua;

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** lennonvarmistus\-, navigaatio\- ja telejärjestelmien asennuksia, korjauksia ja huoltoa; sekä

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** ilmailuhallinnon elektroniikkahuoltojen toimintaa ja kehittämistä\.

<a id="section-36"></a>
### 36 §

<a id="section-36-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena ilmailuhallinnon virkoihin on:

<a id="section-36-subsection-1-paragraph-8"></a>
- **8.** järjestelmäsuunnittelutoimiston ja lennonjohtotoimiston toimistopäälliköllä virkaan soveltuva korkeakoulututkinto sekä perehtyneisyys toimiston toimialaan kuuluviin tehtäviin;
