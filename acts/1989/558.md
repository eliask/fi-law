# Asetus tapaturmaviraston eräiden virkojen perustamisesta ja lakkauttamisesta

<a id="section-1"></a>
### 1 § Tapaturmavirasto

<a id="section-1-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yksi A 22 palkkausluokkaan kuuluva taloussihteerin virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** neljä A 18 palkkausluokkaan kuuluvaa esittelijän virkaa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** neljä A 14 palkkausluokkaan kuuluvaa toimistosihteerin virkaa; ja

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kaksi A 7 palkkausluokkaan kuuluvaa tallentajan virkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Lakkautetaan:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** yksi A 20 palkkausluokkaan kuuluva kamreerin virka;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** yksi A 20 palkkausluokkaan kuuluva tarkastavan ortopedilääkärin virka;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** yksi A 5 palkkausluokkaan kuuluva konekirjoittajan virka;

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** kaksi A 3 palkkausluokkaan kuuluvaa siivoojan virkaa; ja

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** yhdeksän A 2 palkkausluokkaan kuuluvaa toimistovirkailijan virkaa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä joulukuuta 1989\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella perustetut virat voidaan täyttää ensimmäisellä kerralla niitä haettavaksi julistamatta\.
