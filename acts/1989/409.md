<a id="section-1"></a>
### 1 § Turun ja Porin lääninhallitus

<a id="section-1-subsection-1"></a>
#### \(1\)

Lakkautetaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yksi A 17 palkkausluokkaan kuuluva lääninarkistonhoitajan virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** yksi A 16 palkkausluokkaan kuuluva lääninkirjaajan virka;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** yksi A 16 palkkausluokkaan kuuluva asuntosihteerin virka; ja

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kolme A 5 palkkausluokkaan kuuluvaa toimistovirkailijan virkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Perustetaan:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** yksi A 23 palkkausluokkaan kuuluva ylitarkastajan virka;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** yksi A 19 palkkausluokkaan kuuluva suunnittelijan virka;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** yksi A 14 palkkausluokkaan kuuluva osastosihteerin virka;

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** yksi A 11 palkkausluokkaan kuuluva toimistosihteerin virka; ja

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** yksi A 10 palkkausluokkaan kuuluva toimistosihteerin virka\.

<a id="section-2"></a>
### 2 § Keski\-Suomen lääninhallitus

<a id="section-2-subsection-1"></a>
#### \(1\)

Lakkautetaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yksi A 22 palkkausluokkaan kuuluva taloussihteerin virka;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yksi A 17 palkkausluokkaan kuuluva lääninkirjaajan virka;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** yksi A 15 palkkausluokkaan kuuluva osastosihteerin virka;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** yksi A 13 palkkausluokkaan kuuluva lääninkassanhoitajan virka; ja

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** yksi A 5 palkkausluokkaan kuuluva osa\-aikaisen \(56,8 %\) toimistovirkailijan virka\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Perustetaan:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** yksi A 23 palkkausluokkaan kuuluva erikoissuunnittelijan virka;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** yksi A 21 palkkausluokkaan kuuluva taloussihteerin virka;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** yksi A 16 palkkausluokkaan kuuluva osastosihteerin virka; ja

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** yksi A 14 palkkausluokkaan kuuluva osastosihteerin virka\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä syyskuuta 1989\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tällä asetuksella perustetut virat saadaan niitä ensimmäistä kertaa täytettäessä täyttää haettavaksi julistamatta\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Toimenpiteisiin tällä asetuksella perustettujen virkojen täyttämiseksi voidaan ryhtyä jo ennen sitä ajankohtaa, josta virka on perustettu, ei kuitenkaan ennen kuin eduskunta on käsitellyt asian\.
