# Liikenneministeriön päätös kunnista, joiden alueella peritään korkeampaa televisiolupamaksua

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Korkeampaa televisiolupamaksua peritään seuraavissa kunnissa, joiden alueella Ruotsin televisio\-ohjelman Etelä\-Suomen jakeluverkon näkyvyys on riittävä:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Espoo

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Helsinki

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Inkoo

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Järvenpää

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Karjaa

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Kauniainen

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Kerava

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kirkkonummi

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Nurmijärvi

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Sipoo

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Siuntio

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** Vantaa

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Televisiolupamaksu peritään koko lupakauden ajalta sen kunnan mukaan, jossa vastaanotin sijaitsee lupakauden alussa\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä kesäkuuta 1989 ja sitä sovelletaan televisiolupiin, joiden lupakausi alkaa sanottuna päivänä tai sen jälkeen\.
