# Asetus ilmatieteen laitoksen suoritteista perittävistä maksuista annetun asetuksen muuttamisesta

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Jäljempänä mainituista suoritteista peritään maksu seuraavasti:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Suoraan tilastoihin tai havaintopäiväkirjoihin perustuvat selvitykset, ensimmäiseltä arkin lehdeltä 95 mk kultakin seuraavalta arkin lehdeltä 59 mk

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Lämmitystä varten lasketut astepäivät, luvulta 23 mk

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Sanomalehtiä varten laaditut ennustekartat, kappaleelta 25 mk
