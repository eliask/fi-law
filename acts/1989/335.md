# Sisäasiainministeriön päätös erään tilan, tilanosien ja alueiden siirtämisestä Iisalmen kaupungista ja Vieremän kunnasta Sonkajärven kuntaan

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Iisalmen kaupungista siirretään Sonkajärven kuntaan seuraavat tila, tilanosa ja alueet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Ryhälänmäen kylässä kokonaan tila Karjala 5:15;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Ulmalan kylässä osa tilasta Itikka 3:13; sekä

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen tilan ja tilanosan alueella olevat yleiset ja yhteiset alueet\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Vieremän kunnasta siirretään Sonkajärven kuntaan Pyöriän kylässä Poikainmäen tilasta 1:33 Saarisenpuron niittypalsta sekä tilanosan alueella olevat yleiset ja yhteiset alueet\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1990\.
