<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Keskusosasto käsittelee asiat, jotka koskevat:

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** sotilasoikeudenhoitoa sekä ministeriön edustamista tuomioistuimissa ja muissa viranomaisissa sekä laitoksissa ja yhteisöissä, jollei asia kuulu ministeriön muun osaston käsiteltäviin;

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Sotilasasiainosasto käsittelee asiat, jotka koskevat:

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** puolustusvoimien osien kokoonpanoa ja sijoitusta yhteistyössä järjestelyosaston kanssa;

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Järjestelyosasto käsittelee asiat, jotka koskevat:

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** virkoihin ja tehtäviin liittyvää tulo\- ja menoarvion valmistelua sekä hallinnonalan henkilöstökoulutusta;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** hallinnonalan organisaatiota;

<a id="section-9"></a>
### 9 §

<a id="section-9-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikkö,

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** hallitusneuvoksia, joista yksi toimii keskusosaston ja yksi kiinteistöosaston osastopäällikkönä,

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** sotilasasiainosaston osastopäällikkö,

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** järjestelyosaston ja talousosaston osastopäälliköt, joilla on puolustusasiainneuvoksen arvonimi,

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** rakennusosaston osastopäällikkönä toimiva rakennusneuvos,

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksia, toimistopäällikköinä,

<a id="section-9-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköitä,

<a id="section-9-subsection-1-paragraph-8"></a>
- **8.** vanhempia ja nuorempia hallitussihteereitä,

<a id="section-9-subsection-1-paragraph-9"></a>
- **9.** vanhempia ja nuorempia toimistoesiupseereita sekä vanhempia toimistoupseereita,

<a id="section-9-subsection-1-paragraph-10"></a>
- **10.** arkkitehti, maanmittausinsinööri ja insinöörejä,

<a id="section-9-subsection-1-paragraph-11"></a>
- **11.** metsänhoitaja ja aluemetsänhoitajia,

<a id="section-9-subsection-1-paragraph-12"></a>
- **12.** neuvotteleva virkamies, pääsihteeri ja yleissihteeri,

<a id="section-9-subsection-1-paragraph-13"></a>
- **13.** ylitarkastajia, taloustarkastajia ja tarkastajia,

<a id="section-9-subsection-1-paragraph-14"></a>
- **14.** erikoistutkija,

<a id="section-9-subsection-1-paragraph-15"></a>
- **15.** esittelijöitä,

<a id="section-9-subsection-1-paragraph-16"></a>
- **16.** kamreereita ja apulaiskamreereita,

<a id="section-9-subsection-1-paragraph-17"></a>
- **17.** tiedotuspäällikkö ja suunnittelija,

<a id="section-9-subsection-1-paragraph-18"></a>
- **18.** suunnittelusihteeri, henkilöstösihteeri, laskentasihteeri ja osastosihteereitä,

<a id="section-9-subsection-1-paragraph-19"></a>
- **19.** metsätalousinsinööri,

<a id="section-9-subsection-1-paragraph-20"></a>
- **20.** maanmittausteknikko ja agrologi,

<a id="section-9-subsection-1-paragraph-21"></a>
- **21.** sotilaspalotoimen tarkastaja,

<a id="section-9-subsection-1-paragraph-22"></a>
- **22.** ministerin sihteeri, hankintasihteeri ja sihteereitä,

<a id="section-9-subsection-1-paragraph-23"></a>
- **23.** notaari ja kirjaajia,

<a id="section-9-subsection-1-paragraph-24"></a>
- **24.** arkistonhoitaja, pääkirjanpitäjä, kartoittaja, tekstinkäsittelijöitä, piirtäjiä, toimistosihteereitä, konekirjoittajia ja toimistovirkailijoita, sekä

<a id="section-9-subsection-1-paragraph-25"></a>
- **25.** ylivirastomestari ja virastomestari\.

<a id="section-9-subsection-2"></a>
#### \(2\)

Lisäksi puolustusministeriössä voi olla tilapäisiä virkamiehiä ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-10"></a>
### 10 §

<a id="section-10-subsection-1"></a>
#### \(1\)

Lisäksi vaaditaan erityisenä kelpoisuusvaatimuksena:

<a id="section-10-subsection-1-paragraph-7"></a>
- **7.** toimistopäälliköltä, neuvottelevalta virkamieheltä, pääsihteeriltä, yleissihteeriltä, ylitarkastajalta ja taloustarkastajalta virkaan soveltuva ylempi korkeakoulututkinto sekä kiinteistöosaston toimistopäälliköltä lisäksi hyvä perehtyneisyys hallintotoimiin;

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** talousosaston toimistopäälliköltä, taloustarkastajalta, tarkastajalta, kamreerilta ja laskentasihteeriltä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyyttä tiliviraston tehtäviin;

<a id="section-10-subsection-1-paragraph-20"></a>
- **20.** apulaiskamreerilta ja pääkirjanpitäjältä virkaan soveltuva korkeakoulututkinto tai merkonomin tutkinto sekä valtion maksuliikkeen ja kirjanpidon tuntemus;

<a id="section-10-subsection-1-paragraph-23a"></a>
- **23a.** agrologilta agrologin tutkinto;

<a id="section-10-subsection-1-paragraph-24a"></a>
- **24a.** hankintasihteeriltä merkonomin tutkinto;

<a id="section-12"></a>
### 12 §

<a id="section-12-subsection-1"></a>
#### \(1\)

Neuvottelevan virkamiehen nimittää valtioneuvosto\.

<a id="section-23"></a>
### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Muista kuin 22§:ssä tarkoitetuista ministeriössä päätettävistä asioista ratkaisee:

<a id="section-23-subsection-1-paragraph-1"></a>
- **1.** keskusosaston päällikkönä toimiva hallitusneuvos asiat, jotka koskevat:

<a id="section-23-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** puolustushallinnon alalla voimassa olevien työehtosopimusten soveltamista sekä hallinnonalan työsopimussuhteisen henkilöstön palkkausta ja muita työehtoja;

<a id="section-23-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** niitä puolustushallinnon henkilöstön palkkausehtoja tai muita niihin verrattavia palvelussuhteen ehtoja, joista ministeriö lainsäädännön taikka virkaehtosopimusten nojalla päättää;

<a id="section-23-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** ministeriön virkamiesten ikälisiä ja vuosilomakorvauksia;

<a id="section-23-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** vahingonkorvauksia;

<a id="section-23-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** asevelvollisuuslain 45§:n 3 momentissa tarkoitettuja hakemuksia; sekä

<a id="section-23-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** rintamasotilastunnuksesta annetussa asetuksessa \(772/69\), rintamapalvelustunnuksesta annetussa asetuksessa \(554/78\) ja rintamatunnuksesta annetussa asetuksessa \(256/88\) tarkoitettuja valituksia;
