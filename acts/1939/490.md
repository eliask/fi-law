# Laki Suomen Pankin ohjesäännön 6 §:n väliaikaisesta muuttamisesta\.

- Version: `1939-12-13`
- LawVM tree hash: `e1df11358882553e3a4ac11df86daa6098f633d7ef9a5a499d44378be92500cf`

## Contents

- [6 §\.](#section-6)

<a id="section-6"></a>
### 6 §\.

<a id="section-6-subsection-1"></a>
#### \(1\)

Pankin setelien liikkeessä oleva määrä saa toistaiseksi nousta enintään tuhatkahdeksansataa miljoonaa markkaa suuremmaksi, kuin mitä

<a id="section-6-subsection-2"></a>
#### \(2\)

pankin kultakassa;

<a id="section-6-subsection-3"></a>
#### \(3\)

pankin riidattomat saatavat sen ulkomaisilta asiamiehiltä;

<a id="section-6-subsection-4"></a>
#### \(4\)

ulkomailla maksettavat ulkomaan rahan

<a id="section-6-subsection-5"></a>
#### \(5\)

määräiset vekselit;

<a id="section-6-subsection-6"></a>
#### \(6\)

ulkomaisissa pörsseissä noteeratut ulkomaiset obligatiot;

<a id="section-6-subsection-7"></a>
#### \(7\)

ulkomaan rahan määräiset erääntyneet korkoliput;

<a id="section-6-subsection-8"></a>
#### \(8\)

ulkomaiset setelit; ja

<a id="section-6-subsection-9"></a>
#### \(9\)

kotimaiset vekselit, joiden maksupäivään ei ole kolmea kuukautta pitempää aikaa, yhteensä ovat\.

<a id="section-6-subsection-10"></a>
#### \(10\)

Pankin kultavarat kirjataan enintään arvoon, jonka mukaan kilo hienoa kultaa maksaisi viisikymmentätuhatta markkaa\.

<a id="section-6-subsection-11"></a>
#### \(11\)

Pankin ulkomaan rahan määräiset varat, joista puhutaan 1 momentissa, kirjataan enintään niiden käypään arvoon tai hankintahintaan, milloin tämä on edellistä alempi, obligatiot kuitenkin enintään nimellisarvoon\.

<a id="section-6-subsection-12"></a>
#### \(12\)

Liikkeessä oleviin seteleihin luetaan myös pankin Suomen rahan määräiset osoitukset ja muut vaadittaessa maksettavat sitoumukset, niin myös myönnettyjen kassakreditiivien ja konttokuranttien nostamattomat määrät\.
