# Asetus maan jakamisesta sotilaslääneihin ja maanpuolustusalueisiin

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Puolustusvoimien tehtäviä varten maa jaetaan sotilaslääneihin ja lähinnä poikkeusolojen varalta muodostettaviin maanpuolustusalueisiin niin kuin tässä asetuksessa säädetään\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Sotilasläänejä ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Helsingin sotilaslääni, joka muodostuu Espoon, Helsingin, Kauniaisten ja Vantaan kaupungeista;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Uudenmaan sotilaslääni, joka muodostuu Uudenmaan liiton ja Itä\-Uudenmaan liiton toimialueista Helsingin sotilasläänin aluetta lukuun ottamatta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Hämeen sotilaslääni, joka muodostuu Hämeen liiton, Päijät\-Hämeen liiton ja Pirkanmaan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Turun ja Porin sotilaslääni, joka muodostuu Varsinais\-Suomen liiton ja Satakuntaliiton toimialueista sekä Ahvenanmaan maakunnasta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Vaasan sotilaslääni, joka muodostuu Etelä\-Pohjanmaan liiton, Keski\-Pohjanmaan liiton ja Österbottens förbund\-Pohjanmaan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Kymen sotilaslääni, joka muodostuu Kymenlaakson liiton ja Etelä\-Karjalan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Mikkelin sotilaslääni, joka muodostuu Etelä\-Savon maakuntaliiton toimialueesta;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Pohjois\-Karjalan sotilaslääni, joka muodostuu Pohjois\-Karjalan liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Kuopion sotilaslääni, joka muodostuu Savon liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Keski\-Suomen sotilaslääni, joka muodostuu Keski\-Suomen liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Oulun sotilaslääni, joka muodostuu Pohjois\-Pohjanmaan liiton ja Kainuun liiton toimialueista; sekä

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Lapin sotilaslääni, joka muodostuu Lapin liiton toimialueesta\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Maanpuolustusalueita ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** pohjoinen maanpuolustusalue, joka käsittää Oulun ja Lapin sotilasläänin;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** läntinen maanpuolustusalue, joka käsittää Helsingin, Uudenmaan, Hämeen, Turun ja Porin, Vaasan ja Keski\-Suomen sotilasläänin; sekä

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** itäinen maanpuolustusalue, joka käsittää Kymen, Mikkelin, Pohjois\-Karjalan ja Kuopion sotilasläänin\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tarkempia määräyksiä tämän asetuksen täytäntöönpanosta antaa tarvittaessa puolustusministeriö\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 1993\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan maan jakamisesta sotilaslääneihin ja sotilaspiireihin 28 päivänä tammikuuta 1977 annettu asetus \(120/77\) siihen myöhemmin tehtyine muutoksineen\.

<a id="section-5-subsection-3"></a>
#### \(3\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä sen täytäntöönpanemiseksi tarpeellisiin toimenpiteisiin\.
