<a id="section-1"></a>
### 1 § Muutetaan:

<a id="section-1-subsection-1"></a>
#### \(1\)

Hämeenlinnan ammatillinen opettajakorkeakoulu

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yksi C 61 palkkausluokkaan kuuluva kurssitoimenjohtajan virka samaan palkkausluokkaan kuuluvaksi johtajan \(lisäkoulutus\) viraksi;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kaksi C 57 palkkausluokkaan kuuluvaa yliopettajan \(kasvatus\- ja opetusopilliset aineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(kasvatusaineet\) viroiksi;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kolme C 57 palkkausluokkaan kuuluvaa yliopettajan \(ammattiaineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(ainedidaktiikka\) viroiksi;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** yksitoista C 51 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet ja muut aineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(ainedidaktiikka\) viroiksi; ja

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** yksi C 42 palkkausluokkaan kuuluva lehtorin \(ammatilliset aineet ja muut aineet\) virka samaan palkkausluokkaan kuuluvaksi yliopettajan \(ainedidaktiikka\) viraksi\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Sijoitettuina Hämeenlinnan ammatillisen opettajakorkeakoulun liikenneopetuskeskukseen

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** neljä C 51 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet ja muut aineet\) virkaa samaan palkkausluokkaan kuuluviksi lehtorin \(ainedidaktiikka\) viroiksi\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Jyväskylän ammatillinen opettajakorkeakoulu

<a id="section-1-subsection-3-paragraph-1"></a>
- **1.** kolme C 57 palkkausluokkaan kuuluvaa yliopettajan \(kasvatus\- ja opetusopilliset aineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(kasvatusaineet\) viroiksi;

<a id="section-1-subsection-3-paragraph-2"></a>
- **2.** kolme C 57 palkkausluokkaan kuuluvaa yliopettajan \(ammattiaineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(ainedidaktiikka\) viroiksi;

<a id="section-1-subsection-3-paragraph-3"></a>
- **3.** viisi C 51 palkkausluokkaan kuuluvaa lehtorin \(kasvatus\- ja opetusopilliset aineet, erityisopetus, oppilaanohjaus\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(kasvatusaineet\) viroiksi;

<a id="section-1-subsection-3-paragraph-4"></a>
- **4.** kymmenen C 51 palkkausluokkaan kuuluvaa lehtorin \(ammatilliset aineet ja muut aineet\) virkaa samaan palkkausluokkaan kuuluviksi yliopettajan \(ainedidaktiikka\) viroiksi; ja

<a id="section-1-subsection-3-paragraph-5"></a>
- **5.** yksi C 61 palkkausluokkaan kuuluva kurssitoimenjohtajan virka samaan palkkausluokkaan kuuluvaksi johtajan \(lisäkoulutus\) viraksi\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä elokuuta 1990\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Entisen viran haltija siirtyy ilman eri toimenpiteitä nimeltään muutetun viran haltijaksi\.
