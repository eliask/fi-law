### 1 § Ministeriön osastot

<a id="section-1-subsection-1"></a>
#### \(1\)

Kauppa\- ja teollisuusministeriössä on:

<a id="section-3"></a>
### 3 § Yleinen osasto

<a id="section-3-subsection-1"></a>
#### \(1\)

Yleinen osasto käsittelee asiat, jotka koskevat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** taloussuunnittelua, laskentatointa sekä suunnittelu\- ja seurantajärjestelmiä,

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** tulo\- ja menoarvioehdotusta sekä erityismenoarviota,

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** ministeriön toimialan yleistä tehokkuus\- ja talousvalvontaa, hallinnon kehittämistä sekä tietojärjestelmien ja automaattisen tietojenkäsittelyn yhteensovittamista koko ministeriötä koskevilta osiltaan,

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** virka\- ja työsuhteita, koulutusta sekä muita henkilöstöhallinnollisia kysymyksiä,

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** lainsäädäntöä, mikäli asia ei kuulu muun osaston käsiteltäviin tai mikäli se koskee useamman kuin yhden osaston toimialaa,

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** viranomaisille annettavia esityksiä ja lausuntoja, mikäli ne koskevat useamman kuin yhden osaston toimialaa,

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** ministeriölle tilivirastona kuuluvia asioita,

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** ministeriön edustusta oikeusasioissa, mikäli asia ei kuulu ministeriön muun osaston käsiteltäviin,

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** työjärjestystä ja yhteistoimintasopimusta,

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** asiakirjojen kirjaamista, lähettämistä ja arkistointia sekä nimikirjanpitoa,

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** elinkeinojen valvontaa,

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** kuluttajakysymyksiä,

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** taloudellisen kilpailun edistämistä,

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** elintarvikevalvontaa,

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** ulkomaalaisen oikeutta toimia suomalaisissa yhtiöissä ja omistaa niissä osakkeita sekä eräiden suomalaisten yhteisöjen oikeutta omistaa ja hallita kiinteätä omaisuutta,

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** Saimaan Kanavalaivat Oy ja Suomen Vientiluotto Oy \-nimisiä osakeyhtiöitä, sekä

<a id="section-3-subsection-1-paragraph-17"></a>
- **17.** muita ministeriön toimialaan kuuluvia asioita, mikäli tässä asetuksessa ei ole toisin säädetty\.

### 10 § Kauppaosasto

<a id="section-10-subsection-1"></a>
#### \(1\)

Kauppaosasto käsittelee asiat, jotka koskevat:

<a id="section-10-subsection-1-paragraph-1"></a>

<a id="section-10-subsection-1-paragraph-2"></a>
- **2.** kansainvälistä taloudellista yhteistyötä,

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** viennin edistämistä,

<a id="section-10-subsection-1-paragraph-4"></a>

- **7.** matkailua,

<a id="section-10-subsection-1-paragraph-8"></a>
- **8.** polttoaineiden tuontia,

- **9.** valtion varmuusvarastointia, ei kuitenkaan polttoaineiden varmuusvarastojen rakentamiseen ja rakennusten hoitoon liittyviä kysymyksiä, turvavarastointia, velvoitevarastointia ja muuta materiaalisen huoltovarmuuden kehittämistä, ohjausta ja valvontaa,

- **14.** valtion hankintakeskusta, sekä

### 15§ Teollisuusosasto

<a id="section-15-subsection-1"></a>
#### \(1\)

Teollisuusosasto käsittelee asiat, jotka koskevat:

<a id="section-15-subsection-1-paragraph-1"></a>
- **1.** yleistä teollisuuspolitiikkaa,

<a id="section-15-subsection-1-paragraph-2"></a>
- **2.** teollisuuteen ja geologiaan liittyvää tutkimus\- ja kehittämistyötä,

<a id="section-15-subsection-1-paragraph-3"></a>
- **3.** teollisuuspoliittisesti merkittävää teollisuuden rahoitusta,

<a id="section-15-subsection-1-paragraph-4"></a>
- **4.** alueellista teollisuus\- ja siihen liittyvää elinkeinopolitiikkaa yhteistyössä yrityskehitysosaston kanssa,

<a id="section-15-subsection-1-paragraph-5"></a>
- **5.** Kehitysaluerahasto Oy \-nimistä osakeyhtiötä omistajavalvontaan kuuluvien kysymysten osalta,

<a id="section-15-subsection-1-paragraph-6"></a>
- **6.** teollisuuden ja muun yritystoiminnan koulutuksen kehittämistä, siltä osin kuin nämä asiat eivät kuulu yrityskehitysosaston tehtäviin,

<a id="section-15-subsection-1-paragraph-7"></a>
- **7.** luonnonvarojen teollisen hyväksikäytön suunnittelua,

<a id="section-15-subsection-1-paragraph-8"></a>
- **8.** teknillisen tarkastustoiminnan valvontaa, lukuun ottamatta sähkö\- ja ydinenergia\-alaan kuuluvaa teknillistä tarkastusta,

<a id="section-15-subsection-1-paragraph-9"></a>
- **9.** teknologiapolitiikkaa sekä kansainvälistä teknillistä ja teknillistaloudellista yhteistyötä,

<a id="section-15-subsection-1-paragraph-10"></a>
- **10.** tuotannollista toimintaa harjoittavia valtioenemmistöisiä osakeyhtiöitä,

<a id="section-15-subsection-1-paragraph-11"></a>
- **11.** patentti\- ja rekisterihallitusta,

<a id="section-15-subsection-1-paragraph-12"></a>
- **12.** Valtiontakuukeskusta,

<a id="section-15-subsection-1-paragraph-13"></a>
- **13.** avaruusteknologiaa,

<a id="section-15-subsection-1-paragraph-14"></a>
- **14.** ulkomaalaisten omistamia ja hallitsemia yrityksiä yhteistyössä yleisen osaston kanssa, sekä

<a id="section-15-subsection-1-paragraph-15"></a>
- **15.** osaston käsiteltäviin asioihin liittyvää lainsäädäntöä\.

- **1.** yritystalouden toimisto,

<a id="section-16-subsection-2-paragraph-2"></a>
- **2.** teollisuustoimisto,

<a id="section-16-subsection-2-paragraph-3"></a>
- **3.** valtionyhtiöiden toimisto,

<a id="section-16-subsection-2-paragraph-4"></a>
- **4.** teknologian toimisto,

<a id="section-16-subsection-2-paragraph-5"></a>
- **5.** teknillisen tarkastuksen toimisto, sekä

<a id="section-16-subsection-2-paragraph-6"></a>
- **6.** kansainvälisten asiain toimisto\.

<a id="section-16-subsection-3"></a>
#### \(3\)

Ryhmien ja toimistojen tehtävistä määrätään osaston työnjaossa\.

<a id="section-17"></a>
### 17§ Energiaosasto

<a id="section-17-subsection-1"></a>
#### \(1\)

Energiaosasto käsittelee asiat, jotka koskevat:

<a id="section-17-subsection-1-paragraph-1"></a>
- **1.** yleistä energiapolitiikkaa ja sen toteuttamista,

<a id="section-17-subsection-1-paragraph-2"></a>
- **2.** energiatalouteen liittyvää tutkimus\- ja kehittämistyötä,

<a id="section-17-subsection-1-paragraph-3"></a>
- **3.** energiahuoltoa ja \-tuotantoa sekä energian säästöä ja käyttöä,

<a id="section-17-subsection-1-paragraph-4"></a>
- **4.** energiatalouden rahoitusta,

<a id="section-17-subsection-1-paragraph-5"></a>
- **5.** poikkeusolojen energiahuollon turvaamista samoin kuin polttoaineiden varmuusvarastojen rakentamista ja hoitoa,

<a id="section-17-subsection-1-paragraph-7"></a>

<a id="section-17-subsection-1-paragraph-8"></a>
- **8.** sähkö\-, ydin\- ja säteilyturvallisuutta,

<a id="section-17-subsection-1-paragraph-9"></a>
- **9.** energiahuollon ja ympäristönsuojelun yhteisiä kysymyksiä,

<a id="section-17-subsection-1-paragraph-10"></a>
- **10.** energiahuoltoon liittyviä lunastusasioita, sekä

<a id="section-17-subsection-1-paragraph-11"></a>

<a id="section-28"></a>
### 28§ Ministeriön virkamiehet

<a id="section-28-subsection-1"></a>
#### \(1\)

Ministeriössä on kansliapäällikkö, kauppaosaston, teollisuusosaston, energiaosaston ja yrityskehitysosaston osastopäälliköt sekä yleisen osaston osastopäällikkönä toimiva hallitusneuvos, neuvottelevia virkamiehiä, hallitusneuvoksia, apulaisosastopäälliköitä, hallitusneuvos toimistopäällikkönä, vanhempi hallitussihteeri toimistopäällikkönä, vanhempia ja nuorempia hallitussihteereitä, toimistopäälliköitä, kaupallinen neuvos, tiedotuspäällikkö, ylitarkastajia ja tarkastajia, yritystutkijoita, erikoistutkijoita, tutkijoita, suunnittelijoita, koulutuspäällikkö, esittelijöitä, pääsihteereitä, kaupallisia sihteereitä, ylikielenkääntäjä, kielenkääntäjiä, yliaktuaari, ylikamreeri, kamreereja ja apulaiskamreeri, tiedotussihteereitä, taloustarkastajia, osastosihteereitä ja ministerin sihteereitä, kirjaaja, apulaistarkastajia sekä muita vakinaisia virkamiehiä\.

<a id="section-28-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä voi olla tulo\- ja menoarvion rajoissa tilapäisiä virkamiehiä sekä työsopimussuhteessa olevaa henkilökuntaa\.

<a id="section-28-subsection-3"></a>
#### \(3\)

Kauppaosaston, teollisuusosaston, energiaosaston ja yrityskehitysosaston osastopäälliköllä on ylijohtajan arvonimi\. Kauppaosaston apulaisosastopäälliköllä ja toimistopäälliköillä on kaupallisen neuvoksen arvonimi\. Teollisuusosaston apulaisosastopäälliköillä ja toimistopäälliköillä sekä energiaosaston ja yrityskehitysosaston toimistopäälliköillä on teollisuusneuvoksen arvonimi\.

<a id="section-30"></a>
### 30 §

<a id="section-30-subsection-1"></a>
#### \(1\)

Kansliapäällikön, osastopäällikön, apulaisosastopäällikön, hallitusneuvoksen, toimistopäällikön ja hallitussihteerin nimittämisestä on säädetty valtioneuvoston ohjesäännössä\.

<a id="section-30-subsection-2"></a>
#### \(2\)

Hallitusneuvoksen osastopäällikkönä ja neuvottelevan virkamiehen nimittää tasavallan presidentti valtioneuvoston esityksestä virkaa haettavaksi julistamatta\.

<a id="section-30-subsection-3"></a>
#### \(3\)

Hallitusneuvoksen toimistopäällikkönä, kaupallisen neuvoksen ja vanhemman hallitussihteerin toimistopäällikkönä nimittää tasavallan presidentti valtioneuvoston esityksestä\.

<a id="section-30-subsection-4"></a>
#### \(4\)

Osastosihteerin, häntä vastaavan ja häntä virka\-asemaltaan alemman virkamiehen nimittää sekä vastaavat tilapäiset virkamiehet ja vastaavan työsopimussuhteisen henkilöstön ottaa yleisen osaston osastopäällikkö\.

<a id="section-30-subsection-5"></a>
#### \(5\)

Muun henkilökunnan nimittää tai ottaa ministeri\.

<a id="section-30-subsection-6"></a>
#### \(6\)

Ministeriö määrää yleisen osaston hallitusneuvoksista toimistopäällikköinä, vanhemmista hallitussihteereistä toimistopäällikköinä ja toimistopäälliköistä yhden hallinnollisen toimiston, yhden elinkeinotoimiston, yhden elintarvikeasiain toimiston, yhden taloussuunnittelutoimiston sekä yhden taloustoimiston toimistopäälliköksi ja kauppaosaston toimistopäälliköistä yhden multilateraalikaupan toimiston, yhden yleisen toimiston ja yhden vienninedistämistoimiston toimistopäälliköksi sekä teollisuusosaston toimistopäälliköistä yhden yritystalouden toimiston, yhden teollisuustoimiston, yhden valtionyhtiöiden toimiston, yhden teknologian toimiston, yhden teknillisen tarkastuksen toimiston ja yhden kansainvälisten asiain toimiston toimistopäälliköksi sekä energiaosaston toimistopäälliköistä yhden energiapolitiikan toimiston, yhden energiateknologian toimiston, yhden energiankäytön toimiston, yhden energiantuotannon toimiston ja yhden ydinenergiatoimiston toimistopäälliköksi sekä yrityskehitysosaston toimistopäälliköistä toisen kehittämistoimiston ja toisen yritysrahoitustoimiston toimistopäälliköksi\.

<a id="section-31"></a>
### 31§

<a id="section-31-subsection-1"></a>
#### \(1\)

Virkavapauden, johon virkamiehellä on lain tai virkaehtosopimuksen nojalla oikeus, sekä tätä virkavapautta vastaavan vapautuksen työsopimussuhteiselle henkilöstölle myöntää yleisen osaston hallinnolliseen toimistoon määrätty toimistopäällikkö\.

<a id="section-31-subsection-2"></a>
#### \(2\)

Muun kuin 1 momentissa tarkoitetun virkavapauden tai vapautuksen myöntää:

<a id="section-31-subsection-2-paragraph-1"></a>
- **1.** tasavallan presidentin nimittämälle virkamiehelle enintään yhdeksi vuodeksi ministeri ja yli yhdeksi vuodeksi valtioneuvosto,

<a id="section-31-subsection-2-paragraph-2"></a>
- **2.** ministerin nimittämälle virkamiehelle enintään yhdeksi vuodeksi yleisen osaston osastopäällikkö ja yli yhdeksi vuodeksi ministeri,

<a id="section-31-subsection-2-paragraph-3"></a>
- **3.** yleisen osaston osastopäällikön nimittämälle virkamiehelle yleisen osaston osastopäällikkö, sekä

<a id="section-31-subsection-2-paragraph-4"></a>
- **4.** tilapäisille virkamiehille ja työsopimussuhteiselle henkilöstölle se, joka on heidät ottanut\.

<a id="section-32"></a>
### 32§

<a id="section-32-subsection-1"></a>
#### \(1\)

Avoinna olevan viran väliaikaisen hoitajan ottamisesta ja viran hoitamisesta virkavapauden aikana päättää se, joka 31§:n 2 momentin mukaan myöntää virkavapauden\.

<a id="section-33"></a>
### 33§ Virkamiesten tehtävät

<a id="section-33-subsection-1"></a>
#### \(1\)

Kansliapäällikön tehtävistä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\. Kansliapäällikkö käsittelee myös asiat, jotka ministeri niiden tärkeyden tai erityisen laadun takia on antanut hänen valmisteltavikseen ja esiteltävikseen\. Kansliapäällikkö voi pidättää käsiteltäväkseen asian, joka tämän asetuksen tai ministeriön työjärjestyksen mukaan kuuluisi ministeriön muulle virkamiehelle\.

<a id="section-34"></a>
### 34§

<a id="section-34-subsection-1"></a>
#### \(1\)

Osastopäällikön tulee:

<a id="section-34-subsection-1-paragraph-1"></a>
- **1.** johtaa osastonsa toimintaa ja valvoa, että osastolle kuuluvat asiat käsitellään huolellisesti ja tehokkaasti,

<a id="section-34-subsection-1-paragraph-2"></a>
- **2.** seurata osaston toimialalla tapahtuvaa kehitystä ja tehdä aloitteita lainsäädännöllisiksi ja muiksi uudistuksiksi, sekä

<a id="section-34-subsection-1-paragraph-3"></a>
- **3.** käsitellä ne osastolle kuuluvat asiat, jotka ministeriön työjärjestyksessä on hänelle määrätty, ja ne asiat, jotka hän pidättää käsiteltäväkseen\.

<a id="section-35"></a>
### 35§

<a id="section-35-subsection-1"></a>
#### \(1\)

Neuvottelevan virkamiehen ja apulaisosastopäällikön tulee:

<a id="section-35-subsection-1-paragraph-1"></a>
- **1.** osastopäällikön apuna johtaa osaston toimintaa ja valvoa, että ne asiat, joiden valvonnan osastopäällikkö on hänelle määrännyt, käsitellään huolellisesti ja tehokkaasti, sekä

<a id="section-35-subsection-1-paragraph-2"></a>
- **2.** käsitellä ne osastolle kuuluvat asiat, jotka osaston työnjaossa on hänelle määrätty tai jotka osastopäällikkö on hänen käsiteltäväkseen määrännyt\.

<a id="section-36"></a>
### 36 §

<a id="section-36-subsection-1"></a>
#### \(1\)

Teollisuusosaston neuvottelevista virkamiehistä yksi toimii osastopäällikön apuna teollisuuspolitiikan alaan liittyvissä tehtävissä, toinen yritystalouden alaan liittyvissä tehtävissä, kolmas teknologiapolitiikkaan ja koulutukseen liittyvissä tehtävissä sekä neljäs kansainvälisiin asioihin liittyvissä tehtävissä\. Lisäksi neuvottelevat virkamiehet suorittavat tarvittaessa ministerin, kansliapäällikön tai osastopäällikön erikseen määräämät tehtäväalueeseensa liittyvät tehtävät sekä avustavat tarpeen mukaan ministeriön muita osastoja tehtäväalueeseensa kuuluvien asioiden valmistelussa\.

<a id="section-36-subsection-2"></a>
#### \(2\)

Teollisuusosaston apulaisosastopäälliköistä yksi toimii osastopäällikön apuna teollisoikeudellisiin kysymyksiin ja teollisuuden erityisrahoitukseen liittyvissä tehtävissä, toinen innovaatiopolitiikkaan liittyvissä tehtävissä ja kolmas valtionyhtiöihin liittyvissä tehtävissä\.

<a id="section-36-subsection-3"></a>
#### \(3\)

Energiaosaston neuvotteleva virkamies toimii osastopäällikön apuna energiapolitiikan alaan liittyvissä tehtävissä\.

<a id="section-36-subsection-4"></a>
#### \(4\)

Neuvottelevien virkamiesten ja apulaisosastopäälliköiden tehtävistä määrätään tarkemmin osaston työnjaossa\.

<a id="section-37"></a>
### 37§

<a id="section-37-subsection-1"></a>
#### \(1\)

Mitä 34§:ssä on säädetty, koskee soveltuvin kohdin myös neuvottelevia virkamiehiä sekä apulaisosastopäälliköitä ja toimistopäälliköitä\.

<a id="section-38"></a>
### 38§

<a id="section-38-subsection-1"></a>
#### \(1\)

Tehtävien jaosta ministeriön osastojen kesken määrätään tarkemmin ministeriön työjärjestyksessä, jonka ministeriö vahvistaa\.

<a id="section-38-subsection-2"></a>
#### \(2\)

Virkamiesten tehtävistä ja työnjaosta osastoissa määrätään tarkemmin osastopäällikön vahvistamassa osaston työnjaossa\.

<a id="section-38-subsection-3"></a>
#### \(3\)

Yhteistoiminnassa ministeriön ja henkilöstön välillä noudatetaan, mitä yhteistoiminnasta valtion virastoissa ja laitoksissa annetussa laissa \(651/88\) on säädetty ja sen nojalla tehdyissä sopimuksissa määrätty\.

<a id="section-39"></a>
### 39§

<a id="section-39-subsection-1"></a>
#### \(1\)

Milloin syntyy epätietoisuutta siitä, kenen käsiteltäväksi jokin asia kuuluu, määrää siitä asianomainen osastopäällikkö, neuvotteleva virkamies, apulaisosastopäällikkö tai toimistopäällikkö sekä osastojen kesken kansliapäällikkö, jos siitä ei määrää ministeri\.

<a id="section-39-subsection-2"></a>
#### \(2\)

Vahvistetusta työnjaosta huolimatta kukin virkamies on velvollinen suorittamaan ne tehtävät, jotka ministeri, kansliapäällikkö tai asianomainen osastopäällikkö, neuvotteleva virkamies, apulaisosastopäällikkö tai toimistopäällikkö määrää\.

<a id="section-40"></a>
### 40§

<a id="section-40-subsection-1"></a>
#### \(1\)

Kansliapäällikön ollessa estynyt toimii hänen sijaisenaan ministerin määräämä osastopäällikkö\.

<a id="section-40-subsection-2"></a>
#### \(2\)

Osastopäälliköiden, neuvottelevien virkamiesten ja apulaisosastopäälliköiden sijaiset määrätään työjärjestyksessä\.

<a id="section-40-subsection-3"></a>
#### \(3\)

Muissa kuin 1 ja 2 momentissa tarkoitetuissa tapauksissa määrää tehtävien hoidosta virkamiehen estyneenä ollessa asianomainen osastopäällikkö\.

<a id="section-41"></a>
### 41§ Asioiden ratkaiseminen

<a id="section-41-subsection-1"></a>
#### \(1\)

Kansliapäällikön oikeudesta ratkaista ministeriössä päätettäviä asioita on voimassa, ellei jäljempänä ole toisin säädetty, mitä valtioneuvoston ohjesäännössä on säädetty\.

<a id="section-41-subsection-2"></a>
#### \(2\)

Osasto\-, apulaisosasto\- ja toimistopäälliköt sekä muut virkamiehet ratkaisevat jäljempänä 42\-61 §:ssä mainitut, toimialaansa kuuluvat ministeriössä päätettävät asiat, mikäli valtioneuvoston ohjesäännön 32§:stä ei muuta johdu tai ministeri, kansliapäällikkö tai osastopäällikkö ole pidättänyt asiaa ratkaistavakseen\.

<a id="section-42"></a>
### 42§

<a id="section-42-subsection-1"></a>
#### \(1\)

Osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-42-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista muulle viranomaiselle, ei kuitenkaan lain tai asetuksen säätämistä, muuttamista tai kumoamista koskevista ehdotuksista eikä tasavallan presidentin kanslialle, korkeimmalle oikeudelle, korkeimmalle hallinto\-oikeudelle, valtioneuvoston oikeuskanslerille tai eduskunnan oikeusasiamiehelle, paitsi milloin kysymys on osastopäällikön ratkaisemaa asiaa koskevasta lausunnosta,

<a id="section-42-subsection-1-paragraph-2"></a>
- **2.** osaston käytettäviksi asetettujen varojen käyttämistä, jollei näiden asioiden ratkaisemista ole osaston työnjaossa annettu muulle osaston virkamiehelle, sekä

<a id="section-42-subsection-1-paragraph-3"></a>
- **3.** pääosaltaan osaston toimialaan kuuluvien komiteoiden varojen käyttöä siltä osin kuin ne kuuluvat ministeriön ratkaistaviin sekä komiteanmietintöjen painos\- tai monistemäärää ja mietintöjen jakelua\.

<a id="section-42-subsection-2"></a>
#### \(2\)

Milloin 1 momentin 2 kohdassa tarkoitettuja varoja on asetettu toimiston käytettäväksi, ratkaisee toimistopäällikkö niiden käytön\.

<a id="section-42-subsection-3"></a>
#### \(3\)

Osastopäälliköllä on yksittäistapauksissa oikeus pidättää itselleen päätösvalta asioissa ja hänen alaisensa virkamiehen ollessa vuosilomalla tai estyneenä virkaansa hoitamasta ratkaista ne asiat, jotka tämän asetuksen tai erikseen annettavan määräyksen mukaan hänen alaisensa virkamies on oikeutettu ratkaisemaan\.

<a id="section-43"></a>
### 43§

<a id="section-43-subsection-1"></a>
#### \(1\)

Yleisen osaston osastopäällikkö ratkaisee 30§:n 4 momentissa, 31§:n 2 momentissa ja 42§:ssä mainittujen asioiden lisäksi asiat, jotka koskevat:

<a id="section-43-subsection-1-paragraph-1"></a>
- **1.** osastosihteerin, sitä vastaavien ja sitä alempien virkojen sekä vastaavien tilapäisten virkamiesten ja vastaavan työsopimussuhteisen henkilöstön sijoittamista ministeriön osastoihin,

<a id="section-43-subsection-1-paragraph-2"></a>
- **2.** 30§:n 4 momentissa tarkoitetun työsopimussuhteisen henkilöstön palkkauksen vahvistamista,

<a id="section-43-subsection-1-paragraph-3"></a>
- **3.** sivutoimiluvan myöntämistä osastosihteereille, heitä vastaaville ja heitä virka\-asemaltaan alemmille virkamiehille sekä vastaaville tilapäisille virkamiehille ja vastaavalle työsopimussuhteiselle henkilöstölle,

<a id="section-43-subsection-1-paragraph-4"></a>
- **4.** ministeriön yhteisistä määrärahoista maksettavia jakamattomia kulutus\- ja kalustomenoja sekä kansainvälisestä yhteistyöstä aiheutuvia muita menoja, sekä

<a id="section-43-subsection-1-paragraph-5"></a>
- **5.** muulle kuin Suomessa asuvalle Suomen kansalaiselle annettavia lupia olla prokuristina, osakeyhtiön perustajana, hallituksen jäsenenä, toimitusjohtajana ja toiminimen kirjoittajana\.

<a id="section-44"></a>
### 44§

<a id="section-44-subsection-1"></a>
#### \(1\)

Teollisuusosaston osastopäällikkö ratkaisee 42§:ssä mainittujen asioiden lisäksi asiat, jotka koskevat:

<a id="section-44-subsection-1-paragraph-1"></a>
- **1.** määrärahojen käyttämistä tutkimukseen ja julkaisutoimintaan tai näihin tarkoituksiin myönnettäviä valtionavustuksia, ei kuitenkaan silloin, kun käyttötarve tai valtionavustus yksittäistapauksessa ylittää 500 000 markkaa,

<a id="section-44-subsection-1-paragraph-2"></a>
- **2.** erityismenoarviossa nimettyjen yhteisöjen ja säätiöiden toiminnan tukemiseen myönnettäviä valtionavustuksia,

<a id="section-44-subsection-1-paragraph-3"></a>
- **3.** kansainvälisille järjestöille suoritettavia jäsenmaksuja, sekä

<a id="section-44-subsection-1-paragraph-4"></a>
- **4.** kansainväliseen tekniseen tutkimustoimintaan, julkisten palvelujen asiantuntemuksen vientiin ja teollisuuden kansainvälistymiskoulutukseen liittyviä enintään 500 000 markan määräisiä menoja\.

<a id="section-45-subsection-1-paragraph-2"></a>
- **2.** maaseudun sähköistämiseen myönnettäviä valtionavustuksia, ei kuitenkaan silloin, kun valtionavustus yksittäistapauksessa ylittää 500 000 markkaa,

<a id="section-45-subsection-1-paragraph-3"></a>
- **3.** energiainvestointeihin myönnettäviä valtionavustuksia, ei kuitenkaan silloin, kun avustuksen määrä yksittäistapauksessa ylittää 500 000 markkaa,

<a id="section-45-subsection-1-paragraph-4"></a>
- **4.** energiainvestointeihin myönnettäviä lainoja ja korkotukea, ei kuitenkaan silloin, kun lainan tai korkotuen määrä yksittäistapauksissa ylittää 500 000 markkaa,

<a id="section-45-subsection-1-paragraph-5"></a>
- **5.** energiaosaston toimialaan kuuluvia päätöksiä työllisyyslain \(275/87\) nojalla myönnettyjen avustusten maksamisesta silloin, kun avustuksiin osoitetut määrärahat on siirretty kauppa\- ja teollisuusministeriön käyttöön,

<a id="section-45-subsection-1-paragraph-6"></a>
- **6.** energia\-alan kansainvälisille järjestöille suoritettavia jäsenmaksuja, sekä

<a id="section-45-subsection-1-paragraph-7"></a>
- **7.** erityismenoarviossa nimettyjen yhteisöjen ja säätiöiden toiminnan tukemiseen myönnettäviä valtionavustuksia\.

### 46 §

<a id="section-46-subsection-1"></a>

Yrityskehitysosaston osastopäällikkö ratkaisee 42§:ssä mainittujen asioiden lisäksi asiat, jotka koskevat:

- **1.** määrärahojen käyttämistä tutkimukseen ja julkaisutoimintaan tai näihin tarkoituksiin myönnettäviä valtionavustuksia, ei kuitenkaan silloin, kun käyttötarve tai valtionavustus yksittäistapauksessa ylittää 500 000 markkaa,

<a id="section-46-subsection-1-paragraph-2"></a>

### 47§

<a id="section-47-subsection-1"></a>
#### \(1\)

<a id="section-47-subsection-2"></a>
#### \(2\)

Kauppaosaston apulaisosastopäällikkö ratkaisee osastolle kuuluvat valtion varmuusvarastointia koskevat asiat\.

<a id="section-47-subsection-3"></a>
#### \(3\)

Neuvottelevalla virkamiehellä ja apulaisosastopäälliköllä on oikeus, heidän alaisensa virkamiehen ollessa vuosilomalla tai estyneenä virkaansa hoitamasta, ratkaista ne asiat, jotka tämän asetuksen tai erikseen annettavan määräyksen mukaan hänen alaisensa virkamies on oikeutettu ratkaisemaan\.

### 62§

<a id="section-62-subsection-1"></a>
#### \(1\)

Osastopäälliköt, apulaisosastopäälliköt, toimistopäälliköt ja muut virkamiehet ratkaisevat edellä 43\-61§:ssä mainitut asiat esittelystä, kuitenkin niin, että 51§:ssä mainitut asiat ratkaistaan ilman esittelyä\.

<a id="section-62-subsection-2"></a>
#### \(2\)

Toimistopäälliköt ovat oikeutetut antamaan lausuntoja ja tiedotuksia käsiteltävinään olevista juoksevista asioista, ei kuitenkaan 42§:n 1 momentin 1 kohdassa mainituille viranomaisille eikä muille ministeriöille, paitsi milloin kysymys on toimistopäällikön ratkaisemaa asiaa koskevasta lausunnosta tai selityksestä\.

### 63§ Erinäisiä säännöksiä

<a id="section-63-subsection-1"></a>
#### \(1\)

<a id="section-64"></a>
### 64§

<a id="section-64-subsection-1"></a>

<a id="section-64-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin\.
