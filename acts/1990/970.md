# Valtioneuvoston päätös eräiden kuntien ja kunnan osien määräämisestä erityisalueiksi

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erityisalueiksi vuodeksi 1991 määrätään seuraavat kunnat ja kunnan osat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Lapin läänistä Kemijärvi, Salla, Savukoski, Tervola ja Ylitornio;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Oulun läänistä Haapajärvi, Hyrynsalmi, Kuhmo, Kuivaniemi, Pudasjärvi, Suomussalmi, Taivalkoski, Utajärvi, Vaala ja Vihanti;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Vaasan läänistä Alajärvi, Evijärvi, Isojoki, Korsnäs, Kortesjärvi, Lappajärvi ja Uusikaarlepyy;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen läänistä Jyväskylän maalaiskunnan Tikkakoski \(Tikkamannilan kylä\), Keuruu ja Multia;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Kuopion läänistä Keitele, Leppävirran Sorsakoski \(Osmajärven kylä\), Pielavesi, Varkaus ja Varpaisjärvi;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan läänistä Ilomantsi, Lieksa, Nurmes, Tohmajärvi, Tuupovaara, Valtimo ja Värtsilä;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Mikkelin läänistä Heinävesi, Kangaslampi, Mikkeli, Pieksämäki ja Pieksämäen maalaiskunta;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kymen läänistä Hamina ja Vehkalahti;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Hämeen läänistä Kuorevesi, Mänttä, Ruovesi, Vilppula ja Virrat;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Turun ja Porin läänistä Kankaanpää, Kihniö, Rauma ja Rauman maalaiskunta; sekä

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Uudenmaan läänistä Ruotsinpyhtää\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1991\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Valtionavustus, jota koskeva hakemus on toimitettu asianomaiselle viranomaiselle ennen tämän päätöksen voimaantuloa, voidaan kuitenkin myöntää sen suuruisena kuin se olisi ollut myönnettävissä ennen tämän päätöksen voimaantuloa voimassa olleiden päätösten nojalla\.
