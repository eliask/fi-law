# Sisäasiainministeriön päätös kuntajaon muuttamisesta eräiltä osin Evijärven, Luodon ja Pedersören kuntien välillä

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Kuntajakoa Evijärven, Luodon ja Pedersören kuntien välillä muutetaan siten, että kuntien rajat 2\-5§:ssä tarkoitettujen tilojen ja maarekisteriyksiköiden kohdalla yhtyvät muutoksen jälkeen 18 päivänä marraskuuta 1959 maarekisteriin merkityssä tilusvaihtotoimituksessa nro 95484 muodostuneisiin kameraalisiin kunnanrajoihin\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Luodon kunnasta siirretään Pedersören kuntaan Överlappforsin kylästä osa tilasta Esselvik 5:32\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Luodon kunnasta siirretään Evijärven kuntaan Sydänmaan kylästä osa tilasta Rönnbacka 3:6\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Pedersören kunnasta siirretään Luodon kuntaan Luodon kylästä rekisteriyksikkö Luodon kylän yhteismetsä Österbackenissa\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Evijärven kunnasta siirretään Luodon kuntaan Luodon kylästä rekisteriyksikkö Luodon kylän yhteismetsä Fulismossenissa\.

<a id="section-6"></a>
### 6§

<a id="section-6-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-7"></a>
### 7§

<a id="section-7-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1991\.
