<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Eläintautiasetuksen 1§:ssä tarkoitettuina valvottavina eläintauteina pidetään seuraavia eläintauteja:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** nautaeläinten tarttuva leukoosi

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** utaretulehdus pitoeläimiksi myytävillä nautaeläimillä

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** porsasyskä sikalassa, joka kuuluu koeryhmiä koeasemille lähettävien sikaloiden terveysvalvontaohjelmaan

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** aivastustauti, kuten edellä kohdassa 3

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** dysenteria, kuten edellä kohdassa 3

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** Haemophilus pleuropneumoniatartunta, kuten edellä kohdassa 3

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** Clostridium perfringens \-tyyppi C\-tartunta, kuten edellä kohdassa 3

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** hevosen näivetystauti \(anaemia infectiosa equorum\)

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** salmonellan aiheuttama tarttuva keskenvarsominen \(S\. abortus equi\)

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** muut salmonellatartunnat kotieläimillä paitsi edellä 2§:n 6 ja 10 sekä 3§:n 9 kohdissa mainitut

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** leptospiroosi

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** siipikarjan ornitoosi

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** minkkien virusripuli

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** kettusyyhy \(Sarcoptes scabiei var\. vulpis\)

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** mehiläisten varroatoosi \(Varroa jacobsoni\)

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** turkiseläinten penikkatauti

<a id="section-3-subsection-1-paragraph-17"></a>
- **17.** mehiläisten esikotelomätä

<a id="section-3-subsection-1-paragraph-18"></a>
- **18.** lohikalojen paisetauti \(Aeromonas salmonicida\)

<a id="section-3-subsection-1-paragraph-19"></a>
- **19.** kalojen tarttuva haimakuoliotauti \(IPN\)

<a id="section-3-subsection-1-paragraph-20"></a>
- **20.** kalojen bakteeriperäinen munuaistauti \(BKD\)

<a id="section-3-subsection-1-paragraph-21"></a>
- **21.** kalojen Gyrodactylus salaris\-tartunta Tenojoen, Näätämöjoen, Paatsjoen ja Luttojoen vesistöjen alueella\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 16 päivänä toukokuuta 1990\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan 16 päivänä joulukuuta 1987 annettu maa\- ja metsätalousministeriön eläinlääkintöosaston päätös vastustettavista eläintaudeista \(1140/87\)\.
