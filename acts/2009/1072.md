# Valtioneuvoston asetus suhdanneluonteisista avustuksista eräiden asuinrakennusten korjauksiin

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Suhdanneluonteisista avustuksista eräiden asuinrakennusten korjauksiin annetun lain [\(178/2009\) 3 §:n](<https://www.finlex.fi/fi/lainsaadanto/2009/178#sec_3>) 2 momentissa tarkoitetulla avustuksella voidaan tukea:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** rakennuksen ulkovaipan korjausta:

<a id="section-1-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** ikkunoiden parantaminen kunnostamalla ne ja asentamalla lisälasit tai etuikkunat;

<a id="section-1-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** ikkunoiden uusiminen U\-arvoltaan enintään 1,0 W/m 2 K ikkunoiksi;

<a id="section-1-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** ulko\- ja parvekeovien parantaminen tai uusiminen U\-arvoltaan enintään 0,7 W/m 2 K oviksi \(umpiovet\) tai U\-arvoltaan enintään 1,0 W/m 2 K oviksi \(ikkuna\-aukolliset ovet\)

<a id="section-1-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** puolilämpimien tilojen ikkunoiden ja ovien parantaminen tai uusiminen U\-arvoltaan enintään 1,4 W/m 2 K ikkunoiksi tai oviksi;

<a id="section-1-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** ulkoseinän lisäeristäminen ulkopuolelta vähintään 100 millimetriä paksulla mineraalivillalla tai toteuttamalla vastaava eristystason parantaminen muulla tavoin;

<a id="section-1-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** yläpohjan yläpuolinen lisäeristäminen vähintään 150 millimetrin paksuisella mineraalivillalla tai toteuttamalla vastaava eristystason parantaminen muulla tavoin;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** putkiston korjausta ja ilmanvaihtojärjestelmää:

<a id="section-1-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** huoneistokohtaisten vesimittareiden asentaminen;

<a id="section-1-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** vettä säästävien vesikalusteiden asentaminen;

<a id="section-1-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** paineenalennusventtiilien asentaminen;

<a id="section-1-subsection-1-paragraph-2-subparagraph-d"></a>
  - **d.** ilmanvaihdon perussäätö, joka edellytetään tehtäväksi 1 kohdan a―e alakohdassa mainittujen toimenpiteiden jälkeen;

<a id="section-1-subsection-1-paragraph-2-subparagraph-e"></a>
  - **e.** erillisten korvausilmaventtiilien ja poistoilmaventtiilien asentaminen silloin, kun se on tarpeen 1 kohdan a―e alakohdassa tarkoitettujen toimenpiteiden yhteydessä;

<a id="section-1-subsection-1-paragraph-2-subparagraph-f"></a>
  - **f.** ilmanvaihtojärjestelmän korjaaminen tai uusiminen;

<a id="section-1-subsection-1-paragraph-2-subparagraph-g"></a>
  - **g.** ilmanvaihdon lämmöntalteenoton rakentaminen;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** lämmitysjärjestelmää ja uusiutuvien energialähteiden käyttöä:

<a id="section-1-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** liittyminen kauko\- tai aluelämmitykseen

<a id="section-1-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** kiinteistöllä olevien rakennusten välisten lämpöputkien uusiminen, jolloin lämmöneristävyys paranee;

<a id="section-1-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** lämmitysjärjestelmän muuttaminen maalämpöpumpulla toimivaksi keskuslämmitysjärjestelmäksi; maalämpöpumpun tulee hyödyntää maaperän, kallioperän, pohjaveden tai pintavesistön lämpöä;

<a id="section-1-subsection-1-paragraph-3-subparagraph-d"></a>
  - **d.** lämmitysjärjestelmän muuttaminen vähäpäästöisellä pellettejä tai muuta puuperäistä polttoainetta käyttävällä kattilalla toimivaksi keskuslämmitysjärjestelmäksi;

<a id="section-1-subsection-1-paragraph-3-subparagraph-e"></a>
  - **e.** polttoainevaraston rakentaminen d alakohdassa tarkoitettua lämmitysjärjestelmää varten;

<a id="section-1-subsection-1-paragraph-3-subparagraph-f"></a>
  - **f.** lämmitysjärjestelmän perussäätö; säätö on tehtävä aina 1 kohdan a―e alakohdassa ja 2 kohdan g alakohdassa mainittujen avustettavien toimenpiteiden yhteydessä;

<a id="section-1-subsection-1-paragraph-3-subparagraph-g"></a>
  - **g.** tarvittaessa f alakohdassa mainitusta perussäädöstä aiheutuva patteri\- ja linjasäätöventtiilien uusiminen;

<a id="section-1-subsection-1-paragraph-3-subparagraph-h"></a>
  - **h.** lämmitysjärjestelmän täydentäminen ilma\-ilma\- tai ilma\-vesilämpöpumpulla;

<a id="section-1-subsection-1-paragraph-3-subparagraph-i"></a>
  - **i.** aurinkolämpöjärjestelmän lisääminen käyttöveden tai tilojen lämmitysjärjestelmään;

<a id="section-1-subsection-1-paragraph-3-subparagraph-j"></a>
  - **j.** öljykattilan uusiminen, kun siihen liitetään aurinkolämpöjärjestelmä;

<a id="section-1-subsection-1-paragraph-3-subparagraph-k"></a>
  - **k.** aurinkolämpöä, ilma\-vesilämpöpumppua ja polttoainetta hyödyntävän lämmitysjärjestelmän \(hybridilämmitysjärjestelmä\) rakentaminen;

<a id="section-1-subsection-1-paragraph-3-subparagraph-l"></a>
  - **l.** kiinteistökohtaisen tuulivoima\- tai aurinkosähköjärjestelmän rakentaminen\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2010\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Ennen asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin\.
