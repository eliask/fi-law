# Valtioneuvoston asetus sosiaali\- ja terveysministeriöstä annetun valtioneuvoston asetuksen 1 ja 2 §:n muuttamisesta

<a id="section-1"></a>
### 1 § Ministeriön tehtävät

<a id="section-1-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriön tehtäviä ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** terveyden ja toimintakyvyn edistäminen sekä sairauksien ehkäiseminen;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** sosiaalinen hyvinvointi ja sosiaalisten ongelmien ehkäisy;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** sosiaali\- ja terveyspalvelut sekä sosiaali\- ja terveydenhuollon suunnittelu\- ja valtionosuuskysymykset;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** lasten, nuorten ja perheiden hyvinvoinnin turvaaminen;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** maatalousyrittäjien lomituspalvelut;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** alkoholi\- ja huumausaineasiat;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** lääkehuolto;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** työterveyshuolto;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** terveydensuojelu sekä säteilyhaittojen, kemikaalien ja geeniteknologian valvonta;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** toimeentuloturva;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** vakuutustoiminnan sääntely;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** työsuojelu ja metsäpalkkaus;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** naisten ja miesten välinen tasa\-arvo;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** Raha\-automaattiyhdistyksen tuoton jakaminen;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** Kansaneläkelaitosta koskevat asiat\.

<a id="section-2"></a>
### 2 § Ministeriön toimialan virastot, laitokset, toimielimet ja yhteisöt

<a id="section-2-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Terveyden ja hyvinvoinnin laitos;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Lääkelaitos;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Lääkehoidon kehittämiskeskus;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Sosiaali\- ja terveysalan lupa\- ja valvontavirasto;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Säteilyturvakeskus;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** sosiaaliturvan muutoksenhakulautakunta;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** työttömyysturvan muutoksenhakulautakunta;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** työterveyslaitos;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** työsuojelun piirihallinto;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** tasa\-arvovaltuutettu ja tasa\-arvovaltuutetun toimisto;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** lapsiasiavaltuutettu ja lapsiasiavaltuutetun toimisto;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Raha\-automaattiyhdistys;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Alko Oy;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** työsuojelurahasto;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Koulutusrahasto;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** työttömyysvakuutusrahasto;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** työehtosopimuksen yleissitovuuden vahvistamislautakunta\.
