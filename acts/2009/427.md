## 5 a luku Telekuuntelu, televalvonta ja tekninen tarkkailu

<a id="chapter-5a-section-2"></a>
### 2 § Telekuuntelun edellytykset

<a id="chapter-5a-section-2-subsection-1"></a>
#### \(1\)

Lupa 1 momentin mukaiseen telekuunteluun voidaan siinä säädetyin edellytyksin antaa myös, kun on syytä epäillä jotakuta liike\- tai ammattitoimintaan liittyvästä sellaisesta

<a id="chapter-5a-section-2-subsection-1-paragraph-1"></a>
- **1.** törkeästä lahjuksen antamisesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-2"></a>
- **2.** törkeästä kavalluksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-3"></a>
- **3.** törkeästä veropetoksesta, törkeästä avustuspetoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-4"></a>
- **4.** törkeästä väärennyksestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-5"></a>
- **5.** törkeästä petoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-6"></a>
- **6.** törkeästä velallisen epärehellisyydestä, törkeästä velallisen petoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-7"></a>
- **7.** törkeästä lahjuksen ottamisesta, törkeästä virka\-aseman väärinkäytöstä,

<a id="chapter-5a-section-2-subsection-1-paragraph-8"></a>
- **8.** törkeästä säännöstelyrikoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-9"></a>
- **9.** törkeästä sisäpiirintiedon väärinkäytöstä tai törkeästä kurssin vääristämisestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-10"></a>
- **10.** edellä mainittujen rikosten rangaistavasta yrityksestä taikka

<a id="chapter-5a-section-2-subsection-1-paragraph-11"></a>
- **11.** törkeästä tulliselvitysrikoksesta,

<a id="chapter-5a-section-3"></a>
### 3 § Televalvonnan edellytykset

<a id="chapter-5a-section-3-subsection-1"></a>
#### \(1\)

Kun on syytä epäillä jotakuta

<a id="chapter-5a-section-3-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta,

<a id="chapter-5a-section-3-subsection-1-paragraph-2"></a>
- **2.** automaattiseen tietojenkäsittelyjärjestelmään kohdistuneesta rikoksesta, joka on tehty telepäätelaitetta käyttäen, parituksesta, oikeudenkäytössä kuultavan uhkaamisesta, laittomasta uhkauksesta tai huumausainerikoksesta,

<a id="chapter-5a-section-3-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen rikosten rangaistavasta yrityksestä,

<a id="chapter-5a-section-3-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta tai

<a id="chapter-5a-section-3-subsection-1-paragraph-5"></a>
- **5.** törkeästä tulliselvitysrikoksesta,

<a id="chapter-5a-section-4"></a>

#### \(1\)

<a id="chapter-5a-section-4-subsection-1-paragraph-2"></a>
- **2.** huumausainerikoksesta,

<a id="chapter-5a-section-4-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen rikosten rangaistavasta yrityksestä,

<a id="chapter-5a-section-4-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta tai

<a id="chapter-5a-section-4-subsection-1-paragraph-5"></a>
- **5.** törkeästä tulliselvitysrikoksesta,
