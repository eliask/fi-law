# Oikeusministeriön asetus eräistä tuomioistuinten hakemusmaksuista vuosina 2022\-2024

<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään eräiden käräjäoikeudessa, hovioikeudessa ja markkinaoikeudessa hakemuksesta vireille tulevien asioiden hakemusmaksuista\.

<a id="section-2"></a>
### 2 § Käräjäoikeuden hakemusmaksut

<a id="section-2-subsection-1"></a>
#### \(1\)

Hakemuksesta vireille tulevan asian käsittelystä käräjäoikeudessa peritään 270 euroa, jollei jäljempänä toisin säädetä\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Seuraavien hakemusasioiden käsittelystä peritään hakemusmaksut seuraavasti:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** avioero:

<a id="section-2-subsection-2-paragraph-1-subparagraph-a"></a>
  - **a.** avioliiton purkamista koskeva hakemus, 210 euroa, jollei b alakohdassa toisin säädetä;

<a id="section-2-subsection-2-paragraph-1-subparagraph-b"></a>
  - **b.** jos asia siirretään istuntokäsittelyyn kuten riita\-asiassa;

<a id="section-2-subsection-2-paragraph-1-subparagraph-c"></a>
  - **c.** asian jatkokäsittely harkinta\-ajan jälkeen 100 euroa;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** tuomioistuinsovittelu:

<a id="section-2-subsection-2-paragraph-2-subparagraph-a"></a>
  - **a.** jos sovittelua ei aloiteta, 100 euroa;

<a id="section-2-subsection-2-paragraph-2-subparagraph-b"></a>
  - **b.** jos sovittelu aloitetaan, 270 euroa;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** konkurssi:

<a id="section-2-subsection-2-paragraph-3-subparagraph-a"></a>
  - **a.** konkurssiin asettamista koskevassa asiassa hakijalta 320 euroa, jollei velallista aseteta konkurssiin;

<a id="section-2-subsection-2-paragraph-3-subparagraph-b"></a>
  - **b.** konkurssiin asettamisesta konkurssipesältä 690 euroa;

<a id="section-2-subsection-2-paragraph-3-subparagraph-c"></a>
  - **c.** jakoluettelon vahvistamiseen päättyvästä konkurssiasiasta 800 euroa;

<a id="section-2-subsection-2-paragraph-3-subparagraph-d"></a>
  - **d.** muusta kuin jakoluettelon vahvistamiseen päättyvästä konkurssiasiasta 320 euroa; maksua ei kuitenkaan peritä, jos konkurssi jatkuu julkisselvityksenä;

<a id="section-2-subsection-2-paragraph-3-subparagraph-e"></a>
  - **e.** erikseen hakemuksesta käsiteltävästä muusta konkurssilakiin [\(120/2004\)](<https://www.finlex.fi/fi/lainsaadanto/2004/120>) perustuvasta asiasta kuin a–d alakohdassa tarkoitetusta asiasta hakijalta 320 euroa; maksua ei kuitenkaan peritä asiassa, joka koskee turvaamistoimen tai pakkokeinon määräämistä, pesäluettelon vahvistamista tai muuta velallisen velvollisuutta, jälkivalvontaa taikka vahvistetun jakoluettelon oikaisemista tai muuttamista;

<a id="section-2-subsection-2-paragraph-3-subparagraph-f"></a>
  - **f.** riitautettua saatavaa koskevan asian käsittelystä, jos asia siirretään riitaisena istuntokäsittelyyn, riitauttajalta kuten riita\-asiassa;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** saneerausmenettely:

<a id="section-2-subsection-2-paragraph-4-subparagraph-a"></a>
  - **a.** asia, jossa saneerausmenettelyä ei päätetä aloittaa, 320 euroa;

<a id="section-2-subsection-2-paragraph-4-subparagraph-b"></a>
  - **b.** asia, jossa saneerausmenettely päätetään aloittaa, 1 060 euroa;

<a id="section-2-subsection-2-paragraph-4-subparagraph-c"></a>
  - **c.** erikseen hakemuksesta käsiteltävä saneerausmenettelyyn liittyvä muu kuin a tai b alakohdassa tarkoitettu asia 320 euroa;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** yksityishenkilön velkajärjestelystä annetun lain [\(57/1993\)](<https://www.finlex.fi/fi/lainsaadanto/1993/57>) mukainen asia 270 euroa; velallisen ollessa hakijana asia on kuitenkin maksuton\.

<a id="section-3"></a>
### 3 § Hovioikeuden hakemusmaksu

<a id="section-3-subsection-1"></a>
#### \(1\)

Hakemusasian käsittelystä hovioikeudessa peritään hakemusmaksua 270 euroa\.

<a id="section-4"></a>
### 4 § Markkinaoikeuden hakemusmaksu

<a id="section-4-subsection-1"></a>
#### \(1\)

Muun hakemusasian kuin markkinaoikeudellisen asian käsittelystä markkinaoikeudessa peritään hakemusmaksua 270 euroa\.

<a id="section-5"></a>
### 5 § Voimaantulo

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2022 ja on voimassa 31 päivään joulukuuta 2024\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Maksun perimiseen suoritteesta, jonka maksuperuste on syntynyt ennen tämän asetuksen voimaantuloa, sovelletaan tämän asetuksen voimaan tullessa voimassa olleita säännöksiä\.
