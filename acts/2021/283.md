## 5 luku Salaiset tiedonhankintakeinot

<a id="chapter-5-section-3"></a>
### 3 § Salainen tiedonhankinta rikoksen paljastamiseksi

<a id="chapter-5-section-3-subsection-1"></a>
#### \(1\)

Tässä luvussa säädettyjä keinoja saadaan käyttää seuraavien rikosten paljastamisessa:

<a id="chapter-5-section-3-subsection-1-paragraph-1"></a>
- **1.** Suomen itsemääräämisoikeuden vaarantaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-2"></a>
- **2.** sotaan yllyttäminen;

<a id="chapter-5-section-3-subsection-1-paragraph-3"></a>
- **3.** maanpetos ja törkeä maanpetos;

<a id="chapter-5-section-3-subsection-1-paragraph-4"></a>
- **4.** vakoilu ja törkeä vakoilu;

<a id="chapter-5-section-3-subsection-1-paragraph-5"></a>
- **5.** turvallisuussalaisuuden paljastaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-6"></a>
- **6.** luvaton tiedustelutoiminta;

<a id="chapter-5-section-3-subsection-1-paragraph-7"></a>
- **7.** rikoslain 34 a luvun 1 §:n 1 momentin 2–8 kohdassa tai 2 momentissa tarkoitettu terroristisessa tarkoituksessa tehty rikos;

<a id="chapter-5-section-3-subsection-1-paragraph-8"></a>
- **8.** terroristisessa tarkoituksessa tehty radiologista asetta koskeva rikos;

<a id="chapter-5-section-3-subsection-1-paragraph-9"></a>
- **9.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelu;

<a id="chapter-5-section-3-subsection-1-paragraph-10"></a>
- **10.** terroristiryhmän johtaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-11"></a>
- **11.** terroristiryhmän toiminnan edistäminen;

<a id="chapter-5-section-3-subsection-1-paragraph-12"></a>
- **12.** koulutuksen antaminen terrorismirikosten tekemistä varten;

<a id="chapter-5-section-3-subsection-1-paragraph-13"></a>
- **13.** kouluttautuminen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-5-section-3-subsection-1-paragraph-14"></a>
- **14.** värväys terrorismirikoksen tekemiseen;

<a id="chapter-5-section-3-subsection-1-paragraph-15"></a>
- **15.** terrorismirikoksen rahoittaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-16"></a>
- **16.** terroristin rahoittaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-17"></a>
- **17.** terroristiryhmän rahoittaminen;

<a id="chapter-5-section-3-subsection-1-paragraph-18"></a>
- **18.** matkustaminen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta\.

<a id="chapter-5-section-5"></a>
### 5 § Telekuuntelu ja sen edellytykset

<a id="chapter-5-section-5-subsection-1"></a>
#### \(1\)

Poliisille voidaan rikoksen estämiseksi antaa lupa kohdistaa telekuuntelua henkilön hallussa olevaan tai hänen oletettavasti muuten käyttämäänsä teleosoitteeseen tai telepäätelaitteeseen, jos henkilön lausumien, uhkausten tai käyttäytymisen perusteella voidaan perustellusti olettaa hänen syyllistyvän:

<a id="chapter-5-section-5-subsection-1-paragraph-1"></a>
- **1.** Suomen itsemääräämisoikeuden vaarantamiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-2"></a>
- **2.** sotaan yllyttämiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-3"></a>
- **3.** maanpetokseen tai törkeään maanpetokseen;

<a id="chapter-5-section-5-subsection-1-paragraph-4"></a>
- **4.** vakoiluun tai törkeään vakoiluun;

<a id="chapter-5-section-5-subsection-1-paragraph-5"></a>
- **5.** turvallisuussalaisuuden paljastamiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-6"></a>
- **6.** luvattomaan tiedustelutoimintaan;

<a id="chapter-5-section-5-subsection-1-paragraph-7"></a>
- **7.** rikoslain 34 a luvun 1 §:n 1 momentin 2–8 kohdassa tai 2 momentissa tarkoitettuun terroristisessa tarkoituksessa tehtyyn rikokseen;

<a id="chapter-5-section-5-subsection-1-paragraph-8"></a>
- **8.** terroristisessa tarkoituksessa tehtyyn radiologista asetta koskevaan rikokseen;

<a id="chapter-5-section-5-subsection-1-paragraph-9"></a>
- **9.** terroristisessa tarkoituksessa tehtävän rikoksen valmisteluun;

<a id="chapter-5-section-5-subsection-1-paragraph-10"></a>
- **10.** terroristiryhmän johtamiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-11"></a>
- **11.** terroristiryhmän toiminnan edistämiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-12"></a>
- **12.** koulutuksen antamiseen terrorismirikoksen tekemistä varten;

<a id="chapter-5-section-5-subsection-1-paragraph-13"></a>
- **13.** kouluttautumiseen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-5-section-5-subsection-1-paragraph-14"></a>
- **14.** värväykseen terrorismirikoksen tekemiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-15"></a>
- **15.** terrorismirikoksen rahoittamiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-16"></a>
- **16.** terroristin rahoittamiseen;

<a id="chapter-5-section-5-subsection-1-paragraph-17"></a>
- **17.** terroristiryhmän rahoittamiseen; taikka

<a id="chapter-5-section-5-subsection-1-paragraph-18"></a>
- **18.** matkustamiseen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta\.

<a id="chapter-5-section-8"></a>
### 8 § Televalvonta ja sen edellytykset

<a id="chapter-5-section-8-subsection-1"></a>
#### \(1\)

Poliisille voidaan rikoksen estämiseksi antaa lupa kohdistaa televalvontaa henkilön hallussa olevaan tai hänen oletettavasti muuten käyttämäänsä teleosoitteeseen tai telepäätelaitteeseen, jos henkilön lausumien, uhkausten tai käyttäytymisen perusteella taikka muutoin voidaan perustellusti olettaa hänen syyllistyvän:

<a id="chapter-5-section-8-subsection-1-paragraph-1"></a>
- **1.** rikokseen, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-5-section-8-subsection-1-paragraph-2"></a>
- **2.** teleosoitetta tai telepäätelaitetta käyttäen tehtyyn rikokseen, josta säädetty ankarin rangaistus on vähintään kaksi vuotta vankeutta;

<a id="chapter-5-section-8-subsection-1-paragraph-3"></a>
- **3.** teleosoitetta tai telepäätelaitetta käyttäen tehtyyn, automaattiseen tietojenkäsittelyjärjestelmään kohdistuvaan luvattomaan käyttöön;

<a id="chapter-5-section-8-subsection-1-paragraph-4"></a>
- **4.** seksikaupan kohteena olevan henkilön hyväksikäyttöön, lapsen houkuttelemiseen seksuaalisiin tarkoituksiin tai paritukseen;

<a id="chapter-5-section-8-subsection-1-paragraph-5"></a>
- **5.** huumausainerikokseen;

<a id="chapter-5-section-8-subsection-1-paragraph-6"></a>
- **6.** terroristisessa tarkoituksessa tehtävän rikoksen valmisteluun, kouluttautumiseen terrorismirikoksen tekemistä varten, matkustamiseen terrorismirikoksen tekemistä varten tai terrorismirikoksen tekemistä varten tapahtuvan matkustamisen edistämiseen; taikka

<a id="chapter-5-section-8-subsection-1-paragraph-7"></a>
- **7.** törkeään tulliselvitysrikokseen\.

<a id="chapter-5-section-15"></a>
### 15 § Peitelty tiedonhankinta ja sen edellytykset

<a id="chapter-5-section-15-subsection-1"></a>
#### \(1\)

Poliisi saa käyttää peiteltyä tiedonhankintaa rikoksen estämiseksi, jos henkilön lausumien tai muun käyttäytymisen perusteella voidaan perustellusti olettaa hänen syyllistyvän:

<a id="chapter-5-section-15-subsection-1-paragraph-1"></a>
- **1.** rikokseen, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-5-section-15-subsection-1-paragraph-2"></a>
- **2.** seksikaupan kohteena olevan henkilön hyväksikäyttöön tai paritukseen;

<a id="chapter-5-section-15-subsection-1-paragraph-3"></a>
- **3.** huumausainerikokseen;

<a id="chapter-5-section-15-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmisteluun taikka kouluttautumiseen terrorismirikoksen tekemistä varten tai matkustamiseen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-5-section-15-subsection-1-paragraph-5"></a>
- **5.** törkeään tulliselvitysrikokseen; taikka

<a id="chapter-5-section-15-subsection-1-paragraph-6"></a>
- **6.** suunnitelmalliseen, järjestäytyneeseen, ammattimaiseen, jatkuvaan tai toistuvaan rikolliseen toimintaan liittyvään varkauteen tai kätkemisrikokseen\.

<a id="chapter-5-section-17"></a>
### 17 § Tekninen kuuntelu ja sen edellytykset

<a id="chapter-5-section-17-subsection-1"></a>
#### \(1\)

Teknisen kuuntelun edellytyksenä on lisäksi, että henkilön lausumien, uhkausten tai käyttäytymisen perusteella taikka muutoin voidaan perustellusti olettaa hänen syyllistyvän:

<a id="chapter-5-section-17-subsection-1-paragraph-1"></a>
- **1.** rikokseen, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-5-section-17-subsection-1-paragraph-2"></a>
- **2.** huumausainerikokseen;

<a id="chapter-5-section-17-subsection-1-paragraph-3"></a>
- **3.** terroristisessa tarkoituksessa tehtävän rikoksen valmisteluun taikka kouluttautumiseen terrorismirikoksen tekemistä varten tai matkustamiseen terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta; taikka

<a id="chapter-5-section-17-subsection-1-paragraph-4"></a>
- **4.** törkeään tulliselvitysrikokseen\.
