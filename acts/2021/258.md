<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään alueista, joilla ravitsemisliikkeet on pidettävä suljettuina asiakkailta, sekä siitä, millaisissa ravitsemisliikkeissä ja niihin kuuluvissa tiloissa rajoituksia on noudatettava majoitus\- ja ravitsemistoiminnasta annetun lain [\(308/2006\) 3 a §:ssä](<https://www.finlex.fi/fi/lainsaadanto/2006/308>) tarkoitetuissa poikkeusoloissa\.

<a id="section-2"></a>
### 2 § Ravitsemisliikkeiden aukiolon rajoittaminen alueittain tartuntataudin leviämisen estämiseksi

<a id="section-2-subsection-1"></a>
#### \(1\)

Sellaisen ravitsemisliikkeen, jonka pääasiallisena ravitsemistoimintana on tarjota yleisölle maksusta elintarvikelaissa [\(23/2006\)](<https://www.finlex.fi/fi/lainsaadanto/2006/23>) tarkoitetussa elintarvikehuoneistossa alkoholijuomia, sisä\- ja ulkotilat on pidettävä suljettuina asiakkailta seuraavissa maakunnissa:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uusimaa;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Varsinais\-Suomi;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Satakunta;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kanta\-Häme;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaa;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Päijät\-Häme;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Kymenlaakso;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Etelä\-Karjala;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Etelä\-Savo;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Pohjois\-Savo;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Pohjois\-Karjala;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Keski\-Suomi;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Pohjanmaa\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Muun kuin 1 momentissa tarkoitetun ravitsemisliikkeen sisä\- ja ulkotilat on pidettävä suljettuina asiakkailta seuraavissa maakunnissa:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Uusimaa;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Varsinais\-Suomi;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** Satakunta;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** Kanta\-Häme;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** Pirkanmaa;

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** Päijät\-Häme;

<a id="section-2-subsection-2-paragraph-7"></a>
- **7.** Kymenlaakso;

<a id="section-2-subsection-2-paragraph-8"></a>
- **8.** Etelä\-Karjala;

<a id="section-2-subsection-2-paragraph-9"></a>
- **9.** Etelä\-Savo;

<a id="section-2-subsection-2-paragraph-10"></a>
- **10.** Pohjois\-Savo;

<a id="section-2-subsection-2-paragraph-11"></a>
- **11.** Pohjois\-Karjala;

<a id="section-2-subsection-2-paragraph-12"></a>
- **12.** Keski\-Suomi;

<a id="section-2-subsection-2-paragraph-13"></a>
- **13.** Pohjanmaa\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Sisätilalla tarkoitetaan tässä asetuksessa ravitsemisliikkeen suljettua tilaa, jossa on katto, lattia ja seinät, sekä liikkeen sellaista tilaa, josta yhden tasopinnan lisäämisellä voidaan muodostaa suljettu tila\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 29 päivänä maaliskuuta 2021\. Asetus on voimassa 18 päivään huhtikuuta 2021\.
