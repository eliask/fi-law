### 2 § Ravitsemisliikkeiden aukiolon rajoittaminen alueittain tartuntataudin leviämisen estämiseksi

<a id="section-2-subsection-1"></a>
#### \(1\)

Sellaisen ravitsemisliikkeen, jonka pääasiallisena ravitsemistoimintana on tarjota yleisölle maksusta elintarvikelaissa \(23/2006\) tarkoitetussa elintarvikehuoneistossa alkoholijuomia, sisä\- ja ulkotilat on pidettävä suljettuina asiakkailta seuraavissa maakunnissa:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uusimaa;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Varsinais\-Suomi;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Satakunta;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kanta\-Häme;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaa;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Päijät\-Häme;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Kymenlaakso;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Etelä\-Karjala;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Etelä\-Savo;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Pohjois\-Karjala;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Keski\-Suomi;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Pohjanmaa\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Muun kuin 1 momentissa tarkoitetun ravitsemisliikkeen sisä\- ja ulkotilat on pidettävä suljettuina asiakkailta seuraavissa maakunnissa:

<a id="section-2-subsection-2-paragraph-10"></a>
- **10.** Pohjois\-Karjala;

<a id="section-2-subsection-2-paragraph-11"></a>
- **11.** Keski\-Suomi;

<a id="section-2-subsection-2-paragraph-12"></a>
- **12.** Pohjanmaa\.
