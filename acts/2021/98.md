# Valtioneuvoston asetus huomattavan markkinavoiman yrityksen aikaisemman verkon korvaamisesta tai käytöstä poistamisesta

<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä asetusta sovelletaan sähköisen viestinnän palveluista annetun lain [\(917/2014\) 81 c §:n](<https://www.finlex.fi/fi/lainsaadanto/2014/917#chp_10__sec_81c>) 1 momentin mukaisesti tehtäviin ilmoituksiin\.

<a id="section-2"></a>
### 2 § Toimitettavat tiedot

<a id="section-2-subsection-1"></a>
#### \(1\)

Sen lisäksi, mitä tietojen toimittamisesta säädetään sähköisen viestinnän palveluista annetussa lain 81 c §:ssä, on huomattavan markkinavoiman yrityksen liitettävä ilmoitukseensa vähintään seuraavat tiedot:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yrityksen nimi, yhteystiedot ja y\-tunnus;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** käytöstä poistettavan tai korvattavan verkon suunniteltu korvaamisajankohta tai poistamisajankohta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** käytöstä poistettavan tai korvattavan verkon maantieteellinen peittoalue ensisijaisesti kiinteistökohtaisesti paikkatietona tai toissijaisesti sellaisena karttamuotoisena paikkatietona, josta ilmenee verkon tarkka sijainti;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** käytöstä poistettavan tai korvattavan verkon liittymätekniikka, vuokratut tilaaja\-, bitstream\- ja virtuaaliset tilaajayhteydet ja niiden käyttäjät;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** ilmoituksen tekijän vaihtoehtoisten tai korvaavien yhteyksien saatavuus käytöstä poistettavan tai korvattavan verkon alueella sekä näiden yhteyksien liittymätekniikka, vähimmäisliittymänopeus, toimitusaika sekä hinta eriteltynä siten, että siitä selviää kytkentähinta ja kuukausimaksu;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** tieto siitä, onko ilmoituksen tekijä yleispalveluyritys tai sijaitseeko olemassa oleva verkko yleispalvelualueella\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 25 päivänä tammikuuta 2021\.
