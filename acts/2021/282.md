## 10 luku Salaiset pakkokeinot

<a id="chapter-10-section-3"></a>
### 3 § Telekuuntelu ja sen edellytykset

<a id="chapter-10-section-3-subsection-1"></a>
#### \(1\)

Esitutkintaviranomaiselle voidaan antaa lupa kohdistaa telekuuntelua rikoksesta epäillyn hallussa olevaan tai hänen oletettavasti muuten käyttämäänsä teleosoitteeseen tai telepäätelaitteeseen, jos epäiltyä on syytä epäillä:

<a id="chapter-10-section-3-subsection-1-paragraph-1"></a>
- **1.** joukkotuhonnasta, joukkotuhonnan valmistelusta, rikoksesta ihmisyyttä vastaan, törkeästä rikoksesta ihmisyyttä vastaan, hyökkäysrikoksesta, hyökkäysrikoksen valmistelusta, sotarikoksesta, törkeästä sotarikoksesta, kidutuksesta, kemiallisen aseen kiellon rikkomisesta, biologisen aseen kiellon rikkomisesta tai jalkaväkimiinakiellon rikkomisesta;

<a id="chapter-10-section-3-subsection-1-paragraph-2"></a>
- **2.** Suomen itsemääräämisoikeuden vaarantamisesta, sotaan yllyttämisestä, maanpetoksesta, törkeästä maanpetoksesta, vakoilusta, törkeästä vakoilusta, turvallisuussalaisuuden paljastamisesta tai luvattomasta tiedustelutoiminnasta;

<a id="chapter-10-section-3-subsection-1-paragraph-3"></a>
- **3.** valtiopetoksesta, törkeästä valtiopetoksesta tai valtiopetoksen valmistelusta;

<a id="chapter-10-section-3-subsection-1-paragraph-4"></a>
- **4.** törkeästä sukupuolisiveellisyyttä loukkaavan lasta esittävän kuvan levittämisestä;

<a id="chapter-10-section-3-subsection-1-paragraph-5"></a>
- **5.** lapsen seksuaalisesta hyväksikäytöstä, törkeästä lapsen seksuaalisesta hyväksikäytöstä tai törkeästä lapsenraiskauksesta;

<a id="chapter-10-section-3-subsection-1-paragraph-6"></a>
- **6.** taposta, murhasta, surmasta tai rikoslain 21 luvun 6 a §:ssä tarkoitetusta mainitun luvun 1, 2 tai 3 §:n mukaisesta törkeän henkeen tai terveyteen kohdistuvan rikoksen valmistelusta;

<a id="chapter-10-section-3-subsection-1-paragraph-7"></a>
- **7.** törkeästä laittoman maahantulon järjestämisestä, törkeästä vapaudenriistosta, ihmiskaupasta, törkeästä ihmiskaupasta, panttivangin ottamisesta tai panttivangin ottamisen valmistelusta;

<a id="chapter-10-section-3-subsection-1-paragraph-8"></a>
- **8.** törkeästä ryöstöstä, törkeän ryöstön valmistelusta tai törkeästä kiristyksestä;

<a id="chapter-10-section-3-subsection-1-paragraph-9"></a>
- **9.** törkeästä kätkemisrikoksesta, ammattimaisesta kätkemisrikoksesta tai törkeästä rahanpesusta;

<a id="chapter-10-section-3-subsection-1-paragraph-10"></a>
- **10.** tuhotyöstä, liikennetuhotyöstä, törkeästä tuhotyöstä, törkeästä terveyden vaarantamisesta, ydinräjähderikoksesta tai kaappauksesta;

<a id="chapter-10-section-3-subsection-1-paragraph-11"></a>
- **11.** rikoslain 34 a luvun 1 §:n 1 momentin 2–8 kohdassa tai 2 momentissa tarkoitetusta terroristisessa tarkoituksessa tehdystä rikoksesta, terroristisessa tarkoituksessa tehdystä radiologista asetta koskevasta rikoksesta, terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta, terroristiryhmän johtamisesta, terroristiryhmän toiminnan edistämisestä, koulutuksen antamisesta terrorismirikoksen tekemistä varten, kouluttautumisesta terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta, värväyksestä terrorismirikoksen tekemiseen, terrorismirikoksen rahoittamisesta, terroristin rahoittamisesta, terroristiryhmän rahoittamisesta tai matkustamisesta terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-10-section-3-subsection-1-paragraph-12"></a>
- **12.** törkeästä vahingonteosta tai törkeästä datavahingonteosta;

<a id="chapter-10-section-3-subsection-1-paragraph-13"></a>
- **13.** törkeästä petoksesta tai törkeästä kiskonnasta;

<a id="chapter-10-section-3-subsection-1-paragraph-14"></a>
- **14.** törkeästä rahanväärennyksestä;

<a id="chapter-10-section-3-subsection-1-paragraph-15"></a>
- **15.** törkeästä ympäristön turmelemisesta; taikka

<a id="chapter-10-section-3-subsection-1-paragraph-16"></a>
- **16.** törkeästä huumausainerikoksesta\.

<a id="chapter-10-section-6"></a>
### 6 § Televalvonta ja sen edellytykset

<a id="chapter-10-section-6-subsection-1"></a>
#### \(1\)

Esitutkintaviranomaiselle voidaan antaa lupa kohdistaa televalvontaa rikoksesta epäillyn hallussa olevaan tai hänen oletettavasti muuten käyttämäänsä teleosoitteeseen tai telepäätelaitteeseen, jos epäiltyä on syytä epäillä:

<a id="chapter-10-section-6-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-10-section-6-subsection-1-paragraph-2"></a>
- **2.** teleosoitetta tai telepäätelaitetta käyttäen tehdystä rikoksesta, josta säädetty ankarin rangaistus on vähintään kaksi vuotta vankeutta;

<a id="chapter-10-section-6-subsection-1-paragraph-3"></a>
- **3.** teleosoitetta tai telepäätelaitetta käyttäen tehdystä, automaattiseen tietojenkäsittelyjärjestelmään kohdistuneesta luvattomasta käytöstä;

<a id="chapter-10-section-6-subsection-1-paragraph-4"></a>
- **4.** seksikaupan kohteena olevan henkilön hyväksikäytöstä, lapsen houkuttelemisesta seksuaalisiin tarkoituksiin tai parituksesta;

<a id="chapter-10-section-6-subsection-1-paragraph-5"></a>
- **5.** huumausainerikoksesta;

<a id="chapter-10-section-6-subsection-1-paragraph-6"></a>
- **6.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta, kouluttautumisesta terrorismirikoksen tekemistä varten, matkustamisesta terrorismirikoksen tekemistä varten tai terrorismirikoksen tekemistä varten tapahtuvan matkustamisen edistämisestä;

<a id="chapter-10-section-6-subsection-1-paragraph-7"></a>
- **7.** törkeästä tulliselvitysrikoksesta;

<a id="chapter-10-section-6-subsection-1-paragraph-8"></a>
- **8.** törkeästä laittoman saaliin kätkemisestä;

<a id="chapter-10-section-6-subsection-1-paragraph-9"></a>
- **9.** panttivangin ottamisen valmistelusta; taikka

<a id="chapter-10-section-6-subsection-1-paragraph-10"></a>
- **10.** törkeän ryöstön valmistelusta\.

<a id="chapter-10-section-14"></a>
### 14 § Peitelty tiedonhankinta ja sen edellytykset

<a id="chapter-10-section-14-subsection-1"></a>
#### \(1\)

Poliisi saa käyttää peiteltyä tiedonhankintaa, jos on syytä olettaa, että toimenpiteellä saadaan selvitystä:

<a id="chapter-10-section-14-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-10-section-14-subsection-1-paragraph-2"></a>
- **2.** seksikaupan kohteena olevan henkilön hyväksikäytöstä tai parituksesta;

<a id="chapter-10-section-14-subsection-1-paragraph-3"></a>
- **3.** huumausainerikoksesta;

<a id="chapter-10-section-14-subsection-1-paragraph-4"></a>
- **4.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta taikka kouluttautumisesta terrorismirikoksen tekemistä varten tai matkustamisesta terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-10-section-14-subsection-1-paragraph-5"></a>
- **5.** törkeästä tulliselvitysrikoksesta;

<a id="chapter-10-section-14-subsection-1-paragraph-6"></a>
- **6.** suunnitelmalliseen, järjestäytyneeseen, ammattimaiseen, jatkuvaan tai toistuvaan rikolliseen toimintaan liittyvästä varkaudesta tai kätkemisrikoksesta;

<a id="chapter-10-section-14-subsection-1-paragraph-7"></a>
- **7.** panttivangin ottamisen valmistelusta; taikka

<a id="chapter-10-section-14-subsection-1-paragraph-8"></a>
- **8.** törkeän ryöstön valmistelusta\.

<a id="chapter-10-section-16"></a>
### 16 § Tekninen kuuntelu ja sen edellytykset

<a id="chapter-10-section-16-subsection-1"></a>
#### \(1\)

Teknisen kuuntelun edellytyksenä on lisäksi, että kuuntelun kohteena olevaa henkilöä on syytä epäillä:

<a id="chapter-10-section-16-subsection-1-paragraph-1"></a>
- **1.** rikoksesta, josta säädetty ankarin rangaistus on vähintään neljä vuotta vankeutta;

<a id="chapter-10-section-16-subsection-1-paragraph-2"></a>
- **2.** huumausainerikoksesta;

<a id="chapter-10-section-16-subsection-1-paragraph-3"></a>
- **3.** terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta taikka kouluttautumisesta terrorismirikoksen tekemistä varten tai matkustamisesta terrorismirikoksen tekemistä varten, jos teon vakavuus edellyttäisi vankeusrangaistusta;

<a id="chapter-10-section-16-subsection-1-paragraph-4"></a>
- **4.** törkeästä tulliselvitysrikoksesta;

<a id="chapter-10-section-16-subsection-1-paragraph-5"></a>
- **5.** panttivangin ottamisen valmistelusta; taikka

<a id="chapter-10-section-16-subsection-1-paragraph-6"></a>
- **6.** törkeän ryöstön valmistelusta\.

<a id="chapter-10-section-17"></a>
### 17 § Asuntokuuntelu ja sen edellytykset

<a id="chapter-10-section-17-subsection-1"></a>
#### \(1\)

Esitutkintaviranomaiselle voidaan myöntää lupa kohdistaa teknistä kuuntelua vakituiseen asumiseen käytettävään tilaan, jossa rikoksesta epäilty todennäköisesti oleskelee \(asuntokuuntelu\)\. Edellytyksenä on lisäksi, että häntä on syytä epäillä:

<a id="chapter-10-section-17-subsection-1-paragraph-1"></a>
- **1.** joukkotuhonnasta, joukkotuhonnan valmistelusta, rikoksesta ihmisyyttä vastaan, törkeästä rikoksesta ihmisyyttä vastaan, hyökkäysrikoksesta, hyökkäysrikoksen valmistelusta, sotarikoksesta, törkeästä sotarikoksesta, kidutuksesta, kemiallisen aseen kiellon rikkomisesta, biologisen aseen kiellon rikkomisesta tai jalkaväkimiinakiellon rikkomisesta;

<a id="chapter-10-section-17-subsection-1-paragraph-2"></a>
- **2.** Suomen itsemääräämisoikeuden vaarantamisesta, sotaan yllyttämisestä, maanpetoksesta, törkeästä maanpetoksesta, vakoilusta tai törkeästä vakoilusta;

<a id="chapter-10-section-17-subsection-1-paragraph-3"></a>
- **3.** valtiopetoksesta tai törkeästä valtiopetoksesta;

<a id="chapter-10-section-17-subsection-1-paragraph-4"></a>
- **4.** törkeästä lapsen seksuaalisesta hyväksikäytöstä tai törkeästä lapsenraiskauksesta;

<a id="chapter-10-section-17-subsection-1-paragraph-5"></a>
- **5.** taposta, murhasta tai surmasta;

<a id="chapter-10-section-17-subsection-1-paragraph-6"></a>
- **6.** törkeästä ihmiskaupasta;

<a id="chapter-10-section-17-subsection-1-paragraph-7"></a>
- **7.** törkeästä ryöstöstä;

<a id="chapter-10-section-17-subsection-1-paragraph-8"></a>
- **8.** törkeästä tuhotyöstä, törkeästä terveyden vaarantamisesta, ydinräjähderikoksesta tai kaappauksesta;

<a id="chapter-10-section-17-subsection-1-paragraph-9"></a>
- **9.** rikoslain 34 a luvun 1 §:n 1 momentin 2–8 kohdassa tai 2 momentissa tarkoitetusta terroristisessa tarkoituksessa tehdystä rikoksesta, terroristisessa tarkoituksessa tehdystä radiologista asetta koskevasta rikoksesta, terroristisessa tarkoituksessa tehtävän rikoksen valmistelusta, terroristiryhmän johtamisesta, terroristiryhmän toiminnan edistämisestä, koulutuksen antamisesta terrorismirikoksen tekemistä varten, värväyksestä terrorismirikoksen tekemiseen, terrorismirikoksen rahoittamisesta, terroristin rahoittamisesta tai terroristiryhmän rahoittamisesta; taikka

<a id="chapter-10-section-17-subsection-1-paragraph-10"></a>
- **10.** törkeästä huumausainerikoksesta\.
