### 1 § Maksun ja palautuksen yleinen käyttöjärjestys

<a id="section-1-subsection-1"></a>
#### \(1\)

Jos samana päivänä on suoritettavana useita veronkantolain 6 §:n 1 momentin 2 kohdassa tarkoitettuja veroja, maksut ja palautukset käytetään verojen suoritukseksi seuraavassa järjestyksessä:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ennakonpidätys palkoista, palkkioista, henkilöstörahaston ylijäämistä, vakuutussuorituksista, eläkkeistä ja muista etuuksista, muille kuin yhteisöille maksetuista työ\- ja käyttökorvauksista sekä muista vastaavista suorituksista;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Ahvenanmaan lähdevero;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ennakonpidätys puun myyntitulosta;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** ennakonpidätys osakeyhtiölle, osuuskunnalle tai muulle yhteisölle maksetuista työ\- ja käyttökorvauksista;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ennakonpidätys korkotuloista, osuuksista ja osakesäästötililtä nostetuista tuotoista;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** ennakonpidätys osingoista ja osuuskunnan ylijäämistä;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** tulotietojärjestelmästä annetussa laissa \(53/2018\) tarkoitettu myöhästymismaksu\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Jos samana päivänä on suoritettavana useita veronkantolain 6 §:n 1 momentin 5 kohdassa tarkoitettuja veroja, maksut ja palautukset käytetään verojen suoritukseksi seuraavassa järjestyksessä:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** lahjavero;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** perintövero;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** arvonlisävero, ei kuitenkaan 4, 5 ja 6 kohdassa tarkoitettu arvonlisävero;

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** arvonlisäverolain \(1501/1993\) 26 d §:n 2 momentissa tarkoitetun uuden kuljetusvälineen arvonlisävero;

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** valmisteveron alaisen yhteisöhankinnan arvonlisävero;

<a id="section-1-subsection-2-paragraph-6"></a>
- **6.** Suomeen suoritettava arvonlisävero, johon sovelletaan arvonlisäverolain 12 a luvussa tarkoitettua erityisjärjestelmää;

<a id="section-1-subsection-2-paragraph-7"></a>
- **7.** valmisteverot;

<a id="section-1-subsection-2-paragraph-8"></a>
- **8.** autovero;

<a id="section-1-subsection-2-paragraph-9"></a>
- **9.** varainsiirtovero;

<a id="section-1-subsection-2-paragraph-10"></a>
- **10.** tonnistovero;

<a id="section-1-subsection-2-paragraph-11"></a>
- **11.** vakuutusmaksuvero;

<a id="section-1-subsection-2-paragraph-12"></a>
- **12.** lähdevero palkoista, palkkioista, työkorvauksista, henkilöstörahaston ylijäämistä ja etuuksista sekä muista vastaavista suorituksista;

<a id="section-1-subsection-2-paragraph-13"></a>
- **13.** lähdevero osingoista ja osuuskunnan ylijäämistä;

<a id="section-1-subsection-2-paragraph-14"></a>
- **14.** lähdevero rojalteista;

<a id="section-1-subsection-2-paragraph-15"></a>
- **15.** lähdevero rajoitetusti verovelvollisen korkotuloista ja osakesäästötililtä nostetuista tuotoista;

<a id="section-1-subsection-2-paragraph-16"></a>
- **16.** lähdevero korkotulon lähdeverosta annetussa laissa \(1341/1990\) tarkoitetuista yleisesti verovelvollisen korkotuloista;

<a id="section-1-subsection-2-paragraph-17"></a>
- **17.** arpajaisvero;

<a id="section-1-subsection-2-paragraph-18"></a>
- **18.** apteekkivero\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Jos samana päivänä on suoritettavana edellä 2 momentin 7 kohdassa tarkoitettuja valmisteveroja, maksuja ja palautuksia käytettäessä näiden keskinäinen käyttöjärjestys on seuraava:

<a id="section-1-subsection-3-paragraph-1"></a>
- **1.** alkoholi\- ja alkoholijuomavero;

<a id="section-1-subsection-3-paragraph-2"></a>
- **2.** virvoitusjuomavero;

<a id="section-1-subsection-3-paragraph-3"></a>
- **3.** eräiden juomapakkausten valmistevero;

<a id="section-1-subsection-3-paragraph-4"></a>
- **4.** tupakkavero;

<a id="section-1-subsection-3-paragraph-5"></a>
- **5.** nestemäisten polttoaineiden valmistevero;

<a id="section-1-subsection-3-paragraph-6"></a>
- **6.** sähkön valmistevero;

<a id="section-1-subsection-3-paragraph-7"></a>
- **7.** eräiden polttoaineiden valmistevero;

<a id="section-1-subsection-3-paragraph-8"></a>
- **8.** jätevero;

<a id="section-1-subsection-3-paragraph-9"></a>
- **9.** öljysuojamaksu\.

<a id="section-2"></a>
### 2 § Maksun ja palautuksen käyttö veronkorotuksen ja myöhästymismaksun suoritukseksi

<a id="section-2-subsection-1"></a>
#### \(1\)

Jos eri veroeriin sisältyy veronkorotuksia tai muita kuin tulotietojärjestelmästä annetussa laissa tarkoitettuja myöhästymismaksuja, maksu ja palautus käytetään niiden suoritukseksi vastaavassa järjestyksessä kuin maksu ja palautus käytetään niiden perusteena olevien verojen suoritukseksi\.

<a id="section-3"></a>
### 3 § Tarkemmat määräykset veron suoritusjärjestyksestä

<a id="section-3-subsection-1"></a>
#### \(1\)

Jos veroerässä on suoritettavana veroa, viivästysseuraamuksia, veronkorotusta tai myöhästymismaksua, suoritusjärjestys on seuraava:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** veron viivästyskorko, veronlisäys ja viivekorko;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** veron pääoma;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** huojennettu viivästyskorko;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** veronkorotuksen viivästyskorko;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** veronkorotus;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** myöhästymismaksun viivästyskorko;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** myöhästymismaksu\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä helmikuuta 2021\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Päätöksellä kumotaan Verohallinnon päätös maksujen ja palautusten käyttämisestä verojen suoritukseksi \(1032/2019\)\.
