<a id="section-28"></a>
### 28 §

<a id="section-28-subsection-1"></a>
#### \(1\)

Valtion virkamieslain 26 §:n 3 kohdassa tarkoitettuja osastopäällikköä virka\-asemaltaan vastaavia ministeriön virkamiehiä ovat:

<a id="section-28-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriön osastopäällikön tehtävään määrätty ulkoasiainneuvos;

<a id="section-28-subsection-1-paragraph-2"></a>
- **2.** ministeriön osaston päällikkönä toimiva ylijohtaja;

<a id="section-28-subsection-1-paragraph-3"></a>
- **3.** sisäasiainministeriön pelastusosaston pelastusylijohtaja;

<a id="section-28-subsection-1-paragraph-4"></a>
- **4.** valtakunnansovittelija;

<a id="section-28-subsection-1-paragraph-5"></a>
- **5.** ohjelmajohtaja;

<a id="section-28-subsection-1-paragraph-6"></a>
- **6.** valtiovarainministeriön hallinto\- ja kehitysjohtaja\.
