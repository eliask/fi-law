# Valtioneuvoston asetus eräiden alusturvallisuudesta annettujen asetusten kumoamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä asetuksella kumotaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** eräiden tavarain ja elävien eläinten kuljetuksesta aluksessa annettu asetus [\(455/1958\)](<https://www.finlex.fi/fi/lainsaadanto/1958/455>);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** alusten vakavuudesta annettu asetus [\(588/1972\)](<https://www.finlex.fi/fi/lainsaadanto/1972/588>);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** alusten paloturvallisuudesta annettu asetus [\(152/1972\)](<https://www.finlex.fi/fi/lainsaadanto/1972/152>);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** eräiden alusten paloturvallisuudesta annettu asetus [\(289/1973\)](<https://www.finlex.fi/fi/lainsaadanto/1973/289>);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** alusten hengenpelastuslaitteista annettu asetus [\(29/1973\)](<https://www.finlex.fi/fi/lainsaadanto/1973/29>);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** eräistä huviveneitä varten annettavista todistuksista annettu asetus [\(308/1974\)](<https://www.finlex.fi/fi/lainsaadanto/1974/308>);

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** kemikaali\- ja kaasusäiliöaluksista annettu asetus [\(244/1982\)](<https://www.finlex.fi/fi/lainsaadanto/1982/244>);

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** viljan kuljetuksesta aluksessa annettu asetus [\(301/1988\)](<https://www.finlex.fi/fi/lainsaadanto/1988/301>);

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** alusten varalaidasta kotimaan liikenteessä annettu asetus [\(855/1988\)](<https://www.finlex.fi/fi/lainsaadanto/1988/855>)\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2013\.
