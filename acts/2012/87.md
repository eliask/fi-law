<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tämä asetus koskee seuraavissa valtioneuvoston asetuksissa säädettyjen maa\- ja puutarhatalouden kansallisten tukien hakemusten toimittamista sekä kotieläinten laskentapäiviä ja \-ajankohtia:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** vuodelta 2012 maksettavasta Etelä\-Suomen kansallisesta tuesta annettu valtioneuvoston asetus \(3/2012\), jäljempänä Etelä\-Suomen kansallinen tukiasetus ;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** vuodelta 2012 maksettavasta pohjoisesta tuesta annettu valtioneuvoston asetus \(4/2012\), jäljempänä pohjoinen tukiasetus ;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** vuodelta 2012 maksettavasta luonnonhaittakorvauksen kansallisesta lisäosasta annettu valtioneuvoston asetus \(7/2012\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** vuodelta 2012 maksettavasta sokerijuurikkaan kansallisesta tuesta annettu valtioneuvoston asetus \(5/2012\);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** vuodelta 2012 maksettavasta mehiläistalouden kansallisesta pesäkohtaisesta tuesta annettu valtioneuvoston asetus \(6/2012\);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** vuodelta 2011 maksettavasta sokerijuurikkaan kuljetustuesta annettu valtioneuvoston asetus \(85/2012\)\.

<a id="section-2"></a>
### 2 § Hakemusten toimittaminen

<a id="section-2-subsection-1"></a>
#### \(1\)

Kasvintuotannon tukien, luonnonhaittakorvauksen kansallisen lisäosan sekä kotieläintalouden tukien hakemukset, osallistumisilmoitukset ja kotieläintukien ennakkoa koskevat hakemukset sekä sokerijuurikkaan kuljetustuen hakemukset toimitetaan sen kunnan maaseutuelinkeinoviranomaiselle, jonka alueella maatilan talouskeskus sijaitsee\. Jos maatilalla ei ole talouskeskusta, hakemus toimitetaan sen kunnan maaseutuelinkeinoviranomaiselle, jonka alueella pääosa maatilan pelloista sijaitsee\.
