<a id="section-11"></a>
### 11§

<a id="section-11-subsection-1"></a>
#### \(1\)

Kunnassa pitää olla rakennusjärjestys\.

<a id="section-16"></a>
### 16§

<a id="section-16-subsection-1"></a>
#### \(1\)

Rakennusjärjestyksen hyväksyy kunnallisvaltuusto\. Päätös on alistettava kaupungin osalta sisäasiainministeriön ja maalaiskunnan osalta lääninhallituksen vahvistettavaksi\.

<a id="section-37"></a>
### 37§

<a id="section-37-subsection-1"></a>
#### \(1\)

Rakennuskortteliin kuuluva alue on jaettava tontteihin, milloin maanomistaja sitä pyytää tai se muutoin havaitaan tarpeelliseksi \(tonttijako\)\.

<a id="section-38"></a>
### 38§

<a id="section-38-subsection-1"></a>
#### \(1\)

Asemakaavan hyväksyy kaupunginvaltuusto\. Valtuuston päätösvaltaa voidaan vähäisten asemakaavan muutosten osalta siirtää kaupunginhallituksen ohjesäännöllä kaupunginhallitukselle sen mukaan kuin ohjesäännössä tarkemmin määrätään\. Asemakaavan hyväksymistä tai muuttamista koskeva päätös on alistettava sisäasiainministeriön vahvistettavaksi\.

<a id="section-38-subsection-2"></a>
#### \(2\)

Tonttijaon hyväksyy kaupunginhallitus\.

<a id="section-40"></a>
### 40§

<a id="section-40-subsection-1"></a>
#### \(1\)

Tontin tai sen osan omistajalla on oikeus tehdä kaupunginhallitukselle esitys tonttijaon muuttamisesta\.

<a id="section-42"></a>
### 42§

<a id="section-42-subsection-1"></a>
#### \(1\)

Rakennuskielto on voimassa:

<a id="section-42-subsection-1-paragraph-1"></a>
- **1.** rakennuskorttelissa tai sen osassa, jolle ei ole hyväksytty tontti jakoa;

<a id="section-42-subsection-1-paragraph-2"></a>
- **2.** tontilla, jota ei ole merkitty tonttirekisteriin;

<a id="section-42-subsection-1-paragraph-3"></a>
- **3.** alueella, jolle kaupunginvaltuusto on päättänyt laadittavaksi asemakaavan taikka jonka asemakaavaa tai tonttijakoa on päätetty muuttaa;

<a id="section-42-subsection-1-paragraph-4"></a>
- **4.** alueella, jolle on hyväksytty asemakaava tai asemakaavan muutos, kunnes sen vahvistamista koskeva alistus on ratkaistu; sekä

<a id="section-42-subsection-1-paragraph-5"></a>
- **5.** alueella, jolle sisäasiainministeriö jättäessään vahvistamatta asemakaavan tai sen muutoksen on antanut rakennuskiellon\.

<a id="section-69"></a>
### 69§

<a id="section-69-subsection-1"></a>
#### \(1\)

Valtion varoista suoritetaan kaupungille avustusta asemakaavan laatimisesta ja yleiseen tarkoitukseen käytettävien alueiden lunastamisesta aiheutuvien kustannusten peittämiseen harkinnan mukaan, milloin se kustannusten suuruuden ja kaupungin taloudellisen aseman vuoksi katsotaan tarpeelliseksi\.

<a id="section-95"></a>
### 95§

<a id="section-95-subsection-1"></a>
#### \(1\)

Maalaiskunnan taaja\-asutusta ja muuta sellaista aluetta varten, jonka rakentamisen ja muun maankäytön yksityiskohtainen järjestäminen on tarpeellista, on kunnan toimesta, sitä mukaa kuin kehitys vaatii, laadittava rakennuskaava\.

<a id="section-97"></a>
### 97§

<a id="section-97-subsection-1"></a>
#### \(1\)

Rakennuskaavan hyväksyy kunnanvaltuusto\. Valtuuston päätösvaltaa voidaan vähäisten rakennuskaavan muutosten osalta siirtää kunnanhallituksen ohjesäännöllä kunnanhallitukselle sen mukaan kuin ohjesäännössä tarkemmin määrätään\.

<a id="section-97-subsection-2"></a>
#### \(2\)

Rakennuskaavan hyväksymistä tai muuttamista koskeva päätös on alistettava lääninhallituksen vahvistettavaksi\.

<a id="section-99"></a>
### 99§

<a id="section-99-subsection-1"></a>
#### \(1\)

Milloin rakennuskaavan muuttaminen on pääasiallisesti yksityisen edun vaatima ja maanomistaja on sitä pyytänyt, kunnalla on oikeus omistajalta periä kohtuullinen palkkio tarvittavien karttojen laatimisesta ja kustannukset kuulutusten julkaisemisesta sanomalehdissä\.

<a id="section-100"></a>
### 100§

<a id="section-100-subsection-1"></a>
#### \(1\)

Uudisrakennusta ei saa rakentaa vastoin rakennuskaavaa \(rakentamisrajoitus\)\.

<a id="section-100-subsection-2"></a>
#### \(2\)

Rakennuskielto on voimassa:

<a id="section-100-subsection-2-paragraph-1"></a>
- **1.** alueella, jolle kunnanvaltuusto on päättänyt laadittavaksi rakennuskaavan tai jonka rakennuskaavaa on päätetty muuttaa;

<a id="section-100-subsection-2-paragraph-2"></a>
- **2.** alueella, jolle on hyväksytty rakennuskaava tai sen muutos, kunnes sen vahvistamista koskeva alistus on ratkaistu; sekä

<a id="section-100-subsection-2-paragraph-3"></a>
- **3.** alueella, jolle lääninhallitus jättäessään vahvistamatta rakennuskaavan tai sen muutoksen on antanut rakennuskiellon\.

<a id="section-100-subsection-3"></a>
#### \(3\)

Edellä 2 momentin 1 ja 3 kohdassa tarkoitettu rakennuskielto on voimassa enintään kaksi vuotta\. Lääninhallituksella on kuitenkin valta erityisestä syystä pitentää kieltoaikaa enintään kaksi vuotta kerrallaan\.

<a id="section-101"></a>
### 101§

<a id="section-101-subsection-1"></a>
#### \(1\)

Rakennuskaavaan voidaan enintään kolmen vuoden ajaksi kieltää uudisrakennuksen rakentaminen, ennen kuin välttämättömät liikenneväylät ja viemärit on järjestetty sekä veden saanti turvattu \(rakennuskielto\)\. Lääninhallituksella on valta erityisestä syystä pitentää kieltoaikaa enintään kolme vuotta kerrallaan\.

<a id="section-110"></a>
### 110§

<a id="section-110-subsection-1"></a>
#### \(1\)

Jollei aluetta, joka rakennuskaavassa on osoitettu yleisen rakennuksen rakennusmaaksi tai muuksi yleiseksi alueeksi kuin liikenneväyläksi, ole viiden vuoden kuluessa rakennuskaavan vahvistamisesta maanomistajan suostumuksella otettu tarkoitukseensa käytettäväksi tai sen pakkolunastamista pantu vireille, on kunnan, mikäli maanomistaja sitä vaatii, ryhdyttävä toimenpiteisiin rakennuskaavan muuttamiseksi, milloin maanomistaja rakennuskaavasta johtuvan rakentamisrajoituksen tähden ei voi kohtuullista hyötyä tuottavalla tavalla käyttää hyväkseen maataan\.

<a id="section-110-subsection-2"></a>
#### \(2\)

Milloin rakennuskaavaa ei voida kaavallisista syistä muuttaa, kunta on 1 momentissa sanotuin edellytyksin velvollinen lunastamaan yleisen alueen\. Jollei kunta täytä lunastusvelvollisuuttaan, omistajalla on oikeus kanteella vaatia sitä\. Jos tuomioistuin hyväksyy kauteen, omistaja saa hakea lunastuksen täytäntöönpanoa\.

<a id="section-115"></a>
### 115§

<a id="section-115-subsection-1"></a>
#### \(1\)

Rakennuskaava\-alueen mittaamisesta ja kartoittamisesta aiheutuneet hyväksyttävät kustannukset korvataan maalaiskunnalle valtion varoista\.

<a id="section-115-subsection-2"></a>
#### \(2\)

Rakennuskaavan laatimisesta ja maastoon merkitsemisestä sekä yleiseen tarkoitukseen käytettävien alueiden lunastamisesta aiheutuneiden kustannustien peittämiseen maalaiskunnalle suoritetaan valtion varoista avustusta harkinnan mukaan, milloin se kustannusten suuruuden ja kunnan taloudellisen aseman vuoksi katsotaan tarpeelliseksi\.

<a id="section-116"></a>
### 116§

<a id="section-116-subsection-1"></a>
#### \(1\)

Maalaiskuntaan tai sen johonkin osaan voidaan laatia asemakaava\.

<a id="section-117"></a>
### 117§

<a id="section-117-subsection-1"></a>
#### \(1\)

Milloin kunnanvaltuusto on päättänyt asemakaavan laadittavaksi sovelletaan alueella, jota päätös koskee vastaavasti mitä kaupungista on säädetty 5, 12, 14 ja 16 §:ssä sekä II ja IV osastossa\. Rakennuskielto on voimassa myös tontilla, josta osa kuuluu toiselle omistajalle\. Tontinosan lunastamista koskevia säännöksiä ei kuitenkaan sovelleta\.

<a id="section-127"></a>
### 127§

<a id="section-127-subsection-1"></a>
#### \(1\)

Vahvistettaessa kaava tai rakennusjärjestys niihin voidaan tehdä oikaisunluonteisia korjauksia\.

<a id="section-127-subsection-2"></a>
#### \(2\)

Päätös, jolla on hyväksytty kaava tai rakennusjärjestys, voidaan jättää vahvistamatta myös osittain\.

<a id="section-132"></a>
### 132§

<a id="section-132-subsection-1"></a>
#### \(1\)

Sisäasiainministeriöllä kaupungin osalta ja lääninhallituksella maalaiskunnan osalta on valta myöntää uudisrakennuksen rakentamista varten poikkeus rakentamista koskevista säännöksistä, määräyksistä, kielloista ja muista rajoituksista, milloin sen ei havaita tuottavan huomattavaa haittaa kaavoituksen toteuttamiselle tai asutuksen muullekaan järjestämiselle\. Edellä 42 §:n 1 momentissa ja 100 §:n 1 momentissa säädetystä rakentamisrajoituksesta ei saa kuitenkaan myöntää poikkeusta rakennuksen korkeuteen eikä kokonaan maanpäällisten kerrosten lukumäärään\.

<a id="section-132-subsection-2"></a>
#### \(2\)

Maistraatilla, järjestysoikeudella ja rakennuslautakunnalla on valta 1 momentissa sanotuin edellytyksin antaa rakennuslupa, milloin on kysymys vähäisestä poikkeamisesta uudisrakennuksen rakentamista koskevista säännöksistä, määräyksistä, kielloista tai muista rajoituksista tahi tilapäisen uudisrakennuksen rakentamisesta enintään viiden vuoden ajaksi taikka 42 §:n 2 momentin 3 kohdassa ja 100 §:n 2 momentin 1 kohdassa mainituista tapauksista, ottaen kuitenkin huomioon, mitä 5 §:ssä on säädetty\.

<a id="section-138"></a>
### 138§

<a id="section-138-subsection-1"></a>
#### \(1\)

Tämän lain taikka sen nojalla annettujen säännösten tai määräysten perusteella annetusta maistraatin, järjestysoikeuden tai rakennuslautakunnan päätöksestä sekä kaupunginhallituksen päätöksestä tonttijaon hyväksymistä koskevassa asiassa saa valittaa lääninhallitukselle\. Valitusaika on 14 päivää, rakennuslautakunnan päätöksestä valitettaessa 30 päivää, tiedoksi saamisesta\.

<a id="section-138-subsection-2"></a>
#### \(2\)

Valitusoikeus on sillä, jonka oikeutta päätös välittömästi koskee, ja viereisen tai vastapäätä olevan tontin tai rakennuspaikan haltijalla sekä maistraatin, järjestysoikeuden tai rakennuslautakunnan päätöksestä valitettaessa myös kunnallishallituksella\.

<a id="section-140"></a>
### 140§

<a id="section-140-subsection-1"></a>
#### \(1\)

Maistraatin, järjestysoikeuden ja rakennuslautakunnan päätös rakennuslupa\-asiassa sekä lääninhallituksen päätös, joka koskee rakennuskieltoa tai rakennuslupaa taikka 5 tai 132 §:ssä tarkoitettua lupaa, samoin kuin sisäasiainministeriön päätös, joka perustuu tähän lakiin tai sen nojalla annettuun asetukseen, on annettava julkipanon jälkeen\. Päätöksen katsotaan tulleen asianomaisen tietoon silloin, kun se on annettu\.

<a id="section-140-subsection-2"></a>
#### \(2\)

Mitä 1 momentissa on säädetty, ei sovelleta kunnalle tai seutukaavaliitolle suoritettavaa valtionapua tai koMausta koskevaan päätökseen\.

<a id="section-143"></a>
### 143§

<a id="section-143-subsection-1"></a>
#### \(1\)

Milloin rakennusjärjestyksen, asema\- tai rakennuskaavan taikka tonttijaon hyväksyminen tai niiden taikka yleiskaavan muuttaminen on katsottava tarpeelliseksi, sisäasiainministeriö voi asettaa määräajan, jonka kuluessa sitä koskeva päätös on tehtävä ja, tonttijakoa lukuun ottamatta, alistettava vahvistettavaksi\. Jos edellä mainittua määräystä ei noudateta, ministeriö voi, ryhtyä toimenpiteisiin linnan velvoittamiseksi siihen uhkasakolla\.

<a id="section-143-subsection-2"></a>
#### \(2\)

Mitä 1 momentissa on säädetty, sovelletaan vastaavasti, milloin seutukaavaliitto ei ryhdy toimenpiteisiin seutukaavan laatimiseksi tai tarpeellisten muutosten tekemiseksi siihen\.
