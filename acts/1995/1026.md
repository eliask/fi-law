## 5 a luku Telekuuntelu, televalvonta ja tekninen tarkkailu

<a id="chapter-5a-section-2"></a>
### 2 § Telekuuntelun edellytykset

<a id="chapter-5a-section-2-subsection-1"></a>
#### \(1\)

Kun on syytä epäillä jotakuta

<a id="chapter-5a-section-2-subsection-1-paragraph-1"></a>
- **1.** Suomen itsemääräämisoikeuden vaarantamisesta, sotaan yllyttämisestä, maanpetoksesta, törkeästä maanpetoksesta, vakoilusta, törkeästä vakoilusta, turvallisuussalaisuuden paljastamisesta, luvattomasta tiedustelutoiminnasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-2"></a>
- **2.** valtiopetoksesta, törkeästä valtiopetoksesta, valtiopetoksen valmistelusta,

<a id="chapter-5a-section-2-subsection-1-paragraph-3"></a>
- **3.** taposta, murhasta, surmasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-4"></a>
- **4.** törkeästä vapaudenriistosta, ihmisryöstöstä, panttivangin ottamisesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-5"></a>
- **5.** törkeästä ryöstöstä, törkeästä kiristyksestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-6"></a>
- **6.** törkeästä kätkemisrikoksesta, ammattimaisesta kätkemisrikoksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-7"></a>
- **7.** tuhotyöstä, liikennetuhotyöstä, törkeästä tuhotyöstä, törkeästä terveyden vaarantamisesta, ydinräjähderikoksesta, aluksen kaappauksesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-8"></a>
- **8.** törkeästä kiskonnasta,

<a id="chapter-5a-section-2-subsection-1-paragraph-9"></a>
- **9.** törkeästä rahanväärennyksestä,

<a id="chapter-5a-section-2-subsection-1-paragraph-10"></a>
- **10.** törkeästä ympäristön turmelemisesta,

<a id="chapter-5a-section-2-subsection-1-paragraph-11"></a>
- **11.** törkeästä huumausainerikoksesta taikka

<a id="chapter-5a-section-2-subsection-1-paragraph-12"></a>
- **12.** edellä mainittujen rikosten rangaistavasta yrityksestä,

- **12.** rikoksen esitutkintaa toimittavalle viranomaiselle voidaan antaa lupa kuunnella ja tallentaa televiestejä, joita epäilty lähettää hallussaan olevalla tai oletettavasti muuten käyttämällään teleliittymällä, tai tällaiseen teleliittymään tulevia hänelle tarkoitettuja viestejä, jos kuuntelulla saatavilla tiedoilla voidaan olettaa olevan erittäin tärkeä merkitys rikoksen selvittämiselle\.
