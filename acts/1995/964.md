# Ympäristöministeriön päätös asuntokauppalaissa tarkoitetusta kauppasopimuksen kaavasta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Kun perustajaosakas myy kuluttajalle asunto\-osakkeen rakentamisvaiheen aikana, kauppasopimuksessa on mainittava ainakin seuraavat tiedot:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1\..** Osapuolten ja kohteen yksilöinti

<a id="section-1-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** Myyjän ja ostajan nimi sekä yhteystiedot;

<a id="section-1-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** asuntoyhteisön toiminimi ja osoite;

<a id="section-1-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** kaupan kohteena olevien osakkeiden numerot;

<a id="section-1-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** asunnon osoite, sekä asunnon sijaintikiinteistöstä kunta, kaupunginosa tai kylä, kortteli ja tontin numero tai tilan nimi ja rekisterinumero;

<a id="section-1-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** asunnon numero, huoneluku sekä pinta\-alat eriteltyinä asuintiloihin ja muihin tiloihin sekä kerrostaloasunnon sijaintikerros;

<a id="section-1-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** asunnon käyttöä tai sen hallintaan oikeuttavien osakkeiden luovutusoikeutta koskevat rajoitukset sekä yhtiöllä, osakkeenomistajilla tai kunnalla oleva lunastusoikeus, jos tällaisia rajoituksia on; sekä

<a id="section-1-subsection-1-paragraph-1-subparagraph-g"></a>
  - **g.** maininta siitä, miltä osin ostaja täsmentää asunnon tai sen varusteiden yksityiskohtia myöhemmin sekä täsmennyksen ajankohta, jos tällaisesta halutaan sopia\.

<a id="section-1-subsection-1-paragraph-2"></a>
- **2\..** Kauppahinta ja sen maksaminen

<a id="section-1-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** Kauppahinta sekä velaton hinta, jos se poikkeaa myyntihinnasta;

<a id="section-1-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** maininta mahdollisen käsirahan määrästä ja siitä, että se sisältyy kauppahintaan;

<a id="section-1-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** talletuspankin tili, jolle kauppahinta on maksettava myyjän lukuun;

<a id="section-1-subsection-1-paragraph-2-subparagraph-d"></a>
  - **d.** kauppahinnan maksuaikataulu ja muut maksuehdot mukaanlukien ehto siitä, kuinka suuren osan kauppahinnasta myyjä saa käyttöönsä asuntokauppalain \(843/94\) 4 luvun 29 § 3 momentin mukaisesti eli aikaisintaan kuukauden kuluttua siitä, kun asunnon hallinta on luovutettu ostajalle;

<a id="section-1-subsection-1-paragraph-2-subparagraph-e"></a>
  - **e.** ehto ostajan oikeudesta saada hyvityskorkoa kauppahintaerien ennenaikaisen maksun yhteydessä, jos tällaisesta halutaan sopia;

<a id="section-1-subsection-1-paragraph-2-subparagraph-f"></a>
  - **f.** ehto viivästyskoron maksuvelvollisuudesta; sekä

<a id="section-1-subsection-1-paragraph-2-subparagraph-g"></a>
  - **g.** ehto siitä, maksaako leimaveron ostaja vai myyjä\.

<a id="section-1-subsection-1-paragraph-3"></a>
- **3\..** Turva\-asiakirjat

<a id="section-1-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** Asuntokauppa\-asetuksen \(854/95\) 2 §:ssä lueteltujen turva\-asiakirjojen ja osakekirjojen tai väliaikaistodistuksen säilytyspaikka ja säilytyspaikan osoite;

<a id="section-1-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** ne asuntokauppalain 2 luvun 9 §:n 1 momentissa mahdollistetut syyt, joiden perusteella varataan mahdollisuus muuttaa taloussuunnitelmaa, jos tällaisesta halutaan sopia;

<a id="section-1-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** myyjän velvollisuus toimittaa tieto kauppasopimuksesta turva\-asiakirjojen säilyttäjälle;

<a id="section-1-subsection-1-paragraph-3-subparagraph-d"></a>
  - **d.** ostajan oikeus siirtää edelleen kauppakirjaan perustuvat oikeutensa tai pantata ne; sekä

<a id="section-1-subsection-1-paragraph-3-subparagraph-e"></a>
  - **e.** ostajan velvollisuus antaa tieto kauppasopimuksen tuottamien oikeuksien luovutuksesta tai panttauksesta turva\-asiakirjojen säilyttäjälle\.

<a id="section-1-subsection-1-paragraph-4"></a>
- **4\..** Asunnon valmistuminen ja omistusoikeuden siirtyminen

<a id="section-1-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** Asunnon valmistumisajankohta ja hallinnan luovutusajankohta tai näitä koskeva arvio;

<a id="section-1-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** ehto siitä, että viivästystä koskevia asuntokauppalain säännöksiä sovelletaan vasta, kun asunnon hallinnan luovutus myöhästyy arviona ilmoitetusta valmistumisajankohdasta enemmän kuin 30 päivää, jos myyjä haluaa vedota tähän mahdollisuuteen;

<a id="section-1-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** osakkeiden omistusoikeuden siirtymisajankohta ja osakekirjan tai väliaikaistodistuksen luovutusajankohta;

<a id="section-1-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** ostajan asuntoyhteisölle maksettavan yhtiövastikkeen sekä muiden osakkeiden omistamisesta tai asunnon hallinnasta johtuvien maksuvelvollisuuksien alkamisajankohta; sekä

<a id="section-1-subsection-1-paragraph-4-subparagraph-e"></a>
  - **e.** ostajalle maksettavan korvauksen suuruus tai suuruuden määräytymisperusteet silloin, kun myyjän suoritus viivästyy, jos tällaisesta vakiokorvauksesta halutaan sopia, sekä maininta siitä, että ostajalla on vakiokorvauksen estämättä oikeus saada asuntokauppalain 4 luvun 11 §:n mukaisesti korvaus kaikesta myyjän viivästyksen vuoksi kärsimästään vahingosta\.

<a id="section-1-subsection-1-paragraph-5"></a>
- **5\..** Kaupan purku ja peruuttaminen

<a id="section-1-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** Ostajan maksettavaksi tulevan korvauksen suuruus myyjän purkaessa kaupan ostajan maksuviivästyksen vuoksi tai ostajan peruuttaessa kaupan ennen asunnon luovutusta, jos tällaisesta vakiokorvauksesta halutaan sopia; sekä

<a id="section-1-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** maininta perustajaosakkaan velvollisuudesta ilmoittaa kaupan purusta tai peruuttamisesta turva\-asiakirjojen säilyttäjälle\.

<a id="section-1-subsection-1-paragraph-6"></a>
- **6\..** Vakuudet ja rakennusaikainen valvonta

<a id="section-1-subsection-1-paragraph-6-subparagraph-a"></a>
  - **a.** Selvitys asuntokauppalain 2 luvun 17 §:ssä tarkoitettujen rakentamisvaiheen vakuuden ja rakentamisvaiheen jälkeisen vakuuden lajeista ja määristä;

<a id="section-1-subsection-1-paragraph-6-subparagraph-b"></a>
  - **b.** maininta osakkeenostajien oikeudesta valita osakkeenostajien kokouksessa osakeyhtiölle tilintarkastaja ja rakennustyön tarkkailija;

<a id="section-1-subsection-1-paragraph-6-subparagraph-c"></a>
  - **c.** maininta velvollisuudesta vapauttaa vakuudet, kun oikeus niiden pitämiseen on päättynyt; sekä

<a id="section-1-subsection-1-paragraph-6-subparagraph-d"></a>
  - **d.** myyjän ostajalle antama erityinen takuu, jos tällainen sitoumus annetaan\.

<a id="section-1-subsection-1-paragraph-7"></a>
- **7\..** Vuositarkastus ja virheilmoitukset

<a id="section-1-subsection-1-paragraph-7-subparagraph-a"></a>
  - **a.** Maininta myyjän velvollisuudesta järjestää asuntokauppalain 4 luvun 18 §:ssä tarkoitettu vuositarkastus ja selvitys tavasta, jolla tarkastuksesta ilmoitetaan ostajalle;

<a id="section-1-subsection-1-paragraph-7-subparagraph-b"></a>
  - **b.** maininta siitä, että ostaja menettää oikeutensa vedota virheeseen, joka hänen olisi pitänyt havaita viimeistään vuositarkastuksessa, ellei hän ilmoita siitä kohtuullisessa, vähintään kolmen viikon pituisessa ajassa vuositarkastuspöytäkirjan tiedoksisaannista; sekä

<a id="section-1-subsection-1-paragraph-7-subparagraph-c"></a>
  - **c.** maininta siitä, että ostaja menettää oikeutensa vedota virheeseen, jota hänen ei voida edellyttää havainneen vuositarkastuksessa tai sitä ennen, ellei hän ilmoita virheestä kohtuullisessa ajassa siitä, kun hän on virheen havainnut tai hänen olisi pitänyt se havaita\.

<a id="section-1-subsection-1-paragraph-8"></a>
- **8\..** Sopimuksen laatiminen

<a id="section-1-subsection-1-paragraph-8-subparagraph-a"></a>
  - **a.** Maininta siitä, kuinka monena kappaleena sopimus tehdään ja keille sopimuskappaleet annetaan; sekä

<a id="section-1-subsection-1-paragraph-8-subparagraph-b"></a>
  - **b.** päiväys ja osapuolten allekirjoitukset\.
