# Kauppa\- ja teollisuusministeriön päätös ylläpidettävistä kansallisista mittanormaaleista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Seuraavista perusyksiköistä ja niiden avulla määritellyistä muista mittayksiköistä ylläpidetään kansallisia mittanormaaleja:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** pituuden yksikkö metri;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** massan yksikkö kilogramma;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ajan yksikkö sekunti;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** sähkövirran yksikkö ampeeri;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** termodynaamisen lämpötilan yksikkö kelvin;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** valovoiman yksikkö kandela;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** tasokulman yksikkö radiaani;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** tilavuusvirran yksikkö m 3 /s;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** paineen yksikkö pascal;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** voiman yksikkö newton;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** energian yksikkö joule; sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** tehon yksikkö watti\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Lisäksi ylläpidetään maan vetovoiman putoamiskiihtyvyyden kansallista mittanormaalia\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä huhtikuuta 1995\.
