# Valtiovarainministeriön päätös tilastokeskuksen suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja suoritteita, jotka tilastokeskus hinnoittelee liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** tilastoalan kirjat, lehdet ja kustannuspalvelut;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** yritysrekisteri\- ja LY\-tunnuspalvelut;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** muista kuin 2 §:ssä tarkoitetuista aineistoista tilauksesta tehdyt selvitykset, tutkimukset sekä haastattelu\- ja muut tiedonkeruupalvelut;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** tilastojen laadinnan kokonaispalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** koulutus\- ja konsultointipalvelut sekä tietopalvelu;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** tietotekniikkapalvelut;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** tilastokeskuksen hallitsemien tilojen ja laitteiden luovuttaminen viraston henkilöstön yksityiseen käyttöön ja viraston ulkopuoliseen käyttöön;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** välityspalvelut;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** ohjelmien ja niiden käyttöoikeuksien luovuttaminen;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** ilmoitukset viraston lehdissä ja julkaisuissa;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** kaukolainapalvelut;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** muut edellä mainittuihin verrattavat palvelusuoritteet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Liiketaloudellisin perustein hinnoitellaan myös seuraavat osittain tai kokonaan tilasto\- keskuksen valmiista aineistoista tuotetut suoritteet:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tilastojulkaisut ja \-tiedotteet sekä tilastotoimen käsikirjat käsite\-, määritelmä ja luokitusstandardeista;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** tietokanta\- ja muut suorakäyttöpalvelut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** tilauksesta tehdyt selvitykset ja tutkimukset;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** puhelintietopalvelut;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** valokopio\- ja muut jäljennökset\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Kuolintodistusten jäljennökset, jotka annetaan asianomaisille viranomaisille ja vakuutuslaitoksille sekä vainajan lähimmille omaisille yksittäiskappaleina, ovat maksuttomia\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tilastokeskuksen maksuttomia suoritteita ovat:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** kansainvälisten sitoumusten mukaiset tilastoraportit;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** lehdistötiedotteet tiedotusvälineille;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** vähäiset opastus\- ja neuvontapalvelut;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** tieteellisen tilastoalan keskuskirjaston muut kuin 1 §:ssä tarkoitetut lainauspalvelut ja vaihtojulkaisut\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1996 ja on voimassa 31 päivään joulukuuta 1997\.
