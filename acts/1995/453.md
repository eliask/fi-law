# Asetus  vakuutusyhdistyksen vastuuvelan laskentaperiaatteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Vakuutusyhdistyksen vastuuvelkaa laskettaessa on noudatettava seuraavia periaatteita:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Vastuuvelan on aina oltava riittävä siten, että vakuutusyhdistyksen voidaan katsoa kohtuudella arvioiden selviytyvän yhdistyksen vakuutussopimuksista aiheutuvista velvoitteista\.

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Vakuutusyhdistys voi käyttää vastuuvelan laskennassa tilastollisia menetelmiä\. Yhdistyksen on pystyttävä selvittämään käyttämiensä tilastollisten menetelmien asianmukaisuus oman aineistonsa perusteella tai tilastoaineistolla, joka on kerätty sen omaa vakuutuskantaa vastaaviksi katsottavista vakuutuskannoista\.

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Eläkemuotoisten korvausten vastuuvelka lasketaan tavanomaisin henkivakuutuksessa sovellettavin menetelmin\. Käytettävä korkokanta on valittava kohdassa 4 määriteltävällä tavalla\.

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Korkoutuksen käyttö on sallittu muissa kuin kohdassa 3 tarkoitetuissa vastuuvelkalaskelmissa vain, jos se tehdään niin, että korkoutuksen vaikutus on selvitettävissä, ja jos seuraavat ehdot täyttyvät:

<a id="section-1-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** vahinkoryhmän keskimääräisen selviämisajan arvioidaan olevan vähintään neljä vuotta;

<a id="section-1-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** korkoutus suoritetaan turvaavalla tavalla ja noudatettavasta korkoutustavasta ilmoitetaan Vakuutusvalvontavirastolle etukäteen;

<a id="section-1-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** vakuutusyhdistys ottaa huomioon kokonaiskorvausmenoa arvioidessaan kaikki sitä mahdollisesti lisäävät tekijät;

<a id="section-1-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** vakuutusyhdistys pystyy johtamaan käyttämänsä laskentamallin luotettavasti omasta aineistostaan tai omaa vakuutuskantaansa vastaaviksi katsottavista vakuutuskannoista laaditusta tilastoaineistosta; sekä

<a id="section-1-subsection-1-paragraph-4-subparagraph-e"></a>
  - **e.** käytettävä laskuperustekorko ei ylitä vastuuta kattavan omaisuuden turvaavasti määrättyä sijoitustuoton tasoa vahinkojen keskimääräisenä arvioituna selviämisaikana\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Käytetystä korkoutusmenetelmästä on tehtävä selkoa yhdistyksen taseen liitetiedoissa\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Asianomainen ministeriö voi antaa tarkempia määräyksiä 1 momentissa lueteltujen periaatteiden soveltamisesta\. Samoin ministeriö määrittelee ne yleiset periaatteet, joita noudatetaan vakuutusyhdistyksen tasoitusmäärää laskettaessa\. Yhdistyksen on haettava etukäteen Vakuutusvalvontaviraston vahvistus tavalle, jolla se soveltaa edellä tarkoitetuja tasoitusmäärän yleisiä laskentaperiaatteita\.
