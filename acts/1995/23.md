# Työministeriön päätös eräiden työsuojelun valvontaa koskevien päätösten kumoamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä päätöksellä kumotaan sosiaali\- ja terveysministeriön 28\.5\.1975 antama päätös työsuojelutoimikuntien perustamisesta \(386/75\) ja seuraavat työsuojeluhallituksen antamat päätökset koneiden ja laitteiden tyyppitarkastuksesta ja ilmoittamisesta:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** 14\.8\.1974 annettu päätös muovialan ruiskupuristus\- ja muottiinpuhalluskoneista \(2400/021/74\);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** 10\.7\.1975 annettu päätös lumilingoista \(277/71/74\);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** 24\.7\.1975 annettu päätös puutarhatraktoreista \(2511/021/75\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** 24\.7\.1975 annettu päätös tasoleikkureista \(2554/021/75\);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** 24\.7\.1975 annettu päätös hydraulisista ja pneumaattisista puristimista \(2629/021/75\);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** 11\.9\.1975 annettu päätös paperikoneista ja \-leikkureista \(405/01/75\);

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** 3\.2\.1983 annettu päätös leikkuupuimureista \(3188/164/82\);

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** 11\.4\.1985 annettu päätös rakennushisseistä \(1375/0131/81\);

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** 11\.4\.1985 annettu päätös nivelakseleista \(870/164/84\);

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** 16\.11\.1989 annettu päätös henkilönostimista \(664/691/89\);

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** 28\.2\.1991 annettu päätös radio\-ohjatuista nostureista \(14/691/91\) ja

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** 9\.5\.1991 annettu päätös autonostimista \(1665/1684/80\)\.
