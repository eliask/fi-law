<a id="section-1"></a>
### 1 § Ministeriön tehtävät

<a id="section-1-subsection-1"></a>
#### \(1\)

Sisäministeriön tehtäviä ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** poliisihallinto;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** yleinen järjestys ja turvallisuus;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** sisäministeriön hallinnonalan rikostorjunta;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** poliisin lupahallinto;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ampuma\-aseet;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** arpajaiset;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** yksityinen turvallisuusala;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** pelastustoimi;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** hätäkeskustoiminta;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** aluehallinnon yhteinen varautuminen poikkeusoloihin ja häiriötilanteisiin ja siihen liittyvät keskushallinnon tehtävät;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Suomen kansalaisuus;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** maahanmuuton yleiset edellytykset ja maahanmuuton sääntely lukuun ottamatta työntekijöiden, yrittäjien, harjoittelijoiden, opiskelijoiden ja tutkijoiden maahanmuuttoa sekä kansainvälinen suojelu;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** turvapaikanhakijoiden vastaanotto ja joukkopakotilanteisiin varautuminen;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** ulkomaalaislain \(301/2004\) nojalla tapahtuva säilöönotto;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** paluumuuttoon, maastamuuttoon ja ulkosuomalaisiin liittyvät asiat;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** ulkomaan kansalaisten paluu ja palauttaminen;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** rajaturvallisuuden ylläpitäminen, rajojen valvonta, rajatarkastukset ja meripelastustoimi;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** siviilikriisinhallinnan kotimaan valmiuksien yhteensovittaminen;

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** Suomen lippu ja Suomen vaakuna;

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** hengenpelastusmitalit ja Suomen Punaisen Ristin ansiomerkit;

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** Euroopan unionin sisäasioiden rahastojen hallinnointi\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Sen lisäksi, mitä valtioneuvoston ohjesäännössä \(262/2003\) tai muutoin säädetään, sisäministeriön osastojen ja erillisten yksiköiden tehtävistä säädetään ministeriön työjärjestyksessä\.

<a id="section-2"></a>
### 2 § Ministeriön toimialaan kuuluvat virastot, laitokset, yhtiöt ja muut toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Poliisihallitus;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** keskusrikospoliisi;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** suojelupoliisi;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Poliisiammattikorkeakoulu;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** poliisilaitokset;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Pelastusopisto;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Hätäkeskuslaitos;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Palosuojelurahasto;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Maahanmuuttovirasto;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** turvapaikanhakijoiden vastaanottokeskukset;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Rajavartiolaitos;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Kriisinhallintakeskus\.
