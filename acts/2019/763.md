# Valtioneuvoston asetus yhteistoiminnasta yrityksissä annetussa laissa säädetyn hyvityksen enimmäismäärän tarkistamisesta

- Statute: [`763/2019`](<https://www.finlex.fi/fi/laki/ajantasa/2019/763>)
- Version: `2019-07-01`
- LawVM tree hash: `657f579ff46e8fc6aee9640fc32241f15d248e16bb0191e936a605847cb182ec`

## Contents

- [1 §](#section-1)

- [2 §](#section-2)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Yhteistoiminnasta yrityksissä annetun lain [\(334/2007\) 62 §:n](<https://www.finlex.fi/fi/lainsaadanto/2007/334#chp_9__sec_62>) 1 momentissa säädetyn hyvityksen enimmäismäärä on 35 590 euroa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä heinäkuuta 2019\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** yhteistoiminnasta yrityksissä annetussa laissa säädetyn hyvityksen enimmäismäärän tarkistamisesta annettu valtioneuvoston asetus [\(543/2010\)](<https://www.finlex.fi/fi/lainsaadanto/2010/543>);

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** yhteistoiminnasta yrityksissä annetussa laissa säädetyn hyvityksen enimmäismäärän tarkistamisesta annettu valtioneuvoston asetus [\(536/2013\)](<https://www.finlex.fi/fi/lainsaadanto/2013/536>);

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** yhteistoiminnasta yrityksissä annetussa laissa säädetyn hyvityksen enimmäismäärän tarkistamisesta annettu valtioneuvoston asetus [\(581/2016\)](<https://www.finlex.fi/fi/lainsaadanto/2016/581>)\.
