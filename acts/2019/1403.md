<a id="section-2"></a>
### 2 § Määritelmät

<a id="section-2-subsection-1"></a>
#### \(1\)

Tässä laissa ja sen nojalla annetuissa asetuksissa tarkoitetaan:

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kansainvälisillä yleissopimuksilla :

<a id="section-2-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** ihmishengen turvallisuudesta merellä vuonna 1974 tehtyä kansainvälistä yleissopimusta \(SopS 11/1981\), jäljempänä SOLAS\-yleissopimus, siihen myöhemmin tehtyine muutoksineen;

<a id="section-2-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** alusten aiheuttaman meren pilaantumisen ehkäisemisestä vuonna 1973 tehtyyn kansainväliseen yleissopimukseen liittyvää vuoden 1978 pöytäkirjaa \(SopS 51/1983\), jäljempänä MARPOL 73/78 ‑yleissopimus ;

<a id="section-2-subsection-1-paragraph-5-subparagraph-c"></a>
  - **c.** kansainvälistä merenkulkijoiden koulutusta, pätevyyskirjoja ja vahdinpitoa koskevaa vuoden 1978 yleissopimusta \(SopS 22/1984\), jäljempänä STCW\-yleissopimus ;

<a id="section-2-subsection-1-paragraph-5-subparagraph-d"></a>
  - **d.** kansainvälisistä säännöistä yhteentörmäämisen ehkäisemiseksi merellä vuonna 1972 tehtyä kansainvälistä yleissopimusta \(SopS 30/1977\), jäljempänä COLREG\-yleissopimus ;

<a id="section-2-subsection-1-paragraph-5-subparagraph-e"></a>
  - **e.** vuoden 1969 kansainvälistä aluksenmittausyleissopimusta \(SopS 31/1982\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-f"></a>
  - **f.** yleissopimusta \(n:o 147\), joka koskee kauppa\-aluksissa noudatettavaa vähimmäistasoa \(SopS 54/1979\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-g"></a>
  - **g.** öljyn aiheuttamasta pilaantumisvahingosta johtuvasta siviilioikeudellisesta vastuusta vuonna 1969 tehdyn kansainvälisen yleissopimuksen muuttamisesta tehtyä vuoden 1992 pöytäkirjaa \(SopS 43/1996\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-h"></a>
  - **h.** vuoden 1966 kansainvälistä lastiviivayleissopimusta \(SopS 52/1968\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-i"></a>
  - **i.** merityötä koskevaa vuoden 2006 yleissopimusta \(SopS 52/2013\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-j"></a>
  - **j.** vuoden 2001 yleissopimusta alusten haitallisten kiinnittymisenestojärjestelmien rajoittamisesta \(SopS 93/2010\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-k"></a>
  - **k.** vuoden 2001 kansainvälistä yleissopimusta aluksen polttoaineen aiheuttamasta pilaantumisvahingosta johtuvasta siviilioikeudellisesta vastuusta \(SopS 4/2009\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-l"></a>
  - **l.** vuoden 2007 hylkyjen poistamista koskevaa kansainvälistä yleissopimusta \(Nairobin yleissopimus\) \(SopS 14/2017\);

<a id="section-2-subsection-1-paragraph-5-subparagraph-m"></a>
  - **m.** vastuusta ja vahingonkorvauksesta vaarallisten ja haitallisten aineiden merikuljetusten yhteydessä vuonna 1996 tehdyn kansainvälisen yleissopimuksen vuoden 2010 pöytäkirjaa \(1400/2019\);
