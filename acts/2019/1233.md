<a id="section-7"></a>
### 7 § Syyttäjät

<a id="section-7-subsection-1"></a>
#### \(1\)

Syyttäjiä ovat:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** valtakunnansyyttäjä ja apulaisvaltakunnansyyttäjä;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** valtionsyyttäjä;

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** johtava aluesyyttäjä ja johtava maakunnansyyttäjä;

<a id="section-7-subsection-1-paragraph-4"></a>
- **4.** erikoissyyttäjä;

<a id="section-7-subsection-1-paragraph-5"></a>
- **5.** aluesyyttäjä ja maakunnansyyttäjä;

<a id="section-7-subsection-1-paragraph-6"></a>
- **6.** apulaissyyttäjä\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Suomen kansallisesta jäsenestä Eurojustissa säädetään Suomen osallistumisesta Euroopan unionin rikosoikeudellisen yhteistyön viraston \(Eurojust\) toimintaan annetussa laissa \(1232/2019\)\.
