# Oikeusministeriön asetus  eräistä Tietosuojavaltuutetun toimiston maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tietosuojavaltuutetun toimisto perii yhteisötilaajilta liitteenä olevan maksutaulukon mukaisen maksun seuraavista tietoyhteiskuntakaaren [\(917/2014\) 305 §:n](<https://www.finlex.fi/fi/lainsaadanto/2014/917#chp_38__sec_305>) 2 momentin 1 kohdassa tarkoitettuun valvontatehtävään liittyvistä julkisoikeudellisista suoritteista:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ennakkoilmoituksen käsittely;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** vuosittaisen selvityksen käsittely;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** olennaista muutosta koskevan ilmoituksen käsittely;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** valvonnan edellyttämän tarkastuksen toimittaminen\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Suoritteista, jotka Tietosuojavaltuutetun toimisto hinnoittelee valtion maksuperustelain [\(150/1992\) 7 §:n](<https://www.finlex.fi/fi/lainsaadanto/1992/150#chp_2__sec_7>) mukaisesti, säädetään oikeusministeriön ja eräiden hallinnonalalla toimivien viranomaisten maksullisista suoritteista annetun oikeusministeriön asetuksen [\(1745/2015\) 3 §:ssä](<https://www.finlex.fi/fi/lainsaadanto/2015/1745#sec_3>)\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2017 ja on voimassa 31 päivään joulukuuta 2018\.
