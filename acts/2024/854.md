<a id="section-1"></a>
### 1 § Ministeriön tehtävät

<a id="section-1-subsection-1"></a>
#### \(1\)

Oikeusministeriön tehtäviä ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** lainvalmistelu valtiosääntöoikeuden, yleisen hallinto\-oikeuden, yksityisoikeuden sekä rikos\- ja prosessioikeuden alalla, sekä muut lainsäädäntöasiat, jotka eivät kuulu toisen ministeriön toimialaan;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** valtioneuvoston lainvalmistelun kehittäminen ja neuvonta Euroopan unionin oikeuteen liittyvissä asioissa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** tuomioistuimet, oikeudenkäyntimenettely ja oikeudellinen jaotus;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** oikeusapu ja yleinen asianajajayhdistys;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** talous\- ja velkaneuvonta;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** yleinen edunvalvonta;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** syyttäjäntoimi;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** ulosottotoimi ja konkurssipesien hallinnon valvonta;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** sakkorangaistusten, yhdyskuntaseuraamusten ja vankeusrangaistusten täytäntöönpano;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** rikoksentorjunnan ja muun kriminaalipolitiikan yleinen suunnittelu;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** rikoksen uhrien aseman kehittäminen, jos asia ei kuulu toisen ministeriön toimialaan;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** rikosrekisteri ja muut oikeusrekisterit;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** armahdusasiat;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** avioliitto\-oikeudelliset hakemukset;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** kansainvälinen oikeudenhoito, jos asia ei kuulu toisen ministeriön toimialaan;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** Oikeuskanslerinvirasto lukuun ottamatta sen taloushallintoa;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** valtiolliset vaalit, alue\- ja kuntavaalit, kansanäänestykset sekä kansalaisvaikuttamisen edistäminen;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** puoluerekisteri sekä puolueiden muu kuin tilinpidon ja varainkäytön valvonta;

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** kielilain \(423/2003\) täytäntöönpanon seuranta;

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** Suomen säädöskokoelma;

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** onnettomuuksien tutkinta;

<a id="section-1-subsection-1-paragraph-22"></a>
- **22.** Ahvenanmaan maakunnan itsehallinto;

<a id="section-1-subsection-1-paragraph-23"></a>
- **23.** saamelaisten kulttuuri\-itsehallinto ja saamelaisasioiden yhteensovittaminen;

<a id="section-1-subsection-1-paragraph-24"></a>
- **24.** Haagin kansainvälisen yksityisoikeuden konferenssi;

<a id="section-1-subsection-1-paragraph-25"></a>
- **25.** yhdenvertaisuus ja hyvien etnisten suhteiden edistäminen\.

<a id="section-2"></a>
### 2 § Ministeriön toimialaan kuuluvat virastot, laitokset ja toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Oikeusministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** korkein oikeus;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** korkein hallinto\-oikeus;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** hovioikeudet;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** hallinto\-oikeudet;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Ahvenanmaan hallintotuomioistuin;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** käräjäoikeudet;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** markkinaoikeus;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** työtuomioistuin;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** vakuutusoikeus;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Tuomioistuinvirasto

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Rikosseuraamuslaitos;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Rikosseuraamusalan koulutuskeskus;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Syyttäjälaitos;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** Ulosottolaitos;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Oikeuspalveluvirasto;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Oikeushallinnon erityisviranomaiset \-virasto, jossa toimivat konkurssiasiamies, kuluttajariitalautakunta, lapsiasiavaltuutettu, oikeudenkäyntiavustajalautakunta, Onnettomuustutkintakeskus, tasa\-arvovaltuutettu, tiedusteluvalvontavaltuutettu, tietosuojavaltuutettu; vanhusasiavaltuutettu; yhdenvertaisuusvaltuutettu ja Yhdistyneiden Kansakuntien yhteydessä toimiva Euroopan kriminaalipolitiikan instituutti;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** Oikeusrekisterikeskus;

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** yhdenvertaisuus\- ja tasa\-arvolautakunta;

<a id="section-2-subsection-1-paragraph-19"></a>
- **19.** saamelaiskäräjät;

<a id="section-2-subsection-1-paragraph-20"></a>
- **20.** tuomarinvalintalautakunta;

<a id="section-2-subsection-1-paragraph-21"></a>
- **21.** tuomarinkoulutuslautakunta;

<a id="section-2-subsection-1-paragraph-22"></a>
- **22.** nimilautakunta\.
