# Valtioneuvoston asetus eräiden maatalouden tuista annettujen valtioneuvoston asetusten kumoamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Tällä asetuksella kumotaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** täydentävien ehtojen hyvän maatalouden ja ympäristön vaatimuksista annettu valtioneuvoston asetus [\(4/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/4>);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** täydentävien ehtojen lakisääteisistä hoitovaatimuksista sekä niiden ja hyvän maatalouden ja ympäristön vaatimusten noudattamisen valvonnasta annettu valtioneuvoston asetus [\(7/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/7>);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** eläinten hyvinvointikorvauksesta annettu valtioneuvoston asetus [\(121/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/121>);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** perustuesta, viherryttämistuesta ja nuoren viljelijän tuesta annettu valtioneuvoston asetus [\(234/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/234>);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ympäristökorvauksesta annettu valtioneuvoston asetus [\(235/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/235>);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** luonnonhaittakorvauksesta annettu valtioneuvoston asetus [\(236/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/236>);

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** luonnonmukaisen tuotannon korvauksesta annettu valtioneuvoston asetus [\(237/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/237>);

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** ei\-tuotannollisia investointeja koskevasta korvauksesta annettu valtioneuvoston asetus [\(238/2015\)](<https://www.finlex.fi/fi/lainsaadanto/2015/238>)\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 3 päivänä joulukuuta 2024\.
