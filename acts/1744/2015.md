# Oikeusministeriön asetus eräistä tuomioistuinten hakemusmaksuista

### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään eräiden käräjäoikeudessa, hovioikeudessa ja markkinaoikeudessa hakemuksesta vireille tulevien asioiden käsittelymaksuista\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Käräjäoikeudessa hakemusmaksu peritään avioeroa, tuomioistuinsovittelua, konkurssia ja saneerausmenettelyä koskevissa asioissa sekä muissa sellaisissa asioissa, jotka tulevat vireille hakemuksesta ja jotka käsitellään [oikeudenkäymiskaaren 8 luvussa](<https://www.finlex.fi/fi/lainsaadanto/1734/4-000#chp_8>) säädetyssä järjestyksessä\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Hovioikeudessa hakemusmaksu peritään hakemuksesta vireille tulevissa asioissa\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Markkinaoikeudessa hakemusmaksu peritään hakemuksesta vireille tulevissa asioissa, ei kuitenkaan oikeudenkäynnistä markkinaoikeudessa annetun lain [\(100/2013\) 6 §:ssä](<https://www.finlex.fi/fi/lainsaadanto/2013/100>) tarkoitetuissa markkinaoikeudellisissa asioissa\.

<a id="section-2"></a>
### 2 § Käräjäoikeuden hakemusmaksut

<a id="section-2-subsection-1"></a>
#### \(1\)

Hakemusasian käsittelystä käräjäoikeuden kansliassa tai istunnossa peritään hakemusmaksuja tämän pykälän mukaisesti\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Hakemuksesta vireille tulevan asian käsittelystä peritään 250 euroa, jollei jäljempänä toisin säädetä\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Jäljempänä mainittujen hakemusasioiden käsittelystä peritään seuraavat hakemusmaksut:

<a id="section-2-subsection-3-paragraph-1"></a>
- **1.** avioero:

<a id="section-2-subsection-3-paragraph-1-subparagraph-a"></a>
  - **a.** 200 euroa;

<a id="section-2-subsection-3-paragraph-1-subparagraph-b"></a>
  - **b.** jos asia siirretään istuntokäsittelyyn, maksu peritään kuten riita\-asiassa;

<a id="section-2-subsection-3-paragraph-1-subparagraph-c"></a>
  - **c.** asian jatkokäsittely harkinta\-ajan jälkeen 100 euroa;

<a id="section-2-subsection-3-paragraph-2"></a>
- **2.** tuomioistuinsovittelu:

<a id="section-2-subsection-3-paragraph-2-subparagraph-a"></a>
  - **a.** jos sovittelua ei aloiteta, 100 euroa;

<a id="section-2-subsection-3-paragraph-2-subparagraph-b"></a>
  - **b.** jos sovittelu aloitetaan, 250 euroa;

<a id="section-2-subsection-3-paragraph-3"></a>
- **3.** konkurssi:

<a id="section-2-subsection-3-paragraph-3-subparagraph-a"></a>
  - **a.** konkurssiin asettamista koskevassa asiassa hakijalta peritään 300 euroa, jollei velallista aseteta konkurssiin;

<a id="section-2-subsection-3-paragraph-3-subparagraph-b"></a>
  - **b.** konkurssiin asettamisesta peritään konkurssipesältä 650 euroa;

<a id="section-2-subsection-3-paragraph-3-subparagraph-c"></a>
  - **c.** jakoluettelon vahvistamiseen päättyvästä konkurssiasiasta 750 euroa;

<a id="section-2-subsection-3-paragraph-3-subparagraph-d"></a>
  - **d.** muusta kuin jakoluettelon vahvistamiseen päättyvästä konkurssiasiasta peritään 300 euroa; maksua ei kuitenkaan peritä, jos konkurssi jatkuu julkisselvityksenä;

<a id="section-2-subsection-3-paragraph-3-subparagraph-e"></a>
  - **e.** erikseen hakemuksesta käsiteltävästä muusta konkurssilakiin [\(120/2004\)](<https://www.finlex.fi/fi/lainsaadanto/2004/120>) perustuvasta asiasta peritään hakijalta 300 euroa; maksua ei kuitenkaan peritä asiassa, joka koskee turvaamistoimen tai pakkokeinon määräämistä, pesäluettelon vahvistamista tai muuta velallisen velvollisuutta, jälkivalvontaa taikka vahvistetun jakoluettelon oikaisemista tai muuttamista;

<a id="section-2-subsection-3-paragraph-3-subparagraph-f"></a>
  - **f.** riitautettua saatavaa koskevan asian käsittelystä, jos asia siirretään riitaisena istuntokäsittelyyn, peritään maksu riitauttajalta kuten riita\-asiassa;

<a id="section-2-subsection-3-paragraph-4"></a>
- **4.** saneerausmenettely:

<a id="section-2-subsection-3-paragraph-4-subparagraph-a"></a>
  - **a.** asia, jossa saneerausmenettelyä ei päätetä aloittaa, 300 euroa;

<a id="section-2-subsection-3-paragraph-4-subparagraph-b"></a>
  - **b.** asia, jossa saneerausmenettely päätetään aloittaa, 1000 euroa;

<a id="section-2-subsection-3-paragraph-4-subparagraph-c"></a>
  - **c.** erikseen hakemuksesta käsiteltävä saneerausmenettelyyn liittyvä muu asia 300 euroa;

<a id="section-2-subsection-3-paragraph-5"></a>
- **5.** yksityishenkilön velkajärjestelystä annetun lain [\(57/1993\)](<https://www.finlex.fi/fi/lainsaadanto/1993/57>) mukainen asia 250 euroa; velallisen ollessa hakijana asia on kuitenkin maksuton\.

<a id="section-3"></a>
### 3 § Hovioikeuden hakemusmaksu

<a id="section-3-subsection-1"></a>
#### \(1\)

Hakemusasian käsittelystä hovioikeudessa peritään hakemusmaksua 250 euroa\.

<a id="section-4"></a>
### 4 § Markkinaoikeuden hakemusmaksu

<a id="section-4-subsection-1"></a>
#### \(1\)

Hakemusasian käsittelystä markkinaoikeudessa peritään hakemusmaksua 250 euroa\. Hakemuksesta vireille tulevan markkinaoikeudellisen asian käsittelystä peritään kuitenkin tuomioistuinmaksulain [\(1455/2015\) 2 §:n](<https://www.finlex.fi/fi/lainsaadanto/2015/1455>) mukainen maksu\.

<a id="section-5"></a>
### 5 § Voimaantulo

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2016 ja on voimassa 31 päivään joulukuuta 2018\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Suoritteesta, jonka maksuperuste on syntynyt ennen tämän asetuksen voimaantuloa, peritään tuomioistuinten ja eräiden oikeushallintoviranomaisten suoritteista perittävistä maksuista annetussa valtioneuvoston asetuksessa [\(1057/2013\)](<https://www.finlex.fi/fi/lainsaadanto/2013/1057>) säädetty maksu\.
