# Sisäasiainministeriön asetus sisäasiainministeriön maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:n 2 momentissa tarkoitettuja maksullisia julkisoikeudellisia suoritteita, joista sisäasiainministeriö perii tämän asetuksen liitteenä olevan maksutaulukon mukaisen kiinteän maksun, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** erivapautta kunnalliseen pelastustoimen virkaan koskeva päätös;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** ampuma\-aseiden ja patruunoiden tarkastus sekä ampuma\-aseisiin liittyvät luvat;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** vartijan koulutuksesta annetun sisäasiainministeriön päätöksen \(745/1983\) 7 §:n mukainen lupa ja vartioimisliikelautakunnan toimeenpanema koe;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** poliisivaltuuksien myöntäminen ja lupa poliisin tunnuskuvan käyttöön;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** sisäasiainministeriön päätös valitusasiassa, jonka korkein hallinto\-oikeus on siirtänyt tarkoituksenmukaisuusperusteella hallituksen ratkaistavaksi; sekä

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** pyynnöstä annettava todistus\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Maksu peritään myös silloin, kun 1 §:ssä tarkoitettuun hakemukseen annetaan kielteinen päätös\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja suoritteita, jotka sisäasiainministeriö hinnoittelee liiketaloudellisin perustein ovat seuraavat suoritteet:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** selvitykset ja tutkimukset;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** henkilöstön käyttö ministeriön ulkopuolisissa koulutus\-, suunnittelu\- ja muissa asiantuntijatehtävissä lukuun ottamatta tapauksia, jolloin tehtävien hoito tukee ministeriön maksutonta toimintaa;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** kirjasto\- ja tietopalvelut;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** julkaisut ja kustannuspalvelut;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** ilmoitukset ja tiedotteet ministeriön julkaisuissa;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** sähköiset tietotuotteet;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** ministeriön hallinnassa olevien tilojen ja laitteiden käyttö sekä virasto\- ja toimistopalvelut ulkopuolisille;

<a id="section-3-subsection-1-paragraph-7a"></a>
- **7a.** ampuma\-aselainsäädännön soveltamisalaan kuuluviin esineisiin tehtävät merkinnät;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** valokopiot ja muut jäljennökset; sekä

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** toimeksiantoon perustuva asiakirjojen ja muun aineiston lähettäminen ja postitus, mikäli nämä eivät sisälly aineistosta perittävään hintaan\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2002 ja on voimassa 31 päivään joulukuuta 2004\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Tämän asetuksen mukaiset maksut voidaan vuoden 2002 helmikuun loppuun asti maksaa myös käyttäen maksuvälineenä markkamääräisiä seteleitä ja metallirahoja\. Tällöin euromääräinen hinta muutetaan markkamääräiseksi kertomalla se luvulla 5,94573 sekä pyöristämällä loppusumma lähimpään penniin\.

<a id="section-4-subsection-3"></a>
#### \(3\)

Tällä asetuksella kumotaan 20 päivänä marraskuuta 1996 annettu sisäasiainministeriön päätös \(871/1996\) sisäasiainministeriön maksullisista suoritteista siihen myöhemmin tehtyine muutoksineen\.
