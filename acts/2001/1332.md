### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään ympäristöministeriön maksullisista suoritteista, niiden maksuperusteista sekä eräistä julkisoikeudellisista suoritteista perittävistä kiinteistä maksuista\.

<a id="section-2"></a>
### 2 § Julkisoikeudelliset suoritteet, joista peritään omakustannusarvon mukainen maksu

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:ssä tarkoitettuja julkisoikeudellisia suoritteita, joista peritään suoritteen omakustannusarvon mukainen maksu, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** maankäyttö\- ja rakennuslain \(132/1999\) mukainen tyyppihyväksyntä,

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** tyyppihyväksyntään liittyvästä laadunvalvonnasta aiheutuvat toimenpiteet,

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** tyyppihyväksyntähakemuksen peruutus sekä

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** varmentamiselinten, tarkastuslaitosten ja testauslaboratorioiden hyväksyminen

<a id="section-2-subsection-2"></a>
#### \(2\)

Maksu määräytyy suoritteen tuottamiseen käytettyjen työtuntien perusteella\. Esittelijätyöstä peritään 60 euroa työtunnilta ja toimistotyöstä 33 euroa työtunnilta\. Lisäksi peritään tyyppihyväksyntähakemuksen käsittelystä aiheutuvat matkakustannukset valtion virka\- ja työehtosopimuksen mukaisesti\.

<a id="section-3"></a>
### 3 § Julkisoikeudelliset suoritteet, joista peritään kiinteä maksu

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:ssä tarkoitettuja julkisoikeudellisia suoritteita, joista peritään keskimääräiseen omakustannusarvoon perustuva tai 6 §:n 3 momentin perusteella omakustannusarvoa alempi maksu, ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Päätökset:

<a id="section-3-subsection-1-paragraph-1-subparagraph-1"></a>
  - **1.** päätös poikkeuksen myöntämisestä maankäyttö\- ja rakennuslain 20 §:n 2 momentissa säädetyn velvoitteen täyttämisestä 170 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-2"></a>
  - **2.** päätös suostumuksesta yleiskaavan hyväksymiseen seutukaavasta poiketen 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-3"></a>
  - **3.** hakemuksesta tehty päätös maankäyttö\- ja rakennuslain 177 §:n 1 ja 4 momentissa tarkoitetun suunnitteluvelvoitteen täyttämiseksi 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-4"></a>
  - **4.** päätös maakuntakaavasta tehdystä valituksesta 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-5"></a>
  - **5.** päätös kuntien yhteisestä yleiskaavasta tehdystä valituksesta 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-6"></a>
  - **6.** päätös korkeimmasta hallinto\-oikeudesta valtioneuvoston käsiteltäväksi siirretystä valituksesta 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-7"></a>
  - **7.** ympäristönsuojelulain \(86/2000\) 17 §:n mukainen päätös asetuksen noudattamista koskevan poikkeuksen myöntämisestä 200 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-8"></a>
  - **8.** ympäristönsuojelulain 80 §:n mukainen päätös toimivallan siirrosta kunnalle pilaantunutta maaperää koskevassa asiassa 135 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-9"></a>
  - **9.** ympäristönsuojelulain 111 §:n mukainen päätös poikkeuksen myöntämisestä eräisiin päästöjä koskeviin säännöksiin yhteistoteutushankkeissa 840 euroa,

<a id="section-3-subsection-1-paragraph-1-subparagraph-10"></a>
  - **10.** päätös virvoitusjuomien ja alkoholijuomien vähittäismyyntipäällysten keräysjärjestelmän hyväksymisestä 135 euroa sekä

<a id="section-3-subsection-1-paragraph-1-subparagraph-11"></a>
  - **11.** lunastuslupa maankäyttö\- ja rakennuslain nojalla 1 180 euroa\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Edellä kohdissa 4―6 tarkoitettua maksua valituspäätöksestä ei kuitenkaan peritä

<a id="section-3-subsection-2-paragraph-1"></a>
- **1.** varattomaksi asianmukaisesti todistetulta henkilöltä hänen etuaan tai oikeuttaan koskevassa asiassa,

<a id="section-3-subsection-2-paragraph-2"></a>
- **2.** valittajalta, jos valitus peruutetaan eikä

<a id="section-3-subsection-2-paragraph-3"></a>
- **3.** valittajalta, jos valitus kokonaan tai pääosin hyväksytään\.

- **3.** Muut julkisoikeudelliset suoritteet:

<a id="section-3-subsection-2-paragraph-3-subparagraph-1"></a>
  - **1.** diaari\- ja rekisteritodistus tai \-ote 17 euroa,

<a id="section-3-subsection-2-paragraph-3-subparagraph-2"></a>
  - **2.** jäljennökset asiakirjoista 0,70 euroa/sivu,

<a id="section-3-subsection-2-paragraph-3-subparagraph-3"></a>
  - **3.** asiakirjan oikeaksi todistaminen 3,40 euroa/asiakirja sekä

<a id="section-3-subsection-2-paragraph-3-subparagraph-4"></a>
  - **4.** toimitusmaksu 3,40 euroa /lähetys\.

<a id="section-4"></a>
### 4 § Liiketaloudellisin perustein hinnoiteltavat suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Maksullisia suoritteita, jotka hinnoitellaan liiketaloudellisin perustein, ovat seuraavat tilaukseen tai muuhun toimeksiantoon perustuvat palvelut tai muut suoritteet:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** asiantuntija\- ja koulutuspalvelut,

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** tutkimukset ja selvitykset,

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** tietojen luovutus ja tietojärjestelmien suorakäyttö,

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** tiedonhaut ja kaukopalvelulainat,

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** julkaisut, lehdet, videonauhoitteet, äänitteet ja muut vastaavat suoritteet,

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** huonetilojen käyttö,

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** muut kuin 2 §:ssä tarkoitetut jäljennökset sekä

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** muut vastaavat suoritteet\.

<a id="section-5"></a>
### 5 § Voimaantulo

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2002 ja on voimassa 31 päivään joulukuuta 2003\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Päätöksistä asiassa, joka on tullut vireille ennen 15\.6\.2000, peritään maksu silloin voimassa olleiden säännösten mukaisesti\. Tällöin markkamääräinen maksu muutetaan euromääräiseksi jakamalla se luvulla 5,94573 ja pyöristämällä loppusumma lähimpään senttiin\. Sama koskee myös päätöksiä, jotka annetaan rakennuslain \(370/1958\) nojalla 15\.6\.2000 jälkeen vireille tulleissa asioissa\.

<a id="section-5-subsection-3"></a>
#### \(3\)

Tämän maksuasetuksen mukaiset maksut voidaan vuoden 2002 helmikuun loppuun asti maksaa myös käyttäen maksuvälineenä markkamääräisiä seteleitä ja metallirahoja\. Tällöin euromääräinen maksu muutetaan markkamääräiseksi kertomalla se luvulla 5,94573 sekä pyöristämällä loppusumma lähimpään penniin\.

<a id="section-5-subsection-4"></a>
#### \(4\)

Tällä asetuksella kumotaan 31 toukokuuta 2000 annettu ympäristöministeriön asetus ympäristöministeriön maksullisista suoritteista \(509/2000\)\.
