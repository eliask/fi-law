### 16 § Liikennepolitiikan osaston yksiköt

<a id="section-16-subsection-1"></a>
#### \(1\)

Liikennepolitiikan osastossa on seuraavat yksiköt:

<a id="section-16-subsection-1-paragraph-1"></a>
- **1.** liikenneväyläyksikkö;

<a id="section-16-subsection-1-paragraph-2"></a>
- **2.** henkilöliikenneyksikkö;

<a id="section-16-subsection-1-paragraph-3"></a>
- **3.** tavaraliikenneyksikkö;

<a id="section-16-subsection-1-paragraph-4"></a>
- **4.** rautatie\- ja ilmailuyksikkö;

<a id="section-16-subsection-1-paragraph-5"></a>
- **5.** merenkulkuyksikkö;

<a id="section-16-subsection-1-paragraph-6"></a>
- **6.** liikenneturvallisuus\- ja ympäristöyksikkö;

<a id="section-16-subsection-1-paragraph-7"></a>
- **7.** vaarallisten aineiden kuljetusyksikkö; sekä

<a id="section-16-subsection-1-paragraph-8"></a>
- **8.** liikenteen telematiikkayksikkö\.

<a id="section-25"></a>
### 25 § Liikenteen telematiikkayksikkö

<a id="section-25-subsection-1"></a>
#### \(1\)

Liikenteen telematiikkayksikössä käsitellään asiat, jotka koskevat:

<a id="section-25-subsection-1-paragraph-1"></a>
- **1.** liikenteen telemaattisia palveluja;

<a id="section-25-subsection-1-paragraph-2"></a>
- **2.** liikenteen hallinnan telematiikkaa;

<a id="section-25-subsection-1-paragraph-3"></a>
- **3.** liikenteen telemaattisia maksu\-, tuki\- ja valvontajärjestelmiä;

<a id="section-25-subsection-1-paragraph-4"></a>
- **4.** liikenteen telemaattisten palvelujen edellyttämiä informaatiojärjestelmiä ja \-rakenteita, mikäli ne eivät kuulu muulle yksikölle;

<a id="section-25-subsection-1-paragraph-5"></a>
- **5.** liikenteen logististen järjestelmien telematiikkaa, mikäli asia ei kuulu muulle yksikölle;

<a id="section-25-subsection-1-paragraph-6"></a>
- **6.** hallinnonalan virastojen ja laitosten tulosohjausta liikenteen telematiikan osalta; sekä

<a id="section-25-subsection-1-paragraph-7"></a>
- **7.** liikenteen telematiikan hyödyntämisen ja kehittämisen koordinointia\.

<a id="section-26"></a>
### 26 § Viestintämarkkinaosaston tehtävät

<a id="section-26-subsection-1"></a>
#### \(1\)

Viestintämarkkinaosaston toimialaan kuuluvat asiat, jotka koskevat:

<a id="section-26-subsection-1-paragraph-1"></a>
- **1.** viestintäpolitiikkaa ja yleistä tietoyhteiskuntapolitiikkaa;

<a id="section-26-subsection-1-paragraph-2"></a>
- **2.** viestintämarkkinoiden yleistä ohjausta ja kehittämistä;

<a id="section-26-subsection-1-paragraph-3"></a>
- **3.** viestintään käytettäviä verkkoja ja niiden välityksellä tarjottuja viestintäpalveluita;

<a id="section-26-subsection-1-paragraph-4"></a>
- **4.** postitoimintaa ja lehdistötukea;

<a id="section-26-subsection-1-paragraph-5"></a>
- **5.** viestintäelinkeinon kilpailukyvyn ja alan yritysten kansainvälistymisen edistämistä; sekä

<a id="section-26-subsection-1-paragraph-6"></a>
- **6.** Viestintävirastoa ja sen tulosohjausta\.

<a id="section-28"></a>
### 28 § Viestintäverkkoyksikkö

<a id="section-28-subsection-1"></a>
#### \(1\)

Viestintäverkkoyksikössä käsitellään asiat, jotka koskevat:

<a id="section-28-subsection-1-paragraph-1"></a>
- **1.** sähköiseen viestintään käytettäviä verkkoja ja niiden tarjontaa;

<a id="section-28-subsection-1-paragraph-2"></a>
- **2.** telemarkkinalain, radiolain ja viestintähallinnosta annetun lain mukaisia ministeriön tehtäviä, jos ne eivät kuulu muulle yksikölle;

<a id="section-28-subsection-1-paragraph-3"></a>
- **3.** televisio\- ja radiotoiminnasta annetun lain mukaisia ministeriön tehtäviä, siltä osin kuin ne koskevat televisio\- ja radiotoiminnan taajuussuunnittelua;

<a id="section-28-subsection-1-paragraph-4"></a>
- **4.** Internetin nimihallintoa;

<a id="section-28-subsection-1-paragraph-5"></a>
- **5.** itsesääntelyn edistämästä yksikön toimialalla;

<a id="section-28-subsection-1-paragraph-6"></a>
- **6.** Viestintävirastoa ja sen tulosohjausta yksikön toimialalla; sekä

<a id="section-28-subsection-1-paragraph-7"></a>
- **7.** viestintäelinkeinon kilpailukyvyn ja alan yritysten kansainvälistymisen edistämistä yksikön toimialalla\.

<a id="section-29"></a>
### 29 § Mediayksikkö

<a id="section-29-subsection-1"></a>
#### \(1\)

Mediayksikössä käsitellään asiat, jotka koskevat:

<a id="section-29-subsection-1-paragraph-1"></a>
- **1.** sähköisissä viestintäverkoissa tarjottujen palvelujen ja verkoissa harjoitetun viestinnän sääntelyä;

<a id="section-29-subsection-1-paragraph-2"></a>
- **2.** televisio\- ja radiotoiminnasta annetun lain mukaisia ministeriön tehtäviä, jos ne eivät kuulu muulle yksikölle;

<a id="section-29-subsection-1-paragraph-3"></a>
- **3.** televisio\- ja radiotoiminnan julkista palvelua, valtion televisio\- ja radiorahastoa ja lehdistötukea;

<a id="section-29-subsection-1-paragraph-4"></a>
- **4.** postitoimintaa;

<a id="section-29-subsection-1-paragraph-5"></a>
- **5.** luettelo\- ja hakemistopalvelujen tarjontaa;

<a id="section-29-subsection-1-paragraph-6"></a>
- **6.** itsesääntelyn edistämistä yksikön toimialalla;

<a id="section-29-subsection-1-paragraph-7"></a>
- **7.** Viestintävirastoa ja sen tulosohjausta yksikön toimialalla; sekä

<a id="section-29-subsection-1-paragraph-8"></a>
- **8.** viestintäelinkeinon kilpailukyvyn ja alan yritysten kansainvälistymisen edistämistä yksikön toimialalla\.

<a id="section-30"></a>
### 30 § Verkkoliiketoimintayksikkö

<a id="section-30-subsection-1"></a>
#### \(1\)

Verkkoliiketoimintayksikössä käsitellään asiat, jotka koskevat:

<a id="section-30-subsection-1-paragraph-1"></a>
- **1.** yleisen tietoverkon kehittämistä;

<a id="section-30-subsection-1-paragraph-2"></a>
- **2.** sähköisen kaupankäynnin ja muun verkkoliiketoiminnan edistämistä;

<a id="section-30-subsection-1-paragraph-3"></a>
- **3.** yksityisyyden suojaa televiestinnässä sekä tietoturvallisuushallintoa koskevia asioita;

<a id="section-30-subsection-1-paragraph-4"></a>
- **4.** sähköistä allekirjoitusta, salaustuotteita ja \-politiikkaa sekä käyttäjien luottamuksen edistämistä viestintäverkkojen ja \-palvelujen käyttöön;

<a id="section-30-subsection-1-paragraph-5"></a>
- **5.** viestinnän ja tietoyhteiskuntapalvelujen tilastointia;

<a id="section-30-subsection-1-paragraph-6"></a>
- **6.** itsesääntelyn edistämistä yksikön toimialalla;

<a id="section-30-subsection-1-paragraph-7"></a>
- **7.** Viestintävirastoa ja sen tulosohjausta yksikön toimialalla; sekä

<a id="section-30-subsection-1-paragraph-8"></a>
- **8.** viestintäelinkeinon kilpailukyvyn ja alan yritysten kansainvälistymisen edistämistä yksikön toimialalla\.
