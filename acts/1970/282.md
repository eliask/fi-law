<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Kastroimiseen voidaan asianomaisen henkilön omasta vakaasta pyynnöstä antaa lupa, jos on syytä otaksua, että hänelle hänen sukuviettinsä takia aiheutuu vaikeita sielullisia kärsimyksiä tai muita vakavia haittoja ja että vain kastroiminen niitä vähentäisi\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Sitä, joka ei ole täyttänyt kahtakymmentä vuotta tai joka on mielisairas, syvästi vajaamielinen tai erittäin vaikeasti sielullisesti häiriytynyt, ei saa kastroida\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Ennen kuin kastroiminen tämän lain mukaan suoritetaan, on kastroimista pyytävälle annettava selvitys kastroimisen merkityksestä ja vaikutuksista\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Kastroimiseen voidaan ryhtyä vain lääkintöhallituksen luvalla\. Nämä ja muut tässä laissa tarkoitetut lääkintöhallitukselle kuuluvat asiat käsitellään erityisistunnossa oikeustiedettä, psykiatriaa ja endokrinologiaa edustavien lisäjäsenten saapuvilla ollessa, niin kuin siitä asetuksella tarkemmin säädetään\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Lääkintöhallituksen asiasta antamaan päätökseen ei saa hakea muutosta valittamalla\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Ennen kastroimista koskevan päätöksen tekoa on suoritettava tutkimuksia henkilön terveydentilan selville saamiseksi, niin kuin siitä asetuksella tarkemmin säädetään\.

<a id="section-6"></a>
### 6§

<a id="section-6-subsection-1"></a>
#### \(1\)

Ennen kastroimista koskevan päätöksen tekoa on, mikäli mahdollista, varattava aviopuolisolle, holhoojalle ja, jos henkilö on otettu yleiseen laitokseen, sen johtajalle tilaisuus esittää käsityksensä asiassa\.

<a id="section-7"></a>
### 7§

<a id="section-7-subsection-1"></a>
#### \(1\)

Lääkintöhallitus voi luvan myöntävässä päätöksessään määrätä kastroimisen suorittamisen lykättäväksi enintään yhden vuoden määräajaksi päätöksen antamisesta\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Asianomainen henkilö voi milloin tahansa ennen kastroimisen suorittamista peruuttaa pyyntönsä\.

<a id="section-8"></a>
### 8§

<a id="section-8-subsection-1"></a>
#### \(1\)

Kastroimisen sekä siihen mahdollisesti liittyvän jälkitarkastuksen ja \-hoidon suorittaa laillistettu lääkäri lääkintöhallituksen määräämässä sairaalassa\.

<a id="section-9"></a>
### 9§

<a id="section-9-subsection-1"></a>
#### \(1\)

Se, joka on ottanut osaa tässä laissa mainitun asian käsittelyyn taikka viran puolesta tai muuten tehtävässään saanut siitä tiedon, ei saa sivulliselle ilmaista, mitä siten on tullut hänen tietoonsa\.

<a id="section-9-subsection-2"></a>
#### \(2\)

Se, joka rikkoo 1 momentissa säädetyn vaitiolovelvollisuuden, tuomittakoon sakkoon tai vankeuteen enintään kuudeksi kuukaudeksi\.

<a id="section-9-subsection-3"></a>
#### \(3\)

Virallinen syyttäjä ei saa nostaa syytettä vaitiolovelvollisuuden rikkomisesta, ellei asianomistaja ole ilmoittanut sitä syytteeseen pantavaksi\.

<a id="section-10"></a>
### 10§

<a id="section-10-subsection-1"></a>
#### \(1\)

Se, joka on suorittanut luvalliseksi todettavan kastroimisen tai sitä yrittänyt tämän lain säännöksiä noudattamatta, tuomittakoon sakkoon tai vankeuteen enintään yhdeksi vuodeksi\.

<a id="section-11"></a>
### 11§

<a id="section-11-subsection-1"></a>
#### \(1\)

Se, joka vastoin parempaa tietoaan on antanut viranomaiselle tai lääkärille väärän lausunnon tai ilmoituksen kastroimista koskevassa asiassa, tuomittakoon, jollei rikoksesta muutoin seuraa ankarampaa rangaistusta, sakkoon tai vankeuteen enintään yhdeksi vuodeksi\.

<a id="section-12"></a>
### 12§

<a id="section-12-subsection-1"></a>
#### \(1\)

Tätä lakia ei sovelleta sellaiseen sukuelimiä koskevaan toimenpiteeseen, joka on tarpeellinen ruumiillisen sairauden johdosta\.

<a id="section-13"></a>
### 13§

<a id="section-13-subsection-1"></a>
#### \(1\)

Tarkemmat määräykset tämän lain soveltamisesta annetaan asetuksella\.

<a id="section-14"></a>
### 14§

<a id="section-14-subsection-1"></a>
#### \(1\)

Tämä laki tulee voimaan 1 päivänä kesäkuuta 1970, ja sillä kumotaan 17 päivänä helmikuuta 1950 annettu kastroimislaki [\(84/50\)](<https://www.finlex.fi/fi/lainsaadanto/1950/84>)\.
