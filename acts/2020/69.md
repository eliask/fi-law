### 1 § Yleisvaaralliset tartuntataudit

<a id="section-1-subsection-1"></a>
#### \(1\)

Yleisvaarallisia tartuntatauteja ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** EHEC\-bakteerin aiheuttama tauti;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** hepatiitti A;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** hepatiitti E;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** A\-tyypin influenssaviruksen H5N1\- tai H7N9\-alatyypin taikka muun uuden tai harvinaisen alatyypin aiheuttama tauti;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** isorokko;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** kolera;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** kuppa;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** kurkkumätä;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** lavantauti, pikkulavantauti ja muu salmonelloihin kuuluvan bakteerin aiheuttama tauti;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** meningokokin aiheuttama vaikea yleisinfektio ja aivokalvontulehdus;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** pernarutto;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** polio;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** rutto;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** SARS, MERS ja muu uuden koronavirustyypin aiheuttama vaikea infektio;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** shigellapunatauti;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** tuberkuloosi;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** tuhkarokko;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** Ebola, Lassa, Marburg, Krimin\-Kongon verenvuotokuume ja muut virusten aiheuttamat verenvuotokuumeet\.
