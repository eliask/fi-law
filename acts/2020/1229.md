<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä lakia sovelletaan valtion ja rekisteröidyn yhteisön tai säätiön järjestämään koulutukseen, josta säädetään:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** perusopetuslaissa \(628/1998\);

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** lukiolaissa \(714/2018\);

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ammatillisesta koulutuksesta annetussa laissa \(531/2017\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** tutkintokoulutukseen valmentavasta koulutuksesta annetussa laissa \(1215/2020\);

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** vapaasta sivistystyöstä annetussa laissa \(632/1998\);

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** taiteen perusopetuksesta annetussa laissa \(633/1998\) \.
