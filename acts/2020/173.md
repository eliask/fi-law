<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään alueista, joilla ravitsemisliikkeet on pidettävä suljettuina asiakkailta majoitus\- ja ravitsemistoiminnasta annetun lain \(308/2006\) 3 a §:ssä tarkoitetuissa poikkeusoloissa\.

<a id="section-2"></a>
### 2 § Ravitsemisliikkeiden aukiolon rajoittaminen alueittain tartuntataudin leviämisen ehkäisemiseksi

<a id="section-2-subsection-1"></a>
#### \(1\)

Ravitsemisliikkeet on pidettävä suljettuina asiakkailta seuraavissa maakunnissa:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uusimaa;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Varsinais\-Suomi;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Satakunta;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kanta\-Häme;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaa;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Päijät\-Häme;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Kymenlaakso;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Etelä\-Karjala;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Etelä\-Savo;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Pohjois\-Savo;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Pohjois\-Karjala;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Keski\-Suomi;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Etelä\-Pohjanmaa;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** Pohjanmaa;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Keski\-Pohjanmaa;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Pohjois\-Pohjanmaa;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** Kainuu;

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** Lappi;

<a id="section-2-subsection-1-paragraph-19"></a>
- **19.** Ahvenanmaa\.

<a id="section-3"></a>
### 3 § Rajoitusten seuraaminen

<a id="section-3-subsection-1"></a>
#### \(1\)

Työ\- ja elinkeinoministeriö seuraa yhdessä sosiaali\- ja terveysministeriön kanssa säännöllisesti sitä, onko ravitsemisliikkeet pidettävä kussakin maakunnassa edelleen suljettuina asiakkailta\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 4 päivänä huhtikuuta 2020\. Asetus on voimassa 31 päivään toukokuuta 2020\.
