<a id="section-25"></a>
### 25 § Hallinnollisen osaston organisaatio

<a id="section-25-subsection-1"></a>
#### \(1\)

Hallinnollisella osastolla on seuraavat linjat:

<a id="section-25-subsection-1-paragraph-1"></a>
- **1.** henkilöstölinja;

<a id="section-25-subsection-1-paragraph-2"></a>
- **2.** talouslinja;

<a id="section-25-subsection-1-paragraph-3"></a>
- **3.** kiinteistö\- ja materiaalilinja; ja

<a id="section-25-subsection-1-paragraph-4"></a>
- **4.** tietohallintolinja\.

<a id="section-25-subsection-2"></a>
#### \(2\)

Henkilöstölinjaan kuuluvat seuraavat yksiköt:

<a id="section-25-subsection-2-paragraph-1"></a>
- **1.** henkilöstösuunnitteluyksikkö;

<a id="section-25-subsection-2-paragraph-2"></a>
- **2.** palvelussuhdeasiain yksikkö;

<a id="section-25-subsection-2-paragraph-3"></a>
- **3.** työsuojelu\- ja terveydenhuoltoyksikkö; ja

<a id="section-25-subsection-2-paragraph-4"></a>
- **4.** koulutusyksikkö\.

<a id="section-25-subsection-3"></a>
#### \(3\)

Talouslinjaan kuuluvat seuraavat yksiköt:

<a id="section-25-subsection-3-paragraph-1"></a>
- **1.** kirjanpito\- ja maksuliikeyksikkö;

<a id="section-25-subsection-3-paragraph-2"></a>
- **2.** edustustojen talouden tarkastusyksikkö; ja

<a id="section-25-subsection-3-paragraph-3"></a>
- **3.** matkayksikkö\.

<a id="section-25-subsection-4"></a>
#### \(4\)

Kiinteistö\- ja materiaalilinjaan kuuluvat seuraavat yksiköt:

<a id="section-25-subsection-4-paragraph-1"></a>
- **1.** kiinteistöyksikkö;

<a id="section-25-subsection-4-paragraph-2"></a>
- **2.** sisustusyksikkö; ja

<a id="section-25-subsection-4-paragraph-3"></a>
- **3.** materiaaliyksikkö\.

<a id="section-25-subsection-5"></a>
#### \(5\)

Tietohallintolinjaan kuuluvat seuraavat yksiköt:

<a id="section-25-subsection-5-paragraph-1"></a>
- **1.** tietopalveluyksikkö;

<a id="section-25-subsection-5-paragraph-2"></a>
- **2.** tietotekniikkayksikkö; ja

<a id="section-25-subsection-5-paragraph-3"></a>
- **3.** toimistopalveluyksikkö\.

<a id="section-25-subsection-6"></a>
#### \(6\)

Lisäksi hallinnollisella osastolla on seuraavat yksiköt:

<a id="section-25-subsection-6-paragraph-1"></a>
- **1.** turvallisuusyksikkö; ja

<a id="section-25-subsection-6-paragraph-2"></a>
- **2.** hallintoyksikkö, joka palvelee myös hallinnollisista asioista vastaavaa alivaltiosihteeriä\.

<a id="section-66a"></a>
### 66 a § Palkka\- ja korvausasioista vastaavan virkamiehen ratkaisuvalta

<a id="section-66a-subsection-1"></a>
#### \(1\)

Palkka\- ja korvausasioista vastaava virkamies ratkaisee palkanlaskentaa ja \-maksua koskevat tekniset asiat\.

<a id="section-69"></a>
### 69 § Talousjohtajan ratkaisuvalta

<a id="section-69-subsection-1"></a>
#### \(1\)

Talousjohtaja ratkaisee 60 §:ssä määrätyn lisäksi seuraavat asiat:

<a id="section-69-subsection-1-paragraph-1"></a>
- **1.** ministeriön toimintaa tilivirastona koskevat asiat;

<a id="section-69-subsection-1-paragraph-2"></a>
- **2.** valuutanvaihtoa koskevat asiat sekä käytettävän valuutan ja tilikurssin määrääminen;

<a id="section-69-subsection-1-paragraph-3"></a>
- **3.** lupa jatkuvaan oman auton käyttöön virkamatkoilla Suomessa; ja

<a id="section-69-subsection-1-paragraph-4"></a>
- **4.** tileistä poistot\.
