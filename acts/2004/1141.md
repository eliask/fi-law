<a id="section-1"></a>
### 1 § Maksullinen julkisoikeudellinen suorite

<a id="section-1-subsection-1"></a>
#### \(1\)

Maa\- ja elintarviketalouden tutkimuskeskus perii valtion maksuperustelain \(150/1992\) 6 §:n mukaisesti suoritteen omakustannusarvon mukaisesti määräytyvän kiinteän hinnan elintarvikekuljetusvälineiden ATP \-todistuksista\. Todistuksen hinta on 91 euroa\.

<a id="section-2"></a>
### 2 § Maksulliset liiketaloudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka maa\- ja elintarviketalouden tutkimuskeskus hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tilaustutkimukset ja tutkimusaineistot;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** analyysipalvelut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** koestus\-, testaus\- ja tarkastuspalvelut;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** valiotaimituotanto;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** hevossairaala;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** kotieläinten lisääntymispalvelut;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** julkaisumyynti\- ja tiedonvälityspalvelut;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** koulutus\- ja kurssipalvelut;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** asiantuntija\- ja neuvontapalvelut;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** puunmyynti;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** kiinteistönhoitopalvelut sekä muut toimitiloihin ja alueisiin liittyvät korjaus\- ja kunnossapitopalvelut;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** peltoviljelypalvelut;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** muut tilatut erityispalvelut ja suoritteet\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2005 ja se on voimassa 31 päivään joulukuuta 2007\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tämän asetuksen mukaisia maksuja peritään sen voimassaoloaikana tilatuista suoritteista\.
