# Oikeusministeriön asetus Kainuun maakuntavaaleissa käytettävien ehdokasasettelulomakkeiden kaavoista

- Statute: [`158/2004`](<https://www.finlex.fi/fi/laki/ajantasa/2004/158>)
- Version: `2004-02-24`
- LawVM tree hash: `a960df5644d8d3eb2c382cef9b328fb8816dd264b8cec69834ca960a668bf8c9`

## Contents

- [1 §](#section-1)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ehdokkaiden asettamisessa Kainuun maakuntavaaleissa voidaan käyttää tämän asetuksen mukaisia lomakkeita\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Kaavat on vahvistettu seuraaville lomakkeille:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** ilmoitus puolueen jäseniä kunnassa edustavasta yhdistyksestä;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** ilmoitus puolueen vaaliasiamiehestä ja varamiehestä sekä vaaliasiamiehelle annettu valtakirja;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** puolueen ehdokashakemus;

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** ehdotus puolueen ehdokaslistaksi;

<a id="section-1-subsection-2-paragraph-5"></a>
- **5.** puolueen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-2-paragraph-6"></a>
- **6.** ilmoitus puolueiden vaaliliitosta;

<a id="section-1-subsection-2-paragraph-7"></a>
- **7.** valitsijayhdistyksen perustamisasiakirja lisälehtineen;

<a id="section-1-subsection-2-paragraph-8"></a>
- **8.** valitsijayhdistyksen ehdokashakemus;

<a id="section-1-subsection-2-paragraph-9"></a>
- **9.** ehdotus valitsijayhdistyksen ehdokaslistaksi;

<a id="section-1-subsection-2-paragraph-10"></a>
- **10.** valitsijayhdistyksen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-2-paragraph-11"></a>
- **11.** ilmoitus yhteislistasta lisälehtineen;

<a id="section-1-subsection-2-paragraph-12"></a>
- **12.** ilmoitus maakuntayhteislistasta lisälehtineen; sekä

<a id="section-1-subsection-2-paragraph-13"></a>
- **13.** vaaliasiamiehen antama valtakirja\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Vahvistetut kaavat ovat tämän päätöksen liitteinä\.
