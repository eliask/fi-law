### 1 § Yleisvaaralliset tartuntataudit

<a id="section-1-subsection-1"></a>

<a id="section-1-subsection-1-paragraph-2"></a>

- **3.** hepatiitti E;

<a id="section-1-subsection-1-paragraph-4"></a>

- **9.** lavantauti, pikkulavantauti ja muu salmonelloihin kuuluvan bakteerin aiheuttama tauti;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** meningokokin aiheuttama vaikea yleisinfektio ja aivokalvontulehdus;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** pernarutto;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** polio;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** rutto;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** SARS ja MERS;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** shigellapunatauti;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** tuberkuloosi;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** tuhkarokko;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** Ebola, Lassa, Marburg, Krimin\-Kongon verenvuotokuume ja muut virusten aiheuttamat verenvuotokuumeet\.

<a id="section-4"></a>
### 4 § Terveyden ja hyvinvoinnin laitoksen tehtävät

<a id="section-4-subsection-1"></a>
#### \(1\)

Terveyden ja hyvinvoinnin laitoksen on:

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** annettava hyvinvointialueille ja niiden tartuntatautien torjuntatyöstä vastaaville toimielimille ja HUS\-yhtymälle asiantuntija\-apua tartuntatautiepidemioiden selvittämisessä ja hoitoon liittyvien infektioiden torjunnassa;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** tiedotettava ajankohtaisesta tartuntatautitilanteesta hyvinvointialueille, HUS\-yhtymälle, laboratorioille ja sosiaalihuollon ja terveydenhuollon toimintayksiköille;

<a id="section-7"></a>
### 7 § Lääkärin tartuntatauti\-ilmoitus

<a id="section-7-subsection-1"></a>
#### \(1\)

Lääkärin ja hammaslääkärin on tehtävä tartuntatauti\-ilmoitus yleisvaarallisista ja valvottavista tartuntataudeista\. Ilmoitusta ei kuitenkaan tehdä seuraavista taudeista:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** hinkuyskä;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** muu salmonelloosi kuin lavantauti tai pikkulavantauti;

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** pneumokokin aiheuttama vaikea yleisinfektio ja aivokalvontulehdus;

<a id="section-7-subsection-1-paragraph-4"></a>
- **4.** puutiaisaivokuume;

<a id="section-7-subsection-1-paragraph-5"></a>
- **5.** rotavirusinfektio;

<a id="section-7-subsection-1-paragraph-6"></a>
- **6.** hemofiluksen aiheuttama vaikea yleisinfektio ja aivokalvontulehdus;

<a id="section-7-subsection-1-paragraph-7"></a>
- **7.** sukupuoliteitse leviävä klamydiainfektio ja muut mykobakteeritaudit kuin tuberkuloosi;

<a id="section-7-subsection-1-paragraph-8"></a>
- **8.** covid\-19\.
