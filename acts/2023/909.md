### 3 § Muut torjuttavat eläintaudit

<a id="section-3-subsection-1"></a>
#### \(1\)

Muita torjuttavia eläintauteja ovat seuraavat taudit:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** ebolavirustauti ja muut kädellisillä esiintyvät ihmisille vaaralliset filovirustartunnat;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Mycobacterium tuberculosis complex \(M\. bovis, M\. caprae, M\. tuberculosis\) \-tartunnat, MTBC\-tartunnat\) muissa pidettävissä sorkkaeläimissä kuin nautaeläimissä;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** pernarutto;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** raivotautiviruksen aiheuttama tartunta muissa eläimissä kuin sikaeläimissä, hirvi\-eläimissä tai kamelieläimissä taikka eläimissä, jotka kuuluvat Bovidae \- tai Equidae \-heimoon tai Carnivora \-lahkoon;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** muun lyssaviruksen kuin raivotautiviruksen aiheuttama tartunta;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** SARS\-CoV\-2 viruksen aiheuttama tartunta turkistuotantoa varten tarhatuissa minkeissä, supikoirissa ja soopeleissa;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** korkeapatogeeninen lintuinfluenssa turkistuotantoa varten tarhatuissa ketuissa, siniketuissa, minkeissä, supikoirissa ja soopeleissa;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** Bovine spongiform encephalopathy \(BSE\-tauti\);

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** klassinen scrapie;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** epitsoottisen verenvuototautiviruksen aiheuttama tartunta \(EHD\-tauti\);

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** hirvieläinten näivetystauti \(CWD\-tauti\);

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** Brucella abortus\-, B\. melitensis \- ja B\. suis \-tartunnat \(bruselloosi\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** sikojen lisääntymishäiriö\- ja keuhkotulehdusoireyhtymä\-viruksen aiheuttama tartunta \(PRRS\-tauti\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** sikojen tarttuva gastroenteriitti \(TGE\-tauti\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** hevosen näivetystauti;

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** pienen pesäkuoriaisen \(Aethina tumida\) esiintyminen;

<a id="section-3-subsection-1-paragraph-17"></a>
- **17.** Tropilaelaps\-punkin \(Tropilaelaps spp\.\) esiintyminen;

<a id="section-3-subsection-1-paragraph-18"></a>
- **18.** kalojen Gyrodactylus salaris \-tartunta Tenojoen, Näätämöjoen, Paatsjoen, Tuulomajoen ja Uutuanjoen vesistöjen alueella;

<a id="section-3-subsection-1-paragraph-19"></a>
- **19.** lohikalojen alfavirustartunnat \(SAV\-tauti\);

<a id="section-3-subsection-1-paragraph-20"></a>
- **20.** karpin kevätviremia \(SVC\-tauti\);

<a id="section-3-subsection-1-paragraph-21"></a>
- **21.** koikarpin herpesvirustauti \(KHV\-tauti\)\.
