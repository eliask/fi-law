<a id="section-2"></a>
### 2 § Määritelmät

<a id="section-2-subsection-1"></a>
#### \(1\)

Tässä asetuksessa tarkoitetaan

<a id="section-2-subsection-28"></a>
#### \(28\)

eläinryhmällä seuraavia ryhmiä:

<a id="section-2-subsection-28-paragraph-a"></a>
- **a.** emolehmät;

<a id="section-2-subsection-28-paragraph-b"></a>
- **b.** lypsylehmät;

<a id="section-2-subsection-28-paragraph-c"></a>
- **c.** yli kahden vuoden ikäiset naudat;

<a id="section-2-subsection-28-paragraph-d"></a>
- **d.** alkuperäisrotunaudat;

<a id="section-2-subsection-28-paragraph-e"></a>
- **e.** vähintään kuuden kuukauden ja enintään kahden vuoden ikäiset naudat;

<a id="section-2-subsection-28-paragraph-f"></a>
- **f.** alle kuuden kuukauden ikäiset muut naudat;

<a id="section-2-subsection-28-paragraph-g"></a>
- **g.** vähintään kuuden kuukauden ja alle 20 kuukauden ikäiset sonnit;

<a id="section-2-subsection-28-paragraph-h"></a>
- **h.** emakot, porsaat, muut siat;

<a id="section-2-subsection-28-paragraph-i"></a>
- **i.** uuhet ja pässit;

<a id="section-2-subsection-28-paragraph-j"></a>
- **j.** vähintään kahden kuukauden ikäiset karitsat;

<a id="section-2-subsection-28-paragraph-k"></a>
- **k.** alkuperäisrotulampaat, kutut, pukit;

<a id="section-2-subsection-28-paragraph-l"></a>
- **l.** vähintään kahden kuukauden ikäiset kilit;

<a id="section-2-subsection-28-paragraph-m"></a>
- **m.** hanhet, ankat, sorsat, fasaanit, broilerit, munivat kanat, kukot, broileriemolinnut ja kalkkunaemolinnut;

<a id="section-2-subsection-28-paragraph-n"></a>
- **n.** alkuperäisrotukanat ja \-kukot;

<a id="section-2-subsection-28-paragraph-o"></a>
- **o.** suomenhevoset\.
