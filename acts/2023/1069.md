### 3 § Muut torjuttavat eläintaudit

<a id="section-3-subsection-1"></a>
#### \(1\)

Muita torjuttavia eläintauteja ovat seuraavat taudit:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** ebolavirustauti ja muut kädellisillä esiintyvät ihmisille vaaralliset filovirustartunnat;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Mycobacterium tuberculosis complex \(M\. bovis, M\. caprae, M\. tuberculosis\) \-tartunnat, MTBC\-tartunnat\) muissa pidettävissä sorkkaeläimissä kuin nautaeläimissä;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** pernarutto;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** raivotautiviruksen aiheuttama tartunta muissa eläimissä kuin sikaeläimissä, hirvi\-eläimissä tai kamelieläimissä taikka eläimissä, jotka kuuluvat Bovidae \- tai Equidae \-heimoon tai Carnivora \-lahkoon;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** muun lyssaviruksen kuin raivotautiviruksen aiheuttama tartunta;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** SARS\-CoV\-2 viruksen aiheuttama tartunta turkistuotantoa varten tarhatuissa minkeissä, supikoirissa ja soopeleissa;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** Influenssa A \-viruksen H5\-alatyypin aiheuttama tartunta turkistuotantoa varten tarhatuissa minkeissä, supikoirissa, soopeleissa, Vulpes vulpes \- tai Vulpes lagopus \-lajin ketuissa taikka näiden lajiristeymissä;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** Bovine spongiform encephalopathy \(BSE\-tauti\);

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** klassinen scrapie;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** epitsoottisen verenvuototautiviruksen aiheuttama tartunta \(EHD\-tauti\);

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** hirvieläinten näivetystauti \(CWD\-tauti\);

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** Brucella abortus\-, B\. melitensis \- ja B\. suis \-tartunnat \(bruselloosi\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** sikojen lisääntymishäiriö\- ja keuhkotulehdusoireyhtymä\-viruksen aiheuttama tartunta \(PRRS\-tauti\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** sikojen tarttuva gastroenteriitti \(TGE\-tauti\) pidettävissä sikaeläimissä;

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** hevosen näivetystauti;

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** pienen pesäkuoriaisen \(Aethina tumida\) esiintyminen;

<a id="section-3-subsection-1-paragraph-17"></a>
- **17.** Tropilaelaps\-punkin \(Tropilaelaps spp\.\) esiintyminen;

<a id="section-3-subsection-1-paragraph-18"></a>
- **18.** kalojen Gyrodactylus salaris \-tartunta Tenojoen, Näätämöjoen, Paatsjoen, Tuulomajoen ja Uutuanjoen vesistöjen alueella;

<a id="section-3-subsection-1-paragraph-19"></a>
- **19.** lohikalojen alfavirustartunnat \(SAV\-tauti\);

<a id="section-3-subsection-1-paragraph-20"></a>
- **20.** karpin kevätviremia \(SVC\-tauti\);

<a id="section-3-subsection-1-paragraph-21"></a>
- **21.** koikarpin herpesvirustauti \(KHV\-tauti\)\.

### 5 § Muut ilmoitettavat eläintaudit

<a id="section-5-subsection-1"></a>
#### \(1\)

Muita ilmoitettavia eläintauteja ovat 3 ja 4 §:ssä luetellut taudit sekä seuraavat taudit:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** apinarokko;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** AMPV\-tauti muissa linnuissa kuin yli 100 Gallus gallus \-lajiin kuuluvaa lintua tai kalkkunaa pitävien pitopaikkojen mainittuihin lajeihin kuuluvissa linnuissa;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** Aujeszkyn tauti \(ADV\-tartunta\) muissa eläinlajeissa kuin sikaeläimissä;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** Batrachochytrium dendrobatidis \-tartunta;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** besnoitioosi \(Besnoitia besnoiti\);

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** botulismi;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** Brucella \-tartunnat, lukuun ottamatta Brucella abortus\-, B\. melitensis\-, B\. suis \- ja B\.ovis \-tartuntoja pidettävissä sorkkaeläimissä;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** BVD\-tauti muissa eläinlajeissa kuin nautaeläimissä;

<a id="section-5-subsection-1-paragraph-9"></a>
- **9.** duck virus hepatitis;

<a id="section-5-subsection-1-paragraph-10"></a>
- **10.** ekinokokkitartunnat, lukuun ottamatta myyräekinokokkoosia;

<a id="section-5-subsection-1-paragraph-11"></a>
- **11.** entsoottinen abortti \(Chlamydia abortus\);

<a id="section-5-subsection-1-paragraph-12"></a>
- **12.** heartwater\-tauti;

<a id="section-5-subsection-1-paragraph-13"></a>
- **13.** HEV \(hemagglutinating encephalomyelitis \-virus\) sikaeläimissä;

<a id="section-5-subsection-1-paragraph-14"></a>
- **14.** hevossyyhy \(Sarcoptes scabiei var\. equi\);

<a id="section-5-subsection-1-paragraph-15"></a>
- **15.** IPN\-tauti eläintautilain 37 §:n nojalla perustetulla rajoitusalueella ja muut IPN\-virustartunnat;

<a id="section-5-subsection-1-paragraph-16"></a>
- **16.** ISA\-viruksen aiheuttamat tartunnat, lukuun ottamatta viruksen genotyypin HPRΔ \(HPR\-geenin alueella deleetio\) aiheuttamia tartuntoja;

<a id="section-5-subsection-1-paragraph-17"></a>
- **17.** kalojen bakteeriperäinen munuaistauti \(BKD\);

<a id="section-5-subsection-1-paragraph-18"></a>
- **18.** kamelirokko \(Camel pox\);

<a id="section-5-subsection-1-paragraph-19"></a>
- **19.** kasöösi lymfadeniitti \(Corynebacterium pseudotuberculosis\);

<a id="section-5-subsection-1-paragraph-20"></a>
- **20.** klamydioosi linnuissa;

<a id="section-5-subsection-1-paragraph-21"></a>
- **21.** Krimin\-Kongon verenvuotokuume \(Crimean\-Congo haemorrhagic fever\);

<a id="section-5-subsection-1-paragraph-22"></a>
- **22.** kystikerkoosi \(Taenia solium eli Cysticercus cellulosae\) sikaeläimissä;

<a id="section-5-subsection-1-paragraph-23"></a>
- **23.** lammassyyhy \(Psoroptes ovis\);

<a id="section-5-subsection-1-paragraph-24"></a>
- **24.** lehmärokko;

<a id="section-5-subsection-1-paragraph-25"></a>
- **25.** leptospiroosi;

<a id="section-5-subsection-1-paragraph-26"></a>
- **26.** lintuinfluenssat, lukuun ottamatta linnuissa esiintyviä korkeapatogeenista lintuinfluenssaa \(HPAI\) ja LPAIV\-tartuntoja sekä influenssa A \-viruksen H5\-alatyypin aiheuttamaa tartuntaa turkistuotantoa varten tarhatuissa minkeissä, supikoirissa, soopeleissa, Vulpes vulpes \- tai Vulpes lagopus \-lajin ketuissa taikka näiden lajiristeymissä;

<a id="section-5-subsection-1-paragraph-27"></a>
- **27.** Mycoplasma agalactiae \- \(tarttuva agalaktia\), M\. mycoides subsp\.capri \- ja M\.synoviae \-tartunnat sekä M\. gallisepticum \- ja M\.meleagridis \-tartunnat muissa linnuissa kuin Gallus gallus \-lajiin kuuluvissa linnuissa tai kalkkunoissa;

<a id="section-5-subsection-1-paragraph-28"></a>
- **28.** mykobakteeritartunnat, lukuun ottamatta MTBC\-tartuntoja maanisäkkäissä, Mycobacterium avium \-tartuntaa sikaeläimissä ja paratuberkuloosia;

- **29.** Nairobi sheep disease;

- **30.** nautaeläinten anaplasmoosi \(Anaplasma marginale ja A\. centrale\);

<a id="section-5-subsection-1-paragraph-31"></a>
- **31.** nautojen hemorraaginen septikemia \(Pasteurella multocida\);

- **32.** new world screwworm \(Cochliomyia hominivorax\);

<a id="section-5-subsection-1-paragraph-33"></a>
- **33.** Nipah\-viruksen aiheuttama aivotulehdus;

- **35.** orf ja muut parapoxvirustartunnat;

- **36.** Parafilaria bovicola \-tartunta;

<a id="section-5-subsection-1-paragraph-37"></a>
- **37.** PMV\-1 \-tartunnat linnuissa;

- **38.** PED \(porcine epidemic diarrhea\);

<a id="section-5-subsection-1-paragraph-39"></a>
- **39.** piroplasmoosi hevoseläimissä;

- **40.** PRCV \(porcine respiratory coronavirus\);

<a id="section-5-subsection-1-paragraph-41"></a>
- **41.** pulmonaari adenomatoosi;

<a id="section-5-subsection-1-paragraph-42"></a>
- **42.** ranavirustartunnat;

<a id="section-5-subsection-1-paragraph-43"></a>
- **43.** rapurutto;

<a id="section-5-subsection-1-paragraph-44"></a>
- **44.** ritinärutto \(Clostridium chauvoei\);

<a id="section-5-subsection-1-paragraph-45"></a>
- **45.** salmonellatartunnat, lukuun ottamatta Bos taurus \-lajin nautaeläimissä, sioissa, Gallus gallus \-lajin linnuissa ja kalkkunoissa todettuja salmonellatartuntoja sekä siipikarjassa todettuja Salmonella Gallinarum\- ja S\. Pullorum \-tartuntoja;

<a id="section-5-subsection-1-paragraph-46"></a>

<a id="section-5-subsection-1-paragraph-47"></a>
- **47.** STEC\-tartunnat;

- **48.** sian vesikulääritauti \(SVD\);

<a id="section-5-subsection-1-paragraph-49"></a>
- **49.** tarttuvat spongiformiset enkefalopatiat \(TSE\-taudit\), epätyypillinen scrapie mukaan lukien, lukuun ottamatta BSE\-tautia, klassista scrapieta ja CWD\-tautia;

- **53.** tularemia eli jänisrutto;

### 8 § Muut ilmoitettavat hevoseläinten taudit

<a id="section-8-subsection-1"></a>
#### \(1\)

Muita ilmoitettavia eläintauteja ovat 3–5 §:ssä lueteltujen eläintautien lisäksi seuraavat taudit niiden esiintyessä hevoseläimissä:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** herpesvirustartunnat \(EHV\-1\- ja EHV\-4\-tartunta\);

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** hevosen koronavirus;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** hevosinfluenssa;

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** laajakirjoista beetalaktamaasia tuottavien bakteerien aiheuttamat tartunnat, jotka ovat aiheuttaneet oireita isäntäeläimessä;

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** MRSA\-tartunnat;

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** pääntauti\.
