# Valtioneuvoston asetus rautatiematkustajien oikeuksia koskevista poikkeuksista eräillä lähijunaliikenteen yhteysväleillä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Rautatiekuljetuslain [\(1119/2000\) 8 a §:n](<https://www.finlex.fi/fi/lainsaadanto/2000/1119#chp_1__sec_8a>) 3 momentissa tarkoitetun poikkeuksen piiriin kuuluvat lähijunaliikenteen yhteysvälit ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Helsinki–Siuntio;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Helsinki–Vantaankoski–Lentoasema–Hiekkaharju–Helsinki;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Helsinki–Riihimäki–Tampere;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Helsinki–Lahti;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Lahti–Riihimäki;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Lahti–Kouvola;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Kouvola–Kotka;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Tampere–Nokia\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 7 päivänä kesäkuuta 2023\.
