# Laki valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta annetun lain 1 ja 3 §:n muuttamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtioneuvostossa on yleistä hallitusta ja eri hallinnonhaaroja varten kaksitoista ministeriötä, nimittäin:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriö;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** oikeusministeriö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** sisäasiainministeriö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** puolustusministeriö;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** valtiovarainministeriö;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** opetusministeriö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** maa\- ja metsätalousministeriö;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** liikenneministeriö;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** kauppa\- ja teollisuusministeriö;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** sosiaali\- ja terveysministeriö;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** työvoimaministeriö; sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** ympäristöministeriö\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvostolle kuuluvista asioista käsittelee:

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** sisäasiainministeriö asiat, jotka koskevat yleistä järjestystä ja turvallisuutta, läänien hallintoa, kunnallishallintoa lukuun ottamatta kunnallisvaalia, väestökirjanpitoa, palo\- ja pelastustointa, väestönsuojelua sekä rajavartiolaitosta;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** maa\- ja metsätalousministeriö asiat, jotka koskevat maataloutta, metsätaloutta, maanmittausta, asutustoimintaa, eläinlääkintää, kalastusta ja metsästystä sekä, sikäli kuin ne eivät kuulu muulle ministeriölle, vesihallintoa;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** työvoimaministeriö asiat, jotka koskevat työvoimapolitiikan suunnittelua ja ohjausta sekä työllisyyden edistämistä ja työttömyyden torjuntaa;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** ympäristöministeriö asiat, jotka koskevat ympäristönsuojelua, luonnonsuojelua, ulkoilua ja luonnon virkistyskäyttöä, vesiensuojelua, öljyvahinkojen torjuntaa, meriympäristön suojelua, myrkkyjen ja muiden kemikaalien aiheuttamien ympäristöhaittojen torjuntaa, kaavoitusja rakennustointa sekä asuntotointa sikäli kuin edellä mainitut asiat eivät kuulu muulle ministeriölle; sekä
