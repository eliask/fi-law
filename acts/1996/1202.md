# Maa\- ja metsätalousministeriön päätös eräiden maanmittauslaitoksen suoritteiden maksullisuudesta ja maksuperusteista sekäsuoritteista perittävistä maksuista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maksuttomia julkisoikeudellisia suoritteita ovat päätös ja muu toimituskirja

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** hallintokantelusta;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** viranomaisen sisäistä tai sen alaista hallintoa koskevasta asiasta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** asianosaiselle sellaisesta asiasta, jossa hänet on laissa vapautettu suorittamasta maksuja viranomaisen toimenpiteistä tai toimituskirjoista; sekä

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** jos muutoksenhakemusta ei tutkita tai se raukeaa taikka jos asia aineellisia kysymyksiä osaksikaan ratkaisematta palautetaan alemman viranomaisen ratkaistavaksi\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Lisäksi mainittu maksuton suorite on asianosaiselle hänen pyytämättään annettava ote tai jäljennös toimituskirjasta tai muusta viranomaisen hallussa säilytettävästä asiakirjasta\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Maksullisia julkisoikeudellisia suoritteita, joiden maksun maanmittauslaitos määrää suoritteen omakustannusarvon mukaan, ovat

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** rakennus\- ja rantakaavan pohjakartan hyväksyminen;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** kylän nimen muuttaminen;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kyläjaotuksen muuttaminen;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** rekisteriyksikön nimen muuttaminen;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** lunastusluvan antaminen lunastuslain 5 §:n 2 momentin \(476/1996\) nojalla;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** lunastuslain 59 §:n 1 momentissa [\(603/1977\)](<https://www.finlex.fi/fi/lainsaadanto/1977/603>) tarkoitetun ennakkohaltuunottoluvan myöntäminen erillisenä; sekä

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** lunastuslain 72 c §:ssä \(476/1996\) tarkoitettu erityisen oikeuden siirtäminen ja kiinteistörekisteriin merkitseminen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Julkisoikeudellisista suoritteista perittäviä kiinteitä maksuja ovat lakiin tai asetukseen perustuva kiinteistöjen kauppahintarekisterin tietojen luovuttaminen viranomaiselle kiinteistönluovutukselta 3 mk\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Edellä 1 momentissa mainitun maksun lisäksi peritään kauppahintarekisterin tietojen luovuttamisesta aiheutuvat kustannukset\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Muut maksulliset suoritteet, jotka maanmittauslaitos hinnoittelee liiketaloudellisin perustein, ovat

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** kiintopisteaineistot;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** ilma\- ja satelliittikuva\-aineistot sekä niiden julkaisuluvat;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** maastokartta\-aineistot ja kartastot sekä niiden käyttöoikeuksien luovutukset;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** paikkatietojen yhteiskäytön palvelut;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** ohjelmistot ja niiden käyttöoikeudet;

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** muut kiinteistöjen kauppahintarekisterin kuin 4 §:n 1 momentin 1 kohdassa tarkoitetut suoritteet;

<a id="section-4-subsection-1-paragraph-7"></a>
- **7.** koulutuspalvelut;

<a id="section-4-subsection-1-paragraph-8"></a>
- **8.** konsultointipalvelut ja selvitykset;

<a id="section-4-subsection-1-paragraph-9"></a>
- **9.** todistukset;

<a id="section-4-subsection-1-paragraph-10"></a>
- **10.** otteet ja jäljennökset;

<a id="section-4-subsection-1-paragraph-11"></a>
- **11.** asiakirjojen ja muun aineiston lähettäminen ja postitus;

<a id="section-4-subsection-1-paragraph-12"></a>
- **12.** tilauksesta suoritettavat toimialaan kuuluvat suoritteet, jotka ovat muita kuin 1―11 kohdassa mainittuja suoritteita;

<a id="section-4-subsection-1-paragraph-13"></a>
- **13.** maanmittauslaitoksen hallitsemien tilojen, kaluston ja välineiden tilapäinen käyttö;

<a id="section-4-subsection-1-paragraph-14"></a>
- **14.** julkaisut; sekä

<a id="section-4-subsection-1-paragraph-15"></a>
- **15.** muut edellä mainittuihin verrattavat suoritteet\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1997, ja sillä kumotaan eräiden maanmittauslaitoksen suoritteiden maksullisuudesta, maksuperusteista ja suoritteista perittävistä maksuista 21 päivänä joulukuuta 1994 annettu maa\- ja metsätalousministeriön päätös [\(1292/1994\)](<https://www.finlex.fi/fi/lainsaadanto/1994/1292>)\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
