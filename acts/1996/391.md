# Sisäasiainministeriön päätös maistraattien toimialueista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maistraatit toimivat kihlakunnanvirastojen yksikköinä tai erillisinä virastoina ja hoitavat toimialaansa kuuluvat tehtävät yhden tai useamman kihlakunnan alueella sen mukaan kuin tässä päätöksessä määrätään\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Kihlakunnanvirastojen yksikköinä toimivien maistraattien sijaintikihlakunnat ja toimialueet ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Espoon kihlakunta, Lohjan kihlakunta \(sijaintikihlakunnat, päätoimipaikkana Espoo\) ja Vihdin kihlakunta,

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Hyvinkään kihlakunta, jossa maistraatti sijaitsee \(sijaintikihlakunta\) ja Keski\-Uudenmaan kihlakunta

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Porvoon kihlakunta \(sijaintikihlakunta\), Loviisan kihlakunta ja Orimattilan kihlakunta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Raaseporin kihlakunta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Vantaan kihlakunta;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Turunmaan kihlakunta;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Mikkelin kihlakunta, Savonlinnan kihlakunta \(sijaintikihlakunnat, päätoimipaikkana Mikkeli\), Pieksämäen kihlakunta ja Juvan kihlakunta,

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Kokkolan kihlakunta \(sijaintikihlakunta\) ja Kaustisen kihlakunta;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** Seinäjoen kihlakunta \(sijaintikihlakunta\), Alavuden kihlakunta, Kauhajoen kihlakunta ja Lapuan kihlakunta;

<a id="section-2-subsection-1-paragraph-20"></a>
- **20.** Kajaanin kihlakunta \(sijaintikihlakunta\), Kuhmon kihlakunta ja Suomussalmen kihlakunta;

<a id="section-2-subsection-1-paragraph-24"></a>
- **24.** Rovaniemen kihlakunta, Kittilän kihlakunta, Kemin kihlakunta \(sijaintikihlakunnat, päätoimipaikkana Rovaniemi\), Koillis\-Lapin kihlakunta, Ranuan\-Posion kihlakunta, Tornion kihlakunta, Tornionlaakson kihlakunta, Inarin\-Utsjoen kihlakunta, Käsivarren kihlakunta ja Sodankylän kihlakunta\.

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** Joensuun kihlakunta \(sijaintikihlakunta\), Ilomantsin kihlakunta, Kiteen kihlakunta, Lieksan kihlakunta ja Nurmeksen kihlakunta

<a id="section-3-subsection-1-paragraph-11"></a>

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** Jyväskylän kihlakunta, Jämsän kihlakunta, Saarijärven kihlakunta \(sijaintikihlakunnat\), Keuruun kihlakunta ja Äänekosken kihlakunta ja

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** Oulun kihlakunta, Raahen kihlakunta \(sijaintikihlakunnat\), Haukiputaan kihlakunta, Kuusamon kihlakunta, Limingan kihlakunta, Pudasjärven kihlakunta, Haapajärven kihlakunta ja Ylivieskan kihlakunta\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Edellä 2 §:n 1, 4, 5, 6, 9 ja 16 kohdissa sekä 3 §:n 1, 3, 7 ja 11 kohdissa tarkoitetut maistraatit ovat kaksikielisiä\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Muut maistraatit ovat suomenkielisiä\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä joulukuuta 1996\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
