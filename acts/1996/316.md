# Oikeusministeriön päätös valitsijayhdistyksen perustajajäsenten vähimmäismääristä eräissä kunnissa vuoden 1996 kunnallisvaaleissa

- Statute: [`316/1996`](<https://www.finlex.fi/fi/laki/ajantasa/1996/316>)
- Version: `1996-06-01`
- LawVM tree hash: `7d576e2f139395aa2644ace50e399bbcffda0326bc59384e34f8259b3963785c`

## Contents

- [1 §](#section-1)

- [2 §](#section-2)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Poiketen siitä\. mitä kunnallisvaalilain \(361/72\) 20 §:n 1 momentissa säädetään, saa valitsijayhdistyksen vuoden 1996 kunnallisvaaleissa perustaa seuraavissa kunnissa jäljempänä mainittu vähimmäismäärä äänioikeutettuja kunnan jäseniä:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** 1 Vähintään kolme äänioikeutettua kunnan jäsentä\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Uudenmaan lääni: Sammatti\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Turun ja Porin lääni: Askainen, Houtskari, Iniö, Kodisjoki, Korppoo, Kustavi, Merimasku, Särkisalo, Velkua ja Västanfjärd\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Hämeen lääni: Kuhmalahti\.

<a id="section-1-subsection-5"></a>
#### \(5\)

Pohjois\-Karjalan lääni: Värtsilä\.

<a id="section-1-subsection-6"></a>
#### \(6\)

Oulun lääni: Hailuoto ja Temmes\.

<a id="section-1-subsection-7"></a>
#### \(7\)

Lapin lääni: Enontekiö ja Pelkosenniemi\.

<a id="section-1-subsection-8"></a>
#### \(8\)

2 Vähintään viisi äänioikeutettua kunnan jäsentä\.

<a id="section-1-subsection-9"></a>
#### \(9\)

Uudenmaan lääni: Artjärvi, Karjalohja, Liljendal, Myrskylä ja Pukkila\.

<a id="section-1-subsection-10"></a>
#### \(10\)

Turun ja Porin lääni: Kiikala, Kiikoinen, Kisko, Kullaa, Kuusjoki, Lemu, Mellilä, Mietoinen, Muurla, Nauvo, Oripää, Rymättylä, Suodenniemi, Suomusjärvi, Taivassalo, Tarvasjoki, Vahto ja Vampula\.

<a id="section-1-subsection-11"></a>
#### \(11\)

Hämeen lääni: Längelmäki\.

<a id="section-1-subsection-12"></a>
#### \(12\)

Kymen lääni: Saari ja Uukuniemi\.

<a id="section-1-subsection-13"></a>
#### \(13\)

Mikkelin lääni: Savonranta ja Virtasalmi\.

<a id="section-1-subsection-14"></a>
#### \(14\)

Vaasan lääni: Halsua, Korsnäs, Lestijärvi ja Maksamaa\.

<a id="section-1-subsection-15"></a>
#### \(15\)

Keski\-Suomen lääni: Kinnula, Kivijärvi, Luhanka ja Sumiainen\.

<a id="section-1-subsection-16"></a>
#### \(16\)

Oulun lääni: Lumijoki, Merijärvi, Piippola ja Siikajoki\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä kesäkuuta 1996\.
