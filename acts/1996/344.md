### 2 § Ministeriön organisaatio

<a id="section-2-subsection-1"></a>
#### \(1\)

Puolustusministeriössä on puolustuspoliittinen osasto, keskusosasto, järjestelyosasto sekä kiinteistö\- ja ympäristöosasto\. Osastojen vastuualueista ja muista toimintayksiköistä määrätään ministeriön työjärjestyksessä\.

<a id="section-3"></a>
### 3 § Ministeriön hallinnonala

<a id="section-3-subsection-1"></a>
#### \(1\)

Puolustusministeriön hallinnon alaisia ovat puolustusvoimat, puolustushallinnon rakennuslaitos, suomalaiset rauhanturvaamisorganisaatiot, kutsunta\-asiain keskuslautakunta, kutsuntalautakunnat, maanpuolustustiedotuksen suunnittelukunta, maanpuolustuksen tieteellinen neuvottelukunta sekä vapaaehtoisen maanpuolustustyön neuvottelukunta\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Puolustusministeriön valvontaan kuuluvat valtionenemmistöiset osakeyhtiöt Lapua Oy, Vammas Oy ja VPU Pukutehdas Oy\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Lisäksi ministeriön hallinnonalaan kuuluu puolustusneuvosto\.

<a id="section-7"></a>
### 7 § Kiinteistö\- ja ympäristöosasto

<a id="section-7-subsection-1"></a>
#### \(1\)

Kiinteistö\- ja ympäristöosasto käsittelee asiat, jotka koskevat:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** hallinnonalan kiinteistöpolitiikkaa ja \-hallintoa;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** metsätaloutta ja ympäristönsuojelua; sekä

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** puolustusministeriölle kiinteistöyksikkönä kuuluvia tehtäviä\.

<a id="section-8"></a>
### 8 § Ministeriön virkamiehet

<a id="section-8-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** kansliapäällikkö,

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** hallitusneuvoksia, joista yksi toimii keskusosaston ja yksi kiinteistö\- ja ympäristöosaston päällikkönä,

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** puolustuspoliittisen osaston osastopäällikkö,

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** järjestelyosaston osastopäällikkö,

<a id="section-8-subsection-1-paragraph-5"></a>
- **5.** hallitusneuvos, lainsäädäntöjohtajana,

<a id="section-8-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvos, henkilöstöjohtajana,

<a id="section-8-subsection-1-paragraph-7"></a>
- **7.** kaupallinen neuvos, joka toimii materiaalihallintojohtajana,

<a id="section-8-subsection-1-paragraph-8"></a>
- **8.** talousjohtaja,

<a id="section-8-subsection-1-paragraph-9"></a>
- **9.** kehittämisjohtaja,

<a id="section-8-subsection-1-paragraph-10"></a>
- **10.** kiinteistöjohtaja ja vanhempi hallitussihteeri, kiinteistöjohtajana,

<a id="section-8-subsection-1-paragraph-11"></a>
- **11.** vanhempia ja nuorempia hallitussihteereitä,

<a id="section-8-subsection-1-paragraph-12"></a>
- **12.** vanhempia osastoesiupseereita sekä osastoesiupseereita,

<a id="section-8-subsection-1-paragraph-13"></a>
- **13.** neuvottelevia virkamiehiä, pääsihteereitä, hallinnollinen sihteeri ja yleissihteeri,

<a id="section-8-subsection-1-paragraph-14"></a>
- **14.** laskentapäällikkö, tarkastuspäällikkö ja tietohallintopäällikkö,

<a id="section-8-subsection-1-paragraph-15"></a>
- **15.** yli\-insinööri ja insinööri,

<a id="section-8-subsection-1-paragraph-16"></a>
- **16.** ylimetsänhoitaja ja aluemetsänhoitajia,

<a id="section-8-subsection-1-paragraph-17"></a>
- **17.** koulutuspäällikkö ja tiedotuspäällikkö,

<a id="section-8-subsection-1-paragraph-18"></a>
- **18.** ylitarkastajia sekä

<a id="section-8-subsection-1-paragraph-19"></a>
- **19.** esittelijöitä\.

<a id="section-8-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä on muuta virkasuhteessa ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-8-subsection-3"></a>
#### \(3\)

Järjestelyosaston osastopäälliköllä ja puolustuspoliittisen osaston puolustuspolitiikan vastuualueen johtajana toimivalla neuvottelevalla virkamiehellä on puolustusasiainneuvoksen arvonimi\.

<a id="section-9"></a>
### 9 § Virkojen kelpoisuusvaatimukset

<a id="section-9-subsection-1"></a>
#### \(1\)

Lisäksi vaaditaan kelpoisuusvaatimuksena:

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** pääsihteeriltä, yleissihteeriltä, laskentapäälliköltä, tarkastuspäälliköltä, tietohallintopäälliköltä, ylitarkastajalta, tiedotuspäälliköltä ja koulutuspäälliköltä virkaan soveltuva ylempi korkeakoulututkinto;
