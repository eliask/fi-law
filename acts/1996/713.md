<a id="section-1"></a>
### 1 § Tuomiopiirit

<a id="section-1-subsection-1"></a>
#### \(1\)

Ulosottolain 10 luvun 2 §:n 1 momentissa tarkoitettujen käräjäoikeuksien tuomiopiirit ulosottovalituksia koskevissa asioissa ovat seuraavat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Ahvenanmaan käräjäoikeuden tuomiopiiri käsittää Ahvenanmaan maakunnan alueen;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Espoon käräjäoikeuden tuomiopiiri käsittää: Espoon, Lohjan, Raaseporin ja Vihdin kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Helsingin käräjäoikeuden tuomiopiiri käsittää: Helsingin kihlakunnan ulosottoviraston sekä Loviisan ja Porvoon kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Joensuun käräjäoikeuden tuomiopiiri käsittää: Joensuun kihlakunnan ulosottoviraston toimialueen;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Jyväskylän käräjäoikeuden tuomiopiiri käsittää: Jyväskylän kihlakunnan ulosottoviraston sekä Saarijärven ja Äänekosken kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Kajaanin käräjäoikeuden tuomiopiiri käsittää: Kajaanin, Kuhmon ja Suomussalmen kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Kotkan käräjäoikeuden tuomiopiiri käsittää: Kotkan kihlakunnan ulosottoviraston sekä Kouvolan kihlakunnanviraston toimialueet;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kuopion käräjäoikeuden tuomiopiiri käsittää: Kuopion seudun kihlakunnan ulosottoviraston sekä Ylä\-Savon kihlakunnanviraston toimialueet;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Lahden käräjäoikeuden tuomiopiiri käsittää: Lahden kihlakunnan ulosottoviraston toimialueen;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Lappeenrannan käräjäoikeuden tuomiopiiri käsittää: Lappeenrannan kihlakunnan ulosottoviraston toimialueen;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Mikkelin käräjäoikeuden tuomiopiiri käsittää: Juvan, Mikkelin, Pieksämäen ja Savonlinnan kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** Oulun käräjäoikeuden tuomiopiiri käsittää: Oulun kihlakunnan ulosottoviraston toimialueen;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** Porin käräjäoikeuden tuomiopiiri käsittää: Porin kihlakunnan ulosottoviraston sekä Kokemäen, Rauman ja Vammalan kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** Rovaniemen käräjäoikeuden tuomiopiiri käsittää: Inari\-Utsjoen, Kemin, Kittilän, Käsivarren, Koillis\-Lapin, Ranua\-Posion, Rovaniemen, Sodankylän, Tornionlaakson ja Tornion kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** Seinäjoen käräjäoikeuden tuomiopiiri käsittää: Alavuden, Kauhajoen, Lapuan ja Seinäjoen kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** Tampereen käräjäoikeuden tuomiopiiri käsittää: Tampereen ja Hämeenlinnan kihlakuntien ulosottovirastojen sekä Ikaalisten, Kangasalan, Mäntän, Nokian ja Valkeakosken kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** Turun käräjäoikeuden tuomiopiiri käsittää: Turun kihlakunnan ulosottoviraston sekä Kaarinan, Loimaan, Raision, Salon, Turunmaan ja Vakka\-Suomen kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** Vaasan käräjäoikeuden tuomiopiiri käsittää: Vaasan kihlakunnan ulosottoviraston sekä Haapajärven, Kaustisen, Kokkolan, Raahen ja Ylivieskan kihlakunnanvirastojen toimialueet;

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** Vantaan käräjäoikeuden tuomiopiiri käsittää: Hyvinkään, Keski\-Uudenmaan ja Vantaan kihlakunnanvirastojen toimialueet\.

<a id="section-2"></a>
### 2 § Voimaantulo

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä joulukuuta 1996\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimiin\.
