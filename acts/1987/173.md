# Sisäasiainministeriön päätös kuntajaon muuttamisesta eräiltä osin Joutsenon ja Nuijamaan kuntien välillä

- Statute: [`173/1987`](<https://www.finlex.fi/fi/laki/ajantasa/1987/173>)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Joutsenon kunnasta siirretään Nuijamaan kuntaan seuraavat tilat ja alueet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Kähärilän kylästä kokonaan tilat Myränmaa 1:6 ja Myränsalo 4:3 sekä mainittujen tilojen alueella sijaitsevat yleiset ja yhteiset alueet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Nuijamaan kunnasta siirretään Joutsenon kuntaan seuraavat tilat ja alueet:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Kotolan kylästä kokonaan tila Peltola 1:38;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Marttilan kylästä kokonaan tilat Alaniitty 1:6, Välipelto 1:21 ja Alapelto 1:25;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Myrän kylästä kokonaan tila Niittymaa 2:23; sekä

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** edellä mainittujen tilojen alueella sijaitsevat yleiset ja yhteiset alueet\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1988\.
