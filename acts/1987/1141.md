### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtiovarainministeriössä on:

<a id="section-1-subsection-2"></a>
#### \(2\)

yleinen osasto;

<a id="section-1-subsection-3"></a>
#### \(3\)

tulo\- ja menoarvio\-osasto;

<a id="section-1-subsection-4"></a>
#### \(4\)

vero\-osasto;

<a id="section-1-subsection-5"></a>
#### \(5\)

kansantalousosasto;

<a id="section-1-subsection-6"></a>
#### \(6\)

palkkaosasto; sekä

<a id="section-1-subsection-7"></a>
#### \(7\)

hallinnon kehittämisosasto\.

<a id="section-1-subsection-8"></a>
#### \(8\)

Lisäksi ministeriössä on suunnittelusihteeristö ja hallintotoimisto\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön osastot jakaantuvat toimistoihin ja lainvalmisteluyksikköön sen mukaan kuin tässä asetuksessa säädetään\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Osastojen muusta organisaatiosta ja työnjaosta määrää osaston päällikkö\.

<a id="section-3"></a>
### 3 § Ministeriön alaiset virastot ja laitokset

<a id="section-3-subsection-1"></a>
#### \(1\)

Ministeriön alaisia ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** pankkitarkastusvirasto;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Suomen rahapaja;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** tullihallitus;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** rakennushallitus;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** valtiokonttori;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** valtiontalouden tarkastusvirasto;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** verohallitus;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** taloudellinen suunnittelukeskus;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** valtion ravitsemiskeskus;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** tilastokeskus;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** valtion painatuskeskus;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** valtion tietokonekeskus; sekä

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** Valtionhallinnon kehittämiskeskus\.

<a id="section-4"></a>
### 4 § Yleinen osasto

<a id="section-4-subsection-1"></a>
#### \(1\)

Yleisessä osastossa on:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** rahalaitostoimisto; sekä

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** laina\- ja kansainvälisten asiain toimisto\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Yleinen osasto käsittelee asiat, jotka koskevat:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** pankkeja, hypoteekkiyhdistyksiä, luotto\-osakeyhtiöitä, säästökassatoimintaa harjoittavia osuuskuntia ja rahastoyhtiöitä sekä niiden tarkastusta;

<a id="section-5-subsection-1-paragraph-1a"></a>
- **1a.** arvopaperipörssitoimintaa, optioyhteisötoimintaa, arvopaperinvälitysliikkeitä ja panttilainauslaitoksia sekä niiden tarkastusta;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** pankkitarkastusvirastoa;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** Suomen Pankkia;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** valtion lainanottoa ja valtion velanhoitoa;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** valuuttalainsäädäntöä ja rahajärjestelmää;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** Kansainvälistä Valuuttarahastoa, Kansainvälistä Jälleenrakennuspankkia ja sen liitännäisjärjestöjä, Pohjoismaiden Investointipankkia ja Länsipohjolan pohjoismaista kehittämisrahastoa sekä alueellisten kansainvälisten kehityspankkien ja \-rahastojen toiminnan seurantaa;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** kansainvälisten järjestöjen ja yhteistyöelinten toimintaa rahoitus\- ja pääomamarkkinakysymyksissä;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** luvan antamista obligaatiolainan liikkeeseen laskemiseen sekä siihen liittyvän veronhuojennuksen myöntämistä;

<a id="section-5-subsection-1-paragraph-9"></a>
- **9.** valtiontakausta;

<a id="section-5-subsection-1-paragraph-10"></a>
- **10.** tulliverotusta, tasausveroa, varmuusvarastointimaksua, vientitalletusta ja \-maksua, tuontimaksuja sekä muita maahan tuonnin ja maasta viennin yhteydessä kannettavia erityisveroja tai maksuja;

<a id="section-5-subsection-1-paragraph-11"></a>
- **11.** valmisteverotusta ja hinnanerokorvauksia;

<a id="section-5-subsection-1-paragraph-12"></a>
- **12.** markkinahäiriöitä ja polkumyyntiä;

<a id="section-5-subsection-1-paragraph-13"></a>
- **13.** tullihallintoa;

<a id="section-5-subsection-1-paragraph-14"></a>
- **14.** kansainvälistä tulliyhteistyötä;

<a id="section-5-subsection-1-paragraph-15"></a>
- **15.** Suomen rahapajaa;

<a id="section-5-subsection-1-paragraph-16"></a>
- **16.** Ahvenanmaan maakuntaan liittyviä finanssihallintoasioita;

<a id="section-5-subsection-1-paragraph-17"></a>
- **17.** valtionperintöjä;

<a id="section-5-subsection-1-paragraph-18"></a>
- **18.** indeksiehdon käytön rajoittamista;

<a id="section-5-subsection-1-paragraph-19"></a>
- **19.** lainsäädäntöä, joka ei kuulu ministeriön muun osaston käsiteltäviin;

<a id="section-5-subsection-1-paragraph-20"></a>
- **20.** ministeriön edustusta oikeusasioissa ja yhteisöissä, jollei asia kuulu ministeriön muun osaston käsiteltäviin; sekä

<a id="section-5-subsection-1-paragraph-21"></a>
- **21.** ministeriön kansainvälisten asioiden hoidon yhteensovittamista\.

<a id="section-6"></a>
### 6 § Tulo\- ja menoarvio\-osasto

<a id="section-6-subsection-1"></a>
#### \(1\)

Tulo\- ja menoarvio\-osastossa on:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** finanssipoliittinen toimisto;

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** rakennus\- ja kiinteistötoimisto; sekä

<a id="section-6-subsection-1-paragraph-4"></a>
- **4.** tutkimus\- ja kehittämistoimisto\.

<a id="section-7"></a>
### 7 §

<a id="section-7-subsection-1"></a>
#### \(1\)

Tulo\- ja menoarvio\-osasto käsittelee asiat, jotka koskevat:

<a id="section-7-subsection-1-paragraph-1"></a>
- **1.** finanssipolitiikan tavoitteita, päälinjoja ja keinoja;

<a id="section-7-subsection-1-paragraph-2"></a>
- **2.** valtion pitkän ja keskipitkän ajan toiminta\- ja taloussuunnitelmia sekä niiden laadintaa;

<a id="section-7-subsection-1-paragraph-3"></a>
- **3.** valtion tulo\- ja menoarvioesitystä;

<a id="section-7-subsection-1-paragraph-4"></a>
- **4.** valtion erityismenoarviota, lukuun ottamatta virkaluetteloa;

<a id="section-7-subsection-1-paragraph-5"></a>
- **5.** valtion pitkän ja keskipitkän ajan toiminta\- ja taloussuunnitteluun sekä tulo\- ja menoarvioon liittyvää selvitys\- ja kehittämistoimintaa sekä määrärahojen alueellisen kohdentamisen selvittämistä;

<a id="section-7-subsection-1-paragraph-6"></a>
- **6.** valtion tulo\- ja menoarvion soveltamista ja toteuttamisen valvontaa;

<a id="section-7-subsection-1-paragraph-7"></a>
- **7.** valtion maksuvalmiuden sekä määrärahojen käytön suunnittelua ja valvontaa sekä kassavarojen sijoittamista ja maksuvalmiuden turvaamiseksi tarvittavan lyhytaikaisen kotimaisen luoton ottamista;

<a id="section-7-subsection-1-paragraph-8"></a>
- **8.** valtion maksuliikettä;

<a id="section-7-subsection-1-paragraph-9"></a>
- **9.** valtion hallinnollista ja liikekirjanpitoa, muuta tilinpitoa ja tilinpäätöstä sekä valtion virastojen, laitosten ja liikeyritysten suunnittelu\- ja laskentajärjestelmiä;

<a id="section-7-subsection-1-paragraph-10"></a>
- **10.** valtionvelkaa, mikäli asia ei kuulu ministeriön muun osaston käsiteltäviin;

<a id="section-7-subsection-1-paragraph-11"></a>
- **11.** valtiolle perittävien maksujen yleisiä perusteita;

<a id="section-7-subsection-1-paragraph-12"></a>
- **12.** valtiovarainministeriön hallinnonalan tulo\- ja menoarvioehdotusta sekä pitkän ja keskipitkän ajan toiminta\- ja taloussuunnitelmia sekä ehdotusta valtiovarainministeriön osuudeksi valtiontalouden suunnitelmaan;

<a id="section-7-subsection-1-paragraph-13"></a>
- **13.** valtion suhdannerahastoa ja muita valtion rahastoja, mikäli ne eivät kuulu ministeriön muun osaston käsiteltäviin asioihin;

<a id="section-7-subsection-1-paragraph-14"></a>
- **14.** valtion tilien ja taloudenhoidon tarkastusta;

<a id="section-7-subsection-1-paragraph-15"></a>
- **15.** hallituksen kertomusta toimenpiteistä, joihin eduskunnan tekemät muistutukset valtiovarain hoidosta ja tilinpidosta ovat antaneet aihetta;

<a id="section-7-subsection-1-paragraph-16"></a>
- **16.** valtion rakennus\- ja kiinteistöhallintoa;

<a id="section-7-subsection-1-paragraph-17"></a>
- **17.** rakennushallitusta;

<a id="section-7-subsection-1-paragraph-18"></a>
- **18.** valtiokonttoria; sekä

<a id="section-7-subsection-1-paragraph-19"></a>
- **19.** valtiontalouden tarkastusvirastoa\.

<a id="section-8"></a>
### 8 § Vero\-osasto

<a id="section-8-subsection-1"></a>
#### \(1\)

Vero\-osastossa on:

<a id="section-8-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-8-subsection-1-paragraph-2"></a>
- **2.** tutkimustoimisto;

<a id="section-8-subsection-1-paragraph-3"></a>
- **3.** kansainvälisten asiain toimisto; sekä

<a id="section-8-subsection-1-paragraph-4"></a>
- **4.** lainvalmisteluyksikkö\.

<a id="section-9"></a>
### 9 §

<a id="section-9-subsection-1"></a>
#### \(1\)

Vero\-osasto käsittelee asiat, jotka koskevat:

<a id="section-9-subsection-1-paragraph-1"></a>
- **1.** veropoliittisia kysymyksiä talous\- ja finanssipolitiikan suunnittelun ja toimenpidevaihtoehtojen yhteydessä;

<a id="section-9-subsection-1-paragraph-2"></a>
- **2.** verolainsäädäntöä, lukuun ottamatta tulli\- ja valmisteverotusta koskevaa lainsäädäntöä;

<a id="section-9-subsection-1-paragraph-3"></a>
- **3.** kansainvälisten verosopimusten valmistelua ja muita kansainvälisiä veroasioita;

<a id="section-9-subsection-1-paragraph-4"></a>
- **4.** verohallitusta sekä muuta verohallintoa, mikäli niitä koskevia asioita ei ole erikseen säädetty muiden viranomaisten käsiteltäviksi;

<a id="section-9-subsection-1-paragraph-5"></a>
- **5.** muita kuin edellä tarkoitettuja veroihin ja veronluonteisiin maksuihin liittyviä kysymyksiä, mikäli niitä ei ole erikseen säädetty muiden viranomaisten käsiteltäviksi; sekä

<a id="section-9-subsection-1-paragraph-6"></a>
- **6.** tutkimuksia ja tilastollisia selvityksiä, jotka liittyvät 1\-5 kohdassa mainittujen tehtävien hoitoon\.

<a id="section-10"></a>
### 10 § Kansantalousosasto

<a id="section-10-subsection-1"></a>
#### \(1\)

Kansantalousosastossa on:

<a id="section-10-subsection-1-paragraph-1"></a>
- **1.** suhdannetoimisto;

<a id="section-10-subsection-1-paragraph-2"></a>
- **2.** julkisen talouden toimisto;

<a id="section-10-subsection-1-paragraph-3"></a>
- **3.** talouspoliittinen toimisto;

<a id="section-10-subsection-1-paragraph-4"></a>
- **4.** kansainvälisten asiain toimisto; sekä

<a id="section-10-subsection-1-paragraph-5"></a>
- **5.** tutkimus\- ja suunnittelutoimisto\.

<a id="section-11"></a>
### 11 §

<a id="section-11-subsection-1"></a>
#### \(1\)

Kansantalousosasto käsittelee asiat, jotka koskevat:

<a id="section-11-subsection-1-paragraph-1"></a>
- **1.** koti\- ja ulkomaisen suhdanne\- ja muun taloudellisen kehityksen seuraamista, tutkimista ja ennustamista;

<a id="section-11-subsection-1-paragraph-2"></a>
- **2.** julkisen talouden kehitystä ja suunnittelua;

<a id="section-11-subsection-1-paragraph-3"></a>
- **3.** talouspolitiikan suunnittelua ja talouspoliittisten toimenpiteiden vaikutusten selvittämistä;

<a id="section-11-subsection-1-paragraph-4"></a>
- **4.** taloudellisen kehityksen ja talouspolitiikan linjan sekä yhteiskuntapoliittisten suunnitelmien yhteensopeuttamista;

<a id="section-11-subsection-1-paragraph-5"></a>
- **5.** julkisen talouden rahoitusmarkkinavaikutuksia erityisesti finanssi\- ja rahapolitiikan yhteensopeuttamisen kannalta;

<a id="section-11-subsection-1-paragraph-6"></a>
- **6.** lausuntojen antamista sellaisista valmisteilla olevista asioista, joilla on huomattavaa kansantaloudellista merkitystä;

<a id="section-11-subsection-1-paragraph-7"></a>
- **7.** kansainvälisten järjestöjen ja yhteistyöelinten toimintaa kansantaloudellisissa ja talouspoliittisissa kysymyksissä;

<a id="section-11-subsection-1-paragraph-8"></a>
- **8.** kuntien yleistä kalleusluokitusta;

<a id="section-11-subsection-1-paragraph-9"></a>
- **9.** hallituksen kertomusta valtiovarain hoidosta ja tilasta;

<a id="section-11-subsection-1-paragraph-10"></a>
- **10.** taloudellisten katsausten ja ennusteiden julkaisemista sekä muuta taloudellista tiedotustoimintaa;

<a id="section-11-subsection-1-paragraph-11"></a>
- **11.** muita kansantalouden tasapainon, kehityksen ja suunnittelun kannalta keskeisiä kysymyksiä; sekä

<a id="section-11-subsection-1-paragraph-12"></a>
- **12.** taloudellista suunnittelukeskusta\.

<a id="section-12"></a>
### 12 § Palkkaosasto

<a id="section-12-subsection-1"></a>
#### \(1\)

Palkkaosastossa, joka toimii valtion työmarkkinalaitoksena, on:

<a id="section-12-subsection-1-paragraph-1"></a>
- **1.** yleinen toimisto;

<a id="section-12-subsection-1-paragraph-2"></a>
- **2.** virkamiespalkkatoimisto;

<a id="section-12-subsection-1-paragraph-3"></a>
- **3.** työntekijäinpalkkatoimisto;

<a id="section-12-subsection-1-paragraph-4"></a>
- **4.** valtionapupalkkatoimisto; sekä

<a id="section-12-subsection-1-paragraph-5"></a>
- **5.** tutkimustoimisto\.

<a id="section-13"></a>
### 13 §

<a id="section-13-subsection-1"></a>
#### \(1\)

Palkkaosasto käsittelee asiat, jotka koskevat:

<a id="section-13-subsection-1-paragraph-1"></a>
- **1.** osallistumista valtiotyönantajan edustajana tulo\- ja työmarkkinapoliittiseen toimintaan;

<a id="section-13-subsection-1-paragraph-2"></a>
- **2.** valtion työnantajapolitiikan yleistä suunnittelua ja toteuttamista;

<a id="section-13-subsection-1-paragraph-3"></a>
- **3.** valtion henkilöstön oikeudellista asemaa ja virkamieslainsäädäntöä;

<a id="section-13-subsection-1-paragraph-4"></a>
- **4.** valtion virkaehtosopimuslainsäädäntöä ja yksityisten valtionapulaitosten toimiehtosopimuslainsäädäntöä;

<a id="section-13-subsection-1-paragraph-5"></a>
- **5.** valtion virkaehtosopimustoimintaa;

<a id="section-13-subsection-1-paragraph-6"></a>
- **6.** valtion työehtosopimustoiminnan yleistä ohjausta ja valvontaa;

<a id="section-13-subsection-1-paragraph-7"></a>
- **7.** yksityisten valtionapulaitosten toimiehtosopimustoimintaa;

<a id="section-13-subsection-1-paragraph-8"></a>
- **8.** valtion ja sen henkilöstön välisen yhteistoiminnan yleistä järjestelyä;

<a id="section-13-subsection-1-paragraph-9"></a>
- **9.** valtion virkamiesten palkkausta ja muita palvelussuhteen ehtoja;

<a id="section-13-subsection-1-paragraph-10"></a>
- **10.** valtion työsopimussuhteisen henkilöstön periaatteellisia ja muutoin yleisluontoisia palvelussuhteen ehtoja ja periaatteellisesti merkittävien yksittäisten työsopimusten ehtoja sekä niiden soveltamisen valvontaa;

<a id="section-13-subsection-1-paragraph-11"></a>
- **11.** valtion muuta yleistä henkilöstöpolitiikkaa;

<a id="section-13-subsection-1-paragraph-12"></a>
- **12.** kunnallisten ja yksityisten valtionapua saavien yhteisöjen ja laitosten henkilöstön palkkausta ja muita palvelussuhteen ehtoja sekä niihin liittyviä valtionapuperusteita;

<a id="section-13-subsection-1-paragraph-13"></a>
- **13.** valtion virastojen ja laitosten sekä toimiehtosopimusjärjestelmän piiriin kuuluvien yksityisten valtionapulaitosten työrauhan turvaamisen yleistä ohjausta;

<a id="section-13-subsection-1-paragraph-14"></a>
- **14.** virkojen sekä niiden nimien ja kelpoisuusehtojen yleistä järjestelyä sekä valtion virkaluetteloa;

<a id="section-13-subsection-1-paragraph-15"></a>
- **15.** valtion palvelussuhdeasuntojen vuokrien määräytymisperusteita sekä valtion henkilöstön luontoisetujen ja sosiaalisten etujen yleistä järjestämistä;

<a id="section-13-subsection-1-paragraph-16"></a>
- **16.** palvelussuhteen perusteella valtion varoista suoritettavien eläkkeiden, perhe\-eläkkeiden ja ylimääräisten eläkkeiden yleistä järjestelyä;

<a id="section-13-subsection-1-paragraph-17"></a>
- **17.** komiteatyön palkkioperusteita;

<a id="section-13-subsection-1-paragraph-18"></a>
- **18.** oikeutta valtion virka\-ansiomerkin saamiseen;

<a id="section-13-subsection-1-paragraph-19"></a>
- **19.** tilastointia sekä tutkimuksia ja selvityksiä, jotka liittyvät 1\-18 kohdassa mainittujen asioiden käsittelemiseen; sekä

<a id="section-13-subsection-1-paragraph-20"></a>
- **20.** valtion ravitsemiskeskusta\.

<a id="section-14"></a>
### 14 §

<a id="section-14-subsection-1"></a>
#### \(1\)

Hallinnon kehittämisosasto käsittelee asiat, jotka koskevat:

<a id="section-14-subsection-1-paragraph-1"></a>
- **1.** hallinnon kehittämisen toimintalinjoja;

<a id="section-14-subsection-1-paragraph-2"></a>
- **2.** hallinnon palvelukykyä ja tuloksellisuutta;

<a id="section-14-subsection-1-paragraph-3"></a>
- **3.** hallinnon organisointia sekä hallinnon ohjauksen ja toimintojen kehittämistä;

<a id="section-14-subsection-1-paragraph-4"></a>
- **4.** tietohallintoa ja tietotekniikkaa;

<a id="section-14-subsection-1-paragraph-5"></a>

<a id="section-19"></a>
### 19 § Ministeriön virkamiehet

<a id="section-19-subsection-1"></a>
#### \(1\)

Ministeriön kansliapäällikkönä on valtiosihteeri\. Lisäksi ministeriössä on alivaltiosihteeri\.

<a id="section-19-subsection-2"></a>
#### \(2\)

Osaston päällikkönä on osastopäällikkö, hallinnon kehittämisosaston päälikkönä kuitenkin virastovaltuutettu\. Suunnittelusihteeristön päällikkönä on suunnittelupäällikkö\.

<a id="section-19-subsection-3"></a>
#### \(3\)

Apulaisosastopäällikkönä on yleisessä osastossa hallitusneuvos, apulaisosastopäällikkönä, tulo\- ja menoarvio\-osastossa budjettineuvos, apulaisosastopäällikkönä ja hallitusneuvos, apulaisosastopäällikkönä, vero\-osastossa lainsäädäntöjohtaja, apulaisosastopäällikkönä, kansantalousosastossa finanssineuvos, apulaisosastopäällikkönä sekä palkkaosastossa ja hallinnon kehittämisosastossa kummassakin apulaisosastopäällikkö\.

<a id="section-19-subsection-4"></a>
#### \(4\)

Toimiston päällikkönä on, 20§:stä ilmenevin poikkeuksin, budjettineuvos, toimistopäällikkönä, finanssineuvos, toimistopäällikkönä, hallitusneuvos, toimistopäällikkönä tai toimistopäällikkö siten kuin 20§:ssä tarkemmin säädetään\.

<a id="section-19-subsection-5"></a>
#### \(5\)

Lisäksi ministeriössä on koulutuspäällikkö, budjettineuvoksia, finanssineuvoksia, hallitusneuvoksia, lainsäädäntöneuvoksia, rahoitusneuvos, neuvottelevia virkamiehiä, vanhempia ja nuorempia budjettisihteereitä, vanhempia ja nuorempia finanssisihteereitä, vanhempia ja nuorempia hallitussihteereitä, ylitarkastajia, tiedotuspäällikkö, tiedottaja, informaatikko, esittelijöitä, kamreeri, kirjaaja ja tarkastajia\.

<a id="section-19-subsection-6"></a>
#### \(6\)

Ministeriössä on myös osastosihteereitä ja muita vakinaisia virkamiehiä\. Lisäksi ministeriössä voi tulo\- ja menoarvion rajoissa olla tilapäistä ja työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-20"></a>
### 20 §

<a id="section-20-subsection-1"></a>
#### \(1\)

Yleisessä osastossa ovat yleisen toimiston ja laina\- ja kansainvälisten asiain toimiston päällikköinä hallitusneuvokset, toimistopäällikköinä, ja rahalaitostoimiston päällikkönä hallitusneuvos, apulaisosastopäällikkönä\.

<a id="section-20-subsection-2"></a>
#### \(2\)

Tulo\- ja menoarvio\-osastossa ovat yleisen toimiston päällikkönä hallitusneuvos, apulaisosastopäällikkönä, finanssipoliittisen toimiston päällikkönä budjettineuvos, apulaisosastopäällikkönä, rakennus\- ja kiinteistötoimiston päällikkönä hallitusneuvos, toimistopäällikkönä ja tutkimus\- ja kehittämistoimiston päällikkönä budjettineuvos, toimistopäällikkönä\.

<a id="section-20-subsection-3"></a>
#### \(3\)

Vero\-osastossa ovat yleisen toimiston ja kansainvälisten asiain toimiston päällikköinä hallitusneuvokset, toimistopäällikköinä, tutkimustoimiston päällikkönä finanssineuvos, toimistopäällikkönä ja lainvalmisteluyksikön päällikkönä lainsäädäntöjohtaja, apulaisosastopäällikkönä\.

<a id="section-20-subsection-4"></a>
#### \(4\)

Kansantalousosastossa ovat toimistojen päällikköinä finanssineuvokset, toimistopäällikköinä\.

<a id="section-20-subsection-5"></a>
#### \(5\)

Palkkaosastossa ovat yleisen toimiston, virkamiespalkkatoimiston, työntekijäinpalkkatoimiston ja valtionapupalkkatoimiston päällikköinä hallitusneuvokset, toimistopäällikköinä ja tutkimustoimiston päällikkönä finanssineuvos, toimistopäällikkönä\.

<a id="section-20-subsection-7"></a>
#### \(7\)

Suunnittelusihteeristössä ovat toimistojen päällikköinä toimistopäälliköt\.

<a id="section-21"></a>
### 21 §

<a id="section-21-subsection-1"></a>
#### \(1\)

Ministeri määrää 20§:n 1\-7 momentin säännökset huomioon ottaen, minkä toimiston päällikkönä asianomaisen osaston finanssineuvokset, toimistopäällikköinä, hallitusneuvokset, toimistopäällikköinä ja toimistopäälliköt toimivat\.

<a id="section-21-subsection-2"></a>
#### \(2\)

Ministeriön yhteisten virkojen sekä tilapäisen ja työsopimussuhteisen henkilöstön sijoittamisesta osastoihin, suunnittelusihteeristöön ja hallintotoimistoon sekä valtion virkamieslain \(755/86\) 8§:ssä tarkoitetusta viran siirtämisestä määrää alivaltiosihteeri\. Osastosihteerin ja sitä alempien virkojen sekä vastaavan tilapäisen ja työsopimussuhteisen henkilöstön sijoittamisesta kuitenkin määrää hallintotoimiston päällikkö\.

<a id="section-22"></a>
### 22 §

<a id="section-22-subsection-1"></a>
#### \(1\)

Yleisen osaston, vero\-osaston ja kansantalousosaston päälliköllä on ylijohtajan arvonimi, tulo\- ja menoarvio\-osaston päälliköllä budjettipäällikön arvonimi ja palkkaosaston päälliköllä valtion työmarkkinajohtajan arvonimi\.

<a id="section-22-subsection-2"></a>
#### \(2\)

Palkkaosaston ja hallinnon kehittämisosaston apulaisosastopäälliköllä on finanssineuvoksen arvonimi\.

<a id="section-24"></a>
### 24 §

<a id="section-24-subsection-1"></a>
#### \(1\)

Alivaltiosihteerin tulee ministerin ja valtiosihteerin apuna:

<a id="section-24-subsection-1-paragraph-1"></a>
- **1.** johtaa, sovittaa yhteen ja valvoa palkkaosastolle ja hallinnon kehittämisosastolle kuuluvien asioiden valmistelua ja toteuttamista sekä tehdä tarpeelliseksi katsomiaan osastojen toimintaa koskevia esityksiä;

<a id="section-24-subsection-1-paragraph-2"></a>
- **2.** seurata palkkaosaston ja hallinnon kehittämisosaston toimialoilla tapahtuvaa kehitystä sekä tehdä tarpeellisia aloitteita lainsäädännöllisiksi ja muiksi uudistuksiksi;

<a id="section-24-subsection-1-paragraph-3"></a>
- **3.** johtaa ja valvoa ministeriön henkilöstöhallintoa ja muuta sisäistä hallintoa sekä hallintotoimistolle kuuluvien asioiden valmistelua ja toteuttamista;

<a id="section-24-subsection-1-paragraph-4"></a>
- **4.** osallistua palkkaosastolle ja hallinnon kehittämisosastolle kuuluvien tärkeimpien asioiden valmisteluun ja toteuttamiseen;

<a id="section-24-subsection-1-paragraph-5"></a>
- **5.** käsitellä ministeriön tulo\- ja menoarvioehdotusta, toiminta\- ja taloussuunnitelmaa sekä työjärjestystä;

<a id="section-24-subsection-1-paragraph-6"></a>
- **6.** esitellä ministeriön sekä palkkaosaston ja hallinnon kehittämisosaston alaisten virastojen ja laitosten nimitysasiat;

<a id="section-24-subsection-1-paragraph-7"></a>
- **7.** toimia valtioneuvoston ohjesäännön 52§:n 2 momentissa tarkoitettuna esittelijänä 6 kohdassa tarkoitetuissa nimitysasioissa sekä palkkaosastolle ja hallinnon kehittämisosastolle kuuluvissa asioissa; sekä

<a id="section-24-subsection-1-paragraph-8"></a>
- **8.** käsitellä ne muut asiat, jotka ministeri tai valtiosihteeri niiden laadun vuoksi on antanut hänen käsiteltäväkseen\.

<a id="section-24-subsection-2"></a>
#### \(2\)

Alivaltiosihteeri voi yksittäistapauksessa ottaa käsiteltäväkseen asian, joka tämän asetuksen nojalla muutoin kuuluisi palkkaosaston, hallinnon kehittämisosaston tai hallintotoimiston käsiteltäväksi\.

<a id="section-29"></a>
### 29 §

<a id="section-29-subsection-1"></a>
#### \(1\)

Ministeriön yleisistä menettelytavoista ja sisäisestä hallinnosta sekä tarvittaessa toimintayksiköiden tehtävistä määrätään tarkemmin ministeriön työjärjestyksessä\. Työjärjestyksen vahvistaa ministeri\.

<a id="section-29-subsection-2"></a>
#### \(2\)

Yhteistoiminnassa ministeriön ja henkilöstön välillä noudatetaan, mitä yhteistoiminnasta valtion virastoissa ja laitoksissa annetussa laissa \(651/88\) säädetään ja sen nojalla tehdyissä sopimuksissa määrätään\.

<a id="section-30"></a>
### 30 §

<a id="section-30-subsection-2"></a>
#### \(2\)

Vahvistetusta työnjaosta huolimatta on kukin virkamies velvollinen tarvittaessa suorittamaan ne tehtävät, jotka ministeri, valtiosihteeri tai asianomainen osaston päällikkö, suunnittelupäällikkö, apulaisosastopäällikkö tai toimiston päällikkö määrää\. Sama koskee myös alivaltiosihteerin palkkaosaston, hallinnon kehittämisosaston ja hallintotoimiston virkamiesten suoritettaviksi määräämiä tehtäviä\.

<a id="section-33"></a>
### 33 §

<a id="section-33-subsection-1"></a>
#### \(1\)

Valtiosihteeri ratkaisee asiat, jotka koskevat:

<a id="section-33-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista valtioneuvoston ohjesäännön 47§:n 1 momentissa tarkoitetussa valtiovarainministeriön raha\-asiain käsittelyssä;

<a id="section-33-subsection-1-paragraph-2"></a>
- **2.** lausunnon antamista muissa asioissa silloin, kun asia kuuluu useamman kuin yhden osaston toimialaan, jollei asia 34§:n perusteella kuulu alivaltiosihteerin ratkaistavaksi; sekä

<a id="section-33-subsection-1-paragraph-3"></a>
- **3.** valtion tulo\- ja menoarviosta annetun asetuksen \(424/88\) 36§:ssä tarkoitettua valtion shekkitilille tai valtion yleiselle postisiirtotilille kertyneiden varojen tallettamista tai muuta sijoittamista sekä ulkomaisesta lainasta saatujen valuuttavarojen sijoittamista\.

- **1.** lausunnon antamista asioissa, jotka kuuluvat useamman kuin yhden osaston, mutta kuitenkin pääosaltaan palkkaosaston ja hallinnon kehittämisosaston toimialaan;

<a id="section-34-subsection-1-paragraph-2"></a>
- **2.** ministeriön sisäistä toimintaa varten käytettävissä olevia määrärahoja ja niiden jakamista osastojen, hallintotoimiston ja suunnittelusihteeristön käyttöön; sekä

<a id="section-34-subsection-1-paragraph-3"></a>
- **3.** ministeriön sisäistä järjestystä\.

\(1203/87\) 3 ja 8§:n sekä 9§:n 1 momentin mukaan valtion neuvotteluviranomaisen ratkaistavia asioita;

<a id="section-41-subsection-1-paragraph-3"></a>

### 42 §

<a id="section-42-subsection-1"></a>
#### \(1\)

Palkkaosaston työntekijäinpalkkatoimiston päällikkö ratkaisee asiat, jotka koskevat:

<a id="section-42-subsection-1-paragraph-1"></a>
- **1.** voimassa olevien työehtosopimusten ja muiden niihin verrattavien määräysten soveltamista; sekä

<a id="section-42-subsection-1-paragraph-2"></a>
- **2.** yksittäisten työsopimusten palkka\- ja työehtojen vahvistamista sekä lausuntojen antamista niistä, lukuun ottamatta johtavassa asemassa olevien toimihenkilöiden palkkausta\.

<a id="section-43"></a>
### 43 §

<a id="section-43-subsection-1"></a>
#### \(1\)

Palkkaosaston valtionapupalkkatoimiston päällikkö ratkaisee valtiovarainministeriön toimialaan kuuluvat valtion avustusta saavien laitosten palveluksessa olevan henkilöstön palkkausta ja palvelussuhteen ehtoja koskevat asiat ja antaa niistä lausuntoja, jos ne kuuluvat muun ministeriön ratkaistaviin asioihin\.

<a id="section-46"></a>
### 46 §

<a id="section-46-subsection-1"></a>
#### \(1\)

Hallintotoimiston päällikkö ratkaisee 35§:n 1 momentissa säädetyn lisäksi ne ministeriön sisäiseen hallintoon kuuluvat asiat, jotka koskevat:

<a id="section-46-subsection-1-paragraph-1"></a>
- **1.** ikälisiä;

<a id="section-46-subsection-1-paragraph-2"></a>
- **2.** todistuksen antamista irtisanoutumisesta ja virkasuhteen päättymisestä;

<a id="section-46-subsection-1-paragraph-3"></a>
- **3.** myöhästyneinä esitettyjen matkalaskujen maksamista;

<a id="section-46-subsection-1-paragraph-4"></a>
- **4.** lupaa oman auton käyttämiseen virkamatkoilla;

<a id="section-46-subsection-1-paragraph-5"></a>
- **5.** kaluston ja muun siihen verrattavan omaisuuden poistamista; sekä

<a id="section-46-subsection-1-paragraph-6"></a>
- **6.** tileistä poistoa\.

<a id="section-47"></a>
### 47 §

<a id="section-47-subsection-1"></a>
#### \(1\)

Osastojen, suunnittelusihteeristön ja hallintotoimiston käytettäväksi asetettujen varojen käyttöä koskevat asiat ratkaisee osaston päällikkö, suunnittelupäällikkö, hallintotoimiston päällikkö tai sisäiseen toimintaan osoitettujen määrärahojen osalta asianomaisen yksikön päällikön siihen tehtävään määräämä virkamies varojen käyttöä koskevan suunnitelman rajoissa\.

<a id="section-48"></a>
### 48 § Virkojen kelpoisuusvaatimukset

<a id="section-48-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena on:

<a id="section-48-subsection-1-paragraph-1"></a>
- **1.** valtiosihteerillä ja alivaltiosihteerillä virkaan soveltuva ylempi korkeakoulututkinto, hyvä perehtyneisyys julkiseen talouteen ja muihin taloudellisiin kysymyksiin sekä valtion hallintoon;

<a id="section-48-subsection-1-paragraph-2"></a>
- **2.** yleisen osaston päälliköllä virkaan soveltuva ylempi korkeakoulututkinto, hyvä perehtyneisyys hallintotehtäviin sekä verotuksen ja talouselämän tuntemusta;

<a id="section-48-subsection-1-paragraph-3"></a>
- **3.** tulo\- ja menoarvio\-osaston päälliköllä ja budjettineuvoksella, apulaisosastopäällikkönä virkaan soveltuva ylempi korkeakoulututkinto ja hyvä perehtyneisyys julkiseen talouteen ja muihin taloudellisiin kysymyksiin sekä hallitusneuvoksella, apulaisosastopäällikkönä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-48-subsection-1-paragraph-4"></a>
- **4.** vero\-osaston päälliköllä oikeustieteen kandidaatin tutkinto, hyvä perehtyneisyys verolainsäädäntöön ja verotukseen sekä talouselämän tuntemusta;

<a id="section-48-subsection-1-paragraph-5"></a>
- **5.** kansantalousosaston päälliköllä ja apulaisosastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perusteelliset tiedot kansantaloustieteestä ja talouselämästä;

<a id="section-48-subsection-1-paragraph-6"></a>
- **6.** palkkaosaston päälliköllä ja apulaisosastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyyttä julkiseen hallintoon ja työmarkkinakysymyksiin;

<a id="section-48-subsection-1-paragraph-7"></a>
- **7.** hallinnon kehittämisosaston päälliköllä ja apulaisosastopäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä hyvä perehtyneisyys hallintoon;

<a id="section-48-subsection-1-paragraph-8"></a>
- **8.** suunnittelupäälliköllä virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyys julkiseen talouteen;

<a id="section-48-subsection-1-paragraph-9"></a>
- **9.** yleisen osaston apulaisosastopäälliköllä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-48-subsection-1-paragraph-10"></a>
- **10.** vero\-osaston apulaisosastopäälliköllä oikeustieteen kandidaatin tutkinto, hyvä perehtyneisyys verolainsäädäntöön ja verotukseen sekä lainvalmistelutyöhön;

<a id="section-48-subsection-1-paragraph-11"></a>
- **11.** toimiston päälliköllä virkaan soveltuva ylempi korkeakoulututkinto, hallitusneuvoksella, toimistopäällikkönä kuitenkin oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-48-subsection-1-paragraph-12"></a>
- **12.** hallitusneuvoksella ja hallitussihteerillä oikeustieteen kandidaatin tutkinto ja hyvä perehtyneisyys hallintotehtäviin;

<a id="section-48-subsection-1-paragraph-13"></a>
- **13.** koulutuspäälliköllä, budjettineuvoksella, finanssineuvoksella, rahoitusneuvoksella, neuvottelevalla virkamiehellä, budjettisihteerillä, finanssisihteerillä, ylitarkastajalla, tiedotuspäälliköllä, informaatikolla ja esittelijällä virkaan soveltuva ylempi korkeakoulututkinto ja lainsäädäntöneuvoksella edellisen lisäksi lainvalmistelutyössä tarvittavaa tutkimus\- ja suunnittelutaitoa;

<a id="section-48-subsection-1-paragraph-14"></a>
- **14.** tiedottajalla, kamreerilla ja kirjaajalla virkaan soveltuva korkeakoulutukinto;

<a id="section-48-subsection-1-paragraph-15"></a>
- **15.** tarkastajalla virkaan soveltuva opistotason tutkinto; sekä

<a id="section-48-subsection-1-paragraph-16"></a>
- **16.** muilla virkamiehillä sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="section-49"></a>
### 49 § Virkojen täyttäminen ja muut virka\- suhdetta koskevat säännökset

<a id="section-49-subsection-1"></a>
#### \(1\)

Valtiosihteerin, alivaltiosihteerin, osaston päällikön, suunnittelupäällikön, apulaisosastopäällikön, toimiston päällikön sekä hallitusneuvoksen ja hallitussihteerin nimittää tasavallan presidentti valtioneuvoston esityksestä\.

<a id="section-50"></a>
### 50 §

<a id="section-50-subsection-1"></a>
#### \(1\)

Koulutuspäällikön, budjettineuvoksen, finanssineuvoksen, lainsäädäntöneuvoksen, rahoitusneuvoksen ja neuvottelevan virkamiehen nimittää valtioneuvosto\.

<a id="section-50-subsection-2"></a>
#### \(2\)

Lainsäädäntöneuvos nimitetään määräajaksi, enintään viideksi vuodeksi kerrallaan\. Lainsäädäntöneuvoksista tulee vähintään kahden kolmanneksen olla oikeustieteen kandidaatin tutkinnon suorittaneita\.

<a id="section-51"></a>
### 51 §

<a id="section-51-subsection-1"></a>
#### \(1\)

Muista kuin 49\-50§:ssä mainituista virkamiehistä nimittää ministeri tarkastajan ja tarkastajaa virka\-asemaltaan ylemmän virkamiehen\.

<a id="section-51-subsection-2"></a>
#### \(2\)

Muut vakinaiset virkamiehet nimittää hallintotoimiston päällikkö\.

<a id="section-52"></a>
### 52 §

<a id="section-52-subsection-1"></a>
#### \(1\)

Tarkastajaa vastaavan ja tarkastajaa asemaltaan ylemmän tilapäisen ja työsopimussuhteisen henkilöstön ottaa alivaltiosihteeri\.

<a id="section-52-subsection-2"></a>
#### \(2\)

Muun tilapäisen ja työsopimussuhteisen henkilöstön ottaa hallintotoimiston päällikkö\.

<a id="section-52-subsection-3"></a>
#### \(3\)

Vahtimestarin virka voidaan täyttää sitä haettavaksi julistamatta\.

<a id="section-53"></a>
### 53 §

<a id="section-53-subsection-1"></a>
#### \(1\)

Apulaisosastopäällikön ja sitä ylemmät virat täytetään haettavaksi julistamatta\.

<a id="section-53-subsection-2"></a>
#### \(2\)

Toimiston päällikön ja sitä alempien virkojen hakuajan pituuden määrää alivaltiosihteeri, osastosihteerin ja sitä alempien virkojen kuitenkin hallintotoimiston päällikkö\.

<a id="section-54"></a>
### 54 §

<a id="section-54-subsection-1"></a>
#### \(1\)

Virkavapautta, johon virkamiehellä on oikeus lain tai asetuksen taikka valtion virkaehtosopimuslain mukaisen virkaehtosopimuksen nojalla sekä tätä virkavapautta vastaavan vapautuksen työsopimussuhteiselle henkilöstölle myöntää hallintotoimiston päällikkö\.

<a id="section-55"></a>
### 55 §

<a id="section-55-subsection-1"></a>
#### \(1\)

Muuta kuin 54§:ssä tarkoitettua virkavapautta tai vastaavaa vapautusta myöntää:

<a id="section-55-subsection-1-paragraph-1"></a>
- **1.** tasavallan presidentin nimittämälle virkamiehelle enintään yhdeksi vuodeksi ministeri ja yli yhdeksi vuodeksi valtioneuvosto;

<a id="section-55-subsection-1-paragraph-2"></a>
- **2.** valtioneuvoston nimittämälle virkamiehelle ministeri;

<a id="section-55-subsection-1-paragraph-3"></a>
- **3.** ministerin nimittämälle virkamiehelle alivaltiosihteeri;

<a id="section-55-subsection-1-paragraph-4"></a>
- **4.** hallintotoimiston päällikön nimittämälle virkamiehelle virkaan nimittäjä; sekä

<a id="section-55-subsection-1-paragraph-5"></a>
- **5.** tilapäiselle ja työsopimussuhteiselle henkilöstölle se, joka on henkilöstön ottanut\.

<a id="section-56"></a>
### 56 §

<a id="section-56-subsection-1"></a>
#### \(1\)

Viran väliaikaisen hoitajan ottamisesta avoinna olevaan virkaan ja viran hoitamisesta virkavapauden aikana päättää se, joka 55§:n mukaan myöntää virkavapauden\.

<a id="section-57"></a>
### 57 §

<a id="section-57-subsection-1"></a>
#### \(1\)

Vuosilomat ja vuosiloma\-ajat vahvistaa osaston päällikkö, suunnittelupäällikkö ja hallintotoimiston päällikkö\. Heidän lomansa ja loma\-aikansa vahvistaa kuitenkin alivaltiosihteeri\.

<a id="section-57-subsection-2"></a>
#### \(2\)

Osaston päällikön, suunnittelupäällikön ja hallintotoimiston päällikön määräämät virkamiehet voivat hyväksyä tai määrätä vähäisiä poikkeuksia hyväksyttyyn vuosilomajärjestykseen ja myös vahvistaa vuosilomajärjestyksessä lomakauden ulkopuolella pidettäväksi merkittyjen lomapäivien ajankohdan\.

<a id="section-58"></a>
### 58 §

<a id="section-58-subsection-1"></a>
#### \(1\)

Sivutoimiluvasta ja luvan peruuttamisesta sekä sivutoimen vastaanottamisen ja pitämisen kieltämisestä päättää alivaltiosihteeri\. Osastosihteerien ja heitä virka\-asemaltaan alempien virkamiesten sekä vastaavan työsopimussuhteisen henkilöstön osalta päättää sivutoimia koskevista asioista kuitenkin hallintotoimiston päällikkö\.

<a id="section-60"></a>
### 60 §

<a id="section-60-subsection-1"></a>
#### \(1\)

Yleisten asiakirjain julkisuudesta annetun lain \(83/51\) 6§:ssä tarkoitetut luvat antaa asianomainen osaston päällikkö, suunnittelupäällikkö tai hallintotoimiston päällikkö silloin, kun asiakirja pääosaltaan kuuluu yhden yksikön toimialaan\. Muissa tapauksissa luvat antaa alivaltiosihteeri\.

<a id="section-60-subsection-2"></a>
#### \(2\)

Ministeriön työryhmämuistioiden osalta antaa 1 momentissa tarkoitetut luvat kuitenkin työryhmän asettaja\.

<a id="section-61"></a>
### 61 §

<a id="section-61-subsection-1"></a>
#### \(1\)

Mikäli toisin ei ole säädetty, ministeriöstä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\.

<a id="section-62"></a>
### 62 § Voimaantulo

<a id="section-62-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 1988 ja sillä kumotaan valtiovarainministeriöstä 14 päivänä helmikuuta 1986 annettu asetus \(144/86\) siihen myöhemmin tehtyine muutoksineen\. Aikaisemman asetuksen nojalla annettu työjärjestys ja virastodemokratiaohjesääntö ovat kuitenkin edelleen noudatettavina, kunnes valtiovarainministeriö toisin määrää\.

<a id="section-62-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä asetuksen täytäntöönpanon edellyttämiin toimenpiteisiin\.

<a id="section-63"></a>
### 63 §

<a id="section-63-subsection-1"></a>
#### \(1\)

Täytettäessä virkaa, jonka hakuaika päättyy ennen 1 päivää tammikuuta 1988, sovelletaan hakuajan päättyessä voimassa olevia kelpoisuusvaatimuksia\.

<a id="section-63-subsection-2"></a>
#### \(2\)

Tämän asetuksen virkavapauden ja vastaavan vapautuksen myöntämistä koskevia säännöksiä sovellettaessa katsotaan virkaan nimittäjäksi tai tehtävään ottajaksi se viranomainen tai virkamies, jolle ratkaisuvalta tämän asetuksen mukaan kuuluu\.
