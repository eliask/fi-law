# Asetus Kuopion yliopiston, Lapin korkeakoulun ja Vaasan korkeakoulun eräiden virkojen perustamisesta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan jäljempänä mainitut peruspalkkaiset virat\.

<a id="section-2"></a>
### 2§ Kuopion yliopisto

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yksi A 16 palkkausluokkaan kuuluva osastosihteerin virka;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yksi A 10 palkkausluokkaan kuuluva toimistovirkailijan virka; ja

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** yksi A 5 palkkausluokkaan kuuluva puhelunvälittäjän virka\.

<a id="section-3"></a>
### 3§ Lapin korkeakoulu

<a id="section-3-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** yksi A 17 palkkausluokkaan kuuluva kamreerin virka\.

<a id="section-4"></a>
### 4§ Vaasan korkeakoulu

<a id="section-4-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** yksi A 27 palkkausluokkaan kuuluva tietotekniikan professorin virka\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 1988\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Tällä asetuksella Kuopion yliopistoon ja Lapin korkeakouluun perustetut virat saadaan täyttää ensimmäisellä kerralla niitä haettavaksi julistamatta\.
