### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Seuraavat virat voidaan sen estämättä, mitä niiden perustamisesta annetuissa asetuksissa tai muissa asetuksissa on säädetty täyttää toistaiseksi tai määräajaksi, enintään viideksi vuodeksi kerrallaan:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriön valtiosihteerin sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** oikeusministeriön kansliapäällikön sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** tietosuoja\-asiamiehen toimiston tietosuoja\-asiamiehen sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** puolustusministeriön pääsihteerin ja yleissihteerin sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** valtiovarainministeriön valtiosihteerin ja alivaltiosihteerin sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** verohallituksen pääjohtajan sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-8"></a>

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Valtionhallinnon kehittämiskeskuksen ylijohtajan sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-10"></a>

- **12.** Oulun yliopiston professorin \(alaltaan vaihtuva\) sopimuspalkkainen virka;

- **13.** Kuopion yliopiston professorin \(alaltaan vaihtuva\) sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** Turun yliopiston professorin \(alaltaan vaihtuva\) sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** Tampereen yliopiston humanistisen tiedekunnan professorin \(teatterityö\) sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** Teknillisen korkeakoulun professorin \(alaltaan vaihtuva\) ja johtajan \(Metsähovin tutkimuslaitos\) sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** Tampereen teknillisen korkeakoulun professorin \(alaltaan vaihtuva\) sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** Lappeenrannan teknillisen korkeakoulun professorin \(alaltaan vaihtuva\) sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** teatterikorkeakoulun rehtorin, apulaisrehtorin, koulutuskeskuksen johtajan ja näyttelijäntyönlaitoksen professorin sekä professorin \(teatterityö, erityisesti ohjaajantyö\) sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** kuvataideakatemian yliopettajan ja lehtorin sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** taideteollisen korkeakoulun rehtorin, koulutuskeskuksen johtajan, professorin ja apulaisprofessorin sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-22"></a>
- **22.** rauhan\- ja konfliktintutkimuslaitoksen johtajan sopimuspalkkainen virka;

<a id="section-1-subsection-1-paragraph-23"></a>
- **23.** Suomen Akatemian tutkimusjohtajan ja tutkijaprofessorin sopimuspalkkaiset virat;

<a id="section-1-subsection-1-paragraph-24"></a>

<a id="section-1-subsection-1-paragraph-26"></a>

<a id="section-1-subsection-1-paragraph-30"></a>
- **30.** työsuojeluhallituksen ylijohtajan sopimuspalkkainen virka; ja

<a id="section-1-subsection-1-paragraph-31"></a>
- **31.** kansanterveyslaitoksen tutkimusprofessorin sopimuspalkkainen virka ja erikoistutkijan peruspalkkainen virka\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Seuraavat virat täytetään määräajaksi, enintään kuitenkin viideksi vuodeksi kerrallaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriön lainsäädäntöneuvoksen sopimuspalkkainen virka;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** oikeusministeriön lainvalmisteluosaston osastopäällikön, apulaisosastopäällikön lainsäädäntöjohtajana, lainsäädäntöneuvoksen toimistopäällikkönä ja lainsäädäntöneuvoksen sopimuspalkkaiset virat sekä lainsäädäntöneuvoksen peruspalkkaiset virat;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** valtiovarainministeriön lainsäädäntöneuvoksen sopimuspalkkainen virka;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** maa\- ja metsätalousministeriön lainsäädäntöneuvoksen sopimuspalkkainen virka;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** sosiaali\- ja terveysministeriön lainsäädäntöneuvoksen sopimuspalkkainen virka; ja

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** ympäristöministeriön lainsäädäntöneuvoksen sopimuspalkkainen virka\.

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Oikeuspoliittisen tutkimuslaitoksen johtajan sopimuspalkkainen virka ja Yhdistyneiden Kansakuntien yhteydessä toimivan Helsingin kriminaalipoliittisen instituutin johtajan sopimuspalkkainen virka täytetään kolmeksi vuodeksi kerrallaan\.

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Sosiaali\- ja terveysministeriön valtakunnansovittelijan sopimuspalkkainen virka täytetään neljäksi vuodeksi kerrallaan\.
