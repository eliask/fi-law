# Sisäasiainministeriön päätös eräiden tilojen ja alueiden siirtämisestä Ikaalisten kaupungista Parkanon kaupunkiin

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ikaalisten kaupungista siirretään Parkanon kaupunkiin seuraavat tilat ja alueet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Höytölän kylästä kokonaan tilat Kiurusenniemi 1:13 ja Niittymaa 3:8;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Heittolan kylän talosta n:o 3 muodostettujen tilojen yhteinen maa\-alue, jota rajoittavat halkomistoimituksen n:o 34392 kartalle merkityt pyykit n:ot 1, 2, 3, 4, 36 ja 37; sekä

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** edellä mainittujen tilojen alueilla olevat yleiset ja yhteiset alueet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Siirto ei aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1988\.
