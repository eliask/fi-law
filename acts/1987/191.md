### 1 § Ministeriön osastot

<a id="section-1-subsection-1"></a>
#### \(1\)

Kauppa\- ja teollisuusministeriössä on:
Kauppa\- ja teollisuusministeriön teollisuuspiireistä ja niiden piiritoimistoista sekä teollisuussihteereistä säädetään erikseen\.

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** yleinen osasto,

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kauppaosasto,

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** teollisuusosasto,

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** energiaosasto, sekä

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** yrityskehitysosasto\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Kauppa\- ja teollisuusministeriön yrityspalvelun piiritoimistoista sekä teollisuussihteereistä säädetään erikseen\.

<a id="section-3"></a>
### 3 § Yleinen osasto

<a id="section-3-subsection-1"></a>
#### \(1\)

Yleinen osasto käsittelee asiat, jotka koskevat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** taloussuunnittelua, laskentatointa sekä suunnittelu\- ja seurantajärjestelmiä,

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** tulo\- ja menoarvioehdotusta sekä erityismenoarviota,

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** ministeriön toimialan yleistä tehokkuus\- ja talousvalvontaa, hallinnon kehittämistä sekä tietojärjestelmien ja automaattisen tietojenkäsittelyn yhteensovittamista koko ministeriötä koskevilta osiltaan,

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** virka\- ja työsuhteita, koulutusta sekä muita henkilöstöhallinnollisia kysymyksiä,

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** lainsäädäntöä, mikäli asia ei kuulu muun osaston käsiteltäviin tai mikäli se koskee useamman kuin yhden osaston toimialaa,

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** viranomaisille annettavia esityksiä ja lausuntoja, mikäli ne koskevat useamman kuin yhden osaston toimialaa,

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** ministeriölle tilivirastona kuuluvia asioita,

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** ministeriön edustusta oikeusasioissa, mikäli asia ei kuulu ministeriön muun osaston käsiteltäviin,

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** työjärjestystä ja yhteistoimintasopimusta,

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** asiakirjojen kirjaamista, lähettämistä ja arkistointia sekä nimikirjanpitoa,

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** elinkeinojen valvontaa,

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** kuluttajakysymyksiä,

<a id="section-3-subsection-1-paragraph-15"></a>
- **15.** taloudellisen kilpailun edistämistä,

<a id="section-3-subsection-1-paragraph-16"></a>
- **16.** elintarvikevalvontaa,

<a id="section-3-subsection-1-paragraph-18"></a>
- **18.** ulkomaalaisen oikeutta toimia suomalaisissa yhtiöissä ja omistaa niissä osakkeita sekä eräiden suomalaisten yhteisöjen oikeutta omistaa ja hallita kiinteätä omaisuutta,

<a id="section-3-subsection-1-paragraph-20"></a>
- **20.** Saimaan Kanavalaivat Oy ja Suomen Vientiluotto Oy \-nimisiä osakeyhtiöitä, sekä

<a id="section-3-subsection-1-paragraph-21"></a>
- **21.** muita ministeriön toimialaan kuuluvia asioita, mikäli tässä asetuksessa ei ole toisin säädetty\.

### 11 § Kauppaosasto

<a id="section-11-subsection-1"></a>
#### \(1\)

Kauppaosasto käsittelee asiat, jotka koskevat:

<a id="section-11-subsection-1-paragraph-1"></a>
- **1.** kauppasopimusten ja taloudellista yhteistyötä koskevien sopimusten valmisteluun ja toteuttamiseen liittyviä toimenpiteitä,

<a id="section-11-subsection-1-paragraph-2"></a>
- **2.** kansainvälistä taloudellista yhteistyötä,

<a id="section-11-subsection-1-paragraph-3"></a>
- **3.** viennin edistämistä,

<a id="section-11-subsection-1-paragraph-4"></a>
- **4.** kotimaankauppaa ja kauppakamarilaitosta,

<a id="section-11-subsection-1-paragraph-5"></a>
- **5.** osastolle kuuluvien rahastojen varoilla tapahtuvia kauppatoimia,

<a id="section-11-subsection-1-paragraph-6"></a>
- **6.** ulkomaankaupan säännöstelyä,

<a id="section-11-subsection-1-paragraph-7"></a>
- **7.** matkailua,

<a id="section-11-subsection-1-paragraph-8"></a>
- **8.** polttoaineiden tuontia,

<a id="section-11-subsection-1-paragraph-8a"></a>
- **8a.** valtion varmuusvarastointia, ei kuitenkaan polttoaineiden varmuusvarastojen rakentamiseen ja rakennusten hoitoon liittyviä kysymyksiä, turvavarastointia, velvoitevarastointia ja muuta materiaalisen huoltovarmuuden kehittämistä, ohjausta ja valvontaa,

<a id="section-11-subsection-1-paragraph-8b"></a>
- **8b.** kansanhuoltoa,

<a id="section-11-subsection-1-paragraph-9"></a>
- **9.** puolustustaloudellista suunnittelukuntaa,

<a id="section-11-subsection-1-paragraph-10"></a>
- **10.** ulko\- ja kotimaankauppaan liittyvää tutkimustoimintaa,

<a id="section-11-subsection-1-paragraph-11"></a>
- **11.** haja\-asutusalueiden vähittäiskaupan rahoitustukea,

<a id="section-11-subsection-1-paragraph-12"></a>
- **12.** valtion hankintakeskusta, sekä

<a id="section-11-subsection-1-paragraph-13"></a>
- **13.** osaston käsiteltäviin asioihin liittyvää lainsäädäntöä\.

### 17 §

<a id="section-17-subsection-1"></a>
#### \(1\)

Teollisuusosasto käsittelee asiat, jotka koskevat:

<a id="section-17-subsection-1-paragraph-1"></a>
- **1.** yleistä teollisuuspolitiikkaa,

<a id="section-17-subsection-1-paragraph-2"></a>
- **2.** teollisuuteen ja geologiaan liittyvää tutkimus\- ja kehittämistyötä,

<a id="section-17-subsection-1-paragraph-3"></a>
- **3.** teollisuuspoliittisesti merkittävää teollisuuden rahoitusta,

<a id="section-17-subsection-1-paragraph-4"></a>
- **4.** alueellista teollisuus\- ja siihen liittyvää elinkeinopolitiikkaa yhteistyössä yrityskehitysosaston kanssa,

<a id="section-17-subsection-1-paragraph-5"></a>
- **5.** Kehitysaluerahasto Oy \-nimistä osakeyhtiötä omistajavalvontaan kuuluvien kysymysten osalta,

<a id="section-17-subsection-1-paragraph-6"></a>
- **6.** teollisuuden ja muun yritystoiminnan koulutuksen kehittämistä, siltä osin kuin nämä asiat eivät kuulu yrityskehitysosaston tehtäviin,

<a id="section-17-subsection-1-paragraph-7"></a>
- **7.** luonnonvarojen teollisen hyväksikäytön suunnittelua,

<a id="section-17-subsection-1-paragraph-8"></a>
- **8.** teknillisen tarkastustoiminnan valvontaa, lukuun ottamatta sähkö\- ja ydinenergia\-alaan kuuluvaa teknillistä tarkastusta,

<a id="section-17-subsection-1-paragraph-9"></a>
- **9.** teknologiapolitiikkaa sekä kansainvälistä teknillistä ja teknillistaloudellista yhteistyötä,

<a id="section-17-subsection-1-paragraph-10"></a>
- **10.** tuotannollista toimintaa harjoittavia valtionenemmistöisiä osakeyhtiöitä,

<a id="section-17-subsection-1-paragraph-11"></a>
- **11.** patentti\- ja rekisterihallitusta,

<a id="section-17-subsection-1-paragraph-12"></a>
- **12.** Valtiontakuukeskusta,

<a id="section-17-subsection-1-paragraph-13"></a>
- **13.** avaruusteknologiaa, sekä

<a id="section-17-subsection-1-paragraph-14"></a>
- **14.** ulkomaalaisten omistamia ja hallitsemia yrityksiä yhteistyössä yleisen osaston kanssa\.

<a id="section-18-subsection-2"></a>
#### \(2\)

Teollisuusosastossa on:

<a id="section-18-subsection-2-paragraph-1"></a>
- **1.** yritystalouden toimisto,

<a id="section-18-subsection-2-paragraph-2"></a>
- **2.** teollisuustoimisto,

<a id="section-18-subsection-2-paragraph-3"></a>
- **3.** valtionyhtiöiden toimisto,

<a id="section-18-subsection-2-paragraph-4"></a>
- **4.** teknologian toimisto,

<a id="section-18-subsection-2-paragraph-5"></a>
- **5.** teknillisen tarkastuksen toimisto, sekä

<a id="section-18-subsection-2-paragraph-6"></a>
- **6.** kansainvälisten asiain toimisto\.

<a id="section-18-subsection-3"></a>
#### \(3\)

Ryhmien ja toimistojen tehtävistä määrätään osaston työnjaossa\.

### 36 § Ministeriön virkamiehet

<a id="section-36-subsection-1"></a>
#### \(1\)

Ministeriössä on kansliapäällikkö, kauppaosaston, teollisuusosaston, energiaosaston ja yrityskehitysosaston osastopäälliköt sekä yleisen osaston osastopäällikkönä toimiva hallitusneuvos, neuvottelevia virkamiehiä, hallitusneuvoksia, apulaisosastopäälliköitä, hallitusneuvoksia toimistopäällikköinä, vanhempi hallitussihteeri toimistopäällikkönä, vanhempia ja nuorempia hallitussihteereitä, toimistopäälliköitä, kaupallinen neuvos toimistopäällikkönä, ylitarkastajia ja tarkastajia, yritystutkijoita, erikoistutkijoita, tutkijoita, suunnittelijoita, koulutuspäällikkö, esittelijöitä, pääsihteereitä, kaupallisia sihteereitä, ylikielenkääntäjä, kielenkääntäjiä, yliaktuaari, kamreeri ja apulaiskamreeri, tiedotussihteereitä, taloustarkastajia, osastosihteereitä ja ministerin sihteereitä, reviisori, kirjaajia, apulaistarkastajia, pääkirjanpitäjä ja kirjanpitäjä sekä muita vakinaisia virkamiehiä\.

<a id="section-36-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä voi olla tulo\- ja menoarvion rajoissa tilapäisiä virkamiehiä sekä työsopimussuhteessa olevaa henkilökuntaa\.

<a id="section-36-subsection-3"></a>
#### \(3\)

Kauppaosaston, teollisuusosaston, energiaosaston ja yrityskehitysosaston osastopäälliköllä on ylijohtajan arvonimi\. Kauppaosaston apulaisosastopäälliköllä ja toimistopäälliköillä on kaupallisen neuvoksen arvonimi\. Teollisuusosaston apulaisosastopäälliköillä ja toimistopäälliköillä sekä energiaosaston ja yrityskehitysosaston toimistopäälliköillä on teollisuusneuvoksen arvonimi\.

### 38§

<a id="section-38-subsection-1"></a>
#### \(1\)

Kansliapäällikön, osastopäällikön, apulaisosastopäällikön, hallitusneuvoksen, toimistopäällikön ja hallitussihteerin nimittämisestä on säädetty valtioneuvoston ohjesäännössä\.

<a id="section-38-subsection-2"></a>
#### \(2\)

Hallitusneuvoksen osastopäällikkönä ja neuvottelevan virkamiehen nimittää tasavallan presidentti valtioneuvoston esityksestä virkaa haettavaksi julistamatta\.

<a id="section-38-subsection-3"></a>
#### \(3\)

Hallitusneuvoksen toimistopäällikkönä, kaupallisen neuvoksen toimistopäällikkönä ja vanhemman hallitussihteerin toimistopäällikkönä nimittää tasavallan presidentti valtioneuvoston esityksestä\.

<a id="section-38-subsection-4"></a>
#### \(4\)

Osastosihteerin, häntä vastaavan ja häntä virka\-asemaltaan alemman virkamiehen nimittää sekä vastaavat tilapäiset virkamiehet ja vastaavan työsopimussuhteisen henkilöstön ottaa yleisen osaston osastopäällikkö\.

<a id="section-38-subsection-5"></a>
#### \(5\)

Muun henkilökunnan nimittää tai ottaa ministeri\.

<a id="section-38-subsection-6"></a>
#### \(6\)

Ministeriö määrää yleisen osaston hallitusneuvoksista toimistopäällikköinä, vanhemmista hallitussihteereistä toimistopäällikköinä ja toimistopäälliköistä yhden hallinnollisen toimiston, yhden elinkeinotoimiston, yhden elintarvikeasiain toimiston, yhden taloussuunnittelutoimiston sekä yhden taloustoimiston toimistopäälliköksi ja kauppaosaston kaupallisista neuvoksista toimistopäällikköinä ja toimistopäälliköistä yhden suunnittelutoimiston, yhden multilateraalikaupan toimiston, yhden yleisen toimiston ja yhden vienninedistämistoimiston toimistopäälliköksi sekä teollisuusosaston toimistopäälliköistä yhden yritystalouden toimiston, yhden teollisuustoimiston, yhden valtionyhtiöiden toimiston, yhden teknologian toimiston, yhden teknillisen tarkastuksen toimiston ja yhden kansainvälisten asiain toimiston toimistopäälliköksi sekä energiaosaston toimistopäälliköistä yhden sähkötoimiston, yhden ydinenergiatoimiston, yhden polttoainetoimiston, yhden suunnittelutoimiston ja yhden energiatutkimustoimiston toimistopäälliköksi sekä yrityskehitysosaston toimistopäälliköistä toisen kehittämistoimiston ja toisen yritysrahoitustoimiston toimistopäälliköksi\.

### 39§

<a id="section-39-subsection-1"></a>
#### \(1\)

<a id="section-39-subsection-2"></a>
#### \(2\)

Muun kuin 1 momentissa tarkoitetun virkavapauden tai vapautuksen myöntää:

<a id="section-39-subsection-2-paragraph-1"></a>

<a id="section-39-subsection-2-paragraph-2"></a>
- **2.** ministerin nimittämälle virkamiehelle enintään yhdeksi vuodeksi yleisen osaston osastopäällikkö ja yli yhdeksi vuodeksi ministeri,

<a id="section-39-subsection-2-paragraph-3"></a>
- **3.** yleisen osaston osastopäällikön nimittämälle virkamiehelle yleisen osaston osastopäällikkö, sekä

<a id="section-39-subsection-2-paragraph-4"></a>
- **4.** tilapäisille virkamiehille ja työsopimussuhteiselle henkilöstölle se, joka on heidät ottanut\.

<a id="section-40"></a>
### 40 § Virkamiesten tehtävät

<a id="section-40-subsection-1"></a>
#### \(1\)

Kansliapäällikön tehtävistä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\. Kansliapäällikkö käsittelee myös asiat, jotka ministeri niiden tärkeyden tai erityisen laadun takia on antanut hänen valmisteltavikseen ja esiteltävikseen\. Kansliapäällikkö voi pidättää käsiteltäväkseen asian, joka tämän asetuksen tai ministeriön työjärjestyksen mukaan kuuluisi ministeriön muulle virkamiehelle\.

- **1.** johtaa osastonsa toimintaa ja valvoa, että osastolle kuuluvat asiat käsitellään huolellisesti ja tehokkaasti,

<a id="section-41-subsection-1-paragraph-2"></a>
- **2.** seurata osaston toimialalla tapahtuvaa kehitystä ja tehdä aloitteita lainsäädännöllisiksi ja muiksi uudistuksiksi, sekä

<a id="section-41-subsection-1-paragraph-3"></a>
- **3.** käsitellä ne osastolle kuuluvat asiat, jotka ministeriön työjärjestyksessä on hänelle määrätty, ja ne asiat, jotka hän pidättää käsiteltäväkseen\.

<a id="section-42"></a>
### 42 §

<a id="section-42-subsection-1"></a>
#### \(1\)

Neuvottelevan virkamiehen ja apulaisosastopäällikön tulee:

<a id="section-42-subsection-1-paragraph-1"></a>
- **1.** osastopäällikön apuna johtaa osaston toimintaa ja valvoa, että ne asiat, joiden valvonnan osastopäällikkö on hänelle määrännyt, käsitellään huolellisesti ja tehokkaasti, sekä

<a id="section-42-subsection-1-paragraph-2"></a>
- **2.** käsitellä ne osastolle kuuluvat asiat, jotka osaston työnjaossa on hänelle määrätty tai jotka osastopäällikkö on hänen käsiteltäväkseen määrännyt\.

<a id="section-43"></a>
### 43 §

<a id="section-43-subsection-1"></a>
#### \(1\)

Teollisuusosaston neuvottelevista virkamiehistä yksi toimii osastopäällikön apuna yritystalouden alaan liittyvissä tehtävissä, toinen teknologiapolitiikkaan ja koulutukseen liittyvissä tehtävissä sekä kolmas kansainvälisiin asioihin ja teollisoikeudellisiin kysymyksiin liittyvissä tehtävissä\. Lisäksi neuvottelevat virkamiehet suorittavat tarvittaessa ministerin, kansliapäällikön tai osastopäällikön erikseen määräämät tehtäväalueeseensa liittyvät tehtävät sekä avustavat tarpeen mukaan ministeriön muita osastoja tehtäväalueeseensa kuuluvien asioiden valmistelussa\.

<a id="section-43-subsection-2"></a>
#### \(2\)

Teollisuusosaston apulaisosastopäälliköistä yksi toimii osastopäällikön apuna teollisuuspolitiikkaan liittyvissä tehtävissä, toinen innovaatiopolitiikkaan liittyvissä tehtävissä ja kolmas valtionyhtiöihin liittyvissä tehtävissä\.

<a id="section-43-subsection-3"></a>
#### \(3\)

Neuvottelevien virkamiesten ja apulaisosastopäälliköiden tehtävistä määrätään tarkemmin osaston työnjaossa\.

<a id="section-44"></a>
### 44 §

<a id="section-44-subsection-1"></a>
#### \(1\)

Mitä 41§:ssä on säädetty, koskee soveltuvin kohdin myös neuvottelevia virkamiehiä sekä apulaisosastopäälliköitä ja toimistopäälliköitä\.

<a id="section-45"></a>
### 45 §

<a id="section-45-subsection-1"></a>
#### \(1\)

Tehtävien jaosta ministeriön osastojen kesken määrätään tarkemmin ministeriön työjärjestyksessä, jonka ministeriö vahvistaa\.

<a id="section-45-subsection-2"></a>
#### \(2\)

Virkamiesten tehtävistä ja työnjaosta osastoissa määrätään tarkemmin osastopäällikön vahvistamassa osaston työnjaossa\.

<a id="section-45-subsection-3"></a>
#### \(3\)

Yhteistoiminnassa ministeriön ja henkilöstön välillä noudatetaan, mitä yhteistoiminnasta valtion virastoissa ja laitoksissa annetussa laissa \(651/88\) on säädetty ja sen nojalla tehdyissä sopimuksissa määrätty\.

<a id="section-46"></a>
### 46 §

<a id="section-46-subsection-1"></a>
#### \(1\)

Milloin syntyy epätietoisuutta siitä, kenen käsiteltäväksi jokin asia kuuluu, määrää siitä asianomainen osastopäällikkö, neuvotteleva virkamies, apulaisosastopäällikkö tai toimistopäällikkö sekä osastojen kesken kansliapäällikkö, jos siitä ei määrää ministeri\.

<a id="section-46-subsection-2"></a>
#### \(2\)

Vahvistetusta työnjaosta huolimatta kukin virkamies on velvollinen suorittamaan ne tehtävät, jotka ministeri, kansliapäällikkö tai asianomainen osastopäällikkö, neuvotteleva virkamies, apulaisosastopäällikkö tai toimistopäällikkö määrää\.

<a id="section-47"></a>
### 47 §

<a id="section-47-subsection-1"></a>
#### \(1\)

Kansliapäällikön ollessa estynyt toimii hänen sijaisenaan ministerin määräämä osastopäällikkö\.

<a id="section-47-subsection-2"></a>
#### \(2\)

Osastopäälliköiden, neuvottelevien virkamiesten ja apulaisosastopäälliköiden sijaiset määrätään työjärjestyksessä\.

<a id="section-47-subsection-3"></a>
#### \(3\)

Muissa kuin 1 ja 2 momentissa tarkoitetuissa tapauksissa määrää tehtävien hoidosta virkamiehen estyneenä ollessa asianomainen osastopäällikkö\.

<a id="section-48"></a>
### 48 § Asioiden ratkaiseminen

<a id="section-48-subsection-1"></a>
#### \(1\)

Kansliapäällikön oikeudesta ratkaista ministeriössä päätettäviä asioita on voimassa, ellei jäljempänä ole toisin säädetty, mitä valtioneuvoston ohjesäännössä on säädetty\.

<a id="section-48-subsection-2"></a>
#### \(2\)

Osasto\-, apulaisosasto\- ja toimistopäälliköt sekä muut virkamiehet ratkaisevat jäljempänä 49\-68§:ssä mainitut, toimialaansa kuuluvat ministeriössä päätettävät asiat, mikäli valtioneuvoston ohjesäännön 32§:stä ei muuta johdu tai ministeri, kansliapäällikkö tai osastopäällikkö ole pidättänyt asiaa ratkaistavakseen\.

<a id="section-49"></a>
### 49 §

<a id="section-49-subsection-1"></a>
#### \(1\)

Osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-49-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista muulle viranomaiselle, ei kuitenkaan lain tai asetuksen säätämistä, muuttamista tai kumoamista koskevista ehdotuksista eikä tasavallan presidentin kanslialle, korkeimmalle oikeudelle, korkeimmalle hallinto\-oikeudelle, valtioneuvoston oikeuskanslerille tai eduskunnan oikeusasiamiehelle, paitsi milloin kysymys on osastopäällikön ratkaisemaa asiaa koskevasta lausunnosta,

<a id="section-49-subsection-1-paragraph-2"></a>
- **2.** osaston käytettäviksi asetettujen varojen käyttämistä, jollei näiden asioiden ratkaisemista ole osaston työnjaossa annettu muulle osaston virkamiehelle, sekä

<a id="section-49-subsection-1-paragraph-3"></a>
- **3.** pääosaltaan osaston toimialaan kuuluvien komiteoiden varojen käyttöä siltä osin kuin ne kuuluvat ministeriön ratkaistaviin sekä komiteanmietintöjen painos\- tai monistemäärää ja mietintöjen jakelua\.

<a id="section-49-subsection-2"></a>
#### \(2\)

Milloin 1 momentin 2 kohdassa tarkoitettuja varoja on asetettu toimiston käytettäväksi, ratkaisee toimistopäällikkö niiden käytön\.

<a id="section-49-subsection-3"></a>
#### \(3\)

Osastopäälliköllä on yksittäistapauksissa oikeus pidättää itselleen päätösvalta asioissa ja hänen alaisensa virkamiehen ollessa vuosilomalla tai estyneenä virkaansa hoitamasta ratkaista ne asiat, jotka tämän asetuksen tai erikseen annettavan määräyksen mukaan hänen alaisensa virkamies on oikeutettu ratkaisemaan\.

### 50§

<a id="section-50-subsection-1"></a>
#### \(1\)

<a id="section-50-subsection-1-paragraph-1"></a>
- **1.** osastosihteerin, sitä vastaavien ja sitä alempien virkojen sekä vastaavien tilapäisten virkamiesten ja vastaavan työsopimussuhteisen henkilöstön sijoittamista ministeriön osastoihin,

<a id="section-50-subsection-1-paragraph-2"></a>
- **2.** 38§:n 4 momentissa tarkoitetun työsopimussuhteisen henkilöstön palkkauksen vahvistamista,

<a id="section-50-subsection-1-paragraph-3"></a>
- **3.** sivutoimiluvan myöntämistä osastosihteereille, heitä vastaaville ja heitä virka\-asemaltaan alemmille virkamiehille sekä vastaaville tilapäisille virkamiehille ja vastaavalle työsopimussuhteiselle henkilöstölle,

<a id="section-50-subsection-1-paragraph-4"></a>
- **4.** ministeriön yhteisistä määrärahoista maksettavia jakamattomia kulutus\- ja kalustomenoja sekä kansainvälisestä yhteistyöstä aiheutuvia muita menoja,

<a id="section-50-subsection-1-paragraph-9"></a>
- **9.** muulle kuin Suomessa asuvalle Suomen kansalaiselle annettavat luvat olla prokuristina, osakeyhtiön perustajana, hallituksen jäsenenä, toimitusjohtajana ja toiminimen kirjoittajana\.

<a id="section-68"></a>
### 68 §

<a id="section-68-subsection-1"></a>
#### \(1\)

Yrityskehitysosaston yritysrahoitustoimistoon määrätty toimistopäällikkö ratkaisee kuljetusten alueellisesta tukemisesta annetun lain \(954/81\) mukaisen kuljetustuen myöntämistä koskevat asiat sekä hyväksyy niistä johtuvat menot\.

<a id="section-69"></a>
### 69 §

<a id="section-69-subsection-1"></a>
#### \(1\)

Osastopäälliköt, apulaisosastopäälliköt, toimistopäälliköt ja muut virkamiehet ratkaisevat edellä 50\-68§:ssä mainitut asiat esittelystä, kuitenkin niin, että 58§:ssä mainitut asiat ratkaistaan ilman esittelyä\.

<a id="section-69-subsection-2"></a>
#### \(2\)

Toimistopäälliköt ovat oikeutetut antamaan lausuntoja ja tiedotuksia käsiteltävinään olevista juoksevista asioista, ei kuitenkaan 49§:n 1 momentin 1 kohdassa mainituille viranomaisille eikä muille ministeriöille, paitsi milloin kysymys on toimistopäällikön ratkaisemaa asiaa koskevasta lausunnosta tai selityksestä\.

<a id="section-70"></a>
### 70 § Erinäisiä säännöksiä

<a id="section-70-subsection-1"></a>
#### \(1\)

Mikäli toisin ei ole säädetty, ministeriöstä on voimassa, mitä valtioneuvoston ohjesäännössä on säädetty\.
