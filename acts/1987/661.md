# Laki  tullitariffeja ja kauppaa koskevaan yleissopimukseen \(GATT\) lii tettyyn Suomen tullimyönnytys luetteloon tehtyjen muutosten hyväksymisestä

- Statute: [`661/1987`](<https://www.finlex.fi/fi/laki/ajantasa/1987/661>)

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Tullitariffeja ja kauppaa koskevan yleissopimuksen \(GATT\) asianomaisten määräysten perusteella Suomen ja eräiden muiden yleissopimuksen sopimuspuolten välillä vuosina 1986\-\-1987 käydyissä neuvotteluissa tehdyt muutokset yleissopimukseen liittyvään Suomen tullimyönnytysluetteloon ovat, mikäli ne kuuluvat lainsäädännön alaan, voimassa niin kuin niistä on sovittu\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Tarkemmat säännökset tämän lain täytäntöönpanosta annetaan asetuksella\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä laki tulee voimaan asetuksella säädettävänä ajankohtana\.
