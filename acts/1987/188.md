<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Yleisessä osastossa on;

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** hallinnollinen toimisto;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** taloustoimisto;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** rakennusasiaintoimisto;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** viestintäkulttuuri\- ja tekijänoikeusasiain toimisto; sekä

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** tilitoimisto\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Hallinnollinen toimisto käsittelee osaston asioista muut, paitsi jäljempänä 5 a, 5 b, 5 c ja 6§:ssä mainitut asiat\.

<a id="section-5c"></a>
### 5 c §

<a id="section-5c-subsection-1"></a>
#### \(1\)

Viestintäkulttuuri\- ja tekijänoikeusasiain toimisto käsittelee asiat, jotka koskevat:

<a id="section-5c-subsection-1-paragraph-1"></a>
- **1.** viestintäkulttuuria;

<a id="section-5c-subsection-1-paragraph-2"></a>
- **2.** opetusministeriölle tekijänoikeuslainsäädännön mukaan kuuluvia tehtäviä ja muita tekijänoikeuden alaan kuuluvia kysymyksiä; sekä

<a id="section-5c-subsection-1-paragraph-3"></a>
- **3.** kansainvälisiä tekijänoikeussopimuksia ja \-järjestöjä, yhteistyössä ministeriön kansainvälisten asiain osaston kanssa\.

<a id="section-23"></a>
### 23 §

<a id="section-23-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-23-subsection-1-paragraph-1"></a>
- **1.** sopimuspalkkainen kansliapäällikkö;

<a id="section-23-subsection-1-paragraph-2"></a>
- **2.** yleisen osaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-3"></a>
- **3.** kouluosaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-4"></a>
- **4.** korkeakoulu\- ja tiedeosaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-5"></a>
- **5.** taideosaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-6"></a>
- **6.** urheilu\- ja nuoriso\-osaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-7"></a>
- **7.** kansainvälisten asiain osaston sopimuspalkkainen osastopäällikkö;

<a id="section-23-subsection-1-paragraph-8"></a>
- **8.** hallitusneuvoksia;

<a id="section-23-subsection-1-paragraph-9"></a>
- **9.** sopimuspalkkainen neuvotteleva virkamies;

<a id="section-23-subsection-1-paragraph-10"></a>
- **10.** apulaisosastopäälliköitä, joista kolme toimii kouluosaston ja kaksi kansainvälisten asiain osaston apulaisosastopäällikkönä;

<a id="section-23-subsection-1-paragraph-11"></a>
- **11.** korkeakouluneuvoksia toimistopäällikköinä, joista yksi toimii korkeakoulujen hallintotoimiston, yksi opintoasiaintoimiston ja yksi tiedetoimiston päällikkönä;

<a id="section-23-subsection-1-paragraph-12"></a>
- **12.** korkeakouluneuvoksia, joista yksi toimii suunnitteluryhmän päällikkönä;

<a id="section-23-subsection-1-paragraph-13"></a>
- **13.** toimistopäälliköitä, joista yksi toimii taloustoimiston, yksi rakennusasiaintoimiston, yksi tilitoimiston, yksi urheilutoimiston ja yksi nuorisotoimiston toimistopäällikkönä;

<a id="section-23-subsection-1-paragraph-14"></a>
- **14.** sopimuspalkkainen suunnittelupäällikkö, joka toimii suunnittelusihteeristön päällikkönä;

<a id="section-23-subsection-1-paragraph-15"></a>
- **15.** vanhempia ja nuorempia hallitussihteereitä;

<a id="section-23-subsection-1-paragraph-16"></a>
- **16.** opetusneuvoksia;

<a id="section-23-subsection-1-paragraph-17"></a>
- **17.** kulttuuriasiainneuvoksia;

<a id="section-23-subsection-1-paragraph-18"></a>
- **18.** kirjastoasiainneuvos;

<a id="section-23-subsection-1-paragraph-19"></a>
- **19.** kamreeri ja reviisori;

<a id="section-23-subsection-1-paragraph-20"></a>
- **20.** sopimuspalkkainen toimistoinsinööri;

<a id="section-23-subsection-1-paragraph-21"></a>
- **21.** osastosihteereitä;

<a id="section-23-subsection-1-paragraph-22"></a>
- **22.** kirjaaja, notaari, pääkirjanpitäjä ja kirjanpitäjä; sekä

<a id="section-23-subsection-1-paragraph-23"></a>
- **23.** konekirjoittajia, ylivirastomestari ja virastomestareita\.

<a id="section-23-subsection-2"></a>
#### \(2\)

Ministeriön yleisen osaston osastopäälliköllä on hallitusneuvoksen arvonimi ja kouluosaston sekä korkeakoulu\- ja tiedeosaston osastopäälliköillä ylijohtajan arvonimi\.

<a id="section-24"></a>
### 24 §

<a id="section-24-subsection-1"></a>
#### \(1\)

Kelpoisuusuehtona vaaditaan:

<a id="section-24-subsection-1-paragraph-3"></a>
- **3.** hallitusneuvoksen ja hallitussihteerin virkaan sekä notaarin toimeen, mitä valtioneuvoston ohjesäännössä on säädetty;

<a id="section-24-subsection-1-paragraph-5"></a>
- **5.** yleisen osaston:

<a id="section-24-subsection-2"></a>
#### \(2\)

osastopäällikön virkaan oikeustieteen kandidaatin tutkinto, hyvä perehtyneisyys osaston toimialaan kuuluviin asioihin sekä hallinnollista kokemusta;

<a id="section-24-subsection-3"></a>
#### \(3\)

taloustoimiston toimistopäällikön virkaan siihen soveltuva korkeakoulututkinto ja toimiston toimialaan kuuluvien asioiden hyvä tuntemus;

<a id="section-24-subsection-4"></a>
#### \(4\)

rakennusasiaintoimiston toimistopäällikön virkaan siihen soveltuva diplomi\-insinöörin tai arkkitehdin tutkinto ja toimiston toimialaan kuuluvien asioiden hyvä tuntemus;

<a id="section-24-subsection-5"></a>
#### \(5\)

tilitoimiston toimistopäällikön virkaan siihen soveltuva korkeakoulututkinto sekä hyvää perehtyneisyyttä kirjanpitoon ja valtion tililaitokseen;

<a id="section-25"></a>
### 25 §

<a id="section-25-subsection-1"></a>
#### \(1\)

Yleisen osaston hallitusneuvos on hallinnollisen toimiston toimistopäällikkö ja saman osaston neuvotteleva virkamies viestintäkulttuuri\- ja tekijänoikeusasiain toimiston toimistopäällikkö\.
