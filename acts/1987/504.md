<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

e\) reaalikoe, jossa on osoitettava riittäviä tietoja ja taitoja enintään kymmenessä tehtävässä ja jossa tehtävät annetaan koulukurssin pääkohdista seuraavissa aineryhmissä:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** uskonto tai elämänkatsomustieto,

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** psykologia ja filosofia,

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** historia ja yhteiskuntaoppi,

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** fysiikka,

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** kemia,

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** biologia, sekä

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** maantieto\.
