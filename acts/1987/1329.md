# Valtioneuvoston päätös vuoden 1987 satovahinkojen johdosta suoritettavista yleiskorvauksista annetun valtioneuvoston päätöksen 1§:n muuttamisesta

- Statute: [`1329/1987`](<https://www.finlex.fi/fi/laki/ajantasa/1987/1329>)
- Version: `1987-12-31`
- LawVM tree hash: `4e8500c525f1d50feb1dee67ba5dadbf7d52367739a5ba34c9c90f8d10e4c7d1`

## Contents

- [1§](#section-1)

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Vuoden 1987 satovahinkojen johdosta voidaan suorittaa satovahinkojen korvaamisesta annetun asetuksen \(820/75\) 2§:ssä tarkoitettuja yleiskorvauksia yhteensä enintään 221 miljoonaa markkaa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Yleiskorvauksia voidaan suorittaa

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** enintään 11 miljoonaa markkaa koko maassa maksettavana rukiin, vehnän, ohran ja kauran lisähintana siten kuin jäljempänä tässä päätöksessä määrätään;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** enintään 134 miljoonaa markkaa nautaeläinten, lampaiden ja vuohien lukumäärän perusteella maksettavina korvauksina;

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** koko maassa enintään 20 penniä kilolta rehuksi myytävän tai alkoholin valmistuksessa käytettävän vehnän hinnan alentamiseen; sekä

<a id="section-1-subsection-2-paragraph-4"></a>
- **4.** koko maassa maksettavana rukiin ja vehnän lisähintana\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Edellä 2 momentin 2\-4 kohdissa tarkoitettujen yleiskorvausten perusteista päättää valtioneuvosto erikseen\.
