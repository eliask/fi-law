# Asetus lääninhallitusten eräiden virkojen perustamisesta ja lakkauttamisesta

- Statute: [`60/1987`](<https://www.finlex.fi/fi/laki/ajantasa/1987/60>)
- Version: `1987-02-01`
- LawVM tree hash: `8852264028c24f89970569ed47228bcf32504abc5321da2d9f7be62ebb32dc1d`

## Contents

- [1 §](#section-1)

- [2 §](#section-2)

- [3 §](#section-3)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan ja lakkautetaan jäljempänä mainitut sopimuspalkkaiset ja peruspalkkaiset virat\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan lääninhallituksen sosiaali\- ja terveysosasto

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Uudenmaan lääninhallituksen oikeushallinto\-osasto

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Uudenmaan lääninhallitus

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Turun ja Porin lääninhallituksen sosiaali\- ja terveysosasto

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Turun ja Porin lääninhallitus

<a id="section-2-subsection-2"></a>
#### \(2\)

Perustetaan 1 päivästä maaliskuuta 1987:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Uudenmaan lääninhallitus

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Pohjois\-Karjalan lääninhallitus

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** Keski\-Suomen lääninhallituksen oikeushallintotoimisto

<a id="section-2-subsection-3"></a>
#### \(3\)

Lakkautetaan 1 päivästä maaliskuuta 1987:

<a id="section-2-subsection-3-paragraph-1"></a>
- **1.** Uudenmaan lääninhallitus

<a id="section-2-subsection-3-paragraph-2"></a>
- **2.** Mikkelin lääninhallitus

<a id="section-2-subsection-3-paragraph-3"></a>
- **3.** Pohjois\-Karjalan lääninhallitus

<a id="section-2-subsection-3-paragraph-4"></a>
- **4.** Keski\-Suomen lääninhallitus

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä helmikuuta 1987\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Toimenpiteisiin tällä asetuksella perustetun viran täyttämiseksi voidaan ryhtyä jo ennen sitä ajankohtaa, josta virka on perustettu\.
