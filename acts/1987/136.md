### 1 a §

<a id="section-1a-subsection-1"></a>
#### \(1\)

Ministeriön osastot jakaantuvat toimistoihin ja lainvalmisteluyksikköön sen mukaan kuin tässä asetuksessa säädetään\. Toimistot voivat jakaantua jaostoihin ja muihin toimintayksiköihin siten kuin ministeriön työjärjestyksessä määrätään\.

- **12.** Valtionhallinnon kehittämiskeskus; sekä

### 13 § Järjestelyosasto

<a id="section-14"></a>
### 14 §

<a id="section-14-subsection-1"></a>
#### \(1\)

Järjestelyosasto käsittelee asiat, jotka koskevat:

<a id="section-14-subsection-1-paragraph-1"></a>
- **1.** valtion hallinnon yleistä organisointia, rationalisointia ja standardointia sekä niihin liittyvää tutkimusta;

<a id="section-14-subsection-1-paragraph-2"></a>
- **2.** virastojen ja laitosten toiminnan organisointia ja rationalisointia, niiden johtamisen ja sisäisen hallinnon kehittämistä sekä muuta toiminnan tuottavuuden edistämistä;

<a id="section-14-subsection-1-paragraph-3"></a>
- **3.** hallinnon palvelukyvyn edistämistä;

<a id="section-14-subsection-1-paragraph-4"></a>
- **4.** valtionapua saavien laitosten tehokkuuden ja tuottavuuden yleistä edistämistä;

<a id="section-14-subsection-1-paragraph-5"></a>
- **5.** valtion palveluksessa olevan henkilökunnan mitoitusta, valintaa ja käyttöä;

<a id="section-14-subsection-1-paragraph-6"></a>
- **6.** valtion palveluksessa oleville annettavaa koulutusta;

<a id="section-14-subsection-1-paragraph-7"></a>
- **7.** aloitetoimintaa;

<a id="section-14-subsection-1-paragraph-8"></a>
- **8.** valtion materiaalihallinnon kehittämistä;

<a id="section-14-subsection-1-paragraph-9"></a>
- **9.** tilastointia;

<a id="section-14-subsection-1-paragraph-10"></a>
- **10.** automaattista tietojenkäsittelyä;

<a id="section-14-subsection-1-paragraph-11"></a>
- **11.** valtion moottorikulkuneuvojen hankintaa ja käyttöä;

<a id="section-14-subsection-1-paragraph-12"></a>
- **12.** valtion komiteoita 12 §:n 12 kohdassa mainittuja asioita lukuun ottamatta;

<a id="section-14-subsection-1-paragraph-13"></a>
- **13.** virkapuhelimia;

<a id="section-14-subsection-1-paragraph-14"></a>
- **14.** hajasijoituksen yleistä järjestämistä; sekä

<a id="section-14-subsection-1-paragraph-15"></a>
- **15.** tilastokeskusta, Valtionhallinnon kehittämiskeskusta, valtion painatuskeskusta ja valtion tietokonekeskusta\.

<a id="section-18"></a>
### 18 § Ministeriön virkamiehet ja heidän tehtävänsä

<a id="section-18-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-18-subsection-1-paragraph-1"></a>
- **1.** sopimuspalkkainen valtiosihteeri, joka on ministeriön kansliapäällikkö,

<a id="section-18-subsection-1-paragraph-2"></a>
- **2.** sopimuspalkkainen alivaltiosihteeri,

<a id="section-18-subsection-1-paragraph-3"></a>
- **3.** tulo\- ja menoarvio\-osaston sopimuspalkkainen osastopäällikkö, jolla on budjettipäällikön arvonimi, yleisen osaston, vero\-osaston ja kansantalousosaston sopimuspalkkaiset osastopäälliköt, joilla on ylijohtajan arvonimi, palkkaosaston sopimuspalkkainen osastopäällikkö, jolla on valtion työmarkkinajohtajan arvonimi, sekä sopimuspalkkainen virastovaltuutettu, joka toimii järjestelyosaston osastopäällikkönä,

<a id="section-18-subsection-1-paragraph-4"></a>
- **4.** sopimuspalkkainen suunnittelupäällikkö, joka toimii suunnittelusihteeristön päällikkönä,

<a id="section-18-subsection-1-paragraph-5"></a>
- **5.** yleisen osaston hallitusneuvos, apulaisosastopäällikkönä, tulo\- ja menoarvio\-osaston sopimuspalkkainen budjettineuvos, apulaisosastopäällikkönä, joka toimii myös osaston finanssipoliittisen toimiston päällikkönä, vero\-osaston sopimuspalkkainen lainsäädäntöjohtaja, apulaisosastopäällikkönä, joka toimii myös osaston lainvalmisteluyksikön päällikkönä, kansantalousosaston sopimuspalkkainen finanssineuvos, apulaisosastopäällikkönä, palkkaosaston sopimuspalkkainen apulaisosastopäällikkö, jolla on finanssineuvoksen arvonimi ja järjestelyosaston sopimuspalkkainen apulaisosastopäällikkö, jolla on apulaisvirastovaltuutetun arvonimi,

<a id="section-18-subsection-1-paragraph-6"></a>
- **6.** hallitusneuvoksia, toimistopäällikköinä,

<a id="section-18-subsection-1-paragraph-7"></a>
- **7.** sopimuspalkkainen budjettineuvos, toimistopäällikkönä, joka toimii tulo\- ja menoarvio\-osaston tutkimus\- ja kehittämistoimiston päällikkönä,

<a id="section-18-subsection-1-paragraph-8"></a>
- **8.** sopimuspalkkaisia finanssineuvoksia, toimistopäällikköinä,

<a id="section-18-subsection-1-paragraph-9"></a>
- **9.** sopimuspalkkaisia toimistopäälliköitä,

<a id="section-18-subsection-1-paragraph-10"></a>
- **10.** sopimuspalkkainen koulutuspäällikkö,

<a id="section-18-subsection-1-paragraph-11"></a>
- **11.** hallitusneuvoksia,

<a id="section-18-subsection-1-paragraph-12"></a>
- **12.** sopimuspalkkainen budjettineuvos,

<a id="section-18-subsection-1-paragraph-13"></a>
- **13.** sopimuspalkkaisia finanssineuvoksia,

<a id="section-18-subsection-1-paragraph-14"></a>
- **14.** sopimuspalkkaisia lainsäädäntöneuvoksia,

<a id="section-18-subsection-1-paragraph-15"></a>
- **15.** sopimuspalkkaisia neuvottelevia virkamiehiä,

<a id="section-18-subsection-1-paragraph-16"></a>
- **16.** vanhempia hallitussihteereitä,

<a id="section-18-subsection-1-paragraph-17"></a>
- **17.** nuorempia hallitussihteereitä,

<a id="section-18-subsection-1-paragraph-18"></a>
- **18.** sopimuspalkkaisia vanhempia finanssisihteereitä,

<a id="section-18-subsection-1-paragraph-19"></a>
- **19.** sopimuspalkkaisia ja muita ylitarkastajia,

<a id="section-18-subsection-1-paragraph-20"></a>
- **20.** sopimuspalkkaisia hallinnontutkijoita,

<a id="section-18-subsection-1-paragraph-21"></a>
- **21.** osastosihteereitä,

<a id="section-18-subsection-1-paragraph-22"></a>
- **22.** kirjaaja,

<a id="section-18-subsection-1-paragraph-23"></a>
- **23.** apulaistarkastaja,

<a id="section-18-subsection-1-paragraph-24"></a>
- **24.** toimistosihteereitä,

<a id="section-18-subsection-1-paragraph-25"></a>
- **25.** toimistovirkailijoita,

<a id="section-18-subsection-1-paragraph-26"></a>
- **26.** konekirjoittajia,

<a id="section-18-subsection-1-paragraph-27"></a>
- **27.** ylivirastomestari, sekä

<a id="section-18-subsection-1-paragraph-28"></a>
- **28.** virastomestareita\.

<a id="section-18-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä on tulo\- ja menoarvion rajoissa ylimääräisiä toimistopäälliköitä, vanhempia ja nuorempia budjettisihteereitä, vanhempia ja nuorempia finanssisihteereitä, erikoistutkijoita, ylitarkastajia, apulaiskoulutuspäällikkö, suunnittelijoita, tutkijoita, hallintotarkastajia, tarkastajia, esittelijöitä, kamreeri, ministerin sihteereitä ja pääkirjanpitäjä sekä muita ylimääräisiä toimenhaltijoita ja tilapäisiä toimihenkilöitä sekä työsopimussuhteessa olevaa henkilöstöä\.

<a id="section-19"></a>
### 19 §

<a id="section-19-subsection-1"></a>
#### \(1\)

Kelpoisuusehtona vaaditaan:

<a id="section-19-subsection-1-paragraph-11"></a>
- **11.** suunnittelupäälliköltä, budjettineuvokselta, apulaisosastopäällikkönä, budjettineuvokselta, toimistopäällikkönä, finanssineuvokselta, toimistopäällikkönä ja toimistopäälliköltä, lukuun ottamatta järjestelyosaston atk\-toimiston toimistopäällikköä, sekä koulutuspäälliköltä, budjettineuvokselta, finanssineuvokselta ja neuvottelevalta virkamieheltä virkaan soveltuva korkeakoulututkinto;

<a id="section-19-subsection-1-paragraph-14"></a>
- **14.** vanhemman finanssisihteerin, ylitarkastajan ja hallinnontutkijan viran haltijalta virkaan soveltuva korkeakoulututkinto;

<a id="section-20"></a>
### 20 §

<a id="section-20-subsection-1"></a>
#### \(1\)

Budjettineuvoksen, toimistopäällikkönä, finanssineuvoksen, toimistopäällikkönä, toimistopäällikön, koulutuspäällikön, budjettineuvoksen ja finanssineuvoksen nimittää tasavallan presidentti valtioneuvoston esityksestä, sitten kun virka on ollut haettavaksi julistettuna\.

<a id="section-36"></a>
### 36 §

<a id="section-36-subsection-1"></a>
#### \(1\)

Palkkaosaston yleisen toimiston toimistopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-36-subsection-1-paragraph-1"></a>
- **1.** eläkkeen tai perhe\-eläkkeen maksamista ulkomailla olevalle;

<a id="section-36-subsection-1-paragraph-2"></a>
- **2.** valtiovarainministeriön myönnettäviä hautausapuja ja lahjapalkkioita sekä lausunnon antamista niistä;

<a id="section-36-subsection-1-paragraph-3"></a>
- **3.** luvan antamista viran tai toimen täyttämiseen tarjoamatta sitä lakkautuspalkalla olevalle sekä lakkautuspalkalla olevan sijoittamista virkaan tai toimeen;

<a id="section-36-subsection-1-paragraph-4"></a>
- **4.** poikkeuksen myöntämistä valtion työntekijäin terveydenhuollon ohjesäännön, valtion työmaiden huolto\-ohjesäännön sekä valtion rakennustyömailla käytettävien siirrettävien työmaarakennusten hankinnoista annetun valtioneuvoston päätöksen määräyksistä; sekä

<a id="section-36-subsection-1-paragraph-5"></a>
- **5.** niiden syrjäisten kohteiden määräämistä, joissa sijaitsevien valtion palvelussuhdeasuntojen vuokria määrättäessä käytetään valtioneuvoston vahvistamaa alempaa vuokratasoa\.
