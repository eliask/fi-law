# Asetus puolustusministeriön hallinnonalan eräiden virkojen perustamisesta ja lakkauttamisesta

<a id="section-1"></a>
### 1§ Yleistä

<a id="section-1-subsection-1"></a>
#### \(1\)

Eduskunnan myönnettyä tarkoitukseen tarvittavat varat perustetaan ja lakkautetaan jäljempänä mainitut peruspalkkaiset virat\.

<a id="section-2"></a>
### 2§ Puolustusministeriö

<a id="section-2-subsection-1"></a>
#### \(1\)

Perustetaan 1 päivästä maaliskuuta 1988:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yksi A 25 palkkausluokkaan kuuluva vanhemman toimistoesiupseerin virka;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yksi A 22 palkkausluokkaan kuuluva ylitarkastajan virka;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kolme A 21 palkkausluokkaan kuuluvaa taloustarkastajan virkaa;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** yksi A 21 palkkausluokkaan kuuluva esittelijän virka;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** yksi A 5 palkkausluokkaan kuuluva konekirjoittajan virka\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Lakkautetaan 1 päivästä maaliskuuta 1988:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** yksi A 23 palkkausluokkaan kuuluva nuoremman toimistoesiupseerin virka;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** kolme A 19 palkkausluokkaan kuuluvaa tarkastajan virkaa;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** yksi A 4 palkkausluokkaan kuuluva siivoojan virka\.

<a id="section-4"></a>
### 4§ Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 1988\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Toimenpiteisiin virkojen täyttämiseksi saadaan ryhtyä jo ennen sitä ajankohtaa, josta lukien virka on perustettu\.
