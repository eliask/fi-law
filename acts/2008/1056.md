# Opetusministeriön asetus Kansallisen audiovisuaalisen arkiston suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Kansallisen audiovisuaalisen arkiston maksuttomia suoritteita ovat vain vähäisiä kustannuksia aiheuttavat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** lakisääteisten ja vapaaehtoisten talletusten luovutus tallettajan omaan käyttöön;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kansainväliseen kulttuurivaihtoon liittyvä palvelutoiminta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** kirjaston kokoelmista annetut paikallislainat ja kokoelmien käyttö kirjaston tiloissa sekä luetteloiden käyttö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kirjaston suppeat tiedonhaut ja tietopalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** tallennetun radio\- ja televisioaineiston käyttö arkiston tiloissa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain [\(150/1992\) 7 §:n](<https://www.finlex.fi/fi/lainsaadanto/1992/150#chp_2__sec_7>) 1 momentissa tarkoitettuja muita suoritteita, jotka Kansallinen audiovisuaalinen arkisto hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tieto\-, kuva\- ja lainauspalvelut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** huolinta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** käyttö\- ja esitysoikeuksien myynti;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** esitystoiminta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** tilojen ja laitteiden käyttö;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** elokuvateattereiden käyttö;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** koulutus ja konsultointi;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** filmi\- ja videokatselu;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** arkistopelasteen käyttö;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** muut tilauksesta tuotetut suoritteet;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** talletetun elokuva\- sekä radio\- ja televisioaineiston katselu ja kuuntelu\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Viranomaisten toiminnan julkisuudesta annetun lain [\(621/1999\) 34 §:n](<https://www.finlex.fi/fi/lainsaadanto/1999/621#chp_8__sec_34>) 2 momentissa tarkoitetusta tiedon esille hakemisesta sekä saman lain 34 §:n 3 momentissa tarkoitettujen kopioiden ja tulosteiden antamisesta perittävistä maksuista päättää Kansallinen audiovisuaalinen arkisto ottaen huomioon, mitä viranomaisten toiminnan julkisuudesta annetun lain 34 §:ssä säädetään\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Kirjaston kaukopalvelusta, joka annetaan tai välitetään valtion ja kuntien ylläpitämille kirjastoille ja valtionavustusta saaville kirjastoille sekä valtion ja kuntien viranomaisille, peritään aineiston lähettämisestä aiheutuvien kustannusten ja suoritteen tuottamisen johdosta muille suoritettujen maksujen mukainen maksu\. Muu kaukopalvelu hinnoitellaan liiketaloudellisin perustein\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2009 ja on voimassa 31 päivään joulukuuta 2011\.
