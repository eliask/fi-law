<a id="section-1"></a>
### 1 § Ministeriön tehtävät

<a id="section-1-subsection-1"></a>
#### \(1\)

Liikenne\- ja viestintäministeriön tehtäviä ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** liikennejärjestelmien suunnittelu\- ja kehittäminen;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** liikenneverkkojen ylläpito ja kehittäminen;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** tieliikenne sekä tieliikenteessä käytettäviä ajoneuvoja koskevat asiat;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** rautatieliikenne;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** merenkulku ja muu vesiliikenne sekä satamat;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** siviili\-ilmailu ja lentopaikat;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** henkilöliikennepalvelut sekä kysyntää ja tarjontaa koskevat asiat;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** logistiikka ja liikenteen telematiikka;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** liikenteen turvallisuus\- ja ympäristöasiat sekä vaarallisten aineiden kuljetukset;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** ilmakehän tutkimus ja seuranta, sääpalvelut sekä fysikaalinen merentutkimus ja seuranta;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** tietoyhteiskuntakehityksen yleiset edellytykset;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** viestintäverkkojen, \-palveluiden ja \-markkinoiden yleiset toimintaedellytykset;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** postitoiminnan ohjaus sekä sanomalehdistön tukeminen;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** Yleisradio Oyj:tä koskevat asiat;

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** sähköisen kaupankäynnin ja muun verkkoliiketoiminnan yleiset edellytykset;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** yksityisyyden suoja televiestinnässä ja televiestinnän tietoturva;

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** sähköisten allekirjoitusten kehittäminen sekä viestinnän ja tietotekniikan salaustuotteet;

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** kesäaikaa koskevat asiat\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Sen lisäksi, mitä valtioneuvoston ohjesäännössä \(262/2003\) tai muutoin säädetään, liikenne\- ja viestintäministeriön osastojen ja muiden toimintayksiköiden tehtävistä säädetään ministeriön työjärjestyksessä\.

<a id="section-2"></a>
### 2 § Ministeriön toimialaan kuuluvat virastot, laitokset ja toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Tiehallinto;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Merenkulkulaitos;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Ajoneuvohallintokeskus;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Ilmailuhallinto;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Ratahallintokeskus;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Rautatievirasto;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Viestintävirasto;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Ilmatieteen laitos;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Saimaan kanavan hoitokunta;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Ilmailulaitos;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Luotsausliikelaitos;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Varustamoliikelaitos;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Liikenneturva\.
