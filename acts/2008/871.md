<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Maistraatit, jotka hoitavat kuluttajaneuvonnasta annetun lain 1 §:n mukaisesti kuluttajaneuvontaa, ovat

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Vantaan maistraatti

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Hämeenlinnan maistraatti

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Lappeenrannan maistraatti

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Turun seudun maistraatti

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Satakunnan maistraatti

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Keski\-Suomen maistraatti

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Vaasan maistraatti

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Tampereen maistraatti

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Pohjois\-Savon maistraatti

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Pohjois\-Pohjanmaan maistraatti ja

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Lapin maistraatti\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Kuluttajaneuvontaa antavat ja heitä avustavat virkamiehet ovat edellä 1 §:ssä mainittujen maistraattien virkamiehiä\. Maistraatti voi määrätä kuluttajaneuvonnan alueellisen saatavuuden tai toiminnan tarkoituksenmukaisen järjestämisen vuoksi kuluttajaneuvonnan virkamiesten virkapaikaksi muunkin maistraatin yksikön tai toimipisteen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2009\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
