<a id="section-3"></a>
### 3 § Kunnat

<a id="section-3-subsection-1"></a>
#### \(1\)

Kuntien kielellinen jaotus on voimassa lääneittäin seuraavasti:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Etelä\-Suomen lääni:

<a id="section-3-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** Kaksikielisiä kuntia, suomi asukkaiden enemmistön kielenä, ovat Espoo, Hanko, Helsinki, Kauniainen, Kirkkonummi, Lapinjärvi, Lohja, Loviisa, Myrskylä, Porvoo, Pyhtää, Ruotsinpyhtää, Sipoo, Siuntio ja Vantaa\.

<a id="section-3-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** Kaksikielisiä kuntia, ruotsi asukkaiden enemmistön kielenä, ovat Inkoo, Liljendal, Pernaja ja Raasepori\.

<a id="section-3-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Länsi\-Suomen lääni:

<a id="section-3-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** Kaksikielisiä kuntia, suomi asukkaiden enemmistön kielenä, ovat Kaskinen, Kokkola, Turku ja Vaasa\.

<a id="section-3-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** Kaksikielisiä kuntia, ruotsi asukkaiden enemmistön kielenä, ovat Kemiönsaari, Kristiinankaupunki, Kruunupyy, Länsi\-Turunmaa, Maalahti, Mustasaari, Oravainen, Pedersöre, Pietarsaari, Uusikaarlepyy ja Vöyri\-Maksamaa\.

<a id="section-3-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** Ruotsinkielisiä kuntia ovat Korsnäs, Luoto ja Närpiö\.

<a id="section-3-subsection-1-paragraph-2-subparagraph-d"></a>
  - **d.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** Itä\-Suomen, Oulun ja Lapin läänissä kaikki kunnat ovat suomenkielisiä\.
