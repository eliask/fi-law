### 2 § Opetus\- ja kulttuuriministeriön toimialan virastot, laitokset, yhtiöt ja muut toimielimet\.

<a id="section-2-subsection-1"></a>
#### \(1\)

Opetus\- ja kulttuuriministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** yliopistot ja niiden harjoittelukoulut;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** ammattikorkeakoulut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Opetushallitus ja sen toimialaan kuuluvat valtion oppilaitokset;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** ylioppilastutkintolautakunta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Kansallinen koulutuksen arviointikeskus;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** opintotuen muutoksenhakulautakunta;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** opiskelijoiden oikeusturvalautakunta;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Suomen Akatemia;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Kotimaisten kielten keskus;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** arkistolaitos;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Varastokirjasto;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Taiteen edistämiskeskus, taideneuvosto, valtion taidetoimikunnat ja alueelliset taidetoimikunnat;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** näkövammaisten kirjasto;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** Museovirasto;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Suomenlinnan hoitokunta;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Kansallinen audiovisuaalinen instituutti;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** kuvaohjelmalautakunta;

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** Suomen Kansallisooppera;

<a id="section-2-subsection-1-paragraph-19"></a>
- **19.** Suomen Kansallisteatteri;

<a id="section-2-subsection-1-paragraph-20"></a>
- **20.** Kansallisgalleria;

<a id="section-2-subsection-1-paragraph-21"></a>
- **21.** Suomen elokuvasäätiö;

<a id="section-2-subsection-1-paragraph-22"></a>
- **22.** Kansainvälisen liikkuvuuden ja yhteistyön keskus CIMO;

<a id="section-2-subsection-1-paragraph-23"></a>
- **23.** CSC\-Tieteen tietotekniikan keskus Oy;

<a id="section-2-subsection-1-paragraph-24"></a>
- **24.** Veikkaus Oy;

<a id="section-2-subsection-1-paragraph-25"></a>
- **25.** Hevosopisto Oy;

<a id="section-2-subsection-1-paragraph-26"></a>
- **26.** Suomen Ilmailuopisto Oy\.

<a id="section-6"></a>
### 6 § Kelpoisuusvaatimukset

<a id="section-6-subsection-1"></a>
#### \(1\)

Sen lisäksi, mitä valtioneuvoston ohjesäännön 43 §:ssä säädetään, kelpoisuusvaatimuksena on:

<a id="section-6-subsection-1-paragraph-5"></a>
- **5.** hallitusneuvoksella, lainsäädäntöneuvoksella, tekijänoikeusneuvoksella, hallitussihteerillä ja lakimiehellä muu oikeustieteen ylempi korkeakoulututkinto kuin kansainvälisen ja vertailevan oikeustieteen maisterin tutkinto ja perehtyneisyys viran tehtäväalaan, jollei häneen ole tehtävänsä tai asemansa perusteella sovellettava lisäksi 2 tai 3 kohdan säännöksiä;
