### 2 § Määritelmät

<a id="section-2-subsection-1"></a>
#### \(1\)

Tässä asetuksessa tarkoitetaan:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** rajavartiopukineell a rajavartiolaitoksen virkamiehelle vahvistettua, määrätyn kuosista, laatuista ja väristä asustetta;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** virkapukineella rajavartiolaitoksen muulle kuin sotilasvirassa palvelevalle virkamiehelle vahvistettua, määrätyn kuosista, laatuista ja väristä asustetta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kenttävaatetuksella rajavartiolaitoksen operatiivisissa tehtävissä käytettäviä rajavartiomiehelle vahvistettuja asustekokonaisuuksia;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** palveluspuvulla tarkoitetaan muissa kuin operatiivisissa tehtävissä käytettäviä rajavartiomiehelle vahvistettuja asustekokonaisuuksia;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** sotilaspukineella puolustusvoimista annetun lain \(551/2007\) 45 §:ssä ja sen nojalla annetuissa tarkemmissa määräyksissä tarkoitettua sotilaspukinetta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** suojapukineella rajavartiolaitoksen virkamiehelle vahvistettua, määrätyn kuosista, laatuista ja väristä asustetta, jota työtehtävien tai olosuhteiden sitä edellyttäessä käytetään virkamiehen tai tämän asusteiden suojaamiseen muiden asusteiden taikka varusteiden sijasta tai niiden lisäksi;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** rajavartiomiehen tunnuksella rajavartiopukineeseen kiinnitettävää rajavartiomiehen asemaa osoittavaa merkkiä, jossa rajavartiolaitoksen tunnuskuvaa ympäröi teksti "RAJAVARTIOLAITOS – GRÄNSBEVAKNINGSVÄSENDET";

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** arvomerkillä sotilasarvoa tai palvelusarvoa osoittavaa merkkiä;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** rajajoukkomerkillä merkkiä, jossa tunnuskuvana on karhunpää, jonka saatteena on sitä vasten painautuneina kuusen havu ja miekka;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** erikoismerkillä asusteessa käytettävää muuta kuin kohdassa 7—9 tarkoitettua merkkiä tai tunnusta;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** rintamerkillä rajavartiopukineeseen kiinnitettävää merkkiä, jossa on Suomen lippu, henkilön sukunimi sekä teksti ”RAJAVARTIOLAITOS”, ”GRÄNSBEVAKNINGSVÄSENDET” tai ”BORDER GUARD”\.

### 3 § Rajavartiopukineet

<a id="section-3-subsection-1"></a>
#### \(1\)

Rajavartiopukineisiin kuuluvat seuraavat asustekokonaisuudet:

<a id="subsection-1"></a>

Palveluspukuun kuuluvia asusteita ovat:

<a id="subsection-1-paragraph-1"></a>
- **1.** pusero, miesten ja naisten malli;

<a id="subsection-1-paragraph-2"></a>
- **2.** housut, yhteiskäytössä vierailupuvun kanssa, miesten ja naisten malli;

<a id="subsection-1-paragraph-3"></a>
- **3.** päällystakki, 3/4\-malli, yhteiskäytössä vierailupuvun kanssa, miesten ja naisten malli;

<a id="subsection-1-paragraph-4"></a>
- **4.** hame, yhteiskäytössä vierailupuvun kanssa;

<a id="subsection-1-paragraph-5"></a>
- **5.** paitapusero, valkoinen lyhythihainen ja pitkähihainen, miesten ja naisten malli;

<a id="subsection-1-paragraph-6"></a>
- **6.** solmio;

<a id="subsection-1-paragraph-7"></a>
- **7.** palveluspuvun lippalakki;

<a id="subsection-1-paragraph-8"></a>
- **8.** suikkalakki;

<a id="subsection-1-paragraph-9"></a>
- **9.** turkislakki;

<a id="subsection-1-paragraph-10"></a>
- **10.** mustat puolikengät;

<a id="subsection-1-paragraph-11"></a>
- **11.** musta vyö\.

<a id="subsection-2"></a>
#### \(2\)

Palveluspukuun kiinnitetään rajajoukkomerkki, rintamerkki sekä erikoismerkkejä\.

<a id="subsection-7-paragraph-6"></a>

<a id="subsection-7-paragraph-7"></a>

<a id="subsection-8"></a>
#### \(8\)

Käytettäessä vierailupukua paraatipukuna kiinnitetään siihen tarvittavat kunniamerkit sekä yleisesikuntaupseerin olkanauhat\.

<a id="subsection-9"></a>
#### \(9\)

Rajavartiolaitoksen sotilasvirassa palvelevan virkamiehen juhlapukuna on puolustusvoimista annetun lain 45 §:n ja sen nojalla annettujen määräysten mukainen juhlapuku, pieni juhlapuku tai messipuku\. Raja\- ja merivartijan juhlapuku on vierailupuku\. Kenraalit ja amiraalit käyttävät valkoista turkislakkia juhla\- ja paraatipuvuissa\.

<a id="section-4"></a>
### 4 § Virkapukineet

<a id="section-4-subsection-1"></a>
#### \(1\)

Virkapukine on muille kuin sotilasvirassa palveleville rajavartiolaitoksen virkamiehille tarkoitettu rajavartiopukine ilman rajavartiomiehen tunnusta tai arvomerkkejä\.

<a id="section-8"></a>
### 8 § Rajavartiomiehen tunnus ja rintamerkki

<a id="section-8-subsection-1"></a>
#### \(1\)

Rajavartiomiehen tunnus on rajavartiopukineeseen kiinnitetty tai kirjailtu rajavartiolaitoksen tunnuskuva, joka on taustaltaan vihreä ja kuvioltaan kultainen\.

<a id="section-8-subsection-2"></a>
#### \(2\)

Rajavartiomiehen tunnus sijoitetaan hihaan tai rintaan\. Rajavartiomiehen toimivaltuuksia koskeva rajoitus merkitään asusteeseen kiinnitettävällä sanaparilla "HARJOITTELIJA – PRAKTIKANT" tai Ahvenanmaalla tekstillä "PRAKTIKANT"\.

<a id="section-8-subsection-3"></a>
#### \(3\)

Rintamerkki on rajavartiopukineeseen kiinnitetty merkki, joka on taustaltaan vihreä\. Rintamerkissä on Suomen lippu, henkilön sukunimi sekä teksti ”RAJAVARTIOLAITOS”, ”GRÄNSBEVAKNINGSVÄSENDET” tai ”BORDER GUARD” virkamiehen tehtävien ja toimialueiden mukaisesti\. Rintamerkki kiinnitetään rintaan\.

<a id="section-11"></a>
### 11 § Siirtymäsäännös

<a id="section-11-subsection-1"></a>
#### \(1\)

Rajavartiolaitoksen asustetta, joka ei täytä tässä asetuksessa säädettyjä vaatimuksia, saa käyttää virkapukuna 31 päivään joulukuuta 2017 saakka\.
