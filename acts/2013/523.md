<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään maataloustuotteiden markkinajärjestelystä annetussa laissa \(999/2012\) tarkoitettuun mehiläishoitotukeen liittyvistä tukikelpoisista toimenpiteistä ja hyväksyttävistä kustannuksista\.

<a id="section-2"></a>
### 2 § Mehiläishoitajille ja heidän ryhmilleen annettava tekninen apu

<a id="section-2-subsection-1"></a>
#### \(1\)

Tukea voidaan myöntää seuraaviin mehiläishoitoon liittyviin toimiin, joiden tavoitteena on antaa mehiläishoitajille ja heidän ryhmittymilleen teknistä apua:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** neuvonta;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** koulutus;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** tiedottaminen;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** messuille ja kongresseihin osallistuminen;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** kansainvälinen yhteistyö;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** sähköisen viestintä\- ja oppimisympäristön tekninen ja sisällön toteutus\.

<a id="section-3"></a>
### 3 § Hunajan fysikaalis\-kemiallisia ominaisuuksia määrittävää laboratoriota koskevat tukitoimet

<a id="section-3-subsection-1"></a>
#### \(1\)

Tukea voidaan myöntää hunajan laadun määrittämiseen hunajan fysikaalis\-kemiallisia ominaisuuksia määrittävässä laboratoriossa keräämällä ja analysoimalla näytteitä sekä saaduista tuloksista tiedottamiseen\.

<a id="section-4"></a>
### 4 § Yhteistoiminta mehiläishoitoalaa ja mehiläistuotteita koskevan soveltavan tutkimuksen ohjelmien toteuttamiseen erikoistuneiden tahojen kanssa

<a id="section-4-subsection-1"></a>
#### \(1\)

Tukea voidaan myöntää mehiläishoitoalaa ja mehiläistuotteita koskevan soveltavan tutkimuksen ohjelmien toteuttamiseen erikoistuneiden tahojen kanssa tehtävään, seuraavia toimia koskevaan yhteistyöhön:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** mehiläishoitotekniikkaa parantavien menetelmien kehittäminen ja laiteiden hankkiminen;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** vaakapesämonitorointiin liittyvä toiminta ja tiedon käyttö:

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** varroapunkin torjuntamenetelmien kehittäminen;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** muu mehiläishoidon soveltava tutkimus ja koetoiminta pölytykseen, hunajan ominaisuuksiin ja sen koostumukseen tai vastaavaan liittyen\.

<a id="section-5"></a>
### 5 § Hyväksyttävät kustannukset

<a id="section-5-subsection-1"></a>
#### \(1\)

Hyväksyttävien kustannusten on oltava 1—3 §:ssä tarkoitettujen toimenpiteiden toteuttamisen kannalta tarpeellisia ja kohtuullisia:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** palkkaus\- ja palkkiokustannuksia ja niihin liittyviä lakisääteisiä kustannuksia, lukuun ottamatta luontaisetuina suoritettavia kustannuksia;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** matkakustannuksia;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** ulkopuolisten palvelujen ja asiantuntijoiden käytöstä aiheutuvia kustannuksia;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** messuille tai näyttelyyn osallistumisesta aiheutuvia kustannuksia

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** vuokrakustannuksia;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** välttämättömistä materiaaleista, välineistä ja toimitiloista aiheutuvia kustannuksia; materiaalit ja välineet on vuokrattava, jollei niiden hankkiminen ole vuokraamista edullisempaa;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** sellaisia kirjanpito\-, seuranta\- ja raportointikustannuksia, jotka johtuvat myönnetystä tuesta; tai

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** julkaisu\- ja jakelukustannuksia\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Yleishallinnon kulut ja muut hankkeelle jaettavat kustannukset voidaan hyväksyä vain siltä osin kuin ne kohdennetaan ohjelman toteuttamiseen\.

<a id="section-5-subsection-3"></a>
#### \(3\)

Tukea voidaan myöntää kustannusten arvonlisäveron osuuteen, jos avustuksen saaja esittää verottajalta saadun todistuksen tai muun luotettavan selvityksen siitä, ettei kyseiseen toimintaan liittyviä kustannuksia voida vähentää avustuksen saajan toiminnassa\.

<a id="section-6"></a>
### 6 § Hyväksyttävien kustannusten rajoitukset:

<a id="section-6-subsection-1"></a>
#### \(1\)

Tukea ei myönnetä:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** edustusmenoihin;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** rahoituskuluihin;

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** kustannuksiin, jotka aiheutuvat yrityksen tavanomaiseen liiketoimintaan kuuluvasta toiminnasta

- **3.** Palkkaus\- ja palkkiokustannuksista ei hyväksytä määrää, joka ylittää alalla maksettavien palkkojen ja palkkioiden tason\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Matkakustannuksina hyväksytään enintään valtion virkaehtosopimuksen mukaiset kustannukset\.

<a id="section-6-subsection-3"></a>
#### \(3\)

Kustannuksiin, jotka ovat syntyneet ennen kuin Maaseutuvirasto on myöntänyt mehiläishoitotuen, ei myönnetä tukea\.

<a id="section-7"></a>
### 7 § Voimaantulo

<a id="section-7-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 3 päivänä heinä kuuta 2013\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Ennen tämän asetuksen voimaan tuloa myönnettyihin mehiläishoitotukiin sovelletaan tämän asetuksen voimaan tullessa voimassa olleita säännöksiä\.
