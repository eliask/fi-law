# Laki valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtioneuvostossa on yleistä hallitusta ja eri hallinnonhaaroja varten kymmenen ministeriöitä, nimittäin:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1\..** Ulkoasiainministeriö;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2\..** Oikeusministeriö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3\..** Sisäasiainministeriö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4\..** Puolustusministeriö;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5\..** Valtiovarainministeriö;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6\..** Opetusministeriö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7\..** Maatalousministeriö;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8\..** Kulkulaitosten ja yleisten töiden ministeriö;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9\..** Kauppa\- ja teollisuusministeriö; sekä

<a id="section-1-subsection-1-paragraph-10"></a>
- **10\..** Sosialiministeriö\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Sitäpaitsi on valtioneuvostolla kanslia\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Jokaisen ministeriön päällikkönä on ministeri\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Tasavallan presidentti voi ministeriöiden päällikköjen lisäksi kutsua valtioneuvoston jäseniksi enintään kaksi ministeriä, joko päällikön apulaisena käsittelemään yhden tai useamman ministeriön alaan kuuluvia asioita tahi olemaan salkuttomana ministerinä\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Siltä varalta että ministeri sairauden, jäävillisyyden tai muun tilapäisen esteen takia ei voi hoitaa tehtäviään, on tasavallan presidentin asia määrätä joku toinen ministeri hänen sijaansa\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvostolle kuuluvista asioista käsittelee:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Ulkoasiainministeriö asiat, jotka johtuvat Suomen suhteista ulkovaltoihin;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Oikeusministeriö asiat, jotka koskevat oikeudenhoitoa, lainsäädäntöä asioissa, jotka eivät kuulu muun ministeriön toimialaan, sekä vankeinhoitolaitosta, niin myös valtiollisia vaaleja;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** sisäasiainministeriö asiat, jotka koskevat yleistä järjestystä ja turvallisuutta, sisäistä hallintoa sekä yleistä terveydenhoitoa;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** Puolustusministeriö asiat, jotka koskevat sotavoimaa ja puolustuslaitosta;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** Valtiovarainministeriö asiat, jotka koskevat maan rahalaitosta, raha\-asioita ja verotointa;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** Opetusministeriö asiat, jotka koskevat opetustointa, evankelis\-luterilaista kirkkoa ja muita uskonnollisia yhdyskuntia, tiedettä ja taidetta sekä urheilua;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** Maatalousministeriö asiat, jotka koskevat maanviljelystä, metsästystä ja kalastusta, metsätaloutta, asutustoimintaa sekä maanmittauslaitosta;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** Kulkulaitosten ja yleisten töiden ministeriö asiat, jotka koskevat liikennettä, posti\- ja lennätinlaitosta, valtion koskia ja vesilaitoksia, valtion rakennustoimintaa sekä yleisiä hätäaputöitä;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** Kauppa\- ja teollisuusministeriö asiat, jotka koskevat kauppaa, teollisuutta ja merenkulkua; sekä

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** Sosialiministeriö asiat, jotka koskevat työoloja ja niiden yhteydessä olevia kysymyksiä, sosialivakuutusta, köyhäinhoitoa, yleistä tilastoa, siirtolaisuutta ja alkoholilainsäädäntö\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tarkempia säännöksiä asioiden jakautumisesta ministeriöiden kesken sekä määräyksiä valtioneuvosten kansliasta annetaan asetuksella\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Jos syntyy epäilystä siitä, minkä ministeriön käsiteltäviin joku asia kuuluu, ratkaisee kysymyksen valtioneuvosto\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Ministeriö voidaan jakaa osastoihin, milloin sellainen ministeriön alaan kuuluvien tehtävien järjestely havaitaan tarpeelliseksi\. Tarkempia säännöksiä tästä annetaan asetuksella\.
