# Laki valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtioneuvostossa on yleistä hallitusta ja eri hallinnonhaaroja varten kymmenen ministeriötä, nimittäin:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1\..** Ulkoasiainministeriö;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2\..** Oikeusministeriö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3\..** Sisäasiainministeriö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4\..** Puolustusministeri;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5\..** Valtiovarainministeri;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6\..** Opetusministeriö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7\..** Maatalousministeriö;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8\..** Kulkulaitosten ja yleisten töiden ministeriö;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9\..** Kauppa\- ja teollisuusministeriö; sekä

<a id="section-1-subsection-1-paragraph-10"></a>
- **10\..** Sosiaaliministeriö\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Valtioneuvostolla on myös kanslia, josta on voimassa, mitä tässä laissa on ministeriöstä säädetty\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Lisäksi voi valtioneuvostossa ella kansanhuoltoministeriö\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Jokaisen ministeriön päällikkönä on ministeri\.

<a id="section-1-subsection-5"></a>
#### \(5\)

Tasavallan presidentti voi valtioneuvoston jäseniksi kutsua, pääministeri mukaan luettuna, enintään viisitoista ministeriä, jotka toimivat yhden tai useamman ministeriön päällikköinä tai käsittelevät niiden toimialaan kuuluvia asioita taikka ovat salkuttomina ministereinä\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Sen varalta, ettei ministeri vuosiloman, sairauden, esteellisyyden tai muun tilapäisen esteen takia voi hoitaa tehtäviään, määrää tasavallan presidentti toisen ministerin hänen sijaisekseen\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Pääministerin ollessa estyneenä on hänen sijaisenaan se ministeri, joka hallitusmuodon 39 §:n mukaan toimii hänen sijassaan puheenjohtajana valtioneuvoston istunnossa\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvostolle kuuluvista asioista käsittelee:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** valtioneuvoston kanslia, joka on pääministerin alainen, asiat, jotka koskevat valtiopäivistä johtuvia muodollisia toimenpiteitä, valtioneuvostoa sekä asiain käsittelyjärjestystä valtioneuvostossa, valtion julkaisutoimintaa ja sellaiset muut valtioneuvostossa käsiteltävät asiat, jotka eivät kohdistu minkään ministeriön toimialaan;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** ulkoasiainministeriö asiat, jotka johtuvat Suomen suhteista ulkovaltoihin;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** oikeusministeriö asiat, jotka koskevat oikeudenhoitoa, lainsäädäntöä asioissa, jotka eivät kuulu muun ministeriön toimialaan, sekä vankeinhoitoa, niin myös valtiollisia vaaleja;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** sisäasiainministeriö asiat, jotka koskevat yleistä järjestystä ja turvallisuutta, sisäistä hallintoa sekä yleistä terveydenhoitoa;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** puolustusministeriö asiat, jotka koskevat valtakunnan puolustusta ja puolustusvoimia;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** valtiovarainministeriö asiat, jotka koskevat valtion tulo\- ja menoarviota, maan rahalaitosta, raha\-asioita, verotointa j maan talouselämän kehittämistä kansantalouden vaatimusten mukaan sekä yleistä tilastoa;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** opetusministeriö asiat, jotka koskevat yleistä opetustointa, evankelis\-luterilaista ja kreikkalaiskatolista kirkkoa sekä muita uskonnollisia yhdyskuntia, tiedettä ja taidetta sekä urheilua;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** maatalousministeriö asiat, jotka koskevat maataloutta, metsätaloutta, maanmittausta, asutustoimintaa, eläinlääkintää sekä metsästystä ja kalastusta;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** kulkulaitosten ja yleisten töiden ministeriö asiat, jotka koskevat liikennettä, posti\- ja lennätinlaitosta, valtion koskia ja vesilaitoksia, valtion rakennustoimintaa sekä muita yleisiä töitä;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** kauppa\- ja teollisuusministeriö asiat, jotka koskevat kauppaa, vuorityötä, teollisuutta ja \- ammattikasvatusta sekä merenkulkua;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** sosiaaliministeriö asiat, jotka koskevat työoloja ja niiden yhteydessä olevia kysymyksiä, vakuutusta, köyhäinhoitoa, lastensuojelua, sosiaalitilastoa, siirtolaisuutta sekä raittiustyötä ja väkijuomia; sekä

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** kansanhuoltoministeriö, milloin se on asetettu, asiat, jotka koskevat väestön toimeentulon turvaalaista sekä talouselämän ja työvoiman käytön säännöstelyä sodan tai muun poikkeuksellisen tilanteen aikana ja niitä tarkoittavia valmisteluja, mikäli niitä ei ole jätetty jollekin muulle ministeriölle\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tarkempia säännöksiä asioiden jakautumisesta valtioneuvoston kanslian ja ministeriöiden kesken annetaan asetuksella\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Jos syntyy epäilystä siitä, minkä ministeriön käsiteltäviin joku asia kuuluu, ratkaisee kysymyksen valtioneuvosto\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Ministeriö voidaan jakaa osastoihin, milloin sellainen ministeriön alaan kuuluvien tehtävien järjestely havaitaan tarpeelliseksi\. Tarkempia säännöksiä tästä annetaan asetuksella\.
