# Laki valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtioneuvostossa on yleistä hallitusta ja eri hallinnonhaaroja varten kaksitoista ministeriötä, nimittäin:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ulkoasiainministeriö;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** oikeusministeriö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** sisäasiainministeriö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** puolustusministeriö;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** valtiovarainministeriö;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** opetusministeriö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** maa\- ja metsätalousministeriö;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** liikenneministeriö;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** kauppa\- ja teollisuusministeriö;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** sosiaali\- ja terveysministeriö;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** työministeriö; sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** ympäristöministeriö\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Valtioneuvostolla on myös kanslia, josta on voimassa, mitä tässä laissa on ministeriöstä säädetty\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Lisäksi voi valtioneuvostossa ella kansanhuoltoministeriö\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Jokaisen ministeriön päällikkönä on ministeri\.

<a id="section-1-subsection-5"></a>
#### \(5\)

Tasavallan presidentti voi valtioneuvoston jäseniksi kutsua, pääministeri mukaan luettuna, enintään kahdeksantoista ministeriä, jotka toimivat yhden tai useamman ministeriön päällikköinä tai käsittelevät niiden toimialaan kuuluvia asioita taikka ovat salkuttomina ministereinä\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Sen varalta, ettei ministeri vuosiloman, sairauden, esteellisyyden tai muun tilapäisen esteen takia voi hoitaa tehtäviään, määrää tasavallan presidentti toisen ministerin hänen sijaisekseen\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Pääministerin ollessa estyneenä on hänen sijaisenaan se ministeri, joka hallitusmuodon 39 §:n mukaan toimii hänen sijassaan puheenjohtajana valtioneuvoston istunnossa\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvostolle kuuluvista asioista käsittelee:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** valtioneuvoston kanslia, joka on pääministerin alainen, asiat, jotka koskevat valtiopäivistä johtuvia muodollisia toimenpiteitä, tasavallan presidentin kansliaa, valtioneuvostoa ja asiain käsittelyjärjestystä valtioneuvostossa sekä sellaiset muut valtioneuvoston käsiteltävät asiat, jotka eivät kohdistu minkään ministeriön toimialaan;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** ulkoasiainministeriö asiat, jotka johtuvat Suomen suhteista ulkovaltoihin;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** oikeusministeriö asiat, jotka koskevat oikeudenhoitoa, lainsäädäntöä asioissa, jotka eivät kuulu muun ministeriön toimialaan, sekä vankeinhoitoa, niin myös valtiollisia vaaleja ja kunnallisvaalia sekä kansanäänestystä;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** sisäasiainministeriö asiat, jotka koskevat lääninhallintoa, kunnallishallintoa lukuun ottamatta kunnallisvaaleja, väestökirjanpitoa, aluepolitiikkaa ja siihen liittyvää yhteiskuntapoliittista suunnittelua, yleistä järjestystä ja turvallisuutta sekä poliisitointa, palo\- ja pelastustointa, väestönsuojelua ja rajavartiolaitosta;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** puolustusministeriö asiat, jotka koskevat valtakunnan puolustusta ja puolustusvoimia;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** valtiovarainministeriö asiat, jotka koskevat valtiontalouden hoidon ja taloussuunnittelun yleisjohtoa, valtion tulo\- ja menoarviota, vero\- ja tullitointa, maan rahalaitosta, yleistätilastoa, valtionhallinnon organisoinnin ja rationalisoinnin sekä palkkaus\- ja muiden henkilökunta\-asiain yleistä järjestelyä sekä valtion talonrakennustoimintaa;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** opetusministeriö asiat, jotka koskevat yleistä opetustointa, ammattikasvatusta, evankelis\-luterilaista kirkkoa ja ortodoksista kirkkokuntaa sekä muita uskonnollisia yhdyskuntia, sikäli kuin ne eivät kuulu jollekin muulle ministeriölle, korkeakoululaitosta, tiedettä ja taidetta sekä urheilua;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** maa\- ja metsätalousministeriö asiat, jotka koskevat maataloutta, metsätaloutta, maanmittausta, asutustoimintaa, eläinlääkintää, kalastusta ja metsästystä sekä vesivarojen käyttöä, tulvasuojelua ja maankuivatusta samoin kuin yleisten vesialueiden hallintaa ja hoitoa;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** liikenneministeriö asiat, jotka koskevat tie\-, rautatie\-, sisävesi\- ja ilmailuliikennettä sekä niiden liikenneväyliä, niin myös tietoliikennettä ja sääpalvelua;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** kauppa\- ja teollisuusministeriö asiat, jotka koskevat kauppaa, hintoja ja muiden valvontaa ja sen mukaan kuin siitä erikseen säädetään muita kuluttajakysymyksiä, vuorityötä, teollisuutta sekä merenkulkua;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** sosiaali\- ja terveysministeriö asiat, jotka koskevat sosiaali\- ja yksityisvakuutusta, terveyden\- ja sairaanhoitoa, työterveyshuoltoa sikäli kuin nämä asiat eivät kuulu työministeriölle sekä apteekkilaitosta, sosiaalihuoltoa ja \-avustuksia, raittiustyötä ja väkijuomia sekä muita sosiaalisia kysymyksiä, mikäli ne eivät kuulu jollekin muulle ministeriölle;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** työministeriö asiat, jotka koskevat työvoimapolitiikan suunnittelua ja ohjausta, työllisyyden edistämistä ja työttömyyden torjuntaa, työympäristöä, työsuhdetta, työoloja, työsuojelua, työterveyshuollon järjestämisvelvollisuuden toteuttamista ja sen valvontaa, työelämän osallistumisjärjestelmiä, työehtosopimuksia, työvelvollisuutta, siviilipalveluksen järjestämistä, siirtolaisuutta sekä merimiesten palvelu\- ja opintotoimintaa;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** ympäristöministeriö asiat, jotka koskevat ympäristön\- ja luonnonsuojelua, vesien käytön, hoidon ja suojelun kokonaissuunnittelua sekä muuta vesi\- ja ympäristöhallintoa, ulkoilua ja muuta luonnon virkistyskäyttöä, kaavoitus\- ja rakennustointa sekä asuntotointa, sikäli kuin edellä mainitut asiat eivät kuulu muulle ministeriölle; sekä

<a id="section-3-subsection-2"></a>
#### \(2\)

Tarkempia säännöksiä asioiden jakautumisesta valtioneuvoston kanslian ja ministeriöiden kesken annetaan asetuksella\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Milloin syntyy epäilystä siitä, minkä ministeriön käsiteltäviin jokin asia kuuluu, ratkaisee kysymyksen valtioneuvosto\. Valtioneuvosto voi myös päättää, minkä ministeriön on käsiteltävä sellainen laajakantoinen tai periaatteellisesti tärkeä asia, joka koskee useamman kuin yhden ministeriön toimialaa\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Tarkempia säännöksiä ministeriöiden sisäisestä järjestysmuodosta annetaan asetuksella\.
