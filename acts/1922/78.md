# Laki valtioneuvoston ministeriöiden lukumäärästä ja yleisestä toimialasta

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtioneuvostossa on yleistä hallitusta ja eri hallinnonhaaroja varten kymmenen ministeriötä, nimittäin: 1\. Ulkoasiainministeriö;
sekä 10\. Sosiaaliministeriö\. Sitä paitsi on valtioneuvoston kanslia\.

<a id="section-1-subsection-1-paragraph-2"></a>
- **2\..** Oikeusministeriö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3\..** Sisäasiainministeriö;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4\..** Puolustusministeriö;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5\..** Valtiovarainministeriö;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6\..** Opetusministeriö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7\..** Maatalousministeriö;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8\..** Kulkulaitosten ja yleisten töiden ministeriö;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9\..** Kauppa\- ja teollisuusministeriö;

<a id="section-1-subsection-2"></a>
#### \(2\)

Lisäksi voi valtioneuvostossa olla kansanhuoltoministeriö\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Jokaisen ministeriön päällikkönä on ministeri\.

<a id="section-1-subsection-4"></a>
#### \(4\)

Tasavallan presidentti voi ministeriön päälliköiden lisäksi kutsua valtioneuvoston jäseniksi enintään kuusi ministeriä, joko käsittelemään yhden tai useamman ministeriön alaan kuuluvia asioita tai olemaan salkuttomana ministerinä\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Siltä varalta että ministeri sairauden, jäävillisyyden tai muun tilapäisen esteen takia ei voi hoitaa tehtäviään, on tasavallan presidentin asia määrätä joku toinen ministeri hänen sijaansa\.

<a id="section-3"></a>
### 3 §\.

<a id="section-3-subsection-1"></a>
#### \(1\)

Valtioneuvostolle kuuluvista asioista käsittelee:

<a id="section-3-subsection-2"></a>
#### \(2\)

<a id="section-3-subsection-2-paragraph-1"></a>
- **1.** valtioneuvoston kanslia, joka on pääministerin alainen, asiat, jotka koskevat valtiopäivistä johtuvia muodollisia toimenpiteitä, valtioneuvostoa sekä asiain käsittelyjärjestystä valtion yleistä tilastoa ja valtion julkaisutoimintaa, sekä sellaiset muut valtioneuvostossa käsiteltävät asiat, jotka eivät kohdistu minkään ministeriön toimialaan;

<a id="section-3-subsection-2-paragraph-2"></a>
- **2.** ulkoasininministeriö asiat, jotka johtuvat Suomen suhteista ulkovaltoihin;

<a id="section-3-subsection-2-paragraph-3"></a>
- **3.** olkeusministeriö asiat, jotka koskevat oikeudenhoitoa, lainsäädäntöä asioissa, jotka eivät kuulu muun ministeriön toimialaan, sekä vankeinhoitoa, niin myös valtiollisia vaaleja;

<a id="section-3-subsection-2-paragraph-4"></a>
- **4.** sisänsiainministeriö asiat, jotka koskevat yleistä järjestystä ja turvallisuutta, sisäistä hallintoa sekä yleistä terveydenhoitoa:

<a id="section-3-subsection-2-paragraph-5"></a>
- **5.** puolustusministeriö asiat, jotka koskevat valtakunnan puolustusta ja puolustusvoimia;

<a id="section-3-subsection-2-paragraph-6"></a>
- **6.** valtiovarainministeriö asiat, jotka koskevat valtion tulo\- ja menoarviota, maan rahalaitosta, raha\-asioita ja verotointa sekä maan talouselämän kehittämistä kansantalouden vaatimusten mukaan;

<a id="section-3-subsection-2-paragraph-7"></a>
- **7.** opetusministeriö asiat, jotka koskevat yleistä opetustointa, evankelis\-luterilaista ja kreikkalaiskatolista kirkkoa sekä muita uskonnollisia yhdyskuntia, tiedettä ja taidetta sekä urheilua;

<a id="section-3-subsection-2-paragraph-8"></a>
- **8.** maatalousministeriö asiat, jotka koskevat maataloutta, metsätaloutta, maanmittausta, asutustoimintaa, eläinlääkintää sekä metsästystä ja kalastusta;

<a id="section-3-subsection-2-paragraph-9"></a>
- **9.** kulkulaitosten ja yleisten töiden ministeriö asiat, jotka koskevat liikennettä, posti\- ja lennätinlaitosta, valtion koskia ja vesilaitoksia, valtion rakennustoimintaa sekä muita yleisiä töitä;

<a id="section-3-subsection-2-paragraph-10"></a>
- **10.** kauppa\- ja teollisuusministeriö asiat, jotka koskevat kauppaa, vuorityötä, teollisuutta ja ammattikasvatusta sekä merenkulkua;

<a id="section-3-subsection-2-paragraph-11"></a>
- **11.** sosiaaliministeriö asiat, jotka koskevat työoloja ja niiden yhteydessä olevia kysymyksiä, vakuutusta, köyhäinhoitoa, lastensuojelua, sosiaalitilastoa, siirtolaisuutta sekä raittiustyötä ja väkijuomia; sekä

<a id="section-3-subsection-2-paragraph-12"></a>
- **12.** kansanhuoltoministeriö, milloin se on asetettu, asiat, jotka koskevat väestön toimeentulon turvaamista sekä talouselämän ja työvoiman käytön säännöstelyä sodan tai muun poikkeuksellisen tilanteen aikana ja niitä tarkoittavia valmisteluja, mikäli niitä ei ole jätetty jollekin muulle ministeriölle\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Tarkempia säännöksiä asioiden jakautumisesta valtioneuvoston kanslian ja ministeriöiden kesken annetaan asetuksella\.

<a id="section-4"></a>
### 4§

<a id="section-4-subsection-1"></a>
#### \(1\)

Jos syntyy epäilystä siitä, minkä ministeriön käsiteltäviin joku asia kuuluu, ratkaisee kysymyksen valtioneuvosto\.

<a id="section-5"></a>
### 5§

<a id="section-5-subsection-1"></a>
#### \(1\)

Ministeriö voidaan jakaa osastoihin, milloin sellainen ministeriön alaan kuuluvien tehtävien järjestely havaitaan tarpeelliseksi\. Tarkempia säännöksiä tästä annetaan asetuksella\.
