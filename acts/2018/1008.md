<a id="section-5"></a>
### 5 § Toimivaltaiset viranomaiset

<a id="section-5-subsection-1"></a>
#### \(1\)

Vaaratiedotteen saa antaa:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** pelastuslain \(379/2011\) 26 §:ssä tarkoitettu pelastusviranomainen;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** poliisilaitos;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** rajavartiolaitoksen hallinnosta annetun lain \(577/2005\) 4 §:ssä tarkoitettu rajavartioviranomainen;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** Hätäkeskuslaitos;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** Poliisihallitus;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** poliisin hallinnosta annetun lain \(110/1992\) 1 §:n 2 momentissa tarkoitettu Poliisihallituksen alainen valtakunnallinen yksikkö;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** Säteilyturvakeskus;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** Ilmatieteen laitos;

<a id="section-5-subsection-1-paragraph-9"></a>
- **9.** Väylävirasto;

<a id="section-5-subsection-1-paragraph-10"></a>
- **10.** Liikenne\- ja viestintävirasto;

<a id="section-5-subsection-1-paragraph-11"></a>
- **11.** Elintarviketurvallisuusvirasto;

<a id="section-5-subsection-1-paragraph-12"></a>
- **12.** Sosiaali\- ja terveysalan lupa\- ja valvontavirasto;

<a id="section-5-subsection-1-paragraph-13"></a>
- **13.** Lääkealan turvallisuus\- ja kehittämiskeskus;

<a id="section-5-subsection-1-paragraph-14"></a>
- **14.** ministeriö\.
