### 3 § Rajavartiopukineet

<a id="section-3-subsection-1"></a>
#### \(1\)

Rajavartiopukineisiin kuuluvat seuraavat asustekokonaisuudet:

<a id="section-3-subsection-2"></a>
#### \(2\)

Palveluspuku

<a id="section-3-subsection-3"></a>
#### \(3\)

Palveluspukuun kuuluvia asusteita ovat:

<a id="section-3-subsection-3-paragraph-1"></a>
- **1.** pusero, miesten ja naisten malli;

<a id="section-3-subsection-3-paragraph-2"></a>
- **2.** housut, yhteiskäytössä vierailupuvun kanssa, miesten ja naisten malli;

<a id="section-3-subsection-3-paragraph-3"></a>
- **3.** päällystakki, 3/4\-malli, yhteiskäytössä vierailupuvun kanssa, miesten ja naisten malli;

<a id="section-3-subsection-3-paragraph-4"></a>
- **4.** hame, yhteiskäytössä vierailupuvun kanssa;

<a id="section-3-subsection-3-paragraph-5"></a>
- **5.** paitapusero, valkoinen lyhythihainen ja pitkähihainen, miesten ja naisten malli;

<a id="section-3-subsection-3-paragraph-6"></a>
- **6.** tummanvihreä solmio;

<a id="section-3-subsection-3-paragraph-7"></a>
- **7.** palveluspuvun lippalakki;

<a id="section-3-subsection-3-paragraph-8"></a>
- **8.** suikkalakki;

<a id="section-3-subsection-3-paragraph-9"></a>
- **9.** nahkapäällysteinen turkislakki;

<a id="section-3-subsection-3-paragraph-10"></a>
- **10.** mustat puolikengät;

<a id="section-3-subsection-3-paragraph-11"></a>
- **11.** musta vyö\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Palveluspukuun kiinnitetään rajajoukkomerkki, rintamerkki sekä erikoismerkkejä\.

<a id="section-3-subsection-5"></a>
#### \(5\)

Palveluspuvun kanssa voidaan käyttää tarvittaessa kenttävaatetukseen kuuluvaa kylmäsuojapuvun takkia ja housuja sekä kuoripuvun takkia ja housuja sekä sadepukua samoin kuin suojavaatetuksen erityisasusteita kyseisen tehtävän keston ajan\.

<a id="section-3-subsection-7-paragraph-18"></a>
- **18.** kuoripuvun takki;

<a id="section-3-subsection-7-paragraph-19"></a>

<a id="section-3-subsection-8"></a>
#### \(8\)

Kenttävaatetukseen kiinnitetään pukukohtaisesti:

<a id="section-3-subsection-8-paragraph-1"></a>
- **1.** rajavartiomiehen tunnus;

<a id="section-3-subsection-8-paragraph-2"></a>
- **2.** arvomerkit;

<a id="section-3-subsection-8-paragraph-3"></a>
- **3.** erikoismerkit;

#### \(9\)

Kenttävaatetuksen kanssa voidaan käyttää tarvittaessa palvelus\- tai vierailupukuun kuuluvaa turkislakkia\.

<a id="section-3-subsection-10"></a>
#### \(10\)

Vierailupuku

<a id="section-3-subsection-11"></a>
#### \(11\)

<a id="section-3-subsection-11-paragraph-1"></a>
- **1.** päältä valkoinen lippalakki \(merivartiostot, Vartiolentolaivue\);

<a id="section-3-subsection-11-paragraph-2"></a>
- **2.** päältä vihreä lippalakki \(rajavartiostot, Vartiolentolaivue\);

<a id="section-3-subsection-11-paragraph-3"></a>
- **3.** musta nahkapäällysteinen turkislakki;

<a id="section-3-subsection-11-paragraph-4"></a>
- **4.** päällystakki, miesten ja naisten malli;

<a id="section-3-subsection-11-paragraph-5"></a>
- **5.** päällystakki, 3/4\-malli, yhteiskäytössä palveluspuvun kanssa, miesten ja naisten malli;

<a id="section-3-subsection-11-paragraph-6"></a>
- **6.** musta kaulahuivi;

<a id="section-3-subsection-11-paragraph-7"></a>
- **7.** vihreä, musta tai sininen solmio;

<a id="section-3-subsection-11-paragraph-8"></a>
- **8.** takki, miesten ja naisten malli;

<a id="section-3-subsection-11-paragraph-9"></a>
- **9.** housut, yhteiskäytössä palveluspuvun kanssa, miesten ja naisten malli;

<a id="section-3-subsection-11-paragraph-10"></a>
- **10.** hame, yhteiskäytössä palveluspuvun kanssa;

<a id="section-3-subsection-11-paragraph-11"></a>
- **11.** vihreä solmukeliina, naisten malli;

<a id="section-3-subsection-11-paragraph-12"></a>
- **12.** valkoinen paitapusero, lyhythihainen ja pitkähihainen, miesten ja naisten malli;

<a id="section-3-subsection-11-paragraph-13"></a>
- **13.** mustat sileät nahkasormikkaat;

<a id="section-3-subsection-11-paragraph-14"></a>
- **14.** musta vyö;

<a id="section-3-subsection-11-paragraph-15"></a>
- **15.** mustat puolikengät;

<a id="section-3-subsection-11-paragraph-16"></a>
- **16.** mustat sukat;

<a id="section-3-subsection-11-paragraph-17"></a>
- **17.** naisilla lisäksi ihonväriset sukkahousut sekä avokkaat tai talvisaapikkaat\.

<a id="section-3-subsection-12"></a>
#### \(12\)

Käytettäessä vierailupukua paraatipukuna kiinnitetään siihen tarvittavat kunniamerkit sekä yleisesikuntaupseerin olkanauhat\.

<a id="section-3-subsection-13"></a>
#### \(13\)

Juhlapuku

<a id="section-3-subsection-14"></a>
#### \(14\)

Rajavartiolaitoksen sotilasvirassa palvelevan virkamiehen juhlapukuna on puolustusvoimista annetun lain 45 §:n ja sen nojalla annettujen määräysten mukainen juhlapuku, pieni juhlapuku tai messipuku\. Raja\- ja merivartijan juhlapuku on vierailupuku\. Kenraalit ja amiraalit käyttävät valkoista turkislakkia juhla\- ja paraatipuvuissa\.

<a id="section-4"></a>
### 4 § Virkapukineet

<a id="section-4-subsection-1"></a>
#### \(1\)

Virkapukine on muille kuin sotilasvirassa palveleville Rajavartiolaitoksen virkamiehille tarkoitettu rajavartiopukine ilman rajavartiomiehen tunnusta tai arvomerkkejä\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Virkapukineeseen kiinnitetään pukukohtaisesti rintamerkki\. Virkapukineiden päähineissä käytetään lakkimerkkejä ja kokardeja\.

### 6 § Suojapukineet

#### \(1\)

- **1.** suojaliivit;

- **2.** luotisuojapuvut;

- **3.** merellinen suoja\-asu;

<a id="section-6-subsection-1-paragraph-4"></a>
- **4.** sadepuku;

<a id="section-6-subsection-1-paragraph-6"></a>
- **6.** lentohenkilöstön erityissuojapuvut;

<a id="section-6-subsection-1-paragraph-7"></a>
- **7.** heijastinliivi;

<a id="section-6-subsection-1-paragraph-8"></a>
- **8.** viiltosuojahansikkaat;

<a id="section-6-subsection-1-paragraph-9"></a>
- **9.** suoja\- ja turvajalkineet;

<a id="section-6-subsection-1-paragraph-10"></a>
- **10.** suojakypärä;

<a id="section-6-subsection-1-paragraph-11"></a>
- **11.** pelastuspukineet;

<a id="section-6-subsection-1-paragraph-12"></a>
- **12.** siviilitehtävissä palvelevien suojapuvut;

<a id="section-6-subsection-1-paragraph-13"></a>
- **13.** suojapuvut ja \-haalarit\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Suojapukineeseen voidaan tarvittaessa kiinnittää rajavartiomiehen tunnus, arvomerkit ja erikoismerkkejä\.
