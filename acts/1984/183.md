## 1 luku Väestörekisterikeskus

<a id="chapter-1-section-1"></a>
### 1§

<a id="chapter-1-section-1-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksesta annetun lain \(76/84\) 3§:ssä säädettyjen tehtäviensä toteuttamiseksi väestörekisterikeskuksen tulee:

<a id="chapter-1-section-1-subsection-1-paragraph-1"></a>
- **1.** ohjata ja valvoa väestökirjahallinnon paikallisviranomaisten tehtävien suorittamista sekä paikallisviranomaisten välityksellä evankelis\-luterilaisen kirkon ja ortodoksisen kirkkokunnan seurakuntia ja muita kirkollisia väestörekisterin pitäjiä väestörekisterin pitämistä koskevissa asioissa;

<a id="chapter-1-section-1-subsection-1-paragraph-2"></a>
- **2.** huolehtia väestökirjanpidon yleisestä kehittämisestä;

<a id="chapter-1-section-1-subsection-1-paragraph-3"></a>
- **3.** pitää väestön keskusrekisteriä ja antaa siitä viranomaisille, yhteisöille sekä yksityisille henkilöille todistuksia, otteita, jäljennöksiä ja muita tietoja; sekä

<a id="chapter-1-section-1-subsection-1-paragraph-4"></a>
- **4.** suorittaa ne muut tehtävät, jotka sille lakien, asetusten ja niiden nojalla annettujen määräysten mukaan kuuluvat\.

<a id="chapter-1-section-2"></a>
### 2§

<a id="chapter-1-section-2-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksessa on hallinto\-osasto, rekisteriosasto ja järjestelmäosasto\. Osastot voivat jakaantua yksikköihin ja jaostoihin\.

<a id="chapter-1-section-2-subsection-2"></a>
#### \(2\)

Yksiköistä ja jaostoista sekä niiden työtehtävistä määrätään työjärjestyksessä\. Työjärjestyksen vahvistaa väestörekisterikeskus\.

<a id="chapter-1-section-3"></a>
### 3§

<a id="chapter-1-section-3-subsection-1"></a>
#### \(1\)

Hallinto\-osasto käsittelee asiat, jotka koskevat:

<a id="chapter-1-section-3-subsection-1-paragraph-1"></a>
- **1.** väestörekisterikeskuksen toimialaan kuuluvia säädöksiä;

<a id="chapter-1-section-3-subsection-1-paragraph-2"></a>
- **2.** sopimusten tekemistä;

<a id="chapter-1-section-3-subsection-1-paragraph-3"></a>
- **3.** väestörekisterikeskuksen työjärjestystä;

<a id="chapter-1-section-3-subsection-1-paragraph-4"></a>
- **4.** henkilöstöhallintoa;

<a id="chapter-1-section-3-subsection-1-paragraph-5"></a>
- **5.** tulo\- ja menoarviota, toiminta\- ja taloussuunnittelua sekä väestörekisterikeskukselle tilivirastona kuuluvia tehtäviä;

<a id="chapter-1-section-3-subsection-1-paragraph-6"></a>
- **6.** tekstinkäsittelyä, asiakirjojen kirjaamista ja arkistointia;

<a id="chapter-1-section-3-subsection-1-paragraph-7"></a>
- **7.** tietojen luovuttamista väestön keskusrekisteristä;

<a id="chapter-1-section-3-subsection-1-paragraph-8"></a>
- **8.** vaalipiirien vaaliluetteloiden vahvistamista;

<a id="chapter-1-section-3-subsection-1-paragraph-9"></a>
- **9.** tiedottamista; sekä

<a id="chapter-1-section-3-subsection-1-paragraph-10"></a>
- **10.** tehtäviä, joita ei ole säädetty tai määrätty muiden osastojen hoidettavaksi\.

<a id="chapter-1-section-4"></a>
### 4§

<a id="chapter-1-section-4-subsection-1"></a>
#### \(1\)

Rekisteriosasto käsittelee asiat, jotka koskevat:

<a id="chapter-1-section-4-subsection-1-paragraph-1"></a>
- **1.** väestökirjahallinnon paikallisviranomaisten ohjausta, valvontaa ja neuvontaa;

<a id="chapter-1-section-4-subsection-1-paragraph-2"></a>
- **2.** väestökirjoissa ja niihin kuuluvissa asiakirjoissa olevien tietojen suojausta;

<a id="chapter-1-section-4-subsection-1-paragraph-3"></a>
- **3.** väestön keskusrekisterin pitoon liittyvien ilmoitusten käsittelyä ja tietojen tallentamista; sekä

<a id="chapter-1-section-4-subsection-1-paragraph-4"></a>
- **4.** väestökirjanpitoon liittyvien luetteloiden, kortistojen ja muiden vastaavien asiakirjojen sekä vaaliasiakirjojen valmistamista\.

<a id="chapter-1-section-5"></a>
### 5§

<a id="chapter-1-section-5-subsection-1"></a>
#### \(1\)

Järjestelmäosasto käsittelee asiat, jotka koskevat:

<a id="chapter-1-section-5-subsection-1-paragraph-1"></a>
- **1.** väestökirjanpidon menetelmiä ja tietoaineistoa;

<a id="chapter-1-section-5-subsection-1-paragraph-2"></a>
- **2.** automaattista tietojenkäsittelyä;

<a id="chapter-1-section-5-subsection-1-paragraph-3"></a>
- **3.** väestökirjoissa olevien tietojen hyväksikäyttöä;

<a id="chapter-1-section-5-subsection-1-paragraph-4"></a>
- **4.** laitteistohankintoja; sekä

<a id="chapter-1-section-5-subsection-1-paragraph-5"></a>
- **5.** väestökirjanpitoon liittyvien ohjeistojen ja lomakkeiden suunnittelua sekä painatusta\.

<a id="chapter-1-section-6"></a>
### 6 §

<a id="chapter-1-section-6-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksessa on ylijohtajan virka sekä osastopäällikön, ylitarkastajan, erikoissuunnittelijan, tarkastajan, esittelijän ja suunnittelijan virkoja\.

<a id="chapter-1-section-6-subsection-2"></a>
#### \(2\)

Väestörekisterikeskukseen voidaan tulo\- ja menoarvion rajoissa ottaa myös muita vakinaisia ja tilapäisiä virkamiehiä sekä työsopimussuhteessa olevaa henkilöstöä\.

<a id="chapter-1-section-7"></a>
### 7§

<a id="chapter-1-section-7-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksen päällikkönä on ylijohtaja\.

<a id="chapter-1-section-7-subsection-2"></a>
#### \(2\)

Ylijohtajan tehtävänä on:

<a id="chapter-1-section-7-subsection-2-paragraph-1"></a>
- **1.** johtaa ja kehittää väestörekisterikeskuksen toimintaa sekä valvoa, että sille kuuluvat tehtävät suoritetaan taloudellisesti, tehokkaasti ja tarkoituksenmukaisesti;

<a id="chapter-1-section-7-subsection-2-paragraph-2"></a>
- **2.** seurata yleistä kehitystä väestörekisterikeskuksen toimialalla; sekä

<a id="chapter-1-section-7-subsection-2-paragraph-3"></a>
- **3.** ylläpitää ja edistää väestörekisterikeskuksen yhteistoimintaa muiden virastojen ja laitosten sekä väestökirjanpidon ja siihen liittyvien muiden tehtävien kannalta tärkeiden yhteisöjen kanssa\.

<a id="chapter-1-section-8"></a>
### 8§

<a id="chapter-1-section-8-subsection-1"></a>
#### \(1\)

Kunkin osaston päällikkönä on osastopäällikkö\.

<a id="chapter-1-section-8-subsection-2"></a>
#### \(2\)

Osastopäällikön tehtävänä on:

<a id="chapter-1-section-8-subsection-2-paragraph-1"></a>
- **1.** johtaa, kehittää ja valvoa osaston toimintaa ja sen toimialaan kuuluvien asioiden hoitoa;

<a id="chapter-1-section-8-subsection-2-paragraph-2"></a>
- **2.** jakaa tehtävät osaston henkilöstölle ja käsitellä itse tärkeimmät osastolle kuuluvat asiat; sekä

<a id="chapter-1-section-8-subsection-2-paragraph-3"></a>
- **3.** huolehtia siitä, että osastolle kuuluvat asiat käsitellään tehokkaasti\.

<a id="chapter-1-section-9"></a>
### 9 §

<a id="chapter-1-section-9-subsection-1"></a>
#### \(1\)

Ylijohtajan ja osastopäällikön tehtävistä voidaan antaa täydentäviä määräyksiä työjärjestyksessä\.

<a id="chapter-1-section-9-subsection-2"></a>
#### \(2\)

Väestörekisterikeskuksen muiden virkamiesten sekä työntekijöiden tehtävistä voidaan määrätä työjärjestyksessä\.

<a id="chapter-1-section-10"></a>
### 10§

<a id="chapter-1-section-10-subsection-1"></a>
#### \(1\)

Väestörekisterikeskukselle kuuluvat asiat ratkaisee ylijohtaja tai muu viraston virkamies esittelystä, jollei työjärjestyksessä toisin määrätä\.

<a id="chapter-1-section-11"></a>
### 11§

<a id="chapter-1-section-11-subsection-1"></a>
#### \(1\)

Ylijohtaja ratkaisee asiat, joita työjärjestyksessä ei ole annettu viraston muun virkamiehen ratkaistavaksi\.

<a id="chapter-1-section-11-subsection-2"></a>
#### \(2\)

Ylijohtaja voi, jos hän katsoo asian laadun sitä vaativan, ottaa yksittäistapauksessa ratkaistavakseen myös sellaisen asian, joka olisi muun virkamiehen ratkaistava\.

<a id="chapter-1-section-12"></a>
### 12§

<a id="chapter-1-section-12-subsection-1"></a>
#### \(1\)

Ylijohtajan ollessa estynyt toimii hänen sijaisenaan hallinto\-osaston osastopäällikkö ja tämänkin ollessa estyneenä rekisteriosaston osastopäällikkö\. Muiden virkamiesten sijaiset määrää ylijohtaja\.

<a id="chapter-1-section-13"></a>
### 13 §

<a id="chapter-1-section-13-subsection-1"></a>
#### \(1\)

Ylijohtajan poissa ollessa ei ilman painavia syitä saa ryhtyä sellaisiin toimenpiteisiin, jotka saattavat poiketa hänen toiminnassaan noudattamista periaatteista\. Ylijohtajan poissa ollessa ei ilman hänen suostumustaan myöskään saa täyttää virkoja eikä tehdä esitystä avoinna olevan viran täyttämisestä\.

<a id="chapter-2"></a>
## 2 luku Rekisteritoimistot

<a id="chapter-2-section-14"></a>
### 14§

<a id="chapter-2-section-14-subsection-1"></a>
#### \(1\)

Rekisteritoimisto on kihlakunnan alueella toimiva väestökirjahallinnon paikallisviranomainen\. Rekisteritoimisto on väestökirjanpidon hoitamista koskevissa tehtävissään väestörekisterikeskuksen alainen ja muissa tehtävissään lääninhallituksen alainen\.

<a id="chapter-2-section-14-subsection-2"></a>
#### \(2\)

Rekisteritoimiston tehtävänä väestökirjahallinnon paikallisviranomaisena on:

<a id="chapter-2-section-14-subsection-2-paragraph-1"></a>
- **1.** pitää kihlakuntaan kuuluvien kuntien asukkaista paikallisia väestökirjoja, lukuun ottamatta evankelis\-luterilaisen kirkon ja ortodoksisen kirkkokunnan jäseniä koskevaa väestörekisteriä;

<a id="chapter-2-section-14-subsection-2-paragraph-2"></a>
- **2.** ohjata ja valvoa kihlakunnan alueella evankelis\-luterilaisen kirkon ja ortodoksisen kirkkokunnan seurakuntia ja muita kirkollisia väestörekisterin pitäjiä väestörekisterin pitämistä koskevissa asioissa; sekä

<a id="chapter-2-section-14-subsection-2-paragraph-3"></a>
- **3.** suorittaa ne muut väestökirjanpitoon liittyvät tehtävät, jotka sille lakien ja asetusten sekä niiden nojalla annettujen määräysten mukaan kuuluvat\.

<a id="chapter-2-section-15"></a>
### 15§

<a id="chapter-2-section-15-subsection-1"></a>
#### \(1\)

Rekisteritoimiston tehtävänä on lisäksi:

<a id="chapter-2-section-15-subsection-1-paragraph-1"></a>
- **1.** toimia kaupparekisteriasioiden paikallisviranomaisena;

<a id="chapter-2-section-15-subsection-1-paragraph-2"></a>
- **2.** toimia yhdistysrekisteriasioiden paikallisviranomaisena; sekä

<a id="chapter-2-section-15-subsection-1-paragraph-3"></a>
- **3.** suorittaa ne tehtävät, jotka ennen väestökirjahallinnosta annetun lain voimaantuloa annetuissa laeissa ja asetuksissa on säädetty henkikirjoittajalle mutta jotka lain 11§:n nojalla kuuluvat rekisteritoimistolle\.

<a id="chapter-2-section-16"></a>
### 16§

<a id="chapter-2-section-16-subsection-1"></a>
#### \(1\)

Tarkemmat määräykset asioiden käsittelystä rekisteritoimistossa, toimiston muusta toiminnasta sekä henkilöstön tehtävistä voidaan antaa työjärjestyksessä\.

<a id="chapter-2-section-16-subsection-2"></a>
#### \(2\)

Työjärjestyksen vahvistaa rekisteritoimiston esityksestä se lääninhallitus, jonka alainen rekisteritoimisto on, sisäasiainministeriön antamien yleisten ohjeiden mukaan\.

<a id="chapter-2-section-17"></a>
### 17 §

<a id="chapter-2-section-17-subsection-1"></a>
#### \(1\)

Rekisteritoimistossa on henkikirjoittajan ja tarkastajan virkoja\.

<a id="chapter-2-section-17-subsection-2"></a>
#### \(2\)

Rekisteritoimistoon voidaan tulo\- ja menoarvion rajoissa ottaa myös muita vakinaisia ja tilapäisiä virkamiehiä sekä työsopimussuhteessa olevaa henkilöstöä\.

<a id="chapter-2-section-18"></a>
### 18§

<a id="chapter-2-section-18-subsection-1"></a>
#### \(1\)

Rekisteritoimiston päällikkönä on henkikirjoittaja\. Milloin rekisteritoimistossa on useampia henkikirjoittajia, päällikkönä toimii lääninhallituksen siihen määräämä henkikirjoittaja\.

<a id="chapter-2-section-18-subsection-2"></a>
#### \(2\)

Henkikirjoittajan tehtävänä rekisteritoimiston päällikkönä on:

<a id="chapter-2-section-18-subsection-2-paragraph-1"></a>
- **1.** johtaa, kehittää ja valvoa rekisteritoimiston toimintaa ja sille kuuluvien asioiden hoitoa;

<a id="chapter-2-section-18-subsection-2-paragraph-2"></a>
- **2.** jakaa tehtävät rekisteritoimiston henkilöstölle ja käsitellä itse tärkeimmät rekisteritoimistolle kuuluvat asiat; sekä

<a id="chapter-2-section-18-subsection-2-paragraph-3"></a>
- **3.** huolehtia siitä, että rekisteritoimistolle kuuluvat asiat käsitellään tehokkaasti\.

<a id="chapter-2-section-19"></a>
### 19§

<a id="chapter-2-section-19-subsection-1"></a>
#### \(1\)

Henkikirjoittajan tehtävänä on lisäksi:

<a id="chapter-2-section-19-subsection-1-paragraph-1"></a>
- **1.** toimia vihkimisviranomaisena siviiliavioliittoja päätettäessä;

<a id="chapter-2-section-19-subsection-1-paragraph-2"></a>
- **2.** toimia julkisena notaarina;

<a id="chapter-2-section-19-subsection-1-paragraph-3"></a>
- **3.** toimia julkisena kaupanvahvistajana; sekä

<a id="chapter-2-section-19-subsection-1-paragraph-4"></a>
- **4.** suorittaa ne tehtävät, jotka ennen väestökirjahallinnosta annetun lain voimaantuloa annetuissa laeissa ja asetuksissa on säädetty henkikirjoittajalle ja jotka lain 11§:n nojalla edelleen kuuluvat henkikirjoittajalle\.

<a id="chapter-2-section-20"></a>
### 20 §

<a id="chapter-2-section-20-subsection-1"></a>
#### \(1\)

Rekisteritoimistolle kuuluvat asiat ratkaisee sen päällikkönä toimiva henkikirjoittaja, joka myös allekirjoittaa rekisteritoimiston toimituskirjat\.

<a id="chapter-2-section-20-subsection-2"></a>
#### \(2\)

Milloin työjärjestyksessä ei ole asiasta määrätty, lääninhallitus voi rekisteritoimiston esityksestä määrätä rekisteritoimiston muun virkamiehen päällikkönä toimivan henkikirjoittajan sijasta antamaan ja allekirjoittamaan määrätynlaisia rekisteritoimistosta annettavia todistuksia ja muita asiakirjoja\.

<a id="chapter-2-section-20-subsection-3"></a>
#### \(3\)

Jos päällikkönä toimiva henkikirjoittaja ja 2 momentissa tarkoitettu virkamies ovat molemmat esteellisiä antamaan todistuksen tai muun asiakirjan, on päällikkönä toimivan henkikirjoittajan allekirjoitettava asiakirja, minkä jälkeen rekisteritoimiston esteettömän virkamiehen tai työsopimussuhteessa olevan henkilön on todistettava se yhtäpitäväksi sen aineiston kanssa, jonka perusteella asiakirja annetaan\.

<a id="chapter-2-section-21"></a>
### 21 §

<a id="chapter-2-section-21-subsection-1"></a>
#### \(1\)

Rekisteritoimiston päällikkönä toimivan henkikirjoittajan ollessa estynyt toimii hänen sijaisenaan lääninhallituksen siihen määräämä henkikirjoittaja tai tarkastaja taikka muu virkamies\. Rekisteritoimiston muiden virkamiesten sijaiset määrää rekisteritoimiston päällikkönä toimiva henkikirjoittaja\.

<a id="chapter-3"></a>
## 3 luku Virkojen kelpoisuusvaatimukset, virkojen täyttäminen sekä virkavapaus

<a id="chapter-3-section-22"></a>
### 22§

<a id="chapter-3-section-22-subsection-1"></a>
#### \(1\)

Kelpoisuusvaatimuksena väestörekisterikeskuksen ja rekisteritoimiston virkoihin on sellainen taito ja kyky, jota viran menestyksellinen hoitaminen edellyttää\.

<a id="chapter-3-section-22-subsection-2"></a>
#### \(2\)

Lisäksi vaaditaan väestörekisterikeskuksessa:

<a id="chapter-3-section-22-subsection-2-paragraph-1"></a>
- **1.** ylijohtajalta oikeustieteen kandidaatin tutkinto sekä hyvä perehtyneisyys hallinto\- ja väestökirjanpitotehtäviin;

<a id="chapter-3-section-22-subsection-2-paragraph-2"></a>
- **2.** hallinto\-osaston osastopäälliköltä oikeustieteen kandidaatin tutkinto, hyvä perehtyneisyys hallintotehtäviin sekä väestökirjanpidon tuntemusta;

<a id="chapter-3-section-22-subsection-2-paragraph-3"></a>
- **3.** rekisteriosaston osastopäälliköltä oikeustieteen kandidaatin tutkinto, hyvä perehtyneisyys väestökirjanpitoon sekä perehtyneisyyttä hallintotehtäviin ja automaattiseen tietojenkäsittelyyn;

<a id="chapter-3-section-22-subsection-2-paragraph-4"></a>
- **4.** järjestelmäosaston osastopäälliköltä virkaan soveltuva ylempi korkeakoulututkinto, hyvä perehtyneisyys automaattiseen tietojenkäsittelyyn sekä perehtyneisyyttä väestökirjanpitoon;

<a id="chapter-3-section-22-subsection-2-paragraph-5"></a>
- **5.** ylitarkastajalta virkaan soveltuva ylempi korkeakoulututkinto ja perehtyneisyyttä hallintotehtäviin;

<a id="chapter-3-section-22-subsection-2-paragraph-6"></a>
- **6.** erikoissuunnittelijalta virkaan soveltuva ylempi korkeakoulututkinto sekä perehtyneisyyttä automaattiseen tietojenkäsittelyyn ja väestökirjanpitoon;

<a id="chapter-3-section-22-subsection-2-paragraph-7"></a>
- **7.** tarkastajalta oikeustieteen kandidaatin tutkinto ja perehtyneisyyttä hallintotehtäviin;

<a id="chapter-3-section-22-subsection-2-paragraph-8"></a>
- **8.** esittelijältä virkaan soveltuva ylempi korkeakoulututkinto ja perehtyneisyyttä hallintotehtäviin; sekä

<a id="chapter-3-section-22-subsection-2-paragraph-9"></a>
- **9.** suunnittelijalta virkaan soveltuva korkeakoulututkinto\.

<a id="chapter-3-section-22-subsection-3"></a>
#### \(3\)

Rekisteritoimistossa vaaditaan sen lisäksi, mitä 1 momentissa on säädetty:

<a id="chapter-3-section-22-subsection-3-paragraph-1"></a>
- **1.** henkikirjoittajalta oikeustieteen kandidaatin tutkinto, rekisteröintitehtävien tuntemusta sekä perehtyneisyyttä hallintotehtäviin; sekä

<a id="chapter-3-section-22-subsection-3-paragraph-2"></a>
- **2.** tarkastajalta virkaan soveltuva korkeakoulututkinto\.

<a id="chapter-3-section-23"></a>
### 23§

<a id="chapter-3-section-23-subsection-1"></a>
#### \(1\)

Ylijohtajan nimittää tasavallan presidentti valtioneuvoston esityksestä\.

<a id="chapter-3-section-23-subsection-2"></a>
#### \(2\)

Osastopäällikön nimittää sisäasiainministeriö väestörekisterikeskuksen annettua lausuntonsa hakijoista\.

<a id="chapter-3-section-23-subsection-3"></a>
#### \(3\)

Muut väestörekisterikeskuksen virat täyttää ja muun henkilöstön ottaa väestörekisterikeskus\.

<a id="chapter-3-section-24"></a>
### 24§

<a id="chapter-3-section-24-subsection-1"></a>
#### \(1\)

Henkikirjoittajan nimittää lääninhallitus väestörekisterikeskuksen annettua lausuntonsa hakijoista\.

<a id="chapter-3-section-24-subsection-2"></a>
#### \(2\)

Tarkastajan nimittää lääninhallitus rekisteritoimiston annettua lausuntonsa hakijoista\.

<a id="chapter-3-section-24-subsection-3"></a>
#### \(3\)

Muut rekisteritoimiston virat täyttää ja muun henkilöstön ottaa rekisteritoimisto\.

<a id="chapter-3-section-25"></a>
### 25 §

<a id="chapter-3-section-25-subsection-1"></a>
#### \(1\)

Ylijohtajalle myöntää virkavapauden sisäasiainministeriö ja osastopäällikölle väestörekisterikeskus, jos kyse on virkavapaudesta, jonka saamiseen virkamiehellä on lain tai virkaehtosopimuksen nojalla oikeus taikka jos kyse on enintään yhden vuoden kestävästä harkinnanvaraisesta virkavapaudesta\. Yli vuoden kestävän harkinnanvaraisen virkavapauden myöntämisestä ylijohtajalle päättää valtioneuvosto ja osastopäällikölle sisäasiainministeriö\.

<a id="chapter-3-section-25-subsection-2"></a>
#### \(2\)

Muille väestörekisterikeskuksen virkamiehille myöntää virkavapauden väestörekisterikeskus\.

<a id="chapter-3-section-26"></a>
### 26 §

<a id="chapter-3-section-26-subsection-1"></a>
#### \(1\)

Henkikirjoittajalle ja tarkastajalle myöntää virkavapauden lääninhallitus\. Muille rekisteritoimiston virkamiehille myöntää virkavapauden rekisteritoimisto\.

<a id="chapter-3-section-27"></a>
### 27 §

<a id="chapter-3-section-27-subsection-1"></a>
#### \(1\)

Viran väliaikaisen hoitajan ottaa sama viranomainen, joka päättää virkavapauden myöntämisestä\.

<a id="chapter-4"></a>
## 4 luku Erinäisiä säännöksiä

<a id="chapter-4-section-30"></a>
### 30§

<a id="chapter-4-section-30-subsection-1"></a>
#### \(1\)

Rekisteritoimiston tulee sijaita lääninhallituksen hyväksymässä paikassa kihlakunnan alueella\. Erityisestä syystä toimisto voi sijaita myös kihlakunnan alueen ulkopuolella\.

<a id="chapter-4-section-34"></a>
### 34§

<a id="chapter-4-section-34-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksessa ja rekisteritoimistossa työskentelevän työsopimussuhteessa olevan henkilön on kirjallisesti vakuutettava olevansa sivullisille ilmaisematta väestökirjoissa olevia tietoja, jotka asian luonteen vuoksi tai sen mukaan kuin on säädetty, on pidettävä salassa\.

<a id="chapter-4-section-35"></a>
### 35§

<a id="chapter-4-section-35-subsection-1"></a>
#### \(1\)

Rekisteritoimiston on annettava toimintakertomuksensa väestörekisterikeskukselle ja lääninhallitukselle seuraavan vuoden helmikuun loppuun mennessä\.

<a id="chapter-4-section-35-subsection-2"></a>
#### \(2\)

Väestörekisterikeskuksen on annettava sisäasiainministeriölle kultakin kalenterivuodelta kertomus väestökirjahallinnosta seuraavan vuoden toukokuun loppuun mennessä\.

<a id="chapter-4-section-36"></a>
### 36§

<a id="chapter-4-section-36-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksen henkilöstön osallistumisesta sitä itseään koskevan päätöksenteon valmisteluun väestörekisterikeskuksessa määrätään virastodemokratiaohjesäännössä, jonka väestörekisterikeskus vahvistaa\.

<a id="chapter-4-section-37"></a>
### 37§

<a id="chapter-4-section-37-subsection-1"></a>
#### \(1\)

Väestökirjanpidon tehtävien hoitamista varten on sisäasiainministeriön apuna väestökirja\-asiain neuvottelukunta\.

<a id="chapter-4-section-37-subsection-2"></a>
#### \(2\)

Neuvottelukuntaan kutsuu valtioneuvosto kolmeksi vuodeksi kerrallaan puheenjohtajan ja enintään yhdeksän jäsentä siten, että sisäasiainministeriö, väestörekisterikeskus ja väestökirjahallinnon paikallisviranomaiset, evankelis\-luterilainen kirkko ja ortodoksinen kirkkokunta sekä kuntien keskusjärjestöt yhteisesti ovat edustettuina neuvottelukunnassa\. Neuvottelukuntaan voidaan myös kutsua sellaisen valtion viranomaisen edustaja, jonka kanssa väestökirjahallinnon viranomaiset ovat tehtävissään kiinteässä yhteistyössä\. Neuvottelukunnan jäsenille voidaan kutsua henkilökohtaiset varajäsenet\.

<a id="chapter-4-section-37-subsection-3"></a>
#### \(3\)

Neuvottelukunnan tehtävänä on:

<a id="chapter-4-section-37-subsection-3-paragraph-1"></a>
- **1.** tehdä sisäasiainministeriölle esityksiä ja antaa lausuntoja väestökirjanpidon kehittämiseen ja yhdenmukaistamiseen liittyvissä asioissa; sekä

<a id="chapter-4-section-37-subsection-3-paragraph-2"></a>
- **2.** suorittaa ne muut tehtävät, jotka sisäasiainministeriö sille määrää\.

<a id="chapter-4-section-38"></a>
### 38§

<a id="chapter-4-section-38-subsection-1"></a>
#### \(1\)

Tarkempia määräyksiä tämän asetuksen soveltamisesta antaa sisäasiainministeriö\.
