# Valtiovarainministeriön asetus Tilastokeskuksen suoritteiden maksullisuudesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja suoritteita, jotka Tilastokeskus hinnoittelee liiketaloudellisin perustein, ovat seuraavat tilauksesta toimitettavat tai saatavilla olevat suoritteet;

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** tilastoalan julkaisut ja lehdet;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** tutkimukset ja muut asiantuntijapalvelut;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** tutkimus\- ja muut aineistot;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** rekisteri\- ja tietokantapalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** tietotekniikkapalvelut;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Tilastokeskuksen hallinnassa olevien tilojen ja laitteiden käyttö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** kuolintodistusten jäljennökset lukuunottamatta kuolemansyyn selvittämisestä annetun lain \(459/1973\) 15 §:n 2 momentissa mainittuja;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** tilastoalan tieteellisen keskuskirjaston kaukolainapalvelut;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** muut edellä mainittuihin verrattavat palvelusuoritteet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2001 ja on voimassa 31 päivään joulukuuta 2001\.
