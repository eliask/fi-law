<a id="section-1"></a>
### 1 § Liiketaloudellisin perustein hinnoiteltavat suoritteet

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka valtion mielisairaalat hinnoittelevat liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** hoitovuorokausi;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** lääkärin todistus ja lausunto;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** mielentilatutkimuslausunto;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** muu oikeuspsykiatrinen lausunto;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** EEG\- ja EKG\-tutkimus;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** muut laboratoriotutkimukset;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** ulkopuolinen konsultointi, työnohjaus ja muut työsuoritukset;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** pesulapalvelut;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** ravintopalvelut;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** tilojen ja laitteiden käyttö ulkopuolisille;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** toimistopalvelut sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** maatilatalouden tuotteet ja palvelut sekä muut työsuoritukset\.

<a id="section-2"></a>
### 2 § Voimaantulo

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 17 päivänä tammikuuta 2000\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan valtion mielisairaaloiden suoritteiden maksullisuudesta 4 päivänä joulukuuta 1996 annettu sosiaali\- ja terveysministeriön päätös [\(973/1996\)](<https://www.finlex.fi/fi/lainsaadanto/1996/973>)\.
