<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä päätöstä sovelletaan niihin vaaralliseksi luokiteltuihin kemikaaleihin, josta valmistajan tai maahantuojan on toimitettava tiedot rekisteröitäviksi vaaraa aiheuttavia kemikaaleja koskevien tietojen toimittamisesta annetun sosiaali\- ja terveysministeriön päätöksen [\(377/1998\)](<https://www.finlex.fi/fi/lainsaadanto/1998/377>) mukaisesti\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Tätä päätöstä ei sovelleta torjunta\-ainelaissa [\(327/1969\)](<https://www.finlex.fi/fi/lainsaadanto/1969/327>) tarkoitettuihin torjunta\-aineisiin\.

<a id="section-2"></a>
### 2 § Tietojen ilmoittaminen

<a id="section-2-subsection-1"></a>
#### \(1\)

Valmistajan tai maahantuojan on toimitettava sosiaali\- ja terveydenhuollon tuotevalvontakeskukselle seuraavat tiedot:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** toiminnanharjoittajan nimi ja yhteystiedot;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** yhteyshenkilön nimi;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kemikaalin nimi sekä kemikaalirekisterin tuoterekisterin rekisteröintinumero, jos sellainen on kemikaalille annettu;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** valmistajan osalta kemikaalin vuotuinen valmistusmäärä; ja

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** maahantuojan osalta kemikaalin vuotuinen maahantuontimäärä\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Kemikaalin määrä ilmoitetaan seuraavan jaottelun mukaisesti:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** 0,1―1 tonni

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** 1―10 tonnia

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** 10―100 tonnia

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** 100―500 tonnia

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** 500―1000 tonnia

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** \> 1000 tonnia; jolloin ilmoitus annetaan ± 20 %:n tarkkuudella\.

<a id="section-3"></a>
### 3 § Tietojen ilmoittamisen ajankohta

<a id="section-3-subsection-1"></a>
#### \(1\)

Edellä 2 §:ssä tarkoitetut tiedot on toimitettava kultakin vuodelta seuraavan helmikuun loppuun mennessä\. Ensimmäisen kerran tiedot on toimitettava vuodelta 2001\. Sen jälkeen tiedot on toimitettava vain niiden muuttuessa\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Jos rekisteröidään uusi 1 §:ssä tarkoitettu kemikaali, tiedot on toimitettava rekisteröintiä seuraavan vuoden helmikuun loppuun mennessä\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2001\.
