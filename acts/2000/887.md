<a id="section-16"></a>
### 16 § Liikennepolitiikan osaston yksiköt

<a id="section-16-subsection-1"></a>
#### \(1\)

Liikennepolitiikan osastossa on seuraavat yksiköt:

<a id="section-16-subsection-1-paragraph-1"></a>
- **1.** liikenneväyläyksikkö;

<a id="section-16-subsection-1-paragraph-2"></a>
- **2.** henkilöliikenneyksikkö;

<a id="section-16-subsection-1-paragraph-3"></a>
- **3.** tavaraliikenneyksikkö;

<a id="section-16-subsection-1-paragraph-4"></a>
- **4.** rautatie\- ja ilmailuyksikkö;

<a id="section-16-subsection-1-paragraph-5"></a>
- **5.** merenkulkuyksikkö;

<a id="section-16-subsection-1-paragraph-6"></a>
- **6.** liikenneturvallisuus\- ja ympäristöyksikkö; sekä

<a id="section-16-subsection-1-paragraph-7"></a>
- **7.** vaarallisten aineiden kuljetusyksikkö\.

<a id="section-16-subsection-2"></a>
#### \(2\)

Lisäksi osastolla on liikenteen telematiikkaprojekti\.

<a id="section-22"></a>
### 22 § Liikenneturvallisuus\- ja ympäristöyksikkö

<a id="section-22-subsection-1"></a>
#### \(1\)

Liikenneturvallisuus\- ja ympäristöyksikössä käsitellään asiat, jotka koskevat:

<a id="section-22-subsection-1-paragraph-1"></a>
- **1.** liikenneturvallisuustyön koordinointia ja ohjausta;

<a id="section-22-subsection-1-paragraph-2"></a>
- **2.** tieliikenteessä käyttäytymistä ja liikennesääntöjä;

<a id="section-22-subsection-1-paragraph-3"></a>
- **3.** rautatieliikenteen yleistä liikenneturvallisuutta;

<a id="section-22-subsection-1-paragraph-4"></a>
- **4.** liikenneympäristön turvallisuutta ja liikenteen ohjausta;

<a id="section-22-subsection-1-paragraph-5"></a>
- **5.** kuljettajaopetusta, kuljettajantutkintoja ja ajokortteja;

<a id="section-22-subsection-1-paragraph-6"></a>
- **6.** Tiehallinnon tulosohjausta liikenneturvallisuuden osalta;

<a id="section-22-subsection-1-paragraph-7"></a>
- **7.** liikenteen ympäristökysymyksiä;

<a id="section-22-subsection-1-paragraph-8"></a>
- **8.** hallinnonalan virastojen ja laitosten tulosohjausta ympäristökysymysten osalta, mikäli asia ei kuulu muulle yksikölle;

<a id="section-22-subsection-1-paragraph-9"></a>
- **9.** tieliikenteessä käytettävien ajoneuvojen rakennetta, varusteita, katsastusta ja rekisteröintiä;

<a id="section-22-subsection-1-paragraph-10"></a>
- **10.** tieliikenteessä käytettävien ajoneuvojen massoja, mittoja, kuormitusta ja käyttöä;

<a id="section-22-subsection-1-paragraph-11"></a>
- **11.** tieliikenteessä käytettävien ajoneuvojen melu\- ja pakokaasupäästöjä;

<a id="section-22-subsection-1-paragraph-12"></a>
- **12.** Ajoneuvohallintokeskusta ja sen tulosohjausta yksikön toimialan osalta; sekä

<a id="section-22-subsection-1-paragraph-13"></a>
- **13.** Liikenneturvaa\.

<a id="section-58"></a>
### 58 § Liikennepolitiikan osaston osastopäällikkö

<a id="section-58-subsection-1"></a>
#### \(1\)

Liikennepolitiikan osaston osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="section-58-subsection-1-paragraph-1"></a>
- **1.** elinkeinon harjoittamisen oikeudesta annetun lain 4 §:ssä tarkoitettuja lupia;

<a id="section-58-subsection-1-paragraph-2"></a>
- **2.** merilain 5 luvun 6 §:ssä tarkoitettua poikkeusta laivaisännistöyhtiön pääisännän asuinpaikkavaatimuksesta;

<a id="section-58-subsection-1-paragraph-3"></a>
- **3.** luvanvaraisen henkilö\- ja tavaraliikenteen harjoittamista;

<a id="section-58-subsection-1-paragraph-4"></a>
- **4.** joukkoliikenteen palveluostoja ja valtionapua;

<a id="section-58-subsection-1-paragraph-5"></a>
- **5.** poikkeuksia vaarallisten aineiden kuljettamisesta tiellä ja rautatiellä annetuista määräyksistä;

<a id="section-58-subsection-1-paragraph-6"></a>
- **6.** vaarallisten aineiden maakuljetusten reittirajoituksia;

<a id="section-58-subsection-1-paragraph-7"></a>
- **7.** liikenteen ohjauslaitteen vahvistamista käytettäväksi kokeilutarkoituksessa,

<a id="section-58-subsection-1-paragraph-8"></a>
- **8.** ajoneuvojen jaottelua ja siitä johtuvia erikoisohjeita; sekä

<a id="section-58-subsection-1-paragraph-9"></a>
- **9.** poikkeuksia ajoneuvojen massoista, mitoista ja kytkennästä\.
