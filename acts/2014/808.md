### 1 § Ilmoitettavat eläintaudit

<a id="section-1-subsection-1"></a>
#### \(1\)

Sen lisäksi, mitä jäljempänä tässä luvussa säädetään, eläintautilain 5 §:ssä tarkoitettuja ilmoitettavia eläintauteja ovat

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** apinarokko;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Batrachochytrium dendrobatidis \-tartunta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** besnoitioosi \(Besnoitia besnoiti\);

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** botulismi;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Brucella abortus\-, B\. melitensis\-, B\. ovis\- ja B\. suis \-tartunnat muissa eläinlajeissa kuin sorkkaeläimissä sekä muut Brucella\-tartunnat;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** BVD\-tauti muissa eläinlajeissa kuin nautaeläimissä

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Campylobacter fetus ssp\. venerealis \-tartunta;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** CEM\-tauti \(Contagious equine metritis\);

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** duck virus hepatitis;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** ekinokokkitartunnat, lukuun ottamatta myyräekinokokkoosia;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** entsoottinen abortti \(Chlamydophila abortus\);

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** heartwater\-tauti;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** HEV \(hemagglutinating encephalomyelitis \-virus\) sioissa;

<a id="section-1-subsection-1-paragraph-14"></a>
- **14.** hevossyyhy \(Sarcoptes equi\);

<a id="section-1-subsection-1-paragraph-15"></a>
- **15.** IPN\-tauti eläintautilain 35 §:n nojalla perustetulla rajoitusalueella ja muut IPN\-virustartunnat;

<a id="section-1-subsection-1-paragraph-16"></a>
- **16.** japanilainen aivotulehdus \(Japanese encephalitis\);

<a id="section-1-subsection-1-paragraph-17"></a>
- **17.** kalojen bakteeriperäinen munuaistauti \(BKD\-tauti\);

<a id="section-1-subsection-1-paragraph-18"></a>
- **18.** kamelirokko \(Camelpox\);

<a id="section-1-subsection-1-paragraph-19"></a>
- **19.** kasöösi lymfadeniitti \(Corynebacterium pseudotuberculosis\);

<a id="section-1-subsection-1-paragraph-20"></a>
- **20.** Krimin\-Kongon verenvuotokuume \(Crimean\-Congo haemorrhagic fever\);

<a id="section-1-subsection-1-paragraph-21"></a>
- **21.** lammassyyhy \(Psoroptes ovis\);

<a id="section-1-subsection-1-paragraph-22"></a>
- **22.** lehmärokko;

<a id="section-1-subsection-1-paragraph-23"></a>
- **23.** leptospiroosi;

<a id="section-1-subsection-1-paragraph-24"></a>
- **24.** lintuinfluenssat, lukuun ottamatta vastustettavista eläintaudeista ja niiden luokittelusta annetussa maa\- ja metsätalousministeriön asetuksessa \(843/2013\) tarkoitettua korkeapatogeenista ja matalapatogeenista lintuinfluenssaa;

<a id="section-1-subsection-1-paragraph-25"></a>
- **25.** Mycoplasma agalactiae\- \(tarttuva agalaktia\), M\. capricolum\-, M\. mycoides subsp\.capri\- ja M\.synoviae –tartunnat sekä M\. gallisepticum\- ja M\. meleagridis \-tartunnat muissa linnuissa kuin siipikarjassa;

<a id="section-1-subsection-1-paragraph-26"></a>
- **26.** Mycobacterium complex \-ryhmän tartunnat \(nautatuberkuloosi\) muissa eläinlajeissa kuin sorkkaeläimissä sekä muut mykobakteeritartunnat, paratuberkuloosi mukaan lukien;

<a id="section-1-subsection-1-paragraph-27"></a>
- **27.** myksomatoosi;

<a id="section-1-subsection-1-paragraph-28"></a>
- **28.** Nairobi sheep disease;

<a id="section-1-subsection-1-paragraph-29"></a>

<a id="section-1-subsection-1-paragraph-30"></a>
- **30.** nautojen hemorraaginen septikemia \(Pasteurella multocida\);

<a id="section-1-subsection-1-paragraph-31"></a>
- **31.** new world screwworm \(Cochliomyia hominivorax\);

<a id="section-1-subsection-1-paragraph-32"></a>
- **32.** Nipah\-viruksen aiheuttama aivotulehdus;

- **39.** PRCV \(porcine respiratory corona virus\);

<a id="section-1-subsection-1-paragraph-40"></a>
- **40.** psittakoosi \(Chlamydophila psittaci\);

<a id="section-1-subsection-1-paragraph-41"></a>
- **41.** pulmonaari adenomatoosi;

<a id="section-1-subsection-1-paragraph-42"></a>
- **42.** Q\-kuume;

<a id="section-1-subsection-1-paragraph-43"></a>
- **43.** rabbit haemorrhagic disease;

<a id="section-1-subsection-1-paragraph-44"></a>
- **44.** ranavirus\-tartunta;

<a id="section-1-subsection-1-paragraph-45"></a>
- **45.** rapurutto;

<a id="section-1-subsection-1-paragraph-46"></a>
- **46.** ritinärutto \(Clostridium chauvoei\);

<a id="section-1-subsection-1-paragraph-47"></a>
- **47.** salmonellatartunnat, lukuun ottamatta Bos taurus \-lajin nautaeläimissä, sioissa, Gallus gallus \-lajin linnuissa ja kalkkunoissa todettuja salmonellatartuntoja;

<a id="section-1-subsection-1-paragraph-48"></a>

<a id="section-1-subsection-1-paragraph-53"></a>
