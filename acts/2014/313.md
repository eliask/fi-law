<a id="section-1"></a>
### 1 § Eduskuntavaalit

<a id="section-1-subsection-1"></a>
#### \(1\)

Ehdokkaiden asettamisessa eduskuntavaaleissa voidaan käyttää tämän päätöksen mukaisia lomakkeita\. Kaavat on vahvistettu seuraaville lomakkeille:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ilmoitus puolueen vaaliasiamiehestä ja varamiehestä;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** puolueen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ehdotus puolueen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** puolueen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ilmoitus puolueiden vaaliliitosta;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** puolueen vaaliasiamiehen antama valtakirja;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** valitsijayhdistyksen perustamisasiakirja lisälehtineen;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** valitsijayhdistyksen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** ehdotus valitsijayhdistyksen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** valitsijayhdistyksen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** ilmoitus yhteislistasta lisälehtineen; sekä

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** yhteislistan tai valitsijayhdistyksen vaaliasiamiehen antama valtakirja\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Vahvistetut kaavat ovat tämän päätöksen liitteinä\.

### 3 § Kunnallisvaalit

<a id="section-3-subsection-1"></a>
#### \(1\)

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** valitsijayhdistyksen perustamisasiakirja lisälehtineen;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** valitsijayhdistyksen ehdokashakemus;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** ehdotus valitsijayhdistyksen ehdokaslistaksi;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** valitsijayhdistyksen ehdokkaan suostumus ja vakuutus;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** ilmoitus yhteislistasta lisälehtineen;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** ilmoitus varaehdokkaista; sekä

- **13.** vaaliasiamiehen antama valtakirja\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Vahvistetut kaavat ovat tämän päätöksen liitteinä\.
