<a id="section-2"></a>
### 2 § Tullin yksiköt, toimintayksiköt ja tullitoimipaikat

<a id="section-2-subsection-1"></a>
#### \(1\)

Toimipaikkaosastossa toimintayksikköinä ovat tullit\. Tullit sekä niihin kuuluvat tullitoimipaikat ja tilapäiset rajanylityspaikat ovat seuraavat:

<a id="section-2-subsection-2"></a>
#### \(2\)

— Helsingin tulli : Helsingin, Lahden ja Hangon tullitoimipaikat;

<a id="section-2-subsection-3"></a>
#### \(3\)

— Lentotulli : Lentotullitoimipaikka;

<a id="section-2-subsection-4"></a>
#### \(4\)

— Kotkan tulli : Kotkan ja Haminan tullitoimipaikat;

<a id="section-2-subsection-5"></a>
#### \(5\)

— Vaalimaan tulli : Vaalimaan tullitoimipaikka;

<a id="section-2-subsection-6"></a>
#### \(6\)

— Nuijamaan tulli : Nuijamaan ja Vainikkalan tullitoimipaikat;

<a id="section-2-subsection-7"></a>
#### \(7\)

— Imatran tulli : Imatran ja Niiralan tullitoimipaikat sekä Parikkalan tilapäinen rajanylityspaikka;

<a id="section-2-subsection-8"></a>
#### \(8\)

— Turun tulli : Turun, Rauman, Tampereen, Porin, Jyväskylän, Vaasan ja Kokkolan tullitoimipaikat;

<a id="section-2-subsection-9"></a>
#### \(9\)

— Tornion tulli : Tornion, Kilpisjärven, Kivilompolon, Karigasniemen, Utsjoen, Raja\-Joosepin, Sallan, Kuusamon, Vartiuksen ja Oulun tullitoimipaikat;

<a id="section-2-subsection-10"></a>
#### \(10\)

— Maarianhaminan tulli : Maarianhaminan, Eckerön ja Långnäsin tullitoimipaikat\.

<a id="section-7"></a>
### 7 § Valvontaosasto

<a id="section-7-subsection-1"></a>
#### \(1\)

Osastoon kuuluvat valtakunnalliset toiminnot ovat tutkinta, analyysi ja tiedustelu sekä yritystarkastus\.
