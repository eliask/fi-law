<a id="section-1"></a>
### 1 § Luonnonsuojelualueiden perustamistarkoitus

<a id="section-1-subsection-1"></a>
#### \(1\)

Poikkeuksellisen edustavien vanhojen metsien ja suoluonnon sekä niille ominaisten lajien ja pienvesien suojelua, retkeilyä, opetusta ja tutkimusta sekä luonto\- ja kulttuurimatkailun kehittämistä varten perustetaan itäiseen Kainuuseen luonnonsuojelulain [\(1096/1996\)](<https://www.finlex.fi/fi/lainsaadanto/1996/1096>) mukaisiksi muiksi luonnonsuojelualueiksi jäljempänä 2 §:ssä luetellut alueet\.

<a id="section-2"></a>
### 2 § Sijainti ja rajat

<a id="section-2-subsection-1"></a>
#### \(1\)

Kalevalapuistoon kuuluviksi luonnonsuojelualueiksi perustetaan seuraavat Suomussalmen kunnassa sijaitsevat valtion omistamat alueet, joiden rajat on merkitty punaisella viivalla liitteinä oleviin karttoihin:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Pahamaailman luonnonsuojelualue, jonka pinta\-ala on noin 2440 hehtaaria \(liite 1\),

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Vieremänsuon luonnonsuojelualue, jonka pinta\-ala on noin 1192 hehtaaria \(liite 2\),

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Tormuan Pohjanvaaran luonnonsuojelualue, jonka pinta\-ala on noin 1332 hehtaaria \(liite 3\),

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kala\-Peuron luonnonsuojelualue, jonka pinta\-ala on noin 195 hehtaaria \(liite 4\),

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Levävaaran luonnonsuojelualue, jonka pinta\-ala on noin 469 hehtaaria \(liite 5\),

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Housuvaaran luonnonsuojelualue, jonka pinta\-ala on noin 807 hehtaaria \(liite 6\),

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Öllörinsärkän luonnonsuojelualue, jonka pinta\-ala on noin 503 hehtaaria \(liite 7\),

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Iso Vaskenvaaran luonnonsuojelualue, jonka pinta\-ala on noin 541 hehtaaria \(liite 8\),

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Rimpisuon luonnonsuojelualue, jonka pinta\-ala on noin 408 hehtaaria \(liite 9\),

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Mäntypuron luonnonsuojelualue, jonka pinta\-ala on noin 351 hehtaaria \(liite 10\),

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Sydänmaanaron luonnonsuojelualue, jonka pinta\-ala on noin 2205 hehtaaria \(liite 11\),

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Mesiönvaaran luonnonsuojelualue, jonka pinta\-ala on noin 510 hehtaaria \(liite 12\),

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Karsikkovaaran – Losolehdon luonnonsuojelualue, jonka pinta\-ala on noin 1131 hehtaaria \(liite 13\),

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** Viisiriihisen luonnonsuojelualue, jonka pinta\-ala on noin 318 hehtaaria \(liite 14\),

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Murhisalon luonnonsuojelualue, jonka pinta\-ala on noin 5403 hehtaaria \(liite 15\),

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Karttimonjoen luonnonsuojelualue, jonka pinta\-ala on noin 240 hehtaaria \(liite 16\),

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** Malahvian luonnonsuojelualue, jonka pinta\-ala on noin 2442 hehtaaria \(liite 17\)\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Perustettavat luonnonsuojelualueet kuuluvat suomalais\-venäläistä luonnonsuojelu\- ja kulttuuriyhteistyötä varten muodostettuun Kalevalapuiston toiminnalliseen kokonaisuuteen yhdessä ulkoilulain [\(606/1973\) 16 §:n](<https://www.finlex.fi/fi/lainsaadanto/1973/606#chp_2__sec_16>) mukaisen Hossan retkeilyalueen ja luonnonsuojelulain 32 §:n mukaisen Suomussalmen vienalaiskylien maisema\-alueen sekä seuraavien aikaisemmin perustettujen luonnonsuojelualueiden kanssa:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Martinselkosen luonnonsuojelualue;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Raatesuon soidensuojelualue;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** Paiselammen soidensuojelualue;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** Vieremänsuon soidensuojelualue;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** Lososuon\-Saarijärven soidensuojelu\-alue\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Edellä 2 momentissa mainituista alueista on voimassa, mitä niistä erikseen on säädetty tai päätetty\.

<a id="section-3"></a>
### 3 § Rauhoitussäännökset

<a id="section-3-subsection-1"></a>
#### \(1\)

Tällä asetuksella perustettuihin luonnonsuojelualueisiin sovellettavista rauhoitussäännöksistä säädetään luonnonsuojelulain 17 a §:ssä\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä huhtikuuta 2014\.
