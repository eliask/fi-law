# Oikeusministeriön asetus syyttäjänvirastojen palvelutoimistoista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Syyttäjänvirastoilla on palvelutoimistot seuraavissa kunnissa:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Länsi\-Uudenmaan syyttäjänvirastolla Lohjalla ja Raaseporissa;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Itä\-Uudenmaan syyttäjänvirastolla Järvenpäässä ja Porvoossa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Salpausselän syyttäjänvirastolla Hämeenlinnassa, Kotkassa, Lahdessa ja Lappeenrannassa;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Länsi\-Suomen syyttäjänvirastolla Porissa ja Raumalla;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Sisä\-Suomen syyttäjänvirastolla Jyväskylässä;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjanmaan syyttäjänvirastolla Kokkolassa ja Seinäjoella;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Itä\-Suomen syyttäjänvirastolla Iisalmessa, Joensuussa ja Kuopiossa;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Oulun syyttäjänvirastolla Kajaanissa, Kuusamossa, Raahessa ja Ylivieskassa;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Lapin syyttäjänvirastolla Ivalossa, Kemissä ja Sodankylässä\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä elokuuta 2014\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan syyttäjänvirastojen palvelutoimistoista annettu oikeusministeriön asetus [\(469/2013\)](<https://www.finlex.fi/fi/lainsaadanto/2013/469>)\.
