# Valtioneuvoston päätös turvallisuusluokituksen käyttöön otosta annetun valtioneuvoston päätöksen 1 §:n muuttamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Turvallisuusselvityksistä annetun lain \(177/2002\) 14 §:ssä tarkoitettu turvallisuusluokitus otetaan käyttöön seuraavissa valtionhallinnon viranomaisissa tai niiden yksilöidyissä osissa:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** tasavallan presidentin kanslia;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** valtioneuvoston kanslian johto ja EU\-sihteeristö;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ulkoasiainministeriön sekä ulkomaanedustustojen johto;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** sisäministeriön johto, poliisiosasto, pelastusosasto ja ministeriön kansainvälisten asioiden yksikkö;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** rajavartiolaitoksen johto ja esikunta;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Poliisihallitus, keskusrikospoliisi ja suojelupoliisi;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Hallinnon tietotekniikkakeskuksen ja hätäkeskuslaitoksen johto;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** puolustusministeriö ja puolustusvoimat;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** liikenne\- ja viestintäministeriön johto sekä sen hallinnonalan virastojen ja laitosten johto;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Tullin johto;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** oikeuskanslerinviraston johto, valtioneuvostoasiain osasto ja oikeusvalvontaosasto;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** valtiovarainministeriön valtiovarain controller \-toiminto sekä Valtion tieto\- ja viestintätekniikkakeskus Valtorin johto\.
