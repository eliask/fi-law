# Sosiaali\- ja terveysministeriön asetus Terveyden ja hyvinvoinnin laitoksen alaisten lastensuojeluyksiköiden maksullisista suoritteista

- Statute: [`833/2014`](<https://www.finlex.fi/fi/laki/ajantasa/2014/833>)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain [\(150/1992\) 7 §:ssä](<https://www.finlex.fi/fi/lainsaadanto/1992/150#chp_2__sec_7>) tarkoitettuja muita suoritteita, jotka Terveyden ja hyvinvoinnin laitoksen alaiset lastensuojeluyksiköt hinnoittelevat liiketaloudellisin perustein, ovat seuraavat suoritteet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** asumis\- ja hoitopalvelut;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** erityishoitopalvelut, erityisen huolenpidon palvelut;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** koulupaikka;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kriisihoito;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** jälkihuolto;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** koulutus\-, työnohjaus\- ja konsultointipalvelut;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** perhekuntoutusleiri;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** ravintopalvelut ulkopuolisille;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** tilojen ja laitteiden käyttö;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** toimistopalvelut;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** maatilatalouden tuotteet ja palvelut sekä muut työsuoritukset\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä marraskuuta 2014\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan valtion koulukotien maksullisia suoritteita koskeva sosiaali\- ja terveysministeriön asetus [\(1133/2001\)](<https://www.finlex.fi/fi/lainsaadanto/2001/1133>)\.
