### 1 § Maksuttomat julkisoikeudelliset suoritteet

<a id="section-1-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen maksuttomia julkisoikeudellisia suoritteita ovat seuraavat liikenneturvallisuuden edistämiseksi suoritettavat valvontatehtävät:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** liikenteenvalvontatehtävät;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** liikennetarvikelain \(570/78\) mukaiset valvontatehtävät; sekä

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** autokoulujen ja ajoharjoitteluratojen valvontatehtävät\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Maksuton on myös rekisteri\-ilmoitus, joka koskee:

<a id="section-1-subsection-2-paragraph-1"></a>
- **1.** ajoneuvon poistamista rekisteristä;

<a id="section-1-subsection-2-paragraph-2"></a>
- **2.** rekisteritietojen korjausta; sekä

<a id="section-1-subsection-2-paragraph-3"></a>
- **3.** nimen tai osoitteen muutosta\.

### 2 § Maksulliset julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Maksullisia julkisoikeudellisia suoritteita, joiden maksun Autorekisterikeskus määrää suoritteen omakustannusarvon mukaan, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Katsastussuoritteet:

<a id="section-2-subsection-1-paragraph-1-subparagraph-1"></a>
  - **1.** tyyppikatsastus ja teknisen laitteen hyväksyminen;

<a id="section-2-subsection-1-paragraph-1-subparagraph-2"></a>
  - **2.** vuosikatsastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-3"></a>
  - **3.** rekisteröintikatsastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-4"></a>
  - **4.** muutoskatsastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-5"></a>
  - **5.** maahantuontikatsastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-6"></a>
  - **6.** kytkentäkatsastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-7"></a>
  - **7.** ajoneuvolle katsastuksessa määrätty jälkitarkastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-8"></a>
  - **8.** TIR\-yleissopimuksen mukainen tarkastus;

<a id="section-2-subsection-1-paragraph-1-subparagraph-9"></a>
  - **9.** VAK\-ajoneuvon hyväksyntä; sekä

<a id="section-2-subsection-1-paragraph-1-subparagraph-10"></a>
  - **10.** linja\-auton nopeuden hyväksymistä koskeva tarkastus\.

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Kuljettajantutkintosuoritteet:

<a id="section-2-subsection-1-paragraph-2-subparagraph-1"></a>
  - **1.** kuljettajantutkinto;

<a id="section-2-subsection-1-paragraph-2-subparagraph-2"></a>
  - **2.** kuljettajantutkintoon kuuluva koe erikseen suoritettuna; sekä

<a id="section-2-subsection-1-paragraph-2-subparagraph-3"></a>
  - **3.** VAK\- tai ADR\-ajolupakoe\.

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Rekisteröintisuoritteet:

<a id="section-2-subsection-1-paragraph-3-subparagraph-1"></a>
  - **1.** ennakkoilmoitustodistus;

<a id="section-2-subsection-1-paragraph-3-subparagraph-2"></a>
  - **2.** rekisteriote;

<a id="section-2-subsection-1-paragraph-3-subparagraph-3"></a>
  - **3.** rekisteröintitodistus;

<a id="section-2-subsection-1-paragraph-3-subparagraph-4"></a>
  - **4.** rekisterikilpi; sekä

<a id="section-2-subsection-1-paragraph-3-subparagraph-5"></a>
  - **5.** yksittäisten tietojen luovuttaminen puhelimitse tai kirjallisesti ajoneuvorekisteristä\.

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Muut suoritteet:

<a id="section-2-subsection-1-paragraph-4-subparagraph-1"></a>
  - **1.** otteet, jäljennökset ja kopiot rekisteröintiasiakirjoista;

<a id="section-2-subsection-1-paragraph-4-subparagraph-2"></a>
  - **2.** valokopiot asiakirjoista;

<a id="section-2-subsection-1-paragraph-4-subparagraph-3"></a>
  - **3.** kopiot tilastoista; sekä

<a id="section-2-subsection-1-paragraph-4-subparagraph-4"></a>
  - **4.** todistus maksetusta verosta\.

<a id="section-3"></a>
### 3 § Autorekisterikeskuksen luvista perittävät maksut

<a id="section-3-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen luvista ja päätöksistä peritään maksuja seuraavasti:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Ajoneuvoasetuksen \(233/82\) tai sen täytäntöönpanosta annetun liikenneministeriön päätöksen \(150/83\) nojalla tehty poikkeuslupapäätös: a\) Autorekisterikeskuksen antama 500 mk b\) katsastustoimipaikan antama 350 mk

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Ajoneuvon rakenteen muuttamista koskeva päätös: a\) henkilöautoa koskeva 350 mk b\) muuta ajoneuvoa koskeva 100 mk

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** E\-hyväksymispäätös 650 mk

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** Katsastustoimipaikan antama todistus tai vastaava 60 mk

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** Siirtokilpilupa 50 mk

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** VAK\- tai ADR\-koulutuslupa 300 mk

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** VAK\- tai ADR\-ajolupa 120 mk

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** Poikkeuslupapäätös ajolupakoe\- vaatimuksesta \(ARK\) 100 mk

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** Poikkeuslupapäätös ajolupakokeen koulutus\- vaatimuksista \(katsastustoimipaikka\) 100 mk

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** Päätös ajoharjoitteluradan hyväksymisestä 500 mk

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** Poikkeuslupapäätös ajokorttilupaa ja ajo\-oikeutta sekä ammattiajolupaa koskevasta ikävaatimuksesta 350 mk

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** Poikkeuslupapäätös autokoulun hyväksymiseksi opetusharjoittelu\- kouluksi \(ARK\) 300 mk

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** Autokoulun hyväksyminen opetusharjoittelu\- kouluksi \(katsastustoimipaikka\) 300 mk

<a id="section-3-subsection-1-paragraph-14"></a>
- **14.** Autokoulun opetusvälineiden hyväksymis\- päätös 330 mk

<a id="section-4"></a>
### 4 § Myöhästyneet tai käyttämättömät suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Mikäli rekisteri\-ilmoitus jätetään säädetyn määräajan jälkeen, Autorekisterikeskus perii rekisteriotteesta omakustannusarvon lisäksi 50 markkaa\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Mikäli varattu katsastus\- tai kuljettajantutkintosuorite jätetään käyttämättä ja peruuttamatta, voidaan suoritetusta ajanvarauksesta sekä henkilöstön ja tilojen varaamisesta periä aiheutuneita kustannuksia vastaava maksu\.

<a id="section-5"></a>
### 5 § Muut maksulliset suoritteet

<a id="section-5-subsection-1"></a>
#### \(1\)

Autorekisterikeskuksen muita maksullisia suoritteita ovat:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** ajoneuvon punnitus tai muut vastaavat katsastustoimipaikan työvälineillä asiakkaan pyynnöstä tapahtuvat suoritteet, jotka eivät perustu säännökseen;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** Autorekisterikeskuksen järjestämät hallinnon ulkopuolisille tarkoitetut koulutustilaisuudet ja koulutustilaisuuden tilaajan toimeksiannosta toteutettava koulutus;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** toimeksiantoon perustuvat tutkimus\- ja tilauspalvelut;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** asiakirjojen ja muun aineiston lähettäminen; sekä

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** postitus\.

<a id="section-6"></a>
### 6 § Voimaantulo

<a id="section-6-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä kesäkuuta 1992\. Päätöksen 2 §:ssä mainitusta ennakkoilmoitustodistuksesta ryhdytään maksua perimään kuitenkin 1 päivästä lokakuuta 1992 lukien\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimiin\.
