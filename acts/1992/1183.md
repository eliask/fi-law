# Valtioneuvoston päätös eräiden kuntien määräämisestä erityisalueiksi

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Erityisalueiksi vuodeksi 1993 määrätään seuraavat kunnat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Lapin läänistä Kemijärvi, Kolari, Muonio, Pelkosenniemi, Posio ja Ylitornio;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Oulun läänistä Hyrynsalmi, Puolanka, Taivalkoski, Vihanti ja Vuolijoki;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Vaasan läänistä Kauhajoki, Kokkola, Kurikka, Lehtimäki, Lestijärvi, Soini, Teuva ja Vimpeli;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Keski\-Suomen läänistä Kannonkoski, Kinnula, Kivijärvi, Pylkönmäki, Sumiainen, Suolahti, Uurainen ja Äänekoski;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Kuopion läänistä Iisalmi, Kaavi, Rautavaara, Sonkajärvi, Suonenjoki ja Varkaus;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan läänistä Lieksa, Nurmes, Tohmajärvi, Valtimo ja Värtsilä;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Mikkelin läänistä Enonkoski, Kangasniemi, Mäntyharju, Savonranta ja Savonlinna;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Kymen läänistä Imatra ja Joutseno;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Hämeen läänistä Forssa, Kihniö, Mänttä, Toijala, Valkeakoski ja Viiala;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Turun ja Porin läänistä Kullaa, Lappi, Luvia, Noormarkku, Rauma, Pori ja Ulvila sekä

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Uudenmaan läänistä Lohja, Lohjan kunta ja Loviisa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1993\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Valtionavustus, jota koskeva hakemus on toimitettu asianomaiselle viranomaiselle ennen tämän päätöksen voimaantuloa, voidaan kuitenkin myöntää sen suuruisena kuin se olisi ollut myönnettävissä ennen tämän päätöksen voimaantuloa voimassa olleiden päätösten nojalla\.
