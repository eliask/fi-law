# Valtioneuvoston päätös eräiden tilojen ja alueiden siirtämisestä Mietoisten kunnasta Mynämäen kuntaan

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Mietoisten kunnasta siirretään Mynämäen kuntaan seuraavat tilat ja alueet:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Haraisen yksinäistaloa tila Mattila 1:3;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Katavaisen kylästä tila Kivilä 2:1;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Pursilan kylästä tila Mantere 4;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Pyhön kylästä tilat Korpela 1:27 ja Korpelanlisä 2:32;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Ruonkallion kylästä tilat Lehtonen 2:1, Lehtoranta II 2:5 ja Lehtoranta 3:4;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Sukoisen kylästä tila Mikala 2:4;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Tuokilan yksinäistaloa tila Jokela 1:19,

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Valaskallion kylästä tilat Yliheikkilä 1:19; Palmunen 2:2, Reuna II 4:18, Reuna 4:20 ja Kulmala 6:11; sekä

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** edellämainittujen tilojen Mattila 1:3, Kivilä 2:1, Jokela 1:19 ja Palmunen 2:2 alueella olevat yleiset alueet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Siirrot eivät aiheuta muutosta kuntien kielelliseen jaotukseen\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1993\.
