# Opetusministeriön päätös peruskoulussa järjestettävän esiopetuksen perusteista annetun päätöksen muuttamisesta

- Version: `1992-12-18`
- LawVM tree hash: `778eb2ddcf7d4df1eb54eb2c79886a1b09f35523333d49ecb7d1eaaa5ccd85f5`

## Contents

- [4 §](#section-4)

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Koulun ylläpitäjän on haettava lupaa esiopetuksen järjestämiseen opetusministeriöltä opetuksen aloittamista edeltävän tammikuun loppuun mennessä\.

<a id="section-4-subsection-2"></a>
#### \(2\)

Lupahakemuksessa tulee esittää:

<a id="section-4-subsection-2-paragraph-1"></a>
- **1.** suunnitelma esiopetuksen järjestämistavasta; sekä

<a id="section-4-subsection-2-paragraph-2"></a>
- **2.** arvio opetukseen osallistuvien lasten määrästä\.

<a id="section-4-subsection-3"></a>
#### \(3\)

Lupa voidaan myöntää enintään viideksi lukuvuodeksi kerrallaan\.
