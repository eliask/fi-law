# Maa\- ja metsätalousministeriön päätös merilohisaaliin ilmoittamisesta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ammattimaisen kalastuksen harjoittaja on velvollinen viikottain ilmoittamaan saaliiksi saamansa merilohen määrän kiloina\. Tilastoviikko alkaa maanantaina ja päättyy sunnuntaina\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Saalisilmoitus on kultakin viikolta tehtävä viimeistään seuraavan viikon perjantaina puhelimitse palvelunumeroon 9800\-4848\. Palvelunumero on käytössä arkisin maanantaista perjantaihin kello 8\-17 välisenä aikana\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Saalisilmoitusta tehtäessä on annettava seuraavat tiedot:

<a id="section-1-subsection-3-paragraph-1"></a>
- **1.** kalastuksen harjoittajan nimi ja osoite;

<a id="section-1-subsection-3-paragraph-2"></a>
- **2.** kalastusaluksen tunnus tai venerekisteriin merkityn veneen numero;

<a id="section-1-subsection-3-paragraph-3"></a>
- **3.** pyyntialue \(Itämeri, Selkämeri, Perämeri, Suomenlahti\);

<a id="section-1-subsection-3-paragraph-4"></a>
- **4.** kalastuksessa käytetty pyydys \(rysä, verkko, siima tai muu pyydys\); sekä

<a id="section-1-subsection-3-paragraph-5"></a>
- **5.** edellisen viikon lohisaalis kiloina\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 27 päivänä toukokuuta 1992\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Ensimmäinen saalisilmoitus on annettava kesäkuun 1992 ensimmäisellä viikolla\. Ensimmäisen ilmoituksen tulee sisältää alkuvuoden merilohisaaliin koko määrä kiloina\.
