<a id="section-1"></a>
### 1 § Veron maksun yhteydessä annettava ilmoitus

<a id="section-1-subsection-1"></a>
#### \(1\)

Suoritettaessa arpajaisveroa tilillepanokortilla on samalla ilmoitettava seuraavat tiedot:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** arpajaisverovelvollisen nimi, osoite, kotikunta ja henkilö\- tai liike\- ja yhteisötunnus;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kalenterikuukausi ja vuosi, jolta arpajaisvero suoritetaan;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** arpajaisveron alaisen toiminnan laatu;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** arpajaisveron peruste, josta vero lasketaan;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** suoritettavan arpajaisveron määrä;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** yksinoikeudella arpajaisia toimeenpanevan verovelvollisen tekemä vähennys edellisten neljän kalenterikuukauden verosuoritusten yhteydessä liikaa suoritetusta verosta\.

<a id="section-2"></a>
### 2 § Erillinen tilitys

<a id="section-2-subsection-1"></a>
#### \(1\)

Lääninveroviraston pyynnöstä verovelvollisen on annettava erillinen tilitys, josta on ilmoitettava seuraavat tiedot:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** arpajaisverovelvollisen nimi, osoite, kotikunta, henkilö\- tai liike\- ja yhteisötunnus;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** arpajaisveron määrä, suorittamispäivä ja arvontapäivä tai \-päivät taikka muu arpajaisverolaissa tarkoitettu verovelvollisuuden perusteena oleva ajankohta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** kuukausi, jolta vero suoritetaan;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** vähennyksen kohdekuukausi, määrä, arvo ja vähennyksen peruste;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** luettelo bingopeleissä tai muissa arpajaisissa jaettujen voittojen arvosta\. Luettelossa tulee eritellä voittojen ohjehinta, hankintahinta, kappalemäärä ja voittojen arvot yhteensä;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** arpajaisveron määrä prosentteina, laskentaperuste ja veron markkamäärä\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä verohallituksen päätös tulee voimaan 1 päivänä syyskuuta 1992 ja sitä sovelletaan 26 päivänä kesäkuuta 1992 annetun arpajaisverolain \(552/92\) alaisiin arpajaisiin\.
