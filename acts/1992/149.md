# Oikeusministeriön päätös eräistä kunnallisvaalilaissa tarkoitetuista kaavoista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Täten vahvistetaan seuraavat kaavat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** valitsijayhdistyksen perustamisasiakirja;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** hakemus valitsijayhdistyksen ehdokaslistan julkaisemisesta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** ehdotus valitsijayhdistyksen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** valitsijayhdistyksen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ilmoitus valitsijayhdistysten yhteislistasta;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** hakemus puolueen ehdokaslistan julkaisemisesta;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** ehdotus puolueen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** ilmoitus puolueen jäseniä kunnassa edustavasta yhdistyksestä;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** puolueen ehdokkaan suostumus ja vakuutus; sekä

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** ilmoitus puolueiden vaaliliitosta\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Vahvistetut kaavat ovat tämän päätöksen liitteenä\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä maaliskuuta 1992\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan eräistä kunnallisvaalilaissa tarkoitetuista kaavoista 5 päivänä toukokuuta 1988 annettu oikeusministeriön päätös \(421/88\)\.
