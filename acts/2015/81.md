# Valtioneuvoston asetus valtion osuuden maksamisesta takuueläkkeen perusteella

<a id="section-1"></a>
### 1 § Valtion osuuden ennakon maksaminen

<a id="section-1-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriö maksaa Kansaneläkelaitokselle valtion osuuden ennakon kuukausittain viimeistään kolme pankkipäivää ennen takuueläkkeestä annetun lain [\(703/2010\) 16 §:n](<https://www.finlex.fi/fi/lainsaadanto/2010/703#chp_3__sec_16>) 3 momentissa säädettyä maksupäivää\. Kansaneläkelaitoksen on kuukausittain viimeistään kymmenen pankkipäivää ennen kunkin kuukauden takuueläkkeen maksupäivää ilmoitettava sosiaali\- ja terveysministeriölle määrä, joka Kansaneläkelaitoksen arvion mukaan tarvitaan kunkin kuukauden maksupäivänä maksettavien takuueläkkeiden maksamiseen\.

<a id="section-2"></a>
### 2 § Valtion osuuden ennakon tarkistaminen

<a id="section-2-subsection-1"></a>
#### \(1\)

Kalenterikuukautena maksettujen takuueläkkeiden yhteismäärän ja niiden kattamiseksi maksetun valtion osuuden ennakon erotus otetaan huomioon maksukuukautta seuraavan toisen kuukauden ennakkoa määrättäessä\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Kansaneläkelaitoksen on toimitettava sosiaali\- ja terveysministeriölle valtion osuuden ennakon tarkistamisessa tarvittavat tiedot\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 23 päivänä helmikuuta 2015\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Asetusta sovelletaan ensimmäisen kerran maaliskuussa 2015 maksettavaan valtion osuuden ennakkoon\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Tällä asetuksella kumotaan valtion osuuden maksamisesta takuueläkkeen perusteella annettu valtioneuvoston asetus [\(90/2011\)](<https://www.finlex.fi/fi/lainsaadanto/2011/90>)\.
