<a id="section-3"></a>
### 3 § Turvallisuusneuvonantajan nimeämisvelvollisuus

<a id="section-3-subsection-1"></a>
#### \(1\)

Toiminnanharjoittajan on nimettävä yksi tai useampi turvallisuusneuvonantaja hoitamaan hänelle säädettyjä tehtäviä toiminnanharjoittajan valvonnassa\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Turvallisuusneuvonantajaa ei kuitenkaan tarvitse nimetä, jos:

<a id="section-3-subsection-2-paragraph-1"></a>
- **1.** vaarallisen aineen kuljetukset suoritetaan puolustusvoimien valvonnassa tai puolustusvoimien ajoneuvolla;

<a id="section-3-subsection-2-paragraph-2"></a>
- **2.** vaarallisen aineen kuljetuksia suoritetaan satunnaisesti kotimaassa edellyttäen, että toiminnasta voi aiheutua vain vähäistä vaaraa ihmisille, ympäristölle tai omaisuudelle;

<a id="section-3-subsection-2-paragraph-3"></a>
- **3.** vaarallisten aineiden kuljetukset:

<a id="section-3-subsection-2-paragraph-3-subparagraph-a"></a>
  - **a.** täyttävät vaarallisten aineiden kuljetuksesta tiellä annetun Liikenteen turvallisuusviraston määräyksen liitteen A kohdassa 1\.1\.3 tai 1\.7\.1\.4 taikka luvussa 3\.4 tai 3\.5 säädetyt ehdot;

<a id="section-3-subsection-2-paragraph-3-subparagraph-b"></a>
  - **b.** ovat a alakohdassa mainitun määräyksen liitteessä C tarkoitettuja kuljetuksia;

<a id="section-3-subsection-2-paragraph-4"></a>
- **4.** vaarallisten aineiden kuljetukset täyttävät vaarallisten aineiden kuljetuksesta rautatiellä annetun Liikenteen turvallisuusviraston määräyksen liitteen kohdassa 1\.1\.3 tai 1\.7\.1\.4 taikka luvussa 3\.4 tai 3\.5 säädetyt ehdot;

<a id="section-3-subsection-2-paragraph-5"></a>
- **5.** vaarallisten aineiden kuljetuksia suoritetaan ja vaarallisia aineita tilapäisesti säilytetään vain satama\-alueella tai lentopaikalla\.
