## 2 luku Päätösvaltaisuudesta

<a id="chapter-2-section-6"></a>
### 6 §

<a id="chapter-2-section-6-subsection-1"></a>
#### \(1\)

Rikosasiassa käräjäoikeus on päätösvaltainen myös, kun siinä on yksin puheenjohtaja, jos mistään syytteessä tarkoitetusta yksittäisestä rikoksesta ei syytteessä mainittujen seikkojen vallitessa tehtynä ole säädetty ankarampaa rangaistusta kuin vankeutta enintään kaksi vuotta tai jos syytteessä tarkoitettu yksittäinen rikos on:

<a id="chapter-2-section-6-subsection-1-paragraph-1"></a>
- **1.** virkamiehen väkivaltainen vastustaminen;

<a id="chapter-2-section-6-subsection-1-paragraph-2"></a>
- **2.** törkeä varkaus;

<a id="chapter-2-section-6-subsection-1-paragraph-3"></a>
- **3.** törkeä kavallus;

<a id="chapter-2-section-6-subsection-1-paragraph-4"></a>
- **4.** törkeä moottorikulkuneuvon käyttövarkaus;

<a id="chapter-2-section-6-subsection-1-paragraph-5"></a>
- **5.** törkeä kätkemisrikos;

<a id="chapter-2-section-6-subsection-1-paragraph-6"></a>
- **6.** törkeä vahingonteko;

<a id="chapter-2-section-6-subsection-1-paragraph-7"></a>
- **7.** törkeä petos;

<a id="chapter-2-section-6-subsection-1-paragraph-8"></a>
- **8.** törkeä maksuvälinepetos;

<a id="chapter-2-section-6-subsection-1-paragraph-9"></a>
- **9.** törkeä tietomurto;

<a id="chapter-2-section-6-subsection-1-paragraph-10"></a>
- **10.** 1—9 kohdassa mainitun rikoksen rangaistava yritys\.
