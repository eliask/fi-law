# Ympäristöministeriön asetus arava\- ja korkotukivuokra\-asuntojen hakemuslomakkeesta ja sen liitteistä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Arava\- ja korkotukivuokra\-asuntoja on haettava kirjallisesti asuntohakemuslomakkeella\. Lomake voi olla myös sähköisessä muodossa\. Hakemuksessa on mainittava ainakin seuraavat tiedot:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** huoneistoon asumaan tulevien henkilötiedot:

<a id="section-1-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** hakijan nimi, henkilötunnus sekä yhteystiedot; sekä

<a id="section-1-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** muiden asumaan tulevien nimet ja henkilötunnukset;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** haettavaa huoneistoa koskevat tiedot:

<a id="section-1-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** kunta, josta asuntoa haetaan;

<a id="section-1-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** millaista asuntoa haetaan \(tavallista vuokra\-asuntoa, tukiasuntoa tms\.\);

<a id="section-1-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** huoneistotyyppi, jos hakija haluaa rajoittaa; sekä

<a id="section-1-subsection-1-paragraph-2-subparagraph-d"></a>
  - **d.** onko kyseessä vuokra\-asuntohakemus vai asunnonvaihto;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** asunnontarve:

<a id="section-1-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** asunnottomuus ja sen kesto; sekä

<a id="section-1-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** muuttovelvoite nykyisestä asunnosta ja syy siihen;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** nykyistä asuntoa koskevat tiedot:

<a id="section-1-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** asunnon osoite ja sijaintikunta;

<a id="section-1-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** asunnon huoneluku ja pinta\-ala;

<a id="section-1-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** asukkaiden lukumäärä;

<a id="section-1-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** asunnon varustetaso ja kunto; sekä

<a id="section-1-subsection-1-paragraph-4-subparagraph-e"></a>
  - **e.** asunnon hallintasuhde;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** tulot ja varallisuus:

<a id="section-1-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** hakijan tulot ja varallisuus; sekä

<a id="section-1-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** muiden asumaan tulevien tulot ja varallisuus; sekä

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** allekirjoitus:

<a id="section-1-subsection-1-paragraph-6-subparagraph-a"></a>
  - **a.** päiväys ja hakijan allekirjoitus; sähköinen lomake allekirjoitetaan ennen vuokrasopimuksen tekemistä;

<a id="section-1-subsection-1-paragraph-6-subparagraph-b"></a>
  - **b.** maininta, että annetut tiedot vakuutetaan oikeiksi; sekä

<a id="section-1-subsection-1-paragraph-6-subparagraph-c"></a>
  - **c.** maininta, että olosuhteiden muuttuessa hakemus on korjattava muutoksia vastaavaksi\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Asuntohakemukseen on liitettävä ennen vuokrasopimuksen tekemistä muun muassa seuraavat selvitykset:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** kaikkien työssäkäyvien huoneistoon muuttavien palkkatodistukset bruttokuukausiansioista työnantajalta;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** verotodistukset kaikilta huoneistoon muuttavilta yli 18\-vuotiailta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** todistus eläkkeen määrästä \(brutto euroa/kk\);

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** selvitys omaisuuden käyvästä arvosta, jos omaisuutta on; sekä

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** muut mahdolliset todistukset, joihin hakija haluaa vedota \(esimerkiksi tuomioistuimen päätös muuttovelvoitteesta, raskaustodistus tms\.\)\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Edellä 1 momentissa tarkoitettuja selvityksiä ei tarvita, jos vuokra\-asuntoon on vain yksi hakija tai jos on kyse hakemisesta opiskelija\-asuntoon ellei ole aihetta selvittää tarkemmin asuntohakemuslomakkeella annettuja tietoja\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 15 päivänä helmikuuta 2005\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tällä asetuksella kumotaan 15 päivänä marraskuuta 1996 annettu ympäristöministeriön päätös asuntohakemuslomakkeen kaavasta\.
