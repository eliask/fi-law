## 1 luku Yleisiä säännöksiä

<a id="chapter-1-section-1"></a>
### 1 § Soveltamisala

<a id="chapter-1-section-1-subsection-1"></a>
#### \(1\)

Tässä työjärjestyksessä määrätään valtiovarainministeriön organisaatiosta ja sisäisestä työnjaosta, ministeriön johtamisesta ja hallinnonalan ohjauksesta, johtavien virkamiesten tehtävistä ja sijaisista, sisäisestä hallinnosta sekä asioiden valmistelusta ja ratkaisemisesta\.

<a id="chapter-2"></a>
## 2 luku Valtiovarainministeriön organisaatio

<a id="chapter-2-section-2"></a>
### 2 § Osastot, yksiköt ja esikuntaelimet

<a id="chapter-2-section-2-subsection-1"></a>
#### \(1\)

Ministeriössä on seuraavat perusyksiköt:

<a id="chapter-2-section-2-subsection-1-paragraph-1"></a>
- **1.** kansantalousosasto;

<a id="chapter-2-section-2-subsection-1-paragraph-2"></a>
- **2.** budjettiosasto;

<a id="chapter-2-section-2-subsection-1-paragraph-3"></a>
- **3.** vero\-osasto;

<a id="chapter-2-section-2-subsection-1-paragraph-4"></a>
- **4.** rahoitusmarkkinaosasto;

<a id="chapter-2-section-2-subsection-1-paragraph-5"></a>
- **5.** henkilöstöosasto \(Valtion työmarkkinalaitos\);

<a id="chapter-2-section-2-subsection-1-paragraph-6"></a>
- **6.** hallinnon kehittämisosasto;

<a id="chapter-2-section-2-subsection-1-paragraph-7"></a>
- **7.** hallintoyksikkö;

<a id="chapter-2-section-2-subsection-1-paragraph-8"></a>
- **8.** valtioneuvoston tietohallintoyksikkö\.

<a id="chapter-2-section-2-subsection-2"></a>
#### \(2\)

Lisäksi ministeriössä on valtiovarain controller \-toiminto\.

<a id="chapter-2-section-2-subsection-3"></a>
#### \(3\)

Ministeriön johdon esikuntaeliminä toimivat kansainvälisten asioiden sihteeristö, johdon tuki sekä viestintä\. Valtiosihteeri kansliapäällikkönä voi erikseen asettaa muitakin johdon esikuntaelimiä ja määräaikaisia projektiorganisaatioita\.

<a id="chapter-2-section-2-subsection-4"></a>
#### \(4\)

Mitä tässä työjärjestyksessä on sanottu osastosta, noudatetaan 1 momentissa mainittujen perusyksiköiden lisäksi soveltuvin osin 2 momentissa mainittuun valtiovarain controller \-toimintoon ja 3 momentissa tarkoitettuihin esikuntaelimiin\.

### 3 § Kansantalousosasto

<a id="chapter-2-section-3-subsection-1"></a>
#### \(1\)

Kansantalousosasto valmistelee asiat, jotka koskevat:

<a id="chapter-2-section-3-subsection-1-paragraph-1"></a>
- **1.** suhdannekehityksen ja keskipitkän aikavälin taloudellisen kehityksen seuraamista, tutkimista ja ennustamista;

<a id="chapter-2-section-3-subsection-1-paragraph-2"></a>
- **2.** julkisen talouden kehitystä;

<a id="chapter-2-section-3-subsection-1-paragraph-3"></a>
- **3.** talouspolitiikan suunnittelua ja talouspoliittisten toimenpiteiden vaikutusten selvittämistä;

<a id="chapter-2-section-3-subsection-1-paragraph-4"></a>
- **4.** kansantalouden näkökulman esiintuomista yhteiskuntapoliittisessa päätöksenteossa;

<a id="chapter-2-section-3-subsection-1-paragraph-5"></a>
- **5.** valtion luottokelpoisuusluokitukseen liittyviä asioita;

<a id="chapter-2-section-3-subsection-1-paragraph-6"></a>
- **6.** kansainvälisten järjestöjen ja yhteistyöelinten toimintaa kansantaloudellisissa ja talouspoliittisissa kysymyksissä;

<a id="chapter-2-section-3-subsection-1-paragraph-7"></a>
- **7.** taloudellisten katsausten ja ennusteiden julkaisemista sekä muuta taloudellista tiedotustoimintaa;

<a id="chapter-2-section-3-subsection-1-paragraph-8"></a>
- **8.** valtion tilinpäätöskertomukseen otettavia selvityksiä taloudellisesta kehityksestä, talous\- ja rakennepolitiikasta ja talous\- ja rakennepoliittisten toimenpiteiden vaikutusten arvioinnista;

<a id="chapter-2-section-3-subsection-1-paragraph-9"></a>
- **9.** kuntien yleistä kalleusluokitusta;

<a id="chapter-2-section-3-subsection-1-paragraph-10"></a>
- **10.** Valtion taloudellista tutkimuskeskusta\.

- **4.** valtion maksujen yleisiä perusteita ja toiminnan maksullisuutta;

<a id="chapter-2-section-4-subsection-1-paragraph-6"></a>
- **6.** valtion kirjanpidon, tuloksellisuuden ja johdon laskentatoimen sekä muiden seurantajärjestelmien, tilinpäätöksen ja tilinpäätösmenettelyn yleisiä perusteita sekä valtion tilinpäätöskertomusta;

<a id="chapter-2-section-4-subsection-1-paragraph-7"></a>

<a id="chapter-2-section-4-subsection-1-paragraph-12"></a>
- **12.** metallirahoja;

<a id="chapter-2-section-4-subsection-1-paragraph-13"></a>
- **13.** valtionperintöjä;

<a id="chapter-2-section-4-subsection-1-paragraph-14"></a>
- **14.** Valtiokonttoria;

<a id="chapter-2-section-4-subsection-1-paragraph-15"></a>
- **15.** Senaatti\-kiinteistöjä\.

### 5 § Vero\-osasto

<a id="chapter-2-section-5-subsection-1"></a>
#### \(1\)

Vero\-osasto valmistelee asiat, jotka koskevat:

<a id="chapter-2-section-5-subsection-1-paragraph-1"></a>
- **1.** veropolitiikan suunnittelua ja veropoliittisten toimenpiteiden vaikutusten selvittämistä;

<a id="chapter-2-section-5-subsection-1-paragraph-2"></a>
- **2.** verojärjestelmän kehittämistä;

<a id="chapter-2-section-5-subsection-1-paragraph-3"></a>
- **3.** veroja ja veronluontoisia maksuja;

<a id="chapter-2-section-5-subsection-1-paragraph-4"></a>

<a id="chapter-2-section-5-subsection-1-paragraph-6"></a>
- **6.** tullilaitosta;

<a id="chapter-2-section-5-subsection-1-paragraph-7"></a>
- **7.** verohallintoa\.

### 6 § Rahoitusmarkkinaosasto

<a id="chapter-2-section-6-subsection-1"></a>
#### \(1\)

<a id="chapter-2-section-6-subsection-1-paragraph-1"></a>
- **1.** rahoitusjärjestelmän kehittämistä;

<a id="chapter-2-section-6-subsection-1-paragraph-2"></a>

<a id="chapter-2-section-6-subsection-1-paragraph-4"></a>

<a id="chapter-2-section-6-subsection-1-paragraph-6"></a>

<a id="chapter-2-section-6-subsection-1-paragraph-8"></a>

<a id="chapter-2-section-6-subsection-1-paragraph-9"></a>
- **9.** arvopaperistamalla tapahtuvaa varainhankintaa;

<a id="chapter-2-section-6-subsection-1-paragraph-10"></a>
- **10.** valtiontakauksia;

<a id="chapter-2-section-6-subsection-1-paragraph-11"></a>
- **11.** Valtion vakuusrahastoa;

<a id="chapter-2-section-6-subsection-1-paragraph-12"></a>
- **12.** Valtion eläkerahastoa ottaen huomioon, mitä 7 §:n 11 kohdassa määrätään\.

<a id="chapter-2-section-7-subsection-1-paragraph-1"></a>

<a id="chapter-2-section-7-subsection-1-paragraph-2"></a>

<a id="chapter-2-section-7-subsection-1-paragraph-3"></a>
- **3.** valtion henkilöstön oikeudellista asemaa sekä neuvottelu\- ja sopimusjärjestelmän perusteita;

<a id="chapter-2-section-7-subsection-1-paragraph-4"></a>
- **4.** valtion eläkelainsäädäntöä;

<a id="chapter-2-section-7-subsection-1-paragraph-6"></a>
- **6.** hallinnon henkilöstön mitoitusta;

<a id="chapter-2-section-7-subsection-1-paragraph-7"></a>
- **7.** valtion työnantajaviestinnän edistämistä;

<a id="chapter-2-section-7-subsection-1-paragraph-8"></a>

<a id="chapter-2-section-7-subsection-1-paragraph-9"></a>
- **9.** toiminta\- ja taloussuunnittelua sekä valtion talousarvioesitystä ja talousarvion soveltamista henkilöstömenojen osalta;

<a id="chapter-2-section-7-subsection-1-paragraph-10"></a>

<a id="chapter-2-section-7-subsection-1-paragraph-11"></a>
- **11.** yhteistyössä rahoitusmarkkinaosaston kanssa valtion eläkerahastoa koskevia asioita, jos ne ovat työnantaja\- tai henkilöstöpoliittisesti merkittäviä\.

<a id="chapter-2-section-8-subsection-1-paragraph-9"></a>
- **9.** Tilastokeskusta\.

<a id="chapter-2-section-9"></a>
### 9 § Valtiovarain controller \-toiminto

<a id="chapter-2-section-9-subsection-1"></a>
#### \(1\)

Valtiovarain controller \-toiminnon tehtävistä säädetään valtion talousarviosta annetussa laissa \(423/1988\) ja valtion talousarviosta annetussa asetuksessa \(1243/1992\)\.

<a id="chapter-2-section-10"></a>
### 10 § Hallintoyksikkö

<a id="chapter-2-section-10-subsection-1"></a>
#### \(1\)

Hallintoyksikkö valmistelee asiat, jotka koskevat:

<a id="chapter-2-section-10-subsection-1-paragraph-1"></a>
- **1.** ministeriön yleistä hallintoa;

<a id="chapter-2-section-10-subsection-1-paragraph-2"></a>
- **2.** ministeriön henkilöstöhallintoa ja henkilöstön kehittämistä;

<a id="chapter-2-section-10-subsection-1-paragraph-3"></a>
- **3.** hallinnonalan toiminta\- ja taloussuunnittelua, kehysmenettelyä ja talousarviota sekä ministeriön taloushallintoa;

<a id="chapter-2-section-10-subsection-1-paragraph-4"></a>
- **4.** ministeriön tietopalvelun ja muun tietohallinnon yleistä järjestämistä;

<a id="chapter-2-section-10-subsection-1-paragraph-5"></a>
- **5.** muita ministeriön toiminnan tukipalveluja ja sisäisiä palveluja, jolleivät ne tämän työjärjestyksen nojalla kuulu muulle yksikölle\.

<a id="chapter-2-section-11"></a>
### 11 § Valtioneuvoston tietohallintoyksikkö

<a id="chapter-2-section-11-subsection-1"></a>
#### \(1\)

Valtioneuvoston tietohallintoyksikkö valmistelee valtiovarainministeriön toimialaan kuuluvat valtioneuvoston yhteistä tietohallintoa koskevat asiat sekä yksittäisen ministeriön sisäiseen tietohallintoon kuuluvat asiat, joista se palvelusopimuksen nojalla on ottanut vastatakseen\.

<a id="chapter-2-section-12"></a>
### 12 § Kansainvälisten asioiden sihteeristö

<a id="chapter-2-section-12-subsection-1"></a>
#### \(1\)

Kansainvälisten asioiden sihteeristö avustaa ministeriön johtoa ja osastoja Euroopan unioniin liittyvissä sekä muissa kansainvälisissä asioissa, niiden valmistelun yhteensovittamisessa sekä niitä koskevassa yhteydenpidossa ministeriön ulkopuolelle\.

<a id="chapter-2-section-13"></a>
### 13 § Johdon tuki

<a id="chapter-2-section-13-subsection-1"></a>
#### \(1\)

Johdon tuki avustaa ministeriön johtoa johtoryhmän asioiden valmistelun yhteensovittamisessa sekä muissa johdon ja johtoryhmän toimeksi antamissa asioissa\.

<a id="chapter-2-section-13-subsection-2"></a>
#### \(2\)

Johdon tuen omistajaohjausryhmä avustaa ministeriön johtoa ministeriön hallinnonalan valtionyhtiöiden ja valtion osakkuusyhtiöiden omistajaohjausta ja \-politiikkaa koskevien asioiden valmistelussa\.

<a id="chapter-2-section-14"></a>
### 14 § Viestintä

<a id="chapter-2-section-14-subsection-1"></a>
#### \(1\)

Viestintä avustaa ministeriön johtoa ja osastoja ulkoisessa ja sisäisessä viestinnässä sekä koordinoi ja kehittää ministeriön viestintää\.

<a id="chapter-2-section-15"></a>
### 15 § Osastojen sisäiset työjärjestykset

<a id="chapter-2-section-15-subsection-1"></a>
#### \(1\)

Osaston sisäisestä organisaatiosta ja tehtävien jaosta määrätään tarvittaessa tarkemmin osaston sisäisessä työjärjestyksessä\.

<a id="chapter-2-section-15-subsection-2"></a>
#### \(2\)

Osaston päällikkö vahvistaa osaston sisäisen työjärjestyksen sekä määrää henkilöstönsä sijoittamisesta sisäisiin yksiköihin tai erikseen määrättäviin tehtäviin\.

<a id="chapter-2-section-16"></a>
### 16 § Taloustieteellinen neuvosto

<a id="chapter-2-section-16-subsection-1"></a>
#### \(1\)

Valtiovarainministeriön yhteydessä toimii taloustieteellisenä asiantuntijaelimenä taloustieteellinen neuvosto\.

<a id="chapter-2-section-16-subsection-2"></a>
#### \(2\)

Neuvosto laatii ministeriön käyttöön lausuntoja ja selvityksiä talouspolitiikan valmisteluun liittyvistä taloustieteellisesti merkityksellisistä kysymyksistä\. Neuvoston muodostavat neuvoston puheenjohtaja ja varapuheenjohtaja, jotka määrätään valtiovarainministeriön virkamiehistä, sekä enintään kuusi ministeriön kerrallaan enintään kolmeksi vuodeksi kutsumaa taloustieteen eri haarojen korkeaa tieteellistä asiantuntemusta edustavaa jäsentä\. Ministeri toimii neuvoston kokoukseen osallistuessaan sen puheenjohtajana\.

<a id="chapter-2-section-16-subsection-3"></a>
#### \(3\)

Neuvostosta ja sen työn järjestämisestä annetaan tarkempia määräyksiä sen asettamispäätöksessä\.

<a id="chapter-2-section-17"></a>
### 17 § Valmius\- ja suojeluorganisaatio

<a id="chapter-2-section-17-subsection-1"></a>
#### \(1\)

Valtiovarainministeriön valmiuspäällikkönä toimii hallinnollinen alivaltiosihteeri\. Valmiuspäällikön tehtävänä on ohjata ja sovittaa yhteen hallinnonalan poikkeusoloihin varautumista\. Valmiuspäällikköä avustaa valmiussuunnittelussa hänen määräämänsä virkamies\.

<a id="chapter-2-section-17-subsection-2"></a>
#### \(2\)

Valtiovarainministeriön suojelujohtajan määrää hallinnollinen alivaltiosihteeri\. Muusta suojeluorganisaatiosta sekä suojelutoiminnasta määrätään eri toimipaikkoja koskevissa suojelusuunnitelmissa, jotka vahvistaa hallinnollinen alivaltiosihteeri\.

<a id="chapter-3"></a>
## 3 luku Johtaminen

<a id="chapter-3-section-18"></a>
### 18 § Johtamis\- ja ohjausvastuut

<a id="chapter-3-section-18-subsection-1"></a>
#### \(1\)

Ministeri johtaa ministeriön ja hallinnonalan toimintaa\.

<a id="chapter-3-section-18-subsection-2"></a>
#### \(2\)

Ministeriä avustaa ja edustaa ministerin toimikaudeksi nimitetty valtiosihteeri siten, kuin valtiosihteerin tehtävistä on säädetty valtioneuvoston ohjesäännön [\(262/2003\) 44 §:ssä](<https://www.finlex.fi/fi/lainsaadanto/2003/262#chp_6__sec_44>) ja ministeri on tarvittaessa erikseen tarkemmin määrännyt\.

<a id="chapter-3-section-18-subsection-3"></a>
#### \(3\)

Muuna virkamiesjohtona ministeriön johtamisesta vastaavat valtiosihteeri kansliapäällikkönä ja alivaltiosihteerit\. He johtavat ministerin vahvistaman työnjaon mukaisesti hallinnonalan virastojen ja laitosten tulosohjausta, hallinnonalan liikelaitoksia ja talousarvion ulkopuolisia rahastoja koskevien asioiden valmistelua sekä hallinnonalan valtionyhtiöiden ja valtion osakkuusyhtiöiden omistajaohjausta\.

<a id="chapter-3-section-18-subsection-4"></a>
#### \(4\)

Jollei ministeri ole työnjaosta muuta päättänyt, avustavat valtiosihteeriä kansliapäällikkönä ja alivaltiosihteereitä hallinnonalan virastojen ja liikelaitosten ohjauksessa sekä talousarvion ulkopuolisia rahastoja koskevien asioiden valmistelussa osastot edellä tässä työjärjestyksessä määrätyn osastojen toimialajaon mukaisesti\. Lisäksi valmistelussa avustavat ohjausvastuussa olevan valtiosihteerin kansliapäällikkönä tai alivaltiosihteereiden tarvittaessa erikseen nimeämät valmisteluryhmät tai virkamiehet\.

<a id="chapter-3-section-18-subsection-5"></a>
#### \(5\)

Hallinnonalan valtionyhtiöiden ja valtion osakkuusyhtiöiden omistajaohjauksen ja \-politiikan valmistelussa valtiosihteeriä kansliapäällikkönä ja alivaltiosihteereitä avustaa johdon tuen omistajaohjausryhmä\.

<a id="chapter-3-section-18-subsection-6"></a>
#### \(6\)

Osastopäälliköt vastaavat johtamisesta osastoillaan\.

<a id="chapter-3-section-19"></a>
### 19 § Tulostavoitteiden asettaminen

<a id="chapter-3-section-19-subsection-1"></a>
#### \(1\)

Ministeri asettaa ministeriön sekä virastojen ja laitosten keskeiset tulostavoitteet\.

<a id="chapter-3-section-19-subsection-2"></a>
#### \(2\)

Valtiosihteeri kansliapäällikkönä ja alivaltiosihteerit asettavat osastojen keskeiset tulostavoitteet johdettaviensa toimialojen osalta osastopäälliköiden kanssa käytävien tuloskeskustelujen pohjalta\.

<a id="chapter-3-section-19-subsection-3"></a>
#### \(3\)

Osastopäälliköt asettavat osastojen muut tulostavoitteet ja vahvistavat osastojen toimintasuunnitelmat yksiköiden päälliköiden kanssa käytävien tuloskeskustelujen pohjalta\.

<a id="chapter-3-section-19-subsection-4"></a>
#### \(4\)

Henkilötason johtamisessa ministeriössä hyödynnetään tulos\- ja kehityskeskusteluja\.

<a id="chapter-3-section-20"></a>
### 20 § Ministeriön johtoryhmä

<a id="chapter-3-section-20-subsection-1"></a>
#### \(1\)

Ministeriön johtoryhmä käsittelee hallinnonalan ja ministeriön toimintaan keskeisesti vaikuttavat strategiset linjaukset, osastojen toiminnan yhteensovittamista koskevat asiat, periaatteellisesti tärkeät asiat sekä muut asiat, joista puheenjohtaja niin määrää\.

<a id="chapter-3-section-20-subsection-2"></a>
#### \(2\)

Johtoryhmän puheenjohtajana toimii ministeri tai häntä edustava valtiosihteeri\. Heidän poissa ollessaan puheenjohtajana toimii valtiosihteeri kansliapäällikkönä\. Muina virkamiesjäseninä johtoryhmään kuuluvat alivaltiosihteerit\.

<a id="chapter-3-section-20-subsection-3"></a>
#### \(3\)

Hallintojohtaja ja viestinnän päällikkö osallistuvat johtoryhmän kokouksiin\.

<a id="chapter-3-section-20-subsection-4"></a>
#### \(4\)

Valtiosihteeri kansliapäällikkönä määrää johtoryhmälle sihteerin\.

<a id="chapter-3-section-21"></a>
### 21 § Laajennettu johtoryhmä

<a id="chapter-3-section-21-subsection-1"></a>
#### \(1\)

Laajennettu johtoryhmä käsittelee ministeriön ja hallinnonalan toimintaa ohjaavat keskeiset suunnitelmat ja niiden toteuttamisen edellyttämät voimavarakehykset, keskeiset ministeriön kaikkia osastoja koskevat yhteiset asiat sekä muut puheenjohtajan määräämät asiat\.

<a id="chapter-3-section-21-subsection-2"></a>
#### \(2\)

Laajennetun johtoryhmän puheenjohtajana toimii ministeri tai häntä edustava valtiosihteeri\. Heidän poissa ollessaan puheenjohtajana toimii valtiosihteeri kansliapäällikkönä\.

<a id="chapter-3-section-21-subsection-3"></a>
#### \(3\)

Laajennettuun johtoryhmään kuuluvat valtiosihteerin kansliapäällikkönä lisäksi muina virkamiesjäseninä alivaltiosihteerit, osastopäälliköt, hallintojohtaja, kansainvälisten asioiden sihteeristön päällikkö, viestinnän päällikkö sekä valtioneuvoston controller\.

<a id="chapter-3-section-21-subsection-4"></a>
#### \(4\)

Valtiosihteeri kansliapäällikkönä määrää laajennetulle johtoryhmälle sihteerin\.

<a id="chapter-3-section-22"></a>
### 22 § Muut johtoryhmät

<a id="chapter-3-section-22-subsection-1"></a>
#### \(1\)

Ministeri voi asettaa muitakin johtoryhmiä sovittamaan yhteen asioiden valmistelua\.

<a id="chapter-3-section-23"></a>
### 23 § Euroopan unioniin liittyvien sekä muiden kansainvälisten asioiden valmistelu

<a id="chapter-3-section-23-subsection-1"></a>
#### \(1\)

Ministeriön osastot vastaavat toimialaansa liittyvien Euroopan unionissa käsiteltävien sekä muiden kansainvälisten asioiden valmistelusta kansainvälisten asioiden sihteeristön sovittaessa yhteen valmistelua ministeriön johdon apuna\.

<a id="chapter-4"></a>
## 4 luku Johtavien virkamiesten tehtävät ja sijaiset

<a id="chapter-4-section-24"></a>
### 24 § Valtiosihteerin tehtävät

<a id="chapter-4-section-24-subsection-1"></a>
#### \(1\)

Ministerin apuna ja edustajana toimivan ministerin toimikaudeksi nimitetyn valtiosihteerin tehtävistä on säädetty valtioneuvoston ohjesäännön 44 §:ssä\.

<a id="chapter-4-section-25"></a>
### 25 § Valtiosihteerin kansliapäällikkönä tehtävät

<a id="chapter-4-section-25-subsection-1"></a>
#### \(1\)

Valtiosihteerin kansliapäällikkönä tulee johtaa, kehittää ja valvoa ministeriön ja sen hallinnonalan toimintaa siten, kuin ministeriön kansliapäällikön tehtävistä on säädetty valtioneuvoston ohjesäännön 45 §:ssä\.

<a id="chapter-4-section-26"></a>
### 26 § Hallinnollisen alivaltiosihteerin tehtävät

<a id="chapter-4-section-26-subsection-1"></a>
#### \(1\)

Ministerin hallinnolliseksi alivaltiosihteeriksi määräämän alivaltiosihteerin tulee valtiosihteerin kansliapäällikkönä apuna kehittää ja yhteen sovittaa ministeriön sisäistä toimintaa, organisaatiota ja henkilöstöpolitiikkaa ja johtaa henkilöstöosaston, hallinnon kehittämisosaston, hallintoyksikön, johdon tuen ja valtioneuvoston tietohallintoyksikön toimialaan kuuluvien asioiden valmistelua\.

<a id="chapter-4-section-27"></a>
### 27 § Kansantaloudellisten asioiden alivaltiosihteerin tehtävät

<a id="chapter-4-section-27-subsection-1"></a>
#### \(1\)

Ministerin kansantaloudellisten asioiden alivaltiosihteeriksi määräämän alivaltiosihteerin tulee valtiosihteerin kansliapäällikkönä apuna johtaa ja sovittaa yhteen erityisesti kansantalousosaston ja rahoitusmarkkinaosaston toimialaan kuuluvien sekä Euroopan unionin talous\- ja rahoituskomiteassa käsiteltävien asioiden valmistelua\.

<a id="chapter-4-section-28"></a>
### 28 § Valtiosihteerin kansliapäällikkönä ja alivaltiosihteereiden tehtävät hallinnonalan ohjauksessa ja valvonnassa

<a id="chapter-4-section-28-subsection-1"></a>
#### \(1\)

Valtiosihteerin kansliapäällikkönä ja alivaltiosihteereiden tehtävistä ja työnjaosta samoin kuin heidän avustamisestaan hallinnonalan virastojen, liikelaitosten, rahastojen ja yhtiöiden ohjauksessa ja valvonnassa on säädetty 18 §:ssä\.

<a id="chapter-4-section-29"></a>
### 29 § Osastopäällikön tehtävät

<a id="chapter-4-section-29-subsection-1"></a>
#### \(1\)

Osastopäällikön tulee sen lisäksi, mitä muualla tässä työjärjestyksessä on määrätty:

<a id="chapter-4-section-29-subsection-1-paragraph-1"></a>
- **1.** johtaa osaston toimintaa siten, että sille kuuluvat tehtävät hoidetaan tuloksellisesti;

<a id="chapter-4-section-29-subsection-1-paragraph-2"></a>
- **2.** seurata toimialansa kehitystä ja kehittää osaston toimintaa;

<a id="chapter-4-section-29-subsection-1-paragraph-3"></a>
- **3.** huolehtia osaston henkilöstön kehittämisestä ja siitä, että osastolle kuuluvien tehtävien suorittamiselle on riittävät edellytykset\.

<a id="chapter-4-section-29-subsection-2"></a>
#### \(2\)

Hallintojohtajasta, valtioneuvoston tietohallintoyksikön päällikkönä toimivasta tietohallintojohtajasta, valtioneuvoston controllerista, kansainvälisten asioiden sihteeristön päälliköstä ja viestinnän päälliköstä on soveltuvin osin voimassa, mitä 1 momentissa ja muualla tässä työjärjestyksessä säädetään osastopäälliköstä\.

<a id="chapter-4-section-30"></a>
### 30 § Ministerin erityisavustaja

<a id="chapter-4-section-30-subsection-1"></a>
#### \(1\)

Ministerin erityisavustajasta on säädetty valtioneuvoston ohjesäännön 45 a §:ssä\.

<a id="chapter-4-section-31"></a>
### 31 § Sijaisten määrääminen

<a id="chapter-4-section-31-subsection-1"></a>
#### \(1\)

Valtiosihteerin kansliapäällikkönä ja alivaltiosihteerien sijaiset määrää ministeri\.

<a id="chapter-4-section-31-subsection-2"></a>
#### \(2\)

Osastopäällikön, hallintojohtajan ja valtioneuvoston tietohallintoyksikön päällikkönä toimivan tietohallintojohtajan sijaiset määrää valtiosihteeri kansliapäällikkönä\. Valtioneuvoston controllerin sijaisesta säädetään valtion talousarviosta annetussa laissa\.

<a id="chapter-4-section-31-subsection-3"></a>
#### \(3\)

Muissa kuin edellä tarkoitetuissa tapauksissa määrää tehtävien hoidosta virkamiehen estyneenä ollessa asianomaisen osaston tai osaston sisäisen yksikön päällikkö\.

<a id="chapter-5"></a>
## 5 luku Asioiden valmistelu

<a id="chapter-5-section-32"></a>
### 32 § Vahvistetusta työnjaosta poikkeaminen

<a id="chapter-5-section-32-subsection-1"></a>
#### \(1\)

Kukin virkamies on velvollinen vahvistetusta työnjaosta riippumatta tarvittaessa suorittamaan ne tehtävät, jotka ministeri, valtiosihteeri kansliapäällikkönä, alivaltiosihteeri taikka osaston tai osaston sisäisen yksikön päällikkö hänelle määrää\.

<a id="chapter-5-section-32-subsection-2"></a>
#### \(2\)

Valtiosihteeri kansliapäällikkönä, alivaltiosihteeri taikka osaston tai osaston sisäisen yksikön päällikkö voi yksittäistapauksessa ottaa valmisteltavakseen ja esiteltäväkseen asian, joka muuten olisi hänen alaisensa virkamiehen valmisteltava\.

<a id="chapter-5-section-32-subsection-3"></a>
#### \(3\)

Edellä 2 momentissa tarkoitetusta menettelystä on neuvoteltava asianomaisen kanssa\.

<a id="chapter-5-section-33"></a>
### 33 § Johdolle ja esimiehille tiedottaminen

<a id="chapter-5-section-33-subsection-1"></a>
#### \(1\)

Ministeri, valtiosihteeri, valtiosihteeri kansliapäällikkönä ja alivaltiosihteerit on pidettävä tietoisena tärkeimmistä ministeriön ja osastojen toimialoilla esille tulevista ja vireillä olevista asioista\.

<a id="chapter-5-section-33-subsection-2"></a>
#### \(2\)

Ministerin erityisavustajalle on annettava ne tiedot, joita hän tarvitsee tehtävänsä suorittamiseksi\. Erityisavustajan on annettava virkamiehelle tämän tehtävien hoitamiseen tarvitsemat tiedot\.

<a id="chapter-5-section-34"></a>
### 34 § Lupa esittelylistan jakamiseen

<a id="chapter-5-section-34-subsection-1"></a>
#### \(1\)

Esittelylistaa ei saa muutoin kuin pakottavista syistä jakaa ennen kuin asia on selostettu ministerille ja hän on hyväksynyt sen ottamisen esittelyyn\.

<a id="chapter-5-section-34-subsection-2"></a>
#### \(2\)

Mitä edellä on määrätty esittelylistojen jakamisesta, on noudatettava myös valtiovarainministeriön kannanottoja sisältävien muistioiden jakamisessa ministerivaliokuntien käsittelyä varten\.

<a id="chapter-5-section-34-subsection-3"></a>
#### \(3\)

Muutoinkin milloin asia on periaatteellisesti tärkeä tai laajakantoinen, on muistio tai ministeriön muu kannanotto saatettava ministerin hyväksyttäväksi ennen kuin se toimitetaan ministeriön ulkopuolelle\.

<a id="chapter-5-section-35"></a>
### 35 § Osastojen välinen yhteistyö ja osastoille tiedottaminen

<a id="chapter-5-section-35-subsection-1"></a>
#### \(1\)

Ministeriön osastot ja yksiköt antavat tarpeen mukaan toimialansa asiantuntijapalveluita toiselle osastolle ja yksikölle niiden käsitellessä asiaa, joka koskee osaksi myös toisen osaston toimialaa\. Asianomaiset osastopäälliköt sopivat kulloinkin tarkemmin asiantuntijapalveluiden antamisesta toiselle osastolle ja osastojen yhteisestä valmistelusta\. Valtiosihteeri kansliapäällikkönä tai asianomainen alivaltiosihteeri määrää tarvittaessa osastojen yhteisestä valmistelusta\.

<a id="chapter-5-section-35-subsection-2"></a>
#### \(2\)

Asiasta, joka koskee myös toisen osaston toimialaa, kuin mistä se esitellään, on sitä valmisteltaessa hyvissä ajoin neuvoteltava kysymyksessä olevan osaston asianomaisten virkamiesten kanssa\.

<a id="chapter-5-section-35-subsection-3"></a>
#### \(3\)

Osastojen on toimitettava käsittelemistään asioista annetut tärkeimmät päätökset ja lausunnot tiedoksi niille, joita asian voidaan katsoa koskevan\.

<a id="chapter-5-section-35-subsection-4"></a>
#### \(4\)

Ministeriössä pidettävistä kokouksista ja neuvotteluista, joissa tehdään päätöksiä ja toimenpideratkaisuja, jotka ovat toiminnallisesti merkityksellisiä tai joilla on ministeriön sisällä tiedotusarvoa, laaditaan tarpeen mukaan päätös\- ja toimenpidemuistio, joka toimitetaan kaikille osastoille, joita asia koskee\.

<a id="chapter-5-section-35-subsection-5"></a>
#### \(5\)

Keskeisten päätösten, lausuntojen ja muistioiden saatavuus tulee varmistaa tallentamalla ne dokumentinhallintajärjestelmän sähköiseen arkistoon\.

<a id="chapter-5-section-36"></a>
### 36 § Yhteistyö tiedottamisessa

<a id="chapter-5-section-36-subsection-1"></a>
#### \(1\)

Tärkeimpien asioiden tarkoituksenmukainen ulkoinen ja sisäinen tiedottaminen on suunniteltava jo asioiden valmisteluvaiheessa yhteistyössä ministeriön viestinnän kanssa\.

<a id="chapter-5-section-36-subsection-2"></a>
#### \(2\)

Osastojen päälliköiden on huolehdittava sisäisestä tiedonvälityksestä ja sen edistämiseksi järjestettävä tarvittaessa osasto\-, yksikkö\- tai muita työyhteisökokouksia\.

<a id="chapter-5-section-37"></a>
### 37 § Ministeriön edustaminen valmisteluelimissä

<a id="chapter-5-section-37-subsection-1"></a>
#### \(1\)

Valtiovarainministeriöstä komiteaan tai toimikuntaan tahi muuhun sivuelimeen nimetyn tulee antaa tietoja komitean tai toimikunnan työstä ja siinä esille tulevista kannanmäärittelyistä ennen kaikkea taloudellisesti merkittävissä tai periaatteellisesti tärkeissä asioissa esimiehilleen ja asianomaisen osaston päällikölle\. Mikäli osastopäällikkö katsoo asian valtiovarainministeriön kannalta erittäin tärkeäksi, on asiasta informoitava myös ministeriä, valtiosihteeriä, valtiosihteeriä kansliapäällikkönä ja alivaltiosihteerejä\.

<a id="chapter-5-section-37-subsection-2"></a>
#### \(2\)

Kun komiteassa tai toimikunnassa käsiteltävät asiat koskevat tai sivuavat myös muun kuin asianomaisen henkilön oman yksikön toimialaa, tulee henkilön olla yhteydessä myös tähän toiseen yksikköön\.

<a id="chapter-5-section-37-subsection-3"></a>
#### \(3\)

Kun komiteassa tai toimikunnassa on edustettuna useampia henkilöitä valtiovarainministeriöstä, tulee heidän kannanmäärittelyjensä yhteensovittamiseksi neuvotella etukäteen esimiestensä kanssa\.

<a id="chapter-6"></a>
## 6 luku Sisäinen hallinto

<a id="chapter-6-section-38"></a>
### 38 § Sisäisen hallinnon työnjako

<a id="chapter-6-section-38-subsection-1"></a>
#### \(1\)

Ministeriön sisäistä hallintoa johtaa valtiosihteerin kansliapäällikkönä apuna hallinnollinen alivaltiosihteeri\. Heidän apunaan ovat hallintoyksikkö, osastojen päälliköt sekä näiden määräämät henkilöt\.

<a id="chapter-6-section-38-subsection-2"></a>
#### \(2\)

Osastojen päälliköt määräävät, mikäli tästä työjärjestyksestä ei muuta johdu, miten osaston sisäisen hallinnon tehtävät järjestetään\.

<a id="chapter-6-section-39"></a>
### 39 § Vuosilomien vahvistaminen

<a id="chapter-6-section-39-subsection-1"></a>
#### \(1\)

Osastojen henkilöstön vuosilomat vahvistaa osaston päällikkö\.

<a id="chapter-6-section-39-subsection-2"></a>
#### \(2\)

Osastojen päälliköiden lomat vahvistaa hallinnollinen alivaltiosihteeri, alivaltiosihteerien vuosilomat valtiosihteeri kansliapäällikkönä ja valtiosihteerin sekä valtiosihteerin kansliapäällikkönä vuosilomat ministeri\.

<a id="chapter-6-section-39-subsection-3"></a>
#### \(3\)

Osaston päällikön määräämät virkamiehet voivat hyväksyä tai määrätä vähäisiä poikkeuksia hyväksyttyyn vuosilomajärjestykseen ja myös vahvistaa vuosilomajärjestyksessä lomakauden ulkopuolella pidettäväksi merkittyjen lomapäivien ajankohdan\.

<a id="chapter-6-section-39-subsection-4"></a>
#### \(4\)

Osastojen on toimitettava ehdotus päällikkönsä vuosilomaksi ja vuosiloma\-ajoiksi hallintoyksikölle vuosittain huhtikuun 15 päivään mennessä hallinnolliselle alivaltiosihteerille esittelyä varten\. Vahvistetut muun henkilökunnan vuosilomat ja vuosiloma\-ajat on toimitettava hallintoyksikköön tiedoksi vuosittain toukokuun alkuun mennessä\.

<a id="chapter-6-section-39-subsection-5"></a>
#### \(5\)

Vuosilomat on vahvistettava siten, että osastojen ja yksiköiden toimintakyky säilyy riittävänä kaikissa tilanteissa\.

<a id="chapter-6-section-40"></a>
### 40 § Matkamääräysten antaminen

<a id="chapter-6-section-40-subsection-1"></a>
#### \(1\)

Valtiosihteerille ja valtiosihteerille kansliapäällikkönä antaa virkamatkamääräyksen ministeri ja alivaltiosihteereille valtiosihteeri kansliapäällikkönä\.

<a id="chapter-6-section-40-subsection-2"></a>
#### \(2\)

Osastojen päälliköille virkamatkamääräyksen antaa hallinnollinen alivaltiosihteeri\.

<a id="chapter-6-section-40-subsection-3"></a>
#### \(3\)

Ministeriön muut virkamiehet tekevät virkamatkoja osaston päällikön tai osaston sisäisessä työjärjestyksessä määrätyn muun esimiehen antaman matkamääräyksen perusteella\.

<a id="chapter-6-section-40-subsection-4"></a>
#### \(4\)

Valtionhallinnon ulkopuolisen tahon tarjoaman virkamatkan vastaanottamisesta päättää ulkomaan matkojen osalta hallinnollinen alivaltiosihteeri ja kotimaan matkojen osalta osaston päällikkö\.

<a id="chapter-7"></a>
## 7 luku Ratkaisuvallan järjestäminen

<a id="chapter-7-section-41"></a>
### 41 § Ministerin ratkaisuvalta

<a id="chapter-7-section-41-subsection-1"></a>
#### \(1\)

Ministerin ratkaisuvallasta säädetään valtioneuvostosta annetussa laissa [\(175/2003\)](<https://www.finlex.fi/fi/lainsaadanto/2003/175>)\.

<a id="chapter-7-section-42"></a>
### 42 § Virkamiesten ratkaisuvalta

<a id="chapter-7-section-42-subsection-1"></a>
#### \(1\)

Ministeriön esittelijöinä toimivien virkamiesten ratkaistavaksi voidaan antaa valtioneuvoston ohjesäännön 36 §:ssä säädettyjä, muita kuin yhteiskunnallisesti tai taloudellisesti merkittäviä asioita siten kuin tässä työjärjestyksessä tarkemmin säädetään\.

<a id="chapter-7-section-42-subsection-2"></a>
#### \(2\)

Valtioneuvoston controllerin ja apulaiscontrollerin ratkaisuvallasta valtiovarain controller \-toiminnon havaintojen esittämistä ja tietojen pyytämistä ja antamista koskevissa asioissa säädetään valtion talousarviosta annetussa laissa\.

<a id="chapter-7-section-43"></a>
### 43 § Yhteiskunnallisesti tai taloudellisesti merkittävä asia

<a id="chapter-7-section-43-subsection-1"></a>
#### \(1\)

Ministeri ratkaisee asian, jonka virkamies muutoin saisi ratkaista, jos se on yhteiskunnallisesti tai taloudellisesti merkittävä taikka jos siitä on hankittava valtioneuvoston raha\-asiainvaliokunnan lausunto\.

<a id="chapter-7-section-43-subsection-2"></a>
#### \(2\)

Jos on epäselvää tai harkinnanvaraista, onko asia katsottava yhteiskunnallisesti tai taloudellisesti niin merkittäväksi, että se on saatettava ministerin ratkaistavaksi, ministeri päättää, katsotaanko asia sellaiseksi\. Ennen kysymyksen saattamista ministerin ratkaistavaksi, on esittelijän neuvoteltava asiasta sen virkamiehen kanssa, jolle ratkaisuvalta muutoin kuuluisi\.

<a id="chapter-7-section-44"></a>
### 44 § Ministerin ja eräiden virkamiesten pidätysoikeus

<a id="chapter-7-section-44-subsection-1"></a>
#### \(1\)

Ministeri voi pidättää itsellään päätösvallan asiassa, jonka virkamies tämän työjärjestyksen mukaan saisi ratkaista\. Sama oikeus on yksittäistapauksessa valtiosihteerillä kansliapäällikkönä, alivaltiosihteerillä ja osaston päälliköllä asiassa, jonka ratkaiseminen kuuluu hänen alaiselleen virkamiehelle\.

<a id="chapter-7-section-44-subsection-2"></a>
#### \(2\)

Pidätysoikeuden käyttämisestä on aina ilmoitettava asianomaiselle virkamiehelle\.

<a id="chapter-7-section-45"></a>
### 45 § Esittely

<a id="chapter-7-section-45-subsection-1"></a>
#### \(1\)

Ministeriössä päätettävät asiat ratkaistaan esittelystä, jollei asia koske ainoastaan rekisteröinti\- tai kirjaamistoimenpidettä\. Palvelussuhdetta koskevia asioita lukuun ottamatta esittelyä ei kuitenkaan tarvita asioissa, jotka koskevat ministeriön sisäistä henkilöstö\- tai taloushallintoa, ellei erikseen ole toisin säädetty tai määrätty\.

<a id="chapter-7-section-45-subsection-2"></a>
#### \(2\)

Valtiovarainministeriössä esittelijöinä voivat toimia perusvaativuustasolle 9 tai sitä ylemmälle sijoitetut virkamiehet sekä sisäisen hallinnon tehtävissä myös perusvaativuustasolle 7 ja 8 sijoitetut virkamiehet\.

<a id="chapter-8"></a>
## 8 luku Nimittämistä ja virkavapautta koskevien asioiden ratkaiseminen

<a id="chapter-8-section-46"></a>
### 46 § Ministerin ratkaistavat nimitysasiat

<a id="chapter-8-section-46-subsection-1"></a>
#### \(1\)

Ministerin ratkaistavia nimitysasioita ovat:

<a id="chapter-8-section-46-subsection-1-paragraph-1"></a>
- **1.** ministeriön päätettävä virkaan nimittäminen ja työsopimussuhteeseen ottaminen silloin, kun asianomaisen tehtäväkohtainen palkanosa määräytyy perusvaativuustason 10 tai sitä ylemmän tason mukaisesti sekä kun euromääräiseksi määrätty palkkaus vastaa vaativuustason 102 palkkausta tai on sitä suurempi;

<a id="chapter-8-section-46-subsection-1-paragraph-2"></a>
- **2.** ministeriön päätettävä määräaikaiseen virkasuhteeseen nimittäminen silloin, kun vastaavaan virkaan nimittää tasavallan presidentti tai valtioneuvosto\.

<a id="chapter-8-section-47"></a>
### 47 § Hallinnollisen alivaltiosihteerin ratkaistavat nimitysasiat

<a id="chapter-8-section-47-subsection-1"></a>
#### \(1\)

Hallinnollisen alivaltiosihteerin ratkaistavia nimitysasioita ovat:

<a id="chapter-8-section-47-subsection-1-paragraph-1"></a>
- **1.** ministeriön päätettävä virkaan nimittäminen ja työsopimussuhteeseen ottaminen silloin, kun virkaa tai tehtävää ei ole sijoitettu 48 §:ssä mainittujen päälliköiden johdettaviin organisaatioihin ja asian ratkaiseminen ei 46 §:n nojalla kuulu ministerille;

<a id="chapter-8-section-47-subsection-1-paragraph-2"></a>
- **2.** ministeriön päätettävä määräaikaiseen virkasuhteeseen nimittäminen silloin, kun vastaavaan virkaan nimittää ministeri\.

<a id="chapter-8-section-48"></a>
### 48 § Osastopäällikön ja eräiden muiden päälliköiden ratkaistavat nimitysasiat

<a id="chapter-8-section-48-subsection-1"></a>
#### \(1\)

Osastopäällikön, hallintojohtajan, valtioneuvoston tietohallintoyksikön päällikkönä toimivan tietohallintojohtajan sekä valtioneuvoston controllerin ratkaistavia ministeriössä päätettäviä nimitysasioita ovat:

<a id="chapter-8-section-48-subsection-1-paragraph-1"></a>
- **1.** ministeriön päätettävä virkaan nimittäminen ja työsopimussuhteeseen ottaminen silloin, kun virka tai tehtävä on sijoitettu heidän johdettavaansa organisaatioon ja asian ratkaiseminen ei 46 §:n nojalla kuulu ministerille;

<a id="chapter-8-section-48-subsection-1-paragraph-2"></a>
- **2.** ministeriön päätettävä määräaikaiseen virkasuhteeseen nimittäminen silloin, kun tehtävä on sijoitettu heidän johdettavaansa organisaatioon eikä asian ratkaiseminen 47 §:n 2 kohdan nojalla kuulu hallinnolliselle alivaltiosihteerille\.

<a id="chapter-8-section-49"></a>
### 49 § Virkojen ja tehtävien sijoittaminen

<a id="chapter-8-section-49-subsection-1"></a>
#### \(1\)

Ministeriön yhteiset virat ja työsopimussuhteiset tehtävät sijoitetaan osastoille hallinnollisen alivaltiosihteerin päätöksellä\.

<a id="chapter-8-section-49-subsection-2"></a>
#### \(2\)

Sijoittamista koskeva päätös raukeaa, kun virka tai tehtävä tulee avoimeksi\.

<a id="chapter-8-section-49-subsection-3"></a>
#### \(3\)

Mitä edellä on sanottu, koskee myös määräaikaisia tehtäviä\.

<a id="chapter-8-section-50"></a>
### 50 § Ministeriössä päätettävä virkavapaus

<a id="chapter-8-section-50-subsection-1"></a>
#### \(1\)

Sellaisen virkavapauden tai vapautuksen työstä, johon asianomaisella on lain tai virka\- taikka työehtosopimuksen nojalla oikeus, myöntää hallintojohtaja\.

<a id="chapter-8-section-50-subsection-2"></a>
#### \(2\)

Enintään kolmen kuukauden pituisen harkinnanvaraisen virkavapauden tai sitä vastaavan vapautuksen työstä myöntää osaston tai yksikön päällikkö\. Osaston ja yksikön päällikölle tällaisen virkavapauden ja vapautuksen työstä myöntää hallinnollinen alivaltiosihteeri ja osasto\- ja yksikköjaon ulkopuoliselle henkilöstölle hallintojohtaja\.

<a id="chapter-8-section-50-subsection-3"></a>
#### \(3\)

Yli kolmen kuukauden pituisen harkinnanvaraisen virkavapauden tai vastaavan vapautuksen myöntää

<a id="chapter-8-section-50-subsection-3-paragraph-1"></a>
- **1.** ministeri, jos nimitystoimivalta on tasavallan presidentillä tai valtioneuvostolla;

<a id="chapter-8-section-50-subsection-3-paragraph-2"></a>
- **2.** hallinnollinen alivaltiosihteeri, jos nimitystoimivalta on hänellä tai ministerillä;

<a id="chapter-8-section-50-subsection-3-paragraph-3"></a>
- **3.** asianomainen osastopäällikkö, hallintojohtaja, valtioneuvoston tietohallintoyksikön päällikkönä toimiva tietohallintojohtaja tai valtioneuvoston controller, jos nimitystoimivalta on hänellä\.

<a id="chapter-9"></a>
## 9 luku Muiden asioiden ratkaiseminen

<a id="chapter-9-section-51"></a>
### 51 § Valtiosihteerin kansliapäällikkönä ratkaistavat asiat

<a id="chapter-9-section-51-subsection-1"></a>
#### \(1\)

Valtiosihteeri kansliapäällikkönä ratkaisee asiat, jotka koskevat lausunnon antamista asioissa, jotka kuuluvat useamman kuin yhden osaston tai yksikön toimialaan, jollei asia 52 §:n nojalla kuulu alivaltiosihteerin ratkaistavaksi\.

<a id="chapter-9-section-51-subsection-2"></a>
#### \(2\)

Valtiosihteeri kansliapäällikkönä ratkaisee myös asiat, jotka koskevat lausunnon antamista valtion talousarviosta annetun asetuksen 13 §:n 2 ja 3 momentissa sekä 17 §:n 3 momentissa tarkoitetuissa asioissa\.

<a id="chapter-9-section-52"></a>
### 52 § Alivaltiosihteerien ratkaistavat asiat

<a id="chapter-9-section-52-subsection-1"></a>
#### \(1\)

Asianomainen alivaltiosihteeri ratkaisee asiat, jotka koskevat lausunnon antamista useamman osaston tai yksikön valmisteltavista ja pääosin johdettavanaan olevaan toimialaan kuuluvista asioista\.

<a id="chapter-9-section-52-subsection-2"></a>
#### \(2\)

Hallinnollinen alivaltiosihteeri ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-52-subsection-2-paragraph-1"></a>
- **1.** valtuutusta edustaa ministeriötä tuomioistuimessa ja muussa viranomaisessa;

<a id="chapter-9-section-52-subsection-2-paragraph-2"></a>
- **2.** ministerin asettaman valmistelevan toimielimen määräajan jatkamista;

<a id="chapter-9-section-52-subsection-2-paragraph-3"></a>
- **3.** toimintamäärärahojen ja muiden ministeriön toimintaan osoitettujen määrärahojen käyttöä ja jakamista osastojen käyttöön;

<a id="chapter-9-section-52-subsection-2-paragraph-4"></a>
- **4.** ministeriön virkojen perustamista, lakkauttamista, siirtämistä ja nimikkeen muuttamista sekä yhteisten virkojen ja henkilöstön sijoittamista ministeriössä;

<a id="chapter-9-section-52-subsection-2-paragraph-5"></a>
- **5.** valtion virkaehtosopimuslain \(664/1970\) nojalla valtiovarainministeriön ratkaistavia sen virkamiesten palvelussuhteen ehtoja;

<a id="chapter-9-section-52-subsection-2-paragraph-6"></a>
- **6.** sivutoimilupaa ja sen peruuttamista sekä sivutoimen vastaanottamisen ja pitämisen kieltämistä;

<a id="chapter-9-section-52-subsection-2-paragraph-7"></a>
- **7.** ministeriön sisäistä hallintoa, jollei asia tämän työjärjestyksen nojalla kuulu muun virkamiehen ratkaistavaksi;

<a id="chapter-9-section-52-subsection-2-paragraph-8"></a>
- **8.** palvelusopimusta, jolla valtioneuvoston tietohallintoyksikkö ottaa vastatakseen yksittäisen ministeriön sisäisistä tietohallintopalveluista\.

<a id="chapter-9-section-53"></a>
### 53 § Osaston päällikön ratkaistavat asiat

<a id="chapter-9-section-53-subsection-1"></a>
#### \(1\)

Asiaa valmistelevan osaston päällikkö ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-53-subsection-1-paragraph-1"></a>
- **1.** lausunnon antamista osaston toimialaan kuuluvissa asioissa;

<a id="chapter-9-section-53-subsection-1-paragraph-2"></a>
- **2.** osaston käytettäviksi jaettuja tai sen toimialalle edelleen jaettaviksi osoitettuja määrärahoja\.

<a id="chapter-9-section-53-subsection-2"></a>
#### \(2\)

Asianomainen apulaisosastopäällikkö ratkaisee asiat, jotka koskevat lausunnon antamista osaston toimialaan kuuluvissa, merkitykseltään vähäisissä asioissa, jollei asia jäljempänä määrätyn perusteella kuulu muun virkamiehen ratkaistavaksi\.

<a id="chapter-9-section-54"></a>
### 54 § Budjettiosaston toimialaan kuuluvien asioiden ratkaiseminen

<a id="chapter-9-section-54-subsection-1"></a>
#### \(1\)

Budjettiosaston osastopäällikkö ratkaisee asiat, jotka koskevat Rahapaja Oy:n kanssa tehtäviä sopimuksia metallirahojen hankkimisesta valtiolle\.

<a id="chapter-9-section-54-subsection-2"></a>
#### \(2\)

Budjettiosaston budjettioikeudellisia asioita hoitavan yksikön päällikkö ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-54-subsection-2-paragraph-1"></a>
- **1.** luvan antamista tilivirastoille saada maksaa edellisille vuosille kuuluva meno kuluvan vuoden määrärahasta;

<a id="chapter-9-section-54-subsection-2-paragraph-2"></a>
- **2.** valtion talousarviosta annetun asetuksen 33 §:ssä, 41 b §:n 2 momentissa ja 62 §:n 2 momentissa tarkoitettujen lupien antamista;

<a id="chapter-9-section-54-subsection-2-paragraph-3"></a>
- **3.** valtiovarainministeriön hallinnonalan menorästin pitämistä edelleen tileissä\.

<a id="chapter-9-section-55"></a>
### 55 § Vero\-osaston toimialaan kuuluvien asioiden ratkaiseminen

<a id="chapter-9-section-55-subsection-1"></a>
#### \(1\)

Vero\-osaston osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-55-subsection-1-paragraph-1"></a>
- **1.** verotusmenettelystä annetun lain [\(1558/1995\) 89 ja 90 §:n](<https://www.finlex.fi/fi/lainsaadanto/1995/1558#chp_10__sec_89>) mukaan valtiovarainministeriön ratkaistavaksi kuuluvia veronhuojennus\- ja maksunlykkäyshakemuksia;

<a id="chapter-9-section-55-subsection-1-paragraph-2"></a>
- **2.** tullilain [\(1466/1994\) 8 §:n](<https://www.finlex.fi/fi/lainsaadanto/1994/1466#sec_8>) nojalla taloudellisesti, aluepoliittisesti tai muutoin merkittävistä syistä valtiovarainministeriön ratkaistavaksi otettua lupahakemusta vapaa\-alueen tai vapaavaraston perustamiseksi;

<a id="chapter-9-section-55-subsection-1-paragraph-3"></a>
- **3.** tullilain 35 §:n 2 momentissa tarkoitettua tavaran valtion laitokselle tai erityisestä syystä muullekin luovuttamista tai tavaran hävittämistä koskevaa valtiovarainministeriön päätöstä tai ohjetta\.

<a id="chapter-9-section-56"></a>
### 56 § Rahoitusmarkkinaosaston toimialaan kuuluvien asioiden ratkaiseminen

<a id="chapter-9-section-56-subsection-1"></a>
#### \(1\)

Rahoitusmarkkinaosaston virkamiehet ratkaisevat rahoitusmarkkinaosaston toimialaan kuuluvia asioita sen mukaan kuin jäljempänä säädetään ministerin ratkaistessa kuitenkin periaatteellisesti tärkeät ja laajakantoiset asiat ja aina asiat, jotka koskevat:

<a id="chapter-9-section-56-subsection-1-paragraph-1"></a>
- **1.** Valtion vakuusrahaston tekemän sopimuksen tai sitoumuksen muuttamista, kun muutos on periaatteellisesti merkittävä, sopimuksen tai sitoumuksen alkuperäistä tarkoitusta muuttava tai kun vaikutus valtion talouteen on merkittävä;

<a id="chapter-9-section-56-subsection-1-paragraph-2"></a>
- **2.** Valtion vakuusrahaston tilinpäätöksen hyväksymistä ja allekirjoittamista;

<a id="chapter-9-section-56-subsection-1-paragraph-3"></a>
- **3.** Valtion vakuusrahaston valtuustolle vahvistettavaksi esitettävän rahaston vuosittaisen talousarvion hyväksymistä;

<a id="chapter-9-section-56-subsection-1-paragraph-4"></a>
- **4.** Valtion vakuusrahastosta annetun lain \(379/1992\) 14 a §:n mukaisesti suoritetun erityistarkastuksen perusteella nostetussa vahingonkorvausoikeudenkäynnissä annettuun tuomioon tyytymistä ja siitä valittamista sekä päätöksiä, jotka koskevat kanteen nostamista tai siitä luopumista, sovintotarjouksen hyväksymistä tai tekemistä ja takavarikon poistamista, mikäli asioita ei ole vakuusrahastosta annetussa laissa tai muussa laissa säädetty muiden ratkaistaviksi\.

<a id="chapter-9-section-56-subsection-2"></a>
#### \(2\)

Rahoitusmarkkinaosaston osastopäällikkö ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-56-subsection-2-paragraph-1"></a>
- **1.** säästökassojen ja osuuspankkien yhteenliittymän keskusyhteisön sääntöjen vahvistamista;

<a id="chapter-9-section-56-subsection-2-paragraph-2"></a>
- **2.** Valtion vakuusrahastosta annetun lain 14 a §:n mukaisesti suoritetun erityistilintarkastuksen perusteella nostetun oikeudenkäynnin valvonnassa rahaston nimissä annettavia ohjeita asianajajille, asiakirjajulkisuusasioita sekä oikeudellisten lausuntojen hankkimista, mikäli asioita ei ole vakuusrahastosta annetussa laissa tai muussa laissa säädetty muiden ratkaistaviksi;

<a id="chapter-9-section-56-subsection-2-paragraph-3"></a>
- **3.** Valtion vakuusrahaston nimissä ennen Valtion vakuusrahastosta annetun lain muuttamisesta annetun lain \(245/1996\) voimaantuloa tehtyjen sopimusten ja sitoumusten täytäntöönpanoa sekä sopimuksiin ja sitoumuksiin tehtäviä muutoksia;

<a id="chapter-9-section-56-subsection-2-paragraph-4"></a>
- **4.** menon maksamista Valtion vakuusrahaston varoista\.

<a id="chapter-9-section-56-subsection-3"></a>
#### \(3\)

Ministerin määräämä rahoitusmarkkinaosaston finanssineuvos ratkaisee Valtion vakuusrahaston asiat, jotka koskevat:

<a id="chapter-9-section-56-subsection-3-paragraph-1"></a>
- **1.** rahastoa koskevan sopimuksen täsmentämistä ja muuttamista silloin, kun sopimuksen alkuperäistä tarkoitusta ja taloudellisia vaikutuksia sopijapuolille ei muuteta;

<a id="chapter-9-section-56-subsection-3-paragraph-2"></a>
- **2.** rahaston merkitsemiä pankkitukisijoituksia koskevan tulkintakysymyksen ratkaisemista edellyttäen, että ratkaisulla ei ole merkittäviä vaikutuksia valtion taloudelle;

<a id="chapter-9-section-56-subsection-3-paragraph-3"></a>
- **3.** pankkisijoituksiin ja rahaston hallussa oleviin muihin pääomatodistuksiin tehtävän maksusuorituksen hyväksymistä ja tarvittavan maksumerkinnän tekemistä sijoitusten ehtoja noudattaen;

<a id="chapter-9-section-56-subsection-3-paragraph-4"></a>
- **4.** lausunnon antamista Valtion vakuusrahastosta annetun lain 1 §:n mukaista tukea saavaa pankkia tai lain 1 §:n 4 momentissa tarkoitettua omaisuudenhoitoyhtiötä tai muuta yhtiötä koskevaan asiakasvalitukseen;

<a id="chapter-9-section-56-subsection-3-paragraph-5"></a>
- **5.** valtion vakuusrahastosta annetun lain 1 §:n mukaista tukea saavalle pankille tai lain 1 §:n 4 momentissa tarkoitetulle omaisuudenhoitoyhtiölle tai muulle yhtiölle annettavaa ohjetta, lausuntoa tai vastaavaa muuta yhtiön toimintaa ohjaavaa toimenpidettä, mikäli asioita ei ole vakuusrahastosta annetussa laissa tai muussa laissa säädetty muiden ratkaistaviksi\.

<a id="chapter-9-section-57"></a>
### 57 § Henkilöstöosaston toimialaan kuuluvien asioiden ratkaiseminen

<a id="chapter-9-section-57-subsection-1"></a>
#### \(1\)

Henkilöstöosaston osastopäällikkö ratkaisee asiat, jotka koskevat

<a id="chapter-9-section-57-subsection-1-paragraph-1"></a>
- **1.** valtion virastojen ja laitosten virkaehto\- ja työehtosopimusneuvotteluja, valtion neuvotteluviranomaisen valtion virkaehtosopimusasetuksen [\(1203/1987\)](<https://www.finlex.fi/fi/lainsaadanto/1987/1203>) nojalla muutoin ratkaistavia asioita, valtion henkilöstön palvelussuhdetta, palkkausta ja muita palvelussuhteen ehtoja sekä soveltamismääräysten ja ohjeiden antamista näistä, ei kuitenkaan, jos asia on tämän työjärjestyksen 52 §:n 5 kohdan mukaan hallinnollisen alivaltiosihteerin ratkaistava;

<a id="chapter-9-section-57-subsection-1-paragraph-2"></a>
- **2.** työtuomioistuimesta annetussa laissa [\(646/1974\)](<https://www.finlex.fi/fi/lainsaadanto/1974/646>) tarkoitettuja valtiovarainministeriölle neuvotteluviranomaisena kuuluvia asioita sekä mainitun lain 11 §:n 2 momentissa tarkoitettujen neuvottelujen käymistä\.

<a id="chapter-9-section-57-subsection-2"></a>
#### \(2\)

Ministerin määräämä henkilöstöosaston hallitusneuvos ratkaisee valtiovarainministeriön ratkaistavat eläkeoikeutta koskevat kysymykset\.

<a id="chapter-9-section-58"></a>
### 58 § Hallintoyksikölle kuuluvien asioiden ratkaiseminen

<a id="chapter-9-section-58-subsection-1"></a>
#### \(1\)

Hallintojohtaja ratkaisee asiat, jotka koskevat:

<a id="chapter-9-section-58-subsection-1-paragraph-1"></a>
- **1.** todistuksen antamista irtisanoutumisesta ja virkasuhteen päättymisestä;

<a id="chapter-9-section-58-subsection-1-paragraph-2"></a>
- **2.** kaluston ja muun siihen verrattavan omaisuuden poistamista;

<a id="chapter-9-section-58-subsection-1-paragraph-3"></a>
- **3.** tileistä poistoa;

<a id="chapter-9-section-58-subsection-1-paragraph-4"></a>
- **4.** myöhästyneinä esitettyjen matkalaskujen maksamista;

<a id="chapter-9-section-58-subsection-1-paragraph-5"></a>
- **5.** pysyväisluontoista lupaa oman auton käyttämiseen virkamatkoilla\.

<a id="chapter-9-section-59"></a>
### 59 § Viranomaisen toiminnan julkisuudesta annetussa laissa tarkoitettujen asioiden ratkaiseminen

<a id="chapter-9-section-59-subsection-1"></a>
#### \(1\)

Asianomainen osastopäällikkö tai yksikön päällikkö päättää tiedon antamisesta asiakirjasta, kun tiedon antamista koskeva asia on siirretty viranomaisen toiminnan julkisuudesta annetun lain [\(621/1999\) 14 §:n](<https://www.finlex.fi/fi/lainsaadanto/1999/621#chp_4__sec_14>) 3 momentin mukaisesti viranomaisen ratkaistavaksi\.

<a id="chapter-9-section-59-subsection-2"></a>
#### \(2\)

Jos asia koskee useamman osaston toimialaa, ratkaisee asian hallinnollinen alivaltiosihteeri\.

<a id="chapter-9-section-59-subsection-3"></a>
#### \(3\)

Jos edellä tarkoitettu päätös on kielteinen, se annetaan kirjallisena\.

<a id="chapter-9-section-59-subsection-4"></a>
#### \(4\)

Viranomaisen toiminnan julkisuudesta annetun lain 28 §:ssä tarkoitetun luvan tietojen saamiseen tieteellistä tutkimusta tai muuta mainitussa lainkohdassa tarkoitettua tarkoitusta varten antaa hallintojohtaja\. Valtioneuvoston controller antaa kuitenkin luvan siltä osin kuin tietojen saaminen koskee valtiovarain controller \-toiminnon tietoja ja asiakirjoja\.
