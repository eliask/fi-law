### 2 § Ministeriön toimialan virastot, laitokset, toimielimet ja yhteisöt

<a id="section-2-subsection-1"></a>
#### \(1\)

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Kansanterveyslaitos;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Lääkelaitos;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Lääkehoidon kehittämiskeskus;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** terveydenhuollon oikeusturvakeskus;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** säteilyturvakeskus;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** sosiaali\- ja terveysalan tutkimus\- ja kehittämiskeskus;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** sosiaali\- ja terveydenhuollon tuotevalvontakeskus;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Vakuutusvalvontavirasto;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** tarkastuslautakunta;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** työttömyysturvalautakunta;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** työterveyslaitos;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** työsuojelun piirihallinto;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** tasa\-arvovaltuutettu ja tasa\-arvovaltuutetun toimisto;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** lapsiasiavaltuutettu ja lapsiasiavaltuutetun toimisto;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Raha\-automaattiyhdistys;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** Alko Oy;

<a id="section-2-subsection-1-paragraph-17"></a>

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** Koulutusrahasto;

<a id="section-4"></a>
### 4 § Ratkaisuvallan käyttö

<a id="section-4-subsection-1"></a>
#### \(1\)

Ministeriön yhteydessä toimivat tasa\-arvovaltuutettu ja lapsiasiavaltuutettu ovat riippumattomia hoitaessaan niille säädettyjä tehtäviä\.

<a id="section-8"></a>
### 8 § Virkamiesten nimittämistoimivalta

<a id="section-8-subsection-1"></a>
#### \(1\)

Tasa\-arvovaltuutetun ja tasa\-arvovaltuutetun toimiston muun henkilökunnan sekä lapsiasiavaltuutetun ja lapsiasiavaltuutetun toimiston muun henkilökunnan nimittämisestä ja ottamisesta säädetään erikseen\.
