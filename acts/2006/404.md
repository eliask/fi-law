<a id="section-18"></a>
### 18 §

<a id="section-18-subsection-1"></a>
#### \(1\)

Kielto\- ja rajoitusmerkkien mitat ovat:

<a id="section-18-subsection-2"></a>
#### \(2\)

Merkkiä voidaan käyttää 200 mm:n tai 400 mm:n läpimittaisena liikenteen valvojan tai ohjaajan antamana pysäytysmerkkinä\.

<a id="section-18-subsection-3"></a>
#### \(3\)

Merkkiä 392 voidaan käyttää poliisimiehen ja merkkiä 391 tullimiehen pysäytysmerkkinä myös 200 mm:n läpimittaisena\.

<a id="section-18-subsection-4"></a>
#### \(4\)

Pysäköintimittarin peitoksi asetetussa suojuksessa merkkiä 371 voidaan käyttää pienoiskoossa\.

<a id="section-18-subsection-5"></a>
#### \(5\)

Pysäköintimittarissa tai sitä kannattavassa pylväässä merkkiä 372 voidaan käyttää pienoiskoossa\.

<a id="section-18-subsection-6"></a>
#### \(6\)

Merkin 365 mitoista antaa Tiehallinto tarkemmat ohjeet\.

<a id="section-19"></a>
### 19 §

<a id="section-19-subsection-1"></a>
#### \(1\)

Merkki 353\. Ohituskielto kuorma\-autolla

<a id="section-19-subsection-1-paragraph-1"></a>
- **1.** Merkkiä käytetään, jos on erityinen syy kieltää kuorma\-autolla ohittaminen\. Merkki sijoitetaan ajoradan molemmille puolille\.

<a id="section-19-subsection-2"></a>
#### \(2\)

Merkki 354\. Ohituskielto kuorma\-autolla päättyy

<a id="section-19-subsection-2-paragraph-1"></a>
- **1.** Merkkiä käytetään silloin, kun merkillä 353 osoitettu ohituskielto päättyy muualla kuin maantien tai kadun risteyksessä\.

<a id="section-21"></a>
### 21 §

<a id="section-21-subsection-1"></a>
#### \(1\)

Ohjemerkkien mitat ovat:

<a id="section-21-subsection-2"></a>
#### \(2\)

Pysäköintimittarissa tai sitä kannattavassa pylväässä käytetään merkkiä 521 pienoiskoossa\. Pysäköintilaitoksessa ja sinne opastettaessa merkkien 520 ja 521 koko voi vaihdella\.

<a id="section-21-subsection-3"></a>
#### \(3\)

Silloin kun merkit sijoitetaan tieliikenneasetuksen 19 §:ssä mainittujen kilpien kanssa yhtenäiseen kehysrakenteeseen, voidaan taulukossa annetuista mitoista poiketa\.

<a id="section-21-subsection-4"></a>
#### \(4\)

Merkki 565\. Tunneli

<a id="section-21-subsection-4-paragraph-1"></a>
- **1.** Merkkiä käytetään, kun tunnelin pituus on yli 500 metriä\. Merkillä voidaan osoittaa myös lyhyempi tunneli\. Tunnelin pituus ilmoitetaan lisäkilvellä 814 \(Vaikutusalueen pituus\)\. Merkki toistetaan yli kolmen kilometrin mittaisessa tunnelissa yhden kilometrin välein, jolloin lisäkilvessä 814 ilmoitetaan jäljellä olevan osuuden pituus\. Lisäkilvellä voidaan ilmoittaa myös tunnelin nimi\.

<a id="section-21-subsection-5"></a>
#### \(5\)

Merkki 566\. Tunneli päättyy

<a id="section-21-subsection-6"></a>
#### \(6\)

Merkki 567\. Hätäpysäyttämispaikka

<a id="section-21-subsection-6-paragraph-1"></a>
- **1.** Merkkiä käytetään yleensä tunneleissa\. Jos pysäyttämispaikan varusteisiin kuuluu hätäpuhelin tai sammutin taikka molemmat, se osoitetaan lisäkilvellä 880 \(Hätäpuhelin ja sammutin\)\. Lisäkilven 815 kanssa merkkiä voidaan käyttää ennakkomerkkinä\.

<a id="section-21-subsection-7"></a>
#### \(7\)

Merkki 573\. Pihakatu

<a id="section-21-subsection-7-paragraph-1"></a>
- **1.** Merkkiä käytetään ajoneuvo\- ja jalankulkuliikenteelle yhteisesti tarkoitetulla tiellä\. Merkki sijoitetaan pihakadun alkuun sen oikealle puolelle\.

<a id="section-21-subsection-8"></a>
#### \(8\)

Merkki 575\. Kävelykatu

<a id="section-21-subsection-8-paragraph-1"></a>
- **1.** Merkkiä käytetään jalankulku\- ja polkupyöräliikenteelle yhteisesti tarkoitetulla tiellä\. Merkki sijoitetaan kävelykadun alkuun sen oikealle puolelle\.

<a id="section-21-subsection-9"></a>
#### \(9\)

Merkki 576\. Kävelykatu päättyy

<a id="section-21-subsection-9-paragraph-1"></a>
- **1.** Merkki sijoitetaan kävelykadun päättymiskohtaan joko tien oikealle tai vasemmalle puolelle\.

<a id="section-22"></a>
### 22 §

<a id="section-22-subsection-1"></a>
#### \(1\)

Merkki 690\. Hätäuloskäynti

<a id="section-22-subsection-1-paragraph-1"></a>
- **1.** Merkkiä käytetään yleensä tunnelissa\. Merkillä osoitetaan hätäuloskäynti jalankulkijoille\.

<a id="section-22-subsection-2"></a>
#### \(2\)

Merkki 691\. Poistumisreitti

<a id="section-22-subsection-2-paragraph-1"></a>
- **1.** Merkkiä käytetään yleensä tunnelissa\. Merkki sijoitetaan tien suuntaisesti 1,0–1,5 metrin korkeudelle enintään 25 metrin välein\.

<a id="section-22-subsection-3"></a>
#### \(3\)

Merkki 791\. Hätäpuhelin

<a id="section-22-subsection-3-paragraph-1"></a>
- **1.** Merkillä voidaan osoittaa puhelin, josta voidaan soittaa vain hätäkeskukseen\. Merkkiä käytetään yleensä tunnelissa\.

<a id="section-22-subsection-4"></a>
#### \(4\)

Merkki 792\. Sammutin

<a id="section-22-subsection-4-paragraph-1"></a>
- **1.** Merkkiä käytetään yleensä tunnelissa\.

<a id="section-23"></a>
### 23 §

#### \(1\)

Lisäkilpi 880\. Hätäpuhelin ja sammutin

<a id="section-23-subsection-1-paragraph-1"></a>
