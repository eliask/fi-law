### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä asetuksessa säädetään joukkoliikenteen tarkastusmaksusta annetussa laissa [\(469/1979\)](<https://www.finlex.fi/fi/lainsaadanto/1979/469>) tarkoitetuilta matkalippujen tarkastajilta ja tarkastuksessa apuna olevilta järjestyksenvalvojilta vaadittavasta koulutuksesta\.

<a id="section-2"></a>
### 2 § Matkalipun tarkastajan koulutus

<a id="section-2-subsection-1"></a>
#### \(1\)

Matkalipun tarkastajien koulutukseen on sisällytettävä ainakin seuraavia asiakokonaisuuksia:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tarkastusalueen joukkoliikenteestä:

<a id="section-2-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** asianomaisen joukkoliikennejärjestelmän perusteet;

<a id="section-2-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** tarkastusalueen liikennemuodot ja reitit;

<a id="section-2-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** tarkastusalueen joukkoliikenteen liikennöintiajat;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** tarkastusalueen matkalippujärjestelmästä:

<a id="section-2-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** matkalipputyypit ja niiden hinnat;

<a id="section-2-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** matkalippujen hankkiminen;

<a id="section-2-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** matkalippujen käyttäminen ja voimassaolo;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** tarkastustoimintaa koskevasta lainsäädännöstä ja oikeuskäytännöstä:

<a id="section-2-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** joukkoliikenteen tarkastusmaksusta annettu laki kokonaisuudessaan;

<a id="section-2-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** järjestyksenvalvojista annettu laki [\(533/1999\)](<https://www.finlex.fi/fi/lainsaadanto/1999/533>), järjestyslaki [\(612/2003\)](<https://www.finlex.fi/fi/lainsaadanto/2003/612>) ja järjestyksen pitämisestä joukkoliikenteessä annettu laki [\(472/1977\)](<https://www.finlex.fi/fi/lainsaadanto/1977/472>) keskeisiltä osiltaan;

<a id="section-2-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** tarkastusmaksujen perimistä koskeva oikeuskäytäntö keskeisiltä osiltaan;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** tarkastustoiminnasta käytännössä:

<a id="section-2-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** tarkastajan tehtävät, toimivaltuudet ja vastuut;

<a id="section-2-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** tarkastustehtävissä noudatettavat yleiset periaatteet ja toimintaohjeet;

<a id="section-2-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** tarkastusmaksusta vapauttamiseen liittyvän harkintavallan käyttäminen;

<a id="section-2-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** virkapuku ja tarkastuspassi;

<a id="section-2-subsection-1-paragraph-4-subparagraph-e"></a>
  - **e.** tarkastajan käyttäytyminen tarkastustilanteessa;

<a id="section-2-subsection-1-paragraph-4-subparagraph-f"></a>
  - **f.** tarkastajan käyttäytyminen ja toimiminen ongelmatilanteissa;

<a id="section-2-subsection-1-paragraph-4-subparagraph-g"></a>
  - **g.** työturvallisuus tarkastajan tehtävissä;

<a id="section-2-subsection-1-paragraph-4-subparagraph-h"></a>
  - **h.** tarkastajien yhteistyö järjestyksenvalvojan, kuljettajan, konduktöörin, rahastajan ja poliisin kanssa;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** asiakaspalvelusta:

<a id="section-2-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** asiakaslähtöisyys ja ammattitaitoinen palvelu;

<a id="section-2-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** tarkastajan vuorovaikutustaidot ja asenteet tarkastustilanteissa;

<a id="section-2-subsection-1-paragraph-5-subparagraph-c"></a>
  - **c.** tärkeimmät tarkastustehtävää suoritettaessa käytettävät fraasit ruotsiksi ja englanniksi;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** onnettomuustilanteissa toimimisesta:

<a id="section-2-subsection-1-paragraph-6-subparagraph-a"></a>
  - **a.** asianomaisten liikennemuotojen turvajärjestelmät;

<a id="section-2-subsection-1-paragraph-6-subparagraph-b"></a>
  - **b.** ensiavun antaminen Suomen Punaisen Ristin Ensiapu I \-kurssin tai vastaavan muun ensiapukurssin sisältöä vastaavassa laajuudessa\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Matkalipun tarkastajilta vaadittavan koulutuksen pituus on vähintään 160 oppituntia\. Opetukseen on sisällytettävä 80 tuntia luentomuotoista opetusta ja 80 tuntia työhön opastamista käytännössä\.

<a id="section-3"></a>
### 3 § Tarkastuksessa apuna olevan järjestyksenvalvojan koulutus

<a id="section-3-subsection-1"></a>
#### \(1\)

Tarkastuksessa apuna olevan järjestyksenvalvojan koulutukseen on sisällytettävä soveltuvin osin 2 §:ssä mainitut tehtävän hoitamisen kannalta olennaiset asiakokonaisuudet, kuitenkin ainakin perehdyttäminen tarkastusalueen joukkoliikenteeseen ja sen maksujärjestelmään sekä joukkoliikenteen tarkastusmaksusta annettuun lakiin\. Lisäksi koulutukseen on sisällytettävä perehdyttäminen asiakaspalveluun ja yhteistyöhön matkalipun tarkastajan kanssa\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Koulutuksen pituus on vähintään 40 tuntia\. Siihen tulee sisältyä luentomuotoista opetusta ja työhön opastamista käytännössä\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 15 päivänä lokakuuta 2006\.
