### 2 § Ministeriön toimialan virastot, laitokset, yhtiöt ja muut toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Maa\- ja metsätalousministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** maa\- ja elintarviketalouden tutkimuskeskus

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Metsähallitus

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Metsäntutkimuslaitos

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** riista\- ja kalatalouden tutkimuslaitos

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Elintarviketurvallisuusvirasto

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Geodeettinen laitos

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** maanmittauslaitos

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** maa\- ja metsätalousministeriön tietopalvelukeskus

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** maaseutuelinkeinojen valituslautakunta

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** eläinlääkintävahinkojen arviolautakunta

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Boreal Kasvinjalostus Oy

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Suomen Viljava Oy

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** maatalouden interventiorahasto

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** maatilatalouden kehittämisrahasto

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Maa\- ja metsätalousministeriö ohjaa ja valvoo työvoima\- ja elinkeinokeskuksia toimialaansa kuuluvissa asioissa\. Maa\- ja metsätalousministeriö ohjaa myös alueellisia ympäristökeskuksia ja Suomen ympäristökeskusta toimialaansa kuuluvissa asioissa\.
