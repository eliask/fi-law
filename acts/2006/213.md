# Laki asevelvollisuuslain muuttamisesta

<a id="section-3a"></a>
### 3 a §

<a id="section-3a-subsection-1"></a>
#### \(1\)

Varusmiespalveluksen tarkoituksena on kouluttaa ja harjaannuttaa asevelvolliset sotilaallisen maanpuolustuksen tehtäviin ja siten luoda osaltaan edellytykset sodan ajan varalta tarvittavien joukkokokonaisuuksien tuottamiselle\.

<a id="section-3a-subsection-2"></a>
#### \(2\)

Varusmiespalveluksen ja kertausharjoituksen aikana voidaan antaa lyhytaikaisesti koulutusta sotilaallisen kriisinhallinnan edellyttämien valmiuksien luomiseksi niille asevelvollisille, jotka vapaaehtoisesti hakeutuvat sellaiseen koulutukseen\.

<a id="section-3b"></a>
### 3 b §

<a id="section-3b-subsection-1"></a>
#### \(1\)

Varusmiespalvelusta suorittava tai kertausharjoitukseen osallistuva asevelvollinen voidaan määrätä palvelukseen ulkomaille, jos hän:

<a id="section-3b-subsection-1-paragraph-1"></a>
- **1.** osallistuu 3 a §:n 2 momentissa tarkoitettuun koulutukseen;

<a id="section-3b-subsection-1-paragraph-2"></a>
- **2.** suorittaa 1 kohdassa tarkoitettuun koulutukseen liittyviä tukitehtäviä;

<a id="section-3b-subsection-1-paragraph-3"></a>
- **3.** kuuluu virka\-apuosastoon, jonka tehtävänä on antaa virka\-apua Suomen rajojen ulkopuolella;

<a id="section-3b-subsection-1-paragraph-4"></a>
- **4.** osallistuu tavanomaiseen laivapalvelukseen Suomen aluevesien ulkopuolella;

<a id="section-3b-subsection-1-paragraph-5"></a>
- **5.** osallistuu nimenomaisen suostumuksensa nojalla kansallista puolustusta edistävään kansainväliseen lyhytaikaiseen sotilaalliseen harjoitukseen;

<a id="section-3b-subsection-1-paragraph-6"></a>
- **6.** osallistuu vierailuihin, esiintymismatkoihin, urheilukilpailuihin tai muihin vastaaviin palvelukseensa liittyviin sellaisiin tehtäviin, joihin ei sisälly sotilaallisia harjoituksia\.
