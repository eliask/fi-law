<a id="section-3"></a>
### 3 § Ministeriön organisaatio

<a id="section-3-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriössä on seuraavat osastot:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** hallinto\-osasto;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** vakuutusosasto;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** terveysosasto;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** perhe\- ja sosiaaliosasto;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** talous\- ja suunnitteluosasto;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** työsuojeluosasto\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Osastojen ulkopuolella ovat erillisinä tulosryhminä kansainvälisten asiain toimisto, viestintäyksikkö, esikuntayksikkö ja valmiusyksikkö\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Osastot voivat jakautua tulosryhmiin\. Osaston ja erillisen tulosryhmän sisäisestä organisaatiosta määrätään tarvittaessa ministeriön sisäisessä määräyksessä, jonka osaston tai erillisen tulosryhmän päällikkö vahvistaa\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Sisäinen tarkastus toimii kansliapäällikön alaisena\.
