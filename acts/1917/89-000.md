# Suomen Senaatin päätös, koskeva passiasetusten tarkempaa noudattamista\.

<a id="section-1"></a>
### 1 §\.

<a id="section-1-subsection-1"></a>
#### \(1\)

Joka ilman asianomaista matkapassia matkustaa ulkomaille tai muuten rikkoo tällaisista matkoista sodan aikana annettuja säännöksiä;

<a id="section-1-subsection-2"></a>
#### \(2\)

2\) joka salaisesti tai muualta kuin asianomaiselta ylimenopaikalta, joskin matkapassilla varustettuna, kulkee rajan yli; tai

<a id="section-1-subsection-3"></a>
#### \(3\)

3\) joka yrittää tehdä 1 ja 3 kohdassa mainittuja tekoja tai jollain muulla tavoin avustaa sellaista tekoa, rangaistaan enintään 400 markan sakolla\.

<a id="section-2"></a>
### 2 §\.

<a id="section-2-subsection-1"></a>
#### \(1\)

Tästä johtuvia asioita käsittelevät Kuvernöörit, asianomaisten poliisi\- ja syyttäjäviranomaisten ilmoituksesta\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tätä kaikki asianomaiset noudattakoot\.
