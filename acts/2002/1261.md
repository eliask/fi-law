# Liikenne\- ja viestintäministeriön asetus ajoneuvojen katsastushenkilöstön lisäkoulutuksesta annetun liikenneministeriön päätöksen muuttamisesta

<a id="section-1"></a>
### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tämä päätös koskee katsastustoiminnasta vastaavan henkilön ja katsastuksia suorittavan henkilön lisäkoulutusta, koulutuksen antajaa ja koulutustoimikuntaa sekä vaarallisten aineiden kuljetukseen tarkoitetun ajoneuvon hyväksyntöjä ja katsastuksia suorittavan henkilön ammattitaitoa ja erikoiskoulutusta\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Yksittäisen täydennyskoulutustilaisuuden järjestäjää tämä päätös koskee vain soveltuvin osin\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Tätä päätöstä ei sovelleta tyyppihyväksyntää suorittavaan henkilöön\.

<a id="section-3"></a>
### 3 § Koulutuksen tarkoitus ja rakenne

<a id="section-3-subsection-1"></a>
#### \(1\)

1\. Vuosikatsastuskoulutuksen tarkoituksena on antaa peruskoulutuksen suorittaneelle, katsastusalalle aikovalle henkilölle valmiudet suorittaa ajoneuvojen määräaikaiskatsastuksia säännöksissä ja ohjeissa edellytetyllä tavalla \(alalletulokoulutus\)\. Vuosikatsastuskoulutus muodostuu:

<a id="section-3-subsection-1-paragraph-a"></a>
- **a.** yleisjaksosta;

<a id="section-3-subsection-1-paragraph-b"></a>
- **b.** kevyen kaluston koulutusjaksosta \(katsastajantutkinto kevyen ajoneuvokaluston määräaikaiskatsastuksiin\); ja

<a id="section-3-subsection-1-paragraph-c"></a>
- **c.** raskaan kaluston koulutusjaksosta \(katsastajantutkinto raskaan ajoneuvokaluston määräaikaiskatsastuksiin\)\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Katsastajantutkinnot oikeuttavat 1 momentissa tarkoitetulla tavalla joko kevyen tai kevyen ja raskaan kaluston määräaikaiskatsastuksiin, jollei 3 momentista muuta johdu\.

<a id="section-3-subsection-3"></a>
#### \(3\)

3\. Erikoiskoulutuksen tarkoituksena on antaa valmiudet erityisosaamista vaativien katsastustoimenpiteiden suorittamiseen\. Koulutus jakaantuu seuraaviin jaksoihin:

<a id="section-3-subsection-3-paragraph-a"></a>
- **a.** kevyen kaluston rekisteröinti\-, muutos\- ja kytkentäkatsastusten jakso;

<a id="section-3-subsection-3-paragraph-b"></a>
- **b.** raskaan kaluston rekisteröinti\-, muutos\- ja kytkentäkatsastusten jakso;

<a id="section-3-subsection-3-paragraph-c"></a>
- **c.** vaarallisten aineiden kuljetukseen tarkoitetun ajoneuvon hyväksynnän ja katsastusten jakso;

<a id="section-3-subsection-3-paragraph-d"></a>
- **d.** paineilmajarrujen laajan tarkastuksen jakso\.

<a id="section-3-subsection-4"></a>
#### \(4\)

Erikoiskoulutus oikeuttaa koulutusjakson erityisalan mukaisten katsastustoimenpiteiden suorittamiseen\.

<a id="section-3-subsection-5"></a>
#### \(5\)

Ammattitaidon ylläpitäminen varmistetaan täydennyskoulutuksessa ja erikoiskoulutuksen kertauskokeessa\. Täydennyskoulutuksen tarkoituksena on antaa katsastustoiminnasta vastaavalle henkilölle ja katsastuksia suorittavalle henkilölle tiedot katsastusta koskevista uusista säännöksistä, ohjeista ja työmenetelmistä\. Erikoiskoulutuksen kertauskokeessa tarkastetaan, että katsastuksia suorittava henkilö hallitsee edelleen asianomaista erityisosaamista vaativat katsastus\- ja hyväksyntätoimenpiteet\.

<a id="section-5"></a>
### 5 § Vuosikatsastuskoulutuksen kesto ja sisältö

<a id="section-5-subsection-1"></a>
#### \(1\)

1\. Yleisjaksolla on vähintään 35 oppituntia lähiopetusta\. Jaksolla annetaan perustiedot katsastukseen liittyvistä säännöksistä, katsastusjärjestelmästä sekä katsastajan työhön liittyvistä oikeuksista ja velvollisuuksista\. Yleisjakson opetusaiheita ovat ainakin:

<a id="section-5-subsection-1-paragraph-a"></a>
- **a.** yleiset ajoneuvojen varusteita ja käyttöä koskevat säännökset;

<a id="section-5-subsection-1-paragraph-b"></a>
- **b.** ajoneuvojen katsastusta koskevat säännökset;

<a id="section-5-subsection-1-paragraph-c"></a>
- **c.** ajoneuvojen rakenne, varusteet ja kuormaaminen;

<a id="section-5-subsection-1-paragraph-d"></a>
- **d.** ajoneuvoihin liittyvät hyväksyntämenettelyt;

<a id="section-5-subsection-1-paragraph-e"></a>
- **e.** ajoneuvojen rekisteröinti;

<a id="section-5-subsection-1-paragraph-f"></a>
- **f.** ajoneuvojen verotus;

<a id="section-5-subsection-1-paragraph-g"></a>
- **g.** liikennevakuutus;

<a id="section-5-subsection-1-paragraph-h"></a>
- **h.** työturvallisuus;

<a id="section-5-subsection-1-paragraph-i"></a>
- **i.** liikenneturvallisuus;

<a id="section-5-subsection-1-paragraph-j"></a>
- **j.** yleiset vastuukysymykset ja esteellisyys;

<a id="section-5-subsection-1-paragraph-k"></a>
- **k.** katsastustoiminnan kehitys, tavoitteet ja valvonta;

<a id="section-5-subsection-1-paragraph-l"></a>
- **l.** laatu katsastustoiminnassa;

<a id="section-5-subsection-1-paragraph-m"></a>
- **m.** katsastustoimintaan sovellettavat hallinnolliset säännökset;

<a id="section-5-subsection-1-paragraph-n"></a>
- **n.** ajoneuvoja koskevan tietojärjestelmän käyttö\.

<a id="section-5-subsection-2"></a>
#### \(2\)

2\. Kevyen kaluston koulutusjaksolla on vähintään 35 oppituntia lähiopetusta ja vähintään kaksi viikkoa varsinaista käytännön työharjoittelua\. Kevyen kaluston koulutusjakson opetusaiheita ovat ainakin:

<a id="section-5-subsection-2-paragraph-a"></a>
- **a.** kevyen kaluston määräaikaiskatsastusta koskevat säännökset ja ohjeet;

<a id="section-5-subsection-2-paragraph-b"></a>
- **b.** tarkastuskohteet määräaikaiskatsastuksessa ja vikojen arviointi;

<a id="section-5-subsection-2-paragraph-c"></a>
- **c.** työmenetelmät;

<a id="section-5-subsection-2-paragraph-d"></a>
- **d.** kevyen kaluston teknisten varusteiden tarkoitus ja toiminta;

<a id="section-5-subsection-2-paragraph-e"></a>
- **e.** pakokaasu\- ja jarrumittaukset;

<a id="section-5-subsection-2-paragraph-f"></a>
- **f.** ajoneuvoja koskevan tietojärjestelmän käyttö\.

<a id="section-5-subsection-3"></a>
#### \(3\)

3\. Raskaan kaluston koulutusjaksolla on vähintään 35 oppituntia lähiopetusta ja vähintään kaksi viikkoa varsinaista käytännön työharjoittelua\. Raskaan kaluston koulutusjakson opetusaiheita ovat ainakin:

<a id="section-5-subsection-3-paragraph-a"></a>
- **a.** raskaan kaluston määräaikaiskatsastusta koskevat säännökset ja ohjeet;

<a id="section-5-subsection-3-paragraph-b"></a>
- **b.** tarkastuskohteet määräaikaiskatsastuksessa ja vikojen arviointi;

<a id="section-5-subsection-3-paragraph-c"></a>
- **c.** työmenetelmät;

<a id="section-5-subsection-3-paragraph-d"></a>
- **d.** raskaan kaluston teknisten varusteiden tarkoitus ja toiminta;

<a id="section-5-subsection-3-paragraph-e"></a>
- **e.** pakokaasu\- ja jarrumittaukset;

<a id="section-5-subsection-3-paragraph-f"></a>
- **f.** ajoneuvoyhdistelmien katsastus;

<a id="section-5-subsection-3-paragraph-g"></a>
- **g.** ajoneuvoja koskevan tietojärjestelmän käyttö\.

<a id="section-5-subsection-4"></a>
#### \(4\)

Varsinainen käytännön työharjoittelu on suoritettava ohjattuna katsastustoimipaikalla\. Myös lähiopetukseen tulee sisältyä käytännön harjoittelua\.

<a id="section-9"></a>
### 9 § Erikoiskoulutuksen kesto ja sisältö

<a id="section-9-subsection-1"></a>
#### \(1\)

1\. Kevyen kaluston rekisteröinti\-, muutos\- ja kytkentäkatsastusten koulutusjakso sisältää vähintään 35 oppituntia\. Jakson opetusaiheita ovat ainakin:

<a id="section-9-subsection-1-paragraph-a"></a>
- **a.** kevyen kaluston rekisteröintiä koskevat säännökset ja ohjeet;

<a id="section-9-subsection-1-paragraph-b"></a>
- **b.** tarvittavat asiakirjat;

<a id="section-9-subsection-1-paragraph-c"></a>
- **c.** muutosten vaikutus ajoneuvojen verotukseen;

<a id="section-9-subsection-1-paragraph-d"></a>
- **d.** ajoneuvon ja sen osien hyväksyntämenettely;

<a id="section-9-subsection-1-paragraph-e"></a>
- **e.** kevyen kaluston teknisten varusteiden tarkoitus ja toiminta;

<a id="section-9-subsection-1-paragraph-f"></a>
- **f.** kevyen kaluston rakennemuutokset;

<a id="section-9-subsection-1-paragraph-g"></a>
- **g.** ajoneuvoja koskevan tietojärjestelmän käyttö\.

<a id="section-9-subsection-2"></a>
#### \(2\)

2\. Raskaan kaluston rekisteröinti\-, muutos\- ja kytkentäkatsastusten koulutusjakso sisältää vähintään 35 oppituntia\. Jakson opetusaiheita ovat ainakin:

<a id="section-9-subsection-2-paragraph-a"></a>
- **a.** raskaan kaluston rekisteröintiä koskevat säännökset ja ohjeet;

<a id="section-9-subsection-2-paragraph-b"></a>
- **b.** tarvittavat asiakirjat;

<a id="section-9-subsection-2-paragraph-c"></a>
- **c.** muutosten vaikutus ajoneuvojen verotukseen;

<a id="section-9-subsection-2-paragraph-d"></a>
- **d.** ajoneuvon ja sen osien hyväksyntämenettely;

<a id="section-9-subsection-2-paragraph-e"></a>
- **e.** raskaan kaluston teknisten varusteiden tarkoitus ja toiminta;

<a id="section-9-subsection-2-paragraph-f"></a>
- **f.** raskaan kaluston rakennemuutokset;

<a id="section-9-subsection-2-paragraph-g"></a>
- **g.** ajoneuvoja koskevan tietojärjestelmän käyttö\.

<a id="section-9-subsection-3"></a>
#### \(3\)

3\. Vaarallisten aineiden kuljetukseen tarkoitetun ajoneuvon hyväksynnän ja katsastusten koulutusjakso sisältää 21 oppituntia\. Jakson opetusaiheita ovat ainakin:

<a id="section-9-subsection-3-paragraph-a"></a>
- **a.** yleiset vaarallisten aineiden kuljetusta koskevat säännökset, määräykset ja ohjeet;

<a id="section-9-subsection-3-paragraph-b"></a>
- **b.** ajoneuvon teknisten varusteiden tarkoitus ja toiminta;

<a id="section-9-subsection-3-paragraph-c"></a>
- **c.** toimenpiteet rekisteröinti\- ja määräaikaiskatsastuksissa;

<a id="section-9-subsection-3-paragraph-d"></a>
- **d.** ajoneuvojen hyväksyntämenettely\.

<a id="section-9-subsection-4"></a>
#### \(4\)

4\. Paineilmajarrujen laajan tarkastuksen koulutusjakso sisältää 21 oppituntia\. Jakson opetusaiheita ovat ainakin:

<a id="section-9-subsection-4-paragraph-a"></a>
- **a.** raskaan kaluston jarruja koskevat säännökset ja ohjeet;

<a id="section-9-subsection-4-paragraph-b"></a>
- **b.** raskaan kaluston paineilmajärjestelmän rakenne ja toiminta;

<a id="section-9-subsection-4-paragraph-c"></a>
- **c.** teoreettinen jarrusovitus;

<a id="section-9-subsection-4-paragraph-d"></a>
- **d.** jarrutarkastelu dynamometrillä;

<a id="section-9-subsection-4-paragraph-e"></a>
- **e.** jarrutarkastelu hidastuvuuskokein\.

<a id="section-9-subsection-5"></a>
#### \(5\)

Kaikki tässä pykälässä tarkoitetut koulutusjaksot sisältävät käytännön harjoittelua\.
