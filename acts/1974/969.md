# Laki evankelis\-luterilaisen kirkon työehtosopimuksista

<a id="section-1"></a>
### 1§

<a id="section-1-subsection-1"></a>
#### \(1\)

Työehtosopimuksen evankelis\-luterilaisen kirkon, sen seurakunnan, seurakuntainliiton tai muun seurakuntain yhtymän puolesta tekee evankelis\-luterilaisen kirkon sopimusvaltuuskunta, johon sovelletaan, mitä työehtosopimuslaissa [\(436/46\)](<https://www.finlex.fi/fi/lainsaadanto/1946/436>) on säädetty työnantajasta tai rekisteröidystä työnantajain yhdistyksestä\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Sopimusvaltuuskunnan järjestysmuodosta ja toiminnasta säädetään erikseen lailla\.

<a id="section-2"></a>
### 2§

<a id="section-2-subsection-1"></a>
#### \(1\)

Sopimusvaltuuskunta voi valtuuttaa seurakunnan, seurakuntainliiton tai muun seurakuntain yhtymän taikka kirkon viranomaisen omasta puolestaan tekemään työehtosopimuksen valtuuskunnan määräämissä rajoissa\.

<a id="section-3"></a>
### 3§

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä laki tulee voimaan 1 päivänä tammikuuta 1975\.
