<a id="section-24"></a>
### 24 §

<a id="section-24-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriön toimialaan kuuluvat seuraavat asiaryhmät:

<a id="section-24-subsection-1-paragraph-1"></a>
- **1.** toimeentuloturva;

<a id="section-24-subsection-1-paragraph-2"></a>
- **2.** vakuutustoiminta, vakuutuksen välitystoiminta ja vakuutustarkastus;

<a id="section-24-subsection-1-paragraph-3"></a>
- **3.** sosiaali\- ja terveyspalvelut;

<a id="section-24-subsection-1-paragraph-4"></a>
- **4.** lääkehuolto;

<a id="section-24-subsection-1-paragraph-5"></a>
- **5.** kuntoutus;

<a id="section-24-subsection-1-paragraph-6"></a>
- **6.** terveyden sekä sosiaalisen hyvinvoinnin edistäminen sekä sairauksien ja sosiaalisten ongelmien ehkäisy;

<a id="section-24-subsection-1-paragraph-7"></a>
- **7.** alkoholi\-, huumausaine\- ja tupakka\-asiat;

<a id="section-24-subsection-1-paragraph-8"></a>
- **8.** terveydensuojelu ja säteilyhaittojen valvonta;

<a id="section-24-subsection-1-paragraph-9"></a>
- **9.** kemikaalien valvonta, mikäli asia ei kuulu muun ministeriön toimialaan;

<a id="section-24-subsection-1-paragraph-10"></a>
- **10.** geeniteknologian valvonta, mikäli asia ei kuulu muun ministeriön toimialaan;

<a id="section-24-subsection-1-paragraph-11"></a>
- **11.** työterveyshuolto, mikäli asia ei kuulu muun ministeriön toimialaan;

<a id="section-24-subsection-1-paragraph-12"></a>
- **12.** sosiaaliturvaa sekä sairaanhoitoa ja muuta terveydenhoitoalaa koskevat vieraiden valtioiden kanssa tehtävät sopimukset ja muut kansainväliset velvoitteet;

<a id="section-24-subsection-1-paragraph-13"></a>
- **13.** naisten ja miesten välinen tasa\-arvo;

<a id="section-25"></a>
### 25 §

<a id="section-25-subsection-1"></a>
#### \(1\)

Työministeriön toimialaan kuuluvat seuraavat asiaryhmät:

<a id="section-25-subsection-1-paragraph-13"></a>
- **13.** pakolaisuus, mikäli asia ei kuulu muun ministeriön toimialaan, siirtolaisuus, turvapaikanhakijoiden vastaanotto sekä maahanmuuttajien yhteiskuntaan sijoittumista edistävät toimenpiteet;
