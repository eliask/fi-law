# Asetus Ahvenanmaan maakuntaa koskevista poikkeuksista arvonlisävero\- ja valmisteverolainsäädäntöön annetun lain täytäntöönpanosta

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ahvenanmaan maakuntaa koskevista poikkeuksista arvonlisävero\- ja valmisteverolainsäädäntöön annetun lain \(1266/1996\), jäljempänä poikkeuslaki, 14 §:n 1 momentissa tarkoitetun ostajan, jonka kotipaikka tai vakinainen asuinpaikka on muualla ulkomailla kuin Ruotsissa, Tanskassa tai Norjassa, kotipaikka tai vakinainen asuinpaikka on varmistettava passista ja oleskelu\- tai työluvasta taikka muista asiakirjoista, jotka selvittävät kotipaikan tai vakinaisen asuinpaikan luotettavasti\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Selvitykseksi siitä, että ostaja on vienyt tavarat poikkeuslain 14 §:n 1 momentissa tarkoitetulla tavalla Ahvenanmaan maakunnasta, katsotaan myynnistä laadittu tosite, jonka on vahvistanut:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** se tullitoimipaikka, jonka kautta tavarat poistuvat maakunnasta; tai

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** matkailijamyynnistä suoritetun arvonlisäveron käteispalautustoimintaa harjoittavan velvollisuuksista annetun lain \(250/2015\) mukaisen toimiluvan saanut elinkeinonharjoittaja\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Edellä 1 momentissa tarkoitetussa tositteessa on oltava seuraavat tiedot ainakin suomen tai ruotsin kielellä:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** ostajan nimi, passin numero ja kotipaikka sekä vakinainen asuinpaikka, jos se on eri kuin kotipaikka;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** myyjän nimi, osoite sekä yritys\- ja yhteisötunnus;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** tavaroiden määrä ja laji;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** tavaroiden toimituspäivä, jollei se ole sama kuin tositteen antamispäivä;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** tavaroista maksettu hinta;

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** suoritettavan veron määrä euroissa verokannoittain tai veronperuste verokannoittain;

<a id="section-2-subsection-2-paragraph-7"></a>
- **7.** ostajalle palautettava määrä tai, jos se ei ole tiedossa, palautuksen vähimmäis\- ja enimmäismäärä;

<a id="section-2-subsection-2-paragraph-8"></a>
- **8.** pakkauksien lukumäärä\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Jos kassakuitti tai muu maksutosite ei sisällä kaikkia 2 momentissa tarkoitettuja tietoja, myynnistä tulee laatia erillinen tosite\. Tässä tositteessa ei tarvitse toistaa maksutositteessa olevia tietoja\. Näiden tositteiden on oltava joko kiinteästi toisiinsa liitettyjä tai erillisessä tositteessa on oltava yksiselitteinen viittaus maksutositteeseen\.

<a id="section-2-subsection-4"></a>
#### \(4\)

Myyjän on muissa kuin 5 momentissa tarkoitetuissa tapauksissa luovuttaessaan tavarat ostajalle sinetöitävä ne siten, että niiden yhteys myyjäliikkeeseen sekä käyttämättömyys on todettavissa tavaroita vietäessä maakunnan ulkopuolelle\.

<a id="section-2-subsection-5"></a>
#### \(5\)

Kun myynti tapahtuu lentoaseman lähtöhallissa, selvitykseksi siitä, että ostaja vie tavarat maakunnasta, katsotaan myös ostajan esittämä matkalippu, ulkomaanlennon tarkastuskortti tai vastaava asiakirja\. Myyjän on tällöin laadittava myynnistä tosite, jossa on oltava seuraavat tiedot:

<a id="section-2-subsection-5-paragraph-1"></a>
- **1.** ostajan nimi, passin numero ja kotipaikka sekä vakinainen asuinpaikka, jos se on eri kuin kotipaikka;

<a id="section-2-subsection-5-paragraph-2"></a>
- **2.** lennonnumero;

<a id="section-2-subsection-5-paragraph-3"></a>
- **3.** myyjän nimi ja yritys\- ja yhteisötunnus;

<a id="section-2-subsection-5-paragraph-4"></a>
- **4.** tavaroiden määrä ja laji;

<a id="section-2-subsection-5-paragraph-5"></a>
- **5.** tavaroiden toimituspäivä, jollei se ole sama kuin tositteen antamispäivä;

<a id="section-2-subsection-5-paragraph-6"></a>
- **6.** tavaroista maksettu hinta\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Arvonlisäveroasetuksen \(50/1994\) 8 §:n 7 momenttia sovellettaessa Ahvenanmaan maakunnan ei katsota kuuluvan Suomen alueeseen\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä maaliskuuta 1997\.
