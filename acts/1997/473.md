# Liikenneministeriön päätös toimiluvista ja teletoimintailmoituksista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Telemarkkinalain [\(396/1997\) 7 §:ssä](<https://www.finlex.fi/fi/lainsaadanto/1997/396#chp_2__sec_7>) tarkoitetun asianomaiselle ministeriölle osoitettavan toimilupahakemuksen tulee sisältää seuraavat tiedot:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** hakijan yhteystiedot;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** kaupparekisterin ote tai vastaava selvitys hakijasta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** hakijayhteisön omistussuhteet;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** selvitys siitä, mihin säännösten ja määräysten mukaiseen matkaviestinverkkoon lupaa haetaan;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** televerkkopalveluiden kuvaus ja toiminnan rajaukset;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** toimialue;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** verkostokuvaus tai \-suunnitelma;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** yhteenliittämiskuvaus tai \-suunnitelma;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** arvio toiminnan vaatimista investoinneista ja niiden rahoituksesta; sekä

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** arvio liiketoiminnan kehityksestä viiden vuoden kuluessa toiminnan aloittamisesta tai hakemuksen jättämisestä\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Toimilupahakemus tehdään ministeriöstä saatavalle lomakkeelle, jossa tarkemmin eritellään 1 momentin mukaisesti ilmoitettavat tiedot\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Telemarkkinalain 6 §:ssä tarkoitetun asianomaiselle ministeriölle osoitettavan teletoimintailmoituksen tulee sisältää seuraavat tiedot:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** ilmoittajan yhteystiedot;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** kaupparekisterin ote tai vastaava selvitys ilmoittajasta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** ilmoittajayhteisön omistussuhteet;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** tarjottavien palveluiden erittely ja kuvaus sisältäen toiminnan rajaukset;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** toimialue;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** verkostokuvaus tai \-suunnitelma;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** yhteenliittämiskuvaus tai \-suunnitelma;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** arvio toiminnan vaatimista investoinneista ja niiden rahoituksesta; sekä

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** arvio liiketoiminnan kehityksestä viiden vuoden kuluesssa toiminnan aloittamisesta tai ilmoituksen jättämisestä\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Teletoimintailmoitus tehdään ministeriöstä saatavalle lomakkeella, jossa tarkemmin eritellään 1 momentin mukaisesti ilmoitettavat tiedot\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä kesäkuuta 1997\.
