<a id="section-1"></a>
### 1 § Julkisoikeudelliset suoritteet

<a id="section-1-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 6 §:ssä tarkoitettuja julkisoikeudellisia suoritteita, joista Maatalouden tutkimuskeskus perii suoritteen omakustannusarvon mukaiseksi määräämänsä maksun, ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** elintarvikeautojen \(ATP\) tarkastukset; sekä

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** työturvallisuuslain [\(299/1958\)](<https://www.finlex.fi/fi/lainsaadanto/1958/299>) ja työsuojeluvalvontalain [\(131/1973\)](<https://www.finlex.fi/fi/lainsaadanto/1973/131>) perusteella koneiden tyyppi\- ja hyväksymistarkastukset\.

<a id="section-2"></a>
### 2 § Maksulliset liiketaloudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Valtion maksuperustelain 7 §:ssä tarkoitettuja muita suoritteita, jotka Maatalouden tutkimuskeskus hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tilaustutkimukset;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** analyysipalvelut;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** muut koetus\-, testaus\- ja tarkastuspalvelut;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** valiotaimituotanto;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** hevossairaala;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** lisääntymispalvelut;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** julkaisumyynti ja tiedonvälityspalvelut;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** koulutus\- ja kurssipalvelut;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** asiantuntija\- ja neuvontapalvelut;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** meijeritoiminta;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** puun myynti;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** maatalouden sääpalvelu;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** kiinteistönhoitopalvelut sekä muut toimitiloihin ja alueisiin liittyvät korjaus\- ja kunnossapitopalvelut;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** peltoviljelypalvelut; sekä

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** muut tilatut erityispalvelut\- ja suoritteet\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1998 ja se on voimassa 31 päivään joulukuuta 2001\.
