# Valtioneuvoston päätös alueellisten taidetoimikuntien lukumäärästä ja toimialueista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Suomessa on 13 alueellista taidetoimikuntaa\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Alueellisten taidetoimikuntien toimialueet muodostuvat siten, että:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan taidetoimikunta muodostuu Uudenmaan liiton ja Itä\-Uudenmaan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Varsinais\-Suomen taidetoimikunta muodostuu Varsinais\-Suomen liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Satakunnan taidetoimikunta muodostuu Satakuntaliiton toimialueesta;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Hämeen taidetoimikunta muodostuu Hämeen liiton ja Päijät\-Hämeen liiton toimialueista;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaan taidetoimikunta muodostuu Pirkanmaan liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Kaakkois\-Suomen taidetoimikunta muodostuu Kymenlaakson liiton ja Etelä\-Karjalan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Etelä\-Savon taidetoimikunta muodostuu Etelä\-Savon maakuntaliiton toimialueesta;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Pohjois\-Savon taidetoimikunta muodostuu Savon liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Pohjois\-Karjalan taidetoimikunta muodostuu Pohjois\-Karjalan liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Keski\-Suomen taidetoimikunta muodostuu Keski\-Suomen liiton toimialueesta;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Pohjanmaan taidetoimikunta muodostuu Österbottens förbund \- Pohjanmaan liiton, Etelä\-Pohjanmaan liiton ja Keski\-Pohjanmaan liiton toimialueista;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Oulun läänin taidetoimikunta muodostuu Pohjois\-Pohjanmaan liiton ja Kainuun liiton toimialueista;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Lapin taidetoimikunta muodostuu Lapin liiton toimialueesta\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1998\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ennen päätöksen voimaantuloa voidaan ryhtyä päätöksen täytäntöönpanon edellyttämiin toimenpiteisiin\.
