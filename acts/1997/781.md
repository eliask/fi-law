### 1 § Työsuojelupiirien toimialueet ja nimet

<a id="section-1-subsection-1"></a>
#### \(1\)

Työsuojelun alueellista ohjausta ja tarkastusta varten maa jaetaan työsuojelupiireihin siten, että:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan työsuojelupiirin muodostavat Uudenmaan liiton ja Itä\-Uudenmaan liiton toimialueet;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Turun ja Porin työsuojelupiirin muodostavat Varsinais\-Suomen liiton ja Satakuntaliiton toimialueet ja Ahvenanmaan maakunta;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Hämeen työsuojelupiirin muodostavat Hämeen liiton, Päijät\-Hämeen liiton ja Pirkanmaan liiton toimialueet;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Kymen työsuojelupiirin muodostavat Kymenlaakson liiton ja Etelä\-Karjalan liiton toimialueet;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Mikkelin työsuojelupiirin muodostaa Etelä\-Savon maakuntaliiton toimialue;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan työsuojelupiirin muodostaa Pohjois\-Karjalan liiton toimialue;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Kuopion työsuojelupiirin muodostaa Savon liiton toimialue;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Keski\-Suomen työsuojelupiirin muodostaa Keski\-Suomen liiton toimialue;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Vaasan työsuojelupiirin muodostavat Etelä\-Pohjanmaan liiton, Österbottens förbund\-Pohjanmaan liiton ja Keski\-Pohjanmaan liiton toimialueet;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Oulun työsuojelupiirin muodostavat Pohjois\-Pohjanmaan liiton ja Kainuun liiton toimialueet; sekä

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Lapin työsuojelupiirin muodostaa Lapin liiton toimialue\.

<a id="section-2"></a>
### 2 § Työsuojelutoimistojen toimipaikat

<a id="section-2-subsection-1"></a>
#### \(1\)

Työsuojelupiirien työsuojelutoimistot sijaitsevat siten, että:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan työsuojelupiirin työsuojelutoimisto on Helsingissä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Turun ja Porin työsuojelupiirin työsuojelutoimisto on Turussa;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Hämeen työsuojelupiirin työsuojelutoimisto on Tampereella;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Kymen työsuojelupiirin työsuojelutoimisto on Lappeenrannassa;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Mikkelin työsuojelupiirin työsuojelutoimisto on Mikkelissä;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Pohjois\-Karjalan työsuojelupiirin työsuojelutoimisto on Joensuussa;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Kuopion työsuojelupiirin työsuojelutoimisto on Kuopiossa;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Keski\-Suomen työsuojelupiirin työsuojelutoimisto on Jyväskylässä;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Vaasan työsuojelupiirin työsuojelutoimisto on Vaasassa;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Oulun työsuojelupiirin työsuojelutoimisto on Oulussa; sekä

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** Lapin työsuojelupiirin työsuojelutoimisto on Kemissä\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Lisäksi työsuojelupiirissä voi olla tarpeen mukaan alueellisia toimipisteitä, joiden sijaintipaikoista päättää työsuojelupiirin työsuojelutoimisto\.

<a id="section-3"></a>
### 3 § Voimaantulo

<a id="section-3-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1998\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan työsuojelupiireistä 18 päivänä helmikuuta 1993 annettu valtioneuvoston päätös [\(212/1993\)](<https://www.finlex.fi/fi/lainsaadanto/1993/212>)\.

<a id="section-3-subsection-3"></a>
#### \(3\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
