# Sisäasiainministeriön päätös rekisterihallinnon suoritteiden maksuista

### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tässä päätöksessä määrätään väestörekisterikeskuksen ja maistraattien suoritteiden maksullisuudesta, maksuperusteista sekä julkisoikeudellisista suoritteista perittävistä maksuista lukuun ottamatta kaupparekisterin, yhdistysrekisterin, julkisen notaarin ja julkisen kaupanvahvistajan suoritteita\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Mitä tässä päätöksessä määrätään maistraatin suoritteista, sovelletaan vastaavasti Ahvenanmaan lääninhallituksen tuottamiin rekisterihallinnon suoritteisiin\.

<a id="section-2"></a>
### 2 § Maksuttomat julkisoikeudelliset suoritteet

<a id="section-2-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksen maksuttomia julkisoikeudellisia suoritteita ovat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** väestötietojärjestelmän ylläpito ja toi\-mivuuden varmistaminen;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** uskonnollisten yhdyskuntien rekisterin pito;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** vihkimisoikeusrekisterin pito; sekä

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** rekisterihallinnon paikallisviranomais\-ten ohjaus\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Maistraatin maksuttomia julkisoikeudellisia suoritteita ovat:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** väestötietojärjestelmän tietojen keruu, tallettaminen ja tarkistaminen;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** evankelis\-luterilaisen kirkon ja ortodoksisen kirkkokunnan viranomaisten ohjaus ja valvonta väestökirjanpitoasioissa;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** virkatodistus tai muu siihen verrattava asiakirja, joka annetaan sosiaalisen tuen tai avustuksen hakemista varten; sekä

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** avioliiton esteiden tutkinta ja vihkiminen\.

<a id="section-3"></a>
### 3 § Maksulliset julkisoikeudelliset suoritteet

<a id="section-3-subsection-1"></a>
#### \(1\)

Maksullisia julkisoikeudellisia suoritteita ovat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** väestötietopalvelut valtion viranomaisille, kunnille ja kuntayhtymille sekä evankelis\-luterilaiselle kirkolle ja ortodoksiselle kirkkokunnalle;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** väestötietopalvelut yrityksille ja yhtei\-söille lakiin tai asetukseen perustuvaa tietotarvetta varten;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** väestötietopalvelut tieteellistä tutkimusta varten;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** väestötietojärjestelmästä ja rekisteröityjen uskonnollisten yhdyskuntien jäsenarkistoista annettavat yksittäiset todistukset ja muut niihin verrattavat asiakirjat;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** uskonnollisten yhdyskuntien rekisteristä annettavat otteet;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** vihkimisoikeusrekisteristä annetussa asetuksessa \(421/1993\) tarkoitetut todistukset;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** painovapauslaissa tarkoitetut todistukset;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** kaivosasetuksessa \(663/1965\) tarkoitetut todistukset;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** kansanedustajain vaaleista annetussa laissa \(391/1969\) tarkoitetut vaalitietojärjestelmän äänioikeusrekisteristä annettavat otteet; sekä

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** perintökaaressa \(40/1965\) tarkoitettu perukirjan osakastietojen vahvistaminen\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Edellä 1 momentissa mainituista suoritteista peritään oheisen maksutaulukon mukaiset kiinteät maksut tai tapauskohtaisesti erikseen määrättävät maksut\.

<a id="section-4"></a>
### 4 § Muut maksulliset suoritteet

<a id="section-4-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksen ja maistraattien muut maksulliset suoritteet ovat:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** muut kuin 3 §:ssä mainitut väestötietopalvelut;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** muut kuin väestötietojärjestelmän yllä\-pitoa koskevat koulutuspalvelut;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** konsultointipalvelut;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** julkaisutoiminta;

<a id="section-4-subsection-1-paragraph-5"></a>
- **5.** muut kuin 3 §:ssä tarkoitetut jäljennökset sekä lähettämis\- ja postituspalvelut; sekä

<a id="section-4-subsection-1-paragraph-6"></a>
- **6.** väestörekisterikeskuksen tai maistraatin hallinnassa olevien tilojen käyttö\.

<a id="section-5"></a>
### 5 § Eräiden julkisoikeudellisten suoritteiden maksuperusteet

<a id="section-5-subsection-1"></a>
#### \(1\)

Kunnille muutoin kuin teknisen kysely\-yhteyden avulla luovutettavista rakennusten ja huoneistojen tiedoista sekä rakennushankkeita koskevista tiedoista peritään vain suoritteen luovuttamisesta aiheutuneet tietojenkä sittelykustannukset\.

<a id="section-6"></a>
### 6 § Viranomaisten toimivalta

<a id="section-6-subsection-1"></a>
#### \(1\)

Väestörekisterikeskuksella ja maistraateilla on toimivalta tuottamiensa suoritteiden maksuja ja hinnoittelua koskevissa asioissa lukuun ottamatta oheisessa maksutaulukossa mainittuja maksuja\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Väestörekisterikeskuksella on lisäksi toimivalta rekisterihallinnon valtakunnallisten puhelinpalvelujen maksuja ja hinnoittelua koskevissa asioissa lukuun ottamatta oheisessa maksutaulukossa mainittuja palvelupuhelinmaksuja\.

<a id="section-7"></a>
### 7 § Voimaantulo

<a id="section-7-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä tammikuuta 1998 ja on voimassa vuoden 1998 loppuun\.

<a id="section-7-subsection-2"></a>
#### \(2\)

Suoritteesta, joka on tilattu ennen tämän päätöksen voimaantuloa, peritään maksu ennen tämän päätöksen voimaantuloa voimassa olleen maksupäätöksen mukaan\.

<a id="section-7-subsection-3"></a>
#### \(3\)

Ennen tämän päätöksen voimaantuloa voidaan ryhtyä sen täytäntöönpanon edellyttämiin toimenpiteisiin\.
