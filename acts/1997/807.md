# Valtioneuvoston päätös oikeudesta hankkia maa\- ja metsätalousmaata annetun lain alueellisesta soveltamisesta

- Statute: [`807/1997`](<https://www.finlex.fi/fi/laki/ajantasa/1997/807>)
- Version: `1997-09-01`
- LawVM tree hash: `96dee28cd908ec7a846e9c724304312a4e8595bec3eb3c16fcf81e022a39aa72`

## Contents

- [1 §](#section-1)

- [2 §](#section-2)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Oikeudesta hankkia maa\- ja metsätalousmaata annettua lakia [\(391/1978\)](<https://www.finlex.fi/fi/lainsaadanto/1978/391>), jäljempänä maanhankintaoikeuslakia, ei sovelleta:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Itä\-Uudenmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Kymenlaakson maakunnan Pyhtään kunnassa;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Varsinais\-Suomen maakunnassa;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** Satakunnan maakunnassa;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** Hämeen maakunnassa;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** Pirkanmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** Päijät\-Hämeen maakunnassa;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** Etelä\-Pohjanmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** Vaasan rannikkoseudun maakunnassa;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** Keski\-Pohjanmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** Pohjois\-Pohjanmaan maakunnassa;

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** Lapin maakunnassa\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Maakunnalla tarkoitetaan rakennuslain [\(370/1958\) 18 §:n](<https://www.finlex.fi/fi/lainsaadanto/1958/370#chp_3__sec_18>) mukaista seutukaavaaluetta\.

<a id="section-1-subsection-3"></a>
#### \(3\)

Jos kaupan kohteena olevasta maa\- ja metsätalousmaasta vain osa sijaitsee 1 momentissa tarkoitetulla alueella pääosan maasta sijaitessa lain soveltamisalueella, kauppaan sovelletaan kuitenkin maanhankintaoikeuslakia\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä syyskuuta 1997\. Päätöstä sovelletaan sen voimaantulon jälkeen tehtyihin kauppoihin\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan oikeudesta hankkia maa\- ja metsätalousmaata annetun lain alueellisesta soveltamisesta 25 päivänä tammikuuta 1996 annettu valtioneuvoston päätös [\(44/1996\)](<https://www.finlex.fi/fi/lainsaadanto/1996/44>)\.
