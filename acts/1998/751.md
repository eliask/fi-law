# Oikeusministeriön päätös presidentinvaalissa käytettävien ehdokasasettelulomakkeiden kaavoista

- Statute: [`751/1998`](<https://www.finlex.fi/fi/laki/ajantasa/1998/751>)

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ehdokkaiden asettamisessa presidentinvaalissa voidaan käyttää tämän päätöksen mukaisia lomakkeita\. Kaavat on vahvistettu seuraaville lomakkeille:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ilmoitus puolueen vaaliasiamiehestä ja varamiehestä;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** puolueen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** puolueen ehdokkaan suostumus;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** kannattajakortti;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ilmoitus valitsijayhdistyksen vaaliasiamiehestä ja varamiehestä;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** valitsijayhdistyksen perustamisasiakirja;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** valitsijayhdistyksen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** valitsijayhdistyksen ehdokkaan suostumus; sekä

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** vaaliasiamiehen antama valtakirja\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Vahvistetut kaavat ovat tämän päätöksen liitteinä\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 23 päivänä lokakuuta 1998\.
