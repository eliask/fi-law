# Opetusministeriön päätös Opetusalan koulutuskeskuksen maksullisista suoritteista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Suoritteita, jotka Opetusalan koulutuskeskus hinnoittelee liiketaloudellisin perustein, ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** koulutuskeskuksen järjestämä koulutus;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** konsultointi;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** tilauksesta tehdyt selvitykset ja tutkimukset;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** julkaisut ja kustannuspalvelut;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** majoitus\- ja ruokailupalvelut;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** koulutuskeskuksen toimitilojen ja laitteiden käyttö;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** valokopio\- ja muut jäljennökset;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** asiakirjojen ja muun aineiston lähettäminen ja postitus; sekä

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** muut tilatut palvelusuoritteet\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 1 päivänä elokuuta 1998\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Tällä päätöksellä kumotaan 24 päivänä marraskuuta 1993 annettu opetusministeriön päätös ammattikasvatushallinnon koulutuskeskuksen ja Heinolan kurssikeskuksen maksullisista suoritteista [\(1148/1993\)](<https://www.finlex.fi/fi/lainsaadanto/1993/1148>)\.
