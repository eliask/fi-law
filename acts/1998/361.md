# Asetus valtion virkamiesten työaika\-asetuksen 1 §:n muuttamisesta

- Version: `1998-05-29`

## Contents

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Työaikalakia ei sovelleta valtion virkamiehen työhön seuraavissa tehtävissä:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ulkomaanedustuksessa;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** tuomioistuimen jäsenen, esittelijän, käräjäviskaalin ja notaarin tehtävissä;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** yleisen oikeusavustajan tehtävissä;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** yleisenä syyttäjänä;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** ulosottomies\- ja haastemiestehtävissä; sekä

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** luotsaus\-, luotsikutterinkuljetus\- ja väylänhoitotehtävissä\.
