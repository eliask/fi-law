# Oikeusministeriön päätös kunnallisvaaleissa käytettävien ehdokasasettelulomakkeiden kaavoista

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Ehdokkaiden asettamisessa kunnallisvaaleissa voidaan käyttää tämän päätöksen mukaisia lomakkeita\. Kaavat on vahvistettu seuraaville lomakkeille:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** ilmoitus puolueen jäseniä kunnassa edustavasta yhdistyksestä;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** ilmoitus puolueen vaaliasiamiehestä ja varamiehestä sekä puolueen vaaliasiamiehelle annettu valtakirja;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** puolueen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** ehdotus puolueen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** puolueen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** ilmoitus puolueiden vaaliliitosta;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** valitsijayhdistyksen perustamisasiakirja lisälehtineen;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** valitsijayhdistyksen ehdokashakemus;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** ehdotus valitsijayhdistyksen ehdokaslistaksi;

<a id="section-1-subsection-1-paragraph-10"></a>
- **10.** valitsijayhdistyksen ehdokkaan suostumus ja vakuutus;

<a id="section-1-subsection-1-paragraph-11"></a>
- **11.** ilmoitus yhteislistasta lisälehtineen;

<a id="section-1-subsection-1-paragraph-12"></a>
- **12.** ilmoitus varaehdokkaista; sekä

<a id="section-1-subsection-1-paragraph-13"></a>
- **13.** vaaliasiamiehen antama valtakirja\.

<a id="section-1-subsection-2"></a>
#### \(2\)

Vahvistetut kaavat ovat tämän päätöksen liitteinä\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä päätös tulee voimaan 23 päivänä lokakuuta 1998\.
