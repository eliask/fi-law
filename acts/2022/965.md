### 2 § Ministeriön toimialan virastot, laitokset, toimielimet ja yhteisöt

<a id="section-2-subsection-1"></a>
#### \(1\)

Sosiaali\- ja terveysministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Terveyden ja hyvinvoinnin laitos;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Lääkealan turvallisuus\- ja kehittämiskeskus;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Sosiaali\- ja terveysalan lupa\- ja valvontavirasto;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Säteilyturvakeskus;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** sosiaaliturva\-asioiden muutoksenhakulautakunta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** työterveyslaitos;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** työsuojeluhallinto;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Alko Oy;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** työsuojelurahasto;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** Työllisyysrahasto;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** työehtosopimuksen yleissitovuuden vahvistamislautakunta;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** Lääkkeiden hintalautakunta;

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** Sosiaali\- ja terveysjärjestöjen avustuskeskus;

<a id="section-2-subsection-1-paragraph-14"></a>
- **14.** terveydenhuollon palveluvalikoimaneuvosto;

<a id="section-2-subsection-1-paragraph-15"></a>
- **15.** Sosiaali\- ja terveysalan tietolupaviranomainen;

<a id="section-2-subsection-1-paragraph-16"></a>
- **16.** STUK International Oy;

<a id="section-2-subsection-1-paragraph-17"></a>
- **17.** FinnHEMS Oy;

<a id="section-2-subsection-1-paragraph-18"></a>
- **18.** Rokotetutkimuskeskus Finvac Oy\.

<a id="section-3"></a>
### 3 § Ministeriön organisaatio

<a id="section-3-subsection-1"></a>
#### \(1\)

Osastojen ulkopuolella ovat erillisyksiköinä strategia\- ja talousyksikkö, henkilöstö\- ja hallintoyksikkö, viestintäyksikkö ja kansainvälisten asioiden yksikkö\.

<a id="section-6"></a>
### 6 § Johtavat virkamiehet

<a id="section-6-subsection-1"></a>
#### \(1\)

Ministeriössä on kansliapäällikkö\. Osaston päällikkönä toimii osastopäällikkö\. Osaston päälliköllä on ylijohtajan arvonimi\.
