### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

- **1.** Etelä\-Suomen yhteistyöalue:

<a id="section-1-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** Etelä\-Karjalan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** Helsingin kaupunki;

<a id="section-1-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** HUS\-yhtymä;

<a id="section-1-subsection-1-paragraph-1-subparagraph-d"></a>
  - **d.** Itä\-Uudenmaan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-e"></a>
  - **e.** Keski\-Uudenmaan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-f"></a>
  - **f.** Kymenlaakson hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-g"></a>
  - **g.** Länsi\-Uudenmaan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-h"></a>
  - **h.** Päijät\-Hämeen hyvinvointialue;

<a id="section-1-subsection-1-paragraph-1-subparagraph-i"></a>
  - **i.** Vantaan ja Keravan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** Itä\-Suomen yhteistyöalue:

<a id="section-1-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** Pohjois\-Savon hyvinvointialue;

<a id="section-1-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** Keski\-Suomen hyvinvointialue;

<a id="section-1-subsection-1-paragraph-2-subparagraph-c"></a>
  - **c.** Etelä\-Savon hyvinvointialue;

<a id="section-1-subsection-1-paragraph-2-subparagraph-d"></a>
  - **d.** Pohjois\-Karjalan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** Sisä\-Suomen yhteistyöalue:

  - **a.** Pirkanmaan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** Kanta\-Hämeen hyvinvointialue;

<a id="section-1-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** Etelä\-Pohjanmaan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** Länsi\-Suomen yhteistyöalue:

<a id="section-1-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** Varsinais\-Suomen hyvinvointialue;

<a id="section-1-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** Satakunnan hyvinvointialue;

<a id="section-1-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** Pohjanmaan hyvinvointialue;

- **5.** Pohjois\-Suomen yhteistyöalue:

<a id="section-1-subsection-1-paragraph-5-subparagraph-a"></a>

<a id="section-1-subsection-1-paragraph-5-subparagraph-b"></a>
