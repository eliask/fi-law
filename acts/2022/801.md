# Sosiaali\- ja terveysministeriön asetus Terveyden ja hyvinvoinnin laitoksen laaturekistereistä

<a id="section-1"></a>
### 1 §

<a id="section-1-subsection-1"></a>
#### \(1\)

Terveyden ja hyvinvoinnin laitoksen rekisterinpidollisella vastuulla olevat potilasryhmäkohtaiset, sairautta ja sairauden hoitoa koskevat terveydenhuollon laaturekisterit ovat:

<a id="section-1-subsection-1-paragraph-1"></a>
- **1.** diabetesrekisteri;

<a id="section-1-subsection-1-paragraph-2"></a>
- **2.** HIV\-rekisteri;

<a id="section-1-subsection-1-paragraph-3"></a>
- **3.** munuaistautirekisteri;

<a id="section-1-subsection-1-paragraph-4"></a>
- **4.** psykoosien hoidon laaturekisteri;

<a id="section-1-subsection-1-paragraph-5"></a>
- **5.** selkärekisteri;

<a id="section-1-subsection-1-paragraph-6"></a>
- **6.** suun ja hampaiden sairauksien hoidon laaturekisteri;

<a id="section-1-subsection-1-paragraph-7"></a>
- **7.** sydänrekisteri;

<a id="section-1-subsection-1-paragraph-8"></a>
- **8.** tehohoidon laaturekisteri;

<a id="section-1-subsection-1-paragraph-9"></a>
- **9.** tulehduksellisten reumasairauksien laaturekisteri\.

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2023\.
