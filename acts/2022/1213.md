### 1 § Soveltamisala

<a id="section-1-subsection-1"></a>
#### \(1\)

Tätä asetusta sovelletaan pelastustoimen järjestämisestä annetussa laissa \(613/2021\) säädettyjen tiedonantovelvoitteiden vähimmäistietosisältöön sekä tietojen toimittamiseen sisäministeriölle ja Lupa\- ja valvontavirastolle\.

<a id="section-2"></a>
### 2 § Pelastustoimen palveluiden saatavuus

<a id="section-2-subsection-1"></a>
#### \(1\)

Hyvinvointialueen tulee seurata onnettomuuksien ehkäisyyn ja valvontaan kuuluvien pelastustoimen palveluiden saatavuutta ja niihin varautumista, verrata tätä tietoa palveluiden tarpeeseen ja vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain näitä palveluita koskeva selvitys seuraavasti:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** pelastustoimelle kuuluva ohjaus, neuvonta ja turvallisuusviestintä;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** palontutkinta;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** onnettomuuksien ehkäisyä koskeva yhteistyö;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** onnettomuuskehityksen seuranta;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** hyvinvointialueiden yhteistoiminnassa hoitamien onnettomuuksien ehkäisyyn ja valvontaan kuuluvien tehtävien asianmukaisuuden valvonta;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** valvontatehtävä; sekä

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** valmiustarkastukset\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Hyvinvointialueen tulee seurata pelastustoimintaan kuuluvien pelastustoimen palveluiden saatavuutta ja niihin varautumista, verrata tätä tietoa palveluiden tarpeeseen ja vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain näitä palveluita koskeva selvitys seuraavasti:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** väestön varoittaminen vaara\- ja onnettomuustilanteessa sekä siihen tarvittavan hälytysjärjestelmä;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** pelastuslaitoksen ja sopimuspalokuntien kyky suorittaa onnettomuus\- ja vaaratilanteissa tarvittavat toimenpiteet viivytyksettä ja tehokkaasti;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** pelastustoiminnan johtaminen;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** hyvinvointialueiden yhteistoiminnassa hoitamien pelastustoimintaan kuuluvien tehtävien asianmukaisuuden valvonta;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** pelastusviranomaisen muille viranomaisille antaman virka\-apu; sekä

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** osallistuminen pelastustoimeen kuuluvan ulkomaille annettavan avun ja pelastustoimeen kuuluvan kansainvälisen avun vastaanottamisen edellyttämän valmiuden ylläpitoon\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Hyvinvointialueen tulee seurata pelastustoiminnan suunnitelmien kattavuutta, laadintaa, ajantasaisuutta ja päivittämistä, verrata tätä tietoa palveluiden tarpeeseen ja vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain näitä palveluita koskeva selvitys seuraavasti:

<a id="section-2-subsection-3-paragraph-1"></a>
- **1.** hälytysohje;

<a id="section-2-subsection-3-paragraph-2"></a>
- **2.** pelastuslaitosten keskinäisen avunannon suunnitelma;

<a id="section-2-subsection-3-paragraph-3"></a>
- **3.** yhteistyösuunnitelmat;

<a id="section-2-subsection-3-paragraph-4"></a>
- **4.** hyvinvointialueen onnettomuusuhkien edellyttämät pelastustoimintaa ja sen johtamista koskevat suunnitelmat; sekä

<a id="section-2-subsection-3-paragraph-5"></a>
- **5.** erityistä vaaraa aiheuttavien kohteiden ulkoiset pelastussuunnitelmat\.

<a id="section-2-subsection-4"></a>
#### \(4\)

Hyvinvointialueen tulee seurata pelastustoimen vapaaehtoistoimintaan liittyvien tehtävien hoitamista ja verrata tätä tietoa palveluiden tarpeeseen ja vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain näitä palveluita koskeva selvitys seuraavasti:

<a id="section-2-subsection-4-paragraph-1"></a>
- **1.** vapaaehtoisten käyttö pelastustoimen palveluiden tuottamisessa;

<a id="section-2-subsection-4-paragraph-2"></a>
- **2.** pelastustoimen vapaaehtoistoiminnan edistäminen;

<a id="section-2-subsection-4-paragraph-3"></a>
- **3.** sopimuspalokuntaan ja muuhun vastaavaan yhteisöön kuuluvan terveystarkastukset; sekä

<a id="section-2-subsection-4-paragraph-4"></a>
- **4.** sivutoimisen henkilöstön ja sopimushenkilöstön koulutus\.

<a id="section-2-subsection-5"></a>
#### \(5\)

Hyvinvointialueen tulee seurata väestönsuojeluun varautumiseen kuuluvien pelastustoimen tehtävien saatavuutta, verrata tätä tietoa palveluiden tarpeeseen ja vastaavaan muita hyvinvointialueita koskevaan tietoon; sekä laatia vuosittain näitä palveluita koskeva selvitys seuraavasti:

<a id="section-2-subsection-5-paragraph-1"></a>
- **1.** väestönsuojeluun varautumisen edellyttämä suunnittelu;

<a id="section-2-subsection-5-paragraph-2"></a>
- **2.** pelastustoimen viranomaisten vastuulla olevien väestönsuojelutehtävien edellyttämän toiminnan ja suunnitelmien yhteensovittaminen;

<a id="section-2-subsection-5-paragraph-3"></a>
- **3.** hyvinvointialueen väestönsuojeluorganisaation määrittäminen;

<a id="section-2-subsection-5-paragraph-4"></a>
- **4.** väestönsuojelutehtäviin tarvittavan henkilöstön varaaminen;

<a id="section-2-subsection-5-paragraph-5"></a>
- **5.** väestönsuojelun johto\- ja erityishenkilöstön koulutus;

<a id="section-2-subsection-5-paragraph-6"></a>
- **6.** pelastustoiminnan poikkeusoloissa mahdollistavien johtamistilojen ja muiden edellytysten järjestäminen; sekä

<a id="section-2-subsection-5-paragraph-7"></a>
- **7.** kuntien kanssa tehtävä yhteistyö\.

<a id="section-3"></a>
### 3 § Pelastustoimen palveluiden laatu

<a id="section-3-subsection-1"></a>
#### \(1\)

Hyvinvointialueen tulee seurata pelastustoimen palveluiden laatua, verrata tätä tietoa vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain pelastustoimen palveluiden laatua koskeva selvitys seuraavasti:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** valtioneuvoston laadukkaan pelastustoimen järjestämiselle vahvistamien valtakunnallisten tavoitteiden toteutuminen hyvinvointialueella;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** sisäministeriön ja hyvinvointialueen neuvotteluissa sovittujen tavoitteiden toteutuminen hyvinvointialueella; sekä

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** sisäministeriön laatua koskevien toimenpidesuositusten toteutuminen hyvinvointialueella\.

<a id="section-4"></a>
### 4 § Pelastustoimen palveluiden vaikuttavuus

<a id="section-4-subsection-1"></a>
#### \(1\)

Hyvinvointialueen tulee seurata pelastustoimen palveluiden vaikuttavuutta, verrata seurannassa saatua tietoa vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain pelastustoimen tehtävien vaikuttavuutta koskeva selvitys seuraavasti:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** ihmisten turvallisuuden paranemiselle asetettujen valtakunnallisten tavoitteiden toteutuminen;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** onnettomuuksien vähenemiselle asetettujen valtakunnallisten tavoitteiden toteutuminen; sekä

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** pelastustoiminnan tehokkuudelle asetettujen valtakunnallisten tavoitteiden toteutuminen\.

<a id="section-5"></a>
### 5 § Pelastustoimen palveluiden kustannukset

<a id="section-5-subsection-1"></a>
#### \(1\)

Hyvinvointialueen tulee seurata pelastustoimen palveluiden kustannuksia, verrata seurannassa saatua tietoa vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain pelastustoimen tehtävien tuottavuutta koskeva selvitys seuraavasti:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** onnettomuuksien ehkäisy;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** pelastustoiminta;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** väestönsuojeluun ja muihin poikkeusoloihin varautuminen;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** vaarallisten kemikaalien ja räjähteiden valvonta;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** öljy\- ja aluekemikaalivahinkojen torjunta; sekä

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** muut tehtävät\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Hyvinvointialueen pelastustoimen kustannuksia ja talouden tilaa koskevan selvityksen tulee sisältää seuraavat tiedot:

<a id="section-5-subsection-2-paragraph-1"></a>
- **1.** talousarvion toteuma, tilikauden tulos ja kuvaus rahoituksen riittävyydestä lakisääteisiin palveluihin;

<a id="section-5-subsection-2-paragraph-2"></a>
- **2.** määrä \(€\) ja osuus \(%\) yleiskatteisesta rahoituksesta;

<a id="section-5-subsection-2-paragraph-3"></a>
- **3.** kehitysnäkymät yleiskatteisen rahoituksen riittävyyden osalta;

<a id="section-5-subsection-2-paragraph-4"></a>
- **4.** kustannukset;

<a id="section-5-subsection-2-paragraph-4-subparagraph-a"></a>
  - **a.** kokonaiskustannukset;

<a id="section-5-subsection-2-paragraph-4-subparagraph-b"></a>
  - **b.** kokonaiskustannukset asukasta kohden;

<a id="section-5-subsection-2-paragraph-4-subparagraph-c"></a>
  - **c.** palveluille kohdistetut kokonaiskustannukset;

<a id="section-5-subsection-2-paragraph-4-subparagraph-d"></a>
  - **d.** palveluille kohdistetut asukaskohtaiset kokonaiskustannukset;

<a id="section-5-subsection-2-paragraph-5"></a>
- **5.** kulurakenne;

<a id="section-5-subsection-2-paragraph-6"></a>
- **6.** tuottorakenne;

<a id="section-5-subsection-2-paragraph-7"></a>
- **7.** investoinnit;

<a id="section-5-subsection-2-paragraph-7-subparagraph-a"></a>
  - **a.** investointikulut;

<a id="section-5-subsection-2-paragraph-7-subparagraph-b"></a>
  - **b.** investointikulut asukasta kohden \(brutto\); sekä

<a id="section-5-subsection-2-paragraph-7-subparagraph-c"></a>
  - **c.** investointituotot\.

<a id="section-6"></a>
### 6 § Pelastustoimen palveluiden tuottavuus

<a id="section-6-subsection-1"></a>
#### \(1\)

Hyvinvointialueen tulee seurata pelastustoimen palveluiden tuottavuutta, verrata seurannassa saatua tietoa vastaavaan muita hyvinvointialueita koskevaan tietoon sekä laatia vuosittain pelastustoimen tehtävien tuottavuutta koskeva selvitys seuraavasti:

<a id="section-6-subsection-1-paragraph-1"></a>
- **1.** pelastustoimen tuottavuuden ja kustannusvaikuttavuuden lisäämiselle asetettujen valtakunnallisten tavoitteiden toteutuminen;

<a id="section-6-subsection-1-paragraph-2"></a>
- **2.** sisäministeriön kustannusvaikuttavuutta koskevien toimenpidesuositusten toteutuminen hyvinvointialueella; sekä

<a id="section-6-subsection-1-paragraph-3"></a>
- **3.** toteutetut tuottavuutta parantavat toimenpiteet ja investoinnit sekä tuottavuuden kehittämismahdollisuudet\.
