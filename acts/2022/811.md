# Valtioneuvoston asetus eräistä positiiviseen luottotietorekisteriin talletettavista tiedoista

<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Positiivisesta luottotietorekisteristä annetun lain 7 §:n 2 momentin 2 kohdassa tarkoitettuna luoton lyhennystapana talletetaan positiiviseen luottotietorekisteriin jokin seuraavista:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** tasalyhennys;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** kiinteä tasaerä;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** annuiteetti;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** tieto siitä, että luotto maksetaan takaisin yhdessä erässä,

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** tieto siitä, että luoton viimeinen maksuerä on huomattavasti muita maksueriä suurempi;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** muu lyhennystapa\.

<a id="section-3"></a>
### 3 §

<a id="section-3-subsection-1"></a>
#### \(1\)

Positiivisesta luottotietorekisteristä annetun lain 8 §:n 3 kohdassa tarkoitettuna koron määräytymisperusteena talletetaan positiiviseen luottotietorekisteriin jokin seuraavista:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** euriborkorko;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** luotonantajan itsensä määrittämä viitekorko;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** muu vaihtuva korko;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** kiinteä korko;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** koroton\.

<a id="section-4"></a>
### 4 §

<a id="section-4-subsection-1"></a>
#### \(1\)

Positiivisesta luottotietorekisteristä annetun lain 8 §:n 6 kohdassa tarkoitettuna koron määräytymisperusteena kiinteän koron jakson päättymisen jälkeen talletetaan positiiviseen luottotietorekisteriin jokin seuraavista:

<a id="section-4-subsection-1-paragraph-1"></a>
- **1.** euriborkorko;

<a id="section-4-subsection-1-paragraph-2"></a>
- **2.** luotonantajan itsensä määrittämä viitekorko;

<a id="section-4-subsection-1-paragraph-3"></a>
- **3.** muu vaihtuva korko;

<a id="section-4-subsection-1-paragraph-4"></a>
- **4.** koroton\.

<a id="section-5"></a>
### 5 §

<a id="section-5-subsection-1"></a>
#### \(1\)

Positiivisesta luottotietorekisteristä annetun lain 9 §:n 2 kohdassa tarkoitettuna vakuuden tyyppinä talletetaan positiiviseen luottotietorekisteriin jokin seuraavista:

<a id="section-5-subsection-1-paragraph-1"></a>
- **1.** asunto\-omaisuus;

<a id="section-5-subsection-1-paragraph-2"></a>
- **2.** muu kiinteä omaisuus;

<a id="section-5-subsection-1-paragraph-3"></a>
- **3.** osamaksukaupan kohde;

<a id="section-5-subsection-1-paragraph-4"></a>
- **4.** muu irtain omaisuus;

<a id="section-5-subsection-1-paragraph-5"></a>
- **5.** henkilötakaus;

<a id="section-5-subsection-1-paragraph-6"></a>
- **6.** valtiontakaus;

<a id="section-5-subsection-1-paragraph-7"></a>
- **7.** muu takaus;

<a id="section-5-subsection-1-paragraph-8"></a>
- **8.** muu vakuus\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Edellä 1 momentin 1 kohdassa asunto\-omaisuudella tarkoitetaan [kuluttajansuojalain 7 a luvun 3 §:n](<https://www.finlex.fi/fi/lainsaadanto/1978/38#chp_7a__sec_3>) 1 momentin 1 kohdassa tarkoitettua asunto\-omaisuutta\.

<a id="section-6"></a>
### 6 §

<a id="section-6-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 15 päivänä syyskuuta 2022\.
