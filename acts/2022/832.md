### 2 § Ministeriön toimialaan kuuluvat virastot, laitokset, yhtiöt ja toimielimet

<a id="section-2-subsection-1"></a>
#### \(1\)

Ministeriön toimialaan kuuluvat:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** Ilmatieteen laitos;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** Liikenne\- ja viestintävirasto;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** Väylävirasto;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** Cinia Oy;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** Itärata Oy;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** Liikenteenohjausyhtiö Fintraffic Oy;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** Suomi\-rata Oy;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** Turun Tunnin Juna Oy ja

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** Liikenneturva\.

<a id="section-3"></a>
### 3 § Ministeriön organisaatio

<a id="section-3-subsection-1"></a>
#### \(1\)

Ministeriössä on:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** konserniohjausosasto;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** palveluosasto;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** tieto\- ja turvallisuusosasto ja

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** verkko\-osasto\.

<a id="section-3-subsection-2"></a>
#### \(2\)

Ministeriössä on lisäksi kansliapäällikön välittömässä alaisuudessa ministeriön viestintä ja kansainvälisten asioiden yksikkö\.

<a id="section-5"></a>
### 5 § Virkojen kelpoisuusvaatimukset

<a id="section-5-subsection-1"></a>
#### \(1\)

Hallitusneuvoksen ja hallitussihteerin kelpoisuudesta säädetään valtioneuvoston ohjesäännön \(262/2003\) 43 §:n 1 momentissa\.

<a id="section-5-subsection-2"></a>
#### \(2\)

Kelpoisuusvaatimuksena on:

<a id="section-5-subsection-2-paragraph-1"></a>
- **1.** muulla kuin yksikön johtajana toimivalla neuvoksella, yli\-insinöörillä ja neuvottelevalla virkamiehellä ylempi korkeakoulututkinto sekä perehtyneisyys viran tehtäväalaan; yli\-insinöörillä ylemmän korkeakoulututkinnon tulee olla diplomi\-insinöörin tutkinto;

<a id="section-5-subsection-2-paragraph-2"></a>
- **2.** valtion kyberturvallisuusjohtajalla ylempi korkeakoulututkinto, sekä perehtyneisyys viran tehtäväalaan ja käytännössä osoitettu johtamistaito\.

<a id="section-6"></a>
### 6 § Virkojen täyttäminen

<a id="section-6-subsection-1"></a>
#### \(1\)

Virkamiehistä, jotka nimittää valtioneuvosto, säädetään valtioneuvoston ohjesäännössä\.

<a id="section-6-subsection-2"></a>
#### \(2\)

Yli\-insinöörin nimittää valtioneuvosto\.

<a id="section-6-subsection-3"></a>
#### \(3\)

Muut virkamiehet nimittää sekä työsopimussuhteisen henkilöstön ottaa ministeriö\.
