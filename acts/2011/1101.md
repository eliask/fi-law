### 1 § Suomen metsäkeskuksen julkisen palvelun yksikön keskusyksikön toimipaikka

<a id="section-1-subsection-1"></a>
#### \(1\)

Suomen metsäkeskuksen julkisen palvelun yksikön keskusyksikön toimipaikka on Lahti\.

<a id="section-2"></a>
### 2 § Alueyksiköiden lukumäärä, nimet ja toimialueet

<a id="section-2-subsection-1"></a>
#### \(1\)

Suomen metsäkeskuksen julkisen palvelun yksikön alueyksiköitä on 13\.

<a id="section-2-subsection-2"></a>
#### \(2\)

Alueyksiköiden nimet ja toimialueet ovat seuraavat:

<a id="section-2-subsection-2-paragraph-1"></a>
- **1.** Rannikon alueyksikön toimialueeseen kuuluvat Uudenmaan maakunnan alueesta Espoo, Hanko, Helsinki, Inkoo, Kauniainen, Kirkkonummi, Lapinjärvi, Loviisa, Porvoo, Raasepori, Sipoo, Siuntio ja Vantaa, Varsinais\-Suomen maakunnan alueesta Kemiönsaari ja Parainen sekä Pohjanmaan maakunnan alue lukuun ottamatta Isokyröä ja Laihiaa sekä Keski\-Pohjanmaan maakunnan alueesta Kokkola lukuun ottamatta Kälviän kunnan, Lohtajan kunnan ja Ullavan kunnan liittämisestä Kokkolan kaupunkiin annetulla valtioneuvoston päätöksellä [\(304/2008\)](<https://www.finlex.fi/fi/lainsaadanto/2008/304>) Kokkolaan liitettyjen kuntien alueita;

<a id="section-2-subsection-2-paragraph-2"></a>
- **2.** Lounais\-Suomen alueyksikön toimialue muodostuu Varsinais\-Suomen maakunnan alueesta lukuun ottamatta 1 kohdassa mainittuja Rannikon alueyksikön toimialueeseen kuuluvia kuntia sekä Satakunnan maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-3"></a>
- **3.** Hämeen\-Uudenmaan alueyksikön toimialue muodostuu Uudenmaan maakunnan alueesta lukuun ottamatta 1 kohdassa mainittuja Rannikon alueyksikön toimialueeseen kuuluvia kuntia sekä Kanta\-Hämeen ja Päijät\-Hämeen maakuntien alueista;

<a id="section-2-subsection-2-paragraph-4"></a>
- **4.** Kaakkois\-Suomen alueyksikön toimialue muodostuu Kymenlaakson ja Etelä\-Karjalan maakuntien alueista;

<a id="section-2-subsection-2-paragraph-5"></a>
- **5.** Pirkanmaan alueyksikön toimialue muodostuu Pirkanmaan maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-6"></a>
- **6.** Etelä\-Savon alueyksikön toimialue muodostuu Etelä\-Savon maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-7"></a>
- **7.** Etelä\- ja Keski\-Pohjanmaan alueyksikön toimialue muodostuu Etelä\-Pohjanmaan maakunnan alueesta, Isokyröstä ja Laihiasta sekä Keski\-Pohjanmaan maakunnan alueesta; Kokkolasta toimialueeseen kuuluvat kuitenkin vain 1 kohdassa mainitulla valtioneuvoston päätöksellä siihen liitettyjen kuntien alueet;

<a id="section-2-subsection-2-paragraph-8"></a>
- **8.** Keski\-Suomen alueyksikön toimialue muodostuu Keski\-Suomen maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-9"></a>
- **9.** Pohjois\-Savon alueyksikön toimialue muodostuu Pohjois\-Savon maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-10"></a>
- **10.** Pohjois\-Karjalan alueyksikön toimialue muodostuu Pohjois\-Karjalan maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-11"></a>
- **11.** Kainuun alueyksikön toimialue muodostuu Kainuun maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-12"></a>
- **12.** Pohjois\-Pohjanmaan alueyksikön toimialue muodostuu Pohjois\-Pohjanmaan maakunnan alueesta;

<a id="section-2-subsection-2-paragraph-13"></a>
- **13.** Lapin alueyksikön toimialue muodostuu Lapin maakunnan alueesta\.

<a id="section-2-subsection-3"></a>
#### \(3\)

Rannikon alueyksikkö on Suomen metsäkeskuksesta annetun lain [\(418/2011\) 3 §:n](<https://www.finlex.fi/fi/lainsaadanto/2011/418#chp_2__sec_3>) 3 momentissa pääasiallisesti ruotsin\- ja kaksikielisiä alueita varten tarkoitettu alueyksikkö\.

<a id="section-3"></a>
### 3 § Alueyksiköiden päätoimipaikat

<a id="section-3-subsection-1"></a>
#### \(1\)

Alueyksiköiden päätoimipaikat ovat seuraavat:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Rannikon alueyksikön Helsinki;

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Lounais\-Suomen alueyksikön Turku;

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** Hämeen\-Uudenmaan alueyksikön Lahti;

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** Kaakkois\-Suomen alueyksikön Kotka;

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** Pirkanmaan alueyksikön Tampere;

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** Etelä\-Savon alueyksikön Mikkeli;

<a id="section-3-subsection-1-paragraph-7"></a>
- **7.** Etelä\- ja Keski\-Pohjanmaan alueyksikön Seinäjoki;

<a id="section-3-subsection-1-paragraph-8"></a>
- **8.** Keski\-Suomen alueyksikön Jyväskylä;

<a id="section-3-subsection-1-paragraph-9"></a>
- **9.** Pohjois\-Savon alueyksikön Kuopio;

<a id="section-3-subsection-1-paragraph-10"></a>
- **10.** Pohjois\-Karjalan alueyksikön Joensuu;

<a id="section-3-subsection-1-paragraph-11"></a>
- **11.** Kainuun alueyksikön Kajaani;

<a id="section-3-subsection-1-paragraph-12"></a>
- **12.** Pohjois\-Pohjanmaan alueyksikön Oulu;

<a id="section-3-subsection-1-paragraph-13"></a>
- **13.** Lapin alueyksikön Rovaniemi\.

<a id="section-4"></a>
### 4 § Voimaantulo

<a id="section-4-subsection-1"></a>
#### \(1\)

Tämä asetus tulee voimaan 1 päivänä tammikuuta 2012\.
