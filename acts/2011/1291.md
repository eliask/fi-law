<a id="section-2"></a>
### 2 §

<a id="section-2-subsection-1"></a>
#### \(1\)

Rikosrekisteriin merkitään seuraavat tiedot:

<a id="section-2-subsection-1-paragraph-1"></a>
- **1.** henkilön nimi, henkilötunnus ja kansalaisuus;

<a id="section-2-subsection-1-paragraph-2"></a>
- **2.** tuomioistuimen nimi ja ratkaisupäivä;

<a id="section-2-subsection-1-paragraph-3"></a>
- **3.** syyksi luettu rikos, tekoaika ja rangaistus;

<a id="section-2-subsection-1-paragraph-4"></a>
- **4.** rikoslain \(39/1889\) 3 luvun 4 §:n 1 tai 2 momentin nojalla rangaistukseen tuomitsematta jättäminen;

<a id="section-2-subsection-1-paragraph-5"></a>
- **5.** yhteisen vankeusrangaistuksen määrääminen;

<a id="section-2-subsection-1-paragraph-6"></a>
- **6.** ratkaisun lainvoimaisuus;

<a id="section-2-subsection-1-paragraph-7"></a>
- **7.** ehdollisen vankeuden määrääminen täytäntöönpantavaksi;

<a id="section-2-subsection-1-paragraph-8"></a>
- **8.** jäännösrangaistuksen määrääminen täytäntöönpantavaksi;

<a id="section-2-subsection-1-paragraph-9"></a>
- **9.** nuorisorangaistuksen suorittaminen ja muuntaminen;

<a id="section-2-subsection-1-paragraph-10"></a>
- **10.** yhdyskuntapalvelun suorittaminen ja muuntaminen vankeudeksi;

<a id="section-2-subsection-1-paragraph-11"></a>
- **11.** valvontarangaistuksesta vapauttaminen, suorittamatta oleva jäännösrangaistus, ehdonalaisen vapauden koeajan päättyminen ja valvontarangaistuksen muuntaminen vankeudeksi;

<a id="section-2-subsection-1-paragraph-12"></a>
- **12.** vankilasta vapauttaminen, suorittamatta oleva jäännösrangaistus ja ehdonalaisen vapauden koeajan päättyminen; sekä

<a id="section-2-subsection-1-paragraph-13"></a>
- **13.** armahdus\.
