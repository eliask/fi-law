<a id="section-3"></a>
### 3 § Kunnat

<a id="section-3-subsection-1"></a>
#### \(1\)

Kuntien kielellinen jaotus on voimassa maakunnittain seuraavasti:

<a id="section-3-subsection-1-paragraph-1"></a>
- **1.** Uudenmaan maakunta:

<a id="section-3-subsection-1-paragraph-1-subparagraph-a"></a>
  - **a.** Kaksikielisiä kuntia, suomi asukkaiden enemmistön kielenä, ovat Espoo, Hanko, Helsinki, Kauniainen, Kirkkonummi, Lapinjärvi, Lohja, Loviisa, Myrskylä, Porvoo, Sipoo, Siuntio ja Vantaa\.

<a id="section-3-subsection-1-paragraph-1-subparagraph-b"></a>
  - **b.** Kaksikielisiä kuntia, ruotsi asukkaiden enemmistön kielenä, ovat Inkoo ja Raasepori\.

<a id="section-3-subsection-1-paragraph-1-subparagraph-c"></a>
  - **c.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-2"></a>
- **2.** Kymenlaakson maakunta:

<a id="section-3-subsection-1-paragraph-2-subparagraph-a"></a>
  - **a.** Kaksikielinen kunta, suomi asukkaiden enemmistön kielenä, on Pyhtää\.

<a id="section-3-subsection-1-paragraph-2-subparagraph-b"></a>
  - **b.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-3"></a>
- **3.** Varsinais\-Suomen maakunta:

<a id="section-3-subsection-1-paragraph-3-subparagraph-a"></a>
  - **a.** Kaksikielinen kunta, suomi asukkaiden enemmistön kielenä, on Turku\.

<a id="section-3-subsection-1-paragraph-3-subparagraph-b"></a>
  - **b.** Kaksikielisiä kuntia, ruotsi asukkaiden enemmistön kielenä, ovat Kemiönsaari ja Länsi\-Turunmaa\.

<a id="section-3-subsection-1-paragraph-3-subparagraph-c"></a>
  - **c.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-4"></a>
- **4.** Pohjanmaan maakunta

<a id="section-3-subsection-1-paragraph-4-subparagraph-a"></a>
  - **a.** Kaksikielisiä kuntia, suomi asukkaiden enemmistön kielenä, ovat Kaskinen ja Vaasa\.

<a id="section-3-subsection-1-paragraph-4-subparagraph-b"></a>
  - **b.** Kaksikielisiä kuntia, ruotsi asukkaiden enemmistön kielenä, ovat Kristiinankaupunki, Kruunupyy, Maalahti, Mustasaari, Pedersöre, Pietarsaari, Uusikaarlepyy ja Vöyri\.

<a id="section-3-subsection-1-paragraph-4-subparagraph-c"></a>
  - **c.** Ruotsinkielisiä kuntia ovat Korsnäs, Luoto ja Närpiö\.

<a id="section-3-subsection-1-paragraph-4-subparagraph-d"></a>
  - **d.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-5"></a>
- **5.** Keski\-Pohjanmaan maakunta

<a id="section-3-subsection-1-paragraph-5-subparagraph-a"></a>
  - **a.** Kaksikielinen kunta, suomi asukkaiden enemmistön kielenä, on Kokkola\.

<a id="section-3-subsection-1-paragraph-5-subparagraph-b"></a>
  - **b.** Muut kunnat ovat suomenkielisiä\.

<a id="section-3-subsection-1-paragraph-6"></a>
- **6.** Satakunnan, Kanta\-Hämeen, Pirkanmaan, Päijät\-Hämeen, Etelä\-Karjalan, Etelä\-Savon, Pohjois\-Savon, Pohjois\-Karjalan, Keski\-Suomen, Etelä\-Pohjanmaan, Pohjois\-Pohjanmaan, Kainuun ja Lapin maakuntien alueella kaikki kunnat ovat suomenkielisiä\.
